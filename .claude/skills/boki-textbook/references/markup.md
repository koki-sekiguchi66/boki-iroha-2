# 原稿の記法（build.pl が読む独自マークアップ）

原稿は `_src/<ID>.txt`（UTF-8）。章の並びは `_src/book.txt`。`perl build.pl` で `public/` に HTML を出す。
完全な仕様は `build.pl` 冒頭のコメント。ここでは実際に使う形をまとめる。

## book.txt（章の並び＋本の設定）

```
# 章の並び（1行1ID）
@title ケースで学ぶ簿記2級
@subtitle 物語で、日商簿記2級の商業簿記と工業簿記を学ぶ
@hero ケースで学ぶ<br>簿記2級
@mark 簿
@start 序章から読む
@key kb2
@scope 出題範囲は日本商工会議所「商工会議所簿記検定試験 出題区分表」（20xx年度適用版）に準拠しています。受験前に必ず日本商工会議所の公式情報をご確認ください。
ch00
ch01
…
apx-a
```
`@key` は localStorage のキーの接頭辞。本ごとに必ず変える（同じドメインで2冊を開いたときに「続きから読む」が混ざらないように）。
`_src/index.txt`（表紙）と `_src/guide.txt`（本書の使い方）は book.txt に書かなくても生成される。

## 章ファイルの先頭（メタデータ）

```
@num 第5章
@part 第2部 キャッシュの最前線
@subtitle 商品売買と売上原価          ← 論点名（目次・タブに出る）
@title 売上は過去最高。なのに、なぜ利益が半分以上消えたのか？   ← 章の問い
@lead 紹介文（1〜3文）
@goal この章で学ぶこと（複数行可）
@time 30分
@level ★★☆
```

## 行の記法

- `## 見出し`（自動採番・章内目次）／`### 小見出し`
- `- 箇条書き`／`1. 番号付き`／`---` 区切り線
- `**太字**` `==マーカー==` `!!赤字!!` `[リンク](url)` `{{new:2027年度〜}}` `{{old:2027年度〜範囲外}}` `<br>`
- リンクは文字数10以下なら改行しない（「第7章」など）。長い出典リンクはスマホ幅で折り返す
- 行頭が `<` の行は生HTML

## ブロック（`::名前 引数` で開き、`::` だけの行で閉じる）

### 物語と解説のボックス（入れ子可）

| ブロック | 見た目・用途 |
|---|---|
| `::mystery 見出し` | 章冒頭の「問い」。物語の事件 |
| `::scene 時と場所` | 物語の場面（明朝体の地の文） |
| `::solve 見出し` | 答え合わせ |
| `::theory 見出し` | 青：重要理論 |
| `::danger 見出し` | 赤：経営の落とし穴 |
| `::real 見出し` | 実際にあった話。中に「この章の道具で読む」と仕訳・T字勘定、最後に `::note` で出典 |
| `::cfo 見出し` | THINK（判断してみよう）。中に `::choice` を4つと `::answer` |
| `::exam 見出し` | 緑：試験の急所 |
| `::next 見出し` | 紫：上位級・実務へのつながり |
| `::point 見出し` | 補足のポイント |
| `::case 見出し` | 会社・人物の紹介カード（中に `::kpi` 可） |
| `::example 見出し` | 例題（中に `::answer`） |
| `::quiz` → `::problem 問題文` → `::answer` | 確認問題 |
| `::summary` | 章のまとめ |
| `::formula 見出し` | 式 |
| `::note` | 注記（小さい字） |
| `::tgrid` | T字勘定を横に並べる入れ物 |

### データ（入れ子不可）

```
::journal 見出し（省略可）
借方科目 金額 | 貸方科目 金額
支払利息 175,000 |                ← 複合仕訳。片側が空でもよい
::
```
→ ビルド時に貸借一致を検証。例題・確認問題の `::answer` の中にあれば、自動で「仕訳の入力欄（ドラッグ＋金額＋答え合わせ）」になる。不要なら問題文に `<!-- notry -->`。

```
::taccount 現金
4/1 普通預金 300,000 | 4/3 燃料費 180,000
= 880,000 | 880,000               ← 合計行（あれば左右一致を検証）
::
```

```
::table sum 見出し                 ← 先頭フラグ: compact（列の多い帳簿）/ sum（最後の |= 行＝上の通常行の縦計を検証）/ split:N（左N列と残りを分ける。勘定式の財務諸表用）
| 項目 | 金額 |
| 売上高 | 1,000 |
|= 合計 | 1,000 |                   ← |= は強調行
::
```
2段見出しは `!! 受入*3 | 払出*3` の行（`*3` は3列結合）。

```
::boxes 見出し          ← 貸借対照表・ボックス図（売上原価・仕掛品など）
H 左見出し | 右見出し
L a 50 現金<br>500万円   ← L/R、色（a 資産 l 負債 e 純資産 x 費用 r 収益 p 利益 s z k d）、高さ比、ラベル
R l 30 借入金
::
```
`::steps` / `::kpi` / `::timeline` は「項目 | 説明 | 補足」の行。`::timeline` は行頭 `!` で強調。

### 演習（自動採点・自己テストつき）

- 穴埋め：本文や表に `[[答え]]`、記号つき `[[ア:答え]]`、復習章つき `[[答え@15・18]]`。語句は選択式で、選択肢は答え＋ `<!-- choices: 利益 | 損失 -->`。`[[]]` は「空欄のままが正解」。
- 分類：
```
::sort 指示文
@cats 資産 | 負債 | 純資産
現金 => 資産
::
```
- チェック表：`::checks 指示文`、1行目が見出し、以降「行名 | ✓ | | ✓」。
- シミュレーター：`::sim 種類 タイトル` と `@expect キー=値`（本文の数値と照合）。種類は kb.js に実装したものだけ（3級: fifo / ccc / dep）。新しい種類は build.pl の `r_sim` と kb.js の両方に足し、`@expect` で本文の数字と一致することを自己テストで確かめる。
- 模擬試験：`::mock 60` と「大問の見出し | 配点」の行。中の問題の穴埋め・仕訳を採点し、間違えた章を示す。

### THINK（選択式）の形

```
::cfo 見出し（判断の場面）
状況の説明（誰が・何を迫られているか）。
::table 判断の材料（単位：万円）
| 項目 | A案 | B案 |
…
::
「まず〜を計算してから選んでほしい」と、手を動かす指示を1行。
::choice A. もっともらしい選択肢
**× 一言の評価。**計算を示した講評。なぜ魅力的に見えるか、なぜ失敗するか。
::
::choice B. …
**◎ …**
::
（C・D も同様。◎は1つ、○△×を混ぜる）
::answer 考え方の例を見る
選択肢を超えた一般原則と、物語のその後。
::
::
```
選ぶまで講評と解説は閉じている。選んだ選択肢の講評だけが開き、`::answer` も開く。

## 用語ポップアップ

付録A（`apx-a.txt`）の辞典の見出し語を、本文の各見出しごとに最初の1回だけ自動でタップ可能にする。新しい勘定科目を本文で使ったら、辞典にも足す。
辞典として読み込まれるのは、見出しが「資産の勘定科目」「負債の勘定科目」「純資産の勘定科目」「収益の勘定科目」「費用の勘定科目」「評価勘定…」「その他の勘定…」で始まる `::table` だけ。行の形は次のとおり（列は「勘定科目 | ひとことで言うと | 章」）。

```
::table 資産の勘定科目
| 勘定科目 | ひとことで言うと | 章 |
| 現金<br>^^げんきん^^ | 通貨と通貨代用証券（他人振出小切手など） | [3章](ch03.html) |
::
```
2級で工業簿記の勘定（材料・仕掛品・製造間接費など）を足すなら、build.pl の `load_terms` の見出しの判定（`資産|負債|純資産|収益|費用` などの正規表現）に、工業簿記用の分類を加える。
