::mystery 売上は増えたが、酒はまだ蔵の中にある
5月14日、金曜日。月次の試算表を確かめていた澪は、売上の行で手を止めた。5月の売上が、4月より**1,200万円**多い。
理由はすぐ分かった。4月に募集した頒布会「汐見の四季」だ。6月・9月・12月・3月の年4回、季節の酒を2本ずつ会員に届ける。年会費は2万4,000円の前払い。予想を超える500人が申し込み、5月10日に合わせて1,200万円が振り込まれた。岩倉は、それを入金の日に売上として記録していた。
「お金は入りました。売上でしょう」と岩倉は言った。
だが、最初の発送は6月だ。いま蔵にあるのは、これから瓶に詰める酒だけ。会員が途中で解約すれば、残りの回数分は返金しなければならない。
**まだ1本も届けていない酒の代金1,200万円は、いつ、いくら売上になるのか？**
::

## 収益認識の5つのステップ

5月の訪問日、椎名は、ホワイトボードに5つの番号を書いた。
「売上をいつ、いくら計上するかには、決まった手順があります。お金が入ったときでも、契約を結んだときでもありません。**お客さんに約束したものを渡したとき**です」

::steps 収益を認識する5つのステップ
1 契約を識別する | 顧客との契約（頒布会の会員規約）を確認する
2 履行義務を識別する | 契約の中で、顧客に何を渡す約束をしているか（6月・9月・12月・3月の4回の発送）を、1つずつ数える
3 取引価格を算定する | 約束と引き換えに受け取る対価（年会費2万4,000円×500人＝1,200万円）を決める。リベートなど変動する部分は見積もる
4 取引価格を配分する | 取引価格を、履行義務ごとに配分する（4回の発送が同じ価値なら、1回300万円）
5 履行義務を充足したときに収益を認識する | 約束したものを渡したとき（1回発送するたびに300万円）、売上を計上する
::

::theory 契約負債 ― 先に受け取った代金は「渡す義務」
履行義務を充足する前に、顧客から対価を受け取ったときは、その金額を**契約負債**（負債）とする。お金は手元にあるが、酒を届ける義務を負っている状態だ。発送して義務を果たすたびに、契約負債を減らして売上に振り替える。
3級で学んだ「前受金」と考え方は同じだ。2級では、収益認識のルールにもとづく契約で生じたものを、契約負債として学ぶ。
::

::example 頒布会の取引を仕訳しなさい
(1) 5月10日、頒布会の年会費（2万4,000円×500人）12,000,000円が普通預金に入金された。
(2) 6月20日、第1回の酒を会員に発送した（取引価格の配分額は1回3,000,000円）。
::answer
::journal (1) 入金の時点では、酒を届ける義務を負っている
普通預金 12,000,000 | 契約負債 12,000,000
::
::journal (2) 第1回の発送で、4つの履行義務のうち1つを充足した
契約負債 3,000,000 | 売上 3,000,000
::
6月末の決算では、残りの3回分9,000,000円が契約負債として貸借対照表に残る。9月・12月・3月の発送ごとに、3,000,000円ずつ売上に振り替える。
::
::

## 答え合わせ ― 1,200万円のうち、6月期の売上は300万円

::solve 1,200万円は、4回に分けて売上になる。6月期の売上は300万円だけ
頒布会の約束は、「年4回、季節の酒を届ける」ことだ。売上は、その約束を1つ果たすたびに計上する。入金の時点で1,200万円を売上にすれば、まだ果たしていない3回分の900万円まで、今期の利益に入ってしまう。
6月30日の決算で、頒布会の売上は第1回の300万円。残る900万円は**契約負債**として貸借対照表の負債に載り、翌期の9月・12月・3月に売上になる。
::

岩倉は、自分の仕訳を消しながら言った。「入金の日に売上にしとったのは、問屋に酒を売るのと同じ感覚でした。問屋は、酒を受け取ってから払う。頒布会は、払ってから受け取る。順番が逆なんですな」
「そうです。順番が逆だと、負債が生まれるんです」と澪は答えた。そして気づいた。この900万円は、蔵が会員から預かった「信頼」の金額でもある。届けられなければ、返さなければならない。

## 複数の履行義務と、契約資産

頒布会の申し込みには、もう1つの選択肢があった。年会費3万円で、初回に蔵の特製の**ぐい呑み**がついてくる「酒器つきコース」だ。

::theory 複数の履行義務への配分と、契約資産
1つの契約に複数の履行義務があるときは、取引価格を、それぞれを単独で売ったときの価格（**独立販売価格**）の比で配分する。
履行義務を充足したのに、代金を請求する権利がまだ無条件ではない（ほかの義務を果たさないと請求できない）ときは、その対価を**契約資産**（資産）とする。請求できるようになったら、**売掛金**に振り替える。
::

::example 料亭との契約を仕訳しなさい
料亭「浜千鳥」と、特注の大吟醸100本と、蔵の名入りの酒器セット20組を、合わせて600,000円で納める契約を結んだ。代金は、両方を納めた後にまとめて請求する。独立販売価格は、大吟醸100本が450,000円、酒器セット20組が150,000円である。
(1) 5月25日、大吟醸100本を納めた。
(2) 6月10日、酒器セット20組を納め、代金600,000円を請求した（売掛金）。
::answer
取引価格600,000円を、独立販売価格の比（450,000円：150,000円＝3：1）で配分する。大吟醸に450,000円、酒器セットに150,000円。
::journal (1) 大吟醸を納めたが、酒器を納めるまで代金は請求できない
契約資産 450,000 | 売上 450,000
::
::journal (2) 酒器セットを納めて、全体の代金を請求できるようになった
売掛金 600,000 | 契約資産 450,000
 | 売上 150,000
::
(1)の時点で、大吟醸の分の履行義務は果たしているので、売上は計上する。だが、まだ請求できないので、相手の勘定は売掛金ではなく契約資産になる。
::
::

## 変動対価 ― リベートの見込みは、売上から引いておく

県内の大手の酒販チェーンとの取引には、**リベート**の約束がある。1年間（7月〜翌6月）の仕入れが1万本を超えたら、その年の仕入額の5%を返す。

::theory 変動対価と返金負債
値引き・リベート・返品など、受け取る対価が将来の出来事で変わる部分を**変動対価**という。変動対価は、受け取ると見込まれる金額を見積もって取引価格に含める。顧客に返す見込みの金額は、売上に含めず、**返金負債**（負債）とする。
::

::example 酒販チェーンとのリベートを仕訳しなさい
(1) 4月から6月の間に、酒販チェーンに純米吟醸を4,000,000円で掛け売りした。年間の仕入れは1万本を超える見込みが高く、売上の5%のリベートを支払うと見込まれる。
(2) 6月末、年間の仕入れが1万本を超えたことが確定し、リベート200,000円を、売掛金と相殺した。
::answer
::journal (1) 返す見込みの5%（200,000円）は売上にしない
売掛金 4,000,000 | 売上 3,800,000
 | 返金負債 200,000
::
::journal (2)
返金負債 200,000 | 売掛金 200,000
::
リベートの約束がある取引では、請求額4,000,000円のうち、返す見込みの200,000円は、はじめから売上に含めない。条件を満たさないことが確定すれば、返金負債を売上に振り替える。
::
::

## いつ渡したことになるか ― 出荷基準・着荷基準・検収基準

酒を「渡した」時点は、契約の条件によって違う。

::table 商品・製品の引渡しの時点
| 基準 | 収益を認識する時点 | 向いている取引 |
| 出荷基準 | 蔵から出荷したとき | 国内の問屋・酒販店への通常の出荷（出荷から到着までが通常の期間） |
| 着荷基準 | 顧客に届いたとき | 配送の途中で破損した場合、蔵が責任を負う契約 |
| 検収基準 | 顧客が検品して合格としたとき | 品質を確かめてから受け取る契約（料亭の特注品、輸出品など） |
::

{{new:2027年度〜}} 出荷基準・着荷基準・検収基準は、2027年度からの出題区分表で2級の論点として明記された。問題文の「検収基準により」などの指示を読み落とさないこと。

## 役務収益と役務原価 ― 酒造り体験の売上

汐見酒造は、冬の造りの季節に、一般の人が蔵人と一緒に仕込みを体験する**酒造り体験**（2泊3日、1人5万円）を始めた。売っているのは酒ではなく、体験という**サービス（役務）**だ。

::theory 役務収益・役務原価
サービスを提供して得た収益を**役務収益**、そのサービスにかかった費用を**役務原価**という。サービスの提供前に費用（講師の人件費、資材など）が発生したときは、いったん**仕掛品**に集め、サービスを提供して収益を計上したときに役務原価に振り替える。
::

::example 酒造り体験の取引を仕訳しなさい
(1) 2月の酒造り体験（参加者10人）の準備のため、案内役の蔵人の手当と資材の費用180,000円を普通預金から支払った。この費用は、体験の実施前なので仕掛品とする。
(2) 2月の体験を実施し、参加費500,000円は事前に受け取っていた（契約負債で処理済み）。準備の費用を役務原価に振り替える。
::answer
::journal (1)
仕掛品 180,000 | 普通預金 180,000
::
::journal (2) 体験の実施で、役務収益と役務原価を計上する
契約負債 500,000 | 役務収益 500,000
役務原価 180,000 | 仕掛品 180,000
::
::
::

::exam 収益認識の急所
- 代金を先に受け取ったら**契約負債**、履行義務を充足したら売上（または役務収益）に振り替える
- 複数の履行義務：取引価格を**独立販売価格の比**で配分。片方だけ渡して請求できないときは**契約資産**、請求できるようになったら**売掛金**へ
- リベートなどの**変動対価**は、返す見込みの額を**返金負債**とし、売上に含めない
- 出荷基準・着荷基準・検収基準は、問題文の指示に従う。検収基準なら、出荷しただけでは売上にしない
- 役務収益・役務原価：提供前の費用は**仕掛品**に集め、提供したときに**役務原価**へ振り替える
- 一定の期間にわたり履行義務を果たす契約（保守サービスや期間契約）は、期間の経過に応じて収益を認識する
::

::real 見積りを変えると、利益が前に来る ― 東芝の「工事進行基準」
2015年7月、東芝の第三者委員会は報告書を公表した。2008年度から2014年度の第3四半期までに、不適切な会計処理によって税引前利益が**1,518億円**かさ上げされていた。調査の対象の1つが、インフラ事業などで使われていた**工事進行基準**だった。歴代3人の社長が辞任した。
工事進行基準は、完成まで何年もかかる大型の工事で、工事の進み具合に応じて売上を少しずつ計上する方法だ。収益認識のルールでいえば、**一定の期間にわたり充足される履行義務**にあたる。進み具合（進捗度）は、多くの場合「これまでに発生した原価÷見積総原価」で測る。

**この章の道具で読む ― 見積総原価を小さく見積もると**
受注額100億円、見積総原価90億円の工事で、1年目に45億円の原価が発生したとする（仕組みを示すための例、単位：億円）。
::table 見積総原価の違いで、1年目の売上と利益はどう変わるか（単位：億円）
| 項目 | 見積総原価90億円 | 見積総原価110億円 |
| 進捗度（発生原価45億円÷見積総原価） | 50% | 約40.9% |
| 1年目の売上（受注額100億円×進捗度） | 50 | 約40.9 |
| 1年目の原価 | 45 | 45 |
| 1年目の損益 | 5 | 約△4.1 |
::
::journal ① 見積総原価を90億円とした場合の1年目（請求はまだできないので契約資産）
契約資産 50 | 売上 50
売上原価 45 | 現金預金など 45
::
同じ45億円の原価、同じ工事なのに、見積総原価を90億円と見るか110億円と見るかで、1年目は5億円の黒字にも、約4億円の赤字にもなる。本当に110億円かかる工事なら、全体では10億円の赤字の工事だ。見積りを甘くしておけば、赤字の工事が、完成するまで黒字に見え続ける。
収益認識は、「いつ、いくら売上にするか」を見積りで決める場面が多い。頒布会の発送の回数、リベートの見込み、工事の進捗度。見積りは、会計の中で最も操作されやすい場所の1つだ。
::note

::
::

::cfo 6月の決算まであと1か月 ― 頒布会の発送を前倒しするか
6月に入ったある日、岩倉が提案した。「専務、決算が赤字になるかどうかの瀬戸際です。頒布会の9月の分も、6月の発送と一緒に送ってしまえば、6月期の売上が300万円増えます。送ってしまえば、履行義務は果たしたことになるんでしょう」
::table 頒布会の資料
| 項目 | 金額 |
| 1回の発送の取引価格（500人分） | 300万円 |
| 1回の発送の原価（酒・瓶・送料） | 165万円 |
| 会員規約 | 「6月・9月・12月・3月に、その季節の酒を届ける」 |
| 9月の酒 | 夏を越して熟成させる「秋あがり」の純米吟醸。いまはまだ熟成の途中 |
::
まず、それぞれの案で6月期の売上と利益がいくら変わるか、そして、それが収益認識のルールに合うかを考えてから選んでほしい。
::choice A. 9月の分も6月に発送する。発送すれば履行義務は果たしたことになる
**× 約束したものを渡していない。**会員に約束したのは「9月に、夏を越した秋あがりの酒を届ける」ことだ。熟成途中の酒を6月に送っても、その約束を果たしたことにはならない。売上を135万円（300万円－165万円）分の利益とともに前倒しするための発送は、押し込み販売と呼ばれる不正の典型だ。高梨がそれを見抜けば、決算書全体の信用を失う。
::
::choice B. 予定どおり6月の1回分だけを発送し、6月期の売上は300万円とする
**◎ 収益認識のルールにも、会員との約束にも合っている。**6月期の頒布会の売上は300万円、利益は135万円。残る900万円は契約負債として決算書に載る。決算が赤字になるかどうかは、売上の時期をずらして決めるものではない。赤字の中身を説明できるかどうかが、高梨の判断を決める（第22章）。
::
::choice C. 会員に、9月の分を6月に前倒しで送る代わりに1割引きにすると提案し、同意した人にだけ送る
**△ 同意があれば形式は整うが、目的がずれている。**会員の同意を得て契約を変えれば、6月に渡した分を売上にできる。だが、1割引きで売上は減り、秋あがりという頒布会の価値も損なわれる。そして、決算のために契約を変えたことは、決算書を読む人には分かってしまう。会員との約束を、決算の都合で書き換えるべきではない。
::
::choice D. 入金済みの1,200万円は、すでに蔵のお金なので、全額を6月期の売上に戻す
**× 最初の誤りに戻っている。**1,200万円のうち900万円は、まだ果たしていない3回分の約束の対価だ。全額を売上にすれば、6月期の利益は900万円分かさ上げされる。会員が解約すれば返す必要があるお金を、自分の利益として報告することになる。
::
::answer 考え方の例を見る
売上は、顧客との約束を果たしたときに計上する。決算の数字のために、約束の中身や時期を動かしてはいけない。そして、契約負債は「まだ果たしていない約束」の大きさを、正直に決算書に残す仕組みだ。
澪は、岩倉の提案を断った。「契約負債の900万円は、来年の売上の予約です。高梨さんには、それも含めて説明します」。岩倉は少し黙ってから、「先代なら、送っとったでしょうな」と言った。そして、6月の発送の宛名の確認を、自分から引き受けた。
::

::next 収益認識の先にある論点
1級では、一定の期間にわたり充足される履行義務の進捗度の測り方、工事の総原価が受注額を超える見込みのときの**工事損失引当金**、返品権つきの販売、ポイント制度（カスタマー・ロイヤルティ・プログラム）、代理人取引（総額か純額か）など、収益認識の論点を広く学ぶ。

## 確認問題

::quiz
::problem 次の取引を仕訳しなさい。
(1) 3か月間の講座の受講料90,000円を、講座の開始前に普通預金で受け取った。
(2) 1か月目の講座が終了した（3か月で均等に提供する）。
::answer
::journal (1)
普通預金 90,000 | 契約負債 90,000
::
::journal (2)
契約負債 30,000 | 役務収益 30,000
::
::
::
::problem 商品Aと商品Bを合わせて100,000円で販売する契約を結んだ。独立販売価格はA 72,000円、B 48,000円である。代金はA・Bの両方を引き渡した後に請求する。次の取引を仕訳しなさい。
(1) 商品Aを引き渡した。
(2) 商品Bを引き渡し、代金を請求した（売掛金）。
::answer
取引価格100,000円を72,000円：48,000円（3：2）で配分し、A 60,000円、B 40,000円。
::journal (1)
契約資産 60,000 | 売上 60,000
::
::journal (2)
売掛金 100,000 | 契約資産 60,000
 | 売上 40,000
::
::
::
::problem 得意先に商品1,000,000円を掛けで販売した。この得意先には、一定の条件を満たした場合に販売額の3%のリベートを支払う契約があり、条件を満たす可能性が高い。仕訳しなさい。
::answer
::journal
売掛金 1,000,000 | 売上 970,000
 | 返金負債 30,000
::
::
::
::problem 次の取引を仕訳しなさい。
(1) 旅行の企画・添乗サービスについて、企画担当者の人件費40,000円を普通預金から支払った（サービスは未提供のため仕掛品とする）。
(2) 旅行が催行され、代金150,000円を現金で受け取った。(1)の費用を役務原価に振り替える。
::answer
::journal (1)
仕掛品 40,000 | 普通預金 40,000
::
::journal (2)
現金 150,000 | 役務収益 150,000
役務原価 40,000 | 仕掛品 40,000
::
::
::
::

::summary
- 収益は、顧客との契約で約束したもの（履行義務）を渡したときに認識する。5つのステップ：契約の識別→履行義務の識別→取引価格の算定→配分→充足時に認識
- 先に受け取った代金は契約負債。履行義務を充足するたびに売上に振り替える
- 複数の履行義務には独立販売価格の比で取引価格を配分する。渡したが請求できない対価は契約資産
- リベートなどの変動対価は見積もり、返す見込みの額を返金負債とする
- サービスの収益は役務収益、その費用は役務原価。提供前の費用は仕掛品に集める
- 収益認識は見積りの多い領域で、利益の操作の入り口にもなる。決算の都合で、約束の中身や時期を動かしてはいけない
::
