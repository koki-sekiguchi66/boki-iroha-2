5月12日、水曜日、午後3時。帳場のパソコンの画面に、申込みの通知が続けて鳴った。
季節ごとに年4回、蔵の酒を届ける頒布会「汐見の四季」。1年分24,000円の前払いで、締切の今日までに**500人**の申込みがあった。入金は、合わせて**1,200万円**。
岩倉は、さっそく帳面に書き込んだ。「普通預金　1,200万円／売上　1,200万円」。
澪は、その数字をしばらく見つめた。6月30日の決算で、営業利益はまだ赤字の見込みだ。1,200万円が売上に入れば、赤字は一気に消える。審査まで、あと61日。
澪：「岩倉さん、それで締めましょう。お金はもう入っているんですから」
その夜、月例の訪問の準備で電話をくれた椎名に、澪は少し誇らしげに報告した。電話の向こうで、椎名は黙った。
椎名：「澪さん。その1,200万円の酒は、もう会員の手元に届いていますか」
**お金を受け取った頒布会の1,200万円は、いつ売上になるのか？**

## 4つの約束 ― 収益認識の5つのステップ

::scene 5月13日、午前10時 ― 帳場
翌朝、椎名は予定を早めて蔵に来た。ホワイトボードに、5つの箱を縦に並べる。
椎名：「売上をいつ、いくら計上するかは、5つの順番で決めます。会員と結んだ約束を、この順番でたどってみましょう」
::

::steps 収益認識の5つのステップ
1. 契約を識別する | 誰と、どんな約束をしたか。頒布会なら、会員との「年4回届ける」契約
2. 履行義務を識別する | 約束の中の、別々の「果たすべきこと」。頒布会なら、6月・9月・12月・3月の4回の発送
3. 取引価格を算定する | 受け取る対価。値引きやリベートの見込みも含めて決める。1人24,000円
4. 取引価格を履行義務に配分する | 4回の発送に、6,000円ずつ
5. 履行義務を充足したときに収益を認識する | 発送するたびに、6,000円ずつ売上にする
::

澪：「1回目の発送は、6月20日の予定です。じゃあ、6月の決算で売上になるのは……」
椎名：「1回分、300万円だけです。残りの900万円は、まだ果たしていない約束の分。会員から預かっているお金です」
代金を先に受け取ったのに、まだ商品やサービスを渡していないとき、その対価は**契約負債**（負債）にする。3級で学んだ前受金と同じ考え方だ。

::example 頒布会の代金を受け取り、第1回を届けた
(1) 5月12日、頒布会「汐見の四季」の会費（500人×24,000円）12,000,000円が普通預金に入金された。年4回の発送で、1回分は6,000円である。
(2) 6月20日、第1回の酒を全員に発送した。
::answer
::journal (1) 入金の時点では、酒を届ける義務を負っている
普通預金 12,000,000 | 契約負債 12,000,000
::
::journal (2) 第1回の発送で、4つの履行義務のうち1つを果たした
契約負債 3,000,000 | 売上 3,000,000
::
6月末の決算では、残りの3回分9,000,000円が契約負債として貸借対照表に残る。9月・12月・3月の発送ごとに、3,000,000円ずつ売上に振り替える。
::trap
入金のときに「普通預金／売上」としないこと。収益を認識するのは、お金を受け取ったときではなく、**履行義務を充足したとき**だ。
::
::
::

::theory 収益は、約束を果たしたときに計上する
収益認識の基準では、顧客との契約にもとづく約束（履行義務）を果たし、商品やサービスの支配が顧客に移ったときに、その対価を収益として計上する。
お金が先に入っても、約束が残っていれば負債（契約負債）。約束を先に果たしても、まだ請求できなければ資産（契約資産）。売上は、お金の動きではなく、約束の進み具合についてくる。
::

## 料亭の注文 ― 複数の履行義務と、契約資産

::scene 5月25日 ― 料亭「浜千鳥」
頒布会の騒ぎが収まったころ、地元の料亭の女将から、新しい注文が来た。開店30周年の記念に、特注の大吟醸100本と、蔵の名前を入れた酒器セット20組を、まとめて納めてほしいという。
女将：「お代は、酒器までそろってから、まとめてお支払いしますね」
::

1つの契約に、別々に果たす約束が複数あるとき、取引価格を、それぞれを単独で売ったときの価格（**独立販売価格**）の比で配分する。
約束の1つを果たして売上を計上しても、ほかの約束を果たすまで代金を請求できないなら、その対価は売掛金ではなく**契約資産**（資産）とする。請求できるようになったら、売掛金に振り替える。

::example 料亭に、大吟醸と酒器セットを納めた
料亭「浜千鳥」と、特注の大吟醸100本と蔵の名入りの酒器セット20組を、合わせて600,000円で納める契約を結んだ。代金は、両方を納めた後にまとめて請求する。独立販売価格は、大吟醸100本が450,000円、酒器セット20組が150,000円である。
(1) 5月25日、大吟醸100本を納めた。
(2) 6月10日、酒器セット20組を納め、代金600,000円を請求した。
::answer
取引価格600,000円を、独立販売価格の比（450,000円：150,000円＝3：1）で配分する。大吟醸に450,000円、酒器セットに150,000円。
::journal (1) 大吟醸を納めたが、酒器を納めるまで代金は請求できない
契約資産 450,000 | 売上 450,000
::
::journal (2) 酒器セットを納めて、全体の代金を請求できるようになった
売掛金 600,000 | 契約資産 450,000
 | 売上 150,000
::
(1)の時点で、大吟醸の分の約束は果たしているので、売上は計上する。だが、まだ請求できないので、相手の勘定は売掛金ではなく契約資産になる。
::trap
独立販売価格の合計（ここでは600,000円）と契約の価格が違うときも、配分は**独立販売価格の比**で行う。契約の価格を、品物の数で割らないこと。
::
::
::

## 酒販チェーンのリベート ― 変動対価と返金負債

県内の大手の酒販チェーンとの取引には、**リベート**の約束がある。1年間（7月〜翌6月）の仕入れが1万本を超えたら、その年の仕入額の5%を返す。
受け取る対価のうち、値引き・リベート・返品などで将来変わる部分を**変動対価**という。返す見込みの額は、はじめから売上に含めず、**返金負債**（負債）とする。

::example 酒販チェーンに売り、リベートを見込む
(1) 4月から6月の間に、酒販チェーンに純米吟醸を4,000,000円で掛け売りした。年間の仕入れが1万本を超える見込みが高く、売上の5%のリベートを支払うと見込まれる。
(2) 6月末、年間の仕入れが1万本を超えたことが確定し、リベート200,000円を売掛金と相殺した。
::answer
::journal (1) 返す見込みの5%（200,000円）は売上にしない
売掛金 4,000,000 | 売上 3,800,000
 | 返金負債 200,000
::
::journal (2)
返金負債 200,000 | 売掛金 200,000
::
請求額4,000,000円のうち、返す見込みの200,000円は、はじめから売上に含めない。もし条件を満たさないことが確定すれば、返金負債を売上に振り替える。
::trap
リベートを払うときに「売上／売掛金」とする処理は、見込みを立てていない場合のものだ。見込める変動対価は、売り上げた時点で返金負債にしておく。
::
::
::

買う側から見れば、同じリベートは**仕入割戻**になる。汐見酒造が瓶の仕入先から、年間の購入量に応じて30,000円の割戻しを受けたら、仕入（製造業の材料なら材料）から差し引く（買掛金 30,000／仕入 30,000）。

## 届いた日か、検品した日か ― 引渡しの基準と、役務収益

商品や製品を「渡した」時点は、契約の条件で違う。

::table 商品・製品の引渡しの時点
| 基準 | 収益を認識する時点 | 向いている取引 |
| 出荷基準 | 蔵から出荷したとき | 国内の問屋・酒販店への通常の出荷（出荷から到着までが通常の期間） |
| 着荷基準 | 顧客に届いたとき | 配送の途中で破損したら蔵が責任を負う契約 |
| 検収基準 | 顧客が検品して合格としたとき | 品質を確かめてから受け取る契約（特注品、輸出品など） |
::

出荷基準・着荷基準・検収基準は、2級の出題区分表に示されている論点だ。問題文の「検収基準により」などの指示を読み落とさないこと。
酒を売るだけが、蔵の仕事ではない。冬の造りの季節に、一般の人が蔵人と一緒に仕込みを体験する**酒造り体験**（2泊3日、1人5万円）も始めた。売っているのは、酒ではなく体験という**サービス（役務）**だ。サービスを提供して得た収益を**役務収益**、そのサービスにかかった費用を**役務原価**という。

::example 酒造り体験の準備と実施
(1) 2月の酒造り体験（参加者10人）の準備のため、案内役の蔵人の手当と資材の費用180,000円を普通預金から支払った。体験の実施前なので、仕掛品とする。
(2) 2月の体験を実施した。参加費500,000円は事前に受け取り、契約負債で処理していた。準備の費用を役務原価に振り替える。
::answer
::journal (1)
仕掛品 180,000 | 普通預金 180,000
::
::journal (2) 体験の実施で、役務収益と役務原価を計上する
契約負債 500,000 | 役務収益 500,000
役務原価 180,000 | 仕掛品 180,000
::
サービスの提供前に費用がかかったら、いったん仕掛品に集め、サービスを提供して収益を計上したときに、役務原価に振り替える。
::trap
準備の費用を、支払った時点で役務原価にしないこと。収益と費用は、同じ時点で計上する。
::
::
::

澪は、頒布会の帳面を自分で書き直した。岩倉が書いた「普通預金　1,200万円／売上　1,200万円」の横に、二重線を引く。

::solve 1,200万円は、4回に分けて売上になる。6月期の売上は300万円だけ
頒布会の約束は、「年4回、季節の酒を届ける」ことだ。売上は、その約束を1つ果たすたびに計上する。6月30日の決算で売上になるのは、6月20日に送る第1回の300万円だけ。残る900万円は**契約負債**として貸借対照表の負債に載り、9月・12月・3月の発送のたびに売上になる。
もし入金の日に1,200万円を売上にしていたら、まだ果たしていない900万円まで今期の利益に入り、審査に出す決算書は、実態より900万円よく見えていた。それが分かったとき、高梨が信じなくなるのは、決算書の数字の全部だ。
**売上は、お金ではなく約束についてくる。**前払いの900万円は、利益ではなく、会員から預かった信頼の金額だった。
::

岩倉は、自分の仕訳を消しながら言った。
岩倉：「入金の日に売上にしとったのは、問屋に酒を売るのと同じ感覚でした。問屋は、酒を受け取ってから払う。頒布会は、払ってから受け取る。順番が逆なんですな」
澪：「順番が逆だと、負債が生まれるんです。届けられなければ、返さなければならないお金だから」

### 試験で狙われるパターン ― 一定の期間にわたる履行義務・クレジット売掛金・5つのステップの穴埋め

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 一定の期間にわたって果たす約束**　保守サービスや会員制のサービスのように、期間を通じて少しずつ約束を果たすものは、期間の経過に応じて収益を計上する。

::example 4か月の会員制サービスの会費を受け取った
3月1日、蔵の会員制の「酒蔵サロン」（3月から6月の4か月、毎月の試飲会）の会費240,000円を普通預金で受け取った。3月末に、1か月分の収益を計上する。
::answer
::journal (1) 3月1日
普通預金 240,000 | 契約負債 240,000
::
::journal (2) 3月末：4か月のうち1か月分
契約負債 60,000 | 役務収益 60,000
::
::trap
4か月分の会費を、受け取った月にまとめて収益にしないこと。期間で按分する。
::
::
::

**② クレジット売掛金（キャッシュレス決済を含む）**　日本橋店のカードやQRコードでの売上は、決済会社から後で入金される債権として**クレジット売掛金**とし、手数料は支払手数料にする（3級の復習）。2027年度からの区分表では、クレジット売掛金にキャッシュレス決済が含まれることが明記された。

**③ 5つのステップの用語**　「履行義務」「取引価格」「独立販売価格」「契約資産」「契約負債」「返金負債」の意味を問う穴埋めが出る。

::steps 解法の型 ― 収益認識の仕訳
1. お金と約束のどちらが先か | お金が先なら契約負債、約束が先なら売掛金か契約資産
2. 約束はいくつあるか | 複数なら独立販売価格の比で配分
3. 請求できるか | まだ請求できない対価は契約資産、請求できたら売掛金
4. 返す見込みはあるか | リベート・返品の見込みは返金負債。売上に含めない
5. いつ渡したか | 出荷・着荷・検収の指示を確かめる。サービスは提供したとき（期間なら按分）
::

## 椎名が監査法人で見たもの ― 見積りを変えると、利益が前に来る

::scene 5月13日、夕方 ― 帳場
収益認識の説明を終えた椎名は、ホワイトボードの「見積り」という字を丸で囲んだ。
椎名：「頒布会の回数、リベートの見込み、どこまで約束を果たしたか。収益認識は、見積りだらけです」
椎名：「私が監査法人にいたころ、日本中の会計士が凍りついた事件がありました。2015年の東芝です」
::

2015年7月、東芝の第三者委員会は、2008年度から2014年度の第3四半期までの不適切な会計処理で、税引前利益を累計で約**1,518億円**修正する必要があると報告した。調査の対象の1つが、インフラ事業などで使われていた**工事進行基準**だった。歴代3人の社長が辞任した。
工事進行基準は、完成まで何年もかかる大型の工事で、工事の進み具合に応じて売上を少しずつ計上する方法だ。この章のルールでいえば、**一定の期間にわたり充足される履行義務**にあたる。進み具合（進捗度）は、多くの場合「これまでに発生した原価÷見積総原価」で測る。
椎名：「受注額100億円の工事で、1年目に45億円の原価がかかったとします。見積総原価を90億円と見るか、110億円と見るかで、1年目はどうなるでしょう」

::table 見積総原価の違いで、1年目の売上と利益はどう変わるか（仕組みを示すための例、単位：億円）
| 項目 | 見積総原価90億円 | 見積総原価110億円 |
| 進捗度（発生原価45億円÷見積総原価） | 50% | 約40.9% |
| 1年目の売上（受注額100億円×進捗度） | 50 | 約40.9 |
| 1年目の原価 | 45 | 45 |
| 1年目の損益 | 5 | 約△4.1 |
::

::journal 見積総原価を90億円とした場合の1年目（まだ請求できないので契約資産。単位：億円）
契約資産 50 | 売上 50
売上原価 45 | 現金預金 45
::

澪：「同じ45億円の原価、同じ工事なのに、見積りを変えるだけで、1年目は黒字にも赤字にもなる」
椎名：「本当に110億円かかる工事なら、全体では10億円の赤字です。見積りを甘くしておけば、赤字の工事が、完成するまで黒字に見え続けます」
澪は、頒布会の帳面の「900万円」を思い出した。売上を前に持ってくる方法は、1つではない。

::note
出典：[PHILE WEB「東芝の不適切会計問題で歴代3社長が辞任、経営刷新委員会を設置」（2015年7月21日）](https://www.phileweb.com/sp/news/d-av/201507/21/37107.html)。工事進行基準の詳しい処理は1級の範囲
::

::danger 売上を前倒しする方法は、いくつもある
前受けした代金を受け取った日に売上にする、まだ渡していない商品を出荷したことにする、進み具合の見積りを甘くする。どれも、帳簿の上では利益が早く増えるが、翌期以降の利益を先に使っているにすぎない。見つかれば、会社の数字のすべてが信用を失う。
::

::cfo 6月の決算の前に、9月分を送るか ― 営業担当の提案
5月末、営業の担当者が澪に提案した。「頒布会の9月分の酒も、6月20日に一緒に送ってしまいましょう。そうすれば、600万円が今期の売上になります」。
**前提**
- 頒布会の約束は「年4回、季節の酒を届ける」。9月分は、夏を越して熟成させた「ひやおろし」の予定
- 9月分を6月に送れば、その分の約束は果たしたことになり、売上300万円（原価165万円）を今期に計上できる
- 6月の決算は、営業利益が200万円前後の赤字になる見込み
- 審査で高梨は、頒布会の会員の継続率も見ると言っている
- 頒布会の会員の申込み数は、去年の倍だった
::choice A. 送る。約束を果たして売上を立てるのだから、ルールの上の問題はない
**△ ルールの形は満たしても、約束の中身を変えている。**9月分は「夏を越した酒」という約束だ。6月に送る酒は、会員が買ったものではない。売上は立つが、会員の満足と継続率を失う。
::
::choice B. 9月分の半分だけを送り、残りは9月に送る
**× 中途半端に約束を崩している。**売上は150万円しか前に来ないうえ、会員にとっては、季節の酒の約束が半分だけ破られる。
::
::choice C. 送るが、決算書の注記に「前倒しで発送した」と書いておく
**△ 正直に書く点は評価できるが、約束を変える問題は残る。**高梨は、注記を読めば、利益を前に持ってきたことに気づく。審査では、注記まで読まれる。
::
::choice D. 送らない。9月分は9月に届けてこそ約束で、今期の売上は300万円のままにする
**◎ 約束の中身で判断している。**前倒しで得られる今期の利益は、売上300万円－原価165万円＝135万円にすぎない。その代わりに、季節の酒という約束を崩し、会員の継続率と、決算書への信頼を失う。審査で見せるべきは、前倒しの135万円ではなく、900万円の契約負債が示す来期の売上の確かさだ。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「売上を立てられるか」ではなく、「その売上は、会員と結んだ約束を果たしたことになるのか。そして、前倒しで何を得て、何を失うか」を問う。
#### 手順2　前提の数字で確かめる
前倒しで今期に入る利益は、300万円－165万円＝135万円。営業利益の赤字200万円は、それでも消えない。一方、6月末の契約負債900万円は、来期に売上になる確かな約束として、高梨に見せられる。
#### 手順3　ほかの答えに引かれる理由
Aは「約束を果たせば売上」というルールの形に、Cは「正直に書けば許される」という考えに、Bは折衷の安心に引かれる。会員の申込み数が去年の倍だったことは、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **売上は約束の中身についてくる**：形だけ約束を果たしても、中身を変えれば顧客を失う
- **前倒しで得るものと失うものを、数字で並べる**：今期の135万円と、来期以降の信頼
- **契約負債は、来期の売上の確かさを示す**：審査では、これを見せればよい
#### 前提が変われば
もし会員から「9月分も早く欲しい」という申し出が多く、会員が自分で前倒しを選べる形にするなら、選んだ会員の分を6月に送って売上にするのは、約束の変更として筋が通る。
::
::

::exam 収益認識の急所
- 代金を先に受け取ったら**契約負債**、約束を果たしたら売上（または役務収益）に振り替える
- 複数の約束：取引価格を**独立販売価格の比**で配分。まだ請求できない対価は**契約資産**、請求できたら売掛金へ
- リベートなどの**変動対価**は、返す見込みの額を**返金負債**とし、売上に含めない
- 出荷基準・着荷基準・検収基準は問題文の指示に従う。検収基準なら、出荷しただけでは売上にしない
- 役務収益・役務原価：提供前の費用は**仕掛品**に集め、提供したときに役務原価へ
::

::next 見積りの重い収益は、1級へ
1級では、工事進行基準にあたる「一定の期間にわたり充足される履行義務」の進捗度の測り方や、損失が見込まれる工事の受注損失引当金、ポイント制度や返品権付きの販売など、見積りの重い収益の処理を学ぶ。
::

::summary
- 収益は、5つのステップで、約束（履行義務）を果たしたときに計上する
- 先に受け取った対価は契約負債、先に果たしたが請求できない対価は契約資産
- 複数の約束には、取引価格を独立販売価格の比で配分する
- 返す見込みのリベートは、売上に含めず返金負債にする。買う側では仕入割戻
- 引渡しの時点は出荷・着荷・検収の基準に従い、サービスは提供したとき（期間なら按分）に収益とする
::

## 確認問題

::quiz
::problem 次の取引を仕訳しなさい。
(1) 年3回の講習会の受講料90,000円を、事前に普通預金で受け取った。
(2) 講習会の第1回を開催した。
::answer
::journal (1)
普通預金 90,000 | 契約負債 90,000
::
::journal (2)
契約負債 30,000 | 役務収益 30,000
::
受け取った時点ではサービスを提供していないので契約負債。第1回の開催で、3回のうち1回分を役務収益にする。
::
::
::problem 商品Aと商品Bを合わせて100,000円で販売する契約を結んだ。独立販売価格はA 72,000円、B 48,000円である。代金はA・Bの両方を引き渡した後に請求する。次の取引を仕訳しなさい。
(1) 商品Aを引き渡した。
(2) 商品Bを引き渡し、代金を請求した。
::answer
::journal (1) 100,000円×72/120＝60,000円
契約資産 60,000 | 売上 60,000
::
::journal (2)
売掛金 100,000 | 契約資産 60,000
 | 売上 40,000
::
取引価格100,000円を、独立販売価格の比（72,000：48,000＝3：2）で配分する。Aを渡しても請求できないので、Aの分は契約資産になる。
::
::
::problem 得意先に商品1,000,000円を掛けで販売した。この得意先には、一定の条件を満たした場合に販売額の3%のリベートを支払う契約があり、条件を満たす可能性が高い。仕訳しなさい。
::answer
::journal
売掛金 1,000,000 | 売上 970,000
 | 返金負債 30,000
::
返す見込みの3%は売上に含めず、返金負債とする。
::
::

提供前の費用は仕掛品に集め、提供したときに役務原価にする。
