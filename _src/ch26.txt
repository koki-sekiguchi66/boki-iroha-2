**グループで見たら、芹沢酒造の赤字は、本当はいくらなのか？**

## 成果連結 ― グループの中の取引を消す

第25章の資本連結は、親会社の投資と子会社の資本の相殺だった。連結修正のもう1つの柱が、グループの中の取引の結果を消す**成果連結**だ。

::theory 連結会社間の取引は、グループの外から見れば「なかったこと」
連結財務諸表は、親会社と子会社を1つの会社として見る。1つの会社の中で、ある部署が別の部署に物を渡しても、売上にはならない（第24章の本店から支店への送付と同じ）。だから、連結会社間の取引は、連結財務諸表から消す。
- **売上と仕入（売上原価）の相殺**：グループの中の売上高と、それに対応する売上原価を消す
- **債権と債務の相殺**：グループの中の売掛金と買掛金、貸付金と借入金、未収利息と未払利息などを消す。利息の収益と費用も消す
- **未実現利益の消去**：グループの中で利益を乗せて売った資産が、期末にまだグループの中に残っているとき、その利益は外部に売って**実現**していないので消す
::

## 売上と債権債務の相殺

::example 汐見酒造（親会社）と芹沢酒造（子会社、持分60%）の間の取引を相殺消去する（単位：万円）
(1) 汐見酒造は芹沢酒造に、酒米を1,200万円で売った。芹沢酒造は日本橋店（汐見酒造）に、酒を800万円で売った。
(2) 6月30日に、芹沢酒造の汐見酒造に対する買掛金が300万円ある。
(3) 汐見酒造は芹沢酒造に1,000万円を貸し付けている。当期の利息は20万円で、受取済み・支払済みである。
(4) 汐見酒造は、(2)の売掛金300万円と(3)の貸付金1,000万円に、2%の貸倒引当金を設定している。
::answer
::journal (1) 連結会社間の売上高と売上原価の相殺
売上高 2,000 | 売上原価 2,000
::
::journal (2) 売掛金と買掛金の相殺
買掛金 300 | 売掛金 300
::
::journal (3) 貸付金と借入金、利息の相殺
借入金 1,000 | 貸付金 1,000
受取利息 20 | 支払利息 20
::
::journal (4) グループの中の債権に設定した貸倒引当金を消す：(300万円＋1,000万円)×2%
貸倒引当金 26 | 貸倒引当金繰入 26
::
(1)は、親会社から子会社への売上も、子会社から親会社への売上も、まとめて相殺する。連結財務諸表では「売上高」「売上原価」の科目で修正する（個別の帳簿の「仕入」は、連結では売上原価に含まれている）。
(4)は、親会社の債権に設定した貸倒引当金の修正なので、非支配株主持分には関係しない。
::trap
利息の相殺を忘れないこと。貸付金と借入金を消したら、受取利息と支払利息、未収利息と未払利息も消す。
::
::
::

## 未実現利益の消去 ― ダウンストリームとアップストリーム

グループの中で売った米や酒が、期末にまだ買った側の倉庫に残っていたら、その中に含まれる売った側の利益は、まだ外部に実現していない。

::theory ダウンストリームとアップストリーム
- **ダウンストリーム**（親会社 → 子会社への販売）：未実現利益は、売った親会社の利益なので、**全額を親会社が負担**する
- **アップストリーム**（子会社 → 親会社への販売）：未実現利益は、売った子会社の利益なので、消去額のうち**非支配株主の持分比率の分を非支配株主に負担させる**
消去の仕訳は、棚卸資産なら「売上原価／商品（原材料など）」、土地なら「固定資産売却益／土地」。アップストリームでは、さらに「非支配株主持分／非支配株主に帰属する当期純利益」で、非支配株主の負担分を振り替える。
2級では、未実現利益の消去は、**棚卸資産と土地**に限って出題される。
::

::example 6月30日の未実現利益を消去する（単位：万円）
(1) ダウンストリーム：芹沢酒造の原材料の中に、汐見酒造から買った酒米が300万円分残っている。汐見酒造は、売価の20%の利益を乗せて売っている。
(2) アップストリーム：日本橋店の商品の中に、芹沢酒造から買った酒が200万円分残っている。芹沢酒造は、売価の25%の利益を乗せて売っている。
(3) アップストリーム：芹沢酒造は、帳簿価額1,200万円の土地を、汐見酒造に1,500万円で売った。汐見酒造は、この土地を期末に持っている。
::answer
::journal (1) ダウンストリーム：300万円×20%＝60万円。全額を親会社が負担
売上原価 60 | 原材料 60
::
::journal (2) アップストリーム：200万円×25%＝50万円。うち40%（20万円）を非支配株主が負担
売上原価 50 | 商品 50
非支配株主持分 20 | 非支配株主に帰属する当期純利益 20
::
::journal (3) アップストリーム：土地の売却益300万円を消去。うち40%（120万円）を非支配株主が負担
固定資産売却益 300 | 土地 300
非支配株主持分 120 | 非支配株主に帰属する当期純利益 120
::
未実現利益の計算では、利益が「売価に対する率」（売上総利益率）で示されているか、「原価に対する率」（加算率）で示されているかを、必ず確かめる。原価の25%を加算して売っているなら、未実現利益は売価×25/125になる。
::trap
アップストリームで、非支配株主の負担分の振替えを忘れないこと。ダウンストリームでは振り替えない。
::
::
::

### 1年後の連結 ― 期首の在庫に残っていた未実現利益

椎名：「来年の連結では、もう1つ手順が増えますよ。今年の6月末に芹沢酒造の倉庫に残っている汐見の酒米。その未実現利益60万円は、来年、芹沢酒造がその米で酒を造って外に売れば、実現します」

::theory 期首の未実現利益
前期末の棚卸資産に含まれていた未実現利益は、当期の期首の棚卸資産にもそのまま含まれている。連結では、
1. **開始仕訳**で、前期に行った消去をもう一度行う（損益の科目は利益剰余金当期首残高に置き換える）
2. その在庫は当期中に外部に売れて利益が実現したとみなし、**当期の売上原価を減らして**利益を戻す
アップストリームなら、それぞれについて非支配株主の負担分も振り替える。
::

::example 2028年6月期の連結で、期首の酒米に含まれていた未実現利益60万円（ダウンストリーム）を処理する（単位：万円）
::answer
::journal (1) 開始仕訳：前期末の未実現利益の消去を、もう一度行う
利益剰余金当期首残高 60 | 原材料 60
::
::journal (2) 期首の在庫が当期に実現したとみなす
原材料 60 | 売上原価 60
::
(1)と(2)をまとめると「利益剰余金当期首残高 60／売上原価 60」になる。前期の利益から消した60万円が、当期の利益として戻ってくる。グループの外に売れた期に、利益が計上し直されるわけだ。
アップストリームの場合は、(1)で「非支配株主持分当期首残高／利益剰余金当期首残高」、(2)で「非支配株主に帰属する当期純利益／非支配株主持分当期変動額」の仕訳を加える。
::
::

## 連結精算表 ― 合算して、消して、並べる

試験では、連結修正仕訳を連結精算表にまとめ、連結財務諸表の金額を求める問題がよく出る。型を、例題で確かめよう。

澪：「本当の赤字が見えたから、合併で何を直せばいいかも見えます」

### 試験で狙われるパターン ― 成果連結の4つの型

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 利益率か加算率か**　「売上総利益率25%」なら売価×25%、「原価に25%を加算」なら売価×25/125。ここで間違えると、ほかの修正がすべて正しくても答えが合わない。

**② ダウンかアップか**　親会社が売ったならダウンで、親会社が全額負担。子会社が売ったならアップで、非支配株主も持分比率で負担する。

**③ 期首の未実現利益**　開始仕訳で消し、当期の売上原価を減らして戻す。前期末の在庫の分を、当期末の在庫の分と取り違えない。

**④ 連結精算表と利益剰余金**　利益剰余金の連結の額は、親会社の利益剰余金＋子会社の利益剰余金－開始仕訳の分－当期の修正の損益への影響。親会社株主に帰属する当期純利益とつながっている。

::steps 解法の型 ― 成果連結
1. 取引を書き出す | 売上・仕入、債権・債務、貸付・借入と利息、資産の売買
2. 相殺する | 売上高／売上原価、買掛金／売掛金、借入金／貸付金、受取利息／支払利息
3. 貸倒引当金を直す | グループの中の債権に設定した分を戻す（子会社の債権なら非支配株主の負担も）
4. 未実現利益を消す | 期末の在庫・土地に残る利益。ダウンは親が全額、アップは非支配株主も負担
5. 精算表にまとめる | 合計→修正・消去→連結の金額。利益剰余金と当期純利益のつながりを検算する
::

## 叔父の提案 ― 子会社を、連結から外した会社

::scene 9月22日、水曜日 ― 蔵の事務所
最初の連結の試算表を高梨に送る前に、叔父が事務所に来た。
叔父：「芹沢の株を、俺が少し引き受けてやろうか。汐見の持分が50%を下回れば、子会社じゃなくなるんだろう？　そうすれば、あそこの赤字も保証も、連結に載せなくて済む」
居合わせた椎名が、静かに言った。
椎名：「その手口で、上場廃止になった会社があります。カネボウです」
叔父は、聞き覚えのある名前に眉を上げた。化粧品の、あのカネボウか。
::

1887年に創業し、戦前には国内の企業で売上高1位にもなったカネボウは、2004年に経営が行き詰まり、産業再生機構に支援を求めた。その後の調査で、巨額の粉飾決算が明らかになった。同社は2005年4月13日、2000年3月期から2004年3月期までの5期分の決算の修正を開示し、東京証券取引所は同年5月12日に上場廃止を決めた。研究や報道によれば、同社は1996年3月期から2004年3月期まで、9期連続で実質的に債務超過だった。旧経営陣と、監査を担当した公認会計士が、証券取引法違反の疑いで逮捕された。
椎名：「連結財務諸表の上での手口の中心とされたのが、**連結外し**です。損失や負債を抱えた子会社の株式を、形だけ取引先に譲って持株比率を下げ、子会社ではないことにして、連結の範囲から外していた。日本では2000年3月期から、グループ全体の実態を示すために、連結の対象となる子会社の範囲が広げられていました。その制度の下で、連結の範囲そのものが操作されたんです」
澪は、ホワイトボードに表を書いた。仮に、債務超過の子会社（資産500億円、負債800億円）を連結から外したとする（仕組みを示すための例、単位：億円）。

::table 子会社を連結に含めた場合と、外した場合（単位：億円）
| 項目 | 連結に含める | 連結から外す |
| 子会社の資産 | 500 | 載らない |
| 子会社の負債 | 800 | 載らない |
| グループの純資産への影響 | △300 | 載らない |
::

連結貸借対照表から、子会社の資産500億円と負債800億円がまるごと消え、純資産の△300億円の「穴」も消える。連結から外された子会社に対して親会社が売上を計上していれば、その売上や利益も、連結で消去されずに残る。
澪：「グループの中の取引を消す仕組みは、子会社が連結の範囲に入っていて、初めて働くんです」
叔父は、腕を組んだまま黙っていた。やがて、「俺の金で、芹沢の赤字を隠すのはごめんだな」とだけ言って、帰っていった。

::danger 連結の範囲を、都合で動かす
連結の範囲は、議決権の割合だけでなく、実質的に支配しているかどうかで決まる。持株を形だけ移して子会社でないことにしても、支配と保証の実態が変わらなければ、それは連結外しだ。読む側は、子会社の数や連結の範囲が急に変わったとき、その理由を注記で確かめる。
::

::cfo 高梨に出す最初の連結の数字 ― どこまで修正するか
叔父の提案は引っ込んだ。今度は岩倉が、別の案を出した。「米と酒の売り買いは消すとしても、土地の売却益は芹沢さんが本当に手にしたお金でしょう。それくらいは残してもいいのでは」。
**前提**
- 汐見酒造の個別の当期純損失は1,427万円
- すべての連結修正をすると、親会社株主に帰属する当期純損失は2,001万円
- 土地の未実現利益（300万円）のうち、親会社の負担分は180万円
- 高梨とは「連結の試算表を毎月届ける」と約束している
- 芹沢酒造の8,000万円の借入金は、汐見酒造が保証している
- 汐見酒造の決算書の監査は、法律では義務づけられていない
::choice A. すべての連結修正を行い、親会社株主に帰属する当期純損失△2,001万円を出す
**◎ グループの本当の姿を、そのまま示している。**個別の△1,427万円より574万円悪い。だが、その差の中身（芹沢酒造の赤字の60%分300万円、のれん償却30万円、未実現利益の消去のうち親会社の負担分270万円、貸倒引当金の修正26万円の戻し）は、すべて説明できる。合併で何を直すかの出発点が、この数字だ。
::
::choice B. 中小企業に連結の義務はないので、汐見酒造の個別の数字だけを出す
**× 約束の中身と違う。**高梨と約束したのは「連結の試算表を毎月届ける」ことだ。個別の数字だけでは、芹沢酒造の赤字も、グループの中で作られた利益も見えない。8,000万円の保証を気にしている相手に、芹沢酒造の数字を見せない理由はない。
::
::choice C. 土地の売却益は残し、親会社株主に帰属する当期純損失△1,821万円で出す
**× グループの中で作った利益を残している。**土地は、芹沢酒造から汐見酒造に持ち主が変わっただけで、グループの外にはまだ売れていない。親会社の負担分180万円を残せば、連結の損失を小さく見せることになる。1つを残せば、連結の数字全体の信頼が崩れる。
::
::choice D. 叔父に株式を一部移して持分を50%以下にし、芹沢酒造を連結から外す
**× それは連結外しだ。**持分を形だけ下げても、汐見酒造が芹沢酒造の経営を実質的に支配し、借入金を保証している実態は変わらない。カネボウと同じ手口で、発覚すれば、蔵の信用は二度と戻らない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「どの数字なら小さく見えるか」ではなく、「高梨が知るべきこと（芹沢酒造の赤字、グループの中の取引、保証）が、どの数字ならすべて見えるか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 4つの案の、親会社株主に帰属する当期純損益（単位：万円）
| 案 | 金額 | 見えないもの |
| A すべての連結修正 | △2,001 | なし |
| B 個別の数字だけ | △1,427 | 芹沢酒造の赤字、グループの中の利益 |
| C 土地の利益を残す | △1,821 | 土地の未実現利益180 |
| D 連結から外す | 芹沢酒造の損益が載らない | 芹沢酒造のすべて |
::
#### 手順3　ほかの答えに引かれる理由
Bは「義務がない」という正しさに、Cは「本当に受け取ったお金だ」という実感に、Dは「ルールの数字の上では子会社でなくなる」という形式に引かれる。監査が法律で義務づけられていないことは、何を出すべきかとは関係のない前提だ。
#### 持ち帰る考え方
- **連結の数字は、全部の修正をそろえて初めて意味を持つ**：1つでも都合よく残したり外したりすれば、全体が信用を失う
- **悪い数字ほど、中身を説明できる形で出す**：個別との差を、修正ごとに分けて示す
#### 前提が変われば
芹沢酒造が汐見酒造の支配を離れ、保証もなくなれば、連結しないのが正しい。だが、それは株の名義ではなく、支配と保証の実態が変わったときだ。
::
::

::exam 成果連結の急所
- **売上高と売上原価**：グループの中の取引高を相殺。親→子も子→親も同じ
- **債権債務**：売掛金と買掛金、貸付金と借入金、未収・未払の利息、受取・支払の利息を相殺。グループの中の債権の**貸倒引当金も修正**する（子会社の債権なら、非支配株主の負担分も振り替える）
- **未実現利益**：期末に残っている棚卸資産・土地に含まれる利益を消去。**ダウンは親が全額、アップは非支配株主も持分比率で負担**
- 期首の棚卸資産に含まれていた未実現利益は、開始仕訳で消去したうえで、当期の売上原価を減らして戻す
- 連結精算表は、個別財務諸表の合計 → 修正・消去 → 連結財務諸表の順。当期純利益は利益剰余金に連動する
::

::next 連結会計の先にある論点
1級では、未実現利益に対する税効果、子会社の資産・負債の時価評価、持分法、連結キャッシュ・フロー計算書、包括利益、連結の範囲の詳しい判断などを学ぶ。上場企業の決算書は、連結財務諸表が中心だ。新聞の「最終赤字」「最終黒字」は、たいてい「親会社株主に帰属する当期純利益」のことを指している。
::

::summary
- 成果連結では、連結会社間の売上高と売上原価、債権と債務、利息の収益と費用を相殺し、グループの中の債権の貸倒引当金を修正する
- 期末にグループの中に残る棚卸資産・土地に含まれる未実現利益は消去する。ダウンストリームは親会社が全額負担、アップストリームは非支配株主も持分比率で負担する
- 連結精算表は、個別財務諸表の合計に修正・消去を加えて、連結財務諸表の金額を求める。当期純利益と利益剰余金はつながっている
- グループの中で作った利益は、グループの外に売れるまで実現しない。連結の範囲を操作すれば（連結外し）、損失も負債も見えなくなる
::
