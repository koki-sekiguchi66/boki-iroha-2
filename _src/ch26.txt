::mystery グループの中の「利益」
9月20日、月曜日。初めての連結の試算表を作るため、澪は2つの蔵の帳簿を突き合わせていた。
汐見酒造の帳簿には、芹沢酒造への**精米した米の売上1,200万円**があった。第8章で考えたとおり、汐見の精米機の空き時間を使って、芹沢の分まで精米していたのだ。芹沢酒造の帳簿には、汐見酒造の日本橋店への**酒「芹沢」の売上800万円**。そして2月には、芹沢酒造が使っていなかった倉庫の土地を、汐見酒造の冷蔵倉庫の用地として**1,500万円**で売り、**300万円の売却益**を計上していた。
「芹沢酒造の赤字が500万円で済んだのは、この土地の売却益のおかげです」と千尋は言った。
澪は、手を止めた。米も、酒も、土地も、2つの蔵の間を移っただけだ。グループの外の誰にも売っていない。グループ全体で見れば、お金は1円も外から入ってきていない。
**隣の蔵に米を売って得た利益は、グループの利益と言えるのか？**
::

## 成果連結 ― グループの中の取引を消す

第25章の資本連結は、親会社の投資と子会社の資本の相殺だった。連結修正のもう1つの柱が、グループの中の取引の結果を消す**成果連結**だ。

::theory 連結会社間の取引は、グループの外から見れば「なかったこと」
連結財務諸表は、親会社と子会社を1つの会社として見る。1つの会社の中で、ある部署が別の部署に物を渡しても、売上にはならない（第24章の本店から支店への送付と同じ）。だから、連結会社間の取引は、連結財務諸表から消す。
- **売上と仕入（売上原価）の相殺**：グループの中の売上高と、それに対応する売上原価を消す
- **債権と債務の相殺**：グループの中の売掛金と買掛金、貸付金と借入金、未収利息と未払利息などを消す。利息の収益と費用も消す
- **未実現利益の消去**：グループの中で利益を乗せて売った資産が、期末にまだグループの中に残っているとき、その利益は外部に売って**実現**していないので消す
::

## 売上と債権債務の相殺

::example 汐見酒造（親会社）と芹沢酒造（子会社、持分60%）の間の取引を相殺消去しなさい（単位：万円）
(1) 汐見酒造は芹沢酒造に、精米した米を1,200万円で売った。芹沢酒造は日本橋店（汐見酒造）に、酒を800万円で売った。
(2) 6月30日に、芹沢酒造の汐見酒造に対する買掛金が300万円ある。
(3) 汐見酒造は芹沢酒造に1,000万円を貸し付けている（第19章）。当期の利息は20万円で、受取済み・支払済みである。
(4) 汐見酒造は、(2)の売掛金300万円と(3)の貸付金1,000万円に、2%の貸倒引当金を設定している。
::answer
::journal (1) 連結会社間の売上高と売上原価の相殺
売上高 2,000 | 売上原価 2,000
::
::journal (2) 売掛金と買掛金の相殺
買掛金 300 | 売掛金 300
::
::journal (3) 貸付金と借入金、利息の相殺
借入金 1,000 | 貸付金 1,000
受取利息 20 | 支払利息 20
::
::journal (4) グループの中の債権に設定した貸倒引当金を消す：(300万円＋1,000万円)×2%
貸倒引当金 26 | 貸倒引当金繰入 26
::
(1)は、親会社から子会社への売上も、子会社から親会社への売上も、まとめて相殺する。連結財務諸表では、「売上原価」「売上高」の科目で修正するのがふつうだ（個別の帳簿の「仕入」は、連結では売上原価に含まれている）。
(4)は、親会社の債権に設定した貸倒引当金の修正なので、非支配株主持分には関係しない。
::
::

## 未実現利益の消去 ― ダウンストリームとアップストリーム

グループの中で売った米や酒が、期末にまだ買った側の倉庫に残っていたら、その中に含まれる売った側の利益は、まだ外部に実現していない。

::theory ダウンストリームとアップストリーム
- **ダウンストリーム**（親会社 → 子会社への販売）：未実現利益は、売った親会社の利益なので、**全額を親会社が負担**する
- **アップストリーム**（子会社 → 親会社への販売）：未実現利益は、売った子会社の利益なので、消去額のうち**非支配株主の持分比率の分を非支配株主に負担させる**
消去の仕訳：棚卸資産なら「売上原価／商品（原材料など）」、土地なら「固定資産売却益／土地」。アップストリームでは、さらに「非支配株主持分／非支配株主に帰属する当期純利益」で、非支配株主の負担分を振り替える。
2級では、未実現利益の消去は、**棚卸資産と土地**に限って出題される。
::

::example 未実現利益を消去しなさい（単位：万円）
(1) ダウンストリーム：6月30日、芹沢酒造の原材料の中に、汐見酒造から買った米が300万円分残っている。汐見酒造は、売価の20%の利益を乗せて売っている。
(2) アップストリーム：6月30日、日本橋店の商品の中に、芹沢酒造から買った酒が200万円分残っている。芹沢酒造は、売価の25%の利益を乗せて売っている。
(3) アップストリーム：芹沢酒造は、帳簿価額1,200万円の土地を、汐見酒造に1,500万円で売った。汐見酒造は、この土地を期末に保有している。
::answer
::journal (1) ダウンストリーム：300万円×20%＝60万円。全額を親会社が負担
売上原価 60 | 原材料 60
::
::journal (2) アップストリーム：200万円×25%＝50万円。うち40%（20万円）を非支配株主が負担
売上原価 50 | 商品 50
非支配株主持分 20 | 非支配株主に帰属する当期純利益 20
::
::journal (3) アップストリーム：土地の売却益300万円を消去。うち40%（120万円）を非支配株主が負担
固定資産売却益 300 | 土地 300
非支配株主持分 120 | 非支配株主に帰属する当期純利益 120
::
未実現利益の計算では、利益が「売価に対する率」（売上総利益率）で示されているか、「原価に対する率」（加算率）で示されているかを、必ず確かめる。原価の25%を加算して売っているなら、未実現利益は売価×25/125になる。
::
::

::exam 成果連結の急所
- **売上高と売上原価**：グループの中の取引高を相殺。親→子も子→親も同じ
- **債権債務**：売掛金と買掛金、貸付金と借入金、未収・未払の利息、受取・支払の利息を相殺。グループの中の債権の**貸倒引当金も修正**する（子会社の債権なら、非支配株主の負担分も振り替える）
- **未実現利益**：期末に残っている棚卸資産・土地に含まれる利益を消去。**ダウンは親が全額、アップは非支配株主も持分比率で負担**
- 期首の棚卸資産に含まれていた未実現利益は、当期に外部に売れて実現するので、開始仕訳で消去したうえで当期に戻す（1年目の問題では、期首の未実現利益は「ない」ことが多い）
- 連結精算表は、個別財務諸表の合計 → 修正・消去 → 連結財務諸表の順。損益計算書の当期純利益は、貸借対照表の利益剰余金に連動する
::

## 連結精算表 ― 合算して、消して、並べる

試験の第2問・第3問では、連結修正仕訳を連結精算表にまとめ、連結財務諸表の金額を求める問題がよく出る。型を、例題で確かめよう。

::example 次の資料から、連結精算表を完成させなさい（単位：千円）

## 答え合わせ ― グループの外から見れば、何も起きていない

::solve グループの中の取引の利益は、外部に売れるまで「未実現」
汐見酒造が芹沢酒造に米を売った利益は、汐見酒造の個別の帳簿では本物の利益だ。だが、グループを1つの会社として見れば、米は精米機から隣の蔵の倉庫に移っただけで、グループの外の誰にも売れていない。その米が酒になって外部の客に売れるまで、利益は**実現していない**。
土地も同じだ。芹沢酒造が汐見酒造に売った土地の売却益300万円は、グループの中で土地の持ち主が変わっただけで、グループの外からお金は入っていない。連結では消去され、芹沢酒造の「赤字が500万円で済んだ」理由は消える。
::table 連結にすると、損益はどう変わるか（2027年6月期、単位：万円）
| 項目 | 金額 |
| 汐見酒造の当期純損失（個別） | △1,490 |
| 芹沢酒造の当期純損失（個別） | △500 |
| のれん償却 | △30 |
| 未実現利益の消去（米60・酒50・土地300） | △410 |
| 貸倒引当金の修正 | ＋26 |
| 連結の当期純損失 | △2,404 |
| うち非支配株主に帰属する当期純損失（500×40%＋20＋120） | △340 |
| 親会社株主に帰属する当期純損失 | △2,064 |
::
::

千尋は、連結の表をしばらく見ていた。「土地を売って赤字を小さくしたつもりだった。でも、グループで見たら、自分のポケットからもう一方のポケットにお金を移しただけなんだね」
「芹沢酒造の本当の赤字は800万円でした」と澪は言った。「でも、それが見えたから、合併で何を直せばいいかも見えます」

## 椎名が止めた叔父の提案 ― 子会社を、連結から外した会社

::scene 9月22日、水曜日 ― 蔵の事務所
最初の連結の試算表を高梨に送る前々日、叔父が事務所に来た。
「芹沢の株を、俺が少し引き受けてやろうか。汐見の持分が50%を下回れば、子会社じゃなくなるんだろう？ そうすれば、あそこの赤字も保証も、連結に載せなくて済む」
居合わせた椎名が、静かに言った。「その手口で、上場廃止になった会社があります。カネボウです」
叔父は、聞き覚えのある名前に眉を上げた。化粧品の、あのカネボウか。
::

1887年に創業し、戦前には国内の企業で売上高1位にもなったカネボウは、2004年に経営が行き詰まり、産業再生機構に支援を求めた。その後の調査で、巨額の粉飾決算が明らかになった。同社は2005年4月13日、2000年3月期から2004年3月期までの5期分の決算の修正を開示し、東京証券取引所は同年5月12日に上場廃止を決めた。研究や報道によれば、同社は1996年3月期から2004年3月期まで、9期連続で実質的に債務超過だった。旧経営陣と、監査を担当した公認会計士が、証券取引法違反の疑いで逮捕された。
「連結財務諸表の上での手口の中心とされたのが、**連結外し**です」と椎名は言った。「損失や負債を抱えた子会社の株式を、形だけ取引先に譲って持株比率を下げ、子会社ではないことにして、連結の範囲から外していた。日本では2000年3月期から、グループ全体の実態を示すために、連結の対象となる子会社の範囲が広げられていました。その制度の下で、連結の範囲そのものが操作されたんです」
澪は、ホワイトボードに表を書いた。仮に、債務超過の子会社（資産500億円、負債800億円）を連結から外したとすると（仕組みを示すための例、単位：億円）、

::table 子会社を連結に含めた場合と、外した場合（単位：億円）
| 項目 | 連結に含める | 連結から外す |
| 子会社の資産 | 500 | 載らない |
| 子会社の負債 | 800 | 載らない |
| グループの純資産への影響 | △300 | 載らない |
::

連結貸借対照表から、子会社の資産500億円と負債800億円がまるごと消え、純資産の△300億円の「穴」も消える。連結から外された子会社に対して親会社が売上を計上していれば、その売上や利益も、連結で消去されずに残る。
「グループの中の取引を消す仕組みは、子会社が連結の範囲に入っていて、初めて働くんです」と澪は言った。
叔父は、腕を組んだまま黙っていた。やがて、「俺の金で、芹沢の赤字を隠すのはごめんだな」とだけ言って、帰っていった。

::cfo 高梨に出す最初の連結の数字 ― どこまで修正するか
最初の連結の試算表を高梨に送る前日。叔父の提案は引っ込んだが、今度は岩倉が、別の案を出した。「米と酒の売り買いは消すとしても、土地の売却益は芹沢酒造が本当に稼いだお金でしょう。それくらいは残してもいいのでは」
澪は、叔父の案も含めて、4つの案を並べてみた。
::table 4つの案の、親会社株主に帰属する当期純損益（単位：万円）
| 案 | 金額 |
| A 個別の数字だけを出す（汐見酒造の当期純損失） | △1,490 |
| B すべての連結修正をした連結の数字を出す | △2,064 |
| C 土地の未実現利益の消去だけをしない | △1,884 |
| D 叔父に株式を一部移して持分を50%以下にし、芹沢酒造を連結から外す | （芹沢酒造の損益が載らない） |
::
まず、それぞれの案で、高梨が知るべきこと（芹沢酒造の赤字、グループの中の取引、8,000万円の保証）がどこまで見えるかを考えてから選んでほしい。
::choice A. 中小企業に連結の義務はないので、汐見酒造の個別の数字だけを出す
**× 約束の中身と違う。**高梨と約束したのは「連結の試算表を毎月届ける」ことだ。個別の数字だけでは、芹沢酒造の赤字も、グループの中で作られた利益も見えない。芹沢酒造の8,000万円の保証を気にしている相手に、芹沢酒造の数字を見せない理由はない。
::
::choice B. すべての連結修正を行い、親会社株主に帰属する当期純損失△2,064万円を出す
**◎ グループの本当の姿を、そのまま示している。**個別の△1,490万円より574万円悪い。だが、その差の中身（芹沢酒造の赤字の60%分300万円、のれん償却30万円、未実現利益の消去のうち親会社の負担分270万円、貸倒引当金の修正26万円の戻し）は、すべて説明できる。合併で何を直すかの出発点が、この数字だ。
::
::choice C. 土地の売却益は残し、△1,884万円で出す
**× グループの中で作った利益を残している。**土地は、芹沢酒造から汐見酒造に持ち主が変わっただけで、グループの外にはまだ売れていない。売却益300万円のうち親会社の負担分180万円を残せば、連結の損失を小さく見せることになる。ほかの修正は正しくても、1つを残せば、連結の数字全体の信頼が崩れる。
::
::choice D. 叔父に株式を移して、芹沢酒造を連結から外す
**× それは連結外しだ。**持分を形だけ50%以下にしても、汐見酒造が芹沢酒造の経営を実質的に支配し、借入金を保証している実態は変わらない。連結の範囲は、議決権の割合だけでなく、実質的な支配で判断される。カネボウが行ったのと同じ手口で、発覚すれば、蔵の信用は二度と戻らない。
::
::answer 考え方の例を見る
連結財務諸表は、グループを1つの会社として見せるためのものだ。グループの中の取引を消し、グループの外にまだ売れていない利益を消し、支配している会社はすべて連結の範囲に入れる。どれか1つでも都合よく残したり外したりすれば、連結の数字は意味を失う。
澪はB案で、最初の連結の試算表を送った。高梨からの返信には、こうあった。「芹沢酒造の本当の赤字が800万円だと分かったのは、大きな前進です。合併の計画を、この数字から一緒に詰めましょう」
::

## 確認問題

::problem 親会社P社は、子会社S社（持分70%）に、原価率80%で商品を販売している。期末のS社の商品のうち、P社から仕入れたものは500,000円である。未実現利益を消去する仕訳をしなさい。
::answer
::journal ダウンストリーム：500,000円×(1－80%)＝100,000円。全額を親会社が負担
売上原価 100,000 | 商品 100,000

::problem 子会社S社（持分70%）は、親会社P社に、原価に25%の利益を加算して商品を販売している。期末のP社の商品のうち、S社から仕入れたものは250,000円である。未実現利益を消去する仕訳をしなさい。
::answer
::journal アップストリーム：250,000円×25/125＝50,000円。うち30%（15,000円）を非支配株主が負担
売上原価 50,000 | 商品 50,000
非支配株主持分 15,000 | 非支配株主に帰属する当期純利益 15,000

::problem 親会社P社は子会社S社に800,000円を貸し付けており、当期の受取利息は24,000円、期末の未収利息は6,000円である。連結修正仕訳をしなさい。
::answer
::journal 貸付金と借入金、利息の収益と費用、未収と未払の相殺
借入金 800,000 | 貸付金 800,000
受取利息 24,000 | 支払利息 24,000
未払利息 6,000 | 未収利息 6,000

::summary
- 成果連結では、連結会社間の売上高と売上原価、債権と債務、利息の収益と費用を相殺し、グループの中の債権の貸倒引当金を修正する
- 期末にグループの中に残る棚卸資産・土地に含まれる未実現利益は消去する。ダウンストリームは親会社が全額負担、アップストリームは非支配株主も持分比率で負担する
- 連結精算表は、個別財務諸表の合計に修正・消去を加えて、連結財務諸表の金額を求める。当期純利益と利益剰余金はつながっている
- グループの中で作った利益は、グループの外に売れるまで実現しない。連結の範囲を操作すれば（連結外し）、損失も負債も見えなくなる
::
