::mystery 2,400万円の通知
5月20日、木曜日、午前9時。県の産業振興課から、1通の通知が届いていた。
「汐見酒造株式会社　瓶詰めライン更新事業　補助金交付決定額　**24,000,000円**」
6月1日に稼働する新しい瓶詰めラインは、**4,800万円**。その半分を、県が出してくれる。午後には、補助金が普通預金に振り込まれた。
澪は、思わず電卓をたたいた。6月の決算は、営業利益の段階でまだ赤字の見込みだ。だが、2,400万円が利益になれば、当期純利益は黒字に変わる。
澪：「岩倉さん、これで黒字です！ 審査に『黒字』と書ける！」
岩倉は、珍しく強い声で言った。
岩倉：「専務、お待ちなさい。その金を利益にしたら、税金がかかりますぞ。補助金の3割近くが、税金で消えるかもしれん」
澪：「でも、補助金は返さなくていいお金ですよね。もらった分は、利益じゃないんですか」
**補助金2,400万円で買った4,800万円のラインは、帳簿にいくらで載るのか。補助金は、利益になるのか？**
::

## 父が探していた1,500万円 ― 割賦で買ったボイラー

補助金の話の前に、澪には片づけておく宿題があった。父の手帳の3行目、「釜　春までもたぬ」だ。

::memo 黒い手帳の3行目（第4章）
釜　春までもたぬ
::

5月1日、新しいボイラーが据え付けられた。代金は、1年の分割払い。現金で買えば1,500万円だが、12回の分割にすると、合わせて1,620万円になる。月々135万円を払う。
澪：「父は、この1,500万円を探していたんですね」
岩倉：「借入金を増やさずに買う方法を、社長はずっと考えておられました。分割払いなら、信金の枠を使わずに済む」
固定資産を代金の分割払いで買うことを**割賦購入**という。

::example ボイラーを12回の分割払いで買った
(1) 5月1日、ボイラーを購入した。現金で買う場合の価格は15,000,000円、分割払いの総額は16,200,000円（月1,350,000円×12回）で、差額は利息である。利息は前払利息で処理する。
(2) 5月31日、第1回の支払い1,350,000円を普通預金から行い、利息の1か月分を費用にした。
::answer
::journal (1) 取得原価は現金で買う場合の価格。利息分は前払利息
機械装置 15,000,000 | 未払金 16,200,000
前払利息 1,200,000 |
::
::journal (2) 支払いと、利息の費用化（1,200,000円÷12回＝100,000円）
未払金 1,350,000 | 普通預金 1,350,000
支払利息 100,000 | 前払利息 100,000
::
機械の取得原価は、現金で買う場合の価格15,000,000円だ。分割払いのために余分に払う1,200,000円は、機械の価値ではなく、お金を借りたのと同じ利息なので、資産の原価に入れず、期間に応じて支払利息にする（2級では、利息は毎回同じ額を配分する定額法で計算する）。
6月30日には2回払い終えているので、前払利息は1,200,000円－100,000円×2回＝**1,000,000円**、未払金は16,200,000円－1,350,000円×2回＝**13,500,000円**になる。
::trap
分割払いの総額16,200,000円を、機械の取得原価にしないこと。また、固定資産の購入代金なので、相手の勘定は買掛金ではなく**未払金**だ。最初から「支払利息」で処理し、決算で未経過分を前払利息に振り替える方法もある。
::
::
::

## 冷蔵倉庫の工事 ― 建設仮勘定

古酒の老香の教訓から、澪は、温度を一定に保てる冷蔵倉庫を建てることにした。工事の代金は3,000万円。工事の途中で、手付金と中間金を払う。
完成して使い始める前の建物は、まだ「建物」として使えない。工事中に払った代金は、いったん**建設仮勘定**に集めておき、完成して引渡しを受けたときに、建物などの本来の勘定に振り替える。

::example 冷蔵倉庫の工事代金を払い、完成した
(1) 4月10日、冷蔵倉庫の建設工事（請負金額30,000,000円）の手付金10,000,000円を普通預金から支払った。
(2) 6月10日、中間金10,000,000円を普通預金から支払った。
(3) 7月20日、冷蔵倉庫が完成して引渡しを受け、残額10,000,000円を普通預金から支払った。
::answer
::journal (1)
建設仮勘定 10,000,000 | 普通預金 10,000,000
::
::journal (2)
建設仮勘定 10,000,000 | 普通預金 10,000,000
::
::journal (3) 完成：建設仮勘定から建物へ
建物 30,000,000 | 建設仮勘定 20,000,000
 | 普通預金 10,000,000
::
6月30日の決算では、建設仮勘定20,000,000円が貸借対照表の有形固定資産に載る。減価償却は、7月20日に使い始めてからだ。
::trap
建設仮勘定は、まだ使っていないので**減価償却しない**。完成前の手付金を「前払金」にしないこと。固定資産の建設のための前払いは、建設仮勘定だ。
::
::
::

## 県からの通知 ― 国庫補助金と圧縮記帳

::scene 5月20日、午後3時 ― 帳場
椎名は、電話の向こうで岩倉の話を聞くと、落ち着いた声で言った。
椎名：「番頭さんの言うとおりです。補助金は、受け取ると収益になります。何もしなければ、受け取った年の利益が2,400万円増えて、そこに税金がかかります」
椎名：「でも、税金を払うお金は、どこから出しますか。補助金の一部を、税金に回すことになりますね」
::

国や地方公共団体から設備の購入のために受け取る補助金を**国庫補助金**といい、受け取ったときは**国庫補助金受贈益**（特別利益）とする。
そのままだと、補助金の年に利益が膨らんで税金がかかり、設備を買うための補助金が目減りしてしまう。そこで、補助金で買った資産の帳簿価額を、補助金の額だけ減らす処理が認められている。これを**圧縮記帳**（直接控除方式）という。減らした額は**固定資産圧縮損**（特別損失）とし、受贈益と打ち消し合う。

::example 補助金を受け取り、新しい瓶詰めラインを買って圧縮記帳した
(1) 5月20日、瓶詰めラインの更新のための国庫補助金24,000,000円が普通預金に入金された。
(2) 6月1日、新しい瓶詰めライン48,000,000円（据付費を含む）を購入し、代金は普通預金から支払った。同日に使い始めた。
(3) 6月1日、国庫補助金の額について、圧縮記帳（直接控除方式）を行った。
(4) 6月30日（決算日）、減価償却を行う（耐用年数10年、残存価額ゼロ、定額法、月割計算、間接法）。
::answer
::journal (1)
普通預金 24,000,000 | 国庫補助金受贈益 24,000,000
::
::journal (2) 取得原価は据付費を含めて48,000,000円
機械装置 48,000,000 | 普通預金 48,000,000
::
::journal (3) 圧縮記帳
固定資産圧縮損 24,000,000 | 機械装置 24,000,000
::
::journal (4) 圧縮後の帳簿価額24,000,000円を、10年で償却する：24,000,000円÷10年×1か月÷12か月
減価償却費 200,000 | 減価償却累計額 200,000
::
圧縮記帳をしなければ、6月の減価償却費は48,000,000円÷10年÷12か月＝400,000円だった。毎年の減価償却費が240万円（年480万円→240万円）小さくなり、10年かけて、補助金の2,400万円分だけ利益が大きくなる。
::trap
減価償却の計算は、圧縮**後**の帳簿価額（24,000,000円）をもとにする。48,000,000円で計算しないこと。また、受贈益と圧縮損は、損益計算書では特別利益と特別損失に分けて表示する。
::
::
::

::theory 圧縮記帳は、税金を「なくす」のではなく「先に延ばす」
圧縮記帳をすると、補助金の年は受贈益と圧縮損が打ち消し合い、利益（と課税所得）が増えない。そのかわり、資産の帳簿価額が小さくなるので、翌年以降の減価償却費が小さくなり、利益がその分大きくなる。
補助金にかかる税金は消えるのではなく、資産を使う期間に分けて、少しずつ払うことになる。設備を買う年に、補助金を税金で減らさないための仕組みだ。
::

澪は、新しいラインの帳簿価額を書き込んだ。4,800万円のラインは、帳簿には**2,400万円**で載る。
澪：「補助金で黒字になる、と思ったのに……」
岩倉：「受贈益と圧縮損が並んで、差し引きはゼロ。補助金は、利益にはなりませんでしたな」
澪は、しばらく黙っていた。やがて、ノートの隅に書いた。「でも、2,400万円は、税金に1円も取られずに、ラインになった」

::solve 4,800万円のラインは、帳簿に2,400万円で載る。補助金は、利益ではなく設備になった
補助金2,400万円は、受け取ったときに国庫補助金受贈益（特別利益）になる。だが、圧縮記帳をすると、同じ額の固定資産圧縮損（特別損失）が並び、今期の利益は増えない。4,800万円のラインは、帳簿には2,400万円で載り、その2,400万円を10年かけて減価償却していく。
もし澪の思ったとおり補助金を利益のままにしていたら、当期純利益は黒字に見えた。だが、その黒字は特別利益で作った一度きりのもので、審査で高梨は必ず見抜く。しかも、黒字にした分だけ税金がかかり、蔵から現金が出ていく。
**補助金は、利益を飾るためのお金ではなく、設備を手に入れるためのお金だ。圧縮記帳は、そのお金を税金で目減りさせないための仕組みである。**
::

### 試験で狙われるパターン ― 生産高比例法・資本的支出・除却・直接法

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 使った量で償却する（生産高比例法）**　走った距離や掘った量のように、使った量に比例して価値が減る資産は、期間ではなく利用量で償却する。

::formula 生産高比例法
減価償却費 ＝（取得原価 － 残存価額）× 当期の利用量 ÷ 総利用可能量
::

::example 保冷車を、走った距離で償却する
4月25日に買った保冷車（取得原価3,000,000円、残存価額は取得原価の10%、総走行可能距離300,000km）は、6月30日までに6,000km走った。生産高比例法で減価償却する（間接法）。
::answer
減価償却費＝(3,000,000円－300,000円)×6,000km÷300,000km＝54,000円
::journal
減価償却費 54,000 | 減価償却累計額 54,000
::
::trap
生産高比例法では、月割の計算はしない。期間ではなく、使った量で償却額が決まるからだ。残存価額を引き忘れないこと。
::
::
::

**② 直したのか、良くしたのか（資本的支出と収益的支出）**　固定資産に手を加える支出のうち、性能を上げたり使える年数を延ばしたりする分は**資本的支出**として資産の取得原価に加え、元の状態に戻す分は**収益的支出**として修繕費にする。

::example 仕込みタンクの内側を、ホーローで張り替えた
仕込みタンクの内側をホーロー引きに張り替える工事を行い、代金3,000,000円を普通預金から支払った。このうち2,000,000円はタンクの耐用年数を延ばす改良、1,000,000円は傷んだ部分の修繕である。
::answer
::journal
機械装置 2,000,000 | 普通預金 3,000,000
修繕費 1,000,000 |
::
::trap
全額を修繕費にすると、その期の費用が大きくなり、資産が小さくなる。逆に全額を資産にすると、費用を資産に付け替えたことになる。この区別は、次の節の事件の核心でもある。
::
::
::

**③ 使わなくなった資産を捨てる（除却・廃棄）**　新しいラインが入った6月1日、古い瓶詰めラインは使うのをやめ、取り外した。使わなくなった固定資産を帳簿から除くことを**除却**、物理的に捨てることを**廃棄**という。除却・廃棄は、2027年度からの区分表で3級に移ったが、2級でもそのまま使う。

::example 古い瓶詰めラインを除却した
6月1日、古い瓶詰めライン（取得原価36,000,000円、減価償却累計額27,000,000円。当期分の減価償却は計上ずみ）を除却した。売却できる価値はない。
::answer
::journal 帳簿価額9,000,000円を固定資産除却損に
減価償却累計額 27,000,000 | 機械装置 36,000,000
固定資産除却損 9,000,000 |
::
::trap
除却した資産に売れる価値（見積処分価額）があれば、その額は**貯蔵品**にして、除却損から差し引く。廃棄の費用がかかれば、除却損（廃棄損）に加える。
::
::
::

**④ 減価償却の直接法と、固定資産台帳**　減価償却の記帳には、減価償却累計額を使う**間接法**のほか、資産の勘定を直接減らす**直接法**がある。会社は、資産ごとの取得日・取得原価・耐用年数・償却累計額を**固定資産台帳**に記録して管理する。

::example 備品の減価償却を、直接法で記帳する
決算で、備品の減価償却費120,000円を直接法で計上した。
::answer
::journal 直接法：資産の勘定を直接減らす
減価償却費 120,000 | 備品 120,000
::
間接法なら「減価償却費 120,000／備品減価償却累計額 120,000」となる。直接法では、資産の勘定の残高がそのまま帳簿価額になる。
::trap
問題文の「直接法で記帳している」を読み落とさないこと。直接法の資産の勘定には、取得原価ではなく、帳簿価額が残っている。
::
::
::

::steps 解法の型 ― 固定資産の問題
1. 取得原価 | 購入代価＋付随費用（据付費・引取運賃など）。割賦の利息は含めない
2. 建設中か | 使い始める前は建設仮勘定。減価償却しない
3. 補助金はあるか | 受贈益を計上し、圧縮記帳なら同額を圧縮損として資産から減らす。償却は圧縮後の額で
4. 償却方法 | 定額法・定率法は月割、生産高比例法は利用量で計算する
5. 手を加えたか | 性能・年数が増す分は資本的支出（資産へ）、元に戻す分は収益的支出（修繕費）
::

## 2つの通信会社 ― 費用を資産にした会社、資産で赤字になった会社

::scene 5月21日、夕方 ― 信用金庫の応接室
中間の面談で、高梨は新しいラインの帳簿の数字をじっと見た。
高梨：「補助金を圧縮して、帳簿は2,400万円。正しい処理です。圧縮しないで利益を飾る会社も、たまにありますがね」
高梨：「研修で必ず教わる事件があります。費用を資産に付け替えて、利益を何十億ドルも作った会社です」
::

2002年、アメリカの通信大手ワールドコムの不正が明らかになった。米国証券取引委員会（SEC）の訴えによると、同社は、他社の回線を借りる費用（回線使用料）約**38億ドル**を、費用ではなく資本的支出として資産に振り替え、利益を大きく見せていた。
澪は、この章の資本的支出と収益的支出の区別で、その手口を仕訳にした（単位：百万ドル、仕組みを示すために単純化）。

::journal ① 正しい処理：回線使用料は、その期の費用
回線使用料 3,800 | 未払金 3,800
::

::journal ② 実際に行われた処理：費用から資産へ振り替える
有形固定資産 3,800 | 回線使用料 3,800
::

澪：「②の振替えで、費用が38億ドル減って、利益がその分増える。しかも、その『資産』は何年もかけて減価償却されるから、費用はさらに先に送られる」
高梨の話は、その逆の会社に続いた。楽天グループは、自前の携帯電話網を作るために基地局へ巨額の投資を続け、2023年12月期には連結で2,128億円の営業損失を出した。2024年12月期は、営業利益529億円と、5年ぶりの営業黒字に戻った。
高梨：「基地局のような設備は、買った年に全額が費用になるのではなく、何年もかけて減価償却費になります。設備を作った後は、売上が伸びなくても、減価償却費がしばらく続く。赤字の中身が、本業の失敗なのか、設備の減価償却なのかで、意味は違います」
澪：「減価償却費を足し戻した利益で見る、という見方もありますね」
高梨：「EBITDAですね。2級の範囲ではありませんが、設備の重い会社を見るときに使われます。ただ、設備はいつか作り直す。減価償却費を無視していいわけではありません」

::note
出典：[米国証券取引委員会（SEC）「Litigation Release No. 17588」（2002年6月、ワールドコムに対する訴え）](https://www.sec.gov/enforcement-litigation/litigation-releases/lr-17588)、[楽天グループ「2024年12月期 決算短信」](https://www2.jpx.co.jp/disc/47550/140120250214575394.pdf)、[ケータイ Watch「楽天グループ2024年度決算は通期で営業黒字、モバイルも単月黒字化を達成し連結黒字化を目指す」（2025年2月14日）](https://k-tai.watch.impress.co.jp/docs/news/1663109.html)

::danger 費用を資産に付け替えると、利益はいくらでも作れる
資本的支出と収益的支出の区別は、見積りと判断に頼る部分が大きい。修繕費を資産にすれば、その期の利益は増え、費用は減価償却として何年も先に送られる。固定資産が売上に比べて急に増えている会社は、その中身を確かめる必要がある。
::

::cfo 補助金で黒字に見せるか ― 圧縮記帳をするかどうか
審査まで2か月を切った。澪は、補助金を圧縮記帳するかどうかを、もう一度考えた。
**前提**
- 補助金2,400万円を受け取り、4,800万円のラインを買った（耐用年数10年、定額法）
- 圧縮記帳をしなければ、今期の税引前当期純利益は約680万円の黒字。圧縮すれば約1,720万円の赤字になる
- 黒字なら、今期の法人税等は約200万円（仮の税率30%で計算）。赤字なら、今期の法人税等は住民税の均等割など7万円ほどで、赤字は翌期以降の所得から差し引ける
- 圧縮すると、毎年の減価償却費が240万円小さくなり、その分、翌期以降の課税所得が増える
- 高梨は「審査では、営業利益と資金繰りを見る」と言っている
- 補助金の申請書類は、県の担当者が丁寧に見てくれた
::choice A. 圧縮しない。補助金で当期純利益を黒字にし、審査で「黒字」と言えるようにする
**△ 黒字の見出しは作れるが、中身は変わらない。**黒字の源は特別利益の補助金で、営業利益は赤字のまま。高梨は段階ごとに読むので、見出しの黒字は評価されない。しかも、約200万円の税金が、支払日を待たずに出ていく。
::
::choice B. 圧縮しないで、補助金を10年に分けて少しずつ利益にする
**× 2級のルールにない処理だ。**補助金は受け取ったときに受贈益とし、圧縮記帳をするなら直接資産から減らす。自分で好きな期間に分けて利益にすることはできない。
::
::choice C. 圧縮記帳をして、今期の税金の支払いを先に延ばす。審査では、赤字の中身を段階ごとに説明する
**◎ 現金を守り、数字は正直に見せている。**圧縮すれば今期の税金は均等割の7万円ほどで済み、約190万円の現金が手元に残る。赤字の中身は、研究開発費・立ち上げ費用・一度きりの除却損だと、段階ごとに説明できる（第22章）。
::
::choice D. 補助金を辞退し、ラインは信金からの借入金で買う
**× 返さなくてよいお金を、自分から手放している。**借入金が2,400万円増え、利息もかかる。審査を前に、負債を増やす理由はない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「当期純利益を黒字にできるか」ではなく、「審査で評価されるのは何か。そして、どちらを選ぶと蔵の現金が多く残るか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 圧縮記帳をするか、しないか（今期）
| 項目 | 圧縮しない | 圧縮する |
| 税引前当期純利益 | 約680万円 | 約△1,720万円 |
| 今期の法人税等 | 約200万円 | 約7万円 |
| 営業利益（審査で見る段） | 変わらない | 変わらない |
| 手元に残る現金の差 | ― | 約190万円多い |
::
どちらを選んでも、営業利益は1円も変わらない。変わるのは、特別利益の見せ方と、今期に出ていく税金だけだ。
#### 手順3　ほかの答えに引かれる理由
Aは「黒字」という見出しの魅力に、Bは「補助金を少しずつ利益にする」という合理的に見える考えに、Dは「補助金に頼らない」という潔さに引かれる。県の担当者が丁寧だったことは、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **特別利益で作った黒字は、審査では割り引かれる**：読む人は段階ごとに見る
- **圧縮記帳は税金を先に延ばす仕組み**：資金が苦しい年ほど、今期の現金を守る効果が大きい
#### 前提が変われば
もし今期の本業が大きく黒字で、来期以降に大きな赤字が見込まれるなら、話は変わる。圧縮して利益を将来へ回すより、圧縮せずに今期に課税され、将来の減価償却費を大きく残すほうが有利な場合もある。圧縮記帳は、税金を払う時期を選ぶ道具だ。
::
::

::exam 有形固定資産の急所
- 割賦購入の取得原価は**現金で買う場合の価格**。差額は利息（前払利息・支払利息）、相手は**未払金**
- 建設中の資産は**建設仮勘定**。減価償却しない。完成したら本来の勘定へ
- 国庫補助金は受け取ったら受贈益（特別利益）、圧縮記帳は「固定資産圧縮損／資産」。償却は**圧縮後**の額で
- 生産高比例法は（取得原価－残存価額）×利用量÷総利用可能量。月割しない
- 資本的支出は資産へ、収益的支出は修繕費へ。除却は帳簿価額を除却損に（処分価額は貯蔵品）
::

::next 固定資産の価値が落ちたら、減損へ
1級では、固定資産が生む将来のお金が帳簿価額を大きく下回ったときに、帳簿価額を切り下げる減損会計を学ぶ。資産の取得に伴って将来かかる撤去の費用（資産除去債務）も、1級の範囲だ。圧縮記帳の積立金方式（剰余金の処分で行う方法）も、1級で扱う。
::

::summary
- 固定資産の取得原価は、購入代価に付随費用を加えた額。割賦の利息は含めず、期間に応じて支払利息にする
- 建設中の資産は建設仮勘定に集め、完成して使い始めたら本来の勘定に振り替える
- 国庫補助金は受贈益とし、圧縮記帳では同額を固定資産圧縮損として資産から減らす。税金を先に延ばす仕組み
- 生産高比例法は利用量で償却し、資本的支出は資産に、収益的支出は修繕費にする
- 使わなくなった資産は除却し、帳簿価額を固定資産除却損にする
::

## 確認問題

::quiz
::problem 次の取引を仕訳しなさい。
(1) 機械を分割払いで購入した。現金で買う場合の価格は2,400,000円、分割払いの総額は2,640,000円（月110,000円×24回）で、利息は前払利息で処理する。
(2) 第1回の分割代金110,000円を普通預金から支払い、利息の1回分を費用にした。
::answer
::journal (1)
機械装置 2,400,000 | 未払金 2,640,000
前払利息 240,000 |
::
::journal (2) 利息240,000円÷24回＝10,000円
未払金 110,000 | 普通預金 110,000
支払利息 10,000 | 前払利息 10,000
::
取得原価は現金で買う場合の価格。差額の240,000円は利息で、24回に均等に配分する。
::
::
::problem 次の取引を仕訳しなさい。
(1) 備品の購入のための国庫補助金3,000,000円を受け取り、普通預金に入金した。
(2) 備品9,000,000円を購入し、代金は普通預金から支払った。国庫補助金の額について、圧縮記帳（直接控除方式）を行った。
(3) 決算で、(2)の備品を定額法（耐用年数5年、残存価額ゼロ、1年分、間接法）で減価償却した。
::answer
::journal (1)
普通預金 3,000,000 | 国庫補助金受贈益 3,000,000
::
::journal (2)
備品 9,000,000 | 普通預金 9,000,000
固定資産圧縮損 3,000,000 | 備品 3,000,000
::
::journal (3) (9,000,000円－3,000,000円)÷5年
減価償却費 1,200,000 | 減価償却累計額 1,200,000
::
減価償却は、圧縮後の6,000,000円をもとに計算する。
::

::problem 車両（取得原価2,000,000円、残存価額は取得原価の10%、総走行可能距離150,000km）の当期の走行距離は12,000kmだった。生産高比例法による当期の減価償却費を求めなさい。
減価償却費 [[144,000]] 円
::answer
