::mystery 2,400万円の補助金が、利益にならない
5月20日、木曜日。県から、補助金の交付決定の通知と、**2,400万円**の入金が届いた。「酒蔵の生産性向上」を目的とする県の補助事業で、新しい瓶詰めラインの購入費の半分を補助してくれる。
第9章で宇佐美が記録したとおり、古いラインの停止の7割はラベラーの詰まりだった。新しいラインは、ラベラーも王冠の打栓機も一体になっている。1時間あたりの処理能力は1.5倍、停止はほぼなくなる見込みだ。価格は据付けと試運転を含めて**4,800万円**。6月1日に稼働する。
澪は、すぐに損益の見込みを計算した。6月期は、赤字か黒字かの瀬戸際にある。補助金2,400万円は、特別利益として利益を押し上げるはずだった。
だが、月に1度の訪問に来た椎名は、首を振った。「圧縮記帳をすれば、補助金2,400万円の利益は、同じ年に2,400万円の損失で消えます。今期の利益は1円も増えません」
「では、もらった意味がないのでは」
「ありますよ。消えるのは、今期の帳簿の上の利益だけです」
**補助金を2,400万円もらった年、なぜ利益は1円も増えないのか？**
::

## 設備投資は、その年の費用ではない

まず、3級で学んだ基本を確かめておこう。4,800万円のラインを買っても、その年の費用が4,800万円増えるわけではない。

::theory 固定資産の取得原価と、減価償却
有形固定資産は、**取得原価**（購入代価＋据付費・試運転費・引取運賃などの付随費用）で資産に計上し、使う期間（耐用年数）にわたって**減価償却**で少しずつ費用にする。
4,800万円のラインを耐用年数10年・残存価額ゼロの定額法で償却すれば、費用になるのは1年に480万円ずつ。6月1日に稼働すれば、6月期の費用は1か月分の40万円だけだ。お金は一度に4,800万円出ていっても、損益計算書の費用は10年に分かれる。
{{new:2027年度〜}} 定率法と、有形固定資産の除却・廃棄は、2027年度からの出題区分表で3級に移った。2級の決算問題では、3級の知識として引き続き使う。
::

## 割賦購入 ― 分割払いの利息は、資産の原価に入れない

新しいラインと同じ時期に、第4章で故障を繰り返したボイラーも入れ替えた。代金は分割払い（**割賦**）にした。

::example 新しいボイラーの割賦購入を仕訳しなさい（利息は前払利息として処理し、定額法で費用にする）
(1) 5月1日、ボイラー（現金で買う場合の価格15,000,000円）を、12回の分割払いで購入した。分割払いの総額は16,200,000円（月1,350,000円）で、差額1,200,000円は利息である。
(2) 5月31日、第1回の分割代金1,350,000円を普通預金から支払った。あわせて、1回分の利息を費用に振り替える。
(3) 6月30日、決算日。第2回の分割代金を支払い、利息を費用に振り替えた（仕訳は(2)と同じ）。決算日の前払利息の残高と、未払金の残高を答えなさい。
::answer
::journal (1) 取得原価は現金価格。利息分は前払利息
機械装置 15,000,000 | 未払金 16,200,000
前払利息 1,200,000 |
::
::journal (2) 支払いと、利息の費用化（1,200,000円÷12回）
未払金 1,350,000 | 普通預金 1,350,000
支払利息 100,000 | 前払利息 100,000
::
6月30日の前払利息は1,200,000円－100,000円×2回＝**1,000,000円**、未払金は16,200,000円－1,350,000円×2回＝**13,500,000円**。
機械の取得原価は、現金で買う場合の価格15,000,000円だ。分割払いのために余分に払う1,200,000円は、機械の価値ではなく、お金を借りたのと同じ利息なので、資産の原価に入れず、期間に応じて支払利息にする。最初から「支払利息」で処理し、決算で未経過分を前払利息に振り替える方法もある。
::
::

## 建設仮勘定 ― 完成するまで、仮の箱に入れておく

第14章で古酒の一部を駄目にした反省から、蔵は温度を一定に保てる**冷蔵倉庫**の建設を始めた。総額3,000万円、7月に完成する予定だ。

::theory 建設仮勘定
建物などの建設を外部に頼み、完成前に代金の一部（手付金・中間金）を支払ったときは、**建設仮勘定**（資産）で処理する。まだ完成して使い始めていないので、**減価償却はしない**。完成して引渡しを受けたら、建物などの本来の勘定に振り替える。
::

::example 冷蔵倉庫の建設を仕訳しなさい
(1) 3月15日、冷蔵倉庫の建設の手付金10,000,000円を普通預金から支払った。
(2) 5月15日、中間金10,000,000円を普通預金から支払った。
(3) 7月20日（翌期）、冷蔵倉庫が完成して引渡しを受け、残金10,000,000円を普通預金から支払った。
::answer
::journal (1)
建設仮勘定 10,000,000 | 普通預金 10,000,000
::
::journal (2)
建設仮勘定 10,000,000 | 普通預金 10,000,000
::
::journal (3) 完成：建設仮勘定から建物へ
建物 30,000,000 | 建設仮勘定 20,000,000
 | 普通預金 10,000,000
::
6月30日の決算では、建設仮勘定20,000,000円が貸借対照表の有形固定資産に載る。減価償却は、7月20日に使い始めてからだ。
::
::

## 国庫補助金と圧縮記帳

いよいよ、新しい瓶詰めラインだ。

::theory 国庫補助金と圧縮記帳（直接控除方式）
国や自治体から、固定資産を取得するための補助金（**国庫補助金**）を受け取ると、その額は**国庫補助金受贈益**（収益、特別利益）になる。
ただ、このままでは、補助金を受け取った年に、その全額に法人税がかかってしまう。設備を買うために出したお金なのに、その一部が税金で消えれば、補助の意味が薄れる。そこで、取得した固定資産の帳簿価額を補助金の額だけ減らし、同じ額を**固定資産圧縮損**（費用、特別損失）とする方法が認められている。これを**圧縮記帳**という。
受贈益と圧縮損が同じ額なので、補助金を受け取った年の利益は増えない。そのかわり、固定資産の帳簿価額が小さくなるので、**翌年以降の減価償却費が小さくなり、その分だけ利益と課税所得が大きくなる**。税金がなくなるのではなく、何年かに分けて払うことになる（課税の繰延べ）。
::

::example 新しい瓶詰めラインの取引を仕訳しなさい（6月30日決算、減価償却は定額法・耐用年数10年・残存価額ゼロ・月割）
(1) 5月20日、県から補助金24,000,000円の交付を受け、普通預金に入金された。
(2) 6月1日、瓶詰めラインを購入し、代金46,000,000円と据付け・試運転の費用2,000,000円を普通預金から支払った。
(3) 6月1日、補助金の額について、直接控除方式による圧縮記帳を行った。
(4) 6月30日、決算。新しいラインの減価償却費（1か月分）を計上する。
::answer
::journal (1)
普通預金 24,000,000 | 国庫補助金受贈益 24,000,000
::
::journal (2) 取得原価は付随費用を含めて48,000,000円
機械装置 48,000,000 | 普通預金 48,000,000
::
::journal (3) 圧縮記帳
固定資産圧縮損 24,000,000 | 機械装置 24,000,000
::
::journal (4) 圧縮後の帳簿価額24,000,000円を、10年で償却する：24,000,000円÷10年×1か月÷12か月
減価償却費 200,000 | 減価償却累計額 200,000
::
圧縮記帳をしなければ、減価償却費は48,000,000円÷10年÷12か月＝400,000円だった。毎年の減価償却費が2,400,000円（年480万円→240万円）小さくなり、10年かけて、補助金の2,400万円分だけ利益が大きくなる。
::
::

::tgrid
::taccount 機械装置（新しい瓶詰めライン）
普通預金 48,000,000 | 固定資産圧縮損 24,000,000
 | 次期繰越 24,000,000
= 48,000,000 | 48,000,000
::
::taccount 損益（補助金に関する部分）
固定資産圧縮損 24,000,000 | 国庫補助金受贈益 24,000,000
減価償却費 200,000 |
::

## 答え合わせ ― 消えたのは今期の利益だけ

::solve 補助金の利益は、10年の減価償却費の減少に分けて受け取る
圧縮記帳をすると、補助金2,400万円の受贈益と、同じ額の固定資産圧縮損が、同じ年の特別利益と特別損失に並ぶ。今期の利益は1円も増えない。
だが、補助金は消えていない。ラインの帳簿価額が4,800万円から2,400万円に減ったことで、毎年の減価償却費が480万円から240万円に減る。10年かけて、毎年240万円ずつ、利益が大きくなる。補助金の利益を「今年一度に」ではなく、「設備を使う10年に分けて」受け取る仕組みだ。
そして、お金の面では、2,400万円は5月にすでに蔵の預金に入っている。圧縮記帳は、利益と税金の**時期**を変えるだけで、お金の出入りは何も変えない。
::

「つまり、補助金の分、ラインを半額で買ったのと同じ帳簿になるんですね」と澪は言った。
「そうです」と椎名は答えた。「半額で買ったラインの減価償却費を、10年かけて払っていく。損益計算書は、そういう姿を映します」

## 生産高比例法と、資本的支出

### 生産高比例法 ― 使った分だけ償却する

第12章で買った配送用の保冷車は、走った距離に応じて傷んでいく。このように、使用量に比例して価値が減る資産には、**生産高比例法**を使うことができる。

::formula 生産高比例法
減価償却費 ＝（取得原価 － 残存価額）× 当期の利用量 ÷ 総利用可能量
::

::example 保冷車の減価償却費を、生産高比例法で計算しなさい
取得原価3,000,000円、残存価額は取得原価の10%、総走行可能距離200,000km、当期（4月25日〜6月30日）の走行距離4,000km。
::answer
(3,000,000円－300,000円)×4,000km÷200,000km＝**54,000円**
::journal
減価償却費 54,000 | 減価償却累計額 54,000
::
生産高比例法では、月割の計算はしない。期間ではなく、使った量で償却額が決まるからだ。
::
::

### 資本的支出と収益的支出

6月、古いタンクの内側のホーロー（ガラス質の被膜）を引き直した。費用は300万円。工事業者によれば、このうち200万円分の工事で、タンクの耐用年数が延びるという。

::theory 資本的支出と収益的支出
固定資産に支出したお金のうち、
- 価値を高めたり、耐用年数を延ばしたりする部分は**資本的支出**：固定資産の取得原価に加える
- 元の状態に戻すための部分（修理・維持）は**収益的支出**：**修繕費**（費用）とする
::

::example タンクの改修を仕訳しなさい
タンクのホーローの引き直しの代金3,000,000円を普通預金から支払った。このうち2,000,000円は耐用年数を延ばす資本的支出、1,000,000円は原状回復のための収益的支出である。
::answer
::journal
機械装置 2,000,000 | 普通預金 3,000,000
修繕費 1,000,000 |
::
::
::

::exam 有形固定資産の急所
- 取得原価＝購入代価＋付随費用（据付費・試運転費・引取運賃・登記費用など）。割賦の利息は含めない
- **割賦購入**：利息は前払利息（または支払利息）で処理し、支払いのつど定額法で費用化。決算では未経過分が前払利息
- **建設仮勘定**：完成前の支払い。減価償却しない。完成時に建物などへ振り替える
- **圧縮記帳（直接控除方式）**：「固定資産圧縮損／機械装置など」。減価償却は**圧縮後の帳簿価額**をもとに計算する
- **生産高比例法**：(取得原価－残存価額)×当期の利用量÷総利用可能量。月割しない
- **資本的支出**は資産の原価に加算、**収益的支出**は修繕費
- 除却（固定資産除却損）・定率法は、2027年度から3級の範囲だが、2級の決算問題でも使う
::

::real 費用を資産に付け替えた会社 ― ワールドコム
2002年6月、アメリカの通信大手ワールドコムの粉飾が明るみに出た。米国証券取引委員会（SEC）の訴状によると、同社は、他社の通信回線を使うために払った**ラインコスト**（回線使用料）約**38億ドル**を、費用ではなく資本勘定（資産）に振り替えていた。その結果、税引前利益は2001年に約30億5,500万ドル、2002年1〜3月期に約7億9,700万ドル、実際より大きく報告されていた。同社は同年7月に経営破綻した。

**この章の道具で読む ― 収益的支出を、資本的支出に見せかける**
回線使用料は、その期に使ったサービスの対価で、典型的な収益的支出だ。それを設備のような資本的支出として資産に計上すると、何が起きるか（単位：百万ドル、金額は訴状の数字を単純化）。
::journal ① 正しい処理：回線使用料はその期の費用
回線使用料 3,800 | 未払金など 3,800
::
::journal ② 実際に行われた処理：費用から資産へ振り替える
有形固定資産 3,800 | 回線使用料 3,800
::
②の振替えで、損益計算書の費用は38億ドル減り、利益はその分だけ増える。資産は38億ドル増え、そのうえ、その「資産」は何年もかけて減価償却されるので、費用はさらに先送りされる。
**楽天モバイル ― 正しく資産にした設備が、赤字を生む**
逆に、本物の設備投資を正しく資産に計上しても、その減価償却費が、何年も営業赤字の原因になることがある。楽天グループは、自前の携帯電話網を作るために基地局へ巨額の投資を続け、2023年12月期には連結で2,128億円の営業損失を出した。2024年12月期は、営業利益529億円と、5年ぶりの営業黒字に戻った。モバイル事業だけを見ると、2024年の営業損益（同社の非GAAP）は2,089億円の損失だったが、減価償却費などを足し戻した**EBITDA**は363億円の損失まで縮み、2024年12月には単月で23億円の黒字になった。
::table 楽天モバイルの2024年の損益（同社の非GAAPの数字、単位：億円）
| 項目 | 金額 |
| EBITDA（減価償却費などを引く前の損益） | △363 |
| 減価償却費など（差し引きで読める額） | △1,726 |
| 営業損益 | △2,089 |
::
2,000億円を超える営業損失の8割以上は、基地局などの減価償却費だと読める。設備は一度に買っても、その費用は何年にもわたって損益計算書に表れ、売上が育つまで営業赤字を生み続ける。ワールドコムは費用を資産に見せかけて赤字を隠し、楽天は本物の資産の減価償却で赤字を出した。どちらの決算書も、「何を資産にし、何を費用にしたか」を知らなければ読めない。
::note

::

まず、2つの案で、今期と翌期以降の利益・税金・お金がどう変わるかを考えてから選んでほしい。
::choice A. 圧縮記帳をしない。税引前当期純損益が680万円の黒字になり、高梨の条件を満たせる
**× 黒字の中身は、一度きりの補助金だけだ。**経常損益は△820万円のまま変わらない。黒字は、特別利益の補助金2,400万円がなければ出ない。高梨のような融資の担当者は、特別損益を除いた経常利益や営業利益を必ず見る。しかも、圧縮記帳をしなければ、課税所得が出て今期に税金がかかり（概算で680万円×30%＝約204万円）、翌期以降の減価償却費は年480万円と大きくなる。見た目の黒字のために、税金と将来の利益を前払いすることになる。
::
::choice B. 圧縮記帳をする。今期の利益は増えないが、税金を払わずに済み、翌期以降の利益が大きくなる
**◎ 補助金の効果を、設備を使う期間に合わせて受け取る。**今期は受贈益と圧縮損が相殺し、税引前は△1,720万円。だが、今期に補助金に対する税金はかからず、翌期から10年間、減価償却費が年240万円小さくなる。
そして、高梨に見せるべきは、△1,720万円の中身だ。うち900万円は旧ラインの除却損という一度きりの損失、そのほかに研究開発と立ち上げの費用がある（第17章・第22章）。見た目の黒字ではなく、赤字の中身で説明する。
::
::choice C. 補助金を売上に含め、営業利益を黒字にする
**× 補助金は、酒を売って得た収益ではない。**補助金は、設備の取得のために受け取るもので、本業の売上ではない。売上に含めれば、営業利益が2,400万円かさ上げされ、本業の稼ぐ力を大きく見誤らせる。区分の誤りは、金額の誤りと同じくらい重大だ。
::
::choice D. 圧縮記帳をしたうえで、新しいラインの耐用年数を20年に延ばし、減価償却費を小さくする
**× 耐用年数は、利益の都合で決めるものではない。**耐用年数は、その設備を実際に使える期間の見積りだ。根拠なく延ばせば、毎年の減価償却費が小さくなって利益が大きく見えるが、ワールドコムと同じく、費用を先送りしているだけになる。今期の影響はわずか（1か月分）なのに、決算書の信頼を損なう。
::
::answer 考え方の例を見る
圧縮記帳は、利益と税金の時期を変える仕組みで、お金も、会社の本当の稼ぐ力も変えない。黒字か赤字かを「見せ方」で変えても、決算書を読む側は中身を見る。大事なのは、赤字の中身を、どの段の損益で、何が原因かまで分けて説明できることだ。
澪は、圧縮記帳をすることに決めた。そして、6月期の決算書に添える説明の1枚目に、こう書いた。「特別損益：補助金2,400万円と圧縮損2,400万円は相殺。旧ラインの除却損900万円は、新ラインへの入れ替えに伴う一度きりの損失」。
::

::next 固定資産の会計の先にある論点
1級では、固定資産の**減損会計**（収益性が下がった設備の帳簿価額を回収可能価額まで切り下げる）、**資産除去債務**、圧縮記帳の**積立金方式**、級数法などを学ぶ。また、楽天モバイルの例で見たEBITDAのような「利益に減価償却費を足し戻した指標」は、設備の重い会社を比べるときによく使われるが、会計の基準で定められた利益ではない。その読み方も、1級や実務で身につける。
::

::summary
- 設備投資は、取得原価で資産に計上し、減価償却で耐用年数にわたって費用にする。買った年に全額が費用になるわけではない
- 割賦購入の利息は取得原価に含めず、前払利息（支払利息）として定額法で費用化する
- 建設仮勘定は完成前の支払い。減価償却はせず、完成時に本勘定へ振り替える
- 国庫補助金受贈益と固定資産圧縮損は同じ額で相殺する。圧縮後の帳簿価額で減価償却するので、補助金の効果は翌期以降の減価償却費の減少として表れる（課税の繰延べ）
- 生産高比例法は使用量に比例して償却する。資本的支出は資産に加え、収益的支出は修繕費
- 何を資産にし、何を費用にするかで、利益の見え方は大きく変わる。費用を資産に付け替える粉飾（ワールドコム）と、本物の設備の減価償却による赤字（楽天モバイル）を見分ける
::
