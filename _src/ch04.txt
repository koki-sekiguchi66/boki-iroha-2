::mystery 止まっていた1週間の費用が、原価に表れない
1月14日、木曜日の早朝。蔵の奥で、ボイラーが鈍い音を立てて止まった。蒸し米が作れなければ、仕込みはできない。部品の取り寄せと修理に1週間。その間、蔵人たちは、蔵の掃除と道具の手入れで時間をつぶした。
1月末、澪は原価計算表を作った。蔵人の直接作業時間は、予定の2,000時間に対して**1,600時間**。2割も少ない。それなのに、大吟醸1本の原価は、12月と1円も変わらなかった。
「止まっていた間も、タンクの減価償却費も、ボイラー係の給料も、ちゃんと払っているのに」
澪は、表の「製造間接費」の行を見つめた。製造間接費は、毎月の直接作業時間に1時間4,000円を掛けて酒に割り振る決まりになっていた。作業時間が減れば、割り振られる額も減る。では、割り振られなかった費用は、どこへ消えたのか。
**ボイラーが止まった月、なぜ酒の原価は「いつもどおり」だったのか？**
::

## 製造間接費を集める ― 3つの間接費と、4つの経費

第1章で見たとおり、製造間接費は、どの酒のために使ったか特定できない原価の集まりだ。第2章の間接材料費、第3章の間接労務費に、**間接経費**が加わる。
経費は、金額を把握するタイミングによって、4つに分けられる。

::table 経費の分類（金額の測り方）
| 分類 | 測り方 | 汐見酒造の例 |
| 支払経費 | 支払った額（未払・前払を調整） | 修繕費、旅費交通費、外注加工賃 |
| 月割経費 | 年額などを月割りする | 減価償却費、保険料、固定資産税、賃借料 |
| 測定経費 | メーターで測った消費量で計算する | 電力料、ガス代、水道料 |
| 発生経費 | 発生した額 | 棚卸減耗費（第2章） |
::

経費のほとんどは間接経費だが、特定の製品のために外部に頼んだ加工の代金（**外注加工賃**）は、**直接経費**として仕掛品に入れる。

::example 1月の経費を仕訳しなさい
(1) 純米吟醸の一部の瓶詰めを外部の業者に依頼し、外注加工賃150,000円を普通預金から支払った。
(2) ボイラーの緊急修理の代金300,000円を普通預金から支払った。
(3) 工場の機械と建物の減価償却費の月割額2,250,000円を計上した。
(4) 電力料とボイラーの燃料代の当月の測定額は1,050,000円だった（月末に未払金として計上する）。
::answer
::journal (1) 外注加工賃は直接経費
仕掛品 150,000 | 普通預金 150,000
::
::journal (2)
製造間接費 300,000 | 普通預金 300,000
::
::journal (3)
製造間接費 2,250,000 | 減価償却累計額 2,250,000
::
::journal (4)
製造間接費 1,050,000 | 未払金 1,050,000
::
問題によっては、修繕費・減価償却費などの費目の勘定にいったん記録してから製造間接費に振り替える場合もある。どちらでも、間接経費が最終的に製造間接費の借方に集まることは同じだ。
::
::

1月の製造間接費の実際の発生額は、合計で**7,950,000円**だった。

::table sum 1月の製造間接費の実際発生額（単位：円）
| 費目 | 金額 | 性質 |
| 間接材料費（洗剤・ろ過材・燃料以外の補助材料） | 600,000 | 変動費 |
| 間接労務費（間接作業・手待時間・間接工・職員・法定福利） | 3,200,000 | 固定費 |
| 減価償却費 | 2,250,000 | 固定費 |
| 電力料・燃料代 | 1,050,000 | 変動費 |
| 修繕費（ボイラーの緊急修理） | 300,000 | 固定費 |
| 保険料・固定資産税など | 550,000 | 固定費 |
|= 合計 | 7,950,000 | |
::

表の右の列に、椎名は「変動費」「固定費」と書き込ませた。作業時間が増えれば増え、減れば減る費用（燃料・電力・補助材料）が**変動費**。作業時間が増えても減っても変わらない費用（減価償却費・ボイラー係や杜氏の給料・保険料）が**固定費**だ。この区別が、謎を解く鍵になる。

## 予定配賦 ― 1時間4,000円の正体

「1時間4,000円は、誰が決めたんですか」
澪の問いに、岩倉は7月の会議の資料を出してきた。今期の製造間接費の**予算**と、予定の作業時間（**基準操業度**）が書かれていた。

::table 今期の製造間接費予算（公式法変動予算）
| 項目 | 年間 | 月間 |
| 基準操業度（直接作業時間） | 24,000時間 | 2,000時間 |
| 変動費（1時間あたり1,000円） | 2,400万円 | 200万円 |
| 固定費 | 7,200万円 | 600万円 |
|= 製造間接費予算 | 9,600万円 | 800万円 |
::

::formula 予定配賦率と予定配賦額
予定配賦率 ＝ 製造間接費の年間予算 ÷ 年間の基準操業度 ＝ 9,600万円 ÷ 24,000時間 ＝ **4,000円／時間**
（内訳：変動費率 1,000円＋固定費率 7,200万円÷24,000時間＝3,000円）
予定配賦額 ＝ 実際の操業度（直接作業時間）× 予定配賦率
::

製造間接費を、実際の発生額で毎月割り振る（**実際配賦**）と、2つの問題が起きる。1つは、月末に全部の費用が集まるまで原価が計算できないこと。もう1つが、今回の謎の核心だ。固定費は、作業時間が減っても減らない。実際配賦なら、作業時間の少ない月ほど1時間あたりの間接費が高くなり、同じ酒の原価が月ごとに大きく揺れる。
そこで、年間の予算と基準操業度から決めた**予定配賦率**で割り振る。1月は、実際の直接作業時間1,600時間×4,000円＝**6,400,000円**が、酒の原価に割り振られた。

::example 1月の製造間接費を予定配賦し、配賦差異を計上しなさい
実際の直接作業時間は1,600時間、予定配賦率は4,000円、製造間接費の実際発生額は7,950,000円である。
::answer
::journal (1) 予定配賦：1,600時間×4,000円
仕掛品 6,400,000 | 製造間接費 6,400,000
::
::journal (2) 配賦差異：6,400,000円－7,950,000円＝△1,550,000円（不利差異）
製造間接費配賦差異 1,550,000 | 製造間接費 1,550,000
::
製造間接費の勘定には、実際の発生額7,950,000円が借方に集まり、予定配賦額6,400,000円が貸方から仕掛品へ出ていく。借方に残った1,550,000円が、割り振られなかった費用＝**製造間接費配賦差異**だ。予定配賦額が実際より少ないので、**不利差異（借方差異）**になる。
::
::

::tgrid
::taccount 製造間接費
実際発生額 7,950,000 | 仕掛品 6,400,000
 | 製造間接費配賦差異 1,550,000
= 7,950,000 | 7,950,000
::
::taccount 製造間接費配賦差異
製造間接費 1,550,000 |
::

## 差異の分析 ― 155万円を2つに分ける

「155万円の差異は、ボイラーの修理代ですか」
「修理代は30万円です」と澪は答えた。「残りの125万円は……」
椎名は、ホワイトボードに1本の右上がりの線を引いた。「これが予算の線です。作業時間が増えると、変動費の分だけ費用が増える。固定費600万円の高さから始まる線です」

::theory 予算差異と操業度差異（公式法変動予算）
配賦差異を、原因によって2つに分ける。
- **予算差異**＝予算許容額－実際発生額
  - 予算許容額＝実際の操業度×変動費率＋固定費予算（その作業時間なら、本来いくらで済むはずだったか）
  - 「お金の使いすぎ・節約」を表す。修理や値上がりで、予算より多く使えば不利
- **操業度差異**＝(実際の操業度－基準操業度)×固定費率
  - 「設備や人をどれだけ使ったか」を表す。予定より作業時間が少なければ、固定費の一部が製品に割り振られずに残る（不利）
  - 予算差異＋操業度差異＝配賦差異
::

::example 1月の配賦差異を、予算差異と操業度差異に分けなさい
::answer
- 予算許容額：1,600時間×1,000円＋6,000,000円＝7,600,000円
- **予算差異**：7,600,000円－7,950,000円＝**△350,000円（不利）**
- **操業度差異**：(1,600時間－2,000時間)×3,000円＝**△1,200,000円（不利）**
- 合計：△350,000円＋△1,200,000円＝△1,550,000円（配賦差異と一致）

::boxes 1月の製造間接費の分析（単位：万円）
H 製品に割り振った額と差異 | 実際の発生額
L a 64 予定配賦額<br>640万円
L x 12 操業度差異<br>120万円（不利）
L x 4 予算差異<br>35万円（不利）
R k 80 実際発生額<br>795万円
::
::
::

::solve 止まっていた1週間の固定費は「操業度差異」に取り分けられていた
大吟醸の原価がいつもどおりだったのは、製造間接費を**予定配賦率**で割り振っていたからだ。酒に割り振られたのは、実際に働いた1,600時間×4,000円＝640万円だけ。割り振られなかった155万円は、**製造間接費配賦差異**として取り分けられていた。
差異を分けると、中身がはっきりした。
- **予算差異35万円**：1,600時間なら本来760万円で済むはずが、795万円かかった。その大半はボイラーの緊急修理30万円
- **操業度差異120万円**：ボイラーが止まって作業時間が400時間減り、1時間3,000円ずつ割り振るはずだった固定費が割り振れずに残った。止まっていた1週間の、タンクの減価償却費や給料の分だ
差異は、年度末に売上原価に振り替える。酒1本の原価表には出てこないが、蔵の利益からは確実に155万円が差し引かれる。

::journal 年度末：製造間接費配賦差異を売上原価に振り替える（1月分のみの例）
売上原価 1,550,000 | 製造間接費配賦差異 1,550,000
::
::

「もし、実際の795万円を1,600時間で割って配賦していたら」と椎名は言った。「1時間あたり約4,969円。1月に仕込んだ大吟醸だけが、12月より2割以上高い酒になっていました。故障の責任を、酒が背負うことになる」
澪は、予定配賦の意味が腑に落ちた。原価計算表は、どの月に造っても同じ造り方なら同じ原価になるように作る。そのかわり、いつもと違うことが起きた月の影響は、差異として外に出てくる。

### 固定予算による分析

製造間接費の予算を、操業度にかかわらず1つの金額で決めておく方法もある。これを**固定予算**という。

::example 固定予算で、1月の配賦差異を分析しなさい
月間の製造間接費予算は8,000,000円（基準操業度2,000時間、予定配賦率4,000円）。実際の直接作業時間は1,600時間、実際発生額は7,950,000円。
::answer
- **予算差異**＝予算額－実際発生額＝8,000,000円－7,950,000円＝**＋50,000円（有利）**
- **操業度差異**＝予定配賦額－予算額＝6,400,000円－8,000,000円＝**△1,600,000円（不利）**
- 合計：＋50,000円＋△1,600,000円＝△1,550,000円
固定予算では、変動費も「作業時間にかかわらず一定」とみなすので、作業時間が減った月は、予算差異が有利に、操業度差異が大きく不利に出る。変動費が減ったのは当たり前なのに、「節約した」ように見えてしまう。費用の性質を正しく反映するのは、公式法変動予算のほうだ。
::
::

::exam 製造間接費の出題の急所
- **予定配賦率＝年間予算÷年間の基準操業度**。予定配賦額＝実際操業度×予定配賦率
- **配賦差異＝予定配賦額－実際発生額**。マイナスなら不利（借方）差異：「製造間接費配賦差異／製造間接費」
- **公式法変動予算**：予算差異＝(実際操業度×変動費率＋固定費予算)－実際発生額、操業度差異＝(実際操業度－基準操業度)×固定費率
- **固定予算**：予算差異＝予算額－実際発生額、操業度差異＝予定配賦額－予算額
- 差異分析の図（シュラッター図）を、横軸に操業度、縦軸に金額をとって描けるようにする。固定費率を使うのは操業度差異だけ
- 年度末に、配賦差異は売上原価に振り替える（売上原価加減法）
::

## 操業度差異は、蔵から出ていったお金か

::scene 1月の最終週 ― 蔵の事務所
差異の分析表を見た小松が、珍しく事務所に入ってきた。「ボイラーが止まって120万円の損か。古いボイラーを使い続けた社長の責任だな」
岩倉が言い返した。「修理代は30万円です。120万円は、帳簿の上の話で」
2人の言い分は、どちらも半分だけ正しかった。
::

::danger 操業度差異を「故障の損失」と読みちがえない
操業度差異120万円は、ボイラーが止まらなくても払っていた固定費（減価償却費や給料）のうち、酒に割り振れなかった部分だ。故障したせいで、蔵から新たに120万円が出ていったわけではない。
一方で、「帳簿の上の話」で済ませるのも誤りだ。故障の本当の損失は、**止まっていた間に造れなかった酒が生むはずだった儲け**にある。造りの季節は3月までと決まっていて、失った時間は取り戻せない。操業度差異は、その「失った能力の大きさ」を知らせる警報であって、損失の金額そのものではない。
::

::real 東京ディズニーランドが休園した4か月の、固定費の行き先
2020年2月29日、新型コロナウイルスの感染拡大を受けて、オリエンタルランドは東京ディズニーランドと東京ディズニーシーを臨時休園した。再開は7月1日。約4か月の間、来園者はゼロだったが、従業員の人件費や、アトラクションの減価償却費は発生し続けた。
同社は、2021年3月期の第1四半期（2020年4〜6月）に、休園期間中にテーマパーク事業で生じた固定費（人件費79億円、減価償却費81億円など）**211億円**を、**臨時休園による損失**として特別損失に計上した。この四半期の最終損益は248億円の赤字だった。

**この章の道具で読む ― 操業度ゼロの月の、固定費の行き先**
ふだんの月なら、パークの人件費や減価償却費は、営業のための原価として売上原価に入る。工場でいえば、製造間接費を予定配賦して製品の原価にするのと同じだ。だが、操業度がゼロになれば、固定費は1円も製品（サービス）に割り振れず、全額が操業度差異として残る。

::journal ① 休園中に発生した固定費（金額は報道の内訳を簡略化、単位：億円）
製造間接費 211 | 未払費用・減価償却累計額など 211
::
::journal ② 操業度ゼロのため、予定配賦額は0円。全額が操業度差異になる
製造間接費配賦差異 211 | 製造間接費 211
::
::journal ③ 異常な操業度の低下による差異は、売上原価ではなく特別損失（非原価）とする
臨時休園による損失 211 | 製造間接費配賦差異 211
::
ふつうの操業度差異（ボイラーの1週間の故障のように、毎年いくらかは起こりうるもの）は、売上原価に加えて原価の一部とする。だが、感染症による長期の休園のように、異常で臨時の原因で操業度が落ちたときの固定費は、本業の原価とは区別して特別損失とする。日本公認会計士協会も、新型コロナウイルスの影響で工場が操業を停止・縮小したときの「異常な操業度の低下による原価への影響」は、臨時性があると判断される場合が多いと整理している。
この区別のおかげで、決算書を読む人は、本業の原価と、休園という異常事態の損失を、分けて見ることができる。同じ「赤字」でも、本業が稼げなくなった赤字と、固定費だけが残った休園の赤字は、意味が違う。
::note

::cfo ボイラーの故障1回で、蔵はいくら失ったのか
2月、ボイラーの販売店が、新品への更新を提案してきた。判断の前に、澪は「故障1回の損失」を見積もることにした。
::table 1月の故障の資料
| 項目 | 金額・数量 |
| 製造間接費配賦差異 | 155万円（不利） |
| うち予算差異（緊急修理代30万円を含む） | 35万円（不利） |
| うち操業度差異 | 120万円（不利） |
| 止まっていた作業時間 | 400時間 |
| 400時間で造れたはずの純米吟醸 | 1,600本（1本0.25時間） |
| 純米吟醸1本の出荷価格 | 1,400円 |
| 純米吟醸1本の変動費（材料費260円＋変動製造間接費0.25時間×1,000円） | 510円 |
::
造りの季節は3月まで。失った400時間は取り戻せず、純米吟醸は造れば売れる状態だった。蔵人の賃金は、故障があってもなくても払う。まず、故障によって「なくなったお金」と「入ってこなくなったお金」を分けて計算してから選んでほしい。
::choice A. 配賦差異の155万円。帳簿にそう出ているのだから、それが損失だ
**× 帳簿の差異と、お金の損失を混同している。**155万円のうち120万円は操業度差異で、故障がなくても払っていた固定費のうち、酒に割り振れなかった分だ。蔵から新たに出ていったお金ではない。一方で、造れなかった酒の儲けは、この155万円のどこにも入っていない。最も「会計らしい」数字だが、損失の測り方としては的を外している。
::
::choice B. 操業度差異の120万円。止まっていた間の固定費が、まるごと無駄になった
**× 固定費は、故障しなくても出ていった。**減価償却費も給料も、ボイラーが動いていても同じだけ発生する。故障で変わったのは、それを「酒に割り振れたかどうか」だけだ。操業度差異は失った能力の大きさを示す警報だが、金額をそのまま損失とすると、本当の損失（造れなかった酒の儲け）を見落とす。
::
::choice C. 修理代30万円と、造れなかった純米吟醸1,600本の儲け（売上－変動費）の合計
**◎ 故障で変わったお金だけを数えている。**造れなかった純米吟醸の儲けは、1,600本×(1,400円－510円)＝**142万4,000円**。これに緊急修理代30万円を足して、故障1回の損失は**約172万円**になる。
固定費（減価償却費・給料）は故障があってもなくても変わらないので、損失に入れない。逆に、帳簿の差異には出てこない「入ってこなくなった儲け」を加える。この考え方は、第10章の直接原価計算で「限界利益」として本格的に登場する。
::
::choice D. 予算差異の35万円。お金を使いすぎたのは、この分だけだ
**△ 出ていったお金は正しく見ているが、入ってこなかったお金を見ていない。**修理代など、予算を超えて使ったお金は35万円だ。だが、故障の痛みの大半は、造れなかった酒の儲け142万円のほうにある。修理代だけで判断すれば、ボイラーの更新は「割に合わない」という結論になりかねない。
::
::answer 考え方の例を見る
差異分析は、原因を切り分ける道具だ。予算差異は「お金の使い方」、操業度差異は「能力の使い方」を表す。だが、意思決定に使う「損失の金額」は、差異の金額とは別に、**その出来事で変わるお金**だけを数えて計算する。固定費は変わらない。造れなかった製品の儲けは変わる。
澪の見積もりでは、故障1回の損失は約172万円。今シーズンは12月と1月に2回止まった。販売店の提案する新しいボイラーは1,500万円で、燃料代も年に約90万円下がるという。澪は、この数字を持って、第15章で補助金の申請に挑むことになる。
::
::

::next 差異分析は、標準原価計算で完成する
この章の差異分析は、製造間接費の「お金の使い方」と「能力の使い方」を分けた。第9章の標準原価計算では、さらに「作業の効率（能率差異）」を加えて3つに分ける。製品1本にかかるべき標準の作業時間と比べて、実際に何時間かかったかを測るのだ。1級では、変動費と固定費のそれぞれについて能率差異を分けるなど、分析の方法がさらに細かくなる。
::

## 確認問題

::quiz
::problem 次の資料から、予定配賦率、当月の予定配賦額、配賦差異を求めなさい。
年間の製造間接費予算 36,000,000円、年間の基準操業度（機械運転時間）12,000時間、当月の実際の機械運転時間 950時間、当月の製造間接費の実際発生額 2,960,000円
予定配賦率 [[3,000]] 円／時間、予定配賦額 [[2,850,000]] 円、配賦差異 [[110,000]] 円（[[不利差異]]）
<!-- choices: 有利差異 | 不利差異 -->
::answer
予定配賦率＝36,000,000円÷12,000時間＝**3,000円**。予定配賦額＝950時間×3,000円＝**2,850,000円**。配賦差異＝2,850,000円－2,960,000円＝△**110,000円**で、予定配賦額が実際より少ないので**不利差異（借方差異）**。
::
::
::problem 公式法変動予算による資料から、予算差異と操業度差異を求めなさい（不利差異はマイナスで答える）。
変動費率 600円／時間、月間の固定費予算 1,200,000円、基準操業度 1,000時間、実際操業度 900時間、実際発生額 1,770,000円
予算差異 [[-30,000]] 円、操業度差異 [[-120,000]] 円
::answer
予算許容額＝900時間×600円＋1,200,000円＝1,740,000円。予算差異＝1,740,000円－1,770,000円＝**△30,000円**（不利）。
固定費率＝1,200,000円÷1,000時間＝1,200円。操業度差異＝(900時間－1,000時間)×1,200円＝**△120,000円**（不利）。
合計△150,000円は、配賦差異（予定配賦額900時間×1,800円＝1,620,000円－実際1,770,000円）と一致する。
::

(1) 製造間接費を予定配賦率1時間2,500円で仕掛品に配賦した。当月の実際の直接作業時間は800時間である。
(2) 当月の製造間接費の実際発生額は1,980,000円だった。配賦差異を製造間接費配賦差異勘定に振り替える。

仕掛品 2,000,000 | 製造間接費 2,000,000

::journal (2) 2,000,000円－1,980,000円＝＋20,000円（有利差異）
製造間接費 20,000 | 製造間接費配賦差異 20,000

::summary
- 製造間接費は、間接材料費・間接労務費・間接経費の集まり。経費は支払経費・月割経費・測定経費・発生経費に分かれ、外注加工賃は直接経費として仕掛品へ
- 予定配賦率＝年間予算÷年間の基準操業度。予定配賦額＝実際操業度×予定配賦率。予定配賦で、作業時間の多い月と少ない月の原価の揺れを防ぐ
- 配賦差異＝予定配賦額－実際発生額。年度末に売上原価に振り替える
- 公式法変動予算では、予算差異＝予算許容額－実際発生額、操業度差異＝(実際操業度－基準操業度)×固定費率
- 操業度差異は、割り振れなかった固定費（失った能力の大きさ）であり、出ていったお金そのものではない。意思決定では「その出来事で変わるお金」だけを数える
- 異常な原因による操業度の低下の固定費は、原価ではなく特別損失とする
::
