## 修理業者の請求書 ― 製造間接費を集める

まず、1月に実際にいくらかかったのかを集めることにした。どの酒のためと決められない費用は、すべて**製造間接費**の勘定に集まる。間接材料費、間接労務費、間接経費。第1章から第3章で見てきた3つの流れが、ここで合流する。
修理業者の請求書は、30万円だった。

::table sum 1月の製造間接費の実際発生額（単位：円）
| 費目 | 区分 | 金額 |
| タンクの洗浄剤・ろ過の消耗材 | 間接材料費 | 450,000 |
| 間接工・杜氏の賃金、手待時間など | 間接労務費 | 3,200,000 |
| 仕込み蔵・精米機の減価償却費 | 間接経費 | 1,800,000 |
| ボイラーの燃料・電気 | 間接経費 | 1,200,000 |
| ボイラーの緊急修理代 | 間接経費 | 300,000 |
| 保険料・その他 | 間接経費 | 1,000,000 |
|= 合計 | | 7,950,000 |
::

燃料代は、いつもの月より30万円ほど少なかった。止まっていた4日間、ボイラーは燃料を食わなかったからだ。そこまでは、澪の言うとおりだった。
だが、減価償却費や杜氏の給料は、ボイラーが止まっても1円も減っていない。

::point メモ ― 製造間接費の実際発生額
製造間接費は、間接材料費・間接労務費・間接経費の合計で、月末に実際の発生額が集計される。月の途中で仕訳した「製造間接費／材料」「製造間接費／賃金・給料」「製造間接費／減価償却累計額」などが、製造間接費勘定の借方に集まった姿だ。
::

## 1時間4,000円の正体 ― 予定配賦と配賦差異

::scene 2月3日、午後2時 ― 帳場
月例の訪問に来た椎名は、1月の原価計算表を見るなり、聞いた。
椎名：「製造間接費は、1時間いくらで酒に配っていますか」
澪：「4,000円です。岩倉さんが、7月から同じ数字で」
椎名：「では、1月に酒に配った製造間接費はいくらですか」
澪：「作業時間が1,600時間なので、1,600×4,000円で640万円……あれ」
実際にかかったのは795万円。酒に配られたのは640万円。155万円が、酒の原価に入っていない。
::

岩倉が、7月に作った予算表を出してきた。

::table 今期の製造間接費予算（公式法変動予算）
| 項目 | 年間 | 月間 |
| 基準操業度（直接作業時間） | 24,000時間 | 2,000時間 |
| 変動費（1時間あたり1,000円） | 2,400万円 | 200万円 |
| 固定費 | 7,200万円 | 600万円 |
|= 製造間接費予算 | 9,600万円 | 800万円 |
::

::formula 予定配賦率
予定配賦率 ＝ 製造間接費の年間予算 ÷ 年間の基準操業度
9,600万円 ÷ 24,000時間 ＝ 4,000円／時間
::

内訳は、変動費率1,000円と、固定費率3,000円（7,200万円÷24,000時間）だ。
椎名：「実際の発生額を、実際の時間で割って配ると、どうなりますか」
澪は電卓をたたいた。795万円÷1,600時間＝約4,969円。12月は4,000円前後だったから、2割以上高い。
澪：「1月に仕込んだ大吟醸だけが、12月より2割も高い酒になる……。故障の責任を、酒が背負うことになるんですね」
椎名：「だから、期首に決めた**予定配賦率**で配るんです。第2章の米、第3章の賃金と同じ考え方です」

::theory 予定配賦で原価を安定させ、ずれは配賦差異に取り分ける
製造間接費は、**予定配賦率×実際の操業度**（実際の作業時間など）で仕掛品に配賦する。実際の発生額との差は、**製造間接費配賦差異**に振り替える。
実際の発生額は月末まで分からず、しかも固定費が多いので、操業度の少ない月ほど1時間あたりの額が高くなる。予定配賦を使えば、仕込んだ月によって同じ酒の原価が上下しない。
::

::example 1月の製造間接費を予定配賦し、配賦差異を計上する
1月の実際の直接作業時間は1,600時間、予定配賦率は1時間4,000円。製造間接費の実際発生額は7,950,000円だった。
::answer
::journal (1) 予定配賦：1,600時間×4,000円
仕掛品 6,400,000 | 製造間接費 6,400,000
::
::journal (2) 配賦差異：6,400,000円－7,950,000円＝△1,550,000円（不利差異）
製造間接費配賦差異 1,550,000 | 製造間接費 1,550,000
::
製造間接費勘定は、借方に実際発生額7,950,000円、貸方に予定配賦額6,400,000円が入る。貸方の足りない1,550,000円を配賦差異の借方に振り替えると、残高がゼロになる。
::trap
予定配賦額は「予定配賦率×**実際**の操業度」だ。基準操業度（2,000時間）を掛けないこと。また、不利差異は借方。実際のほうが多いのに配賦差異を貸方に書く誤りが多い。
::
::
::

::tgrid
::taccount 製造間接費
諸口 7,950,000 | 仕掛品 6,400,000
 | 製造間接費配賦差異 1,550,000
= 7,950,000 | 7,950,000
::
::taccount 製造間接費配賦差異
製造間接費 1,550,000 |
= 1,550,000 |

## ホワイトボードの斜めの線 ― 予算差異と操業度差異

澪：「155万円の差異は、ボイラーの修理代ですか」
椎名：「修理代は30万円でしたね。残りの125万円は？」
澪は答えられなかった。椎名はホワイトボードに、右上がりの線を2本引いた。
椎名：「上の線が予算の線です。作業時間が増えると変動費の分だけ費用が増える。固定費600万円の高さから始まります」
椎名：「下の線が、予定配賦の線。原点から、1時間4,000円の傾きで上がります。2,000時間のところで、2本の線が出会う」

::point メモ ― 予算許容額
実際の操業度のときに、予算上かかってよい製造間接費の額を**予算許容額**という。公式法変動予算では、予算許容額＝変動費率×実際の操業度＋固定費予算。1月は1,000円×1,600時間＋600万円＝760万円になる。
::

配賦差異155万円は、2つに分けられる。
- **予算差異**：予算許容額760万円と実際発生額795万円の差、△35万円。1,600時間なら760万円で済むはずが、35万円使いすぎた。その大半は、ボイラーの緊急修理代30万円だ
- **操業度差異**：予定配賦額640万円と予算許容額760万円の差、△120万円。作業時間が400時間減り、1時間3,000円ずつ配るはずだった固定費が、配りきれずに残った

::formula 予算差異と操業度差異
予算差異 ＝ 予算許容額 － 実際発生額
操業度差異 ＝（実際操業度 － 基準操業度）× 固定費率
::

::example 1月の配賦差異を、予算差異と操業度差異に分ける
変動費率1,000円、月間の固定費予算6,000,000円、基準操業度2,000時間（固定費率3,000円）。1月の実際操業度は1,600時間、実際発生額は7,950,000円、予定配賦額は6,400,000円だった。
::answer
- 予算許容額：1,000円×1,600時間＋6,000,000円＝7,600,000円
- 予算差異：7,600,000円－7,950,000円＝**△350,000円（不利）**
- 操業度差異：(1,600時間－2,000時間)×3,000円＝**△1,200,000円（不利）**
- 合計：△1,550,000円で、配賦差異と一致する
::journal 差異を内訳の勘定に振り替える場合
予算差異 350,000 | 製造間接費配賦差異 1,550,000
操業度差異 1,200,000 |
::
::trap
操業度差異は**固定費率**で計算する。予定配賦率（4,000円）を掛けると、変動費の分まで入って480万円…と大きく誤る。変動費は操業度に比例して予算も動くので、操業度のずれでは差異が生まれない。
::
::
::

澪は、ホワイトボードの2本の線と、自分の原価計算表を見比べた。表に載っているのは、予定配賦率×実際の時間の640万円だけだ。実際に払った795万円との差155万円は、配賦差異の勘定に入っている。
燃料が浮いた30万円は、修理代の30万円で、とっくに消えていた。

::solve 原価が安く見えたのは、止まった時間の固定費が、差異の勘定に隠れていたから
1月の酒の原価が安く見えたのは、作業時間が減って、酒に配られた製造間接費の合計が640万円に減ったからだ。だが、蔵が実際に払ったのは795万円。配られなかった155万円は、**製造間接費配賦差異**として取り分けられていた。
その内訳は、修理代を中心とする予算差異35万円と、止まった400時間に配るはずだった固定費の操業度差異120万円。燃料が浮いた分など、とっくに修理代で消えていた。
もし澪の言うとおり「故障も悪くない」と考えて古いボイラーを使い続けていたら、止まるたびに配れない固定費が積み上がり、年度末に売上原価として一気に利益を削っていた。
**機械が止まっても、固定費は止まらない。予定配賦の原価計算表は、止まった時間の固定費を、差異の勘定に黙って預けておくだけだ。**
::

::journal 会計年度末：製造間接費配賦差異（借方残高）を売上原価に振り替える（1月分のみの例）
売上原価 1,550,000 | 製造間接費配賦差異 1,550,000
::

### 試験で狙われるパターン ― 固定予算・有利差異・異常な操業度の低下

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 固定予算で分析する**　操業度がいくらでも、予算を1つの金額（基準操業度のときの予算）に固定して考える方法を**固定予算**という。予算許容額は、操業度にかかわらず固定予算の額になる。

::example 1月の配賦差異を、固定予算で分析する
固定予算は月8,000,000円、基準操業度2,000時間、予定配賦率4,000円。1月の実際操業度は1,600時間、実際発生額は7,950,000円だった。
::answer
- 予算差異：8,000,000円－7,950,000円＝**＋50,000円（有利）**
- 操業度差異：(1,600時間－2,000時間)×4,000円＝**△1,600,000円（不利）**
- 合計：△1,550,000円（配賦差異と一致）
固定予算では、操業度が減っても予算が減らないので、変動費の節約分（作業が減って自然に減った分）まで「予算の節約」に見える。修理代で使いすぎたのに、予算差異が有利になる。
::trap
固定予算の操業度差異は、固定費率ではなく**予定配賦率**（4,000円）で計算する。公式法変動予算と固定予算で、操業度差異に掛ける率が違うことが、最も狙われる。
::
::
::

**② 有利差異のとき**　実際発生額が予定配賦額より少なければ有利差異（貸方差異）になり、年度末に売上原価から差し引く。

**③ 異常な原因で操業度が大きく落ちたとき**　毎年いくらかは起こりうる操業度差異は売上原価に加えるが、災害や長期の操業停止のような異常な原因による差異は、原価から除いて**非原価項目**（特別損失など）とする。次の節で、実際の例を見る。

::steps 解法の型 ― 製造間接費の差異分析（シュラッター図）
1. 率を出す | 変動費率と固定費率（固定費予算÷基準操業度）、予定配賦率＝両者の合計
2. 3つの金額を縦に並べる | 実際発生額、予算許容額（変動費率×実際操業度＋固定費予算）、予定配賦額（予定配賦率×実際操業度）
3. 予算差異 | 予算許容額－実際発生額
4. 操業度差異 | （実際操業度－基準操業度）×固定費率。固定予算なら×予定配賦率
5. 検算 | 2つの差異の合計＝予定配賦額－実際発生額
::

## 東京の春の記憶 ― 休園したテーマパークの固定費

::scene 1月31日、夜 ― 帳場
止まった4日間の固定費、120万円。止まっていても、払い続ける費用。澪は、6年前の春を思い出した。
商社に入ったばかりの2020年、新型コロナウイルスで東京の街から人が消えた。浦安の東京ディズニーランドと東京ディズニーシーも、2月29日から臨時休園した。再開は7月1日。約4か月、客は1人も来なかった。
澪：「あのとき、パークの人件費や、アトラクションの減価償却費は、どこへ行ったんだろう」
::

運営会社のオリエンタルランドは、2021年3月期の第1四半期（2020年4〜6月）に、休園期間中にテーマパーク事業で生じた固定費（人件費79億円、減価償却費81億円など）**211億円**を、**臨時休園による損失**として特別損失に計上していた。この四半期の最終損益は248億円の赤字だった。
ふだんの月なら、パークの人件費や減価償却費は、サービスの原価として売上原価に入る。工場でいえば、製造間接費を予定配賦して製品の原価にするのと同じだ。だが、操業度がゼロになれば、固定費は1円も配れず、全額が操業度差異として残る。澪は、この章の勘定で流れを描いてみた（報道の内訳を簡略化した、仕組みを示すための仕訳。単位：億円）。

::journal ① 休園中に発生した固定費（人件費79・その他51は未払、減価償却費81）
製造間接費 211 | 未払費用 130
 | 減価償却累計額 81
::

::journal ② 操業度ゼロのため予定配賦額は0円。全額が操業度差異になる
製造間接費配賦差異 211 | 製造間接費 211
::

::journal ③ 異常な操業度の低下による差異は、売上原価ではなく特別損失（非原価）とする
臨時休園による損失 211 | 製造間接費配賦差異 211
::

翌月、澪がこの仕訳を見せると、椎名はうなずいた。
椎名：「ボイラーの4日間のように、毎年いくらかは起こりうる操業度差異は、売上原価に加えます。でも、感染症による長い休園のような異常な原因なら、本業の原価とは区別して特別損失にする。当時、日本公認会計士協会もそう整理しています」
澪：「同じ赤字でも、本業が稼げなくなった赤字と、休園で固定費だけが残った赤字は、意味が違うんですね」
澪はノートの隅に書いた。「赤字の中身を、段で分ける」。半年後、この1行が、蔵の命運を分けることになる。

::note
出典：[トラベルボイス「オリエンタルランド、休園響き売上高94.9%減、最終損益は248億円の赤字に」（2020年7月31日）](https://www.travelvoice.jp/20200731-146746)、[日本公認会計士協会「新型コロナウイルス感染症に関連する監査上の留意事項（その3）」（2020年6月18日）](https://jicpa.or.jp/news/information/files/3-99-0-0-20200618-3.pdf)
::

::cfo 故障1回で、蔵はいくら損をしたのか ― ボイラーの更新を考える前に
澪は、ボイラーを新しくするかどうかを考えるために、まず「故障1回の損失」を見積もることにした。
**前提**
- 1月の製造間接費配賦差異は155万円（不利）。うち予算差異35万円（緊急修理代30万円を含む）、操業度差異120万円
- 止まった400時間で造れなかったのは、純米吟醸1,600本（1本0.25時間）。純米吟醸は造れば必ず売れる
- 純米吟醸1本の出荷価格は1,400円。造る量に比例してかかる費用（材料費と変動製造間接費）は1本510円
- 蔵人の賃金と固定費は、故障があってもなくても同じ額を払う
- 新しいボイラーは1,500万円で、燃料代が年に約90万円下がる
::choice A. 配賦差異の155万円。帳簿に出ている差異が、そのまま故障の損失だ
**× 帳簿の差異と、お金の損失を混同している。**155万円のうち120万円は、故障がなくても払っていた固定費のうち、酒に配れなかった分だ。蔵から新たに出ていったお金ではない。一方で、造れなかった酒の儲けは、155万円のどこにも入っていない。
::
::choice B. 修理代30万円と、造れなかった純米吟醸1,600本の儲け（出荷価格－変動費）の合計
**◎ 故障で変わったお金だけを数えている。**造れなかった純米吟醸の儲けは、1,600本×（1,400円－510円）＝142万4,000円。修理代30万円を足して、故障1回の損失は**約172万円**になる。
::
::choice C. 操業度差異の120万円。止まっていた間の固定費が、まるごと無駄になった
**△ 半分だけ正しい。**固定費の配り残しは、故障の影ではある。だが、その固定費は止まらなくても払っていた。故障で本当に失ったのは、その時間で稼げたはずの儲けと、修理代だ。
::
::choice D. 予算差異の35万円。予算より多く使ったお金だけが、故障の損失だ
**△ 出ていったお金は見ているが、入ってこなかったお金を見ていない。**故障の痛みの大半は、造れなかった酒の儲け142万円のほうにある。修理代だけで判断すれば、ボイラーの更新は「割に合わない」という結論になりかねない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「帳簿の差異はいくらか」ではなく、「故障がなかった場合と比べて、蔵のお金はいくら少なくなったか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 故障1回で変わったお金
| 中身 | 金額 |
| 出ていったお金：緊急修理代 | 30万円 |
| 入ってこなかったお金：純米吟醸1,600本×（1,400円－510円） | 142万4,000円 |
| 故障があってもなくても同じ：蔵人の賃金・固定費 | 0円 |
|= 合計 | 約172万円 |
::
#### 手順3　ほかの答えに引かれる理由
Aは、帳簿に載った「最も会計らしい」数字だから引かれる。Cは、止まっていた間の固定費が無駄に見えるから、Dは、目に見えて出ていったお金だから引かれる。新しいボイラーの値段と燃料代は、この問いには関係のない前提で、次の判断（更新するか）で使う。
#### 持ち帰る考え方
- **判断で変わるお金だけを数える**：故障があってもなくても払う固定費は、損失に入れない
- **帳簿の差異は、損失の額そのものではない**：差異は原価計算のずれを示す数字で、意思決定には読み替えが要る
#### 前提が変われば
純米吟醸の注文が少なく、止まった分を後で造れば十分に間に合ったなら、失った儲けはほぼゼロで、損失は修理代の30万円だけになる。そのときは、ボイラーの更新を急ぐ理由も小さくなる。
::
::

::exam 製造間接費の急所
- 予定配賦額＝予定配賦率×**実際**操業度。配賦差異＝予定配賦額－実際発生額（マイナスは不利・借方）
- 予算許容額＝変動費率×実際操業度＋固定費予算（公式法変動予算）
- 予算差異＝予算許容額－実際発生額。操業度差異＝（実際操業度－基準操業度）×**固定費率**
- 固定予算なら、予算許容額は固定予算の額、操業度差異は×**予定配賦率**
- 差異は年度末に売上原価へ（不利は加算、有利は減算）。異常な原因の差異は非原価項目
::

::next 差異は、管理の道具になる
第5章では、製造間接費を部門ごとに集めて配る。第9章の標準原価計算では、製造間接費の差異をさらに「能率差異」まで分け、誰の責任で、何が原因かを突き止める。1級では、差異の情報を使って予算を立て、業績を評価する方法を学ぶ。
::

::summary
- 製造間接費は、間接材料費・間接労務費・間接経費の合計を月末に集計する
- 予定配賦率＝年間予算÷年間の基準操業度。予定配賦額＝予定配賦率×実際操業度
- 予定配賦額と実際発生額の差が製造間接費配賦差異
- 配賦差異は、予算許容額をはさんで、予算差異（使いすぎ）と操業度差異（固定費の配り残し）に分けられる
- 固定予算では、操業度差異に予定配賦率を掛ける
- 差異は年度末に売上原価に加減する。異常な原因によるものは非原価項目
::

## 確認問題

::quiz
::problem 当社は製造間接費を予定配賦している。年間の製造間接費予算は30,000,000円、年間の基準操業度（直接作業時間）は12,000時間である。当月の実際直接作業時間は800時間、製造間接費の実際発生額は1,980,000円だった。
(1) 製造間接費を予定配賦した。
(2) 配賦差異を計上した。
(3) 会計年度末に、製造間接費配賦差異（当月分）を売上原価に振り替えた。
::answer
::journal (1) 予定配賦率30,000,000円÷12,000時間＝2,500円、800時間×2,500円
仕掛品 2,000,000 | 製造間接費 2,000,000
::
::journal (2) 2,000,000円－1,980,000円＝＋20,000円（有利差異）
製造間接費 20,000 | 製造間接費配賦差異 20,000
::
::journal (3) 有利差異（貸方残高）は売上原価から差し引く
製造間接費配賦差異 20,000 | 売上原価 20,000
::
実際発生額のほうが少ないので、有利差異。配賦差異の勘定は貸方に残り、年度末に売上原価を減らす。
::
::
::problem 公式法変動予算による資料から、予算差異と操業度差異を求めなさい（不利差異はマイナスの数で答える）。
変動費率 600円／時間、月間の固定費予算 1,800,000円、月間の基準操業度 3,000時間、当月の実際操業度 2,800時間、当月の実際発生額 3,500,000円
予算差異 [[-20,000]] 円、操業度差異 [[-120,000]] 円
::answer
予算許容額＝600円×2,800時間＋1,800,000円＝3,480,000円。予算差異＝3,480,000円－3,500,000円＝**△20,000円（不利）**。
固定費率＝1,800,000円÷3,000時間＝600円。操業度差異＝(2,800時間－3,000時間)×600円＝**△120,000円（不利）**。
予定配賦率は600円＋600円＝1,200円で、予定配賦額2,800時間×1,200円＝3,360,000円。実際3,500,000円との差△140,000円が、2つの差異の合計と一致する。
::
::
::problem 固定予算による資料から、予算差異と操業度差異を求めなさい（不利差異はマイナスの数で答える）。
固定予算（月額）2,400,000円、基準操業度 1,200時間、実際操業度 1,100時間、実際発生額 2,350,000円
予算差異 [[50,000]] 円、操業度差異 [[-200,000]] 円
::answer
予定配賦率＝2,400,000円÷1,200時間＝2,000円。予算差異＝2,400,000円－2,350,000円＝**＋50,000円（有利）**。
操業度差異＝(1,100時間－1,200時間)×2,000円＝**△200,000円（不利）**。固定予算では、操業度差異に予定配賦率を掛ける。
合計は△150,000円で、予定配賦額2,200,000円－実際2,350,000円と一致する。
::
