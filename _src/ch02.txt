::mystery 上がったはずの原価が、表に出てこない
11月30日、月曜日。初めての月次の原価計算を終えた澪は、事務所の机で首をかしげていた。
この月に届いた酒米の請求書は、2通とも1kgあたり700円を超えていた。去年の契約は600円。新米の価格交渉で、農家から「肥料も燃料も上がった」と言われ、父の代わりに澪がうなずいた値段だ。
それなのに、出来上がった原価計算表の「直接材料費」の欄では、酒米は1kg**600円**のまま計算されていた。表の上では、大吟醸1本の原価は、先月と1円も変わっていない。
「番頭さん、計算が間違っていませんか」
岩倉は、老眼鏡をずらして表を見た。「間違っとりません。今期の酒米は1kg600円で計算する。7月に、そう決めましたから」
請求書の金額は、確かに預金から出ていく。それなのに、原価には入っていない。**上がった分のお金は、帳簿のどこへ消えたのか？**
::

## 材料の購入原価 ― 請求書の金額だけでは足りない

12月の第2火曜日。月に1度の訪問に来た椎名に、澪は原価計算表と請求書を並べて見せた。椎名は表には触れず、請求書の束をめくった。
「まず、材料を買ったときの話からにしましょう。この酒米は、いくらで買いましたか」
「1kg680円です。8,000kgで544万円」
「それを蔵まで運んだのは、誰ですか」
「運送会社です……あ」
請求書の下に、もう1枚、運送会社の請求書があった。16万円。

::theory 材料の購入原価＝購入代価＋材料副費
材料を手に入れて使える状態にするまでにかかった費用は、すべて材料の原価に含める。
- **購入代価**：材料そのものの代金（送り状価額）。値引・割戻を受けたら差し引く
- **材料副費**：材料の購入から使えるようになるまでの付随費用
  - 外部副費（引取費用）：引取運賃・買入手数料・保険料・関税など、外部に払うもの
  - 内部副費：検収費・整理費・保管費など、社内で発生するもの
3級で学んだ商品の「仕入諸掛」と同じ考え方だ。運賃を払わなければ、米は蔵に届かない。
::

内部副費は、蔵の中で米を検査したり、保管庫を管理したりする費用で、発生額が月末まで確定しない。そこで、あらかじめ決めた割合（予定配賦率）で材料の原価に加えておく方法がある。実際の発生額との差は**材料副費差異**として処理する。

::example 11月の酒米の購入を仕訳しなさい
(1) 11月5日、酒米8,000kgを1kg680円で掛けで購入した。引取運賃160,000円は現金で支払った。
(2) 11月20日、酒米6,000kgを1kg700円で掛けで購入した。引取運賃120,000円は現金で支払った。
(3) 内部副費（検収・保管の費用）を、購入代価の1%で予定配賦している。11月の購入代価の合計は9,640,000円である。
(4) 月末に集計した内部副費の実際の発生額は105,000円だった。予定配賦額との差額を材料副費差異に振り替える。
::answer
::journal (1) 引取運賃は材料の原価に含める
材料 5,600,000 | 買掛金 5,440,000
 | 現金 160,000
::
::journal (2)
材料 4,320,000 | 買掛金 4,200,000
 | 現金 120,000
::
::journal (3) 内部副費の予定配賦：9,640,000円×1%
材料 96,400 | 材料副費 96,400
::
::journal (4) 実際105,000円－予定96,400円＝8,600円の不足（借方差異）
材料副費差異 8,600 | 材料副費 8,600
::
(1)は1kgあたり5,600,000円÷8,000kg＝700円、(2)は4,320,000円÷6,000kg＝720円になる。請求書の単価より、運賃の分だけ高い。
(3)(4)の**材料副費**勘定には、実際の内部副費105,000円が借方に集まっていて、予定配賦額96,400円が貸方から材料へ出ていく。貸方が8,600円足りない分が差異だ。実際が予定より多い差異は、原価を押し上げる**不利差異（借方差異）**という。以下の計算では、説明を簡単にするため、内部副費の予定配賦額は消費単価の計算に含めない。
::
::

## 材料の消費 ― 「いくらの米を使ったか」は計算方法で変わる

「では、11月に使った酒米の原価はいくらですか」
「使ったのは1万3,000kgです。でも、1kg600円の米と、700円の米と、720円の米が混ざっていて……」
「それが、材料費の計算でいちばん大事なところです」と椎名は言った。「消費した量に、いくらの単価を掛けるか」

::formula 材料費の計算
材料費 ＝ 消費数量 × 消費単価
::

**消費数量**は、出庫のたびに材料元帳に記録する**継続記録法**で把握するのが原則だ。記録がない補助材料などは、月初の在庫＋購入量－月末の実地棚卸量で逆算する**棚卸計算法**を使う。
**消費単価**は、同じ材料を違う値段で買っているとき、どの値段の分を使ったとみなすかで決まる。2級で使う方法は3つある。

::table 消費単価の計算方法
| 方法 | 考え方 | 特徴 |
| 先入先出法 | 先に買ったものから先に使ったとみなす | 月末の在庫は、新しい（直近の）単価で残る |
| 移動平均法 | 買い入れるたびに、残っている分と平均した単価で払い出す | 払い出すたびに計算が必要 |
| 総平均法 | 月初の在庫と1か月の購入分をまとめて平均した単価で払い出す | 月末まで単価が決まらない |
::

### 11月の材料元帳を、3つの方法で計算する

汐見酒造の11月の酒米の動きはこうだった（月初の在庫は、10月に600円で買った残りの2,000kg）。

::table compact 酒米の受け払い（11月）
| 日付 | 摘要 | 数量 | 単価 | 金額 |
| 11/1 | 月初の在庫 | 2,000kg | 600円 | 1,200,000円 |
| 11/5 | 受け入れ | 8,000kg | 700円 | 5,600,000円 |
| 11/10 | 払い出し（仕込み） | 6,000kg | ? | ? |
| 11/20 | 受け入れ | 6,000kg | 720円 | 4,320,000円 |
| 11/25 | 払い出し（仕込み） | 7,000kg | ? | ? |
::

::example 先入先出法・移動平均法・総平均法で、11月の消費額と月末の在庫を計算しなさい
::answer
**先入先出法**
- 11/10 払い出し6,000kg：月初の2,000kg×600円＝1,200,000円と、11/5分の4,000kg×700円＝2,800,000円 → 4,000,000円
- 11/25 払い出し7,000kg：11/5分の残り4,000kg×700円＝2,800,000円と、11/20分の3,000kg×720円＝2,160,000円 → 4,960,000円
- 消費額の合計 **8,960,000円**、月末の在庫 3,000kg×720円＝**2,160,000円**

**移動平均法**
- 11/5 受け入れ後：(1,200,000円＋5,600,000円)÷(2,000kg＋8,000kg)＝680円
- 11/10 払い出し：6,000kg×680円＝4,080,000円。残り4,000kg×680円＝2,720,000円
- 11/20 受け入れ後：(2,720,000円＋4,320,000円)÷(4,000kg＋6,000kg)＝704円
- 11/25 払い出し：7,000kg×704円＝4,928,000円
- 消費額の合計 **9,008,000円**、月末の在庫 3,000kg×704円＝**2,112,000円**

**総平均法**
- 平均単価：(1,200,000円＋5,600,000円＋4,320,000円)÷(2,000kg＋8,000kg＋6,000kg)＝11,120,000円÷16,000kg＝695円
- 消費額の合計 13,000kg×695円＝**9,035,000円**、月末の在庫 3,000kg×695円＝**2,085,000円**

どの方法でも、「消費額＋月末の在庫＝11,120,000円」になる。計算方法で変わるのは、合計11,120,000円を、今月の原価と来月への在庫にどう分けるかだけだ。値上がりが続く月には、先入先出法は古い安い単価から使うので、消費額が最も小さくなる。
::
::

汐見酒造は、先入先出法を採用している。11月の酒米の実際の消費額は8,960,000円。1kgあたりにすると、約689円だ。

## 予定価格 ― 番頭が600円にこだわった理由

「それなら、原価計算表にも、8,960,000円と書けばいいのでは」
澪がそう言うと、黙って聞いていた岩倉が口を開いた。
「専務。去年の12月は、米を安く買えた月でした。その月に仕込んだ大吟醸は、原価が下がった。今年の1月は、高い米が届いた月で、同じ大吟醸の原価が上がった。造り方は何も変わっとらんのに、です。杜氏さんに『今月は原価が上がった』と言うたら、『わしの腕のせいか』と怒られました」
椎名がうなずいた。「番頭さんが600円で計算しているのは、**予定価格**です」

::theory 予定価格（予定消費単価）で計算する理由
材料の実際の単価は、仕入れた時期と値段の巡り合わせで上下する。実際の単価で原価を計算すると、作り方が何も変わらなくても、製品の原価が月ごとに揺れてしまう。そこで、期首に1年間の**予定価格**を決め、消費した材料は「実際の消費量×予定価格」で製品の原価に入れる。
- 原価計算が早く終わる（月末に実際の単価が確定するのを待たなくてよい）
- 製品の原価から、**仕入れ値の変動**の影響を取り除き、**材料の使い方（量）の良し悪し**だけを見られる
- 実際の消費額との差額は、**材料消費価格差異**として、製品の原価とは別の勘定に集める
::

「上がった分のお金は消えたのではありません」と椎名は言った。「材料消費価格差異という勘定に、取り分けてあるだけです」

::formula 材料消費価格差異
材料消費価格差異 ＝ 予定消費額（実際の消費量×予定価格）－ 実際消費額
マイナス（予定＜実際）なら**不利差異（借方差異）**、プラスなら**有利差異（貸方差異）**
::

::example 11月の酒米の消費を、予定価格で仕訳しなさい
11月に仕込みに使った酒米13,000kgは、すべて直接材料である。予定価格は1kg600円。実際の消費額は先入先出法で8,960,000円だった。
::answer
::journal (1) 予定価格による消費：13,000kg×600円
仕掛品 7,800,000 | 材料 7,800,000
::
::journal (2) 差異の計上：7,800,000円－8,960,000円＝△1,160,000円（不利差異）
材料消費価格差異 1,160,000 | 材料 1,160,000
::
(1)で、製品の原価（仕掛品）には予定価格の7,800,000円だけが入る。(2)で、材料勘定から実際に出ていった額との差1,160,000円を、材料消費価格差異の借方に振り替える。これで材料勘定の残高は、月末の在庫の実際の金額2,160,000円と一致する。
::
::

::tgrid
::taccount 材料（酒米）
前月繰越 1,200,000 | 仕掛品 7,800,000
買掛金・現金 5,600,000 | 材料消費価格差異 1,160,000
買掛金・現金 4,320,000 | 次月繰越 2,160,000
= 11,120,000 | 11,120,000
::

材料 1,160,000 |

## 答え合わせ ― 消えたお金は、どこにあったか

::scene 12月の第2火曜日、夕方 ― 蔵の事務所
「つまり、11月に高く買った分の116万円は、原価計算表ではなく、この差異の勘定に貯まっていくんですね」
澪はホワイトボードに書いた。「仕込みは3月まで続きます。高い米は、これからも届く。毎月100万円以上ずつ貯まっていったら――」
「年度末には、どうなると思いますか」と椎名が聞いた。
::

::solve 上がった分は「材料消費価格差異」に貯まり、年度末に売上原価に加わる
原価計算表の酒米が1kg600円のままだったのは、計算の誤りではない。予定価格で計算していたからだ。上がった分の1,160,000円は、**材料消費価格差異**の借方に取り分けられていた。
この差異は、消えたわけでも、なかったことになるわけでもない。会計年度末に、原則として**売上原価**に振り替えて（売上原価に加算して）、その期の費用にする。製品1本あたりの原価表には出てこないが、損益計算書の利益は、確実に1,160,000円減る。

::journal 年度末：材料消費価格差異（借方残高）を売上原価に振り替える
売上原価 1,160,000 | 材料消費価格差異 1,160,000
::
原価計算表は「造り方の良し悪し」を見るための物差しで、損益計算書は「蔵がいくら儲けたか」を示す結果だ。予定価格は、この2つを分けて見るための仕組みだった。
::

岩倉は、差異の勘定のT字を長いこと見ていた。「わしは、600円で計算して、それで終わりにしとりました。差額は、年に1度、決算のときに椎名先生の事務所で片づけてもらっとった」
「それが、毎月見えるようになっただけです」と椎名は言った。「見えるようになったら、使えます」

::danger 差異を見ない予定価格は、値上げの合図を握りつぶす
予定価格で計算した原価表だけを見ていると、仕入れ値が上がっても製品の原価は動かない。「原価は変わっていないから、値段も据え置き」と判断すれば、差異はそのまま年度末に売上原価へ流れ込み、利益を削る。
予定価格は、仕入れ値の変動を「差異」として切り分ける道具であって、変動を消す道具ではない。毎月、差異の大きさと原因（仕入れ値か、使った量か）を確かめてこそ意味がある。
::

## 棚卸減耗と、そのほかの材料費

### 棚卸減耗 ― 帳簿の米と、倉庫の米が合わない

12月末、澪は初めて酒米の倉庫で実地棚卸に立ち会った。材料元帳では3,000kgあるはずの米袋を数え、秤にかけると、2,980kgだった。
袋の破れからこぼれた米や、ネズミの食害、水分が抜けて軽くなった分だ。このように、帳簿の数量と実際の数量の差を**棚卸減耗**という。

::example 棚卸減耗を仕訳しなさい
酒米の帳簿の在庫は3,000kg（先入先出法の単価720円）、実地棚卸の数量は2,980kgだった。この減耗は毎年生じる程度の正常なものである。
::answer
::journal 20kg×720円＝14,400円
製造間接費 14,400 | 材料 14,400
::
毎年生じる程度の正常な棚卸減耗は、製造のために避けられない費用として**間接経費**になり、製造間接費に集める（製造間接費の配賦は第4章で学ぶ）。台風で倉庫が浸水したような異常な原因による減耗は、原価にせず非原価項目（特別損失など）とする。第1章で見た「ふつうに使ったものだけが原価」という原則と同じだ。
::
::

### 材料の種類と、行き先

酒米のほかにも、蔵ではさまざまな材料を使う。工業簿記では、材料を次のように分類する。

::table 材料費の分類（汐見酒造の例）
| 分類 | 内容 | 例 | 直接か間接か |
| 主要材料費 | 製品の本体になる材料 | 酒米・醸造用アルコール | 直接材料費 |
| 買入部品費 | 外部から買って、そのまま製品に取り付ける部品 | 瓶・王冠・化粧箱 | 直接材料費 |
| 補助材料費 | 製品の本体にはならないが、製造に使う材料 | ろ過助剤・ボイラーの燃料 | 間接材料費 |
| 工場消耗品費 | 製造で使う消耗品 | 洗剤・軍手・ホース | 間接材料費 |
| 消耗工具器具備品費 | 耐用年数1年未満か、金額の小さい工具 | 温度計・ひしゃく・小型の秤 | 間接材料費 |
::

::sort 次の材料費を、直接材料費と間接材料費に分けなさい。
@cats 直接材料費 | 間接材料費
大吟醸の仕込みに使った山田錦 => 直接材料費
純米吟醸用の720mL瓶 => 直接材料費
普通酒に添加した醸造用アルコール => 直接材料費
タンクの洗浄に使った洗剤 => 間接材料費
ろ過に使った活性炭 => 間接材料費
醪の温度を測る温度計（耐用年数1年未満） => 間接材料費
::

::exam 材料費の出題の急所
- **材料の購入原価に副費を入れる**：引取運賃・買入手数料は材料勘定へ。内部副費を予定配賦するときは「材料／材料副費」
- **消費単価**：先入先出法か平均法かは、必ず問題文で確かめる。移動平均法は受け入れのたびに単価が変わる
- **予定価格**：「仕掛品（直接）・製造間接費（間接）／材料」を予定価格で切り、差額を「材料消費価格差異／材料」（不利差異）または「材料／材料消費価格差異」（有利差異）で振り替える
- **差異の符号**：予定－実際がマイナスなら借方差異（不利）。差異の勘定が借方にあるか貸方にあるかで判断する
- **棚卸減耗**：正常なものは製造間接費（間接経費）。異常なものは非原価
::

## 夕方のニュース ― 令和の米騒動と、予定価格の防波堤

::scene 12月の第2火曜日、夜 ― 蔵の事務所
椎名が帰った後、事務所のテレビが、米の値段のニュースを流していた。2年前の夏に始まった米の高騰は、まだ落ち着いていなかった。
「専務、うちだけではありません」と岩倉が言った。「農水省の発表では、去年の秋の新米の卸値は、その前の年の1.6倍だったそうです。3年前の米と比べたら、倍を超えとります」
::

澪は、岩倉の言葉を、農林水産省が集計する相対取引価格（産地と卸売業者の間の取引価格、全銘柄平均・玄米60kg）で確かめた。2023年産米の年平均は**15,315円**、2024年産米は**25,179円**。2025年産米は、出回り始めの2025年10月に**37,058円**と、過去最高を記録していた。主食用の米の値段だが、酒造りに使う米もこの流れと無縁ではない。大手の白鶴酒造は2025年5月、原料米の高騰などを理由に、10月出荷分から約180品目の参考小売価格を5〜18%引き上げると発表していた。
「大手が値上げに踏み切ったのは、差異の勘定を見たからでしょうな」と岩倉は言った。
澪は、その「差異の勘定」を、自分の手で作ってみた。仮に、ある蔵が2024年の酒造年度の予定価格を、前年の相場の1俵（60kg）15,315円に置いたまま、2024年産の米を1俵25,179円で1,000俵（60トン）仕入れて使ったとする（2つの価格は実際の全銘柄平均、1,000俵は仕組みを示すための例）。

::journal ① 予定価格による消費：15,315円×1,000俵
仕掛品 15,315,000 | 材料 15,315,000
::
::journal ② 差異：15,315,000円－25,179,000円＝△9,864,000円
材料消費価格差異 9,864,000 | 材料 9,864,000
::

原価計算表の上では、この蔵の酒の原価は前の年と変わらない。だが、差異の勘定には986万円が貯まり、年度末には売上原価を押し上げる。原価計算表だけを見て値段を据え置けば、この986万円は丸ごと利益から消える。
「予定価格は、価格の嵐から原価計算表を守る防波堤ですね」と澪は言った。「でも、防波堤の外に積み上がっていく水の量を見なければ、気づいたときには蔵が沈んでいる」
岩倉は、汐見酒造の差異の勘定のT字を指でたたいた。「うちの防波堤の外にも、もう116万円、水が貯まっとります」

::note
出典：[秋田魁新報（共同通信）「9月の新米卸値が過去最高 前年1・6倍」（2025年10月21日、24年産米の年平均25,179円・23年産15,315円）](https://www.sakigake.jp/news/article/20251021CO0120/)、[秋田魁新報（共同通信）「コメ業者取引価格、3月最大下落」（2026年4月17日、2025年10月に過去最高の37,058円）](https://www.sakigake.jp/news/article/20260417CO0122/)、[LOGISTICS TODAY「白鶴酒造、物流費高騰などで最大18％値上げ」（2025年5月30日）](https://www.logi-today.com/784983)
::

::cfo 年末の値付け会議 ― 原価表は「変わっていない」と言っている
12月の最終週。来年4月からの出荷価格を決める会議で、営業担当が言った。「原価計算表を見ると、どの酒も原価は去年と同じです。取引先の居酒屋さんは、ほかの蔵が値上げするなら汐見さんは据え置いてくれと言っています。据え置けば、シェアを取れます」
澪の手元には、次の資料がある。仕込みは3月まで続き、高い米はこれからも毎月届く。
::table 判断の材料
| 項目 | 金額・数量 |
| 酒米の予定価格 | 1kg600円 |
| 11月の材料消費価格差異 | 116万円（不利） |
| 12月〜3月の差異の見込み | 毎月100万〜130万円（不利） |
| 1本あたりの玄米の使用量 | 普通酒0.13kg、純米吟醸0.43kg、大吟醸1.5kg |
| 実際の仕入れ値（見込みの平均） | 1kg約700円 |
::
まず、年度末までに貯まる差異の合計と、1本あたりの原価の実際の上昇額（使用量×実際との差100円）を計算してから選んでほしい。
::choice A. 原価計算表では原価が変わっていないので、全商品を据え置いてシェアを取る
**× 原価表の「変わらない」は、予定価格の効果にすぎない。**差異は11月の116万円に、12月〜3月の4か月分（400万〜520万円）が加わり、年度末には**約520万〜640万円**になる。これは売上原価に加算され、そのまま利益を削る。今期の営業利益の見込みは1,100万円。半分以上が消える計算だ。シェアを取る前に、蔵の体力がなくなる。
::
::choice B. 差異を1本あたりに換算し、上昇の大きい大吟醸と純米吟醸の値上げを優先する
**◎ 差異の中身を、製品ごとに読み解いている。**1kgあたり約100円の上昇を使用量に掛けると、1本あたりの原価の上昇は、普通酒13円、純米吟醸43円、大吟醸150円。普通酒の出荷価格600円に対して13円は約2%だが、大吟醸の150円は3,500円の約4%で、しかも第1章で見たとおり、大吟醸はもともと作業時間あたりの稼ぎが最も小さい酒だ。値上げの痛みを最も小さくしつつ、差異を回収できる。地元の居酒屋向けの普通酒は据え置いて、関係を守る道もある。
::
::choice C. 全商品を一律10%値上げする
**△ 回収はできるが、上げ幅が実際の上昇と合っていない。**普通酒の原価上昇は約2%なのに10%上げれば、地元の取引先に必要以上の負担をかけ、価格競争の激しい普通酒で客を失うおそれがある。一方、大吟醸は10%の値上げで350円となり、上昇分150円の2倍を超える。製品ごとの影響の違いを無視した値上げは、どこかで無理が出る。
::
::choice D. 値上げはせず、一般の安い米に切り替えて材料費を下げる
**× 品質と表示のルールを見落としている。**国税庁の「清酒の製法品質表示基準」では、吟醸酒や純米酒などの特定名称を表示する酒には、農産物検査法で3等以上に格付けされた玄米（またはこれに相当する玄米）を使う必要がある。条件を満たさない米に替えれば、「純米吟醸」「大吟醸」と表示できなくなるおそれがある。しかも、米の値上がりは酒米に限らない。
::
::answer 考え方の例を見る
予定価格で作った原価計算表は、「造り方」の良し悪しを見るのに向いている。だが、「いくらで売るか」を決めるには、差異を含めた実際の原価を見なければならない。差異を、原因（仕入れ値か、使った量か）と製品ごとの影響に分けて読むことが、値付けの出発点になる。
澪は、普通酒を据え置き、純米吟醸を50円、大吟醸を200円上げる案を出した。営業担当は渋い顔をしたが、杜氏の小松が一言だけ言った。「斗瓶取りは、200円上げても買う人は買う。安く売るほうが、酒に失礼だ」
::
::

::next 予定価格は「標準原価計算」への入り口
予定価格は、材料の単価だけを前もって決める方法だ。第9章の標準原価計算では、単価だけでなく、製品1本を作るのに使うべき材料の**量**も前もって決める。すると差異は、「値段の差（価格差異）」と「使った量の差（数量差異）」に分かれ、誰の責任で原価が上がったのかまで分かるようになる。1級では、さらに差異の原因を細かく分析する。
::

::summary
- 材料の購入原価は、購入代価に材料副費（外部副費＝引取費用、内部副費）を加えた額。内部副費は予定配賦し、実際との差は材料副費差異
- 材料費＝消費数量×消費単価。消費単価の計算には先入先出法・移動平均法・総平均法があり、方法によって「当月の消費額」と「月末の在庫」の分け方が変わる
- 予定価格で消費を記録すると、製品の原価から仕入れ値の変動を切り離せる。実際との差は材料消費価格差異（予定＜実際なら不利差異＝借方）
- 材料消費価格差異は、会計年度末に原則として売上原価に振り替える。原価表に出なくても、利益は確実に変わる
- 正常な棚卸減耗は製造間接費（間接経費）、異常なものは非原価
