11月30日、午後9時。帳場の石油ストーブの前で、澪は初めての月次の原価計算表を書き上げた。蔵の1か月を、数字で1枚にまとめた表だ。

陸：「なのに、この表の米は600円のまま。番頭さん、数字いじってません？」
帳場の空気が、凍った。岩倉が、ゆっくりと老眼鏡を外した。

澪は請求書と表を見比べた。今月使った米は1万3,000kg。1kgあたりの差を掛ければ、表に載っていない金額は、ざっと100万円を超える。
**値上がりした米の代金、116万円は、帳簿のどこへ消えたのか？**

## 運送会社の請求書 ― 材料の値段は、請求書の金額だけではない

翌朝、椎名に電話をすると、椎名は「まず、米1kgの値段を、正しく出してみてください」と言った。
澪：「請求書に書いてあります。11月5日に8,000kgを1kg680円、11月20日に6,000kgを1kg700円」
椎名：「その米は、蔵まで歩いてきましたか」
澪は、請求書の束をめくり直した。下に、運送会社の請求書が2枚あった。16万円と、12万円。
椎名：「米を蔵の倉庫に入れるまでにかかったお金は、全部、米の値段の一部です」

::point メモ ― 材料の購入原価と材料副費
材料の**購入原価**は、**購入代価**（請求書の代金）に、**材料副費**を加えたものだ。材料副費には、引取運賃・買入手数料・関税など、材料が届くまでに外部に払う**外部副費**（引取費用）と、検収・保管・整理など、届いてから社内でかかる**内部副費**がある。
::

::example 11月の酒米の購入
11月5日、酒米8,000kgを1kg680円で掛けで購入し、引取運賃160,000円は現金で支払った。11月20日にも、酒米6,000kgを1kg700円で掛けで購入し、引取運賃120,000円を現金で支払った。
::answer
::journal 11月5日　8,000kg×680円＋運賃160,000円
材料 5,600,000 | 買掛金 5,440,000
 | 現金 160,000
::
::journal 11月20日　6,000kg×700円＋運賃120,000円
材料 4,320,000 | 買掛金 4,200,000
 | 現金 120,000
::
引取運賃は、材料の購入原価に含める。1kgあたりにすると、11月5日の米は5,600,000円÷8,000kg＝700円、11月20日の米は4,320,000円÷6,000kg＝720円になる。
::trap
引取運賃を「発送費」や「支払運賃」として費用にしないこと。材料を手に入れるための運賃は材料の原価、製品を得意先に届ける運賃は販管費（発送費など）だ。どちらへ運ぶ運賃かで行き先が変わる。
::
::
::

澪：「請求書の680円じゃなくて、700円と720円……。米は、思っていたよりさらに高かったんですね」

## 3つの単価 ― 「いくらの米を使ったか」は、計算方法で変わる

::scene 12月1日、午前10時 ― 米蔵
米蔵には、10月に1kg600円で買った米の残りと、11月に届いた2回分の米が、袋の色を変えて積んである。陸がフォークリフトから降りてきた。
陸：「今月の仕込みで使ったのは、10日に6,000kg、25日に7,000kgっす。どの袋から使ったかは……正直、覚えてないっす」
澪：「600円の米と、700円の米と、720円の米。混ざって使ったら、使った米はいくら？」
::

材料を倉庫から出して使うことを**払い出し**（消費）という。消費した金額は「消費量×消費単価」で計算する。消費量は、出し入れのたびに材料元帳に記録して数える**継続記録法**が原則で、期末の棚卸から逆算する**棚卸計算法**は、記録しにくい安い材料に使う。
問題は単価だ。値段の違う米が混ざっているとき、どの値段で払い出したことにするか。

::table 酒米の受け払い（11月。月初の在庫は10月に1kg600円で買った残り）
| 日付 | 摘要 | 数量 | 単価 | 金額 |
| 11/1 | 月初の在庫 | 2,000kg | 600円 | 1,200,000円 |
| 11/5 | 受け入れ | 8,000kg | 700円 | 5,600,000円 |
| 11/10 | 払い出し（仕込み） | 6,000kg | ？ | ？ |
| 11/20 | 受け入れ | 6,000kg | 720円 | 4,320,000円 |
| 11/25 | 払い出し（仕込み） | 7,000kg | ？ | ？ |
::

::table 消費単価の計算方法
| 方法 | 考え方 | 11月の消費額 | 月末の在庫（3,000kg） |
| 先入先出法 | 先に受け入れたものから先に払い出したとみなす | 8,960,000円 | 2,160,000円 |
| 移動平均法 | 受け入れのたびに平均単価を計算し直す | 9,008,000円 | 2,112,000円 |
| 総平均法 | 1か月分の受け入れの合計で平均単価を1つ出す | 9,035,000円 | 2,085,000円 |
::

::example 3つの方法で、11月の消費額を計算する
上の受け払いの表をもとに、先入先出法・移動平均法・総平均法で、11月の酒米の消費額と月末の在庫を計算する。
::answer
**先入先出法**
- 11/10の6,000kg：月初2,000kg×600円＝1,200,000円と、11/5分の4,000kg×700円＝2,800,000円 → 4,000,000円
- 11/25の7,000kg：11/5分の残り4,000kg×700円＝2,800,000円と、11/20分の3,000kg×720円＝2,160,000円 → 4,960,000円
- 消費額 **8,960,000円**、月末の在庫 3,000kg×720円＝**2,160,000円**
**移動平均法**
- 11/5の受け入れ後：(1,200,000円＋5,600,000円)÷10,000kg＝680円。11/10の払い出し 6,000kg×680円＝4,080,000円
- 11/20の受け入れ後：(4,000kg×680円＋4,320,000円)÷10,000kg＝704円。11/25の払い出し 7,000kg×704円＝4,928,000円
- 消費額 **9,008,000円**、月末の在庫 3,000kg×704円＝**2,112,000円**
**総平均法**
- (1,200,000円＋5,600,000円＋4,320,000円)÷16,000kg＝695円
- 消費額 13,000kg×695円＝**9,035,000円**、月末の在庫 3,000kg×695円＝**2,085,000円**
どの方法でも、消費額＋月末の在庫＝11,120,000円になる。方法で変わるのは、その合計を「今月の原価」と「来月への在庫」にどう分けるかだけだ。
::trap
総平均法の平均単価は、月初の在庫と1か月の受け入れの**全部**を合わせて計算する。受け入れ分だけで平均しないこと。また、値上がりが続く月は、先入先出法は古い安い単価から使うので消費額が最も小さく、月末の在庫が最も大きくなる。
::
::
::

汐見酒造は、先入先出法を採っている。11月の酒米の実際の消費額は8,960,000円。1kgあたり約689円だ。
澪：「じゃあ、原価計算表にも8,960,000円と書けばいいはずです。なのに、表は600円×13,000kg＝7,800,000円になっている」
差は1,160,000円。陸の言う「消えたお金」は、この金額だった。

## 「米　予六百」 ― 番頭が600円にこだわった理由

その夜、澪は父の黒い手帳を開いた。読めなかった行の1つに、目が止まった。

::memo 黒い手帳の2行目
米　予六百
::

澪：「岩倉さん。この『予六百』って……」
岩倉：「7月、今期の始まりに、社長が決めた数字です。『今期の酒米は、1kg600円で計算しろ』と」
岩倉：「だから、わしは600円で表を作った。ごまかしたのではない。社長の決めた物差しを守っただけです」
帳場の奥で、陸が小さくなっていた。
陸：「……すみません」
翌週の月例訪問で、椎名はこの手帳の1行を見て、うなずいた。
椎名：「社長は、材料の**予定価格**を決めていたんです。今期の米は、いくらで買っても、原価計算の上では1kg600円とみなす」
澪：「実際は700円台なのに、どうしてわざと違う値段で？」
椎名：「理由は3つあります。1つ目は、月によって米の値段が上下しても、酒の原価が揺れないこと。2つ目は、請求書がそろうのを待たずに、仕込んだその日に原価が出せること」
椎名：「3つ目がいちばん大事です。予定と実際の差を、わざと別の場所に取り分けることで、『今月、米でいくら損をしたか』が1つの数字で見えるようになる」

::theory 予定価格で原価を測り、ずれは差異の勘定に取り分ける
材料の消費額は、**予定価格×実際の消費量**で仕掛品（直接材料費）や製造間接費（間接材料費）に入れる。実際の消費額との差は、**材料消費価格差異**という勘定に振り替える。
実際が予定より高ければ、原価を押し上げる**不利差異**（借方差異）、安ければ**有利差異**（貸方差異）だ。差異は消えるのではない。製品の原価表の外に取り分けられ、会計年度末に**売上原価**に加減されて、その期の利益に効いてくる。
::

::formula 材料消費価格差異
材料消費価格差異 ＝（予定価格 － 実際価格）× 実際消費量
::

マイナスなら不利差異（借方）、プラスなら有利差異（貸方）。「予定から実際を引く」順番で覚えておくと、符号で有利・不利が分かる。

::example 11月の酒米の消費を、予定価格で記録する
11月に仕込みに使った酒米13,000kgは、すべて直接材料である。予定価格は1kg600円。先入先出法による実際の消費額は8,960,000円だった。
::answer
::journal (1) 予定価格による消費：13,000kg×600円
仕掛品 7,800,000 | 材料 7,800,000
::
::journal (2) 差異の計上：7,800,000円－8,960,000円＝△1,160,000円（不利差異）
材料消費価格差異 1,160,000 | 材料 1,160,000
::
(1)で、製品の原価（仕掛品）には予定価格の7,800,000円だけが入る。(2)で、材料勘定から実際に出ていった額との差1,160,000円を、材料消費価格差異の借方に振り替える。これで材料勘定の残高は、月末の在庫の実際の金額2,160,000円と一致する。
::trap
予定価格で記録するのは**消費**のときだけだ。購入は、いつも実際の購入原価で記録する。差異の仕訳は、予定と実際の大小を見て借方・貸方を決める。実際のほうが高い（不利）なら、差異は借方。
::
::
::

::tgrid
::taccount 材料（酒米）
前月繰越 1,200,000 | 仕掛品 7,800,000
諸口 5,600,000 | 材料消費価格差異 1,160,000
諸口 4,320,000 | 次月繰越 2,160,000
= 11,120,000 | 11,120,000
::
::taccount 材料消費価格差異
材料 1,160,000 |
= 1,160,000 |
::
::

澪は、材料勘定の貸方を1行ずつたどった。仕掛品に7,800,000円、材料消費価格差異に1,160,000円、次月繰越に2,160,000円。合計11,120,000円で、借方の合計と1円も違わない。
月末の在庫2,160,000円は、3,000kg×720円で、実際の単価のまま正しく評価されている。消えたお金は、どこにもなかった。

::solve 116万円は、材料消費価格差異の借方で待っていた
原価計算表の酒米が1kg600円のままだったのは、計算の誤りでもごまかしでもない。父が7月に決めた**予定価格**で計算していたからだ。値上がりした分の1,160,000円は、材料消費価格差異の借方に取り分けられていた。
もし陸の疑いのとおり岩倉を責めていたら、蔵でいちばん帳面を知る人を失っていた。逆に、表の600円だけを見て「米の値上がりは原価に響いていない」と安心していたら、年度末に売上原価が膨らみ、7月の審査に出す利益が、知らないうちに削られていた。
**予定価格は原価を安定させる物差しであり、差異の勘定は、物差しと現実のずれを1か所に集めて見せる警報装置だ。**警報が鳴っていたのに、誰も聞いていなかった。
::

::journal 会計年度末：材料消費価格差異（借方残高）を売上原価に振り替える
売上原価 1,160,000 | 材料消費価格差異 1,160,000
::

岩倉は、差異の勘定のT字を長いこと見ていた。
岩倉：「わしは600円で計算して、それで終わりにしとりました。差額は、年に1度、決算のときに椎名先生の事務所で片づけてもらっとった」
澪：「これからは、毎月この勘定を見ましょう。差異が貯まり始めたら、それが合図です」
陸が、そっと岩倉の湯のみにお茶を注いだ。岩倉は、何も言わずにそれを飲んだ。

### 試験で狙われるパターン ― 内部副費・棚卸減耗・材料の分類

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 内部副費を予定配賦する**　検収・保管などの内部副費は、月末まで実際の額が分からない。そこで購入代価の何%という予定配賦率で材料の購入原価に加えておき、実際の額との差を**材料副費差異**とする。

::example 内部副費を購入代価の2%で予定配賦する
材料600,000円（購入代価）を掛けで購入した。内部副費は購入代価の2%を予定配賦している。月末に集計した内部副費（材料副費勘定に計上ずみ）の実際の発生額は13,000円だった。
::answer
::journal 購入時：購入代価＋予定配賦額 600,000円×2%＝12,000円
材料 612,000 | 買掛金 600,000
 | 材料副費 12,000
::
::journal 月末：予定12,000円－実際13,000円＝△1,000円（不利差異）
材料副費差異 1,000 | 材料副費 1,000
::
材料副費勘定の借方には実際の13,000円が集まり、貸方からは予定配賦の12,000円が材料へ出ていく。貸方が1,000円足りない分を、材料副費差異の借方に振り替える。
::trap
予定配賦額は、材料の購入原価に**含める**。差異の向きは材料消費価格差異と同じで、実際が予定より多ければ不利差異（借方）だ。
::
::
::

**② 帳簿の米と、倉庫の米が合わない（棚卸減耗）**　継続記録法なら、帳簿の在庫と実際の在庫を比べられる。少ない分が**棚卸減耗費**だ。毎年生じる程度の正常な減耗は、製造間接費（間接経費）とする。

::example 12月末、酒米の実地棚卸で20kg足りなかった
12月末、材料元帳の酒米の在庫は3,000kg（先入先出法の単価720円）、実地棚卸の数量は2,980kgだった。袋の破れなどで毎年生じる程度の、正常な減耗である。
::answer
::journal 20kg×720円＝14,400円。正常な減耗は製造間接費（間接経費）
製造間接費 14,400 | 材料 14,400
::
減耗した米は、どの酒の仕込みにも使われていないので、製品に直接たどれない。だから製造間接費に集めて、ほかの間接費と一緒に配賦する。
::trap
「棚卸減耗費／材料」として、棚卸減耗費の勘定を使う出題もある。その場合も、月末に「製造間接費／棚卸減耗費」と振り替えて、行き先は製造間接費になる。異常な減耗（火災や盗難など）は非原価項目だ。
::
::
::

**③ 材料の種類と、直接・間接**　材料は、どの製品にどれだけ使ったかを測れるかどうかで、直接材料費と間接材料費に分かれる。

::table 材料費の分類（汐見酒造の例）
| 種類 | 汐見酒造の例 | 主な行き先 |
| 主要材料費（素材費） | 酒米（山田錦・五百万石） | 直接材料費（仕掛品） |
| 買入部品費 | 瓶・ラベル・王冠を外から買って取り付ける | 直接材料費（仕掛品） |
| 補助材料費 | 醸造用の水処理剤、ろ過の助剤 | 間接材料費（製造間接費） |
| 工場消耗品費 | タンクの洗浄剤、軍手、ゴム手袋 | 間接材料費（製造間接費） |
| 消耗工具器具備品費 | 温度計、ひしゃく、仕込み用の櫂棒 | 間接材料費（製造間接費） |
::

::steps 解法の型 ― 材料費の問題
1. 購入原価を出す | 購入代価＋外部副費（引取運賃など）＋内部副費の予定配賦額
2. 消費量を確かめる | 直接材料と間接材料に分けておく
3. 消費単価を決める | 先入先出法・移動平均法・総平均法。予定価格の指示があればそれを使う
4. 差異を出す | （予定価格－実際価格）×実際消費量。マイナスは不利（借方）
5. 棚卸減耗を確かめる | 帳簿の数量－実地の数量。正常なら製造間接費
::

## 夕方のニュース ― 米の値段の乱高下と、来年の物差し

::scene 12月10日、夕方 ― 帳場のテレビ
地元局のニュースが、新米の値下がりを伝えていた。陸が、ストーブの前で腕を組んでいる。
陸：「うちの親父、言ってました。去年は主食用の米が高すぎて、酒米をやめる家が出た。だから今年の酒米は高い値段で決まった。なのに今年の秋は、主食用のほうがガクンと下がったって」
澪：「米の値段が、1年で上がって、下がって……」
岩倉：「予定価格を決めるのが、いちばん難しい年ですな」
::

澪は、陸の父の話を、農林水産省が公表している相対取引価格（産地と卸売業者の間の取引価格。全銘柄平均、玄米60kg＝1俵あたり）で確かめた。2023年産米の年平均は**15,315円**、2024年産米は**25,179円**。2025年産米は出回り始めの2025年10月に**37,058円**と過去最高をつけ、2026年6月には31,305円。そして2026年産米は、出回り始めの2026年9月に**21,293円**と、前年の同じ月から42%下がった。
酒米も、この流れと無縁ではない。2025年6月の報道では、主食用の米の値上がりにつられて酒米の値段も上がり、より高く売れる主食用の米へ作付けを替える農家も出ていた。
澪は、この乱高下を、この章の勘定で再現してみた。仮に、ある蔵が予定価格を前年の相場の1俵15,315円に置いたまま、1俵25,179円の米を1,000俵使ったとする（2つの価格は実際の全銘柄平均、1,000俵は仕組みを示すための例）。

::journal ① 予定価格による消費：15,315円×1,000俵
仕掛品 15,315,000 | 材料 15,315,000
::

::journal ② 差異：15,315,000円－25,179,000円＝△9,864,000円（不利差異）
材料消費価格差異 9,864,000 | 材料 9,864,000
::

原価計算表の上では、この蔵の酒の原価は前の年と変わらない。だが、差異の勘定には986万円が貯まり、年度末には売上原価を押し上げる。表だけを見て値段を据え置けば、986万円は丸ごと利益から消える。
逆も起きる。値上がりの最中に予定価格を高く置きすぎると、翌年に米が値下がりしたとき、今度は大きな**有利差異**が出る。原価計算表の酒は実際より高く見え、売れる値段で売る機会を逃すかもしれない。
澪：「予定価格は、高すぎても低すぎても、酒の本当の値段を隠すんだ」

::note
出典：[農林水産省「米の相対取引価格・数量（令和8年9月）」（2026年10月16日公表、2026年産米の全銘柄平均21,293円）](https://www.maff.go.jp/j/press/nousan/kikaku/261016.html)、[秋田魁新報（共同通信）「9月の新米卸値が過去最高 前年1・6倍」（2025年10月21日、24年産米の年平均25,179円・23年産15,315円）](https://www.sakigake.jp/news/article/20251021CO0120/)、[秋田魁新報（共同通信）「コメ業者取引価格、3月最大下落」（2026年4月17日、2025年10月に過去最高の37,058円）](https://www.sakigake.jp/news/article/20260417CO0122/)、[北海道新聞「酒米3割高で北海道内酒造業界が窮地」（2025年6月5日）](https://www.hokkaido-np.co.jp/article/1169004/)
::

大手の白鶴酒造も2025年5月、原料米の高騰などを理由に、10月出荷分から約180品目の参考小売価格を5〜18%上げると発表していた。米の値上がりは、どこかで値段に映さなければならない。問題は、どの酒の値段に、どれだけ映すかだった。
小松：「斗瓶取りは、上げても買う人は買う。安く売るほうが、酒に失礼だ」

::note
出典：[LOGISTICS TODAY「白鶴酒造、物流費高騰などで最大18％値上げ」（2025年5月30日）](https://www.logi-today.com/784983)

::danger 差異の勘定を見ない蔵は、値上げの時機を逃す
予定価格の原価計算表は、値上がりの最中でも数字が動かない。表だけを見ていると、値上げの判断が遅れ、年度末にまとめて利益が削られる。差異の勘定は、毎月、製品ごとの影響に読み替えて確かめる。
::

::cfo 116万円をどう取り戻すか ― 値上げを、どの酒に、どれだけ
12月、澪は営業の担当者と、来年の春からの出荷価格を相談した。米の値上がりを、どの酒の値段に、どれだけ映すか。
**前提**
- 酒米の予定価格は1kg600円、実際の仕入れ値は1kg約700円で、1kgあたり約100円高い
- 11月の材料消費価格差異は116万円（不利）。12月〜3月も、毎月100万〜130万円の不利差異が見込まれる
- 1本あたりの玄米の使用量は、普通酒0.13kg、純米吟醸0.43kg、大吟醸1.5kg
- 出荷価格は、普通酒600円、純米吟醸1,400円、大吟醸3,500円。年間の本数は45万本・15万本・3万本
- 普通酒は地元の居酒屋との値段の競争が厳しい。大吟醸は毎年すぐに売り切れる
- 2026年産の主食用の米は、9月に前年より42%値下がりした
::choice A. 原価計算表の原価は変わっていないので、値段は据え置く
**× 原価表の「変わらない」は、予定価格の効果にすぎない。**差異は年度末までに約520万〜640万円になり、売上原価に加わって利益を削る。表だけを見て据え置けば、そのまま審査の数字が細る。
::
::choice B. 全部の酒を一律に10%値上げして、差異をまとめて取り戻す
**△ 取り戻せるが、上げ幅が原価の上昇と合っていない。**普通酒の原価の上昇は1本13円（約2%）なのに60円上げれば、値段の競争が厳しい居酒屋の取引を失うおそれがある。大吟醸の350円の値上げは、上昇分150円の2倍を超える。
::
::choice C. 主食用の米が値下がりしたので、来年の酒米の値下がりを待って様子を見る
**△ 来年の話と、今年の差異を混ぜている。**酒米は秋に値段が決まっていて、今年の仕込みの原価はもう上がっている。主食用の米が下がっても、今年の116万円は戻らない。来年の予定価格を考えるときの材料にはなる。
::
::choice D. 普通酒は据え置き、純米吟醸を50円、大吟醸を200円上げる
**◎ 差異を、酒ごとの原価の上昇に読み替えている。**1本の原価の上昇は、普通酒13円、純米吟醸43円、大吟醸150円。上げ幅を上昇分に合わせつつ、競争の厳しい普通酒は据え置いて取引を守る。純米吟醸15万本×50円＋大吟醸3万本×200円で、年に1,350万円を取り戻せる。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「値上げするかどうか」ではなく、「米の値上がりで、どの酒の原価が1本いくら上がったか」を先に出す。
#### 手順2　前提の数字で確かめる
::table compact 1本あたりの原価の上昇（1kgあたり約100円の値上がり）
| 酒 | 玄米の使用量 | 原価の上昇 | 出荷価格に対する割合 |
| 普通酒 | 0.13kg | 13円 | 約2% |
| 純米吟醸 | 0.43kg | 43円 | 約3% |
| 大吟醸 | 1.5kg | 150円 | 約4% |
::
年間では、普通酒585万円、純米吟醸645万円、大吟醸450万円、合計1,680万円の原価が上がる。Dは、そのうち8割を、値上げに強い酒で取り戻す。
#### 手順3　ほかの答えに引かれる理由
Aは「原価計算表が変わっていない」という安心に、Bは一律という公平さに、Cは値下がりのニュースに引かれる。どれも、差異を製品ごとの数字に直していない。
#### 持ち帰る考え方
- **差異は、製品ごとに読み替える**：116万円という総額のままでは、どの値段を動かすか決められない
- **上げ幅は、原価の上昇と市場の強さで決める**：原価の上昇が小さく、競争の厳しい製品は据え置く道もある
#### 前提が変われば
普通酒の取引先が、ほかの蔵の値上げに合わせて値段の見直しを受け入れているなら、普通酒も13円程度は上げられる。そのときは、年585万円の原価の上昇も取り戻せる。
::
::

::exam 材料費の急所
- 購入原価＝購入代価＋材料副費。**引取運賃は材料の原価**、製品を送る運賃は販管費
- 先入先出法・移動平均法・総平均法の消費額＋月末の在庫は、どれも同じ合計になる
- 総平均法の平均単価は、**月初の在庫を含めて**計算する
- 予定価格で記録するのは消費だけ。差異＝（予定－実際）×実際消費量。マイナスは不利（借方）
- 正常な棚卸減耗は製造間接費。原価差異は年度末に売上原価へ（不利は加算、有利は減算）
::

::next 予定価格は、標準原価への入り口
1年の予定価格は、第9章の標準原価計算で「製品1本の材料はいくらであるべきか」という標準につながる。そこでは、差異をさらに「値段のずれ」と「使った量のずれ」に分け、誰の責任かまで見ていく。1級では、材料の購入の意思決定（経済的発注量など）も学ぶ。
::

::summary
- 材料の購入原価は、購入代価に材料副費（外部副費と内部副費）を加えた額
- 消費額は消費量×消費単価。単価は先入先出法・移動平均法・総平均法で計算する
- 予定価格を使うと、原価を安定させ、仕込んだ日に原価が出せる
- 予定価格と実際の差は材料消費価格差異に振り替え、年度末に売上原価に加減する
- 正常な棚卸減耗は製造間接費（間接経費）にする
::

::quiz
::problem 次の一連の取引を仕訳しなさい。
(1) 材料2,000kgを1kg500円で掛けで購入し、引取運賃30,000円を現金で支払った。
(2) 上記の材料のうち1,500kgを消費した。このうち1,200kgは直接材料、300kgは間接材料である。消費単価は予定価格510円を用いる。
(3) 材料の実際の消費単価は515円だった。予定価格との差額を材料消費価格差異に振り替える。
::answer
::journal (1) 購入原価：1,000,000円＋30,000円
材料 1,030,000 | 買掛金 1,000,000
 | 現金 30,000
::
::journal (2) 予定消費額：直接1,200kg×510円、間接300kg×510円
仕掛品 612,000 | 材料 765,000
製造間接費 153,000 |
::

::problem 次の資料から、当月の材料の消費額を計算しなさい。
月初の在庫 100kg（@200円）、5日 受け入れ 300kg（@220円）、12日 払い出し 250kg、20日 受け入れ 200kg（@230円）、28日 払い出し 200kg
先入先出法の消費額 [[99,500]] 円、総平均法の消費額 [[99,000]] 円
::answer
**先入先出法**：12日は100kg×200円＋150kg×220円＝53,000円、28日は150kg×220円＋50kg×230円＝44,500円、合計**99,500円**
**総平均法**：(20,000円＋66,000円＋46,000円)÷(100kg＋300kg＋200kg)＝132,000円÷600kg＝220円、450kg×220円＝**99,000円**
月末の在庫は、先入先出法なら150kg×230円＝34,500円、総平均法なら150kg×220円＝33,000円。消費額と月末の在庫を足すと、どちらも132,000円になる。
::
::
::problem 材料の予定価格は1kg300円、当月の実際の消費量は800kg、実際の消費額は236,000円だった。材料消費価格差異の金額と、有利・不利を答えなさい。
差異の金額 [[4,000]] 円、[[有利差異]]
<!-- choices: 不利差異 -->
::answer
予定消費額 800kg×300円＝240,000円、実際消費額236,000円。240,000円－236,000円＝＋4,000円で、実際のほうが安かったので**有利差異（貸方差異）**。仕訳は「材料 4,000／材料消費価格差異 4,000」で、差異の勘定は貸方に残る。年度末に「材料消費価格差異 4,000／売上原価 4,000」として売上原価から差し引く。
::
::
::problem 次の取引を仕訳しなさい。
(1) 材料の帳簿の数量は500kg、実地棚卸の数量は490kgだった。単価は400円で、減耗は正常な範囲のものである。
(2) 会計年度末に、材料消費価格差異の借方残高25,000円を売上原価に振り替えた。
::answer
::journal (1) 10kg×400円＝4,000円。正常な減耗は製造間接費
製造間接費 4,000 | 材料 4,000
::
::journal (2) 不利差異は売上原価に加算する
売上原価 25,000 | 材料消費価格差異 25,000
::
借方残高の差異は不利差異なので、売上原価を増やす。有利差異（貸方残高）なら、逆の仕訳で売上原価を減らす。
