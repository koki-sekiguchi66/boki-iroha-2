::mystery 寝かせるほど値打ちが上がるはずの古酒
5月28日、金曜日。決算前の棚卸の準備で、澪は蔵の奥の貯蔵庫に入った。ひんやりした空気の中、木箱が天井近くまで積まれている。2016年に父が仕込んだ大吟醸を、そのまま10年寝かせた**古酒**だ。帳簿には、1本3,000円、2,000本、**600万円**の製品として載っていた。
「古酒は寝かせるほど値打ちが上がる。社長は、10年物を1本1万円で売ると言うとられました」と岩倉は言った。
だが、宇佐美が品質管理部門に頼んだ抜き取り検査の結果は、思わしくなかった。保管庫の一角の温度が夏に上がっていたらしく、そこにあった460本は、香りが崩れて「老香（ひねか）」が強く出ていた。料理酒にしか使えない、と小松は言った。数え直すと、箱の破損で割れた瓶もあり、実際の本数は2,000本ではなく**1,960本**だった。
熟成で値打ちが上がる酒と、下がる酒。帳簿の600万円は、どちらでもない数字のまま10年が過ぎていた。
**寝かせるほど価値が上がるはずの古酒の、帳簿の価値を、なぜ下げなければならないのか？**
::

## 期末の在庫は、2つの理由で目減りする

決算で、帳簿の在庫の金額を、そのまま貸借対照表に載せてよいとは限らない。2つの点を確かめる必要がある。

::theory 棚卸減耗と評価替
- **数量が減っていないか**：帳簿の数量（帳簿棚卸数量）と、実際に数えた数量（実地棚卸数量）の差を**棚卸減耗**という。紛失・破損・蒸発などで生じる。金額は「減った数量×原価」で、**棚卸減耗損**（製品なら製品減耗損とすることもある）とする
- **価値が下がっていないか**：期末の**正味売却価額**（売れる見込みの価格から、売るためにかかる費用を引いた額）が原価より低ければ、正味売却価額まで帳簿の価額を切り下げる。差額を**商品評価損**（製品なら製品評価損）とする
評価損は「実地棚卸数量×(原価－正味売却価額)」で計算する。減耗した分は、すでに棚卸減耗損として処理しているので、二重に数えない。
::

::formula 正味売却価額
正味売却価額 ＝ 売価（見込み）－ 見積追加製造原価 － 見積販売直接経費
::

## 日本橋店の商品で、型を身につける

まずは、日本橋の直営店で売っている、仕入れた**商品**（作家ものの酒器）で、2級の決算整理の型を確かめよう。商品は三分法（仕入・売上・繰越商品）で記帳している。

::example 日本橋店の酒器について、決算整理仕訳をしなさい
期首商品棚卸高は800,000円。期末の帳簿棚卸数量は500個（原価@2,000円）、実地棚卸数量は480個、期末の正味売却価額は@1,800円である。棚卸減耗損と商品評価損は、売上原価に含める（仕入勘定に振り替える）。
::answer
::journal (1) 期首商品を仕入へ
仕入 800,000 | 繰越商品 800,000
::
::journal (2) 期末商品（帳簿棚卸高 500個×2,000円）を繰越商品へ
繰越商品 1,000,000 | 仕入 1,000,000
::
::journal (3) 棚卸減耗損：(500個－480個)×2,000円、商品評価損：480個×(2,000円－1,800円)
棚卸減耗損 40,000 | 繰越商品 136,000
商品評価損 96,000 |
::
::journal (4) 売上原価に含める
仕入 136,000 | 棚卸減耗損 40,000
 | 商品評価損 96,000
::
::table sum 帳簿の期末商品1,000,000円の内訳
| 部分 | 計算 | 金額（円） |
| 貸借対照表の商品 | 実地480個×正味売却価額1,800円 | 864,000 |
| 商品評価損 | 実地480個×(原価2,000円－1,800円) | 96,000 |
| 棚卸減耗損 | (帳簿500個－実地480個)×原価2,000円 | 40,000 |
|= 帳簿の期末商品 | 帳簿500個×原価2,000円 | 1,000,000 |
::
貸借対照表に載る商品は、実地数量×正味売却価額＝864,000円。帳簿の1,000,000円から、減耗40,000円と評価損96,000円が差し引かれた額だ。図では、横に数量、縦に単価をとり、外側の大きな長方形（帳簿数量×原価）から、右端の減耗の帯と、上の評価損の帯を切り取った内側が、貸借対照表の金額になる。
::
::

::table 棚卸減耗損と評価損の、損益計算書での表示
| 損失 | 原因 | 表示する区分 |
| 棚卸減耗損 | 毎年ふつうに生じる程度（原価性あり） | 売上原価の内訳、または販売費及び一般管理費 |
| 棚卸減耗損 | 異常な原因で生じた（原価性なし） | 営業外費用、または特別損失 |
| 商品評価損・製品評価損 | 品質の低下や市場価格の下落による収益性の低下 | 原則として売上原価の内訳 |
| 商品評価損・製品評価損 | 災害など、臨時の事象で生じた多額のもの | 特別損失 |
::

## 古酒の評価 ― 上がる分は上げず、下がる分だけ下げる

古酒の1,960本は、品質によって2つに分かれた。

::table 古酒の期末の評価の資料
| 区分 | 本数 | 原価 | 正味売却価額 | 根拠 |
| 状態のよい1,500本 | 1,500本 | @3,000円 | @4,000円 | 古酒の専門店が1本4,400円で買う。販売手数料@400円 |
| 老香の強い460本 | 460本 | @3,000円 | @500円 | 料理用の酒として1本550円。運賃@50円 |
| 箱の破損で割れた瓶 | 40本（帳簿2,000本－実地1,960本） | @3,000円 | ― | |
::

::example 古酒について、決算整理仕訳をしなさい（棚卸減耗損は毎年ふつうに生じる程度のもので、販売費及び一般管理費とする。製品評価損は売上原価に含める）
::answer
::journal (1) 割れた40本の棚卸減耗：40本×3,000円
棚卸減耗損 120,000 | 製品 120,000
::
::journal (2) 品質が低下した460本の評価損：460本×(3,000円－500円)
製品評価損 1,150,000 | 製品 1,150,000
::
状態のよい1,500本は、正味売却価額4,000円が原価3,000円を上回っているが、**帳簿の価額は上げない**。評価を切り下げるのは、正味売却価額が原価を下回るときだけだ。古酒の期末の帳簿価額は、1,500本×3,000円＋460本×500円＝**4,730,000円**になる。
::
::

::theory なぜ、下げるだけで上げないのか
在庫の価値が上がっても、それは売れるまで「まだ実現していない利益」だ。会計は、確実でない利益を先に計上しない。一方、価値が下がった在庫を原価のまま載せておけば、売ったときに一度に損失が出て、損失を出すべき期が先送りされる。
そこで、取得原価で記録したうえで、**収益性が下がったときだけ**、正味売却価額まで切り下げる。「将来の損失は早めに、将来の利益は実現してから」というのが、在庫の評価の考え方だ。
::

## 答え合わせ ― 600万円の古酒は、473万円だった

::solve 価値が上がる酒は原価のまま、下がる酒は正味売却価額まで下げる
帳簿の600万円の古酒は、決算で**473万円**に切り下げられた。差の127万円は、割れた40本の棚卸減耗損12万円と、老香の強い460本の製品評価損115万円だ。
状態のよい1,500本は、専門店に売れば1本4,000円が手元に残る。だが、その値上がりの分150万円（1,500本×1,000円）は、帳簿には載らない。売れたときに、初めて利益になる。
父の「1本1万円」は、帳簿の世界では、売れるまで存在しない数字だった。
::

岩倉は、木箱の伝票に「料理酒」と書かれた460本の札を貼りながら言った。「社長が聞いたら怒るでしょうな。10年も寝かせて、料理酒とは」
「怒る前に、一度だけ、この460本で何ができるか考えてみます」と澪は言った。

::exam 棚卸資産の期末評価の急所
- **棚卸減耗損＝(帳簿数量－実地数量)×原価**、**評価損＝実地数量×(原価－正味売却価額)**。評価損の数量は「実地」
- ボックス図を描く：横に数量（実地＋減耗）、縦に単価（正味売却価額＋差額）。外側から減耗と評価損を切り取る
- 正味売却価額が原価を**上回っていても**、評価を上げない
- 「売上原価に含める」指示があれば、「仕入／棚卸減耗損・商品評価損」で仕入勘定（または売上原価勘定）に振り替える
- 原価性のない減耗は営業外費用・特別損失、臨時で多額の評価損は特別損失。損益計算書の区分を問われたら、原因で判断する
- 品目ごとに評価する。値上がりした品目と値下がりした品目を合算して相殺しない
::

## 杜氏が覚えている夏 ― 1本3万円の獺祭が、1,200円で売られた

::scene 5月28日、夜 ― 貯蔵庫の前
老香の出た460本の札を貼り終えた後、小松は、貯蔵庫の前でしばらく黙っていた。
「温度を守れんかった酒は、悔しいもんだ」と小松は言った。「9年前の夏、山口の獺祭の蔵が豪雨で水に浸かってな。停電で、醪のタンクの温度が3日半も管理できんかった。どこの杜氏も、他人事とは思えんかったよ。だが、あの蔵は、その酒を捨てなかった」
::

2018年7月の西日本豪雨で、山口県岩国市の旭酒造は、蔵の浸水と停電の被害を受けた。報道によると、停電で、仕込み中の醪を入れたタンク150本の温度管理が3日半止まった。その酒は、蔵が定める「獺祭」の品質の基準に届かないおそれがあった。
同社は、その酒を、漫画「島耕作」シリーズの作者の協力を得て「**獺祭 島耕作**」という別の商品として売ることにした。8月2日に発表し、価格は1本**1,200円**均一。9月2日までに**58万本**が売れ、1本200円、合計**1億1,600万円**が被災した4県に寄付された。品質を等級ごとに分けてラベルを貼る時間がなかったため、通常なら3万2,400円で売られる最高級品「磨き その先へ」の原酒が入った瓶もあったと報じられ、ファンの間で「獺祭ガチャ」と呼ばれた。
澪は、この章で学んだ評価損の考え方で、その状況を帳簿に置き換えてみた。仮に、ある蔵の製品のうち1万本が、品質の基準に届かず、本来の商品名では売れなくなったとする。1本の原価は2,000円、別の商品として1本1,200円で売り、販売にかかる費用（運賃など）は1本100円と見込む（仕組みを示すための例）。

::journal ① 正味売却価額（1,200円－100円＝1,100円）まで切り下げる：1万本×(2,000円－1,100円)
災害損失 9,000,000 | 製品 9,000,000
::

収益性の低下による評価損は、ふつうは売上原価に含める。だが、豪雨のような臨時の災害で生じた多額の損失は、本業の原価と区別して、**特別損失**（災害損失など）とする。決算書を読む人は、「本業の原価が上がったのか」「災害という一度きりの出来事か」を区別して読める。
「帳簿の上では、900万円の損失ですね」と澪は言った。
「だが、あの蔵は、58万本を売り切って、1億円以上を被災地に届けた」と小松は言った。「酒の値打ちは、帳簿の原価じゃ決まらん。どう売るかで決まる」
澪は、460本の札を見た。料理酒、と書かれた札。小松の言葉は、そのまま、この460本への問いになっていた。

::note
出典：[Business Insider Japan「豪雨翌月、1本3万円の獺祭が1200円で売られた理由。ファンが狂喜乱舞した“獺祭ガチャ”は必然だった【後編】」（2018年10月27日）](https://www.businessinsider.jp/article/177006/)
::

::cfo 老香の古酒460本 ― どう売るか
460本の古酒について、3つの売り方が見つかった。小松は「混ぜものにするのは気が進まん」と言いながら、試作には付き合ってくれた。
::table 460本の売り方の比較
| 売り方 | 売価 | 追加でかかる費用（1本あたり） | 備考 |
| A 料理用の酒として、地元の料理店に売る | 550円 | 運賃50円 | すぐに売れる |
| B 若い純米酒とブレンドし、「蔵の古酒ブレンド」として売る | 1,500円 | ブレンドする純米酒と瓶詰め300円、販売手数料150円 | 小松の試作は好評 |
| C 原価の3,000円で売れるまで、売らずに待つ | ― | 保管の費用 | 老香はさらに強くなる見込み |
| D 決算の前に廃棄する | 0円 | 廃棄の費用10円 | |
::
まず、それぞれの売り方で、1本あたりいくら手元に残るか（正味売却価額）を計算してから選んでほしい。
::choice A. 料理用の酒として売る。すぐに現金になる
**○ 確実だが、最善ではない。**1本あたりの手元に残る額は550円－50円＝500円、460本で23万円。評価損は(3,000円－500円)×460本＝115万円。手間がかからず確実だが、B案よりも手元に残るお金が少ない。
::
::choice B. ブレンドして、新しい商品として売る
**◎ 正味売却価額が最も高い。**1本あたりの手元に残る額は1,500円－300円－150円＝**1,050円**、460本で48万3,000円。A案より25万3,000円多い。
この売り方を決めて、実行が確実なら、期末の正味売却価額は1,050円になり、評価損は(3,000円－1,050円)×460本＝**89万7,000円**で済む。在庫の価値は、品物そのものだけでなく、どう売るかで決まる。
::
::choice C. 原価の3,000円で売れるまで待つ。評価損を出さずに済む
**× 待っても評価損は避けられず、価値はさらに下がる。**老香の強い酒を3,000円で買う人はいない。期末の正味売却価額が原価を下回っている以上、評価損は決算で計上しなければならない。「売らなければ損は出ない」は、在庫の評価では通用しない。しかも、保管の費用がかかり、品質はさらに落ちる。
::
::choice D. 決算の前に廃棄して、損失をすっきりさせる
**× 価値のある在庫を捨てている。**廃棄すると、460本×3,000円＝138万円が全額損失になり、さらに廃棄の費用がかかる。料理用でも1本500円、ブレンドなら1,050円の価値があるのに、それを0にしてしまう。損失を早く片づけたい気持ちは分かるが、在庫は損失の数字ではなく、お金に変えるべき資産だ。
::
::answer 考え方の例を見る
在庫の評価は、帳簿の原価ではなく、「売ったら手元にいくら残るか」（正味売却価額）で考える。そして、どう売るかを工夫すれば、正味売却価額そのものを上げられる。評価損は、帳簿の数字を現実に合わせる手続きであり、在庫をあきらめる宣言ではない。
「蔵の古酒ブレンド」は、日本橋店で1本1,500円で売り出され、3か月で完売した。小松は、ブレンドの割合を誰にも教えなかった。
::
::

::next 棚卸資産の評価の先にある論点
1級では、評価損を翌期に戻し入れる**洗替法**と戻し入れない**切放法**、売価還元法による在庫の評価、在庫の評価方法の変更などを学ぶ。また、第10章で見たように、在庫の金額は利益に直結する。在庫の評価の見積りは、粉飾の手口になりやすい場所の1つでもある。
::

## 確認問題

::quiz
::problem 次の資料から、棚卸減耗損と商品評価損、貸借対照表に表示する商品の金額を求めなさい。
期末の帳簿棚卸数量 300個、実地棚卸数量 290個、原価@1,000円、正味売却価額@900円
棚卸減耗損 [[10,000]] 円、商品評価損 [[29,000]] 円、貸借対照表の商品 [[261,000]] 円
::answer
棚卸減耗損＝(300個－290個)×1,000円＝**10,000円**。商品評価損＝290個×(1,000円－900円)＝**29,000円**。貸借対照表の商品＝290個×900円＝**261,000円**。

::problem 決算整理仕訳をしなさい。期首商品 150,000円、期末商品の帳簿棚卸高 200,000円（200個×@1,000円）、実地棚卸数量 195個、正味売却価額 @950円。売上原価は仕入勘定で計算し、棚卸減耗損と商品評価損は売上原価に含める。
::answer
::journal 期首商品と期末商品の振替え
仕入 150,000 | 繰越商品 150,000
繰越商品 200,000 | 仕入 200,000
::
::journal 棚卸減耗損 5個×1,000円、商品評価損 195個×50円
棚卸減耗損 5,000 | 繰越商品 14,750
商品評価損 9,750 |
::
::journal 売上原価に含める
仕入 14,750 | 棚卸減耗損 5,000
 | 商品評価損 9,750

::problem 製品Aの期末の原価は@2,000円、見込み売価は@2,300円、見積販売直接経費は@200円である。製品Bの原価は@1,500円、見込み売価は@1,400円、見積販売直接経費は@100円である。実地数量はA 100個、B 50個。製品評価損の合計を求めなさい。
製品評価損 [[10,000]] 円
::answer
正味売却価額：A 2,300円－200円＝2,100円（原価2,000円を上回るので評価損なし）、B 1,400円－100円＝1,300円（原価1,500円を下回る）。評価損＝50個×(1,500円－1,300円)＝**10,000円**。Aの値上がりの分（100個×100円）と相殺してはいけない。

::summary
- 期末の在庫は、数量の減少（棚卸減耗損＝減った数量×原価）と、価値の低下（評価損＝実地数量×(原価－正味売却価額)）の2つを確かめる
- 正味売却価額＝見込み売価－見積追加製造原価－見積販売直接経費。原価より高くても、帳簿の価額は上げない
- 原価性のある減耗と、収益性の低下による評価損は、原則として売上原価（減耗は販管費も可）。異常な減耗は営業外費用・特別損失、災害などの臨時で多額の評価損は特別損失
- 品目ごとに評価し、値上がり分と値下がり分を相殺しない
- 在庫の価値は、売り方で変わる。評価損は在庫をあきらめることではなく、帳簿を現実に合わせること
::
