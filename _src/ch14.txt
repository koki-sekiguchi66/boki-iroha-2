::mystery 棚のいちばん奥
5月28日、金曜日、午後4時。決算を1か月後に控えて、蔵じゅうの在庫を数える棚卸しが始まった。
貯蔵庫のいちばん奥、裸電球の下に、ほこりをかぶった木箱が積まれていた。父が10年前に仕込み、熟成させてきた純米の古酒だ。帳簿には毎年、同じ数字が書かれている。**2,000本、1本3,000円、合わせて600万円**。
陸と2人で数えると、1,960本しかなかった。
陸：「40本足りないっす。でも、これ数え間違いじゃないっすか。暗いし、箱も古いし」
岩倉：「去年も一昨年も、2,000本と書きました。わしは数えとりませんが……」
小松が、1本の栓を抜いた。香りを嗅いで、黙って顔をしかめた。もう1本、また1本。棚の手前の箱から順に開けていき、小松は低い声で言った。
小松：「……老香（ひねか）だ。460本は、もう売り物にならねえ」
審査まで、あと45日。6月30日の貸借対照表に、この古酒をいくらで載せればいいのか。
**帳簿の2,000本・600万円は、本当にそこにあるのか。あるとしたら、いくらの値打ちなのか？**
::

## 帳簿の2,000本と、棚の1,960本 ― 棚卸減耗損

翌朝、澪は懐中電灯を持って、陸ともう一度数えた。やはり1,960本。足りない40本は、底の抜けた木箱の下で見つかった。割れた瓶の破片と、乾いた酒のしみが残っていた。
澪：「何年も前に、箱が壊れて割れていたんだ。誰も数えていなかったから、帳簿だけが2,000本のまま」

::point メモ ― 帳簿棚卸と実地棚卸
帳簿の記録から計算した期末の数量を**帳簿棚卸数量**、実際に数えた数量を**実地棚卸数量**という。紛失・破損・蒸発などで、実地の数量が帳簿より少ないとき、その差に原価を掛けた額が**棚卸減耗損**（棚卸減耗費）だ。
::

::example 古酒の棚卸減耗を記録する
古酒（製品）の帳簿棚卸数量は2,000本、実地棚卸数量は1,960本で、1本の原価は3,000円である。差の40本は、木箱の破損で割れたものだった。
::answer
::journal 40本×3,000円
棚卸減耗損 120,000 | 製品 120,000
::
減耗した40本は、もう存在しない。帳簿の製品を、その原価の分だけ減らす。
::trap
棚卸減耗損は、**原価**×減った数量で計算する。売価や正味売却価額を掛けないこと。また、評価損と一緒に出る問題では、先に減耗損を計算し、評価損は**実地**の数量に掛ける。
::
::
::

## 老香の460本 ― 正味売却価額と評価損

小松が開けた箱には、ひとつの傾向があった。老香が出ていたのは、貯蔵庫の入口に近い、夏に温度が上がりやすい棚の酒だった。奥の1,500本は、とろりとした琥珀色の、いい古酒に育っていた。
澪は、古酒の専門店と、地元の料理店に問い合わせた。

::table 古酒の期末の評価の資料
| 区分 | 本数 | 原価 | 売れる値段と、売るための費用 |
| 状態のよい古酒 | 1,500本 | @3,000円 | 古酒の専門店が1本4,400円で買う。販売手数料@400円 |
| 老香の強い古酒 | 460本 | @3,000円 | 料理用の酒として1本550円。運賃@50円 |
| 割れて失われた分 | 40本 | @3,000円 | ― |
::

椎名：「在庫は、原価で帳簿に載せるのが原則です。でも、売れる値段が原価を下回ったら、話が変わります」
売れる見込みの値段から、売るためにかかる費用を引いた額を**正味売却価額**という。期末に、正味売却価額が原価を下回っていたら、帳簿の価額を正味売却価額まで切り下げる。その差額が**商品評価損**（製品なら**製品評価損**）だ。

::formula 正味売却価額と評価損
正味売却価額 ＝ 売価（見込み）－ 見積販売直接経費
評価損 ＝（原価 － 正味売却価額）× 実地棚卸数量
::

::theory 在庫は原価で記録し、値打ちが下がったら切り下げる。上がっても切り上げない
期末の在庫は、原則として取得原価で評価する。ただし、品質の低下や市場の値下がりで、正味売却価額が原価を下回ったときは、その分だけ収益性が下がっているので、帳簿の価額を正味売却価額まで切り下げ、差額を評価損とする。
逆に、正味売却価額が原価を上回っても、帳簿の価額は上げない。まだ売れていない儲けを、利益にしないためだ。
::

::example 老香の460本の評価損を記録する
老香の強い460本は、料理用の酒として1本550円で売れる見込みで、運賃が1本50円かかる。原価は1本3,000円。状態のよい1,500本の正味売却価額は1本4,000円である。
::answer
正味売却価額＝550円－50円＝500円。評価損＝(3,000円－500円)×460本＝1,150,000円。
::journal 品質が低下した460本の評価損
製品評価損 1,150,000 | 製品 1,150,000
::
状態のよい1,500本は、正味売却価額4,000円が原価3,000円を上回っているが、**帳簿の価額は上げない**。古酒の期末の帳簿価額は、1,500本×3,000円＋460本×500円＝**4,730,000円**になる。
::trap
評価損は、正味売却価額が原価を下回った品物にだけ計上する。全部の在庫の正味売却価額を合計して比べないこと。品物ごとに比べる。
::
::
::

澪は、帳簿の600万円を、3つに分けた。

::table sum 帳簿の古酒6,000,000円の内訳
| 部分 | 計算 | 金額（円） |
| 貸借対照表の製品（状態のよい古酒） | 1,500本×原価3,000円 | 4,500,000 |
| 貸借対照表の製品（老香の古酒） | 460本×正味売却価額500円 | 230,000 |
| 製品評価損 | 460本×(3,000円－500円) | 1,150,000 |
| 棚卸減耗損 | 40本×3,000円 | 120,000 |
|= 帳簿の古酒 | 2,000本×3,000円 | 6,000,000 |
::

::solve 帳簿の600万円のうち、本当にあったのは473万円だった
帳簿の古酒2,000本・600万円のうち、40本（12万円）は何年も前に割れて、もう存在しなかった。残る1,960本のうち460本は老香で、売れる値段は1本500円しかない。帳簿の価額を切り下げると、評価損は115万円。6月30日の貸借対照表に載せられる古酒は、**473万円**だった。
もし陸の言うとおり「数え間違い」として600万円のまま載せていたら、審査に出す貸借対照表の資産は、127万円も実態より大きく見えていた。それが後で分かれば、ほかの資産の数字まで疑われる。
**帳簿の在庫は、数えて、味を見て、売れる値段を確かめて、初めて本当の数字になる。**
::

岩倉は、去年までの帳面の「古酒　2,000本」の行を、しばらく指でなぞっていた。
岩倉：「数えもせんで、毎年同じ数を書いとりました。社長の大事な酒だから、触らんほうがいいと思って」
澪：「父の酒だから、ちゃんと数えるべきだったんです。私も、今日まで来なかった」

## 日本橋店の酒器 ― 三分法の決算整理

棚卸しは、日本橋の直営店でも行われた。店では、蔵の酒のほかに、仕入れた酒器（ぐい呑みや片口）を商品として売っている。商品の会計は3級で学んだ**三分法**（仕入・売上・繰越商品）で記録している。

::example 日本橋店の酒器の決算整理
期首の商品棚卸高は800,000円だった。期末の帳簿棚卸数量は500個（原価@2,000円）、実地棚卸数量は480個、正味売却価額は@1,800円である。棚卸減耗損と商品評価損は、売上原価に含める。
::answer
::journal (1) 期首商品を仕入へ
仕入 800,000 | 繰越商品 800,000
::
::journal (2) 期末商品（帳簿棚卸高500個×2,000円）を繰越商品へ
繰越商品 1,000,000 | 仕入 1,000,000
::
::journal (3) 棚卸減耗損：(500個－480個)×2,000円、商品評価損：480個×(2,000円－1,800円)
棚卸減耗損 40,000 | 繰越商品 136,000
商品評価損 96,000 |
::
::journal (4) 売上原価に含める
仕入 136,000 | 棚卸減耗損 40,000
 | 商品評価損 96,000
::
(2)では、まず帳簿の数量で期末の商品を計上する。そのうえで(3)で、減った分と値打ちの下がった分を繰越商品から差し引く。貸借対照表の商品は、480個×1,800円＝864,000円になる。
::trap
(2)で実地の数量を使うと、棚卸減耗損が二重に引かれる。期末の商品は、まず**帳簿**の数量×原価で計上し、減耗と評価損は別に計算する。図にすると、横に数量（実地・帳簿）、縦に単価（正味売却価額・原価）をとった長方形になる。
::
::
::

::point メモ ― 三分法の月次処理と、払出単価の計算
月次で損益を計算する会社は、月末ごとに「仕入／繰越商品」「繰越商品／仕入」の振替えを行う。月末の商品の単価は、商品有高帳で計算する。払い出すたびに計算する先入先出法・移動平均法のほか、1か月分をまとめて平均する**総平均法**も使える（第2章の材料と同じ計算）。販売のつど売上原価勘定に振り替える方法（売上原価対立法）は、2027年度からの区分表で3級に移ったが、2級でも前提の知識として使う。
::

### 試験で狙われるパターン ― 表示の区分・原価性・評価の図

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 損益計算書のどこに載せるか**　棚卸減耗損と評価損は、原因によって表示する区分が変わる。

::table 棚卸減耗損と評価損の、損益計算書での表示
| 損失 | 原因 | 表示する区分 |
| 棚卸減耗損 | 毎年ふつうに生じる程度（原価性あり） | 売上原価の内訳、または販売費及び一般管理費 |
| 棚卸減耗損 | 異常な原因で生じた（原価性なし） | 営業外費用、または特別損失 |
| 商品評価損・製品評価損 | 品質の低下や市場価格の下落による収益性の低下 | 原則として売上原価の内訳 |
| 商品評価損・製品評価損 | 災害など、臨時の事象で生じた多額のもの | 特別損失 |
::

**② 原価性の判断**　問題文に「棚卸減耗損のうち○個分は原価性がない」とあれば、その分だけ営業外費用（または特別損失）にする。

**③ 評価の図を描く**　期末の商品の問題は、横軸に数量（実地・帳簿）、縦軸に単価（正味売却価額・原価）をとった図を描くと、貸借対照表の価額・評価損・減耗損が一目で分かる。

::steps 解法の型 ― 期末の商品・製品の評価
1. 帳簿の期末棚卸高 | 帳簿数量×原価。三分法ならこの額で「繰越商品／仕入」
2. 棚卸減耗損 | （帳簿数量－実地数量）×原価
3. 評価損 | （原価－正味売却価額）×実地数量。正味売却価額は売価－見積販売直接経費
4. 貸借対照表の価額 | 実地数量×正味売却価額（正味売却価額が原価以上なら原価）
5. 表示 | 原価性のある減耗と通常の評価損は売上原価へ。異常・臨時のものは営業外費用・特別損失
::

## 杜氏が覚えている夏 ― 1本3万円の獺祭が、1,200円で売られた

::scene 5月28日、夜 ― 貯蔵庫の前
老香の出た460本の札を貼り終えたあと、小松は、貯蔵庫の前でしばらく黙っていた。
小松：「温度を守れなかった酒は、悔しいもんだ。9年前の夏、山口の獺祭の蔵が豪雨で水に浸かってな。停電で、醪のタンクの温度が3日半も見られなかった」
小松：「どこの杜氏も、人ごととは思えなかったよ。だが、あの蔵は、その酒を捨てなかった」
::

2018年7月の西日本豪雨で、山口県岩国市の旭酒造は、蔵の浸水と停電の被害を受けた。報道によると、停電で、仕込み中の醪を入れたタンク150本の温度管理が3日半止まった。その酒は、蔵が定める「獺祭」の品質の基準に届かないおそれがあった。
同社は、その酒を、漫画「島耕作」シリーズの作者の協力を得て「**獺祭 島耕作**」という別の商品として売ることにした。価格は1本**1,200円**均一。9月2日までに**58万本**が売れ、1本200円、合計**1億1,600万円**が被災した4県に寄付された。等級ごとに分けてラベルを貼る時間がなかったため、通常なら1本3万円を超える最高級品の原酒が入った瓶もあったと報じられ、ファンの間で「獺祭ガチャ」と呼ばれた。
澪は、この章の評価損の考え方で、その状況を帳簿に置き換えてみた。仮に、ある蔵の製品のうち1万本が品質の基準に届かず、本来の商品名では売れなくなったとする。1本の原価は2,000円、別の商品として1本1,200円で売り、売るための費用は1本100円と見込む（仕組みを示すための例）。

::journal 正味売却価額（1,200円－100円＝1,100円）まで切り下げる：1万本×(2,000円－1,100円)
災害損失 9,000,000 | 製品 9,000,000
::

収益性の低下による評価損は、ふつうは売上原価に含める。だが、豪雨のような臨時の災害で生じた多額の損失は、本業の原価と区別して、**特別損失**（災害損失など）とする。決算書を読む人は、本業の原価が上がったのか、一度きりの出来事なのかを、区別して読める。
澪：「帳簿の上では、900万円の損失ですね」
小松：「だが、あの蔵は、58万本を売り切って、1億円以上を被災地に届けた。酒の値打ちは、帳簿の原価じゃ決まらねえ。どう売るかで決まる」

::note
出典：[Business Insider Japan「豪雨翌月、1本3万円の獺祭が1200円で売られた理由。ファンが狂喜乱舞した“獺祭ガチャ”は必然だった【後編】」（2018年10月27日）](https://www.businessinsider.jp/article/177006/)
::

::danger 在庫を数えない会社は、資産を水増ししている
棚卸しを省いて帳簿の数量のまま決算をすると、失われた在庫や値打ちの下がった在庫が、資産として残り続ける。意図的に在庫を多く数えれば、売上原価が減り、利益を水増しできる。決算の前の実地棚卸と、売れる値段の確認は、決算書の信頼の土台だ。
::

::cfo 老香の460本 ― どう売るか
小松は、老香の460本を若い純米酒とブレンドしてみた。試飲した宇佐美が「これ、売れますよ」と言った。澪は、4つの売り方を比べた。
**前提**
- 原価は1本3,000円。料理用の酒としてなら、1本550円ですぐに売れる（運賃50円）
- 若い純米酒とブレンドして「蔵の古酒ブレンド」として売れば、1本1,500円で売れる見込み。ブレンドに使う純米酒と瓶詰めに1本300円、販売手数料に1本150円かかる
- 原価の3,000円で売れるまで待つ案もあるが、老香はさらに強くなる見込み
- 廃棄すれば、1本10円の費用がかかる
- 古酒の専門店は、状態のよい1,500本を1本4,400円で買うと言っている
::choice A. 若い純米酒とブレンドし、「蔵の古酒ブレンド」として1本1,500円で売る
**◎ 正味売却価額が最も高い売り方を選んでいる。**1,500円－300円－150円＝1,050円が手元に残る。料理用の500円の2倍以上だ。正味売却価額が1,050円なら、評価損は(3,000円－1,050円)×460本＝89万7,000円に縮む。
::
::choice B. 料理用の酒として、地元の料理店に1本550円で売る
**○ 確実だが、取れるお金を取り残している。**正味売却価額は500円で、評価損115万円。すぐに現金になる点はよいが、ブレンドなら1本あたり550円多く手元に残る。
::
::choice C. 原価の3,000円で売れるまで、売らずに待つ
**× 待つほど値打ちが下がる。**老香はさらに強くなる見込みで、評価損は避けられない。在庫として抱えるほど、保管の費用もかかる。
::
::choice D. 決算の前に廃棄して、在庫をきれいにする
**× 売れる酒を、お金を払って捨てている。**廃棄すれば手元に残るのは－10円で、損失は3,010円×460本＝約138万円と、最も大きい。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「いくらで売れるか」ではなく、「売るための費用を引いて、1本あたりいくら手元に残るか（正味売却価額）」で比べる。
#### 手順2　前提の数字で確かめる
::table compact 460本の売り方の比較
| 売り方 | 1本あたり手元に残る額 | 評価損 |
| A ブレンドして1,500円 | 1,050円 | 89万7,000円 |
| B 料理用に550円 | 500円 | 115万円 |
| C 売らずに待つ | 下がり続ける | 避けられない |
| D 廃棄 | △10円 | 約138万円 |
::
#### 手順3　ほかの答えに引かれる理由
Bは「すぐ現金になる」安心に、Cは「原価割れで売りたくない」気持ちに、Dは「在庫をきれいにしたい」気持ちに引かれる。状態のよい1,500本の買取りの話は、老香の460本の判断には関係のない前提だ。
#### 持ち帰る考え方
- **正味売却価額は、売り方しだいで変わる**：売価から売るための費用を引いた額で比べる
- **原価はもう戻らない**：3,000円は、どの売り方を選んでも変わらない過去の数字だ
#### 前提が変われば
ブレンドに使う純米酒が足りず、ブレンドに回すと看板の純米酒の出荷が減るなら、その分の儲けも「ブレンドの費用」に入れて比べる。そのときは、料理用に売るほうがよい場合もある。
::
::

::exam 商品・製品の評価の急所
- 棚卸減耗損＝（帳簿数量－実地数量）×**原価**
- 評価損＝（原価－正味売却価額）×**実地数量**。正味売却価額＝売価－見積販売直接経費
- 正味売却価額が原価を上回っても、帳簿の価額は上げない
- 三分法の決算整理：期末の商品はまず**帳簿数量×原価**で計上し、減耗損と評価損を差し引く
- 表示：原価性のある減耗と通常の評価損は売上原価、異常・臨時のものは営業外費用か特別損失
::

::next 在庫の評価は、会社の利益を左右する
1級では、評価損を翌期に戻し入れる洗替法と戻さない切放法の違い、売価還元法など、在庫の評価のさまざまな方法を学ぶ。在庫の水増しは、粉飾の典型的な手口でもある。決算書を読むときは、売上が伸びていないのに在庫だけが増えていないかを確かめる。
::

::summary
- 帳簿の数量と実地の数量の差に原価を掛けた額が棚卸減耗損
- 正味売却価額（売価－見積販売直接経費）が原価を下回ったら、その差に実地数量を掛けた額を評価損とする
- 正味売却価額が原価を上回っても、帳簿の価額は上げない
- 三分法では、期末の商品を帳簿数量×原価で計上してから、減耗損と評価損を差し引く
- 原価性のある減耗と通常の評価損は売上原価、異常・臨時のものは営業外費用・特別損失に表示する
::

## 確認問題

::quiz
::problem 次の資料から、決算整理仕訳をしなさい。棚卸減耗損と商品評価損は、売上原価に含める。
期首商品棚卸高 150,000円、期末の帳簿棚卸数量 200個（原価@1,000円）、実地棚卸数量 195個、正味売却価額 @950円
::answer
::journal 期首商品と期末商品の振替え
仕入 150,000 | 繰越商品 150,000
繰越商品 200,000 | 仕入 200,000
::
::journal 棚卸減耗損 5個×1,000円、商品評価損 195個×50円
棚卸減耗損 5,000 | 繰越商品 14,750
商品評価損 9,750 |
::
::journal 売上原価に含める
仕入 14,750 | 棚卸減耗損 5,000
 | 商品評価損 9,750
::
評価損は、実地の195個に（1,000円－950円）を掛ける。帳簿の200個に掛けないこと。
::
::
::problem 製品Aの期末の原価は@2,000円、見込み売価は@2,300円、見積販売直接経費は@200円である。製品Bの原価は@1,500円、見込み売価は@1,400円、見積販売直接経費は@100円である。実地数量はA 100個、B 50個。製品評価損の合計を求めなさい。
製品評価損 [[10,000]] 円
::answer
製品Aの正味売却価額は2,300円－200円＝2,100円で、原価2,000円を上回るので評価損はない。製品Bの正味売却価額は1,400円－100円＝1,300円で、評価損は(1,500円－1,300円)×50個＝**10,000円**。品物ごとに比べ、合計どうしを比べないこと。
::
::
::problem 次の棚卸減耗損と評価損を、損益計算書の表示区分に分けなさい。
::sort
@cats 売上原価 | 営業外費用 | 特別損失
毎年ふつうに生じる程度の棚卸減耗損 => 売上原価
品質の低下による商品評価損 => 売上原価
原因不明の大量の紛失による棚卸減耗損 => 営業外費用
大地震で生じた多額の製品評価損 => 特別損失
::
::answer
原価性のある減耗と、通常の収益性の低下による評価損は売上原価。異常な原因の減耗は営業外費用（または特別損失）、災害など臨時の多額の評価損は特別損失。
::
