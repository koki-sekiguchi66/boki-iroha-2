::mystery 醪は0円か、完成品と同じ値段か
2月26日、金曜日。越後みなと信用金庫の高梨から電話があった。「来月から、毎月の試算表を出してください。造りの最中の蔵は、在庫が大きく動きますから」
試算表を作り始めた澪は、普通酒のタンクの前で立ち止まった。2月末の時点で、3本のタンクの中で、合わせて**30キロリットル**の醪が発酵している。搾るのは3月の半ばだ。
「番頭さん、この醪は、試算表にいくらで載せればいいでしょう」
「まだ酒になっとらんのだから、0円でしょう。売れんのですから」
澪は首を振った。酒米を使い、蔵人が仕込み、ボイラーで米を蒸した。お金はもう使っている。では、完成した原酒と同じ値段か。だが、まだ発酵の途中で、これから搾る手間もかかる。
**タンクの中で発酵している途中の醪に、いくらの値段をつけるのか？**
そしてもう1つ。2月に完成した原酒は88キロリットル。仕込んだ量と月末の醪を合わせても、**2キロリットル足りない**。消えた酒の原価は、誰が払うのか。
::

## 同じ酒を続けて造る ― 総合原価計算

第6章の結婚式の酒は、注文ごとに原価を集める個別原価計算だった。普通酒「汐見」は違う。同じ規格の酒を、冬の間、毎日のように仕込み続ける。このような製品では、1か月にかかった原価を、その月にできた量で割って、1単位あたりの原価を求める。これが**総合原価計算**だ。

::formula 総合原価計算の基本の式
完成品総合原価 ＝ 月初仕掛品原価 ＋ 当月製造費用 － 月末仕掛品原価
完成品単位原価 ＝ 完成品総合原価 ÷ 完成品数量
::

計算の難しさは、ただ1か所にある。**月末仕掛品原価**をどう計算するかだ。月末のタンクの醪は、完成品ではない。だが、0でもない。

## 完成品換算量 ― 「何%できているか」で数える

::scene 2月末、夕方 ― 普通酒の仕込み蔵
「醪の半分はできている、と言える日はいつですか」
澪の問いに、小松は少し考えてから答えた。「米と麹と水は、最初の日に全部入れる。手間とボイラーの蒸気は、毎日少しずつだ」
::

小松の答えに、計算の鍵が2つあった。

::theory 原価を2つに分けて、完成品換算量で配分する
- **直接材料費**（酒米など）は、工程の始め（**始点**）で全量を投入する。だから、月末の醪にも、完成品と**同じだけ**入っている
- **加工費**（直接労務費＋製造間接費）は、工程の進み具合に応じて**平均的**に発生する。月末の醪には、進み具合（**加工進捗度**）の割合だけしか入っていない
月末仕掛品の数量に加工進捗度を掛けたものを**完成品換算量**という。30kLの醪の進捗度が40%なら、加工費の計算では「完成品12kL分」として扱う。
::

2月の普通酒の醸造工程の資料は、こうだった。

::table 2月の醸造工程（普通酒）の生産データと原価
| 項目 | 数量 | 直接材料費 | 加工費 |
| 月初仕掛品（醪） | 20kL（進捗度50%） | 1,100,000円 | 500,000円 |
| 当月投入 | 100kL | 6,100,000円 | 4,600,000円 |
| 完成品（原酒） | 88kL | | |
| 正常減損（工程の終点で発生） | 2kL | | |
| 月末仕掛品（醪） | 30kL（進捗度40%） | | |
::

月初の醪は、去年の秋に1kgあたり600円前後で仕入れた米で仕込んだ分、当月投入分は、第2章で見た値上がりした米の分だ。直接材料費の1kLあたりの単価は、月初分が55,000円、当月分が61,000円と違う。この違いが、計算方法で結果を変える。

## 平均法 ― 月初の分も当月の分も、混ぜて平均する

まず、減損はないものとして考え方をつかむため、月初仕掛品と当月の投入を合わせて平均単価を出し、月末仕掛品に配る方法から見ていこう。これを**平均法**という。

::example 平均法で、月末仕掛品原価と完成品総合原価を求めなさい（正常減損2kLは工程の終点で発生し、度外視法により完成品だけに負担させる）
::answer
**直接材料費**（始点投入。月末仕掛品は30kL分を負担）
- 平均単価：(1,100,000円＋6,100,000円)÷(完成品88kL＋減損2kL＋月末30kL)＝7,200,000円÷120kL＝60,000円
- 月末仕掛品：30kL×60,000円＝**1,800,000円**
- 完成品：7,200,000円－1,800,000円＝5,400,000円

**加工費**（平均的発生。月末仕掛品の完成品換算量＝30kL×40%＝12kL）
- 平均単価：(500,000円＋4,600,000円)÷(完成品88kL＋減損2kL＋月末12kL)＝5,100,000円÷102kL＝50,000円
- 月末仕掛品：12kL×50,000円＝**600,000円**
- 完成品：5,100,000円－600,000円＝4,500,000円

**結果**
- 月末仕掛品原価：1,800,000円＋600,000円＝**2,400,000円**
- 完成品総合原価：5,400,000円＋4,500,000円＝**9,900,000円**
- 完成品単位原価：9,900,000円÷88kL＝**112,500円／kL**
::boxes 平均法の直接材料費のボックス図（単位：kL）
H 投入（借方） | 産出（貸方）
L a 20 月初 20kL<br>1,100,000円
L a 100 当月投入 100kL<br>6,100,000円
R k 88 完成品 88kL
R x 2 減損 2kL
R a 30 月末 30kL<br>1,800,000円
::
::
::

減損の2kLは、工程の終点で発生した。月末の醪（進捗度40%）はまだ終点に達していないので、減損とは関係がない。だから、減損の分の原価は**完成品だけ**が負担する。上の計算では、減損2kLを割る数に含めて単価を出し、その分の原価を月末仕掛品に配らずに、完成品の側に残している。

## 正常減損と正常仕損 ― 消えた2kLの原価

::theory 度外視法：正常な減損・仕損の原価は、良品に負担させる
**減損**は、製造の途中で、蒸発・ガス化・ろ過などで原料が消えてなくなること。**仕損**は、不良品が生じること（第6章）。毎期ふつうに生じる程度のもの（**正常**減損・正常仕損）は、良品を作るために避けられないコストなので、その原価を良品（完成品・月末仕掛品）に負担させる。2級では、減損・仕損の分の原価を別に計算せず、良品に含めてしまう**度外視法**を使う。
- **工程の終点**で発生：月末仕掛品は終点に達していないので、**完成品だけ**が負担する
- **工程の始点**（または月末仕掛品の進捗度より手前）で発生：月末仕掛品も減損の地点を通過しているので、**完成品と月末仕掛品の両方**が、数量の割合で負担する
仕損品に売却・転用できる価値（評価額）があるときは、負担させる側の原価から評価額を差し引く。
::

始点で発生する場合は、計算の分母から減損の数量を除くだけでよい。減損の分の原価が、自動的に完成品と月末仕掛品に按分される。

::example 同じ資料で、正常減損2kLが工程の始点で発生していたとしたら、平均法による月末仕掛品原価はいくらか
::answer
**直接材料費**：7,200,000円÷(88kL＋30kL)×30kL＝**1,830,508円**（円未満四捨五入）
**加工費**：5,100,000円÷(88kL＋12kL)×12kL＝**612,000円**
月末仕掛品原価は**2,442,508円**、完成品総合原価は12,300,000円－2,442,508円＝9,857,492円。
減損の分の原価を月末の醪も負担するので、終点発生のときより月末仕掛品原価が42,508円大きく、そのぶん完成品原価が小さくなる。
::
::

## 先入先出法 ― 月初の醪から先に完成する

醪は、先に仕込んだものから先に搾る。この流れに合わせて、**月初仕掛品が先に完成し、月末仕掛品は当月投入分からできている**と考えるのが**先入先出法**だ。月末仕掛品の原価は、当月投入分の単価だけで計算する。

::example 先入先出法で、月末仕掛品原価と完成品総合原価を求めなさい（正常減損2kLは工程の終点で発生）
::answer
**直接材料費**
- 当月投入分の単価：6,100,000円÷当月投入100kL＝61,000円
- 月末仕掛品：30kL×61,000円＝**1,830,000円**
- 完成品：1,100,000円＋6,100,000円－1,830,000円＝5,370,000円

**加工費**
- 当月の完成品換算量：完成品88kL－月初仕掛品の換算量(20kL×50%＝10kL)＋減損2kL＋月末仕掛品12kL＝92kL
- 当月の単価：4,600,000円÷92kL＝50,000円
- 月末仕掛品：12kL×50,000円＝**600,000円**
- 完成品：500,000円＋4,600,000円－600,000円＝4,500,000円

**結果**
- 月末仕掛品原価：1,830,000円＋600,000円＝**2,430,000円**
- 完成品総合原価：5,370,000円＋4,500,000円＝**9,870,000円**（1kLあたり約112,159円）
::
::

::table 平均法と先入先出法の比較（終点減損、単位：円）
| 項目 | 平均法 | 先入先出法 | 差 |
| 月末仕掛品原価 | 2,400,000 | 2,430,000 | ＋30,000 |
| 完成品総合原価 | 9,900,000 | 9,870,000 | △30,000 |
::

差は、直接材料費の単価の違いから生まれている。値上がりした米で仕込んだ当月分の単価61,000円が、先入先出法では月末の醪にそのまま残り、平均法では月初の安い米と混ぜた60,000円で配られる。仕入れ値が上がっている時期には、先入先出法のほうが月末仕掛品が大きく、完成品原価が小さくなる。第2章の材料の消費単価と同じ構図だ。

::exam 単純総合原価計算の急所
- **ボックス図**を、直接材料費と加工費で別々に描く。加工費のボックスでは、月初・月末仕掛品を**完成品換算量**（数量×進捗度）で書く
- 直接材料費が**始点投入**なら、月末仕掛品の換算量は数量そのもの（進捗度100%扱い）。工程の途中や終点で投入する材料は、問題文の指示に従う
- **平均法**：（月初＋当月）÷（完成品＋月末）。**先入先出法**：当月÷（完成品－月初＋月末）。先入先出法では月初仕掛品の換算量を差し引く
- **正常減損・仕損の度外視法**：終点発生なら分母に減損・仕損の数量を含める（または完成品原価に残す）＝完成品のみ負担。始点発生なら分母から除く＝両者負担
- 仕損品に評価額があれば、負担させる原価から差し引く（多くは直接材料費から）
::

## 答え合わせ ― 醪の値段と、消えた2kL

::solve 醪は「完成品に換算して何kL分か」で値段をつける
2月末のタンクの醪30kLは、0円でも、完成品と同じ337万5,000円（30kL×112,500円）でもない。
- 酒米などの直接材料費は、仕込みの初日に全部入っているので、完成品と同じ30kL分を負担する
- 手間と蒸気（加工費）は、40%しか進んでいないので、完成品12kL分だけ負担する
平均法で計算すると、醪の価値は**240万円**。これが、高梨に出す試算表の「仕掛品」の金額になる。
消えた2kLは、ろ過とおり引きで毎年ふつうに失われる**正常減損**だった。工程の終点で起きるので、その原価は、2月に完成した原酒88kLが負担している。完成品単位原価112,500円には、減損の分の原価が含まれている。
::

岩倉は、自分の帳面の「醪 0円」の欄を、しばらく見ていた。「醪を0円にしたら、その分の原価は、全部、その月に完成した酒に乗っかるわけですな」
「はい。2月に搾った原酒が、3月に搾る醪の分の米代まで背負うことになります」
「月によって酒の値段が変わる。わしが一番嫌いな話です」

::danger 進捗度は、在庫の金額と利益を動かす「つまみ」
月末仕掛品の加工進捗度は、現場の見積りで決まる。進捗度を高く見積もれば、月末仕掛品の金額が増え、完成品原価（そして売上原価）が減って、利益が増える。翌月には逆に動くが、決算期末に大きく見積もれば、その期の利益をかさ上げできてしまう。
在庫の水増しは、粉飾決算の典型的な手口だ。進捗度の見積りは、根拠（作業時間・工程表）を記録し、毎期同じ方法で行うことが欠かせない。
::

::real 天使の分け前 ― ウイスキーは、熟成中に毎年2%消える
スコッチ・ウイスキーは、樽に詰めてから少なくとも3年、長いものは10年以上熟成させる。その間、樽の木を通して、ウイスキーは少しずつ蒸発していく。この消えた分を、つくり手たちは「**天使の分け前**（エンジェルズ・シェア）」と呼ぶ。スコッチ・ウイスキー協会の担当者は、熟成中のエタノールの損失は**平均で年約2%**だと説明している。

**この章の道具で読む ― 消えた分の原価を、残ったウイスキーが背負う**
年2%ずつ消えると、12年後に樽に残る量は、0.98の12乗で約78.5%。2割以上が天使の分け前になる。仮に、樽詰めした原酒1万リットルの原価が1,000万円だったとすると（仕組みを示すための例）、
::table 12年熟成で残る量と、1リットルあたりの原価
| 時点 | 樽の中の量 | 原価の合計 | 1リットルあたり |
| 樽詰め | 10,000L | 10,000,000円 | 1,000円 |
| 12年後 | 約7,847L | 10,000,000円（＋保管の費用） | 約1,274円 |
::
蒸発は熟成という工程のなかで毎年ふつうに起こる**正常減損**だ。度外視法の考え方では、消えた分の原価を別に計算せず、残ったウイスキーが負担する。仕訳で見ると、消えた分を取り出す仕訳は1本もない。仕掛品の金額は1,000万円のまま、量だけが減っていく。

::journal ① 樽詰め：原酒の原価を、熟成中の仕掛品とする
仕掛品 10,000,000 | 材料・加工費 10,000,000
::
::journal ② 12年後に瓶詰めして製品へ（約7,847L分。減損の仕訳はない）
製品 10,000,000 | 仕掛品 10,000,000
::
長期熟成のウイスキーが高価な理由の1つが、ここにある。12年物の1本には、天使が飲んだ2割以上の原酒の原価が、静かに上乗せされているのだ。

::cfo 醪の進捗度は、40%か60%か
3月の最初の試算表を出す前日、小松が澪の計算に異を唱えた。「月末の醪が40%だと？ 冗談じゃない。蒸しと仕込みの最初の5日で、手間と蒸気の半分は使う。残りの20日は見回りと温度の管理だ。月末の醪は、手間でいえば6割は済んどる」
澪の40%は、醪の全工程25日のうち、月末の醪が平均して10日目にあることから計算していた。
::table 進捗度の見積りと、月末仕掛品の加工費（平均法、終点減損）
| 項目 | 日数で見た進捗度 | 作業時間で見た進捗度 |
| 根拠 | 25日のうち10日目 | 最初の5日で作業時間の50%、残り20日で50%。10日目は50%＋5/20×50%＝62.5% |
| 採用する進捗度 | 40% | 60%（端数を丸める） |
| 月末仕掛品の完成品換算量 | 12kL | 18kL |
| 月末仕掛品の加工費 | 600,000円 | 850,000円 |
| 完成品の加工費 | 4,500,000円 | 4,250,000円 |
::
60%にすると、月末仕掛品が25万円増え、そのぶん2月の完成品原価が下がって、利益が25万円増える。高梨は「数字がよく見えるほうがありがたい」と冗談めかした。まず、加工進捗度が何を測るための数字なのかを考えてから選んでほしい。
::choice A. 日数で計算した40%を使う。誰が見ても同じ数字になる、客観的な基準だから
**△ 客観的だが、測る対象を取り違えている。**加工進捗度は、「加工費がどこまで発生したか」を表す数字だ。醪の加工費は、蒸しと仕込みの最初の5日に集中して発生する。日数で測ると、加工費の進み具合を低く見積もり、月末の醪の価値を小さく、完成品の原価を大きく計算してしまう。客観性は大事だが、物差しそのものが費用の発生と合っていなければ意味がない。
::
::choice B. 作業時間の割合で計算した60%を使い、根拠を記録して毎月同じ方法で見積もる
**◎ 進捗度の意味に合い、操作の余地も閉じている。**加工費の大半は作業時間と蒸気に比例して発生するので、作業時間の割合で測るのが筋だ。月末仕掛品の加工費は、18kL×(5,100,000円÷108kL)＝**850,000円**になる。
大事なのは、方法を変える理由を記録し、高梨にも「今月から進捗度の測り方を作業時間基準に改めた。2月分は25万円の影響」と伝えたうえで、以後は毎月同じ方法を続けることだ。都合のよいときだけ方法を変えるのでなければ、利益が増えることは問題ではない。
::
::choice C. 間をとって50%にする。杜氏の顔も立つ
**× 根拠のない数字は、毎月の比較を壊す。**50%には、日数の根拠も作業時間の根拠もない。根拠のない見積りは、来月以降、誰かが「今月は55%」と言い出したときに止められない。原価計算の数字は、関係者の顔を立てるための妥協では決めない。
::
::choice D. 試算表を出す月ごとに、利益がよく見えるほうを選ぶ
**× それは在庫の水増しの入り口だ。**月末仕掛品の進捗度を都合よく上げれば、利益は簡単に増える。だが、翌月には同じだけ完成品原価が増えて利益が減る。毎月方法を変える会社の試算表を、信金は信用しない。決算期末にこれをやれば、利益のかさ上げ（粉飾）そのものになる。
::
::answer 考え方の例を見る
加工進捗度は、「加工費がどこまで発生したか」を測るための数字だ。物差しは、費用の発生のしかたに合ったものを選ぶ。そして、一度選んだ方法は、根拠を記録して継続して使う。方法を変えるなら、理由と影響を明らかにする。
3月、澪は作業時間基準の進捗度で試算表を作り、変更の理由と影響額を1行添えて高梨に送った。返信は短かった。「この1行があるから、信用できます」
::

::next 総合原価計算は、等級別・組別・工程別へ
この章では、1種類の製品を1つの工程で造る**単純総合原価計算**を学んだ。第8章では、品質の違う製品を同じ工程で造る**等級別**、種類の違う製品を造る**組別**、複数の工程を順に通る**工程別**の総合原価計算へ進む。1級では、仕損・減損の原価を別に計算して負担させる**非度外視法**や、酒粕のように主な製品と一緒にできる**副産物**の評価も学ぶ。

## 確認問題

::quiz
::problem 次の資料から、平均法により、月末仕掛品原価と完成品総合原価を求めなさい。直接材料は工程の始点で投入している。
月初仕掛品 400個（進捗度50%）：直接材料費 160,000円、加工費 90,000円
当月投入 1,600個：直接材料費 640,000円、加工費 1,100,000円
完成品 1,500個、月末仕掛品 500個（進捗度40%）
月末仕掛品原価 [[340,000]] 円、完成品総合原価 [[1,650,000]] 円
::answer
**直接材料費**：(160,000円＋640,000円)÷(1,500個＋500個)＝400円、月末500個×400円＝200,000円
**加工費**：(90,000円＋1,100,000円)÷(1,500個＋500個×40%)＝1,190,000円÷1,700個＝700円、月末200個×700円＝140,000円
月末仕掛品原価＝200,000円＋140,000円＝**340,000円**、完成品総合原価＝(160,000円＋640,000円＋90,000円＋1,100,000円)－340,000円＝**1,650,000円**
::
::
::problem 次の資料から、先入先出法により、月末仕掛品原価と完成品総合原価を求めなさい。直接材料は工程の始点で投入している。
月初仕掛品 200個（進捗度50%）：直接材料費 90,000円、加工費 60,000円
当月投入 1,000個：直接材料費 500,000円、加工費 1,100,000円
完成品 900個、月末仕掛品 300個（進捗度2/3）
月末仕掛品原価 [[370,000]] 円、完成品総合原価 [[1,380,000]] 円
::answer
**直接材料費**：当月単価 500,000円÷1,000個＝500円、月末300個×500円＝150,000円
**加工費**：当月の換算量＝完成品900個－月初200個×50%＋月末300個×2/3＝900個－100個＋200個＝1,000個。当月単価 1,100,000円÷1,000個＝1,100円、月末200個×1,100円＝220,000円
月末仕掛品原価＝150,000円＋220,000円＝**370,000円**、完成品総合原価＝(90,000円＋500,000円＋60,000円＋1,100,000円)－370,000円＝**1,380,000円**
::
::
::problem 次の資料から、平均法により、完成品総合原価を求めなさい。直接材料は工程の始点で投入している。正常仕損は工程の終点で発生し、度外視法により処理する。仕損品の評価額5,000円は直接材料費から控除する。
月初仕掛品 なし。当月投入 1,000個：直接材料費 300,000円、加工費 273,000円
完成品 800個、正常仕損 50個、月末仕掛品 150個（進捗度40%）
月末仕掛品原価 [[63,000]] 円、完成品総合原価 [[505,000]] 円
::answer
終点発生なので、仕損は完成品だけが負担する（仕損の数量を分母に含め、その原価を完成品に残す）。
**直接材料費**：300,000円÷(800個＋50個＋150個)＝300円、月末150個×300円＝45,000円、完成品＝300,000円－45,000円－評価額5,000円＝250,000円
**加工費**：273,000円÷(800個＋50個＋150個×40%)＝273,000円÷910個＝300円、月末60個×300円＝18,000円、完成品＝273,000円－18,000円＝255,000円
月末仕掛品原価＝45,000円＋18,000円＝**63,000円**、完成品総合原価＝250,000円＋255,000円＝**505,000円**。評価額5,000円は仕損品勘定（資産）になる。
::

::summary
- 総合原価計算は、同じ規格の製品を続けて造るときに、1か月の原価を完成品と月末仕掛品に分けて、単位原価を求める方法
- 月末仕掛品は、直接材料費（始点投入なら数量そのもの）と加工費（数量×加工進捗度＝完成品換算量）を分けて計算する
- 平均法は月初分と当月分を混ぜた平均単価で、先入先出法は当月投入分の単価で月末仕掛品を計算する
- 正常減損・正常仕損は度外視法で良品に負担させる。終点発生なら完成品だけ、始点発生なら完成品と月末仕掛品の両方が負担する
- 加工進捗度は在庫の金額と利益を動かす。費用の発生に合った物差しで見積もり、継続して使う
::
