::mystery 米の代金だけの醪
2月26日、金曜日、午後7時。月末の締めの夜だ。普通酒「汐見」の醸造工程には、搾りを待つ醪が30キロリットル、タンクの中で泡を立てていた。
2月の完成品（搾った原酒）は88キロリットル。澪は、2月の普通酒の原価1,230万円を、完成品と、月末の醪に分けなければならない。
岩倉が、先に答えを書いた。
岩倉：「月末の醪は、米の代金だけで180万円です。まだ酒になっとらんのですから、人の手間の分は、完成した酒のほうに」
澪：「でも、蔵人はこの醪のためにも働いてます。仕込んで、櫂を入れて、温度を見て。その分は、どこへ行くんですか」
2人の計算は、60万円も食い違った。60万円ずれれば、2月に完成した原酒1キロリットルあたりの原価も変わる。来月の月末の醪も、再来月の原価も、全部ずれていく。
しかも、帳簿の数字を足し合わせると、仕込んだ量より2キロリットル少ない。
陸：「2キロリットル、どこ行ったんすか。まさか、誰か飲んだとか……」
**仕込み途中の醪に、値段はつけられるのか。消えた2キロリットルの原価は、誰が背負うのか？**
::

## 1か月ごとに区切る ― 総合原価計算と、2つの原価

::scene 2月27日、午前9時 ― 帳場
翌朝、澪は椎名に電話をかけた。
澪：「第6章の名入れの酒は、注文ごとに原価計算表がありました。でも普通酒は、毎日同じ酒を造り続けています。どこで区切ればいいんですか」
椎名：「時間で区切るんです。1か月分の原価をまとめて、1か月にできた量で割る。それが**総合原価計算**です」
椎名：「ただし、月末にできかけの醪が残る。そこで、原価を2つに分けて考えます」
::

総合原価計算では、製造原価を**直接材料費**と**加工費**に分ける。加工費は、直接労務費・直接経費・製造間接費をまとめた、「材料を製品に変えるための費用」だ。2つに分けるのは、工程の中での使われ方が違うからだ。

::table 材料費と加工費の使われ方（醸造工程）
| 原価 | 中身 | 工程の中での使われ方 |
| 直接材料費 | 蒸し米・麹米 | 仕込みのとき（工程の始点）に全部入る |
| 加工費 | 蔵人の賃金・タンクの減価償却費・燃料など | 発酵の進み具合に合わせて、少しずつかかる |
::

澪：「米は最初に全部入れる。だから、月末の醪にも、米は完成品と同じだけ入っている」
椎名：「そうです。でも加工費は、まだ半分しかかかっていないかもしれない。それを数で表すのが、**完成品換算量**です」

::point メモ ― 進捗度と完成品換算量
月末の仕掛品が、加工の上でどこまで進んでいるかを割合で表したものを**加工進捗度**（進捗度）という。仕掛品の数量に進捗度を掛けたものが**完成品換算量**で、「完成品に直すと何個分の加工費を使ったか」を表す。醪30kLの進捗度が40%なら、加工費は完成品12kL分（30kL×40%）を負担する。
::

::table 2月の醸造工程（普通酒）の生産データと原価
| 項目 | 数量 | 直接材料費 | 加工費 |
| 月初仕掛品（醪） | 20kL（進捗度50%） | 1,100,000円 | 500,000円 |
| 当月投入 | 100kL | 6,100,000円 | 4,600,000円 |
| 完成品（原酒） | 88kL | | |
| 正常減損（工程の終点で発生） | 2kL | | |
| 月末仕掛品（醪） | 30kL（進捗度40%） | | |
::

## ボックス図 ― 平均法で、醪に値段をつける

椎名に言われたとおり、澪はノートに箱を2つ描いた。左に「月初」と「当月投入」、右に「完成」「減損」「月末」。材料費の箱と、加工費の箱だ。
澪：「左の合計と右の合計は、量も金額も必ず同じになる。第1章の『月初＋当月－月末＝完成』ですね」
月初の醪と当月に仕込んだ醪をまとめて平均の単価を出す方法を、**平均法**という。

::example 平均法で、月末仕掛品原価と完成品総合原価を求める
上の生産データにもとづき、平均法で計算する。正常減損2kLは工程の終点で発生し、度外視法により完成品だけに負担させる。
::answer
**直接材料費**（始点投入なので、月末仕掛品は30kL分を負担）
- 平均単価：(1,100,000円＋6,100,000円)÷(完成88kL＋減損2kL＋月末30kL)＝7,200,000円÷120kL＝60,000円
- 月末仕掛品：30kL×60,000円＝**1,800,000円**
- 完成品：7,200,000円－1,800,000円＝5,400,000円
**加工費**（月末仕掛品の完成品換算量＝30kL×40%＝12kL）
- 平均単価：(500,000円＋4,600,000円)÷(完成88kL＋減損2kL＋月末12kL)＝5,100,000円÷102kL＝50,000円
- 月末仕掛品：12kL×50,000円＝**600,000円**
- 完成品：5,100,000円－600,000円＝4,500,000円
**結果**
- 月末仕掛品原価：1,800,000円＋600,000円＝**2,400,000円**
- 完成品総合原価：5,400,000円＋4,500,000円＝**9,900,000円**（1kLあたり9,900,000円÷88kL＝112,500円）
::trap
加工費の計算で、月末仕掛品を30kLのまま使わないこと。加工費は**完成品換算量**（12kL）で計算する。一方、材料費は始点で全部入っているので、30kLのままでよい。材料費と加工費で、月末の数量が違うのが総合原価計算のいちばんの急所だ。
::
::
::

::journal 2月の完成品を、仕掛品から製品へ振り替える
製品 9,900,000 | 仕掛品 9,900,000
::

::taccount 仕掛品（醸造工程・普通酒）
前月繰越 1,600,000 | 製品 9,900,000
材料 6,100,000 | 次月繰越 2,400,000
加工費 4,600,000 |
= 12,300,000 | 12,300,000
::

## 消えた2キロリットル ― 正常減損と度外視法

陸の「誰か飲んだ」説を確かめに、澪は小松のところへ行った。
小松：「ろ過と、おり引きで減る分だ。搾ったあと、酒をきれいにすると、毎年ふつうにこれくらいは減る」
澪：「工程の最後で減る、ってことですね。じゃあ、その2キロリットル分の原価は……」
製造の途中で、蒸発やろ過などで原材料の一部が目減りすることを**減損**という。毎年ふつうに起こる程度なら**正常減損**だ。2級では、正常減損の原価を別に計算せず、良品に負担させる**度外視法**で処理する。

::theory 正常減損の原価は、減損の発生点を通過した良品が背負う
正常減損は、良い製品を造るために避けられない費用なので、良品の原価に含める。誰が負担するかは、**減損が工程のどこで起きたか**で決まる。
- **終点で発生**：月末の仕掛品は終点を通過していないので、減損の原価は**完成品だけ**が負担する。計算では、減損の数量を分母に入れて単価を出し、減損の分を完成品に足す
- **始点で発生**（または途中で発生し、月末仕掛品の進捗度がそれより進んでいる）：完成品と月末仕掛品の**両方**が負担する。計算では、減損の数量を分母から除いて単価を出す
::

上の計算は、終点発生のやり方だった。減損2kLを分母に入れて単価を出し、月末仕掛品を差し引いた残りを、全部完成品に回している。消えた2キロリットルの原価は、完成した原酒88キロリットルが背負った。

::example 同じ資料で、正常減損が工程の始点で発生していたとしたら
正常減損2kLが工程の始点で発生し、度外視法で完成品と月末仕掛品の両方に負担させる場合、平均法による月末仕掛品原価はいくらか。
::answer
減損の数量を分母に入れないで単価を出す（そのぶん、完成品と月末仕掛品の単価が上がる）。
- 直接材料費：7,200,000円÷(88kL＋30kL)×30kL＝**1,830,508円**（円未満四捨五入）
- 加工費：5,100,000円÷(88kL＋12kL)×12kL＝**612,000円**
- 月末仕掛品原価＝**2,442,508円**、完成品総合原価＝12,300,000円－2,442,508円＝9,857,492円
減損の原価を月末の醪も負担するので、終点発生のときより月末仕掛品原価が42,508円大きくなり、そのぶん完成品原価が小さくなる。
::trap
始点発生のとき、加工費の分母に減損を入れないのは当然として、**材料費の分母からも**減損を外す。「減損＝加工の途中で消える」と思い込んで、材料費だけ分母に入れてしまう誤りが多い。
::
::
::

澪は、ボックス図を指でなぞった。米は仕込みのとき、つまり工程の始点で全部入る。だから月末の醪30キロリットルは、完成品と同じだけ米を負担する。60,000円×30kL＝180万円。
手間（加工費）は、まだ4割しかかかっていない。完成品換算量は30kL×40%＝12kL。50,000円×12kL＝60万円。消えた2キロリットルは工程の終点で起きたので、月末の醪は負担しない。

::solve 醪には、米の代金と、4割ぶんの手間の値段がついていた
月末の醪30キロリットルの原価は、米（材料費）が180万円、手間（加工費）が完成品換算量12キロリットル分の60万円で、合計240万円。岩倉の180万円との差60万円は、すでに醪に注ぎ込まれた蔵人の手間の分だった。
消えた2キロリットルは、誰も飲んでいない。搾ったあとのろ過とおり引きで、毎年ふつうに減る**正常減損**だった。工程の終点で起きたので、その原価は、完成した原酒88キロリットルが背負った。
もし岩倉の180万円で締めていたら、手間の60万円は2月の完成品に押し付けられ、2月の原酒は1キロリットルあたり約6,800円高く見えていた。翌月、その醪が完成するときには逆に安く見え、月ごとの原価の比較が狂う。
**できかけの物にも、そこまでにかけた手間の値段がある。材料は始点で、手間は進み具合で数える。**
::

岩倉は、ボックス図をしばらく眺めてから、自分の帳面に箱を2つ描き写した。
岩倉：「米は最初に、手間は少しずつ。……わしが45年、勘でやっとったことを、絵にするとこうなるわけですか」

## 先入先出法 ― 月初の醪から、先に搾る

醪は、先に仕込んだものから先に搾る。この流れに合わせて、**月初仕掛品が先に完成し、月末仕掛品は当月投入分からできている**と考えるのが**先入先出法**だ。月末仕掛品の原価は、当月投入分の単価だけで計算する。

::example 先入先出法で、月末仕掛品原価と完成品総合原価を求める
同じ生産データで、先入先出法で計算する（正常減損2kLは工程の終点で発生）。
::answer
**直接材料費**
- 当月投入分の単価：6,100,000円÷100kL＝61,000円
- 月末仕掛品：30kL×61,000円＝**1,830,000円**
- 完成品：1,100,000円＋6,100,000円－1,830,000円＝5,370,000円
**加工費**
- 当月の完成品換算量：完成88kL－月初の換算量（20kL×50%＝10kL）＋減損2kL＋月末12kL＝92kL
- 当月の単価：4,600,000円÷92kL＝50,000円
- 月末仕掛品：12kL×50,000円＝**600,000円**
- 完成品：500,000円＋4,600,000円－600,000円＝4,500,000円
**結果**
- 月末仕掛品原価：1,830,000円＋600,000円＝**2,430,000円**
- 完成品総合原価：5,370,000円＋4,500,000円＝**9,870,000円**
::trap
先入先出法の加工費の分母は、「当月投入分の完成品換算量」だ。月初仕掛品の換算量（10kL）を、完成品88kLから**引く**ことを忘れない。月初の醪は、先月までに加工費の半分を使い終えているからだ。
::
::
::

::table 平均法と先入先出法の比較（終点減損、単位：円）
| 項目 | 平均法 | 先入先出法 | 差 |
| 月末仕掛品原価 | 2,400,000 | 2,430,000 | ＋30,000 |
| 完成品総合原価 | 9,900,000 | 9,870,000 | △30,000 |
::

米の値段が上がっている月は、先入先出法では月末の醪が当月の高い単価で評価され、そのぶん完成品が安くなる。どちらの方法でも、合計12,300,000円は変わらない。分け方が変わるだけだ。

### 試験で狙われるパターン ― 進捗度の読み方・仕損の評価額・途中投入

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 正常仕損に評価額があるとき**　減損と違って、仕損品に売れる価値があれば、その評価額を負担する側の原価から差し引く。終点発生なら完成品総合原価から、両者負担なら（2級では）材料費などから差し引いてから按分する、と問題文の指示に従う。

::example 終点で発生した正常仕損に、評価額がある
当月の完成品総合原価は、仕損の処理前で3,000,000円だった。工程の終点で発生した正常仕損品10個の評価額は1個2,000円で、度外視法により完成品だけに負担させる。
::answer
完成品総合原価＝3,000,000円－10個×2,000円＝**2,980,000円**
::journal 仕損品の評価額を、仕掛品から仕損品勘定へ
仕損品 20,000 | 仕掛品 20,000
::
::trap
評価額を差し引くのは、仕損の原価を負担する側だ。終点発生なら完成品の原価から差し引く。月末仕掛品の原価から差し引かないこと。
::
::
::

**② 材料が工程の途中で入る**　始点以外で投入される材料は、投入点を通過した物だけが負担する。たとえば進捗度60%の点で入る材料なら、進捗度40%の月末仕掛品は負担しない（完成品換算量0）。工程を通じて平均的に入る材料は、加工費と同じく進捗度で換算する。

**③ 進捗度の書き方**　「月初仕掛品 20kL（50%）」の50%は加工の進み具合。材料費の計算には使わない（始点投入なら100%）。

::steps 解法の型 ― 総合原価計算（ボックス図）
1. 材料費と加工費の箱を分けて描く | 左に月初・当月投入、右に完成・減損（仕損）・月末
2. 加工費の箱は換算量で書く | 月初・月末の数量×進捗度。材料が始点投入なら材料費の箱は数量のまま
3. 減損（仕損）の発生点を確かめる | 終点→分母に入れて完成品に負担。始点→分母から外す
4. 方法を確かめる | 平均法は（月初＋当月）÷右の合計、先入先出法は当月投入÷当月の量
5. 月末を先に出し、完成品は差額で | 完成品＝月初＋当月投入－月末（－仕損品の評価額）
::

## 天使の分け前 ― 熟成のあいだに消える2%

::scene 2月28日、日曜日 ― 仕込み蔵
月末の数字を固めた翌々日、澪は、消えた2キロリットルのことを小松に話した。小松は、空になったタンクの縁を布で拭きながら言った。
小松：「酒は生き物だ。どこかで必ず減る。ウイスキーの連中は、樽で寝かせとる間に消える分を『天使の分け前』と呼ぶそうだ」
小松：「うちの減り方なんぞ、かわいいもんだ」
::

スコッチ・ウイスキーは、樽に詰めてから少なくとも3年、長いものは10年以上熟成させる。その間、樽の木を通して、ウイスキーは少しずつ蒸発していく。スコッチ・ウイスキー協会の担当者は、熟成中のエタノールの損失は**平均で年約2%**だと説明している。
年2%ずつ消えると、12年後に樽に残る量は、0.98の12乗で約78.5%。2割以上が天使の分け前になる。澪は、この章の度外視法で考えた。仮に、樽詰めした原酒1万リットルの原価が1,000万円だったとすると（仕組みを示すための例）、

::table 12年熟成で残る量と、1リットルあたりの原価
| 時点 | 樽の中の量 | 原価の合計 | 1リットルあたり |
| 樽詰め | 10,000L | 10,000,000円 | 1,000円 |
| 12年後 | 約7,847L | 10,000,000円（＋保管の費用） | 約1,274円 |
::

::journal ① 樽詰め：原酒の原価を、熟成中の仕掛品とする（内訳は仮の数字）
仕掛品 10,000,000 | 材料 4,000,000
 | 賃金・給料 3,000,000
 | 製造間接費 3,000,000
::

::journal ② 12年後に瓶詰めして製品へ（約7,847L分。消えた分を取り出す仕訳はない）
製品 10,000,000 | 仕掛品 10,000,000
::

蒸発は、熟成の工程の中で毎年ふつうに起こる正常減損だ。度外視法では、消えた分の原価を別に計算せず、残ったウイスキーが背負う。仕掛品の金額は1,000万円のまま、量だけが減っていく。
小松：「12年物が高い理由が分かったか。天使に2割飲ませた分まで、残りの酒が払っとるんだ」
澪：「うちの蔵の奥の古酒も、同じですね」
小松の顔から、笑いが消えた。
小松：「古酒の話は、またにしてくれ」
その意味を澪が知るのは、5月の棚卸の日だった。

::danger 進捗度の見積りは、月末の在庫と利益を動かす
月末仕掛品の進捗度は、見積りだ。進捗度を高く見積もれば、月末仕掛品（資産）が大きくなり、完成品の原価、ひいては売上原価が小さくなる。根拠のない見積りは、利益を動かす道具になりうる。進捗度は、加工費が実際にかかる様子（作業時間の進み方など）にもとづいて、毎月同じ考え方で見積もる。
::


::cfo 月末の醪の進捗度 ― 何で測り、どう伝えるか
2月の締めのあと、澪は進捗度の見積り方を見直した。いまは「仕込みから何日目か」で決めている。小松の作業日誌を見ると、手間のかかり方は日数とは違っていた。
**前提**
- 普通酒の醪は25日で搾る。2月末の醪は、仕込みから10日目
- 日数で見た進捗度は40%。作業日誌では、蔵人の手間は最初の5日に半分が集中していて、作業時間で見ると10日目は約60%
- 加工費の大半は、蔵人の賃金と、作業時間で配る製造間接費だ
- 進捗度を60%にすると、月末の醪の加工費は60万円から85万円に増え、2月の完成品の原価はそのぶん下がる
- 先入先出法に変えると、月末仕掛品原価は3万円増える
- 高梨には、毎月の損益を報告している
::choice A. 加工費のかかり方に合わせて作業時間で60%とし、変更の理由と影響額を高梨に伝える
**◎ 進捗度の根拠を、原価の生まれ方に合わせている。**加工費の大半は作業時間に比例するので、作業時間で見た60%のほうが実態に近い。変更で利益が動く以上、理由と影響額（月末の醪が25万円増え、完成品原価が25万円減る）を添えて伝えれば、数字の作り方を変えたことが信頼を損ねない。
::
::choice B. 利益が良く見えるので、今月から黙って60%に変える
**× 方向は正しいが、伝え方が逆だ。**作業時間で測ること自体は筋が通っている。だが、利益を動かす変更を黙って行えば、あとで見つかったとき、ほかの数字まで疑われる。審査の前なら、なおさらだ。
::
::choice C. 日数の40%のままにする。毎月同じ測り方なら、月ごとに比べやすい
**△ 比べやすさは大事だが、実態から外れている。**毎月同じように外れていれば比べることはできる。だが、月末の醪が実際より安く、完成品が実際より高く計算され続ける。
::
::choice D. 間をとって、進捗度を50%にする
**× 根拠のない数字だ。**40%と60%の間をとっても、加工費のかかり方を表したことにはならない。根拠のない見積りは、毎月、都合のよい方向へ動かされやすい。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「進捗度は何%か」ではなく、「加工費は、何に比例して醪に入っていくか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 進捗度の見積りと、2月末の醪の加工費（平均法、終点減損）
| 項目 | 日数で見る | 作業時間で見る |
| 進捗度 | 40% | 60% |
| 月末の醪の換算量 | 12kL | 18kL |
| 月末の醪の加工費 | 600,000円 | 850,000円 |
| 完成品の加工費 | 4,500,000円 | 4,250,000円 |
::
作業時間で見ると、月末の醪の加工費は25万円増え、完成品の原価が25万円減る。合計5,100,000円は変わらない。
#### 手順3　ほかの答えに引かれる理由
Bは「利益が増えるなら早く」という気持ちに、Cは「変えないほうが安全」という慎重さに、Dは折衷の分かりやすさに引かれる。先入先出法に変えた場合の影響は、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **進捗度は、加工費のかかり方で測る**：日数ではなく、作業時間や機械の時間に比例することが多い
- **数字の作り方を変えたら、理由と影響額を添える**：変えること自体より、黙って変えることが信頼を損ねる
#### 前提が変われば
加工費の大半が、タンクの冷却の電気代のように日数に比例する費用なら、日数で見た40%のほうが実態に近い。何で測るかは、費用の中身しだいだ。
::
::

::exam 総合原価計算の急所
- 材料費と加工費は**別々の箱**で計算する。始点投入の材料は月末仕掛品も数量どおり、加工費は**完成品換算量**
- 平均法：（月初＋当月）÷（完成＋減損＋月末）。先入先出法：当月投入÷当月の量（加工費は月初の換算量を引く）
- 正常減損・仕損の**終点発生は完成品だけが負担**（分母に入れる）、**始点発生は両者負担**（分母から外す）
- 仕損品の評価額は、負担する側の原価から差し引く
- 月末を先に計算し、完成品は差額で出すと間違えにくい
::

::next 2つの工程、2つの製品へ
第8章では、同じ工程から大きさの違う製品ができるとき（等級別）、違う製品を同じ工場で造るとき（組別）、工程が2つ以上あるとき（工程別）の総合原価計算を学ぶ。1級では、減損や仕損の原価を別に計算する「非度外視法」や、異常な仕損の処理も扱う。
::

::summary
- 総合原価計算は、1か月の原価をまとめ、完成品と月末仕掛品に分ける方法
- 原価は直接材料費と加工費に分け、加工費は完成品換算量（数量×進捗度）で配る
- 平均法は月初と当月投入をまとめた単価、先入先出法は当月投入の単価で月末仕掛品を評価する
- 正常減損・正常仕損は度外視法で処理し、終点発生なら完成品だけ、始点発生なら両者が負担する
- 進捗度の見積りは、月末仕掛品と完成品の原価を動かす
::

## 確認問題

::quiz
::problem 次の資料から、平均法による月末仕掛品原価と完成品総合原価を求めなさい。材料はすべて工程の始点で投入している。
月初仕掛品 200個（進捗度50%）直接材料費 80,000円、加工費 30,000円
当月投入 1,000個　直接材料費 400,000円、加工費 402,000円
完成品 900個、月末仕掛品 300個（進捗度60%）
月末仕掛品原価 [[192,000]] 円、完成品総合原価 [[720,000]] 円
::answer
**直接材料費**：(80,000＋400,000)÷(900＋300)＝400円。月末 300個×400円＝120,000円、完成品 360,000円
**加工費**：月末の換算量は300×60%＝180個。(30,000＋402,000)÷(900＋180)＝400円。月末 180個×400円＝72,000円、完成品 360,000円
月末仕掛品原価＝120,000＋72,000＝**192,000円**、完成品総合原価＝360,000＋360,000＝**720,000円**
加工費の分母に月末の300個をそのまま入れると、単価も月末仕掛品原価も誤る。
::
::
::problem 次の資料から、先入先出法による月末仕掛品原価と完成品総合原価を求めなさい。材料はすべて工程の始点で投入し、正常減損は工程の終点で発生した（度外視法、完成品だけに負担させる）。
月初仕掛品 100個（進捗度40%）直接材料費 60,000円、加工費 20,000円
当月投入 900個　直接材料費 450,000円、加工費 273,000円
完成品 850個、正常減損 50個、月末仕掛品 100個（進捗度50%）
月末仕掛品原価 [[65,000]] 円、完成品総合原価 [[738,000]] 円
::answer
**直接材料費**：当月投入の単価 450,000÷900＝500円。月末 100個×500円＝50,000円。完成品＝60,000＋450,000－50,000＝460,000円
**加工費**：当月の換算量＝完成850－月初の換算量40＋減損50＋月末50＝910個。単価 273,000÷910＝300円。月末 50個×300円＝15,000円。完成品＝20,000＋273,000－15,000＝278,000円
月末仕掛品原価＝**65,000円**、完成品総合原価＝**738,000円**
終点減損は分母に入れ、その原価は完成品が負担する。
::
::
::problem 次の資料から、平均法による月末仕掛品原価と完成品総合原価を求めなさい。材料は工程の始点で投入し、正常減損は工程の始点で発生した（度外視法、完成品と月末仕掛品の両方に負担させる）。月初仕掛品はない。
当月投入 1,000個　直接材料費 270,000円、加工費 240,000円
完成品 700個、正常減損 100個、月末仕掛品 200個（進捗度50%）
月末仕掛品原価 [[90,000]] 円、完成品総合原価 [[420,000]] 円
::answer
始点発生の減損は、分母から外して、完成品と月末仕掛品の両方に負担させる。
**直接材料費**：270,000÷(700＋200)＝300円。月末 200個×300円＝60,000円、完成品 210,000円
**加工費**：月末の換算量 200×50%＝100個。240,000÷(700＋100)＝300円。月末 100個×300円＝30,000円、完成品 210,000円
月末仕掛品原価＝**90,000円**、完成品総合原価＝**420,000円**
::
