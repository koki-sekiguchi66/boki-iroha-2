::mystery 金賞の酒が売れるほど、蔵の利益が消えていく
10月の最初の月曜日、午後3時。東京・丸の内の商社のオフィスで、隣の席の同期が、スマートフォンの画面を汐見澪に向けた。
「見た？ あのAIの会社、去年の赤字が420億ドルだって。売上の9倍の赤字。AIバブルも、もうおしまいだな」
見出しには、売上は1年で12倍、とあった。売上が12倍になった会社が、おしまいなのだろうか。澪がそう言いかけたとき、自分のスマートフォンが鳴った。母からだった。
「お父さんが、蔵で倒れた」
翌朝の新幹線と在来線を乗り継いで、澪は4時間後、新潟の海沿いの町に立っていた。潮の匂いの中に、蒸した米の甘い香りが混じっている。創業1872年の汐見酒造。澪は、この蔵の6代目・汐見謙三の一人娘だ。
父は命を取りとめたが、言葉と右手に後遺症が残った。復帰の見通しは立たない。その週の金曜日、蔵の応接間に、取引先の越後みなと信用金庫の高梨がやって来た。
「澪さん、率直に申し上げます。営業利益は3年前の4,000万円から、今期の見込みで1,100万円。来年の6月の決算で赤字になれば、4億円の借入金の借換えは、お約束できません」
澪は耳を疑った。汐見酒造の大吟醸「斗瓶取り」は、3年連続で全国の品評会の金賞を取っている。1本3,500円で出荷して、毎年すぐに売り切れる。父はその大吟醸を、3年で1万本から3万本に増やした。売上は伸びている。それなのに、利益は4分の1になった。
**金賞の酒が売れるほど、なぜ蔵は貧しくなるのか？**
その夜、蔵の事務所で、70歳を超えた番頭の岩倉が、黒い表紙の帳面を澪の前に置いた。「先代も社長も、この帳面で酒の値段を決めてきました。どこにも、間違いはありません」
::

## 3級の簿記では、酒の値段が分からない

澪の簿記の知識は、商社に入って2年目に取った3級で止まっている。3級の簿記では、仕入れた商品をそのまま売る会社を考えた。牛丼の店なら、牛肉を「仕入」、売ったら「売上」。差し引きが利益だ。
だが、酒蔵が仕入れているのは、酒ではなく**米**だ。その米を磨き、蒸し、麹と酵母で1か月かけて発酵させ、搾り、火入れをし、瓶に詰めて、ようやく売れる「製品」になる。その間に、蔵人の給料も、ボイラーの燃料も、タンクの減価償却費もかかる。
「この1本の酒には、いくらのお金がかかっているのか」。商品を作る会社では、この問いに答えるための、もう1つの簿記が必要になる。それが**工業簿記**だ。

::table 商業簿記と工業簿記
| 項目 | 商業簿記（3級・2級） | 工業簿記（2級） |
| 対象 | 商品を仕入れて売る活動と、会社全体の記録 | 製品を作る活動（製造） |
| 中心の問い | 会社はいくら儲けたか | 製品1つを作るのに、いくらかかったか |
| 主な勘定 | 仕入・売上・繰越商品 | 材料・賃金・製造間接費・仕掛品・製品・売上原価 |
| 2級の配点（一般的な出題の型） | 60点（第1〜3問） | 40点（第4〜5問） |
::

製品を作るのにかかった金額を**原価**といい、それを計算する手続きを**原価計算**という。工業簿記は、原価計算の結果を帳簿に記録し、製造業の決算書を作るための技術だ。

## 番頭の帳面を、計算し直してみる

その週末、澪は岩倉の帳面を1冊ずつ読んだ。几帳面な字で、米の仕入、蔵人の給料、燃料代が並んでいる。そして毎年の終わりに、3つの酒の「1本あたりの儲け」が書かれていた。

::table 番頭の帳面：1本あたりの儲け（720mL換算・酒税を除く・単位：円）
| 項目 | 普通酒 | 純米吟醸 | 大吟醸 |
| 1本の出荷価格 | 600 | 1,400 | 3,500 |
| 米などの材料費 | 80 | 260 | 900 |
| 給料・燃料などの費用（1本あたり） | 400 | 400 | 400 |
| 1本の儲け | 120 | 740 | 2,200 |
| 年間の本数（万本） | 45 | 15 | 3 |
::

給料や燃料などの費用は、1年で2億5,200万円。岩倉はそれを、年間の本数63万本で割り、どの酒にも1本400円ずつ割り振っていた。この帳面を見れば、大吟醸は1本2,200円も儲かる、いちばんの稼ぎ頭に見える。父が大吟醸を増やしたのも、無理はなかった。

::scene 10月18日、午前5時 ― 仕込み蔵
まだ暗い仕込み蔵に、湯気が立ちこめていた。杜氏の小松が、蒸し上がった米を手で広げている。澪は、ずっと聞きたかったことを聞いた。
「小松さん。大吟醸と普通酒で、手間はどれくらい違いますか」
小松は、手を止めずに笑った。「比べもんにならんよ。普通酒の醪は3週間で搾れる。大吟醸は低い温度で5週間かけて、毎日様子を見る。搾るのも、袋に吊るして、垂れてくる雫だけを斗瓶に取る。1本あたりの手間は、普通酒の十何倍だろうね」
澪は、作業日誌から、それぞれの酒にかかった延べの作業時間を拾い出した。普通酒4万5,000時間、純米吟醸3万7,500時間、大吟醸4万3,500時間。本数では全体の5%にも満たない大吟醸が、作業時間では3分の1を使っていた。
::

澪は、同じ2億5,200万円を、本数ではなく作業時間で割り振り直してみた。合計12万6,000時間だから、1時間あたり2,000円だ。

::table 作業時間で割り振り直した、1本あたりの儲け（単位：円）
| 項目 | 普通酒 | 純米吟醸 | 大吟醸 |
| 1本の出荷価格 | 600 | 1,400 | 3,500 |
| 米などの材料費 | 80 | 260 | 900 |
| 給料・燃料などの費用（作業時間で配分） | 200 | 500 | 2,900 |
| 1本の儲け | 320 | 640 | △300 |
::

::note
※給料・燃料などの費用の配分：普通酒 45,000時間×2,000円＝9,000万円÷45万本＝200円、純米吟醸 37,500時間×2,000円＝7,500万円÷15万本＝500円、大吟醸 43,500時間×2,000円＝8,700万円÷3万本＝2,900円。配分の合計は2億5,200万円で、本数で割ったときと同じ。
::

::solve 大吟醸は、1本売るごとに300円を失っていた
同じ費用の合計を、何を基準に割り振るか。たったそれだけで、大吟醸は「1本2,200円儲かる酒」から「1本300円損をする酒」に変わった。
3つの酒の儲けを本数で掛けて合計すると、どちらの計算でも2億3,100万円になる。会社全体の利益は変わらない。変わるのは、**どの酒が利益を生み、どの酒が利益を食っているか**という、経営の判断に使う情報だ。
父は、本数で割った帳面を信じて、大吟醸を増やした。大吟醸に手間をとられた蔵人とタンクは、そのぶん、儲かる普通酒や純米吟醸を造れなくなっていた。金賞の酒が売れるほど、蔵は貧しくなっていたのだ。
もちろん、作業時間で割るのが唯一の正解というわけではない。燃料はタンクの数と日数で、精米の費用は米の量で、と費用ごとに正しい物差しがある。その「物差し」を選ぶ技術こそが、これから1年かけて澪が学ぶ**原価計算**である。
::

帳面を閉じた岩倉は、しばらく何も言わなかった。それから、ぽつりと言った。「本数で割るのは、先々代からのやり方でした。大吟醸がほんの少しだった時代には、それで困らんかったんです」
誰も間違えてはいなかった。ただ、蔵が変わったのに、物差しが変わっていなかった。

::real 日本酒の出荷量は、ピークの4分の1以下になった
汐見酒造のような蔵が大吟醸に力を入れる背景には、日本酒の市場そのものの縮小がある。清酒の課税数量（国内に出荷され、酒税がかかった量）は、1973年度の176万キロリットルが最高だった。それが2023年度には約38.7万キロリットルと、ピークの約22%にまで減っている。量が売れなくなったぶん、多くの蔵が、1本あたりの値段が高い吟醸酒・大吟醸酒に活路を求めてきた。

**この章の道具で読む ― 本数が減ると、1本の原価はどう変わるか**
蔵には、造る量が減っても簡単には減らない費用がある。タンクや精米機の減価償却費、通年で雇う蔵人の給料、建物の保険料。こうした費用を**固定費**という（第4章・第10章）。
仮に固定費が年1億円の蔵が、50万本造れば1本あたり200円。25万本に減れば、1本あたり400円になる。同じ酒、同じ手間でも、造る量が半分になるだけで、1本が背負う固定費は2倍になる。そこで蔵は、1本あたりの値段の高い酒へと舵を切る。ただし、その酒が本当に固定費を背負えるだけ稼いでいるかは、原価を正しく計算しなければ分からない。汐見酒造の帳面がつまずいたのは、まさにそこだった。
::note
出典：[農林水産省「清酒の需要と供給」（2016年3月、ピーク時 昭和48年度176万kL）](https://www.maff.go.jp/j/seisan/keikaku/kome_torihiki/seisyu/attach/pdf/160322-3.pdf)、[国税庁「酒のしおり」（令和7年版、令和5年度の清酒の課税数量 約38.7万kL）](https://www.nta.go.jp/taxes/sake/shiori-gaikyo/shiori/2025/index.htm)
::

::cfo 信金への返事 ― 来期の造りを、どう変えるか
翌週、高梨から電話が来た。「年明けまでに、来期の生産計画を出してください。それを見て、借換えを判断します」
澪の手元には、上の2つの表がある。今年の造りはもう始まっているが、仕込みの配分は、まだ変えられる。4つの案のうち、来期の利益を最も確実に増やす案はどれか。2つ目の表（作業時間で割り振った儲け）を使って選んでほしい。手がかりは作業時間だ。大吟醸1本には1.45時間（4万3,500時間÷3万本）、純米吟醸1本には0.25時間（3万7,500時間÷15万本）かかる。純米吟醸の販売は、あと6万本まで増やせる見込みだ。
::choice A. 金賞の大吟醸を、さらに倍の6万本に増やす
**× 帳面の錯覚を、さらに大きくする。**作業時間で計算し直すと、大吟醸は1本300円の損だ。3万本増やせば、損は900万円増える。しかも大吟醸1本には1.45時間かかる。増やす3万本で新たに4万3,500時間、いまの蔵の作業時間の3分の1以上が必要になり、そのぶん儲かる酒を造る手間が奪われる。
::
::choice B. 大吟醸を2万本に減らし、空いた手間で純米吟醸を増やす
**◎ 数字が示す方向。**大吟醸を1万本減らすと、1本300円の損が消えて、300万円の改善。空いた1万4,500時間（1万本×1.45時間）で、純米吟醸を1万4,500÷0.25＝5万8,000本造れる。販売の見込みの6万本に収まり、1本640円の儲けで約3,700万円。合わせて**約4,000万円**の改善になる。
ただし、2万本に減らしても大吟醸の赤字は残る。金賞の酒をやめるのではなく、値上げや、造り方の手間の見直しも同時に考えたい。
::
::choice C. 大吟醸をやめ、普通酒だけを造る
**△ 極端すぎる。**大吟醸の赤字は消えるが、普通酒の儲けは1本320円で、地元の需要には限りがある。金賞の大吟醸は、蔵の名前を全国に知らせ、純米吟醸を売る「看板」の役目も果たしている。損得の計算に入らない価値も含めて、ゼロか百かではなく、量と値段で調整する道を探すべきだ。
::
::choice D. 原価計算をやり直すのは手間なので、全商品を一律1割値上げする
**△ 方向は悪くないが、的を外している。**値上げで売上は約5,850万円増える計算だが、普通酒は地元の飲食店との価格競争が厳しく、客が離れれば逆効果だ。どの酒が損をしているかが分かった以上、上げるべきは大吟醸の値段であり、一律の値上げではない。
::
::answer 考え方の例を見る
大事なのは、「どの酒を何本造るか」を、**正しく割り振った原価**で決めることだ。本数で割った帳面では、大吟醸は最優等生に見えた。作業時間で割り直すと、最も足を引っぱる酒だった。
1つの計算方法で出た数字を、そのまま判断に使ってはいけない。費用の性質に合った物差しで割り振ること。それが、第4章（製造間接費）・第5章（部門別計算）・第8章（等級別総合原価計算）で本格的に学ぶ原価計算の核心である。
澪は、生産計画の表をBの案で作り、年明けに高梨に届けた。添えたのは、作業時間で計算し直した原価の表だ。高梨は表を2度読み、「この表を、毎月作れますか」とだけ聞いた。
作れなかった。この蔵には、まだ、原価を毎月計算する仕組みがない。澪の1年は、その仕組みを作ることから始まった。
::

## もう1つの問い ― 「赤字」の中には、何が入っているのか

高梨の言葉は、澪の頭の中で、あの日オフィスで見た記事の見出しと重なっていた。「赤字なら、借換えはお約束できません」。「赤字420億ドル、AIバブルもおしまい」。どちらも、**赤字**という1つの言葉で、会社の良し悪しを決めている。
10月の終わり、その会社は、アメリカの証券取引委員会（SEC）に上場の届出書を提出した。澪は夜の蔵の事務所で、それを開いた。損益計算書は、3級で学んだものより、ずっと段の多い形をしていた。

::table アメリカのAI企業 Anthropic の2025年の損益（単位：百万ドル）
| 項目 | 金額 | 中身 |
| 売上高 | 4,585 | 前年の386から約12倍 |
| 営業費用 | 12,645 | うち計算資源・インフラ費7,326、和解金1,500 |
| 営業損失 | △8,060 | 本業の損益 |
| 受取利息など | 423 | |
| 転換社債などの公正価値の変動 | △34,308 | 企業価値が上がったことで生じた損失。現金は出ていかない |
| 当期純損失 | △41,965 | 「赤字420億ドル」の正体 |
::
::note
※税引前損失41,945に法人税等20を加えた額が当期純損失。受取利息など423は、受取利息431とその他△8の合計。出典は第22章。
::

澪は、電卓を2回たたいて目を疑った。420億ドルの赤字のうち、**8割を超える343億ドルは、事業の費用ではなかった**。会社の価値が上がったので、将来その会社の株に変わる約束（転換社債など）の価値も上がり、その分を損失として計上していたのだ。会社の評価が高まるほど、帳簿の損失が増える。直感とは、まるで逆だった。
残りの営業損失80億ドルも、いちばん大きいのは、次のAIを作るための計算資源の費用だった。工場を建てたのなら、建物は資産になり、何十年かに分けて費用になる。だが、研究のための費用は、使った年に、全額が費用になる。

::theory 「赤字」は1つの数字ではない
損益計算書は、利益を何段階かに分けて示す。売上から製品の原価を引いた**売上総利益**、そこから販売と管理の費用を引いた**営業利益**、利息などを加減した**経常利益**、臨時の損益と税金を加減した**当期純利益**。
同じ「赤字」でも、どの段で、何が原因で生じたのかによって、意味はまったく違う。本業が稼げなくなった赤字なのか。将来への投資を、ルールどおりに一度に費用にした赤字なのか。現金の出ていかない、評価の上だけの赤字なのか。それを見分ける道具が、簿記だ。
::

あの会社が本当に大丈夫なのかは、届出書を読んでも、まだ分からない。届出書そのものも、「新しい計算資源が届く期は利益率が下がる」「将来の巨額の支払いを、すでに約束している」とリスクを並べている。それでも、「売上の9倍の赤字だから、おしまい」という読み方が雑すぎることだけは、澪にも分かった。
問題は、自分の蔵だった。汐見酒造の「赤字」と「黒字」の中には、何が入っているのか。それを自分の言葉で高梨に説明できる日が、この1年の終わりに来る。本書の第10章・第17章・第18章・第22章で、澪はこの会社の数字に何度も立ち戻り、自分の蔵の数字と並べて読むことになる。

## 2級で学ぶこと ― 1年間の地図

澪が向き合うことになる論点は、2級の出題範囲そのものだ。本書は、澪の1年に沿って、3つの部に分けて学んでいく。

::table 本書の構成
| 部 | 澪の1年 | 主な論点 |
| 第1部　酒の本当の値段（工業簿記） | 10月〜3月：酒造りの季節 | 材料費・労務費・製造間接費、部門別計算、個別原価計算、総合原価計算、標準原価計算、直接原価計算とCVP分析 |
| 第2部　蔵を立て直す（商業簿記） | 4月〜6月：資金繰りと決算 | 電子記録債権とファクタリング、収益認識、棚卸資産の評価、固定資産（補助金・割賦）、リース、無形固定資産、有価証券、引当金、外貨建取引、税効果会計、決算 |
| 第3部　会社を大きくする | 7月〜9月：統合と連結 | 純資産と配当、本支店会計、合併と連結会計 |
::

もう1つ、本書には通しの問いがある。**「赤字」の中身を読む**ことだ。売上総利益・営業利益・経常利益・当期純利益という段の違い、研究開発費や減価償却費の計上のしかた、評価の上だけの損益。2級で学ぶ仕訳の1つ1つが、決算書の「赤字」と「黒字」の見え方を変える。各章の「実際にあった話」では、AI企業の巨額赤字、アマゾンの長い赤字、費用を資産に付け替えたワールドコムなど、計上のしかたで会社の姿が変わった事例を、その章の仕訳で読み解いていく。

工業簿記は、2級で初めて登場する。3級の知識（仕訳・勘定・決算）は、そのまま土台として使う。商業簿記は、3級で学んだ取引に、会社が大きくなったときに起きる取引が加わる。リースで設備を借りる、海外と外貨で取引する、ほかの会社を子会社にする。そして、その子会社を含めたグループ全体の決算書（連結財務諸表）を作る。

## 2級の試験 ― 敵を知る

::table 日商簿記2級の試験概要
| 項目 | 内容 |
| 試験方式 | 統一試験（ペーパー：例年6月・11月・2月）／ネット試験（随時） |
| 試験時間 | 90分 |
| 試験科目 | 商業簿記、工業簿記（原価計算を含む）。5題以内 |
| 合格基準 | 70%以上 |
| 一般的な出題の型 | 第1問 仕訳（商業簿記）／第2問・第3問 商業簿記（個別論点・連結・財務諸表など）／第4問 工業簿記（仕訳と原価計算）／第5問 工業簿記（標準原価計算・直接原価計算など） |
::

合格率は、統一試験が**15.1%**（2026年6月の第173回、実受験者4,821名）、ネット試験が**31.9%**（2026年4〜6月、受験者3万3,659名）。3級よりはっきり難しい。範囲が広く、しかも商業簿記と工業簿記で頭の使い方がまったく違うからだ。
それでも、工業簿記は「型」がはっきりしていて、正しく練習すれば満点に近い点を取りやすい分野でもある。本書は工業簿記から始める。澪の蔵の、いちばん切実な問いがそこにあるからだ。

::exam 2級の合否を分けるもの
- **工業簿記で得点を固める**：工業簿記（一般に40点）は、計算の手順を身につければ安定して高得点を取れる。第1部を何度も解き直そう
- **商業簿記は仕訳から**：第1問の仕訳は、ほぼすべての論点から出る。第2部・第3部の仕訳を、確実に切れるようにする
- **連結会計は避けて通れない**：第2問・第3問で、連結精算表や連結財務諸表の作成がよく問われる。第3部で、手順を1つずつ確かめる
::

::note
※本書は、日本商工会議所が2026年7月31日に公表した「2027年度適用」の出題区分表（2027年4月1日以降の試験に適用）に準拠しています。2027年3月までの試験を受ける人のために、現行の区分表との違い（紙の手形の論点、リースの区分、売上原価対立法と固定資産の除却・定率法の3級への移行など）は、各章で注記します。工業簿記・原価計算の出題区分に変更はありません。合格率は日本商工会議所の公表データによる。
::

---

最後に、本書の読み方について。
各章は、澪が蔵で出会う1つの「問い」から始まる。答えは、必ずその章で学ぶ簿記のルールの中にある。澪と一緒に帳面を開き、仕訳を切り、原価を計算しながら読み進めてほしい。
各章の「判断してみよう」では、答えを読む前に、必ず自分で1つ選んでから進んでほしい。そして「実際にあった話」では、現実の事件を、その章で学ぶ仕訳と計算で読み解く。

::summary 序章のまとめ
- 製品を作る会社では、「製品1つを作るのにいくらかかったか（原価）」を計算する工業簿記が必要になる
- 同じ費用の合計でも、何を基準に製品へ割り振るかで、製品ごとの儲けはまったく違って見える。会社全体の利益は変わらない
- 正しく割り振った原価は、どの製品を何本造るかという経営判断の土台になる
- 損益計算書の「赤字」は、どの段（売上総利益・営業利益・経常利益・当期純利益）で、何が原因で生じたかによって意味が違う。2級の計上のルールは、その読み方を変える
- 2級は90分、商業簿記と工業簿記の5題以内、70%以上で合格。合格率は統一試験15.1%（第173回）、ネット試験31.9%（2026年4〜6月）
- 本書は2027年度適用の出題区分表に準拠し、現行の区分表との違いを注記する
::
