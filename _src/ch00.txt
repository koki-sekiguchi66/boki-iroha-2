::mystery 金賞の酒が売れるほど、蔵の預金が減っていく
10月1日、木曜日。午前8時40分。東京・丸の内の総合商社のフロアで、同期の桐生が、スマートフォンの画面を汐見澪の顔の前に突き出した。
桐生：「見た？ アメリカのAIの会社、去年の赤字が420億ドルだって。売上は1年で12倍なのに、赤字は売上の9倍。バブルも終わりだな」
澪は見出しを読んだ。売上が12倍になった会社が、終わり。何かが引っかかった。だが、その引っかかりを言葉にする前に、自分のスマートフォンが震えた。母からだった。
母：「お父さんが、蔵で倒れた」
上越新幹線と在来線を乗り継いで4時間。新潟の海沿いの町は、潮の匂いの中に、蒸した米の甘い香りが混じっていた。創業1872年の汐見酒造。今日は、今季最初の米を蒸す日だった。父・汐見謙三は、湯気の立つ蒸し場で倒れたのだという。
命は取りとめた。だが、右手と言葉に、まひが残った。
1週間後の10月7日。蔵の応接間で、越後みなと信用金庫の高梨が、ファイルを開いた。
高梨：「率直に申し上げます。御社の営業利益は、3年前の4,000万円から、今期の見込みで1,100万円まで落ちています」
高梨：「来年7月12日に、4億円の借入金の借換えを審査します。6月の決算が赤字なら、お約束はできません」
**4億円。**澪は、膝の上で手を握った。
汐見酒造の大吟醸「汐見 斗瓶取り」は、3年続けて全国の品評会で金賞を取っている。1本3,500円で出荷して、毎年すぐに売り切れる。父は大吟醸を、3年で1万本から3万本に増やした。売上は伸びている。それなのに、利益は4分の1になり、預金は減り続けている。
同席していた叔父の汐見達也が、鼻で笑った。
叔父：「金賞の酒が損をするはずがないだろう。銀行の言いなりになるくらいなら、蔵ごと大手に売っちまえ」
澪：「売りません。……少なくとも、数字を見るまでは」
その夜、帳場で、番頭の岩倉が黒い表紙の帳面を澪の前に置いた。
岩倉：「先代も社長も、この帳面で酒の値段を決めてきました。どこにも、間違いはありません」
**金賞の酒が売れるほど、なぜ蔵は貧しくなるのか？**
::

## 帳場の夜 ― 3級の簿記では、酒の値段が分からない

午後10時。帳場の石油ストーブが、ちりちりと鳴っている。澪は商社の2年目に、簿記3級を取った。仕訳も、試算表も、決算も、ひととおりは分かる。そう思っていた。
澪：「岩倉さん。この大吟醸1本の原価は、いくらですか」
岩倉：「原価、ですか。米の代金なら、ここに」
岩倉が指さした欄には、米の仕入れの金額が並んでいた。だが、酒蔵が仕入れているのは酒ではない。米だ。
3級で学んだのは、仕入れた商品をそのまま売る会社だった。牛丼の店なら、牛肉を「仕入」れて、売れたら「売上」。差し引きが利益になる。
酒蔵は違う。米を磨き、蒸し、麹と酵母で1か月かけて発酵させ、搾り、火を入れ、瓶に詰めて、ようやく売れる酒になる。その間に、蔵人の給料も、ボイラーの燃料も、タンクの減価償却費もかかる。
澪：「米の代金だけでは、1本の酒の値段にならないんです。給料も燃料も、どこかで酒の値段に入っているはずで」
岩倉：「入っておりますよ。帳面の最後のページに」
そのページの話は、あとにしよう。まず澪が気づいたのは、自分の知っている簿記には、「作る」という工程が抜けていることだった。

::point メモ ― 工業簿記と原価
製品を作るのにかかった金額を**原価**といい、それを計算する手続きを**原価計算**という。原価計算の結果を帳簿に記録し、製造業の決算書を作るための簿記が**工業簿記**だ。2級で初めて登場する。
::

::table 商業簿記と工業簿記
| 項目 | 商業簿記（3級・2級） | 工業簿記（2級） |
| 対象 | 商品を仕入れて売る活動と、会社全体の記録 | 製品を作る活動（製造） |
| 中心の問い | 会社はいくら儲けたか | 製品1つを作るのに、いくらかかったか |
| 主な勘定 | 仕入・売上・繰越商品 | 材料・賃金・製造間接費・仕掛品・製品・売上原価 |
| 2級の配点（一般的な出題の型） | 60点（第1〜3問） | 40点（第4〜5問） |
::

## 帳面の最後のページ ― 本数で割った「1本の儲け」

岩倉が開いた最後のページには、几帳面な字で、3つの酒の「1本あたりの儲け」が書いてあった。

::table 番頭の帳面：1本あたりの儲け（720mL換算・酒税を除く・単位：円）
| 項目 | 普通酒 | 純米吟醸 | 大吟醸 |
| 1本の出荷価格 | 600 | 1,400 | 3,500 |
| 米などの材料費 | 80 | 260 | 900 |
| 給料・燃料などの費用（1本あたり） | 400 | 400 | 400 |
| 1本の儲け | 120 | 740 | 2,200 |
| 年間の本数（万本） | 45 | 15 | 3 |
::

澪：「大吟醸が1本2,200円。普通酒の18倍も儲かっているんですね」
岩倉：「さようです。社長が大吟醸を増やしたのも、この数字を見てのことでした」
給料や燃料などの費用は、1年で2億5,200万円。岩倉はそれを、年間の本数63万本で割り、どの酒にも1本400円ずつ載せていた。
澪は表計算を開き、同じ計算をなぞった。合っている。足し算にも掛け算にも、間違いはない。
澪：「数字は嘘をつきませんね。じゃあ、なぜ預金が減るんだろう」
岩倉は、眼鏡を外して目頭を押さえた。
岩倉：「帳面は嘘をつきません。嘘をつくのは、いつも帳面の読み方のほうです」
その言葉の意味が分かったのは、3日後の朝だった。

## 午前5時の仕込み蔵 ― 手間は、本数に比例しない

::scene 10月10日、午前5時 ― 仕込み蔵
まだ暗い仕込み蔵に、湯気が立ちこめていた。杜氏の小松が、蒸し上がった米を素手で広げている。その横で、見習いの蔵人の陸が、湯気の向こうからこちらに手を振った。
陸：「専務、早っ。まだ5時っすよ」
澪：「小松さんに、聞きたいことがあって。大吟醸と普通酒で、手間はどれくらい違いますか」
小松は手を止めずに、鼻で笑った。
小松：「比べもんにならねえ。普通酒の醪は3週間で搾れる。大吟醸は低い温度で5週間、毎日見てやらねばならねえ」
小松：「搾るのも、袋に吊るして、垂れてくる雫だけを斗瓶に取る。1本あたりの手間は、普通酒の十何倍だ」
::

事務所に戻った澪は、作業日誌から、酒ごとの延べの作業時間を拾い出した。普通酒4万5,000時間、純米吟醸3万7,500時間、大吟醸4万3,500時間。合計12万6,000時間。
本数では全体の5%にも満たない大吟醸が、作業時間では3分の1を使っていた。
澪：「本数で割ると、手間のかかる酒も、かからない酒も、同じ400円を背負うことになる……」
陸：「それ、ずるくないっすか。大吟醸の手間を、普通酒が肩代わりしてるってことでしょ」
澪は、同じ2億5,200万円を、本数ではなく作業時間で割り振り直してみた。12万6,000時間で割ると、1時間あたり2,000円だ。

::table 作業時間で割り振り直した、1本あたりの儲け（単位：円）
| 項目 | 普通酒 | 純米吟醸 | 大吟醸 |
| 1本の出荷価格 | 600 | 1,400 | 3,500 |
| 米などの材料費 | 80 | 260 | 900 |
| 給料・燃料などの費用（作業時間で配分） | 200 | 500 | 2,900 |
| 1本の儲け | 320 | 640 | △300 |
::

::note
※配分の計算：普通酒 45,000時間×2,000円＝9,000万円÷45万本＝200円、純米吟醸 37,500時間×2,000円＝7,500万円÷15万本＝500円、大吟醸 43,500時間×2,000円＝8,700万円÷3万本＝2,900円。配分の合計は2億5,200万円で、本数で割ったときと同じ。
::

澪の指が止まった。大吟醸の欄に、マイナスがついている。

::point メモ ― 配る、という計算
いくつもの製品に共通してかかった費用を、何かの物差し（本数・作業時間・機械の運転時間など）で製品ごとに割り振ることを、原価計算では**配賦**（はいふ）という。物差しのことを**配賦基準**という。何を物差しにするかで、製品1つあたりの原価は大きく変わる（第4章・第5章）。
::

澪は、2つの表を並べて考えた。どちらで配っても、3つの酒の儲けの合計は同じ2億3,100万円になる。費用の合計が同じなのだから、当たり前だ。違うのは、手間のかかる大吟醸が、本数で配った帳面では1本400円しか費用を背負っていなかったことだけだった。
澪：「大吟醸1本に使う1.45時間があれば、純米吟醸を5.8本造れる……」
蔵人の手間には、限りがある。その手間を、最も稼がない酒に吸い込ませていたのだ。

::solve 大吟醸は、1本売るごとに300円を失っていた
同じ2億5,200万円を、本数で配れば大吟醸は1本2,200円の黒字、作業時間で配れば1本300円の赤字になる。数字は1つも嘘をついていない。違ったのは、**配り方の物差し**だけだ。
父は本数で配った帳面を信じて、大吟醸を3倍に増やした。大吟醸に手間をとられた蔵人とタンクは、そのぶん、稼ぎの大きい純米吟醸を造れなくなった。金賞の酒が売れるほど、蔵は貧しくなっていたのだ。
もし叔父の言うとおり「金賞の酒が損をするはずがない」と信じて、来期も大吟醸を増やしていたら、預金はさらに減り、7月の審査の前に資金が尽きていたかもしれない。
**原価は、事実ではなく計算だ。配り方を決める物差しが、製品の姿を決める。**その物差しを選ぶ技術こそが、澪がこれから1年かけて学ぶ原価計算である。
::

翌朝、澪が表を見せると、岩倉はしばらく黙っていた。
岩倉：「本数で割るのは、先々代からのやり方でした。大吟醸がほんの少しだった時代には、それで困らなかったんです」
誰も間違えてはいなかった。ただ、蔵が変わったのに、物差しが変わっていなかった。

## 書庫の出荷台帳 ― 酒が5分の1しか売れなくなった時代

::scene 10月12日、夜 ― 帳場の奥の書庫
「大吟醸がほんの少しだった時代」とは、いつのことなのか。澪が聞くと、岩倉は書庫の奥から、背の擦り切れた出荷台帳を何冊も出してきた。
岩倉：「わしが入ったのは昭和の終わりです。毎朝、普通酒の一升瓶をトラックに積んで、町じゅうの酒屋に運んだもんです」
岩倉：「いまの倍は出とりました。造る酒のほとんどが普通酒なら、本数で割っても困りません」
::

その夜、澪は、岩倉の言う「倍」が、この蔵だけの話ではないことを知った。国税庁の統計では、清酒の課税数量（国内に出荷され、酒税がかかった量）は、1973年度の**176万キロリットル**が最高だった。それが2023年度には**約38.7万キロリットル**と、ピークの約22%まで減っている。
量が売れなくなったぶん、全国の多くの蔵が、1本の値段が高い吟醸酒・大吟醸酒に活路を求めてきた。父が大吟醸を3倍にしたのも、その流れの中だった。
澪は、帳場のホワイトボードに数字を書いた。
澪：「蔵には、造る量が減っても減らない費用があります。タンクや精米機の減価償却費、通年の蔵人の給料、建物の保険料」
澪：「仮にそういう費用が年1億円なら、50万本造れば1本200円。25万本に減れば、1本400円です」
岩倉：「同じ酒、同じ手間でも、量が半分になるだけで、1本が背負う分は倍になる、と」
量が減っても減らない費用を**固定費**、量に比例して増える費用を**変動費**という（第4章・第10章）。高い酒へ舵を切ること自体は、間違いではない。問題は、その高い酒が本当に稼いでいるかを、正しい物差しで確かめていなかったことだ。

::note
出典：[農林水産省「清酒の需要と供給」（2016年3月。ピークは昭和48年度の176万kL）](https://www.maff.go.jp/j/seisan/keikaku/kome_torihiki/seisyu/attach/pdf/160322-3.pdf)、[国税庁「酒のしおり」（令和7年版。令和5年度の清酒の課税数量 約38.7万kL）](https://www.nta.go.jp/taxes/sake/shiori-gaikyo/shiori/2025/index.htm)
::

## 父の机の引き出し ― 黒い手帳の、読めない行

::scene 10月14日、午後 ― 長岡の病院
病室の窓から、信濃川が見えた。父は、左手でゆっくりと澪の手を握った。何か言おうとして、口が動く。言葉にならない。
父：「……ちょう、めん」
澪：「帳面？ 岩倉さんの？」
父は、首を横に振った。それから、自分の胸ポケットのあたりを、左手で2回たたいた。
::

その夜、澪は父の机の引き出しを開けた。一番奥に、手のひらほどの黒い手帳があった。父がいつも胸ポケットに入れていたものだ。
ページのほとんどは、鉛筆の走り書きだった。米の銘柄、酵母の番号、天気。その合間に、四角い字で書かれた、読めない行がいくつもあった。

::memo 黒い手帳の、最後の数ページ
斗瓶　一本　いくら
米　予六百
釜　春までもたぬ
芹　六割　三千六百　六月晦日
保　八千
小松　三月　千二百
Ｍ・Ｌ　紐育
日本橋　黒か赤か
免許は金で買えぬ
::

最初の1行だけは、読めた。「斗瓶　一本　いくら」。大吟醸「斗瓶取り」は、1本いくらでできているのか。
澪は、手帳を握ったまま、しばらく動けなかった。父は、本数で割った帳面を信じきっていたわけではなかった。誰にも答えられない問いを、1人で抱えていたのだ。
残りの行は、まだ何のことか分からない。「芹」とは何か。「保　八千」の八千とは、何の八千なのか。
岩倉に見せると、岩倉は一瞬だけ、目をそらした。
岩倉：「……社長の覚え書きでしょう。わしには、さっぱり」
澪は、その一瞬を見逃さなかった。

## 赤字の中に、何が入っているのか ― 桐生の電話

10月20日の夜。休職の手続きを済ませた澪のスマートフォンに、桐生からビデオ通話が来た。
桐生：「蔵、どう？ 例のAIの会社の続報、見た？」
桐生：「420億ドルの赤字のうち、340億ドルくらいは、現金の出ていかない評価の損なんだってさ」
澪：「評価の損？」
桐生：「会社の価値が上がったから、将来その会社の株に変わる約束の値段も上がって、その分を損として載せてるらしい。会社の評価が高まるほど、帳簿の赤字が増えるわけ」
澪は、画面の向こうの記事を読み上げてもらいながら、ノートに数字を書いた。

::table アメリカのAI企業 Anthropic の2025年の損益（報道と上場の届出書による。単位：百万ドル）
| 段 | 金額 | 中身 |
| 売上高 | 4,585 | 前年の386から約12倍 |
| 営業損失 | △8,060 | 本業の損益。次のAIを作る計算資源の費用が大きい |
| 転換社債などの公正価値の変動 | △34,308 | 企業価値の上昇で生じた評価の損。現金は出ていかない |
| 当期純損失 | △41,965 | 「赤字420億ドル」の正体 |
::

**赤字の8割を超える部分は、事業の費用ではなかった。**残りの営業損失も、その多くは次のAIを作るための研究開発の費用だ。工場を建てたのなら資産になって何十年かに分けて費用になるが、研究開発の支出は、使った年に全額を費用にするルールになっている（第17章）。
澪：「同じ『赤字』でも、中身がまるで違うんだ……」
桐生：「でしょ。まあ、それでも大丈夫な会社かどうかは、別の話だけどね。本人たちも、届出書で『将来の巨額の支払いを、もう約束している』ってリスクを書いてるし」
通話を切ったあと、澪は高梨の言葉を思い出した。「6月の決算が赤字なら、お約束はできません」。
その「赤字」の中には、何が入っているのか。それを自分の言葉で説明できなければ、蔵は守れない。

::theory 「赤字」は1つの数字ではない
損益計算書は、利益を何段階かに分けて示す。売上から製品の原価を引いた**売上総利益**、販売と管理の費用を引いた**営業利益**、利息などを加減した**経常利益**、臨時の損益と税金を加減した**当期純利益**だ（第22章）。
同じ赤字でも、どの段で、何が原因で生じたかで意味が違う。本業が稼げなくなった赤字なのか。将来への支出を、ルールどおり一度に費用にした赤字なのか。現金の出ていかない、評価の上だけの赤字なのか。それを見分ける道具が、簿記だ。
::

::note

## 2級という地図 ― 265日の旅程

その夜、澪は2級の問題集を買った。高梨の審査まで、あと265日。蔵の数字を読めるようになるには、2級の範囲がそのまま必要だった。
2級の論点は、澪の1年に沿って、3つの部に分かれる。

## この本の歩き方 ― 事件、解決編、考えてみよう

各章は、蔵で起きる1つの事件から始まる。澪は帳面を開き、仕訳を切り、手がかりを集める。答えは、章の後半の**解決編**で明かされる。物語の中で登場人物が持ち込む実際の事件は、その章の仕訳で読み解く。
章の終わりの**考えてみよう**は、蔵が実際に迷いそうな場面で、どう見積もり、どう考え、何で確かめるかを問う発展問題だ。試験には出ないので、余力があるときや2周目に取り組んでほしい。
章の扉には**融資審査までの残り日数**がある。父の黒い手帳の行は、2級の知識がそろうたびに、1行ずつ読めるようになる。各章の最後には**次回予告**がある。

::cfo 年明けまでに出す生産計画 ― 来期の造りを、どう変えるか
11月、高梨から電話が来た。「年明けまでに、来期の生産計画を出してください。それを見て、借換えを判断します」。今年の造りはもう始まっているが、来期の仕込みの配分は、まだ変えられる。
**前提**
- 作業時間で配った1本の儲けは、普通酒320円、純米吟醸640円、大吟醸△300円
- 1本の作業時間は、普通酒0.1時間、純米吟醸0.25時間、大吟醸1.45時間。蔵人の作業時間は年12万6,000時間で、来期も増やせない
- 純米吟醸は、あと6万本までなら売れる見込み。普通酒は地元の需要が頭打ちで、増やしても売れない
- 大吟醸は3年続けて金賞を取り、純米吟醸を売るときの「看板」になっている
- 大吟醸の出荷価格は1本3,500円で、毎年すぐに売り切れる
::choice A. 金賞の看板を太くするため、大吟醸を倍の6万本に増やす
**× 帳面の錯覚を、さらに大きくする。**作業時間で配ると大吟醸は1本300円の損で、3万本増やせば損が900万円増える。しかも3万本×1.45時間＝4万3,500時間を新たに使い、そのぶん稼ぎの大きい酒を造る手間が消える。
::
::choice B. 大吟醸を1万本減らし、空いた手間で純米吟醸を増やす
**◎ 増やせない手間を、稼ぎの大きい酒に回している。**大吟醸1万本で1万4,500時間が空き、純米吟醸なら5万8,000本（1万4,500÷0.25）造れる。売れる見込みの6万本に収まる。大吟醸の損300万円が消え、純米吟醸の儲けが640円×5万8,000本＝3,712万円増えて、合わせて**約4,000万円**の改善になる。
::
::choice C. 大吟醸をやめ、空いた手間で普通酒を増やす
**△ 赤字は消えるが、空いた手間の行き先がない。**普通酒は地元の需要が頭打ちで、増やしても売れない。看板の大吟醸を失えば、純米吟醸の売れ行きにも響く。
::
::choice D. 本数は変えず、大吟醸だけを1本300円値上げする
**○ 赤字は消えるが、手間の使い方は変わらない。**3万本×300円＝900万円の改善で、毎年売り切れる酒なら値上げは通るかもしれない。だが、手間を最も稼がない酒に使い続ける形は残る。Bと組み合わせられる手だ。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「どの酒が儲かるか」ではなく、「増やせない作業時間を、どの酒に使うと蔵全体がいちばん稼ぐか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 作業1時間あたりの儲け
| 酒 | 1本の儲け | 1本の時間 | 1時間あたり |
| 普通酒 | 320円 | 0.1時間 | 3,200円 |
| 純米吟醸 | 640円 | 0.25時間 | 2,560円 |
| 大吟醸 | △300円 | 1.45時間 | 約△207円 |
::
普通酒は1時間あたりの稼ぎが最も大きいが、売れる量に限りがある。次に大きい純米吟醸には、あと6万本の余地がある。だから、大吟醸の手間を純米吟醸に回すBが、最も大きく稼ぐ。
#### 手順3　ほかの答えに引かれる理由
Aは「金賞の酒は儲かる」という直感に、Cは「赤字の酒はやめればいい」という分かりやすさに引かれる。Dは手堅く見えるが、手間の配り方という本当の問題に手をつけていない。
#### 持ち帰る考え方
- **限られた資源あたりで比べる**：1本の儲けではなく、作業時間1時間あたりの儲けで並べる
- **売れる量の上限を確かめる**：1時間あたりの稼ぎが大きくても、売れなければ意味がない
#### 前提が変われば
蔵人をもう1人雇えて作業時間を増やせるなら、大吟醸を減らさずに純米吟醸を増やす道もある。そのときは、増える賃金と、増える儲けを比べることになる。
::
::

::exam 2級の合否を分けるもの
- **工業簿記で得点を固める**：工業簿記（一般に40点）は手順の型を覚えれば安定して高得点を取れる。第1部を何度も解き直そう
- **商業簿記は仕訳から**：第1問の仕訳は、ほぼすべての論点から出る。第2部・第3部の仕訳を、確実に切れるようにする
- **連結会計は避けて通れない**：第2問・第3問で連結精算表や連結財務諸表がよく問われる。第3部で手順を1つずつ確かめる
- **配賦の物差しを疑う**：製造間接費・部門費・等級別の問題は、すべて「何を基準に配るか」の問題だ
::

::summary 序章のまとめ
- 製品を作る会社では、製品1つを作るのにいくらかかったか（原価）を計算する工業簿記が必要になる
- 複数の製品に共通する費用を製品に割り振ることを配賦といい、物差し（配賦基準）しだいで製品ごとの損得が逆転する
- 会社全体の利益は配り方で変わらないが、どの製品を増やすかの判断は、配り方で正反対になる
- 損益計算書の赤字は、どの段で何が原因で生じたかによって意味が違う
- 2級は90分、商業簿記と工業簿記の5題以内、70%以上で合格。本書は2027年度適用の出題区分表に準拠する
::

::quiz
::problem 次の勘定科目を、主に商業簿記で使うものと、2級の工業簿記で使うものに分けなさい。
::sort
@cats 商業簿記 | 工業簿記
仕入 => 商業簿記
繰越商品 => 商業簿記
仕掛品 => 工業簿記

::answer
仕入・繰越商品は、商品を仕入れて売る商業簿記の勘定。材料・賃金・給料・製造間接費・仕掛品は、製品を作る活動を記録する工業簿記の勘定だ（第1章）。売上・売上原価は両方で使う。

::problem ある蔵の共通費（給料・燃料など）は年1,200万円で、A酒とB酒に配る。A酒は年10万本・作業時間2,000時間、B酒は年2万本・作業時間4,000時間である。
本数で配ると、B酒1本あたりの共通費は[[100]]円。作業時間で配ると、B酒1本あたりの共通費は[[400]]円になる。
::answer
本数で配る：1,200万円÷12万本＝1本100円。どちらの酒も100円ずつ。
作業時間で配る：1,200万円÷6,000時間＝1時間2,000円。B酒は4,000時間×2,000円＝800万円を2万本で割って、1本400円。A酒は2,000時間×2,000円＝400万円÷10万本＝1本40円。
手間のかかるB酒は、本数で配ると共通費を4分の1しか背負わない。序章の大吟醸と同じ構図だ。
::
::
::problem 損益計算書の「赤字」について、正しいものを1つ選び、記号で答えなさい。
ア. 当期純損失が出ている会社は、本業でも必ず損をしている
イ. 評価の上だけの損失は、損益計算書には載らない
ウ. 当期純損失が大きくても、営業利益が黒字のことがある
エ. 研究のための支出は資産になるので、赤字の原因にはならない
正しいもの：[[ウ]]
<!-- choices: ア | イ | エ -->
::answer
正解は**ウ**。
営業利益（本業の損益）と当期純利益の間には、利息・評価の損益・臨時の損益・税金が入る。営業利益が黒字でも、評価の損失や臨時の損失で当期純損失になることはある。評価の上だけの損失も、ルールに従って損益計算書に載る。研究のための支出（研究開発費）は、発生した年の費用になる（第17章）。
