::mystery 同じ4万ドルが、3つの円になる
6月1日、火曜日。新潟港から、ニューヨーク行きのコンテナが出た。マーカス・リーの会社への、純米吟醸「汐路」とスパークリングの初めての大口の出荷だ。代金は**4万ドル**、支払いは8月末。この日の為替相場は1ドル**150円**。売上は600万円になった。
6月30日、決算日。円安が進み、相場は1ドル**155円**。売掛金の4万ドルは、円にすると620万円だ。椎名は「売掛金を620万円に直して、差額の20万円を為替差益にしてください」と言った。
ところが、8月31日の入金の日、相場は1ドル**148円**に戻っていた。手元に入ったのは**592万円**。決算で計上した為替差益20万円は、いったい何だったのか。
商社で鉄鋼を売っていたころ、澪はドルの数字しか見ていなかった。円の帳簿の中では、同じ4万ドルが、600万円にも、620万円にも、592万円にもなる。
**円安の利益は、本物だったのか？**
::

## 外貨建取引 ― ドルで決めた取引を、円の帳簿に記録する

取引の金額を外国の通貨で決める取引を、**外貨建取引**という。日本の会社の帳簿は円で記録するので、ドルの金額を、どの日の為替相場で円に直すか（**換算**）が問題になる。

::theory 外貨建取引の換算の3つの場面
1. **取引発生時**：取引が起きた日の為替相場（**取引日レート**、HR）で換算する
2. **決算時**：外貨建の**貨幣項目**（現金・預金・売掛金・買掛金・貸付金・借入金など、将来お金で受け取ったり払ったりするもの）は、**決算日の為替相場**（**決算日レート**、CR）で換算し直す。差額は**為替差損益**
3. **決済時**：実際に受け取ったり払ったりした円の金額と、帳簿の金額との差額を、**為替差損益**とする
前受金・前払金や棚卸資産など、お金で決済しない**非貨幣項目**は、決算時に換算し直さない（取引日レートのまま）。
::

::example マーカス・リーへの輸出を仕訳しなさい（決算日は6月30日）
(1) 6月1日、4万ドルの酒を船積みし、代金は8月31日に受け取ることにした（輸出の売上は船積みの日に計上する）。相場は1ドル150円。
(2) 6月30日、決算。相場は1ドル155円。
(3) 8月31日、4万ドルが普通預金に入金された。相場は1ドル148円。
::answer
::journal (1) 取引日レートで換算：40,000ドル×150円
売掛金 6,000,000 | 売上 6,000,000
::
::journal (2) 売掛金を決算日レートで換算し直す：40,000ドル×155円＝6,200,000円
売掛金 200,000 | 為替差損益 200,000
::
::journal (3) 決済：40,000ドル×148円＝5,920,000円。帳簿の6,200,000円との差
普通預金 5,920,000 | 売掛金 6,200,000
為替差損益 280,000 |
::
**売上**は、取引の日に600万円で決まり、その後は動かない。動くのは、まだ受け取っていない**売掛金**の円の価値だけだ。為替差損益は、損益計算書の営業外損益に表示する。
::
::

## 答え合わせ ― 売上は600万円、円安の利益は「途中経過」

::solve 売上は取引の日に決まる。為替の変動は、売上とは別の「為替差損益」
4万ドルの酒の**売上**は、船積みの日の600万円だ。決算でも入金でも、売上は変わらない。
決算日の為替差益20万円は、まだ受け取っていない4万ドルを、その日の相場で測り直した**途中経過**の利益だった。8月31日には相場が戻り、28万円の為替差損が出た。2つの期を通して見ると、為替の変動による損益は、20万円－28万円＝**8万円の損**。600万円で売った酒の代金を、592万円で受け取った。
円安の利益は、ドルを円に換えるまでは確定しない。決算書の為替差益は、決算日の相場で測った「その時点の値打ち」の変化にすぎない。
::

「商社にいたころは、為替は財務部の仕事でした」と澪は言った。「売上はドルで立てて、それで終わり。円に直したときに増えたり減ったりするのは、自分の成績とは別の話だと思っていました」
「蔵にとっては、別の話ではありません」と椎名は言った。「8万円の為替差損は、その輸出の儲けから直接引かれます。ドルで売るなら、為替も商売の一部です」

## 前受金と前払金 ― 換算し直さないもの

ニューヨークへの2回目の出荷は、マーカスが代金の一部を先に払ってくれた。

::example 前受金を受け取った輸出を仕訳しなさい
(1) 7月10日、マーカスから、次の注文の代金の一部として1万ドルを前受けし、普通預金に入金された。相場は1ドル152円。
(2) 8月1日、3万ドルの酒を船積みした。前受けした1万ドルを差し引いた2万ドルは、9月末に受け取る。相場は1ドル149円。
::answer
::journal (1) 前受金は取引日レートで記録し、その後は換算し直さない
普通預金 1,520,000 | 前受金 1,520,000
::
::journal (2) 売上は、前受金の分は前受けの日のレート、残りは船積みの日のレートで計上する
前受金 1,520,000 | 売上 4,500,000
売掛金 2,980,000 |
::
前受けした1万ドルは、すでに円で受け取っていて、将来ドルで受け取るものではない。だから為替の変動の影響を受けず、前受けした日の152円のまま売上に振り替える。残りの2万ドルは船積みの日の149円で売掛金にする。売上は1,520,000円＋2,980,000円＝4,500,000円。
::
::

輸入でも同じだ。スパークリングの耐圧瓶は、イタリアのメーカーから輸入している。先に払った**前払金**は換算し直さず、後で払う**買掛金**は、決算日に決算日レートで換算し直す。

## 為替予約 ― 将来の相場を、今決めておく

8月の為替差損を見た澪は、3回目の出荷では、為替の変動を避ける手を打つことにした。銀行と**為替予約**を結ぶのだ。

::theory 為替予約と振当処理
**為替予約**は、将来の決められた日に、決められた相場（**予約レート**、先物の相場）で外貨と円を交換する約束を、銀行と結ぶことだ。予約をすれば、その後に相場がどう動いても、受け取る円の金額は変わらない。
2級では、予約レートで外貨建の債権・債務を換算する**振当処理**を学ぶ。
- **取引の前**（または同時）に予約したとき：取引を**予約レート**で記録する。決算日にも換算し直さず、為替差損益は生じない
- **取引の後**に予約したとき：予約した日に、売掛金・買掛金を予約レートに直し、差額を**為替差損益**とする（2級では、この差額を期間に配分しない）
::

::example 為替予約をした輸出を仕訳しなさい
(1) 取引の前に予約：10月1日、5万ドルの輸出の契約と同時に、12月25日を期日として1ドル151円で売りの為替予約を結んだ。10月5日に船積みした（直物相場は1ドル153円）。
(2) 取引の後に予約：11月1日、2万ドルの酒を船積みした（相場は1ドル150円、代金は1月末に受取り）。11月15日、1ドル152円で売りの為替予約を結んだ（11月15日の直物相場は1ドル153円）。
::answer
::journal (1) 予約レートで売上と売掛金を記録する：50,000ドル×151円
売掛金 7,550,000 | 売上 7,550,000
::
::journal (2-a) 11月1日：取引日レートで記録：20,000ドル×150円
売掛金 3,000,000 | 売上 3,000,000
::
::journal (2-b) 11月15日：予約レートに直す：20,000ドル×(152円－150円)
売掛金 40,000 | 為替差損益 40,000
::
(1)は、船積みの日の直物相場153円ではなく、予約レート151円で記録する。その後、決算や入金の日に相場が動いても、売掛金は7,550,000円のままで、為替差損益は出ない。
(2)は、取引の時点では予約がなかったので、まず取引日レートで売上を記録し、予約した日に売掛金を予約レートの3,040,000円に直す。売上の3,000,000円は動かさない。
::
::

::exam 外貨建取引の急所
- 取引時は**取引日レート**、決算時は**貨幣項目だけ決算日レート**、決済時は実際の円の金額。差額はすべて**為替差損益**（営業外損益）
- 換算し直す（貨幣項目）：外貨の現金・預金、売掛金・買掛金、未収入金・未払金、貸付金・借入金
- 換算し直さない（非貨幣項目）：**前受金・前払金**、棚卸資産、有形固定資産
- 前受金がある売上は、前受金の部分は**前受けの日のレート**、残りは取引の日のレートで計上する
- 為替予約（振当処理）：取引前の予約なら取引を予約レートで記録、取引後の予約なら予約日に予約レートへ修正（差額は為替差損益、期間配分しない）
- 為替差損益の勘定は1つで、貸借の差額で差益か差損かを判断する。損益計算書には純額で為替差益または為替差損と表示する
::

## マーカスのビデオ会議 ― 日本酒の輸出459億円、円安は追い風か

::scene 6月の第3水曜日、夜 ― 蔵の事務所（ニューヨークとのビデオ会議）
ニューヨークの朝、画面の向こうのマーカス・リーは上機嫌だった。
「ミオ、日本酒は、いまアメリカでいちばん勢いのある輸入酒の1つだ。2025年には、日本酒の輸出先が過去最多の81の国と地域に広がった。それに、円安だ。君たちにとっては、何もしなくても売上が増える追い風だろう？」
澪は、すぐには答えなかった。商社で鉄鋼を売っていたころ、円安の年の「売上の伸び」の半分は、為替の数字の手品だと先輩に教えられたことがある。
::

日本酒造組合中央会によると、2025年の日本酒の輸出額は**約459億円**（前年比約106%）、数量は約3.35万キロリットル（前年比約108%）だった。輸出先の国・地域は81と、過去最多になった。金額は過去最高だった年に次ぐ水準で、国内の出荷量が減り続ける中で、海外は蔵の数少ない成長の舞台になっている（序章）。
会議の後、澪は、マーカスの言う「何もしなくても売上が増える」を、この章の換算の考え方で確かめた。仮に、ある蔵が毎年同じ10万ドル分の酒をアメリカに売ったとすると（仕組みを示すための例）、

::table 毎年10万ドルの輸出を、円で記録すると
| 為替相場 | 円の売上 |
| 1ドル110円 | 1,100万円 |
| 1ドル130円 | 1,300万円 |
| 1ドル150円 | 1,500万円 |
::
::journal 1ドル150円の年：100,000ドル×150円
売掛金 15,000,000 | 売上 15,000,000
::

ドルで見れば、売上は1円も増えていない。それでも、円の帳簿の売上は、1ドル110円の年より36%多く記録される。円安は、輸出する蔵の円の売上を押し上げる。逆に、円高に振れれば、同じ量を売っても円の売上は減る。
だから、輸出の成長を読むときは、円の金額だけでなく、**数量**と**現地の通貨での金額**を見る。日本酒の輸出も、2025年は金額（約106%）より数量（約108%）の伸びのほうが大きかった。1リットルあたりの平均単価は下がっていた計算になる。
翌朝、澪はマーカスにメールを書いた。「追い風は、ありがたく受けます。でも、私たちの成長は、ドルの本数で測ります。そして、風向きが変わっても困らないように、為替の手当てを考えます」。マーカスの返信は1行だった。「君は、商社の人間の顔をしているね」

::note
出典：[日本酒造組合中央会のプレスリリース（Business Wire、2026年2月5日、2025年の日本酒の輸出実績）](https://www.businesswire.com/news/home/20260205539233/ja)、[nippon.com「日本酒の輸出」（Japan Data）](https://www.nippon.com/ja/japan-data/h02706/)
::

::cfo 3回目の出荷 ― 為替予約を結ぶか
6月の決算の直前、マーカスから次の注文が届いた。8万ドル、代金は9月末に受取り。蔵にとっては、来期の利益を左右する大きさだ。
::table 判断の材料（いまは6月25日）
| 項目 | 内容 |
| 注文の額 | 8万ドル（船積みは7月20日、受取りは9月30日） |
| 今日の直物相場 | 1ドル154円 |
| 9月30日を期日とする予約レート | 1ドル152円 |
| 相場の見通し | 銀行のアナリストの予想は1ドル140円から165円まで幅がある |
| この輸出の、円で見た儲け（予約レートで計算した場合） | 約300万円 |
| 蔵の資金繰り | 9月末の酒税と借入金の返済に、この入金を充てる予定 |
::
まず、9月30日の相場が140円になった場合と165円になった場合に、予約をする・しないで受け取る円の金額がいくら違うかを計算してから選んでほしい。
::choice A. 予約しない。円安が続いている。相場が上がれば、為替差益が出る
**× 酒蔵が、為替の賭けをすることになる。**165円なら1,320万円を受け取れるが、140円なら1,120万円。予約した場合の1,216万円（8万ドル×152円）と比べて、上に104万円、下に96万円の幅がある。この輸出の儲けは約300万円だから、円高に振れれば、その3分の1近くが消える。しかも、9月末の入金は酒税と返済に充てる予定のお金だ。読みが外れたときに困る相場の賭けは、本業ではない。
::
::choice B. 全額を予約する。受け取る円の金額を、1,216万円で確定させる
**◎ 本業の儲けを守り、資金繰りを確かにする。**予約すれば、相場が140円になっても165円になっても、受け取るのは8万ドル×152円＝**1,216万円**。今日の直物の154円より16万円少ないが、これは「確実さの値段」だ。9月末に払うべきお金の計画が立てられる。
仕訳は、取引の前に予約するので、7月20日の船積みの日に「売掛金 12,160,000／売上 12,160,000」。入金の日にも、為替差損益は出ない。
::
::choice C. 半分の4万ドルだけ予約する。上がっても下がっても、半分は得をする
**○ 考え方としては成り立つが、何のために半分なのかを決める必要がある。**半分を予約すれば、140円でも165円でも、受け取る額の幅は半分（上に52万円、下に48万円）になる。円安の利益を一部残したいなら合理的だ。ただ、9月末の酒税と返済にいくら確実に必要かから逆算して、予約する割合を決めるのが筋だ。「なんとなく半分」は、半分の賭けにすぎない。
::
::choice D. 入金されたドルを円に換えず、ドルの預金で持っておく。円安になったら換える
**× 賭けの期間を延ばしているだけだ。**ドルの預金も外貨建の貨幣項目で、決算のたびに換算し直され、為替差損益が出る。円が必要な9月末に、相場がたまたま円高なら、不利な相場で換えるしかない。必要なのは円なのに、円にする日を相場の読みで決めるのは、Aと同じ賭けだ。
::
::answer 考え方の例を見る
為替予約は、相場で儲けるための道具ではなく、**本業の儲けを相場の変動から守る**道具だ。予約をすれば、相場が有利に動いたときの利益もあきらめることになる。その代わりに、受け取る円の金額が確定し、儲けと資金繰りの計画が立つ。輸出の儲けに比べて、為替の振れ幅がどれだけ大きいかを数字で確かめれば、予約すべきかどうかは自ずと見えてくる。
澪は、8万ドルの全額に為替予約を結んだ。商社時代の財務部の先輩に電話で相談すると、先輩は笑った。「お前が予約の相談をしてくるとはな。蔵の社長の顔になってきたじゃないか」
::
::

::next 外貨建取引の先にある論点
1級では、為替予約の差額を期間に配分する方法（直先差額の期間配分）、ヘッジ会計（繰延ヘッジ）、外貨建の有価証券の換算、在外支店や在外子会社の財務諸表の換算（為替換算調整勘定）などを学ぶ。海外に子会社を持つ会社の連結財務諸表では、為替の変動が純資産を大きく動かす。
::

::problem 3月1日に商品10,000ドルを掛けで販売した（相場は1ドル140円）。3月15日に、1ドル143円で売りの為替予約を結んだ（振当処理）。3月15日の仕訳をしなさい。また、決算日（3月31日、相場は1ドル145円）に必要な仕訳はあるか答えなさい。
決算日の仕訳 [[不要]]
<!-- choices: 不要 | 必要 -->
::answer
::journal 3月15日：10,000ドル×(143円－140円)
売掛金 30,000 | 為替差損益 30,000
::
為替予約によって、売掛金は予約レートの1,430,000円で確定している。決算日の相場が145円でも、換算し直さないので、決算日の仕訳は**不要**。
::

::summary
- 外貨建取引は、取引日レートで円に換算して記録する。売上・仕入は、その後の相場の変動で変わらない
- 決算時は、貨幣項目（売掛金・買掛金・外貨預金・借入金など）だけを決算日レートで換算し直し、差額を為替差損益とする。前受金・前払金・棚卸資産は換算し直さない
- 決済時の円の金額と帳簿の金額の差も為替差損益
- 為替予約（振当処理）：取引前の予約は予約レートで記録、取引後の予約は予約日に予約レートへ修正し、差額は為替差損益（2級では期間配分しない）
- 決算の為替差損益は、決算日の相場で測った途中経過。円の売上の増減には、量と値段の変化と、為替の変化が混ざっている
::
