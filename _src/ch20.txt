## ドルで決めた取引を、円の帳簿に ― 3つの日の換算

商社で鉄鋼を売っていたころ、澪は売上をドルで立てていた。円に直したときに増えたり減ったりするのは、財務部の仕事だった。蔵の帳簿は、円しかない。

::theory 外貨建取引の換算の3つの場面
取引の金額を外国の通貨で決める取引を**外貨建取引**という。円の帳簿に記録するには、どの日の為替相場で円に直すか（**換算**）を決める。
1. **取引の日**：取引が起きた日の為替相場（**取引日レート**）で換算する
2. **決算の日**：外貨建の**貨幣項目**（外貨の現金・預金、売掛金・買掛金など、将来お金で受け取ったり払ったりするもの）は、**決算日の為替相場**（**決算日レート**）で換算し直す。差額は**為替差損益**
3. **決済の日**：実際に受け取ったり払ったりした円の金額と、帳簿の金額との差額を、**為替差損益**とする
::

::example マーカス・リーへの輸出を仕訳する（決算日は6月30日）
(1) 6月1日、4万ドルの酒を船積みし、代金は8月31日に受け取ることにした（輸出の売上は船積みの日に計上する）。相場は1ドル150円。
(2) 6月30日、決算。相場は1ドル155円。
(3) 仮に、8月31日の入金の日の相場が1ドル148円だったとする。4万ドルが普通預金に入金された。
::answer
::journal (1) 取引日レートで換算：40,000ドル×150円
売掛金 6,000,000 | 売上 6,000,000
::
::journal (2) 売掛金を決算日レートで換算し直す：40,000ドル×155円＝6,200,000円
売掛金 200,000 | 為替差損益 200,000
::
::journal (3) 決済：40,000ドル×148円＝5,920,000円。帳簿の6,200,000円との差
普通預金 5,920,000 | 売掛金 6,200,000
為替差損益 280,000 |
::
**売上**は、取引の日に600万円で決まり、その後は動かない。動くのは、まだ受け取っていない**売掛金**の円の値打ちだけだ。為替差損益は、損益計算書の営業外損益に表示する。
::trap
決算日に、売上を決算日レートで換算し直さないこと。換算し直すのは、まだ決済していない売掛金などの貨幣項目だけだ。
::
::
::

## 換算し直すもの、し直さないもの ― 貨幣項目と非貨幣項目

澪：「先に代金の一部を受け取っていたら、どうなりますか？」
椎名：「前受金は、もうお金を受け取り終えています。将来ドルで受け取るものではないので、相場が動いても、値打ちは変わりません」
前受金・前払金や、棚卸資産・有形固定資産のように、将来お金で決済しないものを**非貨幣項目**という。非貨幣項目は、決算日に換算し直さない。取引の日のレートのままにしておく。

::example 前受金を受け取った輸出を仕訳する
(1) ある輸出の取引で、注文の代金の一部として1万ドルを前受けし、普通預金に入金された。相場は1ドル152円。
(2) 3万ドルの酒を船積みした。前受けした1万ドルを差し引いた2万ドルは、あとで受け取る。相場は1ドル149円。
::answer
::journal (1) 前受金は、前受けの日のレートで記録し、その後は換算し直さない
普通預金 1,520,000 | 前受金 1,520,000
::
::journal (2) 売上は、前受金の分は前受けの日のレート、残りは船積みの日のレートで計上する
前受金 1,520,000 | 売上 4,500,000
売掛金 2,980,000 |
::
前受けした1万ドルは152円のまま売上に振り替え、残りの2万ドルは船積みの日の149円で売掛金にする。売上は1,520,000円＋2,980,000円＝4,500,000円。輸入でも同じで、先に払った**前払金**は換算し直さず、あとで払う**買掛金**は、決算日に決算日レートで換算し直す。
::trap
売上の全額を、船積みの日のレート（3万ドル×149円＝4,470,000円）で計上しないこと。前受金の分は、前受けの日のレートで決まっている。
::
::
::

## 為替予約 ― 将来の相場を、今決めておく

商社の財務部は、毎日のように**為替予約**を結んでいた。澪も、その言葉は知っていた。知らなかったのは、それを帳簿にどう書くかだった。

::theory 為替予約と振当処理
**為替予約**は、将来の決められた日に、決められた相場（**予約レート**）で外貨と円を交換する約束を、銀行と結ぶことだ。予約をすれば、その後に相場がどう動いても、受け取る円の額は変わらない。
2級では、外貨建の売掛金・買掛金を予約レートで換算する**振当処理**を学ぶ。
- **取引の前（または同時）に予約したとき**：取引を**予約レート**で記録する。決算日にも換算し直さず、為替差損益は出ない
- **取引の後に予約したとき**：予約した日に、売掛金・買掛金を予約レートに直し、差額を**為替差損益**とする（2級では、この差額を期間に配分しない）
::

::example 為替予約をした輸出を仕訳する
(1) 取引の前に予約：5万ドルの輸出の契約と同時に、1ドル151円で売りの為替予約を結んだ。その後、船積みした（船積みの日の相場は1ドル153円）。
(2) 取引の後に予約：2万ドルの酒を船積みした（相場は1ドル150円、代金はあとで受取り）。その2週間後、1ドル152円で売りの為替予約を結んだ（その日の相場は1ドル153円）。
::answer
::journal (1) 予約レートで売上と売掛金を記録する：50,000ドル×151円
売掛金 7,550,000 | 売上 7,550,000
::
::journal (2-a) 船積みの日：取引日レートで記録する：20,000ドル×150円
売掛金 3,000,000 | 売上 3,000,000
::
::journal (2-b) 予約の日：売掛金を予約レートに直す：20,000ドル×(152円－150円)
売掛金 40,000 | 為替差損益 40,000
::
(1)は、船積みの日の相場153円ではなく、予約レート151円で記録する。その後、決算や入金の日に相場が動いても、売掛金は7,550,000円のままで、為替差損益は出ない。
(2)は、まず取引日レートで売上を記録し、予約した日に売掛金を予約レートの3,040,000円に直す。売上の3,000,000円は動かさない。
::trap
(2)で、予約の日の相場153円を使わないこと。売掛金を直す先は、予約レートの152円だ。
::
::
::

その日の午後、澪は、6月30日の決算整理の仕訳を1本だけ書いた。売上には、手を付けなかった。

::solve 売上は、船積みの日の600万円で決まり、動かない。円安の20万円は、売上ではなく為替差益という「途中経過」
4万ドルの酒の**売上**は、船積みの日の600万円だ。決算の日にも入金の日にも、売上は動かない。
6月30日の20万円は、まだ受け取っていない4万ドルの**売掛金**を、その日の相場で測り直した差額で、**為替差益**（営業外収益）になる。ドルを円に換えるまでは、確定していない。
もし8月31日の相場が1ドル148円に戻れば、入金は592万円で、28万円の為替差損が出る。2つの期を通して見ると、20万円－28万円＝**8万円の損**。600万円で売った酒の代金を、592万円で受け取ることになる。
**円安の儲けは、ドルが円になるまでは、途中経過にすぎない。**決算書の為替差益は、決算日の相場で測った、その日の値打ちの変化だ。
::

### 試験で狙われるパターン ― 換算する・しない、前受金、予約の前後

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 決算日に換算し直すかどうか**　外貨の預金・売掛金・買掛金・未収入金・未払金は換算し直す。前受金・前払金・棚卸資産・有形固定資産は換算し直さない。

**② 前受金・前払金がある取引**　売上（仕入）は、前受け（前払い）の分は前受け（前払い）の日のレート、残りは取引の日のレート。

**③ 為替予約の前後**　取引の前の予約なら、取引を予約レートで記録して終わり。取引の後の予約なら、予約の日に売掛金・買掛金を予約レートに直し、差額を為替差損益に。予約した債権・債務は、決算日に換算し直さない。

**④ 為替差損益の表示**　為替差損益の勘定は1つで、1年の合計が貸方なら為替差益（営業外収益）、借方なら為替差損（営業外費用）と、純額で表示する。

::steps 解法の型 ― 外貨建取引
1. 取引の日 | 取引日レートで売上・仕入と売掛金・買掛金を記録（前受金・前払金の分は、その日のレート）
2. 予約があるか | 取引の前なら予約レートで記録。取引の後なら、予約の日に予約レートへ直し、差額は為替差損益
3. 決算の日 | 予約のない貨幣項目だけ決算日レートに直し、差額は為替差損益
4. 決済の日 | 受け取った（払った）円と帳簿の額の差を為替差損益に
5. 表示 | 為替差損益を純額にして、営業外収益か営業外費用へ
::

## ニューヨークとの通話 ― 日本酒の輸出459億円、円安は追い風か

::scene 6月30日、夜10時 ― ニューヨークとのビデオ通話
ニューヨークは朝の9時。画面の向こうのマーカス・リーは上機嫌だった。
マーカス：「ミオ、日本酒は、いまアメリカでいちばん勢いのある輸入酒の1つだ。去年、日本酒の輸出先は、過去最多の81の国と地域に広がった。それに、円安だ。君たちにとっては、何もしなくても売上が増える追い風だろう？」
澪は、すぐには答えなかった。商社のころ、円安の年の「売上の伸び」の半分は為替の手品だと、財務部の先輩に教えられたことがある。
マーカス：「ケンゾウさんは、試飲会で言ったよ。『うちの酒は、ドルで値打ちが決まる酒にしたい』と」
::

日本酒造組合中央会によると、2025年の日本酒の輸出額は**約459億円**（前年比約106%）、数量は約3.35万キロリットル（前年比約108%）だった。輸出先の国・地域は81と、過去最多になった。国内の出荷量が減り続ける中で、海外は、蔵の数少ない成長の舞台になっている。
通話の後、澪は、マーカスの「何もしなくても売上が増える」を、この章の換算で確かめた。仮に、ある蔵が毎年同じ10万ドル分の酒をアメリカに売ったとする（仕組みを示すための例）。

::table 毎年10万ドルの輸出を、円で記録すると
| 為替相場 | 円の売上 |
| 1ドル110円 | 1,100万円 |
| 1ドル130円 | 1,300万円 |
| 1ドル150円 | 1,500万円 |
::

::journal 1ドル150円の年：100,000ドル×150円
売掛金 15,000,000 | 売上 15,000,000
::

ドルで見れば、売上は1ドルも増えていない。それでも、1ドル150円の年の円の売上は、110円の年より36%多く記録される。円安は輸出する蔵の円の売上を押し上げ、円高は押し下げる。
だから、輸出の成長を読むときは、円の金額だけでなく、**数量**と**現地の通貨での金額**を見る。2025年の日本酒の輸出も、金額（約106%）より数量（約108%）のほうが大きく伸びていた。1リットルあたりの平均の単価は、下がっていた計算になる。
翌朝、澪はマーカスにメールを書いた。「追い風は、ありがたく受けます。でも、私たちの成長は、ドルと本数で測ります。そして、風向きが変わっても困らないように、為替の手当てを考えます」。マーカスの返信は1行だった。「君は、ケンゾウさんと同じことを言う」。

::note
出典：[日本酒造組合中央会のプレスリリース（Business Wire、2026年2月5日、2025年の日本酒の輸出実績）](https://www.businesswire.com/news/home/20260205539233/ja)、[nippon.com「日本酒の輸出」（Japan Data）](https://www.nippon.com/ja/japan-data/h02706/)
::

::danger 為替で膨らんだ売上を、成長と呼ぶ
円安の年は、海外の売上が円で大きく見える。本数もドルの金額も増えていないのに「売上が過去最高」と説明すれば、読む人は事業の力を見誤る。海外の売上の伸びを説明するときは、為替の影響を除いた伸び（前の年と同じ相場で換算した伸び）も並べて示す。
::

::cfo マーカスの次の注文 ― 為替予約を結ぶか
通話の最後に、マーカスは次の注文を出した。8万ドル。蔵にとっては、来期の利益を左右する大きさだ。
**前提**
- 船積みは7月20日、代金の受取りは9月30日（ドルで受け取る）
- 今日（6月30日）の相場は1ドル155円。9月30日を期日とする予約レートは1ドル153円
- 信用金庫の予想では、9月30日の相場は1ドル140円から165円まで幅がある
- この輸出の儲けは、予約レートで計算して約300万円
- 9月末の入金は、酒税と借入金の返済に充てる予定
- マーカスの店では、汐路が1本45ドルで売られている
::choice A. 8万ドルの全額を予約し、受け取る円を1,224万円で確定させる
**◎ 本業の儲けを守り、資金繰りを確かにする。**相場が140円でも165円でも、受け取るのは8万ドル×153円＝1,224万円。今日の相場155円より16万円少ないが、それは「確実さの値段」だ。取引の前の予約なので、7月20日に「売掛金 12,240,000／売上 12,240,000」と記録し、入金の日にも為替差損益は出ない。
::
::choice B. 半分の4万ドルだけを予約し、残りは相場に任せる
**○ 成り立つが、なぜ半分なのかを決める必要がある。**受け取る額の幅は、140円なら1,172万円、165円なら1,272万円と、予約しない場合の半分になる。円安の利益を一部残したいなら合理的だが、9月末に確実に要る額から逆算して、予約する割合を決めるのが筋だ。
::
::choice C. 予約しない。円安が続いているので、為替差益が期待できる
**× 酒蔵が、為替の賭けをすることになる。**165円なら1,320万円だが、140円なら1,120万円。予約した場合と比べて、上に96万円、下に104万円の幅がある。この輸出の儲けは約300万円だから、円高に振れれば、その3分の1が消える。しかも、入金は酒税と返済に充てるお金だ。
::
::choice D. 入金されたドルを円に換えずに持ち、円安になったら換える
**× 賭けの期間を延ばしているだけだ。**外貨の預金も貨幣項目で、決算のたびに換算し直され、為替差損益が出る。円が要る9月末に相場が円高なら、不利な相場で換えるしかない。必要なのは円なのに、換える日を相場の読みで決めるのは、Cと同じ賭けだ。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「円安で儲けられるか」ではなく、「9月30日に、酒税と返済に充てる円が、確実にいくら入るか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 9月30日に受け取る円（単位：万円）
| 9月30日の相場 | 予約しない | 半分を予約 | 全額を予約 |
| 1ドル140円 | 1,120 | 1,172 | 1,224 |
| 1ドル165円 | 1,320 | 1,272 | 1,224 |
| 上と下の幅 | 200 | 100 | 0 |
::
予約しなければ、受け取る円は200万円の幅で揺れる。この輸出の儲け約300万円の、3分の2にあたる幅だ。
#### 手順3　ほかの答えに引かれる理由
Cは「円安が続いている」という今の空気に、Dは「ドルのまま持てば損は確定しない」という思い込みに、Bは「半分なら外れても痛くない」という安心に引かれる。汐路がニューヨークで1本45ドルで売られていることは、予約するかどうかとは関係のない前提だ。
#### 持ち帰る考え方
- **為替予約は、相場で儲ける道具ではなく、本業の儲けを相場から守る道具**：有利に動いたときの利益をあきらめる代わりに、受け取る円が決まる
- **振れ幅を、儲けと資金繰りに比べる**：振れ幅が儲けに比べて大きく、入金の使い道が決まっているほど、予約する理由は強い
#### 前提が変われば
9月末の入金を急いで使う予定がなく、円高に振れても儲けが残るほど利幅が大きいなら、一部を相場に任せる（B）のも選べる。逆に、受取りが半年先など遠ければ、振れ幅はもっと大きくなる。
::
::

::exam 外貨建取引の急所
- 取引時は**取引日レート**、決算時は**貨幣項目だけ決算日レート**、決済時は実際の円の金額。差額はすべて**為替差損益**（営業外損益）
- 換算し直す（貨幣項目）：外貨の現金・預金、売掛金・買掛金、未収入金・未払金
- 換算し直さない（非貨幣項目）：**前受金・前払金**、棚卸資産、有形固定資産
- 前受金のある売上は、前受金の部分は**前受けの日のレート**、残りは取引の日のレート
- 為替予約（振当処理）：取引の前の予約は予約レートで記録、取引の後の予約は予約の日に予約レートへ直す（差額は為替差損益、期間配分しない）
- 為替差損益は純額で、差益なら営業外収益、差損なら営業外費用に表示する
::

::next 外貨建取引の先にある論点
1級では、為替予約の差額を期間に配分する方法、ヘッジ会計、外貨建の有価証券の換算、在外支店や在外子会社の財務諸表の換算（為替換算調整勘定）などを学ぶ。海外に子会社を持つ会社の連結財務諸表では、為替の変動が純資産を大きく動かす。
::

::summary
- 外貨建取引は、取引日レートで円に換算して記録する。売上・仕入は、その後の相場の変動で変わらない
- 決算時は、貨幣項目（外貨の預金・売掛金・買掛金など）だけを決算日レートで換算し直し、差額を為替差損益とする。前受金・前払金・棚卸資産は換算し直さない
- 決済のときの円の金額と帳簿の金額の差も、為替差損益とする
- 為替予約（振当処理）：取引の前の予約は予約レートで記録し、取引の後の予約は予約の日に予約レートへ直して差額を為替差損益とする
- 決算の為替差損益は、決算日の相場で測った途中経過。円の売上の増減には、量と値段の変化と、為替の変化が混ざっている
::

::problem 決算日に、決算日の為替相場で換算し直すものと、換算し直さないものに分けなさい。

@cats 換算し直す | 換算し直さない
