## 赤字を読む6つの手順

この1年で身につけた読み方を、6つの手順にまとめておこう。決算書の「赤字」でも「黒字」でも、同じ手順で読める。

::steps 決算書の損益を読む6つの手順
1 段を分ける | 売上総利益・営業利益・経常利益・特別損益・当期純利益の、どの段で赤字（黒字）なのか（第22章）
2 粗利を見る | 売上総利益はプラスか。売るほど損をしていないか。粗利率は上がっているか、下がっているか（第1章・第17章）
3 将来への支出を見つける | 研究開発費・立ち上げの費用・広告など、ルールで発生した年に全額費用にしたものはいくらか。それを除いた本業の利益は（第17章）
4 一度きりの損益を見つける | 除却損・和解金・災害損失・補助金など、繰り返さない損益はどれか（第4章・第14章・第15章）
5 評価の上だけの損益を見つける | 有価証券や負債の時価の変化、為替の換算、税効果など、現金の出入りを伴わない損益はどれか（第18章・第20章・第21章）
6 帳簿の外と推移を見る | 注記の約束（リース・購入の契約・保証）と、粗利率・費用の比率の推移を確かめる（第16章・第19章・第26章）
::

::theory 「除いた数字」は、説明の責任とセットで
手順3〜5で、研究開発費や一度きりの損失や評価の上の損失を「除いた」数字を作るのは、赤字の中身を知るためだ。だが、都合のよい費用だけを除けば、どんな会社も黒字に見せられる。除いた費用は本当に一度きりか、将来の収益にどうつながるのか、どう確かめるのか。除いた数字を使う人には、その説明の責任がある（第22章）。
::

## 答え合わせ ― 1年前の記事を、6つの手順で読む

::solve 「赤字420億ドル」の中には、性質の違う4つのものが入っていた
::table 2つの「赤字」を、6つの手順で読む
| 手順 | Anthropic（2025年、百万ドル） | 汐見酒造（2027年6月期、万円） |
| 1 段を分ける | 営業損失△8,060、当期純損失△41,965 | 営業損失△200、経常損失△820、当期純損失△1,490 |
| 2 粗利を見る | 売上総利益1,812（39.5%）。前年の△366から黒字に。2026年1〜6月は85.4% | 売上総利益19,000。前期より2,500増加 |
| 3 将来への支出 | 研究開発費6,338 | 研究開発費2,600、スパークリングの立ち上げ1,200 |
| 4 一度きりの損益 | 著作権訴訟の和解金1,500 | 旧ラインの除却損900（補助金と圧縮損は相殺） |
| 5 評価の上だけの損益 | 転換社債などの公正価値の変動△34,308 | 法人税等調整額△300（税金の欄のマイナス） |
| 6 帳簿の外と推移 | 未開始のリース約4,512億ドルなど巨額の約束。研究開発費の売上高比は約589%→約138%→約60% | 芹沢酒造の借入金8,000の保証。来期の研究開発費は1,000に |
::
1年前の見出しの「赤字420億ドル」は、手順1の最後の段の数字だった。6つの手順で分けると、その8割以上は、現金の出ていかない評価の上の損失（手順5）で、残りの営業損失の大部分は、次のモデルを作るための研究開発費（手順3）と、一度きりの和解金（手順4）だった。顧客に提供する事業の粗利（手順2）は、すでに黒字で、しかも急速に良くなっていた。
汐見酒造の「赤字」も、同じ形をしていた。本業の粗利は伸び、赤字の原因は、将来への支出と一度きりの損失だった。高梨が借換えを認めたのは、赤字の中身が分解され、繰り返す部分と繰り返さない部分が区別され、残るリスク（研究の成否、保証）を確かめる仕組みが示されたからだ。
::

1年前、同期は「売上の9倍の赤字。AIバブルもおしまいだな」と言った。いまの澪なら、こう答える。「最後の段の赤字の8割は、会社の価値が上がったことで生まれた、評価の上の損失。本業の粗利は黒字で、研究開発費の重さは年々下がっている。ただし、巨額の計算資源の約束がある。そこから先は、決算書の外の問題」。
あの会社が、この先どうなったか。それは、この本を読んでいるあなたのほうが知っているかもしれない。大事なのは、答えを当てることではない。どの数字を見れば、問いを正しく立てられるのかを知っていることだ。

::cfo 最後の判断 ― 黒字の決算書を、どう読むか
6つの手順は、赤字の会社を擁護するための道具ではない。最後に、逆の場面を考えよう。ある新興の食品メーカー（架空のX社）が、上場を前に、次の決算書を公表した。見出しは「X社、初の黒字。当期純利益25億円」。
::table X社の損益（単位：億円）
| 項目 | 前期 | 当期 |
| 売上高 | 80 | 100 |
| 売上原価 | 85 | 106 |
| 売上総利益 | △5 | △6 |
| 販売費及び一般管理費 | 40 | 44 |
| 営業損益 | △45 | △50 |
| 営業外損益（保有する他社株式の評価益など） | 2 | 80 |
| 特別損益 | 0 | 0 |
| 法人税等 | 0 | 5 |
| 当期純損益 | △43 | 25 |
::
6つの手順で読んでから選んでほしい。
::choice A. 初の黒字。成長が実を結んだ。安心して投資できる会社だ
**× 黒字の中身を見ていない。**当期純利益25億円は、営業外の評価益80億円がなければ出ていない（手順5）。本業の営業損失は△45億円から△50億円に拡大している。黒字の見出しは、最後の段の数字にすぎない。
::
::choice B. 売上総利益がマイナス。売るほど損が増える構造で、本業の改善は見られない
**◎ 手順2で、事業の根幹の問題を見抜いている。**売上原価が売上高を上回り、売上総利益は△5億円から△6億円に悪化している。売上が25%伸びても、粗利のマイナスは広がっている。これは、研究開発や立ち上げの費用の問題ではなく、製品を作って売るたびに損をする構造の問題だ。Anthropic の2024年（粗利△366百万ドル）と似ているが、違うのは、その後の推移だ。Anthropic の粗利率は翌年に39.5%、その翌年の上半期に85.4%へ改善した。X社は悪化している。
::
::choice C. 販管費が大きいのは、将来への投資だ。心配はいらない
**△ 手順3は大事だが、ここでは的を外している。**販管費の中に研究開発費や広告が含まれているなら、将来への支出として読む余地はある。だが、X社の問題は、販管費の前の段、売上総利益がマイナスであることだ。販管費をすべて除いても、売るたびに損が出る。
::
::choice D. 評価益80億円は、持っている株の値上がりで、本物の利益だ
**× 評価の上の利益と、本業の利益を混ぜている。**他社株式の評価益は、時価が下がれば消える。しかも、本業とは関係がない（第18章）。アマゾンの評価益と同じく、評価益が本業の利益を上回るときは、とくに慎重に読む必要がある。
::
::answer 考え方の例を見る
6つの手順は、赤字の会社にも黒字の会社にも、同じように使う。赤字でも、粗利が改善し、赤字の原因が将来への支出や一度きりの損失なら、その赤字は「事業が悪くなった」ことを意味しない。逆に、黒字でも、それが評価の上の利益や一度きりの利益に支えられ、粗利が悪化しているなら、その黒字は「事業が良くなった」ことを意味しない。
簿記は、良い会社と悪い会社を決めてくれる道具ではない。決算書の数字が、何を、いつ、どの段に、どう計上した結果なのかを教えてくれる道具だ。そこまで分かれば、判断は、自分でできる。
::

## 蔵の、その後

2028年7月、汐見酒造は芹沢酒造を合併した。「芹沢」の銘柄と、その製造免許は、汐見酒造の中に残った。芹沢酒造の借入金の保証は、注記の1行から、汐見酒造の貸借対照表の借入金に姿を変えた。新しい酵母で仕込んだ汐見スパークリングは、2年目に1万4,000本が売れ、損益分岐点を越えた。
2029年3月。小松の最後の造りが終わった。甑倒し（こしきだおし）の日、蔵人たちと酒を酌み交わした後で、澪は、1年半かけて積み立てた退職金の通帳を小松に渡した。小松は、通帳を開かずに、懐にしまった。「数字で酒を語られるのは嫌いだった。だが、あんたの数字は、最後まで酒の話をしとったな」
小松の後を継ぐのは、芹沢酒造から来た若い蔵人2人と、汐見の蔵人たちだ。
父は、杖をついて蔵を歩けるようになった。ある朝、仕込み蔵の前で、父は澪に言った。「7代目は、お前だ」
澪は、うなずいた。1年前、蔵を継ぐかどうか決めていなかった。いまは、決算書の1行1行に、自分が下した判断が刻まれている。それを、誰かに渡すつもりはなかった。

::next 次の一歩
1級は、商業簿記・会計学と、工業簿記・原価計算の2つの科目に分かれ、さらに広く深く学ぶ。だが、どの論点も、この本で学んだ問い ― この数字は、何を、いつ、どの段に、どう計上した結果なのか ― の延長線上にある。
そして、いちばんの練習の場は、実際の決算書だ。気になる会社の決算短信や有価証券報告書を開き、6つの手順で読んでみてほしい。新聞の「赤字」「黒字」の見出しが、きっと違って見えるはずだ。
::

::summary 終章のまとめ
- 本書の27の問いは、「この数字は、何を、いつ、どの段に、どう計上した結果なのか」という1つの問いの言いかえだった
- 決算書の損益は、6つの手順（段を分ける・粗利を見る・将来への支出・一度きりの損益・評価の上だけの損益・帳簿の外と推移）で読む
- 赤字でも事業が良くなっていることがあり、黒字でも事業が悪くなっていることがある。除いた数字を使うときは、説明の責任を伴う
- 簿記は良い会社と悪い会社を決める道具ではなく、判断のための問いを正しく立てる道具だ
::
