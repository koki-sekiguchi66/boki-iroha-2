## 赤字を読む6つの手順

この1年で身につけた読み方を、6つの手順にまとめておこう。決算書の「赤字」でも「黒字」でも、同じ手順で読める。

::steps 決算書の損益を読む6つの手順
1. 段を分ける | 売上総利益・営業利益・経常利益・特別損益・当期純利益の、どの段で赤字（黒字）なのか（第22章）
2. 粗利を見る | 売上総利益はプラスか。売るほど損をしていないか。粗利率は上がっているか、下がっているか（序章・第1章）
3. 将来への支出を見つける | 研究開発費・立ち上げの費用・広告など、発生した年に全額費用にしたものはいくらか。それを除いた本業の利益は（第17章）
4. 一度きりの損益を見つける | 除却損・和解金・災害の損失・補助金など、繰り返さない損益はどれか（第14章・第15章）
5. 評価の上だけの損益を見つける | 有価証券や負債の時価の変化、為替の換算、税効果など、現金の出入りを伴わない損益はどれか（第18章・第20章・第21章）
6. 帳簿の外と推移を見る | 注記の約束（リース・購入の契約・保証）と、粗利率や費用の比率の推移を確かめる（第16章・第19章・第26章）
::

::theory 「除いた数字」は、説明の責任とセットで
手順3〜5で、研究開発費や一度きりの損失や評価の上の損失を「除いた」数字を作るのは、赤字の中身を知るためだ。だが、都合のよい費用だけを除けば、どんな会社も黒字に見せられる。除いた費用は本当に一度きりか、将来の収益にどうつながるのか、どう確かめるのか。除いた数字を使う人には、その説明の責任がある（第22章）。
::

## 1年前の記事を、6つの手順で読む

::solve 「赤字420億ドル」の中には、性質の違う4つのものが入っていた
::table 2つの「赤字」を、6つの手順で読む
| 手順 | Anthropic（2025年、百万ドル） | 汐見酒造（2027年6月期、万円） |
| 1 段を分ける | 営業損失△8,060、当期純損失△41,965 | 営業損失△200、経常損失△820、当期純損失△1,427 |
| 2 粗利を見る | 売上総利益1,812（39.5%）。前年の△366から黒字に。2026年1〜6月は85.4% | 売上総利益19,000。前期より2,500増加 |
| 3 将来への支出 | 研究開発費6,338 | 研究開発費2,600、スパークリングの立ち上げ1,200 |
| 4 一度きりの損益 | 著作権訴訟の和解金1,500 | 旧ラインの除却損900（補助金と圧縮損は相殺） |
| 5 評価の上だけの損益 | 転換社債などの公正価値の変動△34,308 | 法人税等調整額△300（税金の欄のマイナス） |
| 6 帳簿の外と推移 | 未開始のリースなど巨額の約束。研究開発費の売上高比は約589%→約138%→約60% | 芹沢酒造の借入金8,000の保証。来期の研究開発費は1,000まで |
::
1年前の見出しの「赤字420億ドル」は、手順1の最後の段の数字だった。6つの手順で分けると、その8割以上は、現金の出ていかない評価の上の損失（手順5）で、残りの営業損失の大部分は、次のモデルを作るための研究開発費（手順3）と、一度きりの和解金（手順4）だった。顧客に提供する事業の粗利（手順2）は、すでに黒字で、しかも急速に良くなっていた。
汐見酒造の「赤字」も、同じ形をしていた。本業の粗利は伸び、赤字の原因は、将来への支出と一度きりの損失だった。審査が通ったのは、赤字の中身を分け、繰り返す部分と繰り返さない部分を区別し、残るリスク（研究の成否、保証）を確かめる仕組みを示したからだ。
::

夜、澪は桐生に電話をした。
桐生：「合格？　おめでとう！　で、あのAIの会社は、結局バブルだったの？」
澪：「最後の段の赤字の8割は、会社の値打ちが上がったことで生まれた、評価の上の損失。本業の粗利は黒字で、研究開発費の重さは年々下がっている。ただし、計算資源の巨額の約束がある。そこから先は、決算書の外の問題」
桐生：「……1年前のお前に、聞かせてやりたいな」
あの会社が、この先どうなったか。それは、この本を読んでいるあなたのほうが知っているかもしれない。大事なのは、答えを当てることではない。どの数字を見れば、問いを正しく立てられるのかを知っていることだ。

::cfo 最後の判断 ― 黒字の決算書を、どう読むか
6つの手順は、赤字の会社をかばうための道具ではない。最後に、逆の場面を考えよう。上場を目指す新興の食品メーカー（架空のX社）が、決算書を公表した。見出しは「X社、初の黒字。当期純利益25億円」。
**前提**
- 売上高は80億円から100億円に、25%伸びた
- 売上原価は85億円から106億円に増え、売上総利益は△5億円から△6億円になった
- 販管費は40億円から44億円に増え、営業損益は△45億円から△50億円になった
- 営業外の損益は2億円から80億円に増えた（主に、保有する他社の株の評価益）
- 法人税等は5億円で、当期純損益は△43億円から＋25億円になった
- X社の社長は、テレビの経済番組によく出ている
::choice A. 初の黒字。成長が実を結んだので、安心して投資できる会社だ
**× 黒字の中身を見ていない。**当期純利益25億円は、営業外の評価益80億円がなければ出ていない（手順5）。本業の営業損失は△45億円から△50億円に広がっている。黒字の見出しは、最後の段の数字にすぎない。
::
::choice B. 売上総利益がマイナスで、売るほど損が増える。本業は良くなっていない
**◎ 手順2で、事業の根っこの問題を見抜いている。**売上原価が売上高を上回り、売上総利益は△5億円から△6億円に悪化している。売上が25%伸びても、粗利のマイナスは広がっている。研究開発や立ち上げの費用の問題ではなく、作って売るたびに損をする構造の問題だ。Anthropic の2024年（粗利△366百万ドル）と似ているが、あの会社の粗利率は翌年に39.5%、さらに85.4%へと改善した。X社は悪化している。
::
::choice C. 販管費が大きいのは、将来への投資だ。心配はいらない
**△ 手順3は大事だが、ここでは的を外している。**販管費に研究開発費や広告が含まれているなら、将来への支出として読む余地はある。だが、X社の問題は、販管費の前の段、売上総利益がマイナスであることだ。販管費をすべて除いても、売るたびに損が出る。
::
::choice D. 評価益80億円は、持っている株の値上がりで、本物の利益だ
**× 評価の上の利益と、本業の利益を混ぜている。**他社の株の評価益は、時価が下がれば消え、本業とは関係がない（第18章）。アマゾンの評価益と同じく、評価益が本業の利益を上回るときは、とくに慎重に読む。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「黒字かどうか」ではなく、「黒字を生んだのは、どの段の、何か」を問う。
#### 手順2　前提の数字で確かめる
::table compact X社の損益を段に分ける（単位：億円）
| 段 | 前期 | 当期 | 読み方 |
| 売上総利益 | △5 | △6 | 売るほど損が増えている（手順2） |
| 営業損益 | △45 | △50 | 本業の赤字は広がった |
| 営業外の損益 | 2 | 80 | ほとんどが他社の株の評価益（手順5） |
| 当期純損益 | △43 | 25 | 黒字は評価益がつくった |
::
#### 手順3　ほかの答えに引かれる理由
Aは「初の黒字」の見出しに、Cは「投資の時期」という物語に、Dは「株の値上がりも利益」という正しさの一部に引かれる。社長がテレビによく出ていることは、決算書の読み方とは関係のない前提だ。
#### 持ち帰る考え方
- **赤字でも黒字でも、同じ6つの手順で読む**：赤字でも事業が良くなっていることがあり、黒字でも事業が悪くなっていることがある
- **簿記は、良い会社と悪い会社を決める道具ではない**：数字が何を、いつ、どの段に、どう計上した結果かを教える道具だ。そこまで分かれば、判断は自分でできる
#### 前提が変われば
売上総利益が赤字でも、原価の大部分が立ち上げの時期の一時的な費用で、粗利率がはっきり改善しているなら、読み方は変わる。決め手は、1期の数字ではなく推移だ（手順6）。
::

## 手帳の最後の紙 ― 澪が蔵を継ぐと決めた理由

その夜、澪は、合格の通知を印刷して、父の前に置いた。父は、退院して家にいた。杖があれば、少しずつ歩けるようになっていた。
澪は、まず、1年前の手帳の1行目に答えた。
澪：「お父さん。斗瓶取り、1本2,790円でした」
父は、長いあいだ黙っていた。それから、ゆっくりと言った。
父：「……そうか。……俺は、最後まで、それが分からなかった」
父は、左手で手帳を澪のほうへ押した。裏表紙の内側に、糊で閉じた紙が1枚。澪は、爪の先で、そっと糊をはがした。

::memo 黒い手帳の、最後の紙
澪へ
帳面を読める者に、蔵を任せる
::

日付は、2026年の夏。父が芹沢酒造の株を買い、保証の判子を押し、倒れる前のことだった。父は、娘が帳面を読めるようになることに、蔵を賭けていたのだ。
澪は、紙を見つめたまま考えた。蔵を継ぐのは、汐見の家に生まれたからではない。この1年、帳面の1行1行の向こうに、人がいた。40年の小松の仕込み、45年の岩倉の帳場、陸の打ち間違い、千尋の父の約束、ニューヨークのマーカスの約束、そして、誰にも相談せずに判子を押した父。帳面を読めるということは、その人たちの判断を引き受けるということだった。
澪：「継ぎます。7代目として」
父は、何も言わずにうなずいた。右手が、少しだけ動いた。

## 蔵の、その後

2028年7月、汐見酒造は芹沢酒造を合併した。「芹沢」の銘柄と、その製造免許は、汐見酒造の中に残った。芹沢酒造の借入金の保証は、注記の1行から、汐見酒造の貸借対照表の借入金に姿を変えた。新しい酵母で仕込んだ汐見スパークリングは、2年目に1万4,000本が売れ、損益分岐点の1万2,000本を越えた。
岩倉は、誰にも言わずに表計算を覚えていた。毎月の連結の試算表の検算は、いつのまにか岩倉の仕事になった。
2029年3月。小松の最後の造りが終わった。甑倒し（こしきだおし）の日、蔵人たちと酒を酌み交わしたあとで、澪は、20か月かけて積み立てた退職金の通帳を小松に渡した。小松は、通帳を開かずに、懐にしまった。
小松：「数字で酒を語られるのは嫌いだった。だが、あんたの数字は、最後まで酒の話をしとったな」
小松の後を継ぐのは、芹沢酒造から来た若い蔵人2人と、陸たち汐見の蔵人だ。

1級は、商業簿記・会計学と、工業簿記・原価計算に分かれ、さらに広く深く学ぶ。だが、どの論点も、この本で学んだ問い ― この数字は、何を、いつ、どの段に、どう計上した結果なのか ― の延長線上にある。
いちばんの練習の場は、実際の決算書だ。気になる会社の決算短信や有価証券報告書を開き、6つの手順で読んでみてほしい。新聞の「赤字」「黒字」の見出しが、きっと違って見えるはずだ。
::

::summary 終章のまとめ
- 本書の27の問いは、「この数字は、何を、いつ、どの段に、どう計上した結果なのか」という1つの問いの言いかえだった
- 決算書の損益は、6つの手順（段を分ける・粗利を見る・将来への支出・一度きりの損益・評価の上だけの損益・帳簿の外と推移）で読む
- 赤字でも事業が良くなっていることがあり、黒字でも事業が悪くなっていることがある。除いた数字を使うときは、説明の責任を伴う
- 簿記は良い会社と悪い会社を決める道具ではなく、判断のための問いを正しく立てる道具だ
::
