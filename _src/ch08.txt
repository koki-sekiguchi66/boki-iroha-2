::mystery 量で割れば分かるはずの原価が、合わない
3月の第1月曜日。新潟駅の売店の担当者から、うれしい知らせが届いた。普通酒「汐見」の**カップ酒**（180mL）が、冬の観光客に売れているという。春から、県内のコンビニにも置きたいという話まで来ていた。
番頭の岩倉は、さっそく1個あたりの原価を出した。「中身は一升瓶と同じ酒です。一升瓶は1.8リットル、カップは0.18リットル。量で割れば、カップの原価は一升瓶の10分の1。1個115円ですな。出荷値が220円なら、1個105円の儲けです」
澪は、瓶詰め部門の宇佐美から借りた記録を見ていた。カップ酒は、容器もふたも割高で、ラインの速度も一升瓶より遅い。1リットル詰めるのにかかる時間は、一升瓶の何倍もあった。
「中身が同じなら、原価も量に比例するはず。本当にそうでしょうか」
**中身は同じ酒なのに、1リットルあたりの原価は、なぜ違うのか？**
::

## 等級別総合原価計算 ― 同じ工程から、大きさや品質の違う製品

普通酒「汐見」は、同じタンクで造った同じ酒を、3つの容器に詰めて出荷している。一升瓶（1.8L）、四合瓶（720mL）、カップ（180mL）だ。このように、同じ工程で、同じ種類の製品を造り、大きさや品質（等級）だけが違う場合に使うのが**等級別総合原価計算**だ。

::theory 等価係数と積数
等級ごとの原価の違いを、基準の製品を1とした**等価係数**で表す。等価係数は、原価の発生と関係のある性質（重さ・大きさ・容量・材料の使用量・作業時間など）にもとづいて決める。
- **積数**＝等級ごとの完成品数量×等価係数（基準製品に換算した数量）
- 完成品総合原価を、積数の比で各等級に按分する
- 等級ごとの単位原価＝按分した原価÷その等級の完成品数量
::

岩倉の「量で割る」方法は、容量を等価係数にしたのと同じだ。一升瓶を1とすれば、四合瓶は0.4、カップは0.1。だが、容量で決めた係数には、瓶詰めの費用が入っていない。

::scene 3月の第1月曜日、午後 ― 瓶詰め場
宇佐美は、ラインの記録表を指でたどった。「1リットルあたりで言えば、カップはラインの時間を一升瓶の3倍近く使います。容器とふたも、1リットルあたりなら一升瓶の倍以上です。中身の酒の原価だけなら量に比例しますが、詰める費用は比例しません」
::

澪と宇佐美は、中身の酒の原価と、瓶詰めの作業時間・容器の費用を合わせて、1本あたりの原価の比を計算し直した。一升瓶を1とすると、四合瓶は**0.45**、カップは**0.15**になった。

::example 3月の普通酒「汐見」の完成品総合原価5,750,000円を、等級別に按分しなさい
完成品数量は、一升瓶2,000本、四合瓶5,000本、カップ10,000個。等価係数は、一升瓶1、四合瓶0.45、カップ0.15。
::answer
::table sum 等級別の按分（完成品総合原価5,750,000円）
| 等級 | 完成品数量 | 等価係数 | 積数 | 按分した原価（円） |
| 一升瓶 | 2,000本 | 1 | 2,000 | 2,000,000 |
| 四合瓶 | 5,000本 | 0.45 | 2,250 | 2,250,000 |
| カップ | 10,000個 | 0.15 | 1,500 | 1,500,000 |
|= 合計 | | | 5,750 | 5,750,000 |
::
積数1あたりの原価は、5,750,000円÷5,750＝1,000円。単位原価は、一升瓶2,000,000円÷2,000本＝**1,000円**、四合瓶2,250,000円÷5,000本＝**450円**、カップ1,500,000円÷10,000個＝**150円**。
::journal 等級別の製品勘定へ振り替える
一升瓶 2,000,000 | 仕掛品 5,750,000
四合瓶 2,250,000 |
カップ 1,500,000 |
::
実務や試験では、製品勘定を等級ごとに分けて記録する（「製品（一升瓶）」のように書くこともある）。
::
::

::solve カップ酒は「詰める費用」の割合が大きい
1リットルあたりにすると、一升瓶は1,000円÷1.8L＝**約556円**、四合瓶は450円÷0.72L＝**625円**、カップは150円÷0.18L＝**約833円**。中身の酒は同じでも、容器と瓶詰めの手間が1リットルあたりで大きく違うので、小さい容器ほど1リットルあたりの原価は高くなる。
岩倉の容量の係数（1：0.4：0.1）で按分すると、積数は2,000＋2,000＋1,000＝5,000。カップの原価は5,750,000円÷5,000×0.1＝**115円**になり、実際より35円安く見える。逆に一升瓶は1,150円と、150円高く見える。
カップの出荷値220円に対して、儲けは105円ではなく**70円**だった。容量だけで決めた等価係数は、詰める費用の違いを、一升瓶に押しつけていたのだ。
::

「量で割るのは、先代が一升瓶しか造っていなかったころのやり方です」と岩倉は言った。「カップなんぞ、なかった」
序章の「本数割り」、第5章の「工場全体の配賦率」に続いて、3度目の同じ構図だった。物差しが、蔵の変化に追いついていなかった。

::exam 等級別総合原価計算の急所
- まず等級をひとまとめにして、第7章と同じ手順で**完成品総合原価**を計算し、それを**積数の比**で按分する（2級の基本の形）
- 積数＝完成品数量×等価係数。単位原価は「按分額÷数量」で、「積数1あたりの原価×等価係数」でも求められる
- 等価係数は問題文で与えられることが多い。容量・重量などから自分で計算させる問題では、基準の製品を1とする
- 月末仕掛品の計算にも等価係数を使う方法（当月製造費用を按分する方法）もある。問題文の指示に従う
::

## 組別総合原価計算 ― 種類の違う製品を、同じ蔵で

汐見酒造は、造りの季節が終わる3月から、米麹で造る**甘酒**の製造を始める。アルコールを含まない、夏向けの商品だ。清酒と甘酒は、原料も工程も違う別の製品だが、同じ蔵の、同じボイラーと同じ人で造る。
このように、種類の違う製品を同じ工場で造るときに使うのが**組別総合原価計算**だ。製品の種類ごとの単位を**組**という。

::theory 組直接費と組間接費
- **組直接費**：どの組のための原価か分かるもの（その組の原料、その組の作業の直接労務費）。各組に**賦課**する
- **組間接費**：複数の組に共通する原価（ボイラー・建物・共通の機械）。機械運転時間などの基準で各組に**配賦**する
組ごとに原価を集めたら、あとは組ごとに単純総合原価計算（第7章）をすればよい。
::

::example 3月の組別の製造費用を集計し、仕訳しなさい
::table 3月の製造費用（単位：円）
| 項目 | 清酒組 | 甘酒組 |
| 直接材料費（組直接費） | 3,000,000 | 600,000 |
| 直接労務費（組直接費） | 1,200,000 | 300,000 |
| 機械運転時間 | 400時間 | 100時間 |
::
組間接費1,500,000円は、機械運転時間を基準に配賦する。
::answer
組間接費の配賦：1,500,000円÷(400時間＋100時間)＝3,000円。清酒組400時間×3,000円＝1,200,000円、甘酒組100時間×3,000円＝300,000円。
::journal 組直接費の賦課と、組間接費の配賦
清酒組仕掛品 5,400,000 | 材料 3,600,000
甘酒組仕掛品 1,200,000 | 賃金・給料 1,500,000
 | 組間接費 1,500,000
::
清酒組の当月製造費用は3,000,000円＋1,200,000円＋1,200,000円＝5,400,000円、甘酒組は600,000円＋300,000円＋300,000円＝1,200,000円。ここから先は、組ごとに月初・月末仕掛品を考えて、第7章の計算で完成品原価を求める。
::
::

## 工程別総合原価計算 ― 精米工程から醸造工程へ

酒造りは、2つの工程を順に通る。第1工程の**精米工程**で玄米を磨いて白米にし、第2工程の**醸造工程**でその白米を酒にする。工程ごとに原価を計算し、前の工程の完成品の原価を、次の工程に引き継いでいく方法を、**工程別総合原価計算**という。2級では、前の工程の完成品原価を次の工程の「材料」のように扱う**累加法**を学ぶ。

::theory 前工程費は、次の工程の始点で投入される材料と同じ
第1工程の完成品総合原価は、第2工程に振り替えられて**前工程費**になる。前工程費は、第2工程の始点で全量が投入される材料と同じように扱う（月末仕掛品の完成品換算量は数量そのもの）。第2工程では、前工程費と、第2工程で発生する加工費（自工程費）を、第7章と同じ方法で計算する。
::

::example 3月の精米工程と醸造工程の原価を、累加法で計算しなさい（月初仕掛品はない。数量は玄米に換算したkg）
**第1工程（精米）**：当月投入の玄米10,000kg（直接材料費6,000,000円）、加工費1,128,000円。完成品（白米）9,000kg、月末仕掛品1,000kg（進捗度40%）。
**第2工程（醸造）**：第1工程の完成品9,000kgを始点で投入。加工費2,550,000円。完成品8,000kg、月末仕掛品1,000kg（進捗度50%）。
::answer
**第1工程**
- 直接材料費：6,000,000円÷(9,000kg＋1,000kg)＝600円、月末1,000kg×600円＝600,000円
- 加工費：1,128,000円÷(9,000kg＋1,000kg×40%)＝1,128,000円÷9,400kg＝120円、月末400kg×120円＝48,000円
- 第1工程の完成品総合原価：(6,000,000円－600,000円)＋(1,128,000円－48,000円)＝**6,480,000円**（1kgあたり720円）

**第2工程**
- 前工程費：6,480,000円÷(8,000kg＋1,000kg)＝720円、月末1,000kg×720円＝720,000円
- 加工費：2,550,000円÷(8,000kg＋1,000kg×50%)＝2,550,000円÷8,500kg＝300円、月末500kg×300円＝150,000円
- 第2工程の完成品総合原価：(6,480,000円－720,000円)＋(2,550,000円－150,000円)＝**8,160,000円**

::journal (1) 第1工程の完成品を、第2工程に振り替える
第2工程仕掛品 6,480,000 | 第1工程仕掛品 6,480,000
::
::journal (2) 第2工程の完成品を、製品に振り替える
製品 8,160,000 | 第2工程仕掛品 8,160,000
::
::tgrid
::taccount 第1工程仕掛品
材料 6,000,000 | 第2工程仕掛品 6,480,000
加工費 1,128,000 | 次月繰越 648,000
= 7,128,000 | 7,128,000
::
::taccount 第2工程仕掛品
第1工程仕掛品 6,480,000 | 製品 8,160,000
加工費 2,550,000 | 次月繰越 870,000
= 9,030,000 | 9,030,000
::
::
第1工程の完成品を、すぐに次の工程に回さず倉庫に保管したり、外部に売ったりする場合は、**半製品**勘定（資産）を経由させる。
::
::

::exam 組別・工程別の急所
- **組別**：組直接費は賦課、組間接費は配賦。そのあとは組ごとの単純総合原価計算
- **工程別（累加法）**：第1工程の完成品総合原価＝第2工程の**前工程費**。前工程費は第2工程の始点投入の材料と同じに扱い、月末仕掛品の進捗度を掛けない
- 第2工程の月初仕掛品にも「前工程費」と「加工費」の2つがある。ボックス図を前工程費と加工費で分けて描く
- 第2工程で追加の材料を投入する問題では、その材料の投入点（始点・終点・平均的）を必ず確かめる
::

::real 同じ酒に「特級」「一級」「二級」― 清酒の級別制度
日本酒には、かつて「特級」「一級」「二級」という等級があった。国税庁によると、清酒の級別制度は1943年（昭和18年）に「一級」から「四級」までの4段階で導入され、**級別に酒税が課された**。戦後に特級・一級・二級の3段階になり、1990年（平成2年）に「本醸造」「純米酒」などの特定名称による表示が導入されたことで、1992年（平成4年）に撤廃された。等級は、酒の品質の審査によって決まった。審査に出さない酒は、二級酒として扱われた。

**この章の道具で読む ― 等級が決めたのは原価か、税金か**
仮に、ある蔵が同じタンクで造った酒10kL（原価300万円）のうち、6kLを一級、4kLを二級として出荷したとする（仕組みを示すための例）。中身はまったく同じ酒だ。等級別総合原価計算の考え方では、等価係数は**原価の発生と関係のある性質**で決める。中身も容器も同じなら、係数は1：1になる。

::table 同じタンクの酒を、等級別に按分する
| 等級 | 数量 | 等価係数 | 積数 | 原価 | 1Lあたり |
| 一級 | 6kL | 1 | 6 | 1,800,000円 | 300円 |
| 二級 | 4kL | 1 | 4 | 1,200,000円 | 300円 |
::
::journal 等級別の製品へ振り替える
製品（一級） 1,800,000 | 仕掛品 3,000,000
製品（二級） 1,200,000 |
::
1Lあたりの原価は、一級も二級も300円で同じだ。違うのは、出荷のときにかかる**酒税**と、売値だけ。もし等価係数を「売値」や「税額」の比で決めれば、一級の原価が高く、二級の原価が安く計算されてしまう。だが、それは造るのにかかったお金の違いではない。
等価係数に何を使うかで、製品ごとの原価は簡単に変わる。だからこそ、係数は「原価がどう生まれるか」に結びつけて決める。カップ酒の係数を、容量だけでなく容器と瓶詰めの手間から決め直したのと同じ理屈だ。
::note
出典：[国税庁 租税史料館「酒税の歴史」（平成22年度企画展示資料）](https://www.nta.go.jp/about/organization/ntc/sozei/tokubetsu/h22shiryoukan/05.htm)
::
::

::cfo 精米を外に頼むか ― 工程の原価の中身を読む
3月の終わり、隣の市の精米業者が営業に来た。「1kgあたり100円、運賃込みで110円で精米します。御社の精米工程の加工費は、1kgあたり120円だそうですね。うちに任せれば、年間10万kgで100万円安くなります」
岩倉は乗り気だった。小松は「磨きを他人に任せるのか」と顔をしかめた。澪は、精米工程の加工費120円の中身を調べた。
::table 精米工程の加工費（1kgあたり、年間10万kg）
| 中身 | 1kgあたり | 年間 | 外に頼んだらどうなるか |
| 電力・ぬかの処理など（変動費） | 30円 | 300万円 | なくなる |
| 精米機の減価償却費（固定費） | 50円 | 500万円 | 精米機を売れる見込みはなく、残る |
| 精米係2人の給料（固定費） | 40円 | 400万円 | 2人は通年の社員で、残る |
|= 合計 | 120円 | 1,200万円 | |
| 外部の精米業者の料金（運賃込み） | 110円 | 1,100万円 | |
::
まず、外に頼んだときに「なくなる費用」と「新たにかかる費用」を比べてから選んでほしい。
::choice A. 外に頼む。120円より110円のほうが安く、年間100万円の節約になる
**× 消えない固定費を、消えるものとして比べている。**外に頼んでも、精米機の減価償却費500万円と精米係の給料400万円は残る。なくなるのは変動費の300万円だけで、新たに1,100万円の外注料がかかる。差し引き、年間**800万円の損**だ。工程の加工費120円は、固定費を含んだ「全部の原価」であって、外に頼んだときに浮くお金ではない。
::
::choice B. 自社の精米を続ける。外に頼んでも浮くのは1kgあたり30円だけだから
**◎ 判断で変わるお金だけを比べている。**外に頼んで減るのは変動費の1kgあたり30円、増えるのは外注料の110円。1kgあたり80円、年間800万円、自社で精米したほうが安い。第4章の「故障の損失」と同じで、意思決定では、その判断によって変わるお金だけを数える。
しかも、自社の精米なら、小松が求める精米歩合を、タンクごとに細かく変えられる。
::
::choice C. 精米係の2人を瓶詰めに回して、繁忙期のパート代を浮かせれば、外に頼んでも得になる
**△ 方向はよいが、まだ足りない。**2人を瓶詰めに回せば、瓶詰めの繁忙期に頼んでいるパートの費用（年間約300万円）が浮くとしよう。それでも、外に頼むことによる損800万円のうち、300万円が埋まるだけで、500万円の損が残る。固定費の一部が「ほかで使える」なら判断に入れるべきだが、数字で確かめる必要がある。
::
::choice D. 精米工程の原価を110円に下げるため、精米機の減価償却をやめる
**× 帳簿の数字を変えても、お金は1円も変わらない。**減価償却は、すでに買った機械の原価を使った年数に配分する手続きだ。償却をやめても、機械を買ったお金が戻るわけではない。しかも、減価償却を恣意的に止めることは、会計の基準に反する。数字を外注の見積りに合わせることは、判断ではない。
::
::answer 考え方の例を見る
工程別の原価計算で出てくる工程の単位原価は、固定費を含めた「全部の原価」だ。製品の原価を知るには正しいが、外注するかどうかを決めるには、そのまま使えない。判断に使うのは、外注したら「なくなる費用」と「新たにかかる費用」の差だけだ。
澪は、精米業者の申し出を丁寧に断った。代わりに、精米機の空いている夏の時間で、隣町の芹沢酒造の米を受託で精米できないかと考え始めた。固定費は、使い道を増やせば、1kgあたりの負担が軽くなる。その考え方は、第10章で本格的に登場する。
::

::next 総合原価計算の先にある論点
1級では、工程別総合原価計算の**非累加法**（工程ごとの原価要素を最後まで分けて計算する方法）、同じ原料から必然的に複数の製品ができる**連産品**の原価の分け方、主な製品と一緒にできる**副産物**（酒造りなら酒粕）の評価などを学ぶ。酒粕は、清酒を搾ると必ずできるが、清酒と同じ扱いにはしない。その理由が、1級の連産品と副産物の区別にある。
::

## 確認問題

::quiz
::problem 等級製品A・Bの完成品総合原価は1,710,000円である。完成品数量はA 1,000個、B 1,500個、等価係数はA 1、B 0.6である。A・Bの単位原価を求めなさい。
Aの単位原価 [[900]] 円、Bの単位原価 [[540]] 円
::answer
積数：A 1,000×1＝1,000、B 1,500×0.6＝900、合計1,900。積数1あたり1,710,000円÷1,900＝900円。
Aの按分額 1,000×900円＝900,000円 → 単位原価 **900円**。Bの按分額 900×900円＝810,000円 → 810,000円÷1,500個＝**540円**（900円×0.6とも一致する）。

::problem 第2工程の資料から、累加法により、第2工程の月末仕掛品原価と完成品総合原価を求めなさい。月初仕掛品はない。
前工程費（第1工程の完成品2,000個を始点で投入）1,600,000円、第2工程の加工費 1,140,000円
完成品 1,800個、月末仕掛品 200個（進捗度50%）
月末仕掛品原価 [[220,000]] 円、完成品総合原価 [[2,520,000]] 円

**前工程費**：1,600,000円÷2,000個＝800円、月末200個×800円＝160,000円（始点投入と同じなので進捗度は掛けない）

月末仕掛品原価＝160,000円＋60,000円＝**220,000円**、完成品総合原価＝(1,600,000円＋1,140,000円)－220,000円＝**2,520,000円**

::summary
- 等級別総合原価計算：同じ工程で大きさ・品質の違う製品を造るとき、完成品総合原価を積数（数量×等価係数）の比で按分する。等価係数は原価の発生と関係のある性質で決める
- 組別総合原価計算：種類の違う製品を同じ工場で造るとき、組直接費は賦課、組間接費は配賦し、組ごとに単純総合原価計算をする
- 工程別総合原価計算（累加法）：前の工程の完成品総合原価を、次の工程の前工程費（始点投入の材料と同じ扱い）として引き継ぐ
- 工程の単位原価には固定費が含まれる。外注するかどうかは、判断で変わるお金（なくなる費用と新たにかかる費用）だけで比べる
::
