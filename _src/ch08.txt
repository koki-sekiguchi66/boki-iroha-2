## 3つの容器 ― 等級別総合原価計算

普通酒「汐見」は、同じタンクで造った同じ酒を、3つの容器に詰めて出荷している。一升瓶（1.8L）、四合瓶（720mL）、カップ（180mL）。
このように、同じ工程で同じ種類の製品を造り、大きさや品質（等級）だけが違う場合に使うのが**等級別総合原価計算**だ。1か月分の完成品総合原価を、等級ごとに分ける。
岩倉の「量で割る」は、容量の比で分けたのと同じだ。一升瓶を1とすれば、四合瓶は0.4、カップは0.1。

::theory 等価係数と積数
等級ごとの原価の違いを、基準の製品を1とした**等価係数**で表す。等価係数は、原価の発生と関係のある性質（重さ・大きさ・容量・作業時間など）で決める。
- **積数**＝等級ごとの完成品数量×等価係数（基準の製品に換算した数量）
- 完成品総合原価を、積数の比で各等級に按分する
- 等級ごとの単位原価＝按分した原価÷その等級の完成品数量
::

::scene 3月3日、午後4時 ― 瓶詰め場
宇佐美は、ラインの記録表を指でたどった。
宇佐美：「1リットルあたりで言えば、カップは一升瓶の3倍近くラインの時間を使います。容器とふたも、1リットルあたりなら一升瓶の倍以上です」
宇佐美：「中身の酒は量に比例しますけど、詰める費用は比例しませんよ」
::

澪と宇佐美は、中身の酒の原価に、瓶詰めの作業時間と容器の費用を合わせて、1本あたりの原価の比を計算し直した。一升瓶を1とすると、四合瓶は**0.45**、カップは**0.15**になった。容量の比（0.4、0.1）より、小さな容器ほど大きくなる。

::example 3月の普通酒「汐見」の完成品総合原価5,750,000円を、等級別に按分する
完成品数量は、一升瓶2,000本、四合瓶5,000本、カップ10,000個。等価係数は、一升瓶1、四合瓶0.45、カップ0.15。
::answer
::table sum 等級別の按分（完成品総合原価5,750,000円）
| 等級 | 完成品数量 | 等価係数 | 積数 | 按分した原価（円） |
| 一升瓶 | 2,000本 | 1 | 2,000 | 2,000,000 |
| 四合瓶 | 5,000本 | 0.45 | 2,250 | 2,250,000 |
| カップ | 10,000個 | 0.15 | 1,500 | 1,500,000 |
|= 合計 | | | 5,750 | 5,750,000 |
::
積数1あたりの原価は、5,750,000円÷5,750＝1,000円。単位原価は、一升瓶**1,000円**、四合瓶2,250,000円÷5,000本＝**450円**、カップ1,500,000円÷10,000個＝**150円**。
::journal 等級別の製品勘定へ振り替える
一升瓶 2,000,000 | 仕掛品 5,750,000
四合瓶 2,250,000 |
カップ 1,500,000 |
::
::trap
按分するのは**積数**の比で、完成品数量の比ではない。数量で割ると、1個の小さいカップに一升瓶と同じ原価が配られてしまう。また、等価係数は「1本あたり」の原価の比だ。「1Lあたり」の比と取り違えないこと。
::
::
::

::challenge カップ酒1個の原価は、いくらか
手がかりをまとめる。
- 3月の普通酒の完成品総合原価は5,750,000円。一升瓶2,000本、四合瓶5,000本、カップ10,000個
- 中身の酒は量に比例するが、瓶詰めの時間と容器の費用は、小さな容器ほど1Lあたりで高い
- 原価の発生を反映した等価係数は、一升瓶1、四合瓶0.45、カップ0.15
- カップの出荷値は1個220円
::choice A. 115円。中身は同じ酒なので、容量の比（1：0.4：0.1）で分ければよい
**× 岩倉の見立て。**容量の比で分けると、積数は2,000＋2,000＋1,000＝5,000で、積数1あたり1,150円、カップは115円になる。だが、それでは瓶詰めの手間と容器の費用が、容量に比例するとみなしてしまう。カップの原価を低く、一升瓶の原価を高く見誤る。
::
::choice B. 150円。原価の発生を反映した等価係数0.15で按分する。1個70円の儲けで、赤字ではない
**◎ 正解。**積数1あたり1,000円×0.15＝150円。出荷値220円との差は70円で、黒字だ。千尋の「赤字」も、岩倉の「105円の儲け」も、どちらも外れていた。
::
::choice C. 220円以上。カップは容器も手間もかかるので、出荷値を上回っているはずだ
**× 千尋の見立て。**手間がかかるのは確かだが、どれだけかかるかは数字で確かめるまで分からない。等価係数で按分すると150円で、出荷値を下回っている。
::
::choice D. 約338円。5,750,000円を完成品の数量17,000個で割る
**× 数量で割ると、カップも一升瓶も同じ原価になる。**1.8Lの一升瓶と180mLのカップが、どちらも338円。大きさの違いを無視した、最も粗い分け方だ。
::
::answer
#### 手順1　積数を出す
完成品数量×等価係数。一升瓶2,000、四合瓶2,250、カップ1,500、合計5,750。
#### 手順2　積数1あたりの原価
5,750,000円÷5,750＝1,000円。
#### 手順3　等級ごとの原価と単位原価
カップの原価＝1,500×1,000円＝1,500,000円、1個あたり1,500,000円÷10,000個＝150円。等価係数が「1個あたり」の比なので、按分は積数で行う。
::
::

::solve カップ酒は1個150円。赤字ではないが、105円の儲けでもなかった
中身は同じ酒でも、詰める費用は量に比例しない。等価係数を原価の生まれ方で決め直すと、カップ酒1個の原価は150円だった。出荷値220円との差は70円。千尋の言う赤字ではなかったが、岩倉の「1個105円の儲け」は、瓶詰めの手間を見落とした数字だった。
もし容量の比のまま、コンビニへの出荷を「1個105円の儲け」で値引き交渉していたら、思ったより儲からない酒を、安値で大量に流していた。逆に千尋の言葉を信じてカップ酒をやめていたら、黒字の売れ筋を捨てていた。
**等価係数は、製品の値札でも量でもなく、原価が生まれる仕組みで決める。**
::

岩倉は、等価係数の表を自分の帳面に写しながら、ぼそりと言った。
岩倉：「芹沢のお嬢さん、相変わらず鋭いですな」
澪：「岩倉さん、芹沢酒造のこと、何か知ってるんですか」
岩倉：「……隣町の蔵ですから。それだけです」

## 清酒と甘酒 ― 組別総合原価計算

春から、汐見酒造は、酒米と麹で造るノンアルコールの甘酒を、清酒と同じ蔵で造っている。清酒と甘酒は、等級の違いではなく、まったく種類の違う製品だ。このように、同じ工場で種類の違う製品（組）を造るときに使うのが**組別総合原価計算**だ。

::point メモ ― 組直接費と組間接費
組別総合原価計算では、製造原価を**組直接費**（どの組のものか分かる原価）と**組間接費**（組に共通の原価）に分ける。組直接費はその組に**賦課**し、組間接費は機械運転時間などの基準で各組に**配賦**する。あとは組ごとに、単純総合原価計算と同じ手順で完成品と月末仕掛品に分ける。
::

::example 3月の組別の製造費用を集計する
3月の組直接費は、清酒組が直接材料費3,000,000円・直接労務費1,200,000円、甘酒組が直接材料費600,000円・直接労務費300,000円。組間接費1,500,000円は、機械運転時間（清酒組400時間、甘酒組100時間）を基準に配賦する。
::answer
組間接費の配賦率：1,500,000円÷(400時間＋100時間)＝3,000円。清酒組400時間×3,000円＝1,200,000円、甘酒組100時間×3,000円＝300,000円。
::journal 組直接費の賦課と、組間接費の配賦
清酒組仕掛品 5,400,000 | 材料 3,600,000
甘酒組仕掛品 1,200,000 | 賃金・給料 1,500,000
 | 組間接費 1,500,000
::
清酒組は3,000,000＋1,200,000＋1,200,000＝5,400,000円、甘酒組は600,000＋300,000＋300,000＝1,200,000円。この先は、組ごとにボックス図を描いて、完成品と月末仕掛品に分ける。
::trap
組間接費を、組直接費の比などで配らないこと。問題文が指定する配賦基準（機械運転時間など）を使う。等級別（完成品総合原価を最後に按分する）と、組別（製造原価を最初に組へ分ける）の順番の違いも狙われる。
::
::
::

## 精米から醸造へ ― 工程別総合原価計算（累加法）

千尋の名刺を見ながら、澪は精米の工程を数字で見直すことにした。汐見酒造の酒造りは、2つの工程に分けられる。玄米を磨いて白米にする**精米工程**と、白米から酒を造る**醸造工程**だ。
工程が2つ以上あるときは、工程ごとに原価を計算し、前の工程の完成品原価を次の工程に引き継ぐ。これを**工程別総合原価計算**という。2級で学ぶのは、前の工程の完成品原価を、次の工程の始点で投入した材料のように扱って足し上げていく**累加法**だ。

::point メモ ― 前工程費
前の工程の完成品総合原価を、次の工程では**前工程費**と呼ぶ。前工程費は、次の工程の始点で投入する材料と同じように扱う。月末仕掛品の進捗度を掛けず、数量のまま負担させる。
::

::example 3月の精米工程と醸造工程の原価を、累加法で計算する
月初仕掛品はない（数量は玄米に換算したkg）。
**第1工程（精米）**：当月投入の玄米10,000kg（直接材料費6,000,000円）、加工費1,128,000円。完成品（白米）9,000kg、月末仕掛品1,000kg（進捗度40%）。
**第2工程（醸造）**：第1工程の完成品9,000kgを始点で投入。加工費2,550,000円。完成品8,000kg、月末仕掛品1,000kg（進捗度50%）。
::answer
**第1工程**
- 直接材料費：6,000,000円÷(9,000kg＋1,000kg)＝600円、月末1,000kg×600円＝600,000円
- 加工費：1,128,000円÷(9,000kg＋1,000kg×40%)＝1,128,000円÷9,400kg＝120円、月末400kg×120円＝48,000円
- 第1工程の完成品総合原価：(6,000,000円－600,000円)＋(1,128,000円－48,000円)＝**6,480,000円**（1kgあたり720円）
**第2工程**
- 前工程費：6,480,000円÷(8,000kg＋1,000kg)＝720円、月末1,000kg×720円＝720,000円
- 加工費：2,550,000円÷(8,000kg＋1,000kg×50%)＝2,550,000円÷8,500kg＝300円、月末500kg×300円＝150,000円
- 第2工程の完成品総合原価：(6,480,000円－720,000円)＋(2,550,000円－150,000円)＝**8,160,000円**
::journal 第1工程の完成品を第2工程へ、第2工程の完成品を製品へ
第2工程仕掛品 6,480,000 | 第1工程仕掛品 6,480,000
製品 8,160,000 | 第2工程仕掛品 8,160,000
::
::trap
前工程費に、第2工程の月末仕掛品の進捗度（50%）を掛けないこと。前工程費は始点で全部入っている。加工費だけを換算量で計算する。
::
::
::

### 試験で狙われるパターン ― 等級別の月末仕掛品・組別の仕訳・工程別の月初仕掛品

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 等級別は「最後に按分」**　2級の等級別総合原価計算では、まず全体を1つの製品として単純総合原価計算で完成品総合原価を出し、**完成品総合原価だけを**等価係数で按分する。月末仕掛品は等級に分けない。

**② 組別の勘定**　組ごとに「清酒組仕掛品」「甘酒組仕掛品」のような勘定を立てる。完成品も「清酒組製品」などの勘定へ振り替える。

**③ 第2工程に月初仕掛品がある**　第2工程の月初仕掛品にも、前工程費と加工費の2つがある。ボックス図を、前工程費の箱と加工費の箱に分けて描けば、単純総合原価計算と同じ手順で解ける。

::steps 解法の型 ― 等級別・組別・工程別
1. 等級別 | 全体で単純総合原価計算 → 完成品総合原価を積数（数量×等価係数）の比で按分 → 単位原価
2. 組別 | 組直接費は賦課、組間接費は配賦 → 組ごとに単純総合原価計算
3. 工程別（累加法） | 第1工程の完成品総合原価＝第2工程の前工程費。前工程費は始点投入の材料と同じ（進捗度を掛けない）
4. 第2工程の箱 | 前工程費の箱と加工費の箱。追加の材料があれば、投入点を確かめて箱を足す
::

## 番頭が覚えている「特級・一級・二級」

::scene 3月3日、夕方 ― 帳場
カップ酒の等価係数を決め直したあと、岩倉は、珍しく昔話を始めた。
岩倉：「専務、同じタンクの酒に、違う値札をつけとった時代がありましてな。特級、一級、二級」
岩倉：「審査に出して一級に通れば、一級の酒税がかかる。出さなければ二級。中身は同じでも、税金と値段が違った。帳面では、どっちも同じ原価で書いとりましたがね」
::

国税庁によると、清酒の級別制度は1943年（昭和18年）に「一級」から「四級」までの4段階で導入され、級別に酒税が課された。戦後に特級・一級・二級の3段階になり、1990年（平成2年）に「本醸造」「純米酒」などの特定名称による表示が導入されたことで、1992年（平成4年）に撤廃された。等級は品質の審査で決まり、審査に出さない酒は二級酒として扱われた。
澪は、岩倉の言う「同じ原価で書いとった」を、等級別総合原価計算で確かめた。仮に、同じタンクで造った酒10kL（原価300万円）のうち、6kLを一級、4kLを二級として出荷したとする（仕組みを示すための例）。中身も容器も同じなら、原価の生まれ方も同じなので、等価係数は1：1だ。

::table 同じタンクの酒を、等級別に按分する
| 等級 | 数量 | 等価係数 | 積数 | 原価 | 1Lあたり |
| 一級 | 6kL | 1 | 6 | 1,800,000円 | 300円 |
| 二級 | 4kL | 1 | 4 | 1,200,000円 | 300円 |
::

::journal 等級別の製品へ振り替える
製品（一級） 1,800,000 | 仕掛品 3,000,000
製品（二級） 1,200,000 |
::

違うのは、出荷のときにかかる酒税と売値だけだ。もし等価係数を売値や税額の比で決めれば、一級の原価が高く、二級の原価が安く計算されてしまう。だが、それは造るのにかかったお金の違いではない。
澪：「岩倉さんの帳面は、正しかったんですね」
岩倉：「あのころは、それで正しかった。カップ酒は、瓶詰めの手間が違う。物差しは、原価がどう生まれるかで決めるもんでしょう。……専務に教わりました」

::cfo 千尋の申し出 ― 精米を外に頼むか
千尋の提案は「1kg110円（運賃込み）で精米を引き受ける」だった。汐見酒造の精米工程の加工費は、1kgあたり120円（年間10万kg）。中身は次のとおり。
- 電力・ぬかの処理など（変動費）：1kgあたり30円。外に頼めばなくなる
- 精米機の減価償却費（固定費）：1kgあたり50円。精米機を売れる見込みはなく、外に頼んでも残る
- 精米係2人の給料（固定費）：1kgあたり40円。2人は通年の社員で、外に頼んでも残る
::choice A. 外に頼む。1kgあたり120円より10円安く、年に100万円の節約になる
**× 「1kgあたり」の数字に、外に頼んでも消えない固定費が入っている。**外に頼んで消えるのは変動費の30円だけ。110円を払って30円が消えるので、1kgあたり80円、年に**800万円**の損になる。
::
::choice B. 自社で精米を続ける。外に頼んで減る費用は1kgあたり30円しかない
**◎ 判断で変わるお金だけを比べている。**外に頼むと払う110円に対して、減るのは変動費30円だけ。精米機の減価償却費と精米係の給料は、どちらを選んでも同じだけかかる。
::
::choice C. 外に頼み、精米係2人を醸造に回す。給料の分も浮くはずだ
**△ 2人を醸造に回して、その分の臨時の蔵人を雇わずに済むなら、給料の40円も外注で浮く費用に入る。**それでも、減るのは30円＋40円＝70円で、110円には届かない。年400万円の損だ。
::
::choice D. 精米機が古いので、この機会に外に頼み、精米機を処分する
**△ 精米機を売れる見込みがない以上、減価償却費は処分しても消えない（帳簿の残りは除却損になる）。**更新の時期に、新しい精米機を買うか外に頼むかを、改めて比べるのが筋だ。
::
::answer 考え方の例を見る
#### 手順1　工程の原価を、変わるものと変わらないものに分ける
外に頼むと消えるもの（変動費30円）と、消えないもの（減価償却費50円・給料40円）。
#### 手順2　変わるものだけで比べる
外注：110円を払う。自社：30円を払う。差は80円で自社が有利。年10万kgで800万円。
#### 持ち帰る考え方
製品1単位あたりの原価には、判断で変わらない固定費が混ざっている。外に頼むかどうか、注文を受けるかどうかは、**判断で変わるお金**で比べる。第10章の直接原価計算で、この考え方を本格的に学ぶ。
#### その後の蔵
澪は、千尋の申し出を断った。ただし、汐見の精米機が空いている時期に、逆に芹沢酒造の米を磨く話を持ちかけると、千尋は少し考えて「検討します」と言った。
::

::exam 等級別・組別・工程別の急所
- 等級別：積数＝完成品数量×等価係数。**完成品総合原価**を積数の比で按分（月末仕掛品は按分しない）
- 等価係数は「1個あたり」の原価の比。原価の生まれ方（大きさ・手間・材料の量）で決める
- 組別：組直接費は賦課、組間接費は配賦。そのあとは組ごとに単純総合原価計算
- 工程別（累加法）：第1工程の完成品総合原価が第2工程の**前工程費**。前工程費に進捗度を掛けない
- 第2工程の月初仕掛品も、前工程費と加工費の2つの箱で計算する
::

::next 連産品と副産物 ― 酒粕の値段は？
清酒を搾ると、必ず酒粕ができる。主な製品と一緒にできる、価値の小さい製品を**副産物**、同じ原料から必然的にできる価値の近い複数の製品を**連産品**という。その評価と原価の分け方は、1級の範囲だ。工程別総合原価計算でも、1級では工程ごとの原価要素を最後まで分けて計算する非累加法を学ぶ。
::

::summary
- 等級別総合原価計算は、同じ工程で大きさや品質の違う製品を造るときに、完成品総合原価を積数の比で按分する
- 等価係数は、原価の発生と関係のある性質で決める。値札や税額の比では決めない
- 組別総合原価計算は、組直接費を賦課し、組間接費を配賦してから、組ごとに計算する
- 工程別総合原価計算（累加法）は、前の工程の完成品原価を前工程費として次の工程に引き継ぐ
- 外に頼むかどうかは、判断で変わるお金だけで比べる
::

## 確認問題

::quiz
::problem 次の資料から、等級別総合原価計算により、製品Aと製品Bの単位原価を求めなさい。
完成品総合原価 1,800,000円。製品A 1,000個（等価係数1）、製品B 2,000個（等価係数0.4）
製品Aの単位原価 [[1,000]] 円、製品Bの単位原価 [[400]] 円
::answer
積数はA 1,000、B 800、合計1,800。積数1あたり1,800,000円÷1,800＝1,000円。製品A＝1,000×1,000円＝1,000,000円で1個**1,000円**、製品B＝800×1,000円＝800,000円で1個**400円**。数量の比（1：2）で按分しないこと。
::
::
::problem 組間接費900,000円を、直接作業時間（A組250時間、B組350時間）を基準に配賦した。A組の組直接費は1,000,000円、B組は1,400,000円である。各組の仕掛品に集計される製造費用を求めなさい。
A組 [[1,375,000]] 円、B組 [[1,925,000]] 円
::answer
配賦率＝900,000円÷600時間＝1,500円。A組＝1,000,000＋250×1,500＝**1,375,000円**、B組＝1,400,000＋350×1,500＝**1,925,000円**。
::
::
::problem 第2工程の資料から、累加法による第2工程の完成品総合原価を求めなさい。前工程費は始点で投入され、月初仕掛品はない。
前工程費 2,000,000円（当月投入 1,000個）、第2工程の加工費 1,080,000円
完成品 800個、月末仕掛品 200個（進捗度50%）
完成品総合原価 [[2,560,000]] 円
::answer
**前工程費**：2,000,000円÷(800＋200)＝2,000円。月末 200個×2,000円＝400,000円、完成品 1,600,000円
**加工費**：月末の換算量 200×50%＝100個。1,080,000円÷(800＋100)＝1,200円。月末 100×1,200＝120,000円、完成品 960,000円
完成品総合原価＝1,600,000＋960,000＝**2,560,000円**。前工程費に進捗度を掛けて100個分にしないこと。
::
