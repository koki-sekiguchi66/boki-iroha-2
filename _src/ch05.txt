::mystery 機械に触れない酒が、機械の費用を背負っていた
2月の第1月曜日。原価計算表の束を持って事務所に来たのは、杜氏の小松だった。数字の話を嫌う小松が、自分から表を持ってくるのは初めてだった。
「専務。この大吟醸の『製造間接費』という行。1本あたり**533円**。これには何が入っとる」
澪は答えた。蔵全体の製造間接費を、蔵人の直接作業時間1時間あたり4,000円で割り振っている。大吟醸は作業時間が長いから、そのぶん多く背負う。
「その製造間接費の中に、瓶詰めラインの減価償却費も入っとるんだろう」
入っていた。瓶詰めラインは、蔵でいちばん高い機械だ。
「斗瓶取りは、袋から垂れた雫を斗瓶に受けて、1本ずつ手で瓶に詰めとる。あの機械には、指一本触れとらん。なのに、なんで機械の費用を払わされとるんだ」
澪は、言い返せなかった。**機械を使わない大吟醸が、なぜ機械の費用を背負っていたのか？**
::

## 工場全体の配賦率の限界

第4章で、澪は製造間接費を、工場全体で1つの予定配賦率（直接作業時間1時間あたり4,000円）で製品に割り振った。これを**総括配賦**という。
総括配賦は簡単だが、蔵の中の仕事の違いを無視している。汐見酒造の製造は、大きく2つの場所に分かれる。

::table 汐見酒造の2つの製造部門
| 部門 | 仕事 | 費用の中心 | 費用を生む原因 |
| 醸造部門 | 精米・麹・酒母・醪・上槽 | 蔵人の手間、タンク、麹室 | 人の作業時間 |
| 瓶詰め部門 | ろ過・火入れ・瓶詰め・ラベル貼り | 瓶詰めラインの減価償却費・電力 | 機械の運転時間 |
::

醸造部門の費用は人の手間に比例し、瓶詰め部門の費用は機械の運転時間に比例する。それなのに、両方の費用を合計して、人の作業時間だけで割り振れば、手間のかかる大吟醸に、機械の費用まで乗ってしまう。逆に、機械で大量に詰める普通酒は、機械の費用を十分に負担しない。
そこで、製造間接費を**部門**ごとに集め、部門ごとにふさわしい物差し（配賦基準）で製品に割り振る。これを**部門別計算**という。

::theory 部門別計算の3つのステップ
1. **第1次集計**：製造間接費を、部門ごとに集める。どの部門の費用か分かるもの（**部門個別費**）はその部門に直接集め、複数の部門に共通するもの（**部門共通費**）は適切な基準で配賦する
2. **第2次集計**：製品の製造を直接行わない**補助部門**の費用を、**製造部門**に配賦する
3. **製品への配賦**：製造部門ごとの配賦率（部門別予定配賦率）で、製品に割り振る
::

汐見酒造の部門は、次の5つだ。製造部門が2つ、それを支える補助部門が3つ。

::table 汐見酒造の部門
| 種類 | 部門 | 仕事 |
| 製造部門 | 醸造部門 | 米を酒にする |
| 製造部門 | 瓶詰め部門 | 酒を瓶に詰めて製品にする |
| 補助部門 | ボイラー部門 | 蒸し米と火入れのための蒸気を作る |
| 補助部門 | 品質管理部門 | 醪と製品の成分・微生物を検査する |
| 補助部門 | 工場事務部門 | 蔵の給与計算・資材の発注・記録 |
::

## 第1次集計 ― 部門個別費と部門共通費

蔵の建物の減価償却費や火災保険料は、どの部門のものとも言えない。こうした**部門共通費**は、費用を生む原因に合った基準で各部門に配賦する。

::table 部門共通費の配賦基準の例
| 部門共通費 | 配賦基準 |
| 建物の減価償却費・火災保険料・固定資産税 | 床面積 |
| 電力料 | 電力の消費量（または機械の馬力×運転時間） |
| 福利厚生費・工場の事務の費用 | 従業員数 |
| 機械の保険料 | 機械の帳簿価額 |
::

2月の製造間接費800万円を集計すると、部門費はこうなった（これを**部門費配分表**という）。

::table sum 2月の部門費（第1次集計、単位：円）
| 部門 | 部門個別費＋部門共通費の配賦額 |
| 醸造部門 | 3,800,000 |
| 瓶詰め部門 | 2,200,000 |
| ボイラー部門 | 900,000 |
| 品質管理部門 | 600,000 |
| 工場事務部門 | 500,000 |
|= 合計 | 8,000,000 |
::

## 第2次集計 ― 補助部門の費用を、誰が負担するか

補助部門は、酒を造らない。ボイラー部門は蒸気を、品質管理部門は検査を、工場事務部門は事務を、ほかの部門に提供している。だから、その費用は、サービスを受けた部門が負担するのが筋だ。
2月の補助部門のサービスの提供量は、次のとおりだった。

::table 補助部門のサービスの提供量（2月）
| 補助部門（配賦基準） | 醸造部門 | 瓶詰め部門 | ボイラー部門 | 品質管理部門 | 工場事務部門 |
| ボイラー部門（蒸気の供給量） | 500t | 250t | ― | 150t | ― |
| 品質管理部門（検査件数） | 240件 | 160件 | 100件 | ― | ― |
| 工場事務部門（従業員数） | 15人 | 5人 | 3人 | 2人 | ― |
::

品質管理部門は、ボイラーの水の水質も検査している。ボイラー部門は、検査室の蒸留器にも蒸気を送っている。補助部門どうしも、互いにサービスを提供し合っているのだ。この「補助部門どうしのやりとり」をどう扱うかで、方法が2つに分かれる。

### 直接配賦法 ― 補助部門どうしのやりとりを無視する

::example 直接配賦法で、補助部門費を製造部門に配賦しなさい
::answer
補助部門どうしのサービスを無視し、製造部門（醸造・瓶詰め）の利用量の比だけで配賦する。
- ボイラー部門 900,000円：醸造500t：瓶詰め250t → 醸造600,000円、瓶詰め300,000円
- 品質管理部門 600,000円：醸造240件：瓶詰め160件 → 醸造360,000円、瓶詰め240,000円
- 工場事務部門 500,000円：醸造15人：瓶詰め5人 → 醸造375,000円、瓶詰め125,000円

::table sum 直接配賦法による製造部門費（単位：円）
| 項目 | 醸造部門 | 瓶詰め部門 |
| 第1次集計の部門費 | 3,800,000 | 2,200,000 |
| ボイラー部門費 | 600,000 | 300,000 |
| 品質管理部門費 | 360,000 | 240,000 |
| 工場事務部門費 | 375,000 | 125,000 |
|= 製造部門費 | 5,135,000 | 2,865,000 |
::
::journal 補助部門費の配賦（直接配賦法）
醸造部門費 1,335,000 | ボイラー部門費 900,000
瓶詰め部門費 665,000 | 品質管理部門費 600,000
 | 工場事務部門費 500,000
::
簡単だが、ボイラー部門が品質管理部門に送った蒸気の分（150t）も、品質管理部門がボイラーの水を検査した分（100件）も、なかったことになる。
::
::

### 相互配賦法（簡便法） ― 1回目だけ、補助部門どうしにも配る

::example 相互配賦法（簡便法）で、補助部門費を製造部門に配賦しなさい
::answer
**第1次配賦**：補助部門どうしのサービスも含めて、すべての利用部門に配賦する（自分自身には配賦しない）。
- ボイラー部門 900,000円：醸造500t：瓶詰め250t：品質管理150t → 500,000円・250,000円・150,000円
- 品質管理部門 600,000円：醸造240件：瓶詰め160件：ボイラー100件 → 288,000円・192,000円・120,000円
- 工場事務部門 500,000円：醸造15人：瓶詰め5人：ボイラー3人：品質管理2人 → 300,000円・100,000円・60,000円・40,000円

**第2次配賦**：第1次配賦で補助部門が受け取った額を、直接配賦法と同じく製造部門だけに配賦する。
- ボイラー部門が受け取った額：品質管理から120,000円＋工場事務から60,000円＝180,000円 → 醸造120,000円、瓶詰め60,000円（500：250）
- 品質管理部門が受け取った額：ボイラーから150,000円＋工場事務から40,000円＝190,000円 → 醸造114,000円、瓶詰め76,000円（240：160）
- 工場事務部門が受け取った額：0円

::table sum 相互配賦法（簡便法）による製造部門費（単位：円）
| 項目 | 醸造部門 | 瓶詰め部門 |
| 第1次集計の部門費 | 3,800,000 | 2,200,000 |
| 第1次配賦：ボイラー部門費 | 500,000 | 250,000 |
| 第1次配賦：品質管理部門費 | 288,000 | 192,000 |
| 第1次配賦：工場事務部門費 | 300,000 | 100,000 |
| 第2次配賦：ボイラー部門費 | 120,000 | 60,000 |
| 第2次配賦：品質管理部門費 | 114,000 | 76,000 |
|= 製造部門費 | 5,122,000 | 2,878,000 |
::
直接配賦法と比べると、醸造部門が13,000円少なく、瓶詰め部門が13,000円多い。瓶詰め部門は火入れで蒸気をよく使い、製品検査も多い。補助部門どうしのやりとりを経由した分まで含めると、そのぶん負担が増えるのだ。2つの製造部門の合計は、どちらの方法でも8,000,000円で変わらない。
::
::

::exam 補助部門費の配賦の急所
- **直接配賦法**：補助部門どうしのサービスを無視し、製造部門の利用量の比だけで配賦する。問題の表に補助部門の列があっても使わない
- **相互配賦法（簡便法）**：第1次配賦は補助部門どうしにも配賦（自部門には配賦しない）、第2次配賦は第1次配賦で受け取った額を製造部門だけに配賦する
- 配賦の比率は、配賦される側の合計で割る。直接配賦法なら「製造部門の合計」、相互配賦法の第1次配賦なら「自部門を除くすべての利用部門の合計」
- 最後に、製造部門費の合計＝第1次集計の総額になるかを検算する
- 2級の相互配賦法は**簡便法**（2回目で打ち切る）。補助部門費を連立方程式で配賦する方法（連立方程式法）は1級の範囲
::

## 製品への配賦 ― 部門ごとに、ふさわしい物差しで

部門別計算の最後のステップで、澪は、部門ごとに別の物差しを使うことにした。醸造部門は蔵人の**直接作業時間**、瓶詰め部門は瓶詰めラインの**機械運転時間**だ。今期の予算から、それぞれの予定配賦率を計算した。

::table 部門別の予定配賦率
| 製造部門 | 年間の部門費予算 | 年間の基準操業度 | 予定配賦率 |
| 醸造部門 | 6,144万円 | 直接作業時間 24,000時間 | 2,560円／時間 |
| 瓶詰め部門 | 3,456万円 | 機械運転時間 4,800時間 | 7,200円／時間 |
::

::example 2月の製造部門費を、製品に予定配賦しなさい
2月の実際の操業度は、醸造部門の直接作業時間2,000時間、瓶詰め部門の機械運転時間400時間だった。製造部門費の実際額は、相互配賦法（簡便法）による額（醸造5,122,000円、瓶詰め2,878,000円）である。
::answer
::journal (1) 予定配賦：醸造2,000時間×2,560円、瓶詰め400時間×7,200円
仕掛品 8,000,000 | 醸造部門費 5,120,000
 | 瓶詰め部門費 2,880,000
::
::journal (2) 部門別の配賦差異：醸造5,120,000円－5,122,000円＝△2,000円、瓶詰め2,880,000円－2,878,000円＝＋2,000円
製造部門費配賦差異 2,000 | 醸造部門費 2,000
瓶詰め部門費 2,000 | 製造部門費配賦差異 2,000
::
配賦差異は部門ごとに計算する。醸造部門は不利差異（借方）、瓶詰め部門は有利差異（貸方）だ。部門ごとに差異を見れば、どの部門で予算を超えたかが分かる。
::

## 答え合わせ ― 大吟醸の機械の費用

::scene 2月の第1月曜日、夜 ― 蔵の事務所
澪は、2月に仕込んだ2つの酒を例に、総括配賦と部門別配賦を並べてみた。大吟醸のタンク1本（3,000本分）と、普通酒の仕込み（6万本分）だ。
「大吟醸は、醸造部門の作業時間が400時間、瓶詰めラインは20時間だけ。普通酒は、作業時間が600時間で、ラインは240時間」
小松が身を乗り出した。
::

::solve 工場全体の物差しが、機械の費用を手作業の酒に押しつけていた
::table 2月の製造間接費の配賦の比較
| 項目 | 大吟醸（3,000本） | 普通酒（60,000本） |
| 醸造部門の直接作業時間 | 400時間 | 600時間 |
| 瓶詰め部門の機械運転時間 | 20時間 | 240時間 |
| **総括配賦**（直接作業時間×4,000円） | 1,600,000円 | 2,400,000円 |
| 1本あたり | 533円 | 40円 |
| **部門別配賦**（醸造×2,560円＋瓶詰め×7,200円） | 1,168,000円 | 3,264,000円 |
| 1本あたり | 389円 | 54円 |
::
総括配賦では、瓶詰めラインの費用も、人の作業時間に比例して割り振られていた。手間のかかる大吟醸は作業時間が長いので、ほとんど使っていない機械の費用まで背負い、1本533円。部門別に分けて、瓶詰め部門の費用を機械の運転時間で割り振ると、大吟醸は**1本389円**に下がった。代わりに、ラインをフルに使う普通酒は40円から**54円**に上がった。
製造間接費の総額は変わらない。変わるのは、**どの酒が、どの費用を生んでいるのか**という、原価の正確さだ。
::

小松は、表をしばらく黙って見ていた。「144円か」
「1本あたり、144円です。大吟醸は、序章で計算したほど悪い酒ではありませんでした」
「だが、作業時間を食うのは同じだろう」
「はい。第1章で見た、作業1時間あたりの稼ぎの順番は変わりません。でも、普通酒の原価が少し上がったので、普通酒の値段を据え置いたまま増やすのが正しいかは、もう一度確かめる必要があります」
小松は立ち上がり、出ていきかけて振り返った。「あんたの数字は、毎月少しずつ、本当のことに近づいとるな」

::danger 「公平に見える」配賦基準が、判断を誤らせる
総括配賦の1つの率は、全員に同じ物差しを当てるので、一見公平に見える。だが、費用を生む原因が部門ごとに違うのに同じ物差しを使えば、ある製品の原価は過大に、別の製品の原価は過小になる。過小に計算された製品は「儲かる」ように見えて増産され、過大に計算された製品は「赤字」に見えて削られる。
配賦基準は、**その費用を生んでいる原因**（人の時間か、機械の時間か、検査の回数か）に合わせて選ぶ。これが、序章からの澪の1年を貫く原価計算の核心だ。
::

::real 大学の「間接経費」― 研究費の何%を、図書館や事務が受け取るべきか
大学の研究にも、部門別計算と同じ問題がある。研究室で使う試薬や装置の費用（直接経費）のほかに、大学には、建物の維持、図書館、共用の大型装置、事務や安全管理といった、どの研究のためとも言い切れない費用がかかる。いわば、大学の**補助部門**の費用だ。
日本の科学研究費助成事業（科研費）では、研究者に交付される直接経費とは別に、**直接経費の30%**に相当する額が、**間接経費**として研究機関に交付される。研究環境の改善や、共用設備の整備、事務の体制などに使う費用だ。
アメリカでは、国立衛生研究所（NIH）などの研究費の間接経費の率は、大学ごとに政府と交渉して決める仕組みになっている。2025年2月、NIHはこの率を一律**15%**に制限すると発表した。大学などが提訴し、裁判所は差し止めを命じた。2026年1月、連邦控訴裁判所も、率は機関ごとに交渉して決めるという規則に反するとして、一律の制限を違法と判断している。

**この章の道具で読む ― 大学を1つの工場と見ると**
研究室を製造部門、図書館・事務・共用設備を補助部門と見れば、間接経費の率は、補助部門費を研究（製品）に割り振る**予定配賦率**にあたる。配賦基準は「直接経費の額」だ。
仮に、直接経費1,000万円の研究プロジェクトがあり、そのプロジェクトが実際に使った補助部門のサービスの費用が450万円だったとする（仕組みを示すための例）。
::journal ① 30%の率で予定配賦する（1,000万円×30%）
研究プロジェクト 3,000,000 | 補助部門費 3,000,000
::
::journal ② 実際の450万円との差は、配賦差異として大学が負担する
補助部門費配賦差異 1,500,000 | 補助部門費 1,500,000
::
率が15%に下がれば、①の配賦額は150万円になり、差異（大学が自前で埋める額）は300万円に膨らむ。補助部門の費用は、配賦率を下げても消えない。誰が負担するかが変わるだけだ。
しかも、一律の率は、「試薬と大型装置を大量に使う実験系の研究室」と「紙と鉛筆で済む理論系の研究室」に、同じ物差しを当てる。総括配賦と同じで、一律は単純で公平に見えるが、費用を生む原因の違いを映さない。アメリカで率を機関ごとに交渉で決めてきたのは、大学によって建物や設備の費用の構造がまったく違うからだ。
::note

::cfo 品質管理部門の費用を、何の物差しで配るか
部門別計算を始めて1か月。瓶詰め部門の責任者・宇佐美が、品質管理部門の費用の配り方に疑問を出した。「検査件数で配ると、醸造部門が6割を負担します。でも、醪の検査は15分で終わる。うちの製品検査は、微生物の培養があるから1件1時間半かかる。検査室の人と装置を食っているのは、うちのほうです」
小松も黙っていない。「件数で配って、何が悪い。毎日検査を頼んどるのは、うちだ」
::table 品質管理部門の費用600,000円と、利用の実態（直接配賦法で考える）
| 項目 | 醸造部門 | 瓶詰め部門 |
| 検査件数 | 240件 | 160件 |
| 1件あたりの検査時間 | 0.25時間 | 1.5時間 |
| 検査時間の合計 | 60時間 | 240時間 |
| 品質管理部門の費用の中身 | 検査員の給料と、検査装置の減価償却費がほぼすべて | |
::
まず、件数で配った場合と、検査時間で配った場合の、各部門の負担額を計算してから選んでほしい。
::choice A. いまの検査件数のまま。依頼の回数は、利用の実態を素直に表している
**△ 回数は数えやすいが、費用の原因を映していない。**件数で配ると、醸造部門360,000円、瓶詰め部門240,000円。だが、品質管理部門の費用は、検査員の時間と装置の時間でほぼ決まる。15分の検査と1時間半の検査を同じ1件と数えれば、醸造部門が、瓶詰め部門の長い検査の費用を肩代わりすることになる。
::
::choice B. 検査時間で配る。費用を生んでいるのは、検査員と装置の時間だから
**◎ 費用の原因に合った物差し。**検査時間で配ると、醸造部門は60÷300×600,000円＝**120,000円**、瓶詰め部門は240÷300×600,000円＝**480,000円**。瓶詰め部門の負担は240,000円増える。
瓶詰め部門費が増えれば、機械運転時間あたりの配賦率も上がり、ラインを長く使う普通酒の原価がさらに上がる。宇佐美にとっては耳の痛い結論だが、正確な原価は、普通酒の値付けや、製品検査の効率化（培養の外注など）を考える出発点になる。
::
::choice C. 揉めないように、醸造部門と瓶詰め部門で半分ずつ負担する
**× 争いは収まるが、原価が両方とも不正確になる。**300,000円ずつにすると、検査時間で見た実態（120,000円と480,000円）から、どちらの部門も大きくずれる。配賦は、関係者を納得させるための割り勘ではない。製品の原価を正しく知るための計算だ。
::
::choice D. 品質管理は蔵全体のための仕事なので、製品に配賦せず、販売費及び一般管理費にする
**× 製造のための費用を、製造原価から外してしまう。**醪と製品の検査は、酒を造るために必要な仕事で、製造原価に入る。販管費に回せば、酒の原価は60万円分過小になり、在庫の金額も利益も正しく計算できない。第1章で学んだ「原価の範囲」の誤りだ。
::
::answer 考え方の例を見る
補助部門費の配賦基準は、「誰がいちばん多く頼んでいるか」ではなく、「その部門の費用を、何が生んでいるか」で選ぶ。人と装置の時間で費用が決まる部門なら、時間を物差しにする。物差しが費用の原因からずれるほど、製品の原価は不正確になる。
翌月から、品質管理部門費は検査時間で配賦することになった。宇佐美は、微生物の培養検査の一部を県の醸造試験場に頼む案を出した。この試験場との縁は、第17章で、新しい酵母の共同研究へとつながっていく。
::

::next 配賦の正確さを突きつめると、活動基準原価計算へ
部門別計算は、製造間接費を「部門」という単位で正確にしようとする方法だ。1級では、さらに細かく、検査・段取り・発注といった「活動」ごとに費用を集めて製品に割り振る**活動基準原価計算（ABC）**を学ぶ。また、補助部門費の配賦では、連立方程式法や、予算額で配賦する方法、変動費と固定費で基準を分ける方法（複数基準配賦法）など、より精密な手法が登場する。
::

## 確認問題

::quiz
::problem 次の資料から、直接配賦法により、補助部門費を製造部門（第1製造部・第2製造部）に配賦しなさい。
部門費：第1製造部 1,000,000円、第2製造部 800,000円、動力部 300,000円、修繕部 200,000円
動力部の動力供給量：第1製造部 600kWh、第2製造部 400kWh、修繕部 200kWh
修繕部の修繕時間：第1製造部 30時間、第2製造部 70時間、動力部 25時間
第1製造部の製造部門費 [[1,240,000]] 円、第2製造部の製造部門費 [[1,060,000]] 円
::answer
直接配賦法なので、補助部門どうしの数字（修繕部の200kWh、動力部の25時間）は使わない。
- 動力部 300,000円：600：400 → 第1製造部180,000円、第2製造部120,000円
- 修繕部 200,000円：30：70 → 第1製造部60,000円、第2製造部140,000円
第1製造部＝1,000,000円＋180,000円＋60,000円＝**1,240,000円**、第2製造部＝800,000円＋120,000円＋140,000円＝**1,060,000円**。合計2,300,000円は、部門費の総額と一致する。
::
::
::problem 上の資料を使い、相互配賦法（簡便法）により、第1製造部の製造部門費を求めなさい。
第1製造部の製造部門費 [[1,237,000]] 円
::answer
**第1次配賦**
- 動力部 300,000円：600：400：200 → 第1製造部150,000円、第2製造部100,000円、修繕部50,000円
- 修繕部 200,000円：30：70：25 → 第1製造部48,000円、第2製造部112,000円、動力部40,000円
**第2次配賦**
- 動力部が受け取った40,000円：600：400 → 第1製造部24,000円、第2製造部16,000円
- 修繕部が受け取った50,000円：30：70 → 第1製造部15,000円、第2製造部35,000円
第1製造部＝1,000,000円＋150,000円＋48,000円＋24,000円＋15,000円＝**1,237,000円**。第2製造部は800,000円＋100,000円＋112,000円＋16,000円＋35,000円＝1,063,000円で、合計2,300,000円は部門費の総額と一致する。直接配賦法（1,240,000円）より3,000円少ないのは、動力を多く使う修繕部を経由した分が、修繕を多く使う第2製造部へ流れたからだ。

::summary
- 部門別計算は、製造間接費を部門ごとに集め、部門ごとにふさわしい配賦基準で製品に割り振る方法。総括配賦の「1つの物差し」の限界を補う
- 第1次集計：部門個別費はその部門へ、部門共通費は床面積・従業員数などの基準で配賦する
- 第2次集計：補助部門費を製造部門へ配賦する。直接配賦法は補助部門どうしのサービスを無視、相互配賦法（簡便法）は第1次配賦だけ補助部門どうしにも配賦する
- 製造部門ごとに予定配賦率を決めて製品に配賦し、配賦差異も部門ごとに把握する
- 配賦基準は「その費用を何が生んでいるか」で選ぶ。物差しを誤ると、製品の原価が過大・過小になり、判断を誤る
::
