::mystery 押し付け合いの会議
2月10日、水曜日、午後4時。帳場の奥の8畳間に、蔵の各部門の責任者が集まった。澪が初めて開いた「部門の会議」だ。
澪が配ったのは、1月の製造間接費800万円を、部門ごとに分けた表だった。読み終えるより早く、瓶詰め部門の宇佐美が、紙を机にたたきつけた。
宇佐美：「品質管理室の60万円、なんでうちが4割も持つんですか。検査はほとんど、醸造部門の醪の分析でしょう」
小松：「瓶に詰める前の検査を、毎日頼んどるのはどっちだ」
宇佐美：「件数なら醸造のほうが多いって、品質管理室の記録に出てるじゃないですか」
澪は、間に入るつもりで言った。
澪：「使った分だけ払う。それがいちばん公平ですよね」
2人が同時に澪を見た。
宇佐美：「だから、その『使った分』を何で測るかで、もめてるんですよ」
澪は、言葉に詰まった。件数で測るのか。時間で測るのか。物差しを変えれば、誰の負担が増えて、誰の負担が減るのか。
**品質管理室の費用は、本当はどの部門が、どの酒が、払うべきなのか？**
::

## 蔵の見取り図 ― 製造部門と補助部門

翌朝、澪は蔵の見取り図を広げ、陸と一緒に、部屋ごとに色を塗った。
陸：「醪を造る部屋と、瓶に詰める部屋は分かるっす。でも、ボイラー室と品質管理室って、酒を造ってないっすよね」
澪：「造ってはいない。でも、ボイラーがなければ米は蒸せないし、検査がなければ瓶詰めできない」
製品を直接作る部門を**製造部門**、製造部門を手伝う部門を**補助部門**という。

::table 汐見酒造の部門
| 種類 | 部門 | 仕事 | 費用を生む原因 |
| 製造部門 | 醸造部門 | 精米・麹・酒母・醪・上槽 | 蔵人の作業時間 |
| 製造部門 | 瓶詰め部門 | ろ過・火入れ・瓶詰め・ラベル貼り | 瓶詰めラインの運転時間 |
| 補助部門 | ボイラー部門 | 蒸し米と火入れのための蒸気を作る | 蒸気の量 |
| 補助部門 | 品質管理部門 | 醪と製品の成分・微生物を検査する | 検査の量 |
| 補助部門 | 工場事務部門 | 蔵の給与計算・資材の発注・記録 | 人の数 |
::

椎名に電話すると、すぐに要点が返ってきた。
椎名：「第4章では、製造間接費を1つの箱に集めて、作業時間で配りましたね。でも、瓶詰め部門の費用は、人の時間ではなく機械の時間で生まれています」
椎名：「費用を生む原因が部門ごとに違うなら、部門ごとに集めて、部門ごとの物差しで配る。それが**部門別計算**です」

::point メモ ― 部門別計算の3つの手順
**第1次集計**：製造間接費を、部門個別費と部門共通費に分けて各部門に集める。**第2次集計**：補助部門に集まった費用を、製造部門に配賦する。**製品への配賦**：製造部門ごとの配賦率で、製品（仕掛品）に配賦する。
::

## 床面積と従業員数 ― 部門個別費と部門共通費（第1次集計）

製造間接費のうち、どの部門で生じたかがはっきりしているものを**部門個別費**という。瓶詰めラインの減価償却費は瓶詰め部門、ボイラー係の給料はボイラー部門だ。
複数の部門に共通して生じるものは**部門共通費**という。蔵の建物の減価償却費や、工場全体の電気代は、適切な物差しで各部門に配る。

::table 部門共通費の配賦基準の例
| 部門共通費 | 配賦基準 |
| 建物の減価償却費・火災保険料・固定資産税 | 床面積 |
| 電力料 | 電力の消費量（または機械の馬力×運転時間） |
| 福利厚生費・工場の事務の費用 | 従業員数 |
| 機械の保険料 | 機械の帳簿価額 |
::

::example 蔵の建物の減価償却費を、床面積で各部門に配る
2月の蔵の建物の減価償却費（部門共通費）は500,000円。各部門の床面積は、醸造部門400㎡、瓶詰め部門300㎡、ボイラー部門100㎡、品質管理部門100㎡、工場事務部門100㎡（合計1,000㎡）である。
::answer
1㎡あたり500,000円÷1,000㎡＝500円。醸造部門200,000円、瓶詰め部門150,000円、ボイラー部門50,000円、品質管理部門50,000円、工場事務部門50,000円。
建物の費用は、使っている広さに比例して生まれると考えて、床面積で配る。
::trap
部門共通費を、製造部門だけに配らないこと。第1次集計では、補助部門も含めた**すべての部門**に配る。補助部門から製造部門へ移すのは、次の第2次集計の仕事だ。
::
::
::

## 補助部門の費用を、製造部門へ ― 直接配賦法と相互配賦法（第2次集計）

補助部門の費用は、最後にはすべて製造部門に移さなければならない。酒を造るのは製造部門だけだからだ。
品質管理室の検査員に聞いて、2月に各補助部門がどの部門にどれだけサービスをしたかを表にした。

::table 補助部門のサービスの提供量（2月）
| 補助部門（配賦基準） | 醸造 | 瓶詰め | ボイラー | 品質管理 | 工場事務 |
| ボイラー（蒸気の量） | 500t | 250t | ― | 150t | ― |
| 品質管理（検査件数） | 240件 | 160件 | 100件 | ― | ― |
| 工場事務（従業員数） | 15人 | 5人 | 3人 | 2人 | ― |
::

陸：「ボイラー部門も、品質管理の検査を受けてるんすね。補助部門どうしで、お互いに手伝ってる」
澪：「そこをどう扱うかで、方法が2つに分かれるらしい」

**直接配賦法**は、補助部門どうしのサービスを無視して、製造部門への提供量の割合だけで配る方法だ。

::table sum 直接配賦法による製造部門費（単位：円）
| 項目 | 醸造部門 | 瓶詰め部門 |
| 第1次集計の部門費 | 3,800,000 | 2,200,000 |
| ボイラー部門費（500t：250t） | 600,000 | 300,000 |
| 品質管理部門費（240件：160件） | 360,000 | 240,000 |
| 工場事務部門費（15人：5人） | 375,000 | 125,000 |
|= 製造部門費 | 5,135,000 | 2,865,000 |
::

**相互配賦法（簡便法）**は、補助部門どうしのサービスも1回だけ認める方法だ。第1次配賦では、ほかの補助部門も含めた提供量の割合で配る。そこで補助部門に戻ってきた費用は、第2次配賦で、直接配賦法と同じく製造部門だけに配る。

::table sum 相互配賦法（簡便法）による製造部門費（単位：円）
| 項目 | 醸造部門 | 瓶詰め部門 |
| 第1次集計の部門費 | 3,800,000 | 2,200,000 |
| 第1次配賦：ボイラー部門費（500：250：品質管理150） | 500,000 | 250,000 |
| 第1次配賦：品質管理部門費（240：160：ボイラー100） | 288,000 | 192,000 |
| 第1次配賦：工場事務部門費（15：5：ボイラー3：品質管理2） | 300,000 | 100,000 |
| 第2次配賦：ボイラー部門費（戻り180,000円） | 120,000 | 60,000 |
| 第2次配賦：品質管理部門費（戻り190,000円） | 114,000 | 76,000 |
|= 製造部門費 | 5,122,000 | 2,878,000 |
::

::note
※第1次配賦でボイラー部門に戻る費用は、品質管理部門から120,000円（600,000円×100/500）と工場事務部門から60,000円（500,000円×3/25）の合計180,000円。品質管理部門に戻る費用は、ボイラー部門から150,000円（900,000円×150/900）と工場事務部門から40,000円（500,000円×2/25）の合計190,000円。
::

::example 第2次集計を、直接配賦法で仕訳する
上の直接配賦法の表にもとづき、補助部門費を製造部門に配賦する。
::answer
::journal 補助部門費を製造部門に振り替える
醸造部門費 1,335,000 | ボイラー部門費 900,000
瓶詰め部門費 665,000 | 品質管理部門費 600,000
 | 工場事務部門費 500,000
::
醸造部門には600,000＋360,000＋375,000＝1,335,000円、瓶詰め部門には300,000＋240,000＋125,000＝665,000円が移る。補助部門費の勘定は、これで残高がゼロになる。
::trap
直接配賦法の配賦割合は、**製造部門への提供量だけ**で計算する。品質管理部門費なら240：160で、ボイラー部門への100件は分母に入れない。相互配賦法の第1次配賦と取り違えやすい。
::

::theory 配賦基準は、費用が生まれる原因に合わせる
費用を配る物差し（配賦基準）は、「その費用を生み出している原因」を表すものでなければならない。原因に合わない物差しで配ると、ある部門・ある製品が、ほかの部門・製品の費用を肩代わりすることになる。
序章の「本数割り」と同じ誤りは、部門の中でも起きる。公平かどうかは、気持ちではなく、費用の発生の仕方で決まる。
::

::scene 2月12日、午前10時 ― 品質管理室
澪は品質管理室を訪ね、検査員に作業日誌を見せてもらった。醪の分析は、試料を機械にかければ15分で終わる。瓶詰め前の製品の検査は、香りと色と微生物を確かめ、ロットごとに記録を残す。1件に1時間半かかる。
検査員：「件数だけ数えると、醸造部門のほうが多いんです。でも、手間がかかっているのは、圧倒的に瓶詰め前の検査ですね」
品質管理室の費用60万円は、ほとんどが検査員の給料と、検査装置の減価償却費だった。
::

::table 品質管理部門の費用600,000円と、利用の実態（直接配賦法で考える）
| 項目 | 醸造部門 | 瓶詰め部門 |
| 検査件数 | 240件 | 160件 |
| 1件あたりの検査時間 | 0.25時間 | 1.5時間 |
| 検査時間の合計 | 60時間 | 240時間 |
::

::challenge 品質管理室の費用は、どう配るのが筋か
手がかりをまとめる。
- 品質管理部門の費用600,000円は、ほぼすべてが検査員の給料と検査装置の減価償却費
- 検査件数は醸造部門240件・瓶詰め部門160件。検査時間は醸造部門60時間・瓶詰め部門240時間
- いまの表は検査件数で配っていて、瓶詰め部門の負担は240,000円（4割）
::choice A. 宇佐美の言うとおり、件数でも醸造部門が6割を使っている。瓶詰め部門の4割の負担は多すぎるので、減らすべきだ
**× 件数という物差しを疑っていない。**検査員の給料も装置の減価償却費も、件数ではなく、検査にかけた時間に比例して生まれる。時間で見ると、瓶詰め部門が8割を使っている。
::
::choice B. 検査1件は1件。件数で配るのが、いちばん分かりやすく公平だ
**△ 分かりやすいが、原因に合っていない。**醪の分析15分と製品の検査1時間半を同じ「1件」と数えると、手間の少ない醸造部門が、瓶詰め部門の検査の費用を肩代わりする。
::
::choice C. 品質管理はすべての酒のためなので、酒の本数で配るべきだ
**× 序章の「本数割り」と同じ落とし穴。**本数は、検査の手間とも、検査員の時間とも関係がない。
::
::choice D. 検査時間で配るべきだ。瓶詰め部門の負担は、件数で配る240,000円から480,000円に増える
**◎ 正解。**費用は検査員の時間に比例して生まれるので、物差しは検査時間。600,000円×240/300＝480,000円が瓶詰め部門、120,000円が醸造部門になる。宇佐美の主張とは逆に、瓶詰め部門の負担は増える。
::
::answer
#### 手順1　費用の中身を見る
品質管理部門の費用は、検査員の給料と検査装置の減価償却費。どちらも、検査にかけた時間に比例して生まれる。
#### 手順2　原因を表す物差しを選ぶ
件数ではなく、検査時間。醸造60時間、瓶詰め240時間。
#### 手順3　計算する
600,000円×60/300＝120,000円（醸造）、600,000円×240/300＝480,000円（瓶詰め）。試験では配賦基準は問題文で与えられることが多いが、「どの基準が適切か」を選ばせる問題も出る。
::
::

::solve 払うべきは、検査の時間を使った部門。そして、その部門を使った酒だ
品質管理室の費用は、件数ではなく検査時間で生まれていた。時間で配ると、瓶詰め部門の負担は24万円から48万円に増える。「醸造部門のための検査だ」という宇佐美の主張は、物差しを件数にしていたから成り立っていた。
澪が会議で検査時間の表を見せると、宇佐美は長いあいだ黙っていた。
宇佐美：「……瓶詰め前の検査、いまの半分の時間でできるやり方を考えます。うちの負担なら、うちで減らせる」
小松は、それ以上何も言わなかった。
もし澪が「使った分だけ払う」を件数のまま押し通していたら、瓶詰め部門の検査は割安に見え続け、誰も検査の手間を減らそうとしなかった。
**公平な配り方とは、声の大きい人が納得する配り方ではなく、費用を生んだ原因に費用を返す配り方だ。**そうして初めて、費用を減らす責任も、正しい人のところへ届く。
::

部門別に集めた費用は、最後に酒へ配る。澪は、部門ごとの予定配賦率を作り、第4章の「1時間4,000円」の総括配賦と比べてみた。

::table 部門別の予定配賦率
| 製造部門 | 年間の部門費予算 | 年間の基準操業度 | 予定配賦率 |
| 醸造部門 | 6,144万円 | 直接作業時間 24,000時間 | 2,560円／時間 |
| 瓶詰め部門 | 3,456万円 | 機械運転時間 4,800時間 | 7,200円／時間 |
::

::table 2月の製造間接費の配賦の比較
| 項目 | 大吟醸（3,000本） | 普通酒（60,000本） |
| 醸造部門の直接作業時間 | 400時間 | 600時間 |
| 瓶詰め部門の機械運転時間 | 20時間 | 240時間 |
| 総括配賦（直接作業時間×4,000円） | 1,600,000円 | 2,400,000円 |
| 1本あたり | 533円 | 40円 |
| 部門別配賦（醸造×2,560円＋瓶詰め×7,200円） | 1,168,000円 | 3,264,000円 |
| 1本あたり | 389円 | 54円 |
::

大吟醸は、手作業の多い醸造部門の時間を使うが、高価な瓶詰めラインはほとんど使わない。普通酒は逆だ。工場全体を1つの物差し（人の作業時間）で配ると、瓶詰めラインの重い費用まで、人手の多い大吟醸が背負っていた。部門別に配ると、大吟醸1本の製造間接費は533円から389円に下がった。
澪：「大吟醸は、まだ手間を食う酒です。でも、瓶詰めラインの分まで背負わされる理由はなかった」

### 試験で狙われるパターン ― 部門別予定配賦・部門別配賦差異・相互配賦法の戻り

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 部門別予定配賦と、部門別配賦差異**　製造部門ごとに予定配賦率を決め、製品に配賦する。実際の製造部門費（第2次集計の結果）との差は、部門ごとの配賦差異になる。

::example 2月の部門別予定配賦と配賦差異
2月の実際の操業度は、醸造部門の直接作業時間2,000時間、瓶詰め部門の機械運転時間400時間だった。予定配賦率は醸造部門2,560円、瓶詰め部門7,200円。第2次集計（直接配賦法）後の実際の製造部門費は、醸造部門5,135,000円、瓶詰め部門2,865,000円である。
::answer
::journal (1) 予定配賦：醸造2,000時間×2,560円、瓶詰め400時間×7,200円
仕掛品 8,000,000 | 醸造部門費 5,120,000
 | 瓶詰め部門費 2,880,000
::
::journal (2) 配賦差異：醸造 5,120,000円－5,135,000円＝△15,000円（不利）、瓶詰め 2,880,000円－2,865,000円＝＋15,000円（有利）
製造部門費配賦差異 15,000 | 醸造部門費 15,000
瓶詰め部門費 15,000 | 製造部門費配賦差異 15,000
::
差異は部門ごとに出す。合計がゼロでも、醸造部門は使いすぎ、瓶詰め部門は節約、という違う情報を持っている。
::trap
部門別の予定配賦率は、**部門ごとの基準操業度**（醸造は作業時間、瓶詰めは機械運転時間）で割って出す。工場全体の作業時間で割らないこと。
::
::
::

**② 相互配賦法（簡便法）の戻り**　第1次配賦で補助部門に戻った費用を、第2次配賦で製造部門だけに配る。第2次配賦の割合は、直接配賦法と同じ（製造部門への提供量だけ）。

**③ 適切な配賦基準を選ぶ**　建物の費用は床面積、電力は消費量、福利厚生費は従業員数。費用を生む原因と物差しの組み合わせを問う出題もある。

::steps 解法の型 ― 部門別計算
1. 第1次集計 | 部門個別費はその部門へ、部門共通費は配賦基準ですべての部門へ
2. 第2次集計の方法を確かめる | 直接配賦法なら製造部門への提供量だけで配る
3. 相互配賦法（簡便法）なら | 第1次配賦はほかの補助部門も含めて配り、戻った分を第2次配賦で製造部門だけに配る
4. 製品への配賦 | 製造部門ごとの配賦率×その部門の操業度（作業時間・機械運転時間）
5. 差異 | 部門ごとに、予定配賦額－実際の製造部門費
::

## 試験場の研究員 ― 研究費の「間接経費」は何%か

::scene 2月18日、午後 ― 県の醸造試験場
新しい酵母の相談で、澪は県の醸造試験場を訪ねた。応対したのは、研究員の早瀬。白衣の胸ポケットに、ボールペンが3本差してある。
早瀬：「共同研究の費用の見積もり、出しておきました。直接にかかる試薬や機器の費用に、間接経費を3割乗せています」
澪：「間接経費？」
早瀬：「建物の光熱費や事務の人件費のような、どの研究のためとも言えない費用です。国の科研費でも、直接経費の30%が間接経費として大学に配られます」
::

国の科学研究費助成事業（科研費）では、研究に直接使う**直接経費**に加えて、その30%にあたる**間接経費**が研究機関に配分される。建物の維持や事務部門のような、研究を支える共通の費用を賄うためだ。
アメリカでは2025年2月、国立衛生研究所（NIH）が、大学などに払う間接経費の率を一律15%に下げると発表した。大学側は、それぞれの機関と交渉して決めてきた率（多くは15%を大きく超える）を一方的に変えるのは違法だと訴え、裁判所は上限の適用を止めた。2026年1月5日には、連邦の控訴裁判所も、上限は違法だとする判断を支持した。
澪は、この争いを、この章の部門別計算の言葉に置き換えてみた。大学の研究室を「製造部門」、建物の管理や事務を「補助部門」とすれば、間接経費率は補助部門費の配賦率そのものだ。直接経費1,000万円の研究なら、30%なら300万円、15%なら150万円が配られる。

::journal ① 間接経費率30%のとき：補助部門の費用を研究（製造部門）に配る
研究費（研究室） 3,000,000 | 管理部門費 3,000,000
::

::journal ② 15%に下げると：配れなかった150万円は、大学に残る
研究費（研究室） 1,500,000 | 管理部門費 1,500,000
::

配賦率を下げても、建物の光熱費や事務の人件費そのものは1円も減らない。配れなかった150万円は、大学のどこかが自腹で負担することになる。配賦率をめぐる争いは、「費用を誰が負担するか」の争いだった。
早瀬：「蔵でも同じでしょう。部門の費用の押し付け合い」
澪は、昨日の会議を思い出して、苦笑いした。

::note
出典：[文部科学省・日本学術振興会「科研費ハンドブック（研究者用）2026年度版」](https://www.jsps.go.jp/file/storage/kaken_15_2026/r8_handbook_kenkyusha.pdf)、[NIH「Supplemental Guidance to the 2024 NIH Grants Policy Statement: Indirect Cost Rates」（NOT-OD-25-068、2025年2月7日）](https://grants.nih.gov/grants/guide/notice-files/not-od-25-068.html)、[Venable LLP「First Circuit Holds NIH Rate Caps Unlawful」（2026年1月）](https://www.venable.com/insights/publications/2026/01/first-circuit-holds-nih-rate-caps-unlawful)
::

::danger 配賦率で、費用は消えない
配賦率や配賦基準を変えても、費用の総額は1円も変わらない。変わるのは、誰が負担するかだけだ。部門の業績を良く見せるために配賦基準を変える提案には、「その費用は、どこへ移るのか」を必ず確かめる。
::

::exam 部門別計算の急所
- 第1次集計：部門個別費はその部門へ、部門共通費は配賦基準で**補助部門も含むすべての部門**へ
- 直接配賦法：補助部門どうしのサービスを無視し、**製造部門への提供量だけ**で配る
- 相互配賦法（簡便法）：第1次配賦は補助部門どうしも含めて配り、戻った分を第2次配賦で製造部門だけに配る
- 部門別予定配賦率＝部門の年間予算÷部門の基準操業度（醸造は作業時間、瓶詰めは機械運転時間など）
- 部門別配賦差異は、部門ごとに「予定配賦額－実際の製造部門費」
::

::next 物差しの選び方は、活動基準原価計算へ
1級では、補助部門費の配賦を、変動費と固定費に分けて別々の基準で配る方法（複数基準配賦法）や、連立方程式で補助部門どうしのやり取りを何度でも計算する方法（連立方程式法）を学ぶ。さらに進むと、作業の種類（活動）ごとに原価を集めて配る活動基準原価計算（ABC）にたどり着く。
::

::summary
- 製造部門は製品を作る部門、補助部門は製造部門を手伝う部門
- 第1次集計では、部門個別費はその部門へ、部門共通費は配賦基準ですべての部門へ集める
- 第2次集計では、補助部門費を製造部門に配る。直接配賦法は補助部門どうしを無視し、相互配賦法（簡便法）は1回だけ認める
- 製造部門ごとの予定配賦率で製品に配賦し、部門ごとに配賦差異を出す
- 配賦基準は費用を生む原因に合わせる。物差しを変えても費用の総額は変わらず、負担する人が変わる
::

## 確認問題

::quiz
::problem 次の資料から、直接配賦法による各製造部門の製造部門費を求めなさい。
第1次集計：切削部門 1,000,000円、組立部門 800,000円、動力部門 300,000円、修繕部門 300,000円
補助部門のサービスの提供割合　動力部門（切削60%・組立30%・修繕10%）、修繕部門（切削40%・組立40%・動力20%）
切削部門費 [[1,350,000]] 円、組立部門費 [[1,050,000]] 円
::answer
直接配賦法では、補助部門どうしのサービスを無視し、製造部門への割合だけで配る。
- 動力部門費300,000円を60：30で配る → 切削200,000円、組立100,000円
- 修繕部門費300,000円を40：40で配る → 切削150,000円、組立150,000円
切削部門費＝1,000,000＋200,000＋150,000＝**1,350,000円**、組立部門費＝800,000＋100,000＋150,000＝**1,050,000円**。合計2,400,000円は、第1次集計の合計と一致する。
::
::
::problem 上の問題と同じ資料で、相互配賦法（簡便法）による各製造部門の製造部門費を求めなさい。
切削部門費 [[1,355,000]] 円、組立部門費 [[1,045,000]] 円
::answer
**第1次配賦**（補助部門どうしも含めて、提供割合のとおりに配る）
- 動力部門費300,000円：切削180,000円、組立90,000円、修繕30,000円
- 修繕部門費300,000円：切削120,000円、組立120,000円、動力60,000円
**第2次配賦**（戻った分を、製造部門への割合だけで配る）
- 動力部門に戻った60,000円を60：30で → 切削40,000円、組立20,000円
- 修繕部門に戻った30,000円を40：40で → 切削15,000円、組立15,000円
切削部門費＝1,000,000＋180,000＋120,000＋40,000＋15,000＝**1,355,000円**
組立部門費＝800,000＋90,000＋120,000＋20,000＋15,000＝**1,045,000円**
第2次配賦の割合を、第1次配賦と同じ（補助部門を含む）にしてしまう誤りが多い。
::
::
::problem 次の取引を仕訳しなさい。
当月の切削部門の予定配賦率は1時間3,000円、組立部門は1時間2,000円である。当月の実際の操業度は、切削部門400時間、組立部門500時間だった。
(1) 製造部門費を仕掛品に予定配賦した。
(2) 当月の実際の製造部門費は、切削部門1,230,000円、組立部門980,000円だった。部門別配賦差異を計上する。
::answer
::journal (1) 切削400時間×3,000円、組立500時間×2,000円
仕掛品 2,200,000 | 切削部門費 1,200,000
 | 組立部門費 1,000,000
::
::journal (2) 切削 1,200,000円－1,230,000円＝△30,000円（不利）、組立 1,000,000円－980,000円＝＋20,000円（有利）
製造部門費配賦差異 30,000 | 切削部門費 30,000
組立部門費 20,000 | 製造部門費配賦差異 20,000
::
不利差異は製造部門費配賦差異の借方、有利差異は貸方に振り替える。部門ごとに別々に計算する。
::
::
::problem 次の部門共通費に、最も適した配賦基準を選びなさい。
::sort
@cats 床面積 | 従業員数 | 電力の消費量 | 機械の帳簿価額
工場の建物の減価償却費 => 床面積
工場の建物の火災保険料 => 床面積
工場の福利厚生費 => 従業員数
工場の電力料 => 電力の消費量
機械の保険料 => 機械の帳簿価額
::
::answer
建物にかかる費用は広さ、人にかかる費用は人数、電力は使った量、機械の保険料は機械の価額に比例して生まれる。費用が生まれる原因に合った物差しを選ぶ。
::
