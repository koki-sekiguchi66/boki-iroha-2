## この本の特徴

この本は、試験に受かるためだけの教科書ではない。もちろん、日商簿記2級の出題範囲（2027年度適用の出題区分表）はすべてカバーする。だが、それ以上に目指しているのは、あなたが**数字の裏にある「会社の生と死」を読めるようになること**だ。
本書は、1人の跡取りの1年間の物語だ。父が倒れ、東京の商社から新潟の酒蔵・汐見酒造に戻った汐見澪。簿記は3級どまりの彼女が、金賞の大吟醸が売れるほど貧しくなる蔵の謎を、原価計算で解き明かし、資金繰り・決算・統合・連結へと進みながら、蔵を立て直していく。あなたも、澪と一緒に帳面を開き、原価を計算し、仕訳を切りながら、2級の論点が現実の会社でどう使われるのかを、1章ずつ確かめてほしい。各章の「実際にあった話」では、現実の事件や統計を、その章で学ぶ仕訳・計算で読み解いている。

::kpi
収録 | 序章＋26章＋終章（予定） | 2級の商業簿記・工業簿記の全論点
問い | 章ごとに1つ | 各章の冒頭で、澪が出会う
演習 | 確認問題・仕訳道場・模擬試験 | すべて解答・解説つき
::

## 7種類のボックス

各章は、次のボックスを組み合わせて構成されている。色と役割を覚えておくと、復習のときに目的の情報へ一瞬でたどり着ける。

::mystery 各章は「問い」から始まる
身近な会社で起こる、直感に反する出来事。その理由を考えることが、各章の入り口になる。答えは、章の後半の「答え合わせ」で明かされる。
::

::theory 重要理論は青いボックスに
簿記と原価計算のルールの「なぜ」を説明する、最も大切な理論。1級でもそのまま使う知識なので、ここだけは必ず理解してから先へ進もう。
::

::danger 「経営の落とし穴」は赤いボックスに
会計処理を誤ったり、数字の裏の事実を見落としたりしたとき、会社がどんな危機に陥るかを描く。ルールが生まれた理由は、たいていここにある。
::

::real 「実際にあった話」は、上に黒い線の入った白いボックスに
物語の会社は架空だが、そこで起きる出来事には、現実の手本がある。黒字のまま倒産した上場企業、客の前払い金を使い込んで破綻した旅行会社、在庫の水増しが発覚したメーカー。各章のテーマにつながる実際の事件を、報道・統計資料へのリンクつきで紹介し、「この章の道具で読む」で、その事件の取引をその章の仕訳とT字勘定で再現する。
::

::cfo 「判断してみよう」は黄色のボックスに
数字のついた資料を読んで、経営者や経理担当者、銀行員の立場で判断するケース。A〜Dから1つ選ぶと、その判断がどんな結果を招くかと、考え方の例が開く。選択肢には、どれも「もっともらしい理由」がついている。迷うこと自体が、いちばんの練習になる。
::choice A. 選ぶ前に、自分の判断の理由を一言メモしておく
**◎ それがいちばん効く。**解説を読んだとき、自分の考えのどこが違っていたのかが、はっきり分かる。数字を使って理由を書けたなら、もう本書の狙いどおりだ。
::
::choice B. 考えずに、とりあえず選んで解説を読む
**△ もったいない。**解説は読める。だが、迷わずに選んだ答えからは、ほとんど何も残らない。1分でいいから、資料の数字で計算してから選んでみよう。
::
::answer
こんなふうに、どれかを選ぶと、その結果と考え方の例が開く。まず自分の頭で考えることが、最も効果的な学習法だ。
::
::

::exam 試験の急所は緑のボックスに
出題パターン、ひっかけ、時間短縮のテクニック。試験直前は、緑のボックスだけを拾い読みするのも効果的だ。
::

::next 1級・実務へのつながりは紫のボックスに
2級の知識が、1級や実際のビジネスでどう発展するかを予告する。今は読み飛ばしてもかまわない。
::

::point 例題と確認問題は「TRY」で手を動かして解ける
- **仕訳**：勘定科目をドラッグで記入欄へ入れ（またはタップしてから記入欄をタップ）、金額を入力して「答え合わせ」する。
- **空欄**：計算問題や、帳簿・精算表・財務諸表の空欄に数字を入力する。勘定科目や語句の空欄は、タップして選択肢から選ぶ。
- **分類・チェック表**：項目をドラッグで分類先へ移したり、当てはまるマスにチェックをつけたりする。
ネット試験と同じように、自分の手で答えを作ってから解説を開こう。
::

本文には、ほかにも次のような仕掛けがある。

- **勘定科目をタップ**：本文で点線の下線がついた勘定科目をタップすると、読み方・意味を確認できる（付録の勘定科目辞典の完成後）。
- **模擬試験モード**：付録の模擬試験では、90分のタイマーで本試験形式の問題を解き、大問ごとの得点と、復習すべき章をその場で確認できる（予定）。

仕訳とT字勘定は、次のような表で示す。左の青い列が**借方**、右の赤い列が**貸方**だ。

::journal 例：酒米30万円分を、代金は後払い（掛け）で購入した
材料 300,000 | 買掛金 300,000
::

::taccount 現金
前期繰越 500,000 | 仕入 120,000
売上 380,000 | 次期繰越 760,000
= 880,000 | 880,000
::

## おすすめの学習の進め方

::steps 合格までの4ステップ
1周目：物語として通読する | 確認問題は飛ばしてよい。まずは「なぜそうなるのか」をつかむ。工業簿記の第1部から読み始め、蔵の1年を追いかけよう
2周目：工業簿記の計算を手で解く | 第1部の例題と確認問題を、勘定の流れの図を描きながら解く。工業簿記は型を覚えれば得点源になる
商業簿記の仕訳を固める | 第2部・第3部の仕訳を、1問1分以内で切れるまで繰り返す。連結は手順を紙に書き出して練習する
模擬試験で仕上げる | 90分で全5問を解き、時間配分を体に覚え込ませる。間違えた章に戻って復習する
::

## 出題範囲について

本書は、日本商工会議所が2026年7月31日に公表した「2027年度適用」の出題区分表（2027年4月1日以降の試験に適用）に準拠する。2027年3月までの試験を受ける人のために、現行（2022年度適用）の区分表との違い（紙の手形の論点、リースの区分、売上原価対立法と固定資産の除却・定率法の3級への移行など）を、該当する章で注記する。工業簿記・原価計算の出題区分に変更はない。受験前には、日本商工会議所の公式情報で最新の出題範囲を必ず確認してほしい。

::note
※本書に登場する企業・人物・銘柄・数値は、学習用に設計した架空のものです。実在の企業・団体・商品とは関係ありません。「実際にあった話」で紹介する事例と統計は、公開されている報道・統計資料にもとづき、出典を併記しています。スマートフォンでの閲覧に最適化しています。
::
