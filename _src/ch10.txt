## 2つの損益計算書 ― 全部原価計算と直接原価計算

::scene 4月6日、午後2時 ― 帳場
月例の訪問に来た椎名は、陸の質問を聞くと、ホワイトボードに表を2つ並べて書いた。
椎名：「いまの損益計算書は、汐路を造るためのすべての製造原価を、1本ずつの原価に入れています。工場の設備の減価償却費や、社員の給料のような固定費も」
椎名：「もう1つは、造る量に比例する変動費だけを製品の原価にして、固定費はその月の費用にしてしまう方法です」
::

製造原価のすべて（変動費も固定費も）を製品の原価とする方法を**全部原価計算**、変動製造原価だけを製品の原価とし、固定製造原価は発生した期間の費用とする方法を**直接原価計算**という。これまでの章で学んできたのは、全部原価計算だ。

::table 純米吟醸「汐路」の原価の構造（仕組みを示すために単純化した数字）
| 項目 | 金額 |
| 販売価格 | 1本1,400円 |
| 変動製造原価（材料費260円＋変動加工費250円） | 1本510円 |
| 変動販売費（運賃・販売手数料） | 1本90円 |
| 固定製造原価（汐路の生産にかかる設備・社員の給料など） | 月4,500,000円 |
| 固定販売費及び一般管理費 | 月1,500,000円 |
::

::note
※第9章の標準原価カードは、瓶詰めの工程の原価だけを見たもの。この章では、醸造から販売までの費用を変動費と固定費に分けて、仕組みを示すために単純化した数字を使う。
::

2月は1万2,000本を造って、全部売れた。3月は1万8,000本を造って、9,600本が売れ、8,400本が倉庫に残った（2月末の在庫はない）。全部原価計算では、1本の原価に固定製造原価が入るので、造った本数で1本の原価が変わる。2月は510円＋450万円÷1万2,000本＝885円、3月は510円＋450万円÷1万8,000本＝760円だ。

::table 全部原価計算の損益計算書（単位：円）
| 項目 | 2月 | 3月 |
| 売上高 | 16,800,000 | 13,440,000 |
| 売上原価（2月885円、3月760円×販売本数） | 10,620,000 | 7,296,000 |
| 売上総利益 | 6,180,000 | 6,144,000 |
| 販売費及び一般管理費（変動販売費＋固定費） | 2,580,000 | 2,364,000 |
|= 営業利益 | 3,600,000 | 3,780,000 |
::

::table 直接原価計算の損益計算書（単位：円）
| 項目 | 2月 | 3月 |
| 売上高 | 16,800,000 | 13,440,000 |
| 変動売上原価（510円×販売本数） | 6,120,000 | 4,896,000 |
| 変動製造マージン | 10,680,000 | 8,544,000 |
| 変動販売費（90円×販売本数） | 1,080,000 | 864,000 |
| 貢献利益 | 9,600,000 | 7,680,000 |

直接原価計算では、3月の営業利益は168万円。売れた本数が減った分だけ、利益もきちんと減っている。

::point メモ ― 貢献利益
売上高から変動費（変動売上原価と変動販売費）を引いた利益を**貢献利益**（限界利益）という。固定費を回収し、利益を生むために「貢献」する額だ。汐路なら1本1,400円－510円－90円＝800円。1本売れるごとに800円ずつ、固定費の山を崩していく。
::

## 倉庫に眠る210万円 ― 固定費調整

陸：「同じ3月なのに、378万円と168万円。どっちが本当なんすか」
椎名：「どちらも、ルールどおりの計算です。差の210万円が、どこにあるかを探してみてください」
澪は、倉庫に残った8,400本を思い浮かべた。全部原価計算では、1本760円の原価のうち250円（450万円÷1万8,000本）が固定製造原価だ。8,400本×250円＝210万円。
澪：「3月に払った固定費のうち、210万円が、売れ残った酒の原価として倉庫にいる……」

::theory 全部原価計算では、固定費が在庫に乗って翌月へ運ばれる
全部原価計算では、固定製造原価の一部が、月末の製品（と仕掛品）の原価として資産に残り、翌月以降に売れたときに費用になる。だから、造った量が売れた量より多い月は、固定費の一部が費用にならず、営業利益が大きく見える。
直接原価計算では、固定製造原価はその月に全額が費用になるので、営業利益は**売れた量**だけで決まる。造りすぎても利益は増えない。
::

直接原価計算は、社内の管理（利益計画や意思決定）に使う方法で、外部に公表する財務諸表には全部原価計算が求められる。そこで、直接原価計算の営業利益を、全部原価計算の営業利益に直す手続きが要る。これを**固定費調整**という。

::formula 固定費調整
全部原価計算の営業利益 ＝ 直接原価計算の営業利益 ＋ 期末在庫に含まれる固定製造原価 － 期首在庫に含まれる固定製造原価
::

::example 3月の汐路の固定費調整
直接原価計算の営業利益は1,680,000円。3月末の製品8,400本には、1本250円の固定製造原価が含まれる（全部原価計算の単価760円のうち）。3月初めの在庫はない。
::answer
全部原価計算の営業利益＝1,680,000円＋8,400本×250円－0円＝**3,780,000円**
期末の在庫に乗って翌月へ運ばれた固定費210万円を足し戻すと、全部原価計算の営業利益と一致する。
::trap
期首の在庫に含まれる固定製造原価は**引く**。前の月から運ばれてきた固定費が、今月売れて全部原価計算の売上原価に入っているからだ。足すのは期末、引くのは期首。向きを逆にしやすい。
::
::
::

::solve 利益が増えたのは、固定費210万円が、売れ残った酒に乗って倉庫に入ったから
3月の汐路の営業利益が増えて見えたのは、全部原価計算で、固定製造原価450万円のうち210万円が、売れ残った8,400本の原価として倉庫に運ばれたからだ。売れた本数だけで決まる直接原価計算の営業利益は、2月の360万円から168万円に減っていた。
もし澪が「作れば作るほど儲かる」と考えて、決算の前に蔵をいっぱいにしていたら、6月の損益計算書の利益は大きく見えても、売れない酒とお金の流出だけが残り、7月以降に在庫が売れるたびに、運ばれた固定費がまとめて費用になっていた。
**全部原価計算の利益は、造った量で動く。直接原価計算の利益は、売れた量で動く。**利益の数字を見たら、在庫が増えていないかを必ず確かめる。
::

岩倉は、たたんだ新聞を膝に置いたまま言った。
岩倉：「先代が決算の前に蔵をいっぱいにしとったのは、信金に見せる利益のためでした。わしは、それを止められなんだ」
澪：「これからは、直接原価計算の表も一緒に作ります。高梨さんにも、両方を見せます」

## スパークリングは何本売れば ― CVP分析

::scene 4月7日、夜 ― 帳場
澪には、もう1つ宿題があった。6月に売り出す予定の「汐見スパークリング」（500mL）の計画だ。県の醸造試験場と開発した新しい酵母を使う、蔵で初めての発泡性の日本酒だった。
高梨：「何本売れれば、赤字にならないんですか。それが言えない計画には、お金は貸せません」
::

売上高（Volume）と原価（Cost）と利益（Profit）の関係を分析することを、**CVP分析**という。直接原価計算で原価を変動費と固定費に分けておけば、何本売れたら利益がいくらになるかを、すぐに計算できる。

::table 汐見スパークリング（500mL）の計画
| 項目 | 金額 |
| 販売価格 | 1本2,000円 |
| 変動費（原酒・耐圧瓶・王冠・運賃など） | 1本800円 |
| 固定費（専用の充填機・専任の担当者の給料・広告など） | 年1,440万円 |
| 販売の見込み | 年15,000本 |
::

1本売るごとの貢献利益は2,000円－800円＝1,200円。固定費1,440万円を1,200円ずつ崩していくと、ちょうど崩しきる本数で利益がゼロになる。これが**損益分岐点**だ。

::formula 損益分岐点と安全余裕率
損益分岐点の販売量 ＝ 固定費 ÷ 1単位の貢献利益
損益分岐点の売上高 ＝ 固定費 ÷ 貢献利益率
目標利益を得る販売量 ＝（固定費 ＋ 目標利益）÷ 1単位の貢献利益
安全余裕率 ＝（予定の売上高 － 損益分岐点の売上高）÷ 予定の売上高
経営レバレッジ係数 ＝ 貢献利益 ÷ 営業利益
::

- 損益分岐点の販売量：1,440万円÷1,200円＝**12,000本**（売上高2,400万円）
- 計画どおり15,000本売れたときの営業利益：1,200円×15,000本－1,440万円＝**360万円**
- 安全余裕率：(15,000本－12,000本)÷15,000本＝**20%**。販売が2割減るまでは赤字にならない
- 経営レバレッジ係数：1,800万円÷360万円＝**5**。売上高が10%変わると、営業利益は50%変わる
- 目標利益600万円を得る販売量：(1,440万円＋600万円)÷1,200円＝**17,000本**

::sim cvp 損益分岐図表を動かしてみよう
@expect bepq=12000 profit=3600000 mos=20 dol=5
::

澪：「固定費が大きいほど、損益分岐点が上がる。そして、分岐点を超えたあとは、利益が一気に伸びる」
高梨：「逆に言えば、売れなかったときの落ち方も大きい。経営レバレッジ係数が5なら、売上が2割減れば利益はゼロです」

## 電気代の請求書から ― 原価を変動費と固定費に分ける

CVP分析をするには、まず原価を変動費と固定費に分けなければならない。これを**原価の固変分解**という。費目ごとに、過去の経験から変動費か固定費かを判断していく方法を**費目別精査法**、過去の実績のうち操業度が最も高い月と最も低い月の2点から直線を引く方法を**高低点法**という。

::table 瓶詰めラインの電力・保守費の実績
| 月 | 作業時間 | 電力・保守費 |
| 10月 | 200時間 | 1,400,000円 |
| 11月 | 300時間 | 1,720,000円 |
| 12月 | 420時間 | 2,060,000円 |
| 1月 | 350時間 | 1,830,000円 |
| 2月 | 400時間 | 1,990,000円 |
| 3月 | 378時間 | 1,950,000円 |
::

::example 高低点法で、電力・保守費を変動費と固定費に分ける
上の実績から、高低点法で、1時間あたりの変動費（変動費率）と、月額の固定費を求める。
::answer
最も操業度が高い月は12月（420時間・2,060,000円）、最も低い月は10月（200時間・1,400,000円）。
- 変動費率：(2,060,000円－1,400,000円)÷(420時間－200時間)＝**3,000円／時間**
- 固定費：1,400,000円－200時間×3,000円＝**800,000円**（12月で確かめると 2,060,000円－420時間×3,000円＝800,000円）
::trap
高低点法で選ぶのは、**操業度**（作業時間）が最高と最低の月だ。原価の金額が最高・最低の月ではない。また、正常な操業の範囲の外にある異常な月の実績は、除いてから選ぶ。
::
::
::

### 試験で狙われるパターン ― 直接原価計算の勘定・損益分岐点の売上高・変化の影響

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 直接原価計算の勘定記入**　直接原価計算では、製造間接費を**変動製造間接費**と**固定製造間接費**に分けて記帳する。変動製造間接費は仕掛品に配賦し、固定製造間接費は仕掛品を通さずに、その期の損益（月次損益）に振り替える。

::example 直接原価計算で、製造間接費を記帳する
当月の変動製造間接費の実際発生額は600,000円で、全額を仕掛品に配賦した。固定製造間接費の実際発生額は1,200,000円である。
::answer
::journal 変動製造間接費は仕掛品へ、固定製造間接費は期間の費用として損益へ
仕掛品 600,000 | 変動製造間接費 600,000
損益 1,200,000 | 固定製造間接費 1,200,000
::
固定製造間接費は製品の原価にならないので、仕掛品・製品の勘定を通らない。
::trap
固定製造間接費を仕掛品に配賦するのは、全部原価計算の処理だ。直接原価計算の問題で、固定費を仕掛品に入れないこと。
::
::
::

**② 売上高で問われる損益分岐点**　販売量が分からないときは、貢献利益率（貢献利益÷売上高）を使う。汐見スパークリングなら貢献利益率は60%（1,200円÷2,000円）で、損益分岐点の売上高は1,440万円÷60%＝2,400万円。

**③ 条件が変わったら**　販売価格・変動費・固定費のどれかが変わったときの損益分岐点を問う出題は多い。変わったものだけを入れ替えて、公式に入れ直す。たとえば変動費が1本100円上がれば、貢献利益は1,100円、損益分岐点は1,440万円÷1,100円≒13,091本に上がる。

::steps 解法の型 ― CVP分析と直接原価計算
1. 変動費と固定費に分ける | 固変分解の指示（高低点法など）があれば先に行う
2. 1単位の貢献利益と貢献利益率 | 販売価格－変動費（変動売上原価＋変動販売費）
3. 公式に入れる | 損益分岐点＝固定費÷貢献利益。目標利益は固定費に足してから割る
4. 安全余裕率・経営レバレッジ係数 | （予定－分岐点）÷予定、貢献利益÷営業利益
5. 全部原価計算との違い | 固定費調整：直接原価計算の利益＋期末在庫の固定費－期首在庫の固定費
::

## 桐生の電話 ― AI企業の四半期で、損益分岐点を読む

::scene 4月8日、夜 ― ビデオ通話
澪がCVPの話をすると、画面の向こうで桐生が身を乗り出した。
桐生：「それ、例のAIの会社の四半期の数字に、そっくり当てはまるよ。届出書に、四半期ごとの損益が載ってる」
桐生：「計算資源っていうのは、AIを動かすコンピューターの能力のこと。1年以上前に何年分もまとめて契約するから、短い期間では、ほとんど固定費なんだって」

| 2026年7〜9月 | 16,956 | 9,863 | 17,523 | △567 |
::

澪は、この表を、汐見スパークリングと同じCVPの形で読んだ。仮に、営業費用のすべてを固定費とみなし（実際には売上に比例する費用もある。仕組みを示すための大胆な単純化）、売上高をそのまま貢献利益とみなすと、営業費用の合計が、その四半期の損益分岐点の売上高になる。

- 2026年4〜6月：売上高115.6億ドルが、分岐点105.8億ドルを初めて上回った。安全余裕率は約8.4%（(11,555－10,581)÷11,555）、経営レバレッジ係数は約11.9（11,555÷974）
- 2026年7〜9月：売上高は170億ドルに増えたのに、新しい計算資源が届いて固定費の山が175億ドルに上がり、再び分岐点を下回った

固定費が階段のように上がると、売上が伸びていても、分岐点が逃げていく。届出書自身も、新しい計算資源が届く期は利益率が下がり、事業の基礎的な経済性が改善していても利益率は期ごとに大きく変動しうると書いている。7〜9月には、短期の契約で借りた割高な計算資源（約50億ドル）と、寄付のマッチングによる現金の出ていかない費用（約20億ドル）も重なっていた。
桐生：「アマゾンも、創業から長く赤字だったんだよ。倉庫と物流に先にお金を使って、2003年にようやく通期の黒字になった。純利益は3,500万ドルくらい」
澪：「固定費を先に積んで、売上が追いつくのを待つ。うちのスパークリングも、規模は違うけど同じ形ですね」

::danger 「利益が出た」月の在庫と固定費を、必ず確かめる
全部原価計算の利益は、造りすぎるだけで大きく見せられる。決算の前に生産を増やして在庫を積むと、固定費が在庫に乗って翌期へ運ばれ、その期の利益が膨らむ。利益の増減を見たら、在庫の増減と、固定費の大きさを一緒に確かめる。

::cfo 汐見スパークリングの売り方 ― 何本を、いくらで売るか
4月、澪は営業の担当者と、スパークリングの売り方を3つの案にまとめた。変動費は1本800円、固定費は年1,440万円で、どの案でも変わらない。
**前提**
- A 大量に売る：量販店にも置く。1本1,500円で、年25,000本の見込み
- B 標準：地元と東京の酒販店とECで売る。1本2,000円で、年15,000本の見込み
- C 高級路線：料亭とホテルに限る。1本2,600円で、年9,000本の見込み
- 販売の見込みは、どの案も上下2割はぶれうる
- 原価計算の担当者は「1本の全部原価（変動費＋固定費÷1万5,000本）に2割を乗せて、2,112円にすべき」と言う
- 新しい酵母の研究には、試験場との共同研究で年2,600万円かかっている
::choice A. 量販店にも置いて年25,000本売る。売上高がいちばん大きく、利益も大きい
**△ 売上高は大きいが、利益は最大ではない。**貢献利益700円×25,000本－1,440万円＝310万円。損益分岐点は約20,571本で、見込みが18%減るだけで赤字になる。安い値段で量販店に出すと、ブランドの値打ちも下がる。
::
::choice B. 1本の全部原価に2割を乗せて、約2,112円で売る
**× 全部原価は、販売本数の見込みで変わる。**1本の固定費960円は「1万5,000本売れる」前提の数字だ。値段を上げれば売れる本数が減り、1本あたりの固定費は上がる。原価に利益を乗せる値付けは、需要と固定費の関係を見落とす。
::
::choice C. 料亭とホテルに限って、1本2,600円で年9,000本売る
**△ 1本の儲けは大きいが、固定費を回収しきれない。**貢献利益1,800円×9,000本－1,440万円＝180万円。損益分岐点8,000本に対して安全余裕率は約11%で、見込みが1割強ぶれれば赤字になる。
::
::choice D. 地元と東京の酒販店とECで、1本2,000円で年15,000本売る
**◎ 利益と安全の釣り合いが最もよい。**貢献利益1,200円×15,000本－1,440万円＝360万円で、3案の中で最大。損益分岐点12,000本に対して安全余裕率は20%あり、見込みが2割下にぶれても赤字にならない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「どの案の売上が大きいか」ではなく、「固定費1,440万円を回収したうえで、見込みが2割ぶれても耐えられる案はどれか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 3つの案のCVP分析
| 案 | 貢献利益 | 営業利益 | 損益分岐点 | 安全余裕率 |
| A 1,500円×25,000本 | 1,750万円 | 310万円 | 約20,571本 | 約18% |
| D 2,000円×15,000本 | 1,800万円 | 360万円 | 12,000本 | 20% |
| C 2,600円×9,000本 | 1,620万円 | 180万円 | 8,000本 | 約11% |
::
Dは営業利益が最大で、安全余裕率も最も高い。見込みが2割下にぶれる（12,000本）と利益はゼロだが、赤字にはならない。
#### 手順3　ほかの答えに引かれる理由
Aは「たくさん売れば儲かる」という直感に、Cは「1本の儲けが大きい」ことに、Bは「原価に利益を乗せる」という分かりやすい値付けに引かれる。研究開発費の年2,600万円は、どの案を選んでも変わらないので、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **売上高ではなく、貢献利益の合計で比べる**：値段×本数－変動費×本数
- **見込みのぶれに耐えられるかを、安全余裕率で確かめる**
- **全部原価に利益を乗せる値付けは、本数の見込みに縛られる**
#### 前提が変われば
量販店の1社が、1本1,500円で年2万本を必ず買い取る契約を出してきたなら、Dに加えてAの一部を引き受けても、追加の固定費がかからない限り、貢献利益700円×2万本＝1,400万円がそのまま利益を押し上げる。固定費が変わらない追加の注文は、貢献利益がプラスなら受ける価値がある。
::
::

::exam 直接原価計算とCVP分析の急所
- 全部原価計算は固定製造原価も製品原価、直接原価計算は**変動製造原価だけ**が製品原価で、固定製造原価は期間の費用
- 直接原価計算の利益は売れた量だけで決まる。全部原価計算の利益は造った量でも動く
- 固定費調整：直接原価計算の営業利益＋**期末**在庫の固定製造原価－**期首**在庫の固定製造原価
- 損益分岐点＝固定費÷1単位の貢献利益（売上高なら÷貢献利益率）。目標利益は固定費に足してから割る
- 高低点法は**操業度**が最高と最低の月で計算する
::

::next 変動費と固定費の区別は、意思決定の土台になる
1級では、貢献利益の考え方を使って、注文を受けるか、製品をやめるか、自社で造るか外に頼むかを判断する差額原価収益分析や、複数の製品を組み合わせたCVP分析を学ぶ。第4章・第8章の「考えてみよう」で使った「判断で変わるお金だけを比べる」考え方は、ここで理論になる。
::

::summary
- 全部原価計算は製造原価のすべてを、直接原価計算は変動製造原価だけを製品の原価にする
- 全部原価計算では固定費が在庫に乗って運ばれるので、造りすぎると利益が大きく見える
- 固定費調整で、直接原価計算の営業利益を全部原価計算の営業利益に直せる
- 損益分岐点は固定費÷1単位の貢献利益。安全余裕率と経営レバレッジ係数で、売上の変化への強さを測る
- 原価を変動費と固定費に分ける方法には、費目別精査法と高低点法がある
::

## 確認問題

::quiz
::problem 次の資料から、直接原価計算による営業利益と、全部原価計算による営業利益を求めなさい。期首の在庫はない。
販売価格 1個1,000円、変動製造原価 1個400円、変動販売費 1個100円、固定製造原価 月600,000円、固定販売費及び一般管理費 月200,000円
当月の生産量 3,000個、販売量 2,500個
直接原価計算の営業利益 [[450,000]] 円、全部原価計算の営業利益 [[550,000]] 円
::answer
**直接原価計算**：貢献利益＝(1,000－400－100)×2,500個＝1,250,000円。営業利益＝1,250,000－600,000－200,000＝**450,000円**
**全部原価計算**：1個の製造原価＝400＋600,000÷3,000個＝600円。売上総利益＝(1,000－600)×2,500＝1,000,000円。営業利益＝1,000,000－(100×2,500＋200,000)＝**550,000円**
差の100,000円は、期末の在庫500個に含まれる固定製造原価（500個×200円）だ。
::
::
::problem 販売価格 1個3,000円、変動費 1個1,800円、固定費 年2,400,000円の製品について答えなさい。
損益分岐点の販売量 [[2,000]] 個、目標営業利益600,000円を得る販売量 [[2,500]] 個、販売量2,500個のときの安全余裕率 [[20]] %
::answer
1個の貢献利益＝3,000－1,800＝1,200円。損益分岐点＝2,400,000÷1,200＝**2,000個**。目標利益の販売量＝(2,400,000＋600,000)÷1,200＝**2,500個**。安全余裕率＝(2,500－2,000)÷2,500＝**20%**。
::
::
::problem 次の実績から、高低点法で変動費率と固定費（月額）を求めなさい。
1月 機械運転 500時間・電力料 410,000円／2月 800時間・電力料 560,000円／3月 650時間・電力料 495,000円
変動費率 [[500]] 円／時間、固定費 [[160,000]] 円
::answer
最高の2月（800時間）と最低の1月（500時間）を使う。変動費率＝(560,000－410,000)÷(800－500)＝**500円**。固定費＝410,000－500×500＝**160,000円**。3月で確かめると 160,000＋650×500＝485,000円で、実績495,000円と少し違うが、高低点法は2点だけで線を引くので、ほかの月とは一致しないことがある。
::
