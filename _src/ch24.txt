## 本支店会計 ― 支店にも帳簿を持たせる

会社が支店を持つと、支店で起きた取引をどこで記帳するかを決める必要がある。支店が独自の帳簿を持ち、支店の取引は支店で記帳する方法を、**支店独立会計制度**という。

::theory 本店勘定と支店勘定
本店と支店の間の取引は、会社の外との取引ではない。会社の中で、お金や商品が移るだけだ。そこで、
- 本店の帳簿には**支店**勘定を設ける（支店に対する「貸し」を表す。ふつうは借方残高）
- 支店の帳簿には**本店**勘定を設ける（本店に対する「借り」を表す。ふつうは貸方残高）
本店から支店に何かを送れば、本店は「支店」を借方に、支店は「本店」を貸方に記録する。2つの勘定は、貸借が反対で、金額は一致する（**照合勘定**）。工業簿記の本社工場会計の「工場」勘定と「本社」勘定と、同じ仕組みだ。
::

::example 本店と支店の間の取引を、それぞれの帳簿に仕訳する
(1) 本店は、日本橋店に純米吟醸（原価800,000円）を送付した。本店は原価で送付している（本店は「製品」、支店は「仕入」で処理する）。
(2) 本店は、日本橋店の店舗の今月の賃料（支払リース料）400,000円を、本店の普通預金から支払った。
(3) 日本橋店は、店の売上金のうち500,000円を本店の口座に送金した。
(4) 日本橋店は、本店の得意先（東京の料亭）から、本店の売掛金200,000円を現金で受け取った。
::answer
::journal (1) 本店
支店 800,000 | 製品 800,000
::
::journal (1) 支店
仕入 800,000 | 本店 800,000
::
::journal (2) 本店
支店 400,000 | 普通預金 400,000
::
::journal (2) 支店
支払リース料 400,000 | 本店 400,000
::
::journal (3) 本店
普通預金 500,000 | 支店 500,000
::
::journal (3) 支店
本店 500,000 | 現金 500,000
::
::journal (4) 本店
支店 200,000 | 売掛金 200,000
::
::journal (4) 支店
現金 200,000 | 本店 200,000
::
本店の「支店」勘定と、支店の「本店」勘定は、いつも同じ金額だけ反対側に動く。(4)のように、支店が本店の代わりにお金を受け取ったときは、支店は本店に「借り」ができ、本店は支店に「貸し」ができる。
::trap
本店と支店の間の取引に、「売上」「売掛金」を使わないこと。会社の中の移動なので、相手の勘定は必ず「支店」か「本店」になる。
::
::
::

## 未達取引 ― 片方だけが知っている取引

本店と支店は、離れた場所で記帳する。一方が記帳しても、連絡や商品が届くまで、もう一方は記帳できない。締めの日に、一方だけが記帳している取引を**未達取引**という。
澪は、8月の帳簿を、1行ずつ突き合わせた。

::example 8月31日の未達取引を整理する
本店の「支店」勘定は借方12,500,000円、日本橋店の「本店」勘定は貸方10,900,000円。次の3つの未達取引があった。
(a) 本店は、8月30日に日本橋店へ製品800,000円（原価）を発送して記帳したが、日本橋店にはまだ届いていない。
(b) 本店は、日本橋店の秋の試飲会のチラシの印刷代300,000円を立替払いして記帳したが、連絡が日本橋店に届いていない。
(c) 日本橋店は、8月31日に本店へ現金500,000円を送付して記帳したが、本店ではまだ受け取っていない。
::answer
未達取引は、**まだ記帳していない側**が記帳する。
::journal (a) 支店：届いていない製品は「未達品」として記録する
仕入 800,000 | 本店 800,000
::
::journal (b) 支店
広告宣伝費 300,000 | 本店 300,000
::
::journal (c) 本店：届いていない現金は「未達現金」として記録する
現金 500,000 | 支店 500,000
::
- 本店の「支店」勘定：12,500,000円－500,000円＝**12,000,000円**（借方）
- 支店の「本店」勘定：10,900,000円＋800,000円＋300,000円＝**12,000,000円**（貸方）
2つが一致した。(a)の製品は、支店の期末の在庫（未達品を含む）に加える。
::trap
未達取引を、記帳した側で取り消さないこと。直すのは、まだ記帳していない側だ。
::
::
::

## 本支店合併財務諸表 ― 会社の外に見せる1枚

会社の外の人に見せる財務諸表は、本店と支店を合わせた1つの会社のものだ。本店と支店の帳簿を合わせて作るのが、**本支店合併財務諸表**だ。高梨に出す毎月の試算表も、この形で作る。

::theory 本支店合併財務諸表の作り方
1. 未達取引を整理し、本店勘定と支店勘定を一致させる
2. 本店と支店の同じ勘定を合算する
3. **本店勘定と支店勘定を相殺する**（会社の中の貸し借りなので、外に見せる財務諸表には載せない）
4. 本店から支店への送付のような内部の取引は、会社全体では売買ではないので、売上・仕入に含めない
決算では、支店の当期純損益を本店に振り替える。支店は「損益／本店」（利益の場合）、本店は「支店／損益」とする。本店の損益勘定で、会社全体の当期純損益が計算される。
::

::example 6月期の決算で、日本橋店の当期純利益12,000,000円を本店に振り替えた
::answer
::journal 支店
損益 12,000,000 | 本店 12,000,000
::
::journal 本店
支店 12,000,000 | 損益 12,000,000
::
本店の損益勘定に、支店の利益12,000,000円が加わる。本店の帳簿の「損益」の結果が、会社全体（本店＋支店）の当期純損益になる。
::trap
損失のときは貸借が逆になる。支店は「本店／損益」、本店は「損益／支店」。
::
::
::

::example 本店と支店の決算整理後の貸借対照表から、本支店合併貸借対照表を作る（単位：万円）
未達取引の整理と、支店の当期純利益の本店への振替えは済んでいる。
::table 決算整理後の貸借対照表（単位：万円）
| 科目 | 本店 | 支店 | 合併貸借対照表 |
| 現金預金 | 1,000 | 300 | [[1,300]] |
| 売掛金 | 2,000 | 600 | [[2,600]] |
| 商品 | 800 | 500 | [[1,300]] |
| 支店 | 1,200 | ― | [[0]] |
| 資産合計 | 5,000 | 1,400 | [[5,200]] |
| 買掛金 | 1,500 | 200 | [[1,700]] |
| 本店 | ― | 1,200 | [[0]] |
| 資本金 | 2,000 | ― | 2,000 |
| 繰越利益剰余金 | 1,500 | ― | 1,500 |
| 負債・純資産合計 | 5,000 | 1,400 | 5,200 |
::
::answer
同じ科目を合算し、**本店勘定（1,200）と支店勘定（1,200）を相殺**して消す。会社の外から見れば、本店と支店の間の貸し借りは存在しないからだ。
- 資産合計：1,300＋2,600＋1,300＝**5,200**
- 負債・純資産合計：1,700＋2,000＋1,500＝5,200
支店の当期純利益は、すでに本店の損益勘定に振り替えられて、本店の繰越利益剰余金に含まれている。だから、支店の貸借対照表には純資産の科目がない。合併損益計算書も、同じように本店と支店の収益・費用を合算して作る。
::
::

160万円のずれは、3つの未達取引だった。澪は、整理した試算表を高梨に送った。最初の月の報告は、期限の前に間に合った。
残るのは、戸田のもう1つの言葉だった。「蔵でいちばん儲かる部門です」。澪は、日本橋店の6月期の損益計算書を、もう一度開いた。売上原価の行に、目が止まった。日本橋店は、蔵から製品を**原価**で受け取っている。

::solve 勘定のずれは「未達取引」。店の利益1,200万円には、酒を造る蔵の儲けがまるごと入っていた
本店の「支店」勘定1,250万円と、日本橋店の「本店」勘定1,090万円の差160万円は、3つの未達取引だった。本店が送ったまま届いていない製品80万円、本店が立て替えたまま連絡が届いていないチラシの代金30万円、日本橋店が送ったまま本店に届いていない現金50万円。整理すると、どちらも1,200万円で一致した。
では、日本橋店の利益1,200万円はどうか。この利益は、帳簿の上では正しい。だが、日本橋店は蔵から製品を原価で受け取っている。だから、店の利益には、酒を造った蔵の儲け（製造の利益）が、まるごと含まれている。
同じ酒を問屋に卸していても、蔵には利益が残る。店があることで増えた利益は、その差でしか測れない。**支店の帳簿の利益は、支店で起きた取引の記録であって、支店が会社にもたらした利益とは限らない。**
::

### 試験で狙われるパターン ― 本支店の仕訳・未達・合併

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 本支店間の取引を、両方の帳簿に仕訳する**　相手の勘定は必ず「支店」か「本店」。支店が本店の売掛金を回収した、本店が支店の買掛金を支払った、などの「代わりに」の取引が狙われる。

**② 未達取引の整理**　未記帳の側が記帳する。未達品は支店の「仕入」（期末の在庫に加える）、未達現金は本店の「現金」。整理後の一致額を問う穴埋めが多い。

**③ 本支店合併財務諸表**　第3問で、本店と支店の試算表と決算整理事項から、合併損益計算書・合併貸借対照表を作る。未達取引→決算整理→合算・相殺の順で処理する。

**④ 支店の損益の振替え**　支店は「損益／本店」、本店は「支店／損益」（利益の場合）。損失なら逆。

::steps 解法の型 ― 本支店会計
1. 取引の相手を確かめる | 会社の外との取引か、本店と支店の間の取引か
2. 本支店間なら | 本店は「支店」、支店は「本店」を相手の勘定にする
3. 未達取引 | 未記帳の側で記帳し、本店勘定と支店勘定の一致を確かめる
4. 合併 | 同じ勘定を合算し、本店勘定と支店勘定を相殺。内部の送付は売上・仕入から除く
5. 損益の振替え | 支店の当期純損益を本店へ。本店の損益勘定で会社全体の損益を出す
::

## 椎名の忠告 ― 支店の帳簿の中に、11億ドルの損失が隠れていた

::scene 8月31日、夜 ― 椎名との電話
未達取引を整理し終えたことを報告すると、椎名は少し間を置いて言った。
椎名：「本店勘定と支店勘定が合った。それで安心してはいけませんよ。2つの勘定が合っても、支店の中の資産が本物かどうかまでは分からないんです」
澪：「戸田さんを疑え、ということですか」
椎名：「人を疑うのではなく、仕組みで確かめるんです。1995年に、それを怠った銀行がありました。大和銀行のニューヨーク支店です」
::

1995年9月、大和銀行（当時）は、ニューヨーク支店の1人の行員が、長年にわたる米国債の取引で約**11億ドル**の損失を出し、それを帳簿の上で隠し続けていたことを公表した。日本の大蔵省には8月初めに報告されたが、米国の当局に知らされたのは9月18日だった。米国の当局は、同行の米国での銀行業務を認めず、90日以内に米国の事業から撤退するよう命じた。
椎名：「損失を隠す方法は、仕組みとしては単純です。取引で失ったお金を損失として記録せず、まだ持っている資産のように帳簿に残しておく」
澪は、正しい記録と、隠した記録を並べた（仕組みを示すために単純化した例、単位：億ドル）。

::journal ① 正しい記録（支店の帳簿）：取引の損失を計上する
有価証券売却損 11 | 現金預金 11
::

::journal ② 隠した記録（支店の帳簿）：損失を記録せず、架空の資産として残す
有価証券 11 | 現金預金 11
::

②でも、支店の帳簿の借方と貸方は一致し、本店勘定と支店勘定も一致する。本店から見れば、支店勘定の残高は何も変わらない。支店の中に実在しない11億ドルの「有価証券」があることは、支店の資産を、帳簿とは別に、外部の保管機関の記録と突き合わせなければ見つからない。
椎名：「本支店の照合勘定は、本店と支店の間の貸し借りが正しく記録されているかを確かめる仕組みです。支店の中の資産そのものが本物かどうかは、教えてくれません」
翌週、澪は日本橋店を訪ね、戸田と一緒に、店の現金と在庫を数え、預金の通帳を銀行の残高と突き合わせた。すべて合っていた。
戸田：「疑われたみたいで、いい気はしませんね」
澪：「疑っていません。合っていることを、帳簿の外でも確かめただけです。来月から、毎月やりましょう。戸田さんの店の数字が正しいことを、誰にでも見せられるように」
戸田は、少し考えてから、うなずいた。

::note
出典：[The Christian Science Monitor「A Clash of Cultures Inflates The Daiwa Bank Scandal」（1995年11月6日）](https://www.csmonitor.com/1995/1106/06092.html)
::

::danger 支店の帳簿は、支店の中で閉じている
支店独立会計制度では、支店の取引は支店の帳簿だけに記録され、本店から見えるのは「支店」勘定の残高だけになる。支店の中で資産を水増ししたり、損失を隠したりしても、本店勘定と支店勘定さえ合っていれば、本店の帳簿の上では気づきにくい。だから本店は、支店の現金・在庫・債権を、支店の帳簿とは別に確かめる（実査・残高確認）。支店の帳簿を「信用する」ことと、「確かめない」ことは違う。
::

::cfo 日本橋店の成績 ― 2号店を出すべきか
戸田は、2号店の出店を強く求めている。澪は、日本橋店の1年の数字を、もう一度組み立て直した。
**前提**
- 6月期の日本橋店の売上高（店頭の小売価格）は6,000万円、売上原価（蔵から原価で受け入れた製品と、仕入れた酒器など）は2,400万円
- 店舗の費用は2,400万円（賃料480・人件費1,200・その他720）で、日本橋店の当期純利益は1,200万円
- 同じ酒を問屋に卸すと、売上は小売価格の60%の3,600万円で、運賃などが100万円かかる
- 本店の一般管理費を売上高で配賦すると、日本橋店の負担は1,500万円
- 2号店の出店には、内装などで約3,000万円かかる見込み
- 日本橋店の客の3割は、海外からの旅行者だ
::choice A. 支店の利益1,200万円、利益率20%。蔵でいちばん儲かる部門なので、2号店を出す
**× 蔵の製造の儲けまで、店の手柄にしている。**店がなくても、同じ酒を問屋に卸せば、3,600万円－2,400万円－100万円＝1,100万円が蔵に残る。日本橋店があることで増えている利益は、1,200万円－1,100万円＝約100万円にすぎない。
::
::choice B. 本店の一般管理費を配賦すると300万円の赤字なので、閉店を検討する
**× 閉店しても消えない費用を、閉店の理由にしている。**本店の一般管理費は、日本橋店を閉めてもほとんど減らない。それを売上の比で配賦して「赤字」と判断し、閉店すれば、店が生んでいた約100万円の利益が消え、蔵全体の利益はかえって減る。
::
::choice C. 売上6,000万円は蔵全体の約1割。規模が大きいので、2号店で倍にする
**× 売上の大きさは、利益の大きさではない。**2号店が同じ形なら、増える利益は年100万円ほどにとどまる。3,000万円の出店費用を回収するのに、30年かかる計算だ。
::
::choice D. 問屋に卸した場合と比べた増分（約100万円）で店の力を測り、2号店は見送る
**◎ 会社全体で、店があることによって変わる利益を見ている。**日本橋店の帳簿の利益1,200万円のうち、店ならではの利益は約100万円だ。3,000万円をかける2号店は、この数字では回収できない。そのうえで、客の声を直接聞ける場所としての店の役割を、別の形で生かす道を考える。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「日本橋店の利益はいくらか」ではなく、「日本橋店がなかったら、蔵全体の利益はいくら変わるか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 日本橋店で売る場合と、問屋に卸す場合（単位：万円）
| 項目 | 日本橋店で売る | 問屋に卸す |
| 売上高 | 6,000 | 3,600 |
| 売上原価 | 2,400 | 2,400 |
| 店舗の費用・運賃 | 2,400 | 100 |
| 蔵に残る利益 | 1,200 | 1,100 |
::
店があることで増える利益は、1,200万円－1,100万円＝100万円。本店の一般管理費1,500万円は、どちらの場合も同じだけかかるので、比べる数字に入れない。
#### 手順3　ほかの答えに引かれる理由
Aは「利益率20%」の見栄えに、Bは「全部の費用を負担させるのが公平」という考えに、Cは「売上が大きい」という印象に引かれる。客の3割が海外からの旅行者であることは、この比べ方には関係のない前提だ。
#### 持ち帰る考え方
- **支店の利益は、支店がなかった場合と比べて測る**：本店から原価で受け入れた製品を売る支店の利益には、製造の儲けが含まれる
- **判断で変わらない費用は、判断の理由にしない**：配賦した本店の費用は、閉店しても消えない
#### 前提が変われば
店頭での販売価格を上げられる、あるいは店でしか売れない限定の酒が育つなら、店ならではの利益は増え、2号店の判断も変わる。日本橋店で試す新商品の売れ行きは、その確かめ方になる。
::

::exam 本支店会計の急所
- 本店から支店への送付は、本店「支店／（仕入または製品など）」、支店「仕入／本店」。送付の価額は問題文に従う
- 未達取引は、**未記帳の側**が記帳する。届いていない商品は支店の期末の在庫に含める（未達品）
- 合併財務諸表では、**本店勘定と支店勘定を相殺**し、内部の送付は売上・仕入から除く
- 支店の当期純利益の振替え：支店「損益／本店」、本店「支店／損益」
- 第3問の本支店の問題は、未達取引→決算整理→合算・相殺の順で処理する
::

::next 本支店会計の先にある論点
1級では、本店から支店へ利益を加えた価額で商品を送る場合の**内部利益**の控除、支店が複数あるときの支店どうしの取引（本店集中計算制度・支店分散計算制度）などを学ぶ。また、支店ではなく別の会社（子会社）として事業を分けたときは、本支店合併財務諸表に代わって**連結財務諸表**を作る。それが、次の第25章・第26章の主題だ。
::

::summary
- 支店独立会計制度では、本店の帳簿に支店勘定、支店の帳簿に本店勘定を置き、本支店間の取引を貸借反対で記録する（照合勘定）
- 未達取引は、未記帳の側が記帳し、本店勘定と支店勘定を一致させる。未着の商品は支店の期末の在庫に含める
- 本支店合併財務諸表では、本店勘定と支店勘定を相殺し、内部の送付を売上・仕入から除く。支店の当期純損益は本店に振り替える
- 支店の帳簿の利益は、支店がなかったら会社全体の利益がどう変わるかで評価する
- 本支店の照合勘定は、支店の中の資産が本物かどうかまでは教えてくれない
::

::problem 決算日に、本店の支店勘定は借方3,000,000円、支店の本店勘定は貸方2,950,000円だった。未達取引は次のとおりである。未達取引を整理した後の、本店勘定・支店勘定の一致額を求めなさい。
① 本店が支店に送付した商品150,000円が、支店に未着
② 支店が本店の売掛金100,000円を回収したが、本店に未達
本店勘定・支店勘定の一致額 [[3,100,000]] 円
::answer
①は支店が未記帳：支店「仕入 150,000／本店 150,000」→ 本店勘定 2,950,000円＋150,000円＝3,100,000円
②は本店が未記帳：本店「支店 100,000／売掛金 100,000」→ 支店勘定 3,000,000円＋100,000円＝3,100,000円
どちらも**3,100,000円**で一致する。支店が本店の代わりに売掛金を回収したので、本店は売掛金を減らし、支店に対する「貸し」（支店勘定）を増やす。
::

::problem 支店の当期純損失300,000円を、本店に振り替える。本店の帳簿の仕訳を答えなさい。
::answer
::journal 本店：支店の損失は、本店の損益の借方へ
損益 300,000 | 支店 300,000
::
支店の帳簿では「本店 300,000／損益 300,000」。損失のときは、利益のときと貸借が逆になる。
