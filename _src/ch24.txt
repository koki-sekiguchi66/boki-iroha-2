::mystery 合わない2つの勘定と、いちばん儲かる店
7月14日、水曜日。日本橋店の6月期の帳簿が、店長の戸田から届いた。3年前に父が開いた直営店は、蔵の酒と、作家ものの酒器と、新潟の肴を売っている。店の帳簿は、店で独自につけている。
本店（蔵の事務所）の帳簿には「支店」という勘定があり、6月30日の残高は借方**1,250万円**。日本橋店の帳簿には「本店」という勘定があり、残高は貸方**1,090万円**。椎名によれば、この2つは、同じ取引を両側から記録したものだから、本来は同じ金額になるはずだという。160万円、どこかでずれている。
戸田からは、短いメモが添えられていた。「日本橋店の当期純利益は1,200万円。売上高利益率20%。蔵でいちばん儲かる部門です。来期は2号店を出しませんか」
蔵全体が赤字の年に、東京の店だけが1,200万円の黒字。澪は、そのメモを何度も読み返した。
**本店と支店の勘定は、なぜ合わないのか。そして、日本橋店は本当に、蔵でいちばん儲かる部門なのか？**
::

## 本支店会計 ― 支店にも帳簿を持たせる

会社が支店を持つと、支店で起きた取引をどこで記帳するかを決める必要がある。支店が独自の帳簿を持ち、支店の取引は支店で記帳する方法を、**支店独立会計制度**という。

::theory 本店勘定と支店勘定
本店と支店の間の取引は、会社の外との取引ではない。会社の中でお金や商品が移るだけだ。そこで、
- 本店の帳簿には**支店**勘定を設ける（支店に対する「貸し」を表す。ふつうは借方残高）
- 支店の帳簿には**本店**勘定を設ける（本店に対する「借り」を表す。ふつうは貸方残高）
本店から支店に何かを送れば、本店は「支店」を借方に、支店は「本店」を貸方に記録する。2つの勘定は、貸借が反対で、金額は一致する（**照合勘定**）。第11章の本社工場会計の「工場」勘定と「本社」勘定と同じ仕組みだ。
::

::example 本店と支店の間の取引を、それぞれの帳簿に仕訳しなさい
(1) 本店は、日本橋店に純米吟醸（原価800,000円）を送付した。本店は原価で送付している（本店は「製品」、支店は「仕入」で処理する）。
(2) 本店は、日本橋店の店舗の賃料（支払リース料）300,000円を、本店の普通預金から支払った。
(3) 日本橋店は、店の売上金のうち500,000円を本店の口座に送金した。
(4) 日本橋店は、本店の得意先（東京の料亭）から、本店の売掛金200,000円を現金で受け取った。
::answer
::journal (1) 本店
支店 800,000 | 製品 800,000
::
::journal (1) 支店
仕入 800,000 | 本店 800,000
::
::journal (2) 本店
支店 300,000 | 普通預金 300,000
::
::journal (2) 支店
支払リース料 300,000 | 本店 300,000
::
::journal (3) 本店
普通預金 500,000 | 支店 500,000
::
::journal (3) 支店
本店 500,000 | 現金 500,000
::
::journal (4) 本店
支店 200,000 | 売掛金 200,000
::
::journal (4) 支店
現金 200,000 | 本店 200,000
::
本店の「支店」勘定と、支店の「本店」勘定は、いつも同じ金額だけ反対側に動く。(4)のように、支店が本店の代わりにお金を受け取ったときは、支店は本店に「借り」ができ、本店は支店に「貸し」ができる。
::
::

## 未達取引 ― 片方だけが知っている取引

本店と支店は、離れた場所で記帳する。一方が記帳しても、連絡や商品が届くまで、もう一方は記帳できない。決算日に、一方だけが記帳している取引を**未達取引**という。

::example 6月30日の未達取引を整理しなさい
本店の「支店」勘定は借方12,500,000円、日本橋店の「本店」勘定は貸方10,900,000円。次の3つの未達取引があった。
(a) 本店は、6月29日に日本橋店へ製品800,000円（原価）を発送し記帳したが、日本橋店にはまだ届いていない。
(b) 本店は、日本橋店の6月分の店舗の賃料300,000円を立替払いして記帳したが、連絡が日本橋店に届いていない。
(c) 日本橋店は、6月30日に本店に現金500,000円を送金して記帳したが、本店ではまだ入金を確認していない。
::answer
未達取引は、**まだ記帳していない側**が、決算で記帳する。
::journal (a) 支店：届いていない製品は「未達品」として記録する
仕入 800,000 | 本店 800,000
::
::journal (b) 支店
支払リース料 300,000 | 本店 300,000
::
::journal (c) 本店：送金は「未達現金」として記録する
現金 500,000 | 支店 500,000
::
- 本店の「支店」勘定：12,500,000円－500,000円＝**12,000,000円**（借方）
- 支店の「本店」勘定：10,900,000円＋800,000円＋300,000円＝**12,000,000円**（貸方）
2つが一致した。(a)の製品は、決算では支店の期末商品（未達品を含む）に加えて、支店の棚卸資産に含める。
::
::

## 本支店合併財務諸表

会社の外の人に見せる財務諸表は、本店と支店を合わせた1つの会社のものだ。本店と支店の帳簿を合わせて作るのが**本支店合併財務諸表**だ。

::theory 本支店合併財務諸表の作り方
1. 未達取引を整理し、本店勘定と支店勘定を一致させる
2. 本店と支店の同じ勘定を合算する
3. **本店勘定と支店勘定を相殺する**（会社の中の貸し借りなので、外に見せる財務諸表には載せない）
4. 本店から支店への送付（支店の「仕入」・本店の「製品」の減少など）のような内部の取引は、会社全体では売買ではないので、売上・仕入に含めない
決算では、支店の当期純損益を本店に振り替える。支店は「損益／本店」（利益の場合）、本店は「支店／損益」とする。本店の損益勘定で、会社全体の当期純損益が計算される。
::

::example 日本橋店の当期純利益12,000,000円を、本店に振り替えなさい
::answer
::journal 支店
損益 12,000,000 | 本店 12,000,000
::
::journal 本店
支店 12,000,000 | 損益 12,000,000
::
本店の損益勘定に、支店の利益12,000,000円が加わる。本店の帳簿の「損益」の結果が、会社全体（本店＋支店）の当期純損益になる。
::
::

::exam 本支店会計の急所
- 本店から支店への送付は、本店「支店／（仕入または製品など）」、支店「仕入／本店」。送付の価額（原価か、利益を加えた価額か）は問題文に従う
- 未達取引は、**未記帳の側**が決算で記帳する。届いていない商品は支店の期末商品に含める（未達品）
- 合併財務諸表では、**本店勘定と支店勘定を相殺**し、内部の送付は売上・仕入から除く
- 支店の当期純利益の振替え：支店「損益／本店」、本店「支店／損益」
- 第3問で、本支店の決算整理前残高試算表から合併損益計算書・合併貸借対照表を作る形がある。未達取引→決算整理→合算・相殺の順で処理する
::

## 答え合わせ ― 2つの勘定と、2つの利益

::solve 勘定のずれは「未達取引」、店の利益は「会社全体の儲けの一部」
本店の「支店」勘定1,250万円と、日本橋店の「本店」勘定1,090万円の差160万円は、3つの未達取引だった。本店が送ったまま届いていない製品80万円、本店が立て替えたまま連絡が届いていない賃料30万円、日本橋店が送ったまま本店が確認していない送金50万円。整理すると、どちらも1,200万円で一致した。
では、日本橋店の利益1,200万円はどうか。この利益は、帳簿の上では正しい。だが、日本橋店は、蔵から製品を**原価**で受け取っている。つまり、日本橋店の利益には、酒を造った蔵の儲け（製造の利益）が、まるごと含まれているのだ。
::

澪は、戸田に電話をかけた。「日本橋店の数字は正確でした。ただ、1,200万円の中には、蔵が酒を造る儲けも入っています。同じ酒を問屋に卸していたら、蔵にはいくら残ったか。それと比べないと、店の本当の力は分かりません」

::danger 支店の帳簿は、支店の中で閉じている
支店独立会計制度では、支店の取引は支店の帳簿だけに記録され、本店から見えるのは「支店」勘定の残高だけになる。支店の中で資産を水増ししたり、損失を隠したりしても、本店勘定と支店勘定さえ合っていれば、本店の帳簿の上では気づきにくい。
だから、本店は、支店の現金・在庫・債権を、支店の帳簿とは別に確かめる（実査・残高確認）必要がある。支店の帳簿を「信用する」ことと、「確かめない」ことは違う。
::

::real 支店の帳簿の中に、11億ドルの損失が隠れていた ― 大和銀行ニューヨーク支店
1995年9月、大和銀行（当時）は、ニューヨーク支店の1人の行員が、1980年代から1990年代の初めにかけて、米国債の取引で約**11億ドル**の損失を出し、それを帳簿の上で隠し続けていたことを公表した。日本の大蔵省には8月初めに報告されたが、米国の当局に知らされたのは9月18日だった。米国の当局は、同行の米国での銀行業務の免許を取り消し、90日以内に米国の事業を売却するか閉鎖するよう命じた。

**この章の道具で読む ― 支店の帳簿の中だけで、損失を「資産」にしておく**
損失を隠す方法は、仕組みとしては単純だ。取引で失ったお金を損失として記録せず、「まだ持っている資産」のように帳簿に残しておく。仮に、支店で11億ドルの取引の損失が出たときの、正しい記録と、隠した記録を並べると（仕組みを示すために単純化した例、単位：億ドル）、
::journal ① 正しい記録（支店の帳簿）：取引の損失を計上する
有価証券売却損 11 | 現金預金 11
::
::journal ② 隠した記録（支店の帳簿）：損失を記録せず、架空の資産として残す
有価証券 11 | 現金預金 11
::
②でも、支店の帳簿の借方と貸方は一致し、本店勘定と支店勘定も一致する。本店から見れば、支店勘定の残高は何も変わらない。支店の中に、実在しない11億ドルの「有価証券」があることは、支店の資産を、帳簿とは別に、外部の保管機関の記録と突き合わせなければ見つからない。
本支店会計の照合勘定は、本店と支店の間の貸し借りが正しく記録されているかを確かめる仕組みだ。支店の中の資産そのものが本物かどうかまでは教えてくれない。帳簿が独立していることの便利さと危うさは、表裏一体だ。
::note
出典：[The Christian Science Monitor「A Clash of Cultures Inflates The Daiwa Bank Scandal」（1995年11月6日）](https://www.csmonitor.com/1995/1106/06092.html)
::
::

::cfo 日本橋店の成績 ― 2号店を出すべきか
戸田は、2号店の出店を強く求めている。澪は、日本橋店の1年の数字を、もう一度組み立て直した。
::table 日本橋店の1年（単位：万円）
| 項目 | 金額 |
| 売上高（店頭の小売価格） | 6,000 |
| 売上原価（蔵から原価で受け入れた製品・仕入れた酒器など） | 2,400 |
| 店舗の費用（賃料480・人件費1,200・その他720） | 2,400 |
| 日本橋店の当期純利益（支店の帳簿） | 1,200 |
| 同じ酒を問屋に卸した場合の売上（小売価格の60%） | 3,600 |
| 問屋に卸した場合にかかる運賃など | 100 |
| 本店の一般管理費を売上高で配賦した場合の日本橋店の負担 | 1,500 |
::
まず、日本橋店がなく、同じ酒を問屋に卸していた場合に蔵に残る利益を計算し、日本橋店があることで増えている利益を求めてから選んでほしい。
::choice A. 支店の利益1,200万円、利益率20%。日本橋店は蔵で最も儲かる部門なので、2号店を出す
**× 蔵の製造の儲けまで、店の手柄にしている。**店がなくても、同じ酒を問屋に卸せば、3,600万円－原価2,400万円－運賃100万円＝1,100万円が蔵に残る。日本橋店があることで増えている利益は、1,200万円－1,100万円＝**約100万円**にすぎない。2号店の出店費用と賃料を回収できるかは、この100万円で考える必要がある。
::
::choice B. 問屋に卸した場合と比べた増分（約100万円）で店の稼ぐ力を評価し、新商品の試験販売やECの顧客づくりなどの役割を加えて判断する
**◎ 会社全体で、店があることによって変わる利益を見ている。**日本橋店の帳簿の利益1,200万円のうち、店ならではの利益は約100万円だ。それだけなら、2号店の出店は慎重に考えるべきだ。
ただし、日本橋店には、数字に出にくい役割もある。スパークリングを最初に試したのも、「蔵の古酒ブレンド」を完売させたのも、この店だった（第14章）。客の声を直接聞ける場所としての価値を、どう評価するか。2号店の判断は、増分の利益とその役割を合わせて、試験的に始めるかを決めるのが筋だ。
::
::choice C. 本店の一般管理費1,500万円を配賦すると、日本橋店は300万円の赤字。2号店どころか、閉店を検討する
**× 閉店しても消えない費用を、閉店の理由にしている。**本店の一般管理費（経理・総務・社長室など）は、日本橋店を閉めても、ほとんど減らない。それを売上の比で配賦して「赤字」と判断し、閉店すれば、店が生んでいた約100万円の増分の利益が消え、蔵全体の利益はかえって減る。第4章の故障の損失、第8章の外注の判断と同じく、判断で変わるお金だけを数える。
::
::choice D. 店の売上6,000万円は、蔵全体の売上の約1割。規模が大きいので、2号店で倍にすべきだ
**× 売上の大きさは、利益の大きさではない。**売上が倍になっても、増える利益が問屋に卸した場合との差だけなら、2号店の増分の利益も年100万円程度にとどまる。出店に数千万円をかければ、回収に何十年もかかる。規模で判断すると、利益の伴わない拡大になる。
::
::answer 考え方の例を見る
支店の帳簿の利益は、支店で起きた取引を正しく記録したものだが、それがそのまま「支店が会社にもたらした利益」とは限らない。本店から原価で受け入れた製品を売る支店の利益には、製造の儲けが含まれる。支店を評価するときは、**支店がなかったら会社全体の利益がどう変わるか**で考える。
澪は、2号店の代わりに、日本橋店の一角で、季節ごとに新商品を試す「蔵の試飲会」を月1回開くことを提案した。戸田は不満そうだったが、最初の試飲会で予約が埋まると、2号店の話はしなくなった。
::
::

::next 本支店会計の先にある論点
1級では、本店から支店へ利益を加えた価額（振替価格）で商品を送る場合の**内部利益**の控除、支店が複数あるときの**支店相互間の取引**（本店集中計算制度・支店分散計算制度）などを学ぶ。また、支店ではなく別の会社（子会社）として事業を分けたときは、本支店合併財務諸表に代わって**連結財務諸表**を作る。それが、次の第25章・第26章の主題だ。
::

(2) 支店は、本店の買掛金150,000円を、支店の当座預金から支払った。

::journal (1) 支店
仕入 200,000 | 本店 200,000

::journal (2) 本店
買掛金 150,000 | 支店 150,000
::
::journal (2) 支店
本店 150,000 | 当座預金 150,000
::

::problem 決算日に、本店の支店勘定は借方3,000,000円、支店の本店勘定は貸方2,950,000円だった。未達取引は次のとおりである。未達取引を整理した後の、本店勘定・支店勘定の一致額を求めなさい。
① 本店が支店に送付した商品150,000円が、支店に未着
② 支店が本店の売掛金100,000円を回収したが、本店に未達
本店勘定・支店勘定の一致額 [[3,100,000]] 円
::answer
①は支店が未記帳：支店「仕入 150,000／本店 150,000」→ 本店勘定 2,950,000円＋150,000円＝3,100,000円
②は本店が未記帳：本店「支店 100,000／売掛金 100,000」→ 支店勘定 3,000,000円＋100,000円＝3,100,000円
どちらも**3,100,000円**で一致する。支店が本店の代わりに売掛金を回収したので、本店は売掛金を減らし、支店に対する「貸し」（支店勘定）を増やす。

::summary
- 支店独立会計制度では、本店の帳簿に支店勘定、支店の帳簿に本店勘定を置き、本支店間の取引を貸借反対で記録する（照合勘定）
- 未達取引は、決算で未記帳の側が記帳し、本店勘定と支店勘定を一致させる。未着の商品は支店の期末商品に含める
- 本支店合併財務諸表では、本店勘定と支店勘定を相殺し、内部の送付を売上・仕入から除く。支店の当期純損益は本店に振り替える
- 支店の帳簿の利益は、支店で起きた取引の記録であって、支店が会社にもたらした利益とは限らない。支店がなかったら会社全体の利益がどう変わるかで評価する
- 本支店の照合勘定は、支店の中の資産が本物かどうかまでは教えてくれない
