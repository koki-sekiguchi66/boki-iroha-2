::mystery 44万円のムダは、誰のせいか
3月31日、水曜日。瓶詰め部門の月次の報告を見て、澪は眉を寄せた。純米吟醸「汐路」の四合瓶を1万8,000本詰めた3月の原価は、**908万2,560円**。この本数なら本来かかるはずの原価より、**44万2,560円**多い。
宇佐美は、すぐに答えた。「原酒が値上がりしたんです。醸造部門から受け取る原酒の単価が上がっている。うちのせいじゃありません」
岩倉は首を振った。「いや、ラインが遅い。去年の今ごろは、もっと早く詰め終わっとった」
2人とも、自分の見立てに自信を持っていた。だが、どちらの言い分にも、数字の裏づけはなかった。
**44万円のムダは、原酒の値上がりのせいか、ラインの遅れのせいか？**
::

## 標準原価 ― 「本来かかるべき原価」を先に決める

第2章の予定価格、第3章の予定賃率、第4章の予定配賦率は、どれも「単価」を前もって決める方法だった。**標準原価計算**は、さらに一歩進んで、製品1単位を作るのに使うべき**量**（材料の量・作業時間）も前もって決める。単価と量の両方を決めた「本来かかるべき原価」が**標準原価**だ。

::theory 標準原価計算の目的
- **原価管理**：実際の原価を標準原価と比べ、差（**標準原価差異**）を原因ごとに分析して、ムダを見つけ、改善につなげる
- **記帳の簡略化**：完成品や仕掛品を、標準原価で素早く計算できる
- **予算の作成**：標準原価は、来期の利益計画の土台になる
標準は、理想ではなく、**良い状態で作業したときに達成できる水準**で決めるのがふつうだ（現実的標準原価）。
::

澪は、宇佐美と一緒に、四合瓶1本の**標準原価カード**を作った。

::table 純米吟醸「汐路」四合瓶1本の標準原価カード
| 原価要素 | 標準単価 | 標準消費量 | 標準原価 |
| 直接材料費（原酒） | 1Lあたり400円 | 0.75L（こぼれ・詰め残しの正常な分を含む） | 300円 |
| 直接労務費 | 1時間あたり1,800円（標準賃率） | 0.02時間（72秒） | 36円 |
| 製造間接費 | 1時間あたり7,200円（標準配賦率） | 0.02時間 | 144円 |
|= 1本の標準原価 | | | 480円 |
::

製造間接費の標準配賦率7,200円は、瓶詰め部門の月間の予算（公式法変動予算）から計算した。基準操業度は、ラインの作業時間で月**400時間**（2万本分）、変動費率は1時間2,000円、固定費は月**208万円**（固定費率5,200円）。第5章で決めた瓶詰め部門の予定配賦率と同じ水準だ。

3月に完成した1万8,000本の標準原価は、480円×18,000本＝**864万円**。実際の原価908万2,560円との差44万2,560円が、3月の**標準原価差異**の合計だ。

::table 3月の実際の資料
| 原価要素 | 実際 |
| 直接材料費 | 原酒13,650L×1Lあたり404円＝5,514,600円 |
| 直接労務費 | 378時間×1時間あたり1,820円＝687,960円 |
| 製造間接費 | 2,880,000円 |
|= 合計 | 9,082,560円 |
::

## 直接材料費差異 ― 値段の差と、量の差

まず原酒。1万8,000本詰めるのに、標準では0.75L×18,000本＝**13,500L**で足りるはずだった。実際には13,650L使い、1Lあたり404円だった。

::formula 直接材料費差異の分析
価格差異 ＝（標準価格 － 実際価格）× 実際消費量
数量差異 ＝（標準消費量 － 実際消費量）× 標準価格
::

::example 3月の直接材料費差異を、価格差異と数量差異に分けなさい
::answer
- **価格差異**：(400円－404円)×13,650L＝**△54,600円（不利）**
- **数量差異**：(13,500L－13,650L)×400円＝**△60,000円（不利）**
- 合計：△114,600円＝標準原価5,400,000円（13,500L×400円）－実際5,514,600円
::boxes 直接材料費の差異の図（単位：円）
H 標準原価と差異 | 実際の原価
L a 90 標準原価<br>5,400,000
L x 1 数量差異<br>60,000
L x 1 価格差異<br>54,600
R k 92 実際<br>5,514,600
::
価格差異を計算するときは**実際消費量**を、数量差異を計算するときは**標準価格**を使う。図にすると、内側の長方形（標準価格×標準消費量）が標準原価で、右にはみ出した部分が数量差異、上にはみ出した部分が価格差異になる。
::
::

価格差異は、原酒の値上がり（第2章の米価の影響）による差で、瓶詰め部門の責任ではない。だが、数量差異は違う。150Lもの原酒が、こぼれたり、詰めすぎたりして、標準より多く使われていた。

## 直接労務費差異 ― 賃率の差と、時間の差

::formula 直接労務費差異の分析
賃率差異 ＝（標準賃率 － 実際賃率）× 実際作業時間
作業時間差異 ＝（標準作業時間 － 実際作業時間）× 標準賃率
::

::example 3月の直接労務費差異を、賃率差異と作業時間差異に分けなさい
1万8,000本の標準作業時間は、0.02時間×18,000本＝360時間。
::answer
- **賃率差異**：(1,800円－1,820円)×378時間＝**△7,560円（不利）**
- **作業時間差異**：(360時間－378時間)×1,800円＝**△32,400円（不利）**
- 合計：△39,960円＝標準原価648,000円（360時間×1,800円）－実際687,960円
材料費と同じ形だ。単価の差には実際の量を、量の差には標準の単価を掛ける。
::
::

## 製造間接費差異 ― 予算・能率・操業度

製造間接費は、第4章で学んだ予算差異と操業度差異に、もう1つ**能率差異**が加わる。標準原価計算では、製品に配賦する額を「標準作業時間×標準配賦率」で計算するので、作業に時間がかかった分の差が新たに生まれるのだ。

::theory 製造間接費差異の3分法（公式法変動予算）
- **予算差異**＝予算許容額（実際作業時間×変動費率＋固定費予算）－実際発生額
- **能率差異**＝（標準作業時間－実際作業時間）×標準配賦率
- **操業度差異**＝（実際作業時間－基準操業度）×固定費率
- 合計＝標準配賦額（標準作業時間×標準配賦率）－実際発生額
能率差異は、作業の効率が悪かったために、余分に使った間接費（変動費）と、効率よく働けば製品に配賦できたはずの固定費を表す。2級では、能率差異を標準配賦率で計算する方法（変動費と固定費の両方から計算する方法）が基本だ。
::

::example 3月の製造間接費差異を、予算差異・能率差異・操業度差異に分けなさい
変動費率2,000円、固定費予算2,080,000円、基準操業度400時間（固定費率5,200円、標準配賦率7,200円）。標準作業時間360時間、実際作業時間378時間、実際発生額2,880,000円。
::answer
- 標準配賦額：360時間×7,200円＝2,592,000円。差異の合計は2,592,000円－2,880,000円＝△288,000円
- **予算差異**：(378時間×2,000円＋2,080,000円)－2,880,000円＝2,836,000円－2,880,000円＝**△44,000円（不利）**
- **能率差異**：(360時間－378時間)×7,200円＝**△129,600円（不利）**
- **操業度差異**：(378時間－400時間)×5,200円＝**△114,400円（不利）**
- 合計：△44,000円＋△129,600円＋△114,400円＝△288,000円
::
::

::exam 標準原価計算の差異分析の急所
- 差異は「**標準－実際**」で計算し、マイナスなら不利（借方）差異、プラスなら有利（貸方）差異
- **単価の差（価格・賃率）には実際の量**、**量の差（数量・時間）には標準の単価**を掛ける。図では、内側が標準、外側が実際
- 当月の**標準消費量・標準作業時間**は、「当月の生産量×1単位の標準」で求める。月初・月末仕掛品があるときの生産量は、**完成品換算量**（直接材料が始点投入なら、材料は完成品＋月末－月初の数量、加工費は換算量）で計算する
- 製造間接費の**能率差異**は、問題文の指示（標準配賦率で計算するか、変動費率だけで計算するか）を必ず確かめる。指示がなければ標準配賦率で計算するのが2級の基本
- 差異の合計が、標準原価と実際原価の差に一致するかを検算する
::

## 答え合わせ ― 44万円の内訳と、その持ち主

::scene 4月1日、朝 ― 瓶詰め場の横の休憩室
澪は、7つに分けた差異の表を、宇佐美と岩倉の前に広げた。
::

::solve 44万円の大半は、原酒の値上がりではなく、ラインの遅れと量の少なさだった
::table sum 3月の標準原価差異（単位：円。すべて不利差異）
| 差異 | 金額 | 原因 |
| 原酒の価格差異 | 54,600 | 醸造部門からの原酒の単価の上昇（米価の影響） |
| 原酒の数量差異 | 60,000 | こぼれ・詰めすぎ（標準より150L多く使用） |
| 賃率差異 | 7,560 | 残業の割増賃金 |
| 作業時間差異 | 32,400 | ラインの停止で作業が18時間延びた |
| 製造間接費の予算差異 | 44,000 | 電力・消耗品の使いすぎ |
| 製造間接費の能率差異 | 129,600 | ラインの停止で作業が18時間延びた |
| 製造間接費の操業度差異 | 114,400 | 生産量が予定の2万本に届かなかった |
|= 合計 | 442,560 | |
::
宇佐美の言う「原酒の値上がり」は、**5万4,600円**にすぎなかった。最も大きいのは、ラインの停止で作業時間が延びたことによる**作業時間差異と能率差異の合計16万2,000円**。次が、生産量が予定に届かなかったことによる**操業度差異11万4,400円**だ。
岩倉の「ラインが遅い」は、半分当たっていた。だが、生産量の少なさは、ラインの速さではなく、3月の受注と生産計画の問題だった。
::

宇佐美は、しばらく表を見ていた。「ラインが止まる原因は、ラベラーです。古いラベラーが、1日に何度も瓶を詰まらせる。止まるたびに、こぼれた酒を拭いて、瓶を手で抜いて……」
「数量差異の6万円も、そこから来ているんですね」と澪は言った。
差異は、誰かを責めるための数字ではない。どこを直せば、いくら取り戻せるかを示す地図だった。古いラベラーが止まるたびに失っているお金は、この数字から見積もれる。それは、第15章で澪が新しい瓶詰めラインを決断する根拠の1つになる。

## 標準原価計算の記帳 ― パーシャル・プランとシングル・プラン

標準原価計算では、差異をどの勘定で出すかによって、記帳の方法が2つある。

::table パーシャル・プランとシングル・プラン
| 方法 | 仕掛品勘定の借方（投入） | 仕掛品勘定の貸方（産出） | 差異が出る場所 |
| パーシャル・プラン | 実際原価 | 標準原価 | 仕掛品勘定 |
| シングル・プラン | 標準原価 | 標準原価 | 材料・賃金・製造間接費の各勘定 |
::

::example 3月の瓶詰め部門の記帳を、パーシャル・プランとシングル・プランで示しなさい（月初・月末仕掛品はない）
<!-- notry -->
::answer
**パーシャル・プラン**：仕掛品には実際原価を入れ、完成品は標準原価で出す。差額が仕掛品勘定に差異として残り、それを分析して各差異の勘定に振り替える。
::journal (1) 実際原価を仕掛品へ
仕掛品 9,082,560 | 材料 5,514,600
 | 賃金・給料 687,960
 | 製造間接費 2,880,000
::
::journal (2) 完成品を標準原価で製品へ（18,000本×480円）
製品 8,640,000 | 仕掛品 8,640,000
::
::journal (3) 仕掛品に残った差異を、各差異の勘定へ振り替える
価格差異 54,600 | 仕掛品 442,560
数量差異 60,000 |
賃率差異 7,560 |
作業時間差異 32,400 |
予算差異 44,000 |
能率差異 129,600 |
操業度差異 114,400 |
::

**シングル・プラン**：材料・賃金・製造間接費を消費した時点で、標準原価だけを仕掛品に入れ、差異はその場で各勘定に記録する。
::journal (1) 直接材料費
仕掛品 5,400,000 | 材料 5,514,600
価格差異 54,600 |
数量差異 60,000 |
::
::journal (2) 直接労務費
仕掛品 648,000 | 賃金・給料 687,960
賃率差異 7,560 |
作業時間差異 32,400 |
::
::journal (3) 製造間接費
仕掛品 2,592,000 | 製造間接費 2,880,000
予算差異 44,000 |
能率差異 129,600 |
操業度差異 114,400 |
::
::journal (4) 完成品を製品へ
製品 8,640,000 | 仕掛品 8,640,000
::
シングル・プランでは、仕掛品勘定の借方も貸方も標準原価なので、仕掛品勘定に差異は出ない。どちらの方法でも、製品勘定は標準原価の8,640,000円、差異の合計は442,560円で同じになる。会計年度末には、差異を売上原価に振り替える（第2章〜第4章と同じ）。
::
::

::sort 次の差異を、主に誰が責任を負うべきものかに分けなさい。
@cats 購買・醸造（原酒の調達） | 瓶詰め部門 | 営業・生産計画
原酒の価格差異 => 購買・醸造（原酒の調達）
原酒の数量差異（こぼれ・詰めすぎ） => 瓶詰め部門
作業時間差異（ラインの停止） => 瓶詰め部門
製造間接費の能率差異 => 瓶詰め部門
製造間接費の予算差異（電力・消耗品の使いすぎ） => 瓶詰め部門
製造間接費の操業度差異（受注が少なく生産量が予定未満） => 営業・生産計画
::

## 宇佐美の古い教科書 ― 12時間半が93分になった日

::scene 4月1日、夕方 ― 瓶詰め場の休憩室
差異の表を見せた日の夕方、宇佐美が、色あせた教科書を持ってきた。工業高校の生産管理の授業で使ったものだという。
「標準の時間って、誰が最初に決めたんだろうと思って、読み返したんです。テイラーという技師が、作業を動作に分けて時間を測って、『1日にこなすべき標準の仕事』を決めた。1911年の『科学的管理法の原理』です。それを大量生産で使ったのがフォードで……」
宇佐美が開いたページには、白黒の写真があった。動くラインの上を、自動車の車台が流れていく。
::

1913年10月7日、フォード・モーターは、ハイランドパーク工場で、T型フォードの車台（シャシー）を動くラインに載せて組み立て始めた。作業員が部品のところへ歩くのではなく、車台が作業員の前を流れていく。博物館「ザ・ヘンリー・フォード」などによると、車台の組立時間は、それまでの**約12時間半**から、およそ1年で**93分**にまで縮んだ。
「もし、そのとき標準を12時間半のまま据え置いていたら、差異はどうなったと思いますか」と澪が聞くと、宇佐美は電卓を取り出した。仮に、標準賃率を1時間1,000円として、1,000台を93分（1.55時間）で組み立てたとする（金額は仕組みを示すための例）。

::journal 作業時間差異：(12,500時間－1,550時間)×1,000円＝10,950,000円（有利）
仕掛品 12,500,000 | 賃金・給料 1,550,000
 | 作業時間差異 10,950,000
::

シングル・プランで記帳すると、仕掛品には標準の1,250万円が入り、実際の労務費155万円との差1,095万円が、**有利な作業時間差異**として貸方に現れる。
「1,095万円の有利差異。成績表なら満点ですね」と宇佐美は言った。
「でも、それは成果じゃなくて、標準が古すぎるという警報です」と澪は答えた。「フォードが流れ作業で達成した時間が、新しい標準になったはずです。そこから、さらに改善が積み重ねられた」
宇佐美は、自分のラインの標準作業時間の欄を見つめた。0.02時間、72秒。古いラベラーを前提にした数字だ。「新しいラインが入ったら、この72秒も、決め直さないといけませんね」
標準は、一度決めたら終わりではない。現実の工程が変われば、標準も改めなければ、差異は何も教えてくれなくなる。

::note
出典：[The Henry Ford「K-12 Research Guide: Assembly Line」](https://askus.thehenryford.org/K12/faq/433848)、[Automotive History「October 7, 1913 – Model T chassis moving assembly line」](https://automotivehistory.org/october-7-1913-model-t-chassis-moving-assembly-line/)
::

::cfo 宇佐美の評価 ― どの差異が、瓶詰め部門の責任か
4月の部門長会議で、3月の差異の責任をどう評価するかが議題になった。蔵では初めて、部門ごとの成績を数字で見る試みだ。
岩倉は「44万円は瓶詰め部門の赤字。宇佐美さんの責任です」と言った。宇佐美は「うちが管理できるのは、ラインの速さだけです。作業時間の差異と能率差異の16万円なら認めます」と応じた。
上の「3月の標準原価差異」の表を使い、瓶詰め部門が**自分の努力で管理できる**差異の合計を計算してから選んでほしい。
::choice A. 差異の合計44万2,560円。瓶詰め部門の原価なのだから、すべて部門の責任だ
**× 管理できない差異まで背負わせている。**原酒の価格差異5万4,600円は、醸造部門から受け取る原酒の単価、つまり米価の結果だ。操業度差異11万4,400円は、受注と生産計画が決めた生産量の結果だ。瓶詰め部門がどれだけ頑張っても、これらは変えられない。管理できない数字で評価すれば、部門は「どうせ言い訳できない」と改善をあきらめる。
::
::choice B. 数量差異・作業時間差異・能率差異・予算差異・賃率差異の合計27万3,560円
**◎ 部門が管理できる差異だけを集めている。**数量差異6万円（こぼれ・詰めすぎ）、作業時間差異3万2,400円と能率差異12万9,600円（ラインの停止）、予算差異4万4,000円（電力・消耗品の使い方）、賃率差異7,560円（残業の割増。残業を減らせば防げる）。合計**27万3,560円**が、瓶詰め部門の努力で取り戻せる金額だ。
価格差異は購買と醸造に、操業度差異は営業と生産計画に、それぞれ持ち主を返す。差異の評価は、責任を「管理できる人」に結びつけて初めて、改善の道具になる。
::
::choice C. 作業時間差異と能率差異の合計16万2,000円だけ。宇佐美の言うとおりだ
**△ 大事な部分は押さえているが、取りこぼしがある。**ラインの停止による差異はたしかに最大だ。だが、こぼれ・詰めすぎの数量差異6万円や、電力・消耗品の予算差異4万4,000円も、瓶詰め部門の作業のしかたで変えられる。部門長自身が範囲を狭く決めれば、改善の対象も狭くなる。
::
::choice D. 原酒の価格差異と操業度差異の合計16万9,000円。部門の外から来た差異を、まず問題にすべきだ
**× 責任の向きが逆だ。**この2つは、瓶詰め部門の外で決まる差異だ。もちろん蔵全体としては見逃せないが、瓶詰め部門の成績から外すべき項目であって、部門に問うものではない。外の差異にばかり目を向けると、部門の中の16万円のラインの停止が放置される。
::
::answer 考え方の例を見る
標準原価差異は、原因ごとに分けたうえで、**それを管理できる人**に結びつけて評価する（責任会計）。価格差異は購買、数量差異・作業時間差異・能率差異は製造現場、操業度差異は生産量を決める部門、というのが基本の割り当てだ。
宇佐美は、B案の27万円を自分の部門の課題として受け止めた。そして、ラベラーが止まった時刻と原因を、毎日記録し始めた。1か月後、その記録は、ラインの停止の7割がラベラーの詰まりだったことを示していた。
::

::next 標準原価計算の先にあるもの
1級では、製造間接費の能率差異を変動費と固定費に分ける方法や、材料の配合差異・歩留差異、労働の能率の分析など、より細かい差異分析を学ぶ。また、標準原価は、来期の利益計画（予算）を作るときの土台になる。売上・原価・利益の計画と実績を比べる**予算実績差異分析**は、標準原価計算の考え方を、会社全体に広げたものだ。
::

## 確認問題

::quiz
::problem 次の資料から、直接材料費の価格差異と数量差異を求めなさい（不利差異はマイナスで答える）。
標準価格 1kgあたり200円、製品1個あたりの標準消費量 3kg、当月の生産量 1,000個、実際消費量 3,100kg、実際価格 1kgあたり195円
価格差異 [[15,500]] 円、数量差異 [[-20,000]] 円
::answer
価格差異＝(200円－195円)×3,100kg＝**＋15,500円（有利）**
数量差異＝(3,000kg－3,100kg)×200円＝**△20,000円（不利）**
標準消費量は1,000個×3kg＝3,000kg。
::
::
::problem 次の資料から、製造間接費の予算差異・能率差異・操業度差異を求めなさい（公式法変動予算、能率差異は標準配賦率で計算する。不利差異はマイナスで答える）。
変動費率 1,000円／時間、固定費予算 600,000円（月間）、基準操業度 300時間、当月の標準作業時間 280時間、実際作業時間 290時間、実際発生額 900,000円
予算差異 [[-10,000]] 円、能率差異 [[-30,000]] 円、操業度差異 [[-20,000]] 円
::answer
固定費率＝600,000円÷300時間＝2,000円、標準配賦率＝1,000円＋2,000円＝3,000円
予算差異＝(290時間×1,000円＋600,000円)－900,000円＝890,000円－900,000円＝**△10,000円**
能率差異＝(280時間－290時間)×3,000円＝**△30,000円**
操業度差異＝(290時間－300時間)×2,000円＝**△20,000円**
合計△60,000円＝標準配賦額840,000円－実際900,000円

::problem 月初仕掛品 100個（加工進捗度50%）、当月完成品 900個、月末仕掛品 200個（加工進捗度40%）。直接材料は工程の始点で投入する。製品1個の標準作業時間は0.5時間である。当月の直接材料の標準消費量の計算に使う生産量と、標準作業時間を求めなさい。
直接材料の生産量 [[1,000]] 個、標準作業時間 [[445]] 時間

::summary
- 標準原価は、標準単価×標準消費量（標準作業時間）で決める「本来かかるべき原価」。標準原価カードにまとめる
- 直接材料費差異は価格差異（単価の差×実際量）と数量差異（量の差×標準単価）、直接労務費差異は賃率差異と作業時間差異に分ける
- 製造間接費差異は、予算差異・能率差異・操業度差異に分ける（公式法変動予算）
- パーシャル・プランは仕掛品に実際原価を入れて仕掛品勘定で差異を出し、シングル・プランは仕掛品に標準原価を入れて各原価勘定で差異を出す
- 差異は、それを管理できる人に結びつけて評価する。標準が古くなれば、差異は何も教えてくれない
::
