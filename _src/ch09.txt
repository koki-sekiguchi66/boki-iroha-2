::mystery 44万円は、誰のせいか
3月31日、水曜日、午後6時。年度末を前にした部門の会議で、澪は初めて「標準原価差異」の表を配った。
純米吟醸「汐路」の四合瓶は、1本480円で造る。それが、今期の初めに決めた約束だった。3月に詰めたのは1万8,000本。標準どおりなら864万円で済むはずが、実際は**908万2,560円**かかっていた。
差は**44万2,560円**。
営業の担当者が、真っ先に口を開いた。
営業の担当者：「瓶詰め部門の不手際でしょう。3月はラベラーが何度も止まってましたから。宇佐美さんの責任ですよ」
宇佐美は、何も言い返さなかった。机の下で、ライン日誌を握りしめている。
澪は、2月に自分が決めたことを思い出していた。ラベル紙を、1枚1円安い仕入先に切り替えたのだ。月に1万8,000円の節約。表計算で見たときは、迷う余地のない判断に思えた。
**44万円の超過は、本当に宇佐美の責任なのか。差異の数字は、誰を指さしているのか？**
::

## 1本480円の約束 ― 標準原価カード

::scene 4月1日、午前9時 ― 帳場
会議の翌朝、澪は椎名に電話をかけた。
澪：「第2章から第4章まで、米も人も製造間接費も『予定』で計算してきました。標準原価って、予定と何が違うんですか」
椎名：「予定価格や予定賃率は、1か月の原価の『単価』を先に決めたものでした。標準原価は、もう一歩進んで、製品1つを造るのに『どれだけの量を使うべきか』まで決めます」
椎名：「単価と量の両方に目標がある。だから、ずれたときに『値段のせいか、使い方のせいか』を分けられるんです」
::

科学的・統計的に調べて決めた、製品1つあたりの目標の原価を**標準原価**といい、それを使って原価を計算するのが**標準原価計算**だ。目的は3つある。原価のムダを見つけて減らす**原価管理**、計算を早くする**記帳の簡略化**、そして予算や値決めの土台にすることだ。
製品1つの標準原価を、原価要素ごとに書いたものが**標準原価カード**だ。

::table 純米吟醸「汐路」四合瓶1本の標準原価カード
| 原価要素 | 標準単価 | 標準消費量 | 標準原価 |
| 直接材料費（原酒） | 1Lあたり400円（標準価格） | 0.75L（こぼれ・詰め残しの正常な分を含む） | 300円 |
| 直接労務費 | 1時間あたり1,800円（標準賃率） | 0.02時間（72秒） | 36円 |
| 製造間接費 | 1時間あたり7,200円（標準配賦率） | 0.02時間 | 144円 |
|= 1本の標準原価 | | | 480円 |
::

製造間接費の標準配賦率7,200円は、第5章の瓶詰め部門の予定配賦率と同じだ。内訳は、変動費率2,000円と固定費率5,200円。月間の基準操業度は400時間（2万本分）、月間の固定費予算は208万円（400時間×5,200円）になる。

## 908万円と864万円 ― 差異の総額

::table 3月の実際の資料（月初・月末の仕掛品はない）
| 原価要素 | 実際 |
| 直接材料費 | 原酒13,650L×1Lあたり404円＝5,514,600円 |
| 直接労務費 | 378時間×1時間あたり1,820円＝687,960円 |
| 製造間接費 | 2,880,000円 |
|= 合計 | 9,082,560円 |
::

標準原価は、1万8,000本×480円＝8,640,000円。実際との差、442,560円が**標準原価差異**の総額だ。
澪：「44万円の中に、何が入っているのか。分けてみます」
椎名：「材料は『値段』と『量』、人は『賃率』と『時間』、製造間接費は『予算』と『能率』と『操業度』。7つに分けられます」

## 差異を7つに分ける ― 材料・労務・製造間接費

まず、直接材料費。1万8,000本に対して、標準では原酒を1万3,500L（0.75L×1万8,000本）使うはずだった。実際は1万3,650L、しかも1Lあたり404円だった。

::formula 直接材料費差異
価格差異 ＝（標準価格 － 実際価格）× 実際消費量
数量差異 ＝（標準消費量 － 実際消費量）× 標準価格
::

- 価格差異：(400円－404円)×13,650L＝**△54,600円**（不利）
- 数量差異：(13,500L－13,650L)×400円＝**△60,000円**（不利）

次に、直接労務費。標準の作業時間は360時間（0.02時間×1万8,000本）、実際は378時間で、実際の賃率は1,820円だった。

::formula 直接労務費差異
賃率差異 ＝（標準賃率 － 実際賃率）× 実際作業時間
作業時間差異 ＝（標準作業時間 － 実際作業時間）× 標準賃率
::

- 賃率差異：(1,800円－1,820円)×378時間＝**△7,560円**（不利）
- 作業時間差異：(360時間－378時間)×1,800円＝**△32,400円**（不利）

::point メモ ― 価格は実際の量で、量は標準の価格で
価格（賃率）差異には**実際**の量を掛け、数量（時間）差異には**標準**の価格を掛ける。図にすると、縦軸に価格、横軸に量をとった長方形の、外側の帯が価格差異、右側の帯が数量差異になる。2つの帯が重なる角の部分は、価格差異に含める決まりだ。
::

最後に、製造間接費。第4章のシュラッター図と同じ考え方に、「標準の時間」を1本足す。

::formula 製造間接費差異（公式法変動予算）
予算差異 ＝（変動費率×実際操業度＋固定費予算）－ 実際発生額
能率差異 ＝（標準操業度 － 実際操業度）× 標準配賦率
操業度差異 ＝（実際操業度 － 基準操業度）× 固定費率
::

- 予算許容額：2,000円×378時間＋2,080,000円＝2,836,000円。予算差異＝2,836,000円－2,880,000円＝**△44,000円**（不利）
- 能率差異：(360時間－378時間)×7,200円＝**△129,600円**（不利）
- 操業度差異：(378時間－400時間)×5,200円＝**△114,400円**（不利）

::table sum 3月の標準原価差異（単位：円。すべて不利差異）
| 差異 | 金額 |
| 直接材料費の価格差異 | 54,600 |
| 直接材料費の数量差異 | 60,000 |
| 直接労務費の賃率差異 | 7,560 |
| 直接労務費の作業時間差異 | 32,400 |
| 製造間接費の予算差異 | 44,000 |
| 製造間接費の能率差異 | 129,600 |
| 製造間接費の操業度差異 | 114,400 |
|= 合計 | 442,560 |
::

7つの合計は442,560円。908万円と864万円の差と、1円も違わない。

## 宇佐美のライン日誌 ― 差異の原因をたどる

::scene 4月1日、午後3時 ― 瓶詰め場
澪は、宇佐美のライン日誌を借りた。几帳面な字で、毎日の停止時間と原因が書いてある。
3月の停止は、合計18時間。原因の欄には、同じ言葉が並んでいた。「ラベラー詰まり　ラベル反り」。
宇佐美：「2月から入ってる新しいラベル紙です。紙が薄くて、雨の日は湿気で反るんですよ。前の紙のときは、1度も詰まりませんでした」
澪の背中が、冷たくなった。そのラベル紙に切り替えたのは、澪自身だった。
::

澪は、日誌と差異の表を並べ、7つの差異の原因と、それを左右できる人を書き出した。

::case ライン日誌と、各部門の記録から
- 原酒の単価が404円に上がったのは、醸造部門から受け取る原酒の原価が上がったため（瓶詰め部門には左右できない）
- 原酒を150L多く使ったのは、詰めすぎとこぼれ。瓶詰め部門の作業の精度の問題
- 賃率が1,820円に上がったのは、営業の注文に合わせて組んだ残業の割増賃金
- 作業時間が18時間延びたのは、ラベラーの詰まり。原因は2月に切り替えた薄いラベル紙（ラベル代の節約は月18,000円）
- 予算差異は、ラインの電力と消耗品の使いすぎ。瓶詰め部門の管理の問題
- 生産量が予定の2万本に届かなかったのは、3月の注文が減ったため
::

澪は、7つの差異の横に、原因と、それを左右できる人を書き込んだ。原酒の値上がりは米価、残業の割増は注文に合わせた計画、生産量の不足は注文の減少。どれも、瓶詰め部門には変えられない。
作業時間差異と能率差異は、ふつうなら現場の責任だ。だが、18時間の停止の原因は、ラベル紙だった。その紙を選んだのは、宇佐美ではない。

::solve 44万円の最大の原因は、安いラベル紙を選んだ澪の判断だった
44万2,560円の差異を7つに分け、原因をたどると、宇佐美の瓶詰め部門が左右できたのは、詰めすぎの数量差異6万円と、電力・消耗品の予算差異4万4,000円の、合わせて**10万4,000円**だけだった。
残りのうち、ラベラーの停止による作業時間差異と能率差異の**16万2,000円**は、澪が2月に「1枚1円安い」ラベル紙に切り替えた判断が生んだものだった。ラベル代の節約は月1万8,000円。その代わりに、ラインを18時間止め、16万2,000円の差異を生んでいた。
もし営業の言うとおり宇佐美を責めて終わりにしていたら、澪は自分の判断の誤りに気づかず、薄いラベル紙を使い続け、毎月十数万円の差異を生み続けていた。
**差異は、それが現れた場所ではなく、それを生んだ判断のところに責任がある。**差異分析は、犯人探しの道具ではなく、原因の住所を突き止める道具だ。
::

翌日の会議で、澪は差異の表の横に、1行を書き足して読み上げた。
澪：「作業時間差異と能率差異、16万2,000円。原因は、私がラベル紙を替えたことです。今月から、前の紙に戻します」
宇佐美が、初めて顔を上げた。
宇佐美：「……詰めすぎの6万円は、うちの分です。来月は、ゼロにします」

### 試験で狙われるパターン ― 2つの記帳方法・仕掛品がある月・能率差異のもう1つの分け方

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① パーシャル・プランとシングル・プラン**　標準原価計算の記帳には2つの方法がある。差異が、どの勘定に出てくるかが違う。

::table パーシャル・プランとシングル・プラン
| 方法 | 仕掛品勘定の借方（投入） | 仕掛品勘定の貸方（完成） | 差異が出る勘定 |
| パーシャル・プラン | 実際原価 | 標準原価 | 仕掛品勘定 |
| シングル・プラン | 標準原価 | 標準原価 | 材料・賃金・製造間接費の各勘定 |
::

::example 3月の汐路の原価を、パーシャル・プランで記帳する
上の3月の資料にもとづき、パーシャル・プランで仕訳する。
::answer
::journal (1) 実際原価を仕掛品へ
仕掛品 9,082,560 | 材料 5,514,600
 | 賃金・給料 687,960
 | 製造間接費 2,880,000
::
::journal (2) 完成品を標準原価で製品へ（18,000本×480円）
製品 8,640,000 | 仕掛品 8,640,000
::
::journal (3) 仕掛品に残った差異を、各差異の勘定へ振り替える
価格差異 54,600 | 仕掛品 442,560
数量差異 60,000 |
賃率差異 7,560 |
作業時間差異 32,400 |
予算差異 44,000 |
能率差異 129,600 |
操業度差異 114,400 |
::
パーシャル・プランでは、仕掛品の借方に実際原価、貸方に標準原価が入るので、差の442,560円が仕掛品勘定に残る。それを差異の勘定へ振り替える。
::trap
パーシャル・プランの仕掛品の**借方は実際原価**だ。標準原価を借方に書くのはシングル・プラン。どちらの方法かで、借方の金額が変わる。
::
::
::

::example 同じ資料を、シングル・プランで記帳する
上の3月の資料にもとづき、シングル・プランで仕訳する。
::answer
::journal (1) 直接材料費：標準13,500L×400円を仕掛品へ
仕掛品 5,400,000 | 材料 5,514,600
価格差異 54,600 |
数量差異 60,000 |
::
::journal (2) 直接労務費：標準360時間×1,800円を仕掛品へ
仕掛品 648,000 | 賃金・給料 687,960
賃率差異 7,560 |
作業時間差異 32,400 |
::
::journal (3) 製造間接費：標準360時間×7,200円を仕掛品へ
仕掛品 2,592,000 | 製造間接費 2,880,000
予算差異 44,000 |
能率差異 129,600 |
操業度差異 114,400 |
::
::journal (4) 完成品を製品へ
製品 8,640,000 | 仕掛品 8,640,000
::
シングル・プランでは、仕掛品の借方も貸方も標準原価なので、差異は仕掛品ではなく、材料・賃金・給料・製造間接費の各勘定で出る。どちらの方法でも、製品は8,640,000円、差異の合計は442,560円で同じだ。
::trap
シングル・プランの差異は、**投入のとき**に原価要素の勘定で出る。完成のときに出るのではない。
::
::
::

**② 月初・月末に仕掛品がある月**　標準原価で計算するのは、完成品だけではない。差異分析の「標準消費量」「標準作業時間」は、**当月投入量**に対する標準だ。材料は当月投入の数量、加工費（労務費・製造間接費）は当月投入の完成品換算量（完成品－月初の換算量＋月末の換算量）に、標準の消費量を掛ける。

::example 月末仕掛品がある月の標準原価
4月の汐路は、完成品20,000本、月末仕掛品1,000本（進捗度40%、材料は始点投入）、月初仕掛品はなかった。標準原価カードは上と同じ。
::answer
- 完成品の標準原価：20,000本×480円＝**9,600,000円**
- 月末仕掛品の標準原価：材料1,000本×300円＋加工費（1,000本×40%＝400本）×(36円＋144円)＝300,000円＋72,000円＝**372,000円**
- 差異分析の標準消費量：原酒は当月投入21,000本×0.75L＝15,750L、作業時間は当月投入の換算量20,400本×0.02時間＝408時間
::trap
差異分析で、完成品の数量（20,000本）に標準を掛けないこと。材料は当月投入21,000本、加工費は換算量20,400本が基準になる。
::
::
::

**③ 能率差異のもう1つの分け方**　能率差異を、変動費の部分だけで計算する方法もある。このときは、能率差異＝(標準操業度－実際操業度)×変動費率、操業度差異＝(標準操業度－基準操業度)×固定費率になる。3月の汐路なら、能率差異は(360－378)×2,000円＝△36,000円、操業度差異は(360－400)×5,200円＝△208,000円。合計は同じ△244,000円だ。問題文が「能率差異は変動費と固定費の両方から計算する」のか「変動費のみ」なのかを必ず確かめる。

::steps 解法の型 ― 標準原価計算の差異分析
1. 当月投入の量を出す | 材料は当月投入の数量、加工費は当月投入の完成品換算量
2. 標準の量を出す | 当月投入の量×標準消費量（標準作業時間）
3. 材料と労務の図 | 縦に価格（賃率）、横に量（時間）。価格差異×実際量、数量差異×標準価格
4. 製造間接費の図 | 実際発生額・予算許容額・標準配賦額を並べ、予算・能率・操業度に分ける
5. 検算 | 差異の合計＝標準原価－実際原価
::

## 1913年のデトロイト ― 古い標準は、警報を鳴らさない

::scene 4月2日、夕方 ― 瓶詰め場の休憩室
差異の表を貼り出した日の夕方、宇佐美が、色あせた教科書を持ってきた。工業高校の生産管理の授業で使ったものだという。
宇佐美：「標準の時間って、誰が最初に決めたんだろうと思って、読み返したんです。テイラーという技師が、作業を動作に分けて時間を測って、1日にこなすべき仕事を決めた」
宇佐美：「それを大量生産で使ったのが、フォードで」
宇佐美が開いたページには、白黒の写真があった。動くラインの上を、自動車の車台が流れていく。
::

1913年10月7日、フォード・モーターは、ハイランドパーク工場で、T型フォードの車台（シャシー）を動くラインに載せて組み立て始めた。作業員が部品のところへ歩くのではなく、車台が作業員の前を流れていく。博物館「ザ・ヘンリー・フォード」などによると、車台の組立時間は、それまでの**約12時間半**から、およそ1年で**93分**まで縮んだ。
澪：「もし、そのとき標準を12時間半のまま据え置いていたら、差異はどうなったと思いますか」
宇佐美は電卓を取り出した。仮に、標準賃率を1時間1,000円として、1,000台を93分（1.55時間）で組み立てたとする（金額は仕組みを示すための例）。

::journal シングル・プラン：標準12,500時間分を仕掛品に入れ、実際1,550時間との差を作業時間差異（有利）とする
仕掛品 12,500,000 | 賃金・給料 1,550,000
 | 作業時間差異 10,950,000
::

宇佐美：「1,095万円の有利差異。成績表なら満点ですね」
澪：「でも、それは成果じゃなくて、標準が古すぎるという警報です。流れ作業で達成した時間が、新しい標準になったはずです」
宇佐美は、自分のラインの標準作業時間の欄を見つめた。0.02時間、72秒。古いラベラーを前提にした数字だ。
宇佐美：「6月に新しいラインが入ったら、この72秒も、決め直さないといけませんね」
標準は、一度決めたら終わりではない。現実の工程が変われば標準も改めなければ、差異は何も教えてくれなくなる。

出典：[The Henry Ford「K-12 Research Guide: Assembly Line」](https://askus.thehenryford.org/K12/faq/433848)、[Automotive History「October 7, 1913 – Model T chassis moving assembly line」](https://automotivehistory.org/october-7-1913-model-t-chassis-moving-assembly-line/)

::danger 差異で人を評価すると、差異が隠される
管理できない差異まで部門の責任にすると、部門は記録をごまかしたり、標準をゆるくしたりして、差異を見えなくしようとする。差異は、原因を左右できる人の成績にだけ使い、ほかの差異は原因を正すための情報として扱う。
::

::cfo 新しいラインの標準時間 ― いつ、何秒に決め直すか
6月に、新しい瓶詰めラインが入る。古いラインを前提にした標準の72秒を、どう決め直すか。宇佐美と澪は、試運転の記録を前に考えた。
**前提**
- メーカーの仕様では、新しいラインは1本36秒（0.01時間）で詰められる
- 試運転の最初の3週間の実績は、1本60秒、48秒、42秒と、週ごとに短くなっている
- いまの標準は72秒（0.02時間）で、古いラインが前提
- 標準原価は、毎月の差異で現場を評価することと、新しい酒の値決めに使っている
- ラベル紙は、前の仕入先のものに戻した
- 宇佐美「慣れるまで、2〜3か月はかかると思います」
::choice A. 標準は72秒のまま据え置く。有利差異が出て、現場の励みになる
**× 古い標準は、警報を鳴らさない。**新しいラインなら毎月大きな有利差異が出るが、それは成果ではなく、標準が古いという印だ。値決めにも古い高い原価を使い続け、売れる値段で売る機会を逃す。
::
::choice B. メーカーの仕様の36秒を、すぐに新しい標準にする
**△ 目標としては正しいが、今は届かない。**慣れるまでの数か月、毎月大きな不利差異が出て、現場は「どうせ届かない」と差異を見なくなる。値決めにだけ36秒を使えば、立ち上げの間は赤字の値段になる。
::
::choice C. 実績が安定するまで標準を決めず、その間は実際原価だけで計算する
**△ 慎重だが、立ち上げの問題が見えなくなる。**差異という物差しがなくなると、慣れの遅れなのか、機械の不具合なのかを区別できない。値決めの根拠もなくなる。
::
::choice D. 直近の実績に近い42秒を仮の標準とし、毎月見直して、安定したら改める
**◎ 達成できるが、ゆるくない標準を選んでいる。**仮の標準なら、差異は小さく、意味のある大きさで出る。慣れるにつれて標準を詰めていけば、現場の努力が差異に表れ続ける。値決めには、安定後の見込みの時間を別に使えばよい。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「標準は何秒か」ではなく、「現場の評価と値決めの両方に使える、達成できるが努力の要る水準はどこか」を問う。
#### 手順2　前提の数字で確かめる
仮に、新しいラインの1か月目に2万本を詰め、実績が平均45秒（250時間）だったとする。直接労務費と製造間接費を合わせて1時間9,000円（1,800円＋7,200円）とすると、標準ごとの差異はこうなる。
::table compact 標準の時間と、1か月目の差異（作業時間差異と能率差異の合計）
| 標準 | 標準の時間（2万本） | 差異 |
| 72秒（いまの標準） | 400時間 | 135万円の有利差異 |
| 42秒（仮の標準） | 約233時間 | 約15万円の不利差異 |
| 36秒（メーカーの仕様） | 200時間 | 45万円の不利差異 |
::
72秒では、何もしなくても大きな有利差異が出る。36秒では、毎月の不利差異が当たり前になる。42秒なら、差異は小さく、改善の余地を正直に示す。
#### 手順3　ほかの答えに引かれる理由
Aは「有利差異は良いこと」という思い込みに、Bは「目標は高いほうがいい」という正しさに、Cは「分からないうちは決めない」という慎重さに引かれる。ラベル紙を戻したことは、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **標準は、達成できるが努力の要る水準に置く**：理想の数字（36秒）は目標に、管理には現実的な数字を使う
- **工程が変わったら、標準も変える**：古い標準の有利差異は、成果ではなく警報だ
#### 前提が変われば
立ち上げの途中で大口の注文の値決めをしなければならないなら、値決めには仕様の36秒ではなく、安定後の見込み（たとえば40秒）を使う。管理の標準と値決めの見込みは、目的に合わせて使い分けてよい。
::
::

::exam 標準原価計算の急所
- 価格差異・賃率差異＝（標準－実際）×**実際**の量。数量差異・時間差異＝（標準－実際）×**標準**の価格
- 標準消費量・標準作業時間は、**当月投入量**（加工費は換算量）×1単位あたりの標準
- 製造間接費：予算差異＝予算許容額－実際、能率差異＝（標準時間－実際時間）×標準配賦率、操業度差異＝（実際時間－基準時間）×固定費率
- 能率差異を変動費だけで計算する指示なら、操業度差異は（標準時間－基準時間）×固定費率
- パーシャル・プランは仕掛品で差異、シングル・プランは原価要素の勘定で差異
::

::next 差異の情報を、予算と業績評価へ
1級では、能率差異を変動費と固定費に分けて4つに分析する方法、配合差異・歩留差異、標準原価を使った予算管理と業績評価を学ぶ。標準を見直す仕組みは、トヨタ生産方式の「改善」にも通じている。
::

::summary
- 標準原価は、科学的・統計的に決めた製品1つあたりの目標の原価で、標準原価カードに書く
- 直接材料費差異は価格差異と数量差異、直接労務費差異は賃率差異と作業時間差異に分ける
- 製造間接費差異は、予算差異・能率差異・操業度差異に分ける
- パーシャル・プランは仕掛品勘定で、シングル・プランは原価要素の勘定で差異が出る
- 差異の責任は、差異が現れた部門ではなく、その原因を左右できる人にある
::

## 確認問題

::quiz
::problem 次の資料から、直接材料費の価格差異と数量差異を求めなさい（不利差異はマイナスの数で答える）。
標準価格 1kgあたり500円、製品1個あたりの標準消費量 2kg、当月の生産量 1,000個（仕掛品なし）、実際消費量 2,100kg、実際価格 1kgあたり490円
価格差異 [[21,000]] 円、数量差異 [[-50,000]] 円
::answer
価格差異＝(500円－490円)×2,100kg＝**＋21,000円（有利）**
数量差異＝(2,000kg－2,100kg)×500円＝**△50,000円（不利）**
標準消費量は1,000個×2kg＝2,000kg。価格差異には実際の量（2,100kg）を、数量差異には標準の価格（500円）を掛ける。
::
::
::problem 次の資料から、製造間接費の差異を求めなさい（公式法変動予算、能率差異は変動費と固定費の両方から計算する。不利差異はマイナスの数で答える）。
標準配賦率 1時間あたり3,000円（変動費率1,200円、固定費率1,800円）、月間の固定費予算 900,000円、基準操業度 500時間、標準作業時間 460時間、実際作業時間 480時間、実際発生額 1,500,000円
予算差異 [[-24,000]] 円、能率差異 [[-60,000]] 円、操業度差異 [[-36,000]] 円
::answer
予算許容額＝1,200円×480時間＋900,000円＝1,476,000円。予算差異＝1,476,000－1,500,000＝**△24,000円**
能率差異＝(460時間－480時間)×3,000円＝**△60,000円**
操業度差異＝(480時間－500時間)×1,800円＝**△36,000円**
合計△120,000円は、標準配賦額460×3,000＝1,380,000円と実際1,500,000円の差と一致する。
::
::
::problem パーシャル・プランで、次の取引を仕訳しなさい。
(1) 当月の直接材料の実際消費額820,000円を仕掛品に振り替えた。
(2) 当月の完成品の標準原価2,000,000円を製品に振り替えた。
::answer
::journal (1)
仕掛品 820,000 | 材料 820,000
::
::journal (2)
製品 2,000,000 | 仕掛品 2,000,000
::
パーシャル・プランでは、仕掛品の借方に実際原価、貸方に標準原価が記録され、その差が差異として仕掛品勘定に残る。
