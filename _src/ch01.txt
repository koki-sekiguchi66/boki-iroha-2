## 原価とは何か ― 「製品を作るため」に使ったお金

工業簿記でいう**原価**（製造原価）とは、製品を作るために使った材料・労働・その他のサービスを、お金で測ったものだ。椎名は、帳面の費用を3つの箱に分けるところから始めた。

::table 会社の費用を3つの箱に分ける
| 箱 | 内容 | 汐見酒造の例 |
| 製造原価 | 製品を作るためにかかった費用 | 酒米、蔵人の給料、精米機やタンクの減価償却費、ボイラーの燃料、仕込み蔵の電気代 |
| 販売費及び一般管理費 | 製品を売るため、会社を管理するための費用 | 営業部の給料、東京の展示会の費用、広告、出荷の運賃、事務所の経費、交際費 |
| 非原価項目 | 原価に含めない費用・損失 | 借入金の支払利息、火事や水害の損失、法人税等 |
::

**製造原価**は、製品が売れるまで製品の値段（原価）に含まれ、売れたときに**売上原価**として費用になる。**販売費及び一般管理費**（販管費）は、製品の原価には含めず、発生した期間の費用とする。だから、製造原価を**製品原価**、販管費を**期間原価**と呼ぶこともある。
**非原価項目**は、製造とも販売とも直接関係しない費用や、臨時の損失だ。支払利息は、お金の借り方の問題であって、酒造りの問題ではない。同じ酒を造っても、借金の多い蔵ほど原価が高い、ということになってしまうからだ。

::theory 原価は「製品のために、ふつうに使ったもの」だけ
原価に含めるのは、製品を作るために、通常の状態で使ったものだけだ。蔵が水害で米を失った損失は、たとえ製造の現場で起きても、ふだんの酒造りで生じる費用ではないので原価にしない。
原価の範囲を正しく区切らないと、製品1つあたりの原価は、作り方とは関係のない理由で上下してしまう。原価計算の出発点は、「何を原価に入れないか」を決めることだ。
::

澪は、2億5,200万円を3つの箱に仕分け直した。

::table 2億5,200万円を仕分け直す（単位：万円）
| 中身 | 金額 | 箱 |
| 蔵人・杜氏の給料 | 10,500 | 製造原価 |
| 精米機・タンク・仕込み蔵の減価償却費 | 2,700 | 製造原価 |
| ボイラーの燃料・電気・水道 | 3,000 | 製造原価 |
| 製造設備の修繕・消耗品・保険 | 1,440 | 製造原価 |
| 営業部の給料 | 2,400 | 販売費 |
| 東京の展示会・広告・出荷の運賃 | 2,300 | 販売費 |
| 品評会の出品費 | 200 | 販売費 |
| 事務所の給料・経費 | 1,600 | 一般管理費 |
| 社長の交際費 | 260 | 一般管理費 |
| 借入金の支払利息 | 800 | 非原価項目 |
::

製造原価に入るのは、上の4行の合計**1億7,640万円**だけだった。残りの7,560万円は、酒の原価ではなかった。

## 原価の3つの要素 ― 材料費・労務費・経費

製造原価は、何を使ったかによって3つに分ける。これを**原価の3要素**という。

::table 原価の3要素（形態別分類）
| 要素 | 内容 | 汐見酒造の例 |
| 材料費 | 物品を使ったことによる原価 | 酒米、醸造用の水処理剤、瓶・ラベル・王冠、ろ過の消耗材 |
| 労務費 | 人の労働を使ったことによる原価 | 杜氏・蔵人の賃金、瓶詰め係の給料、製造部門の法定福利費 |
| 経費 | 材料費・労務費以外の原価 | 減価償却費、燃料・電気・水道、修繕費、保険料 |
::

さらに、それぞれの原価が「どの製品のために使ったか」をはっきり特定できるかどうかで、**直接費**と**間接費**に分ける。

::table 直接費と間接費（製品との関連による分類）
| 分類 | 意味 | 汐見酒造の例 |
| 直接材料費 | 特定の製品に使ったと分かる材料費 | 大吟醸の仕込みに使った山田錦 |
| 間接材料費 | どの製品にも共通して使う材料費 | タンクの洗浄剤、ろ過の消耗材 |
| 直接労務費 | 特定の製品の作業に使った労務費 | 大吟醸の仕込み作業をした蔵人の賃金 |
| 間接労務費 | 製品を特定できない労務費 | ボイラー係・精米係・品質検査の担当者の給料、杜氏の給料 |
| 直接経費 | 特定の製品のために使った経費 | 特定の酒の瓶詰めを外部に頼んだ外注加工賃 |
| 間接経費 | どの製品にも共通する経費 | 仕込み蔵の減価償却費、燃料・電気代 |
::

直接費は、その製品の原価に**そのまま入れる**（賦課という）。間接費は、いったん**製造間接費**という勘定に集め、作業時間などの物差しで製品に**割り振る**（配賦という）。序章で澪がやったのは、まさにこの配賦だった。物差しの選び方は第4章と第5章で詳しく学ぶ。

::sort 帳面の費用を、正しい箱に分けなさい。
@cats 製造原価 | 販売費及び一般管理費 | 非原価項目
大吟醸に使った山田錦 => 製造原価
仕込み蔵の電気代 => 製造原価
杜氏の給料 => 製造原価
東京の百貨店での試飲会の費用 => 販売費及び一般管理費
事務所の経理担当者の給料 => 販売費及び一般管理費
借入金の利息 => 非原価項目
台風で倉庫の米が水に浸かった損失 => 非原価項目
製品を得意先へ運ぶ運賃 => 販売費及び一般管理費
::

## 米が酒に変わるまで ― 工業簿記の勘定の流れ

「では、仕訳で酒を造ってみましょう」。椎名は、ホワイトボードに5つの箱を描いた。工業簿記では、原価の流れを、次の勘定でたどる。

::steps 工業簿記の勘定の流れ
材料・賃金・経費 | 原価の3要素を、使う前・払ったときに記録する勘定。材料勘定、賃金・給料勘定、経費の各勘定
製造間接費 | 間接材料費・間接労務費・間接経費を集める勘定。月末に製品へ配賦する
仕掛品 | 作りかけの製品。直接費と、配賦した製造間接費が集まる。酒蔵なら、仕込み中の醪や、搾ったあと瓶に詰める前の酒
製品 | 完成した製品。仕掛品から振り替える
売上原価 | 売れた製品の原価。製品から振り替える
::

商業簿記では、商品を「仕入」れて「売上原価」にした。工業簿記では、その間に「作る」という工程が入る。材料・労働・経費が**仕掛品**に集まり、完成すると**製品**になり、売れると**売上原価**になる。お金が、形を変えながら流れていく。

### 10月の汐見酒造を、仕訳でたどる

造りの季節が始まる10月。空だったタンクに、最初の仕込みが入る。10月の取引を、簡略化した金額で追ってみよう（月初の在庫はないものとする）。

::example 10月の取引を仕訳しなさい
(1) 酒米3,000,000円を掛けで購入した。
(2) 酒米2,500,000円を仕込みに使った。また、タンクの洗浄剤など300,000円分の材料を使った。
(3) 蔵人の賃金9,000,000円を普通預金から支払った（源泉所得税などは考えない）。
(4) 賃金のうち、仕込み作業の分6,000,000円は直接労務費、ボイラー係・精米係などの分3,000,000円は間接労務費だった。
(5) ボイラーの燃料・電気代2,500,000円を普通預金から支払った（製造の経費）。
(6) 仕込み蔵と精米機の減価償却費2,250,000円を計上した（月割額）。
(7) 製造間接費8,050,000円を、仕掛品に配賦した。
(8) 搾って火入れを終えた酒の製造原価13,500,000円を、製品とした。
(9) 製品のうち12,000,000円分を、18,000,000円で掛けで販売した。
::answer

材料 3,000,000 | 買掛金 3,000,000
::
::journal (2) 材料の消費：直接材料費は仕掛品へ、間接材料費は製造間接費へ
仕掛品 2,500,000 | 材料 2,800,000
製造間接費 300,000 |

仕掛品 6,000,000 | 賃金・給料 9,000,000
製造間接費 3,000,000 |
::
::journal (5) 間接経費（燃料・電気）
製造間接費 2,500,000 | 普通預金 2,500,000
::
::journal (6) 間接経費（減価償却費）
製造間接費 2,250,000 | 減価償却累計額 2,250,000
::
::journal (7) 製造間接費の配賦
仕掛品 8,050,000 | 製造間接費 8,050,000
::
::journal (8) 完成品を製品へ
製品 13,500,000 | 仕掛品 13,500,000

売上原価 12,000,000 | 製品 12,000,000
売掛金 18,000,000 | 売上 18,000,000

(2)の材料は、買った3,000,000円のうち2,800,000円を使い、200,000円が月末に残っている。(6)のように、製造に使う設備の減価償却費は、販管費ではなく製造間接費になる。(9)は、売上原価の記録（売上原価／製品）と売上の記録（売掛金／売上）を同時に行う。工業簿記では、製品を売るたびに売上原価を記録する方法がふつうだ。
::

仕掛品勘定の貸方に残った**次月繰越 3,050,000円**は、月末にまだタンクの中で発酵している醪の原価だ。製品勘定の**次月繰越 1,500,000円**は、瓶に詰めたがまだ売れていない酒の原価だ。どちらも、まだ費用ではない。**資産**として、次の月に引き継がれる。

::theory 原価は「売れたとき」に費用になる
製造にかかったお金は、払った月の費用になるのではない。仕掛品、製品と形を変えながら資産として待ち、製品が売れた月に、初めて売上原価という費用になる。
だから、タンクの中の醪や、蔵の奥で熟成を待つ酒は、帳簿の上では「お金が形を変えた資産」だ。造りの季節にどれだけ給料や燃料を払っても、酒が売れるまでは、その分の利益は減らない。逆に言えば、売れない酒を造り続けると、資産が膨らみ、お金だけが出ていく。
::

## 答え合わせ ― 大吟醸の本当の姿

::scene 11月の第2火曜日、夕方 ― 蔵の事務所
「では、1億7,640万円だけで、もう一度割り振ってみてください」
椎名に言われて、澪は電卓をたたいた。作業時間は全部で12万6,000時間。1時間あたり1,400円。大吟醸は1本1.45時間だから、1本あたり2,030円。米などの材料費900円を足して、製造原価は2,930円になる。出荷価格3,500円から引くと――
「570円の、プラス……」
澪は顔を上げた。序章で「1本300円の損」と書いた大吟醸が、製造原価だけで見ると、1本570円の粗利を生んでいた。
::

::solve 交際費と利息を外すと、大吟醸は黒字だった。それでも計画は変わらない
1億7,640万円の製造原価を作業時間で割り振り直すと、1本あたりの売上総利益（粗利）はこうなる。

::table 製造原価だけで計算した、1本あたりの粗利（単位：円）
| 項目 | 普通酒 | 純米吟醸 | 大吟醸 |
| 出荷価格 | 600 | 1,400 | 3,500 |
| 材料費 | 80 | 260 | 900 |
| 加工費（1時間1,400円×作業時間） | 140 | 350 | 2,030 |
| 製造原価 | 220 | 610 | 2,930 |
| 1本の粗利 | 380 | 790 | 570 |
| 1本にかかる作業時間（時間） | 0.1 | 0.25 | 1.45 |
| **作業1時間あたりの粗利** | **3,800** | **3,160** | **393** |
::
序章の表には、酒を造るのとは関係のない販管費と支払利息7,560万円が、本数や時間に応じて割り振られていた。それを外すと、大吟醸は1本570円の粗利を生む、立派な黒字の酒だった。
ただし、表の最後の行を見てほしい。大吟醸は、蔵人の作業時間を1時間使うごとに、393円しか稼がない。普通酒の10分の1だ。蔵人の手間に限りがある以上、その手間を大吟醸に使うほど、蔵全体の稼ぎは小さくなる。「大吟醸が売れるほど蔵が貧しくなる」という序章の結論は、原価の範囲を正しく区切っても、形を変えて生き残った。
::

翌週の巡回で、澪は岩倉と一緒に、帳面の費用に「製」「販」「管」「外」の印をつけていった。最後の1行に「外」と書き込んだとき、岩倉が言った。「社長の交際費を、酒の値段に入れとったとは。先代が聞いたら、何と言うか」

::danger 原価の範囲を誤ると、値段を誤る
販管費や支払利息を製品の原価に入れると、製品1つあたりの原価は実際より高く見える。その原価をもとに値段を決めれば、売れるはずの酒に高すぎる値段をつけてしまう。逆に、原価に入れるべき製造の費用を販管費にしてしまえば、原価は安く見え、赤字の値段で売り続けることになる。
さらに、原価に何を含めるかは、在庫の金額を通じて利益にも影響する。製造の費用は、売れ残った製品や仕掛品の原価として資産に残るが、販管費はその期の費用になる。製造の費用を販管費に回せば、その期の利益は小さく、販管費を製造原価に回せば、利益は大きく見える。原価の範囲は、利益を操作する入り口にもなりうるのだ。
::

## 精米機の前で ― 「磨き二割三分」の材料費

::scene 11月の第3木曜日、早朝 ― 精米所
大吟醸の材料費は、なぜ1本900円と、普通酒の10倍を超えるのか。澪がその疑問を口にすると、小松は精米機の覗き窓を指さした。中では、山田錦が何十時間もかけて削られている。
「大吟醸は、玄米の半分以上を削って、真ん中だけで造る。削った糠は酒にならん。山口の旭酒造の『獺祭』に、二割三分というのがあるだろう。玄米の77%を削り落として、23%しか残さん。米の値段が同じでも、酒にする白米1kgの値段は、まるで別物になる」
::

残った白米の重さが、もとの玄米の何%かを**精米歩合**という。国税庁の表示の基準では、精米歩合60%以下で造るなどの条件を満たした酒を「吟醸酒」、50%以下なら「大吟醸酒」と表示できる。「獺祭 純米大吟醸 磨き二割三分」の精米歩合は23%だ。
事務所に戻った澪は、小松の言葉を、この章で学んだ材料費の考え方で確かめた。白米1kgを得るのに必要な玄米は「1÷精米歩合」。玄米1kgを600円で仕入れるとすると（仕組みを示すための例）、

::table 精米歩合と、白米1kgあたりの材料費（玄米1kg＝600円と仮定）
| 精米歩合 | 必要な玄米 | 白米1kgあたりの材料費 |
| 70%（本醸造酒の基準） | 約1.43kg | 約857円 |
| 50%（大吟醸酒の基準） | 2.00kg | 1,200円 |
| 23%（獺祭 磨き二割三分） | 約4.35kg | 約2,609円 |
::

精米歩合23%で白米1,000kgを仕込むなら、玄米は4,350kg必要だ。帳簿では、こうなる。

::journal 玄米4,350kg（1kg＝600円）を掛けで買い、精米して、白米1,000kgを大吟醸の仕込みに使った
材料 2,610,000 | 買掛金 2,610,000
仕掛品 2,610,000 | 材料 2,610,000
::

削り落とした3,350kgの米の分も、大吟醸の**直接材料費**に入る。同じ白米1,000kgでも、精米歩合70%の酒なら、材料費は約857,000円で済む。
「磨きの深さは、香りのためでもあり、原価の差でもあるんですね」と澪が言うと、小松は鼻を鳴らした。「原価のために磨いとるわけじゃない。だが、磨いた分の値段をつけん蔵は、いずれ潰れる」

::note
出典：[国税庁「清酒の製法品質表示基準の概要」](https://www.nta.go.jp/taxes/sake/hyoji/seishu/gaiyo/02.htm)、[高島屋オンラインストア「獺祭 純米大吟醸 磨き二割三分」の商品説明](https://www.takashimaya.co.jp/shopping/food/0400016594/0400001400)
::

::cfo 原価の範囲を直しても、序章の計画は正しいか
澪は、信金に出す計画（序章の判断：大吟醸を1万本減らし、空いた手間で純米吟醸を5万8,000本増やす）を見直すことにした。製造原価だけで計算すると、大吟醸は1本570円の黒字だったからだ。
岩倉は言う。「黒字の酒を減らすのは、もったいない。計画を戻しましょう」
上の「製造原価だけで計算した、1本あたりの粗利」の表を使い、大吟醸を1万本減らして、空いた1万4,500時間で純米吟醸を5万8,000本造った場合、粗利の合計がいくら変わるかを計算してから選んでほしい。販管費の総額は、本数を入れ替えても変わらないものとする。
::choice A. 大吟醸は黒字なので、計画を撤回して元の生産量に戻す
**× 1本の黒字と、蔵全体の稼ぎを取り違えている。**大吟醸を1万本減らすと、粗利は570円×1万本＝570万円減る。だが、空いた手間で純米吟醸を5万8,000本造れば、790円×5万8,000本＝4,582万円増える。差し引き**約4,000万円の増加**だ。計画を撤回すれば、この4,000万円を手放すことになる。
::
::choice B. 計画は維持する。大吟醸は黒字だが、作業時間あたりの稼ぎが最も小さい
**◎ 制約のある資源で考える。**差し引き4,582万円－570万円＝**4,012万円**の粗利の増加。序章の計算（約4,000万円）とほとんど変わらない。
判断を左右していたのは、1本あたりの損得ではなく、「蔵人の作業時間という限られた資源を、どの酒に使うと最も稼げるか」だった。作業1時間あたりの粗利は、普通酒3,800円、純米吟醸3,160円、大吟醸393円。この順番は、原価の範囲を直しても変わらない。
::
::choice C. 大吟醸は黒字なので、むしろ増やす
**× 序章と同じ錯覚に戻る。**大吟醸を1本増やすたびに、1.45時間の手間を使う。その手間で純米吟醸を5.8本造れば、粗利は約4,580円。大吟醸1本の粗利570円の8倍だ。売れるからといって増やせば、蔵の手間は、最も稼がない酒に吸い込まれていく。
::
::choice D. 販管費も製品ごとに割り振り直してから決める
**△ 慎重だが、今回の判断には要らない。**販管費の総額は、本数を入れ替えても変わらないと置いている。変わらない費用を割り振っても、どちらの案が有利かは変わらない。もちろん、東京の展示会や品評会の出品のように、大吟醸のためにかかっている販管費が減らせるなら、その分だけ計画はさらに有利になる。
::
::answer 考え方の例を見る
原価の範囲を正しく区切ると、1本あたりの損益は大きく変わる。それでも、判断の結論が変わるとは限らない。今回の判断で効いていたのは、**限られた資源（作業時間）1単位あたりの稼ぎ**だった。
意思決定に使う数字は、「その判断で変わるもの」だけを比べる。本数を入れ替えても変わらない販管費は、比べる必要がない。この考え方は、第10章の直接原価計算とCVP分析で、もう一度、本格的に登場する。
澪は、計画をそのまま信金に出した。添えた表は、序章のものではなく、この章で作り直した製造原価の表だ。
::
::

### 番頭の帳面は「商的工業簿記」だった

帰り際、椎名は、岩倉の黒い帳面を手に取った。「番頭さんの帳面は、工業簿記の分け方でいえば、**商的工業簿記**です」

::table 工業簿記の2つの種類
| 種類 | 記帳のしかた | 汐見酒造では |
| 商的工業簿記 | 材料や製品の受け払いを継続して記録せず、期末に棚卸をして原価を逆算する。商業簿記と同じ形 | 岩倉の帳面。1年に1度、在庫を数えて原価を出していた |
| 完全工業簿記 | 材料→仕掛品→製品→売上原価の流れを、原価計算と結びつけて継続して記録する | 澪が始めた月次の原価計算。2級で学ぶのはこちら |
::

「原価計算にも、範囲の違いがあります」と椎名は続けた。製品の原価だけを計算するのが**製造原価計算**、販売費・一般管理費（営業費）を計算するのが**営業費計算**（第11章）、その両方を合わせて製品が売れるまでの全部の原価を計算するのが**総原価計算**だ。そして、原価を管理するには、工場の部門ごとに、その原価に責任を持つ人（**責任センター**）を決めておく。醸造部門なら小松、瓶詰め部門なら宇佐美。第5章の部門別計算と第9章の差異分析は、この考え方の上に成り立っている。
岩倉は、帳面を閉じて言った。「1年に1度では、遅すぎたわけですな」

::exam 工業簿記の仕訳と勘定の流れ
- 第4問(1)の工業簿記の仕訳は、材料・賃金・給料・製造間接費・仕掛品・製品・売上原価などの勘定の流れが基本。**直接費は仕掛品へ、間接費は製造間接費へ**を、反射的に書けるようにする。
- 製造に使う設備の減価償却費・電気代・保険料は**製造間接費**。本社や営業所の分は販管費。問題文の「工場の」「本社の」という言葉に注意する。
- 支払利息・火災損失などの非原価項目は、原価計算には含めない。
- 勘定の流れの問題では、仕掛品勘定と製品勘定の「月初＋当月の増加－月末」の関係を使って、空欄を逆算する。
::

::next 原価計算は、値段と戦略を決める道具になる
1級では、原価計算をさらに意思決定に使う。どの製品を作り、どの製品をやめるか（差額原価収益分析）、設備に投資するか（設備投資の意思決定）、製品の企画の段階で原価を作り込む（原価企画）。いずれも、この章の「原価の範囲」と「勘定の流れ」の上に成り立っている。
::

::problem 次の資料から、当月の製品の製造原価と、売上原価を求めなさい。
月初仕掛品 200,000円、当月の直接材料費 500,000円、直接労務費 300,000円、製造間接費 400,000円、月末仕掛品 250,000円。月初製品 150,000円、月末製品 100,000円。

製品の製造原価 ＝ 月初仕掛品200,000円＋当月製造費用（500,000円＋300,000円＋400,000円）－月末仕掛品250,000円 ＝ **1,150,000円**
売上原価 ＝ 月初製品150,000円＋当月の製品の製造原価1,150,000円－月末製品100,000円 ＝ **1,200,000円**
仕掛品勘定と製品勘定は、どちらも「月初＋増加－月末＝出ていった分」という同じ形をしている。

::summary
- 製造原価は、製品を作るためにふつうに使った材料・労働・経費。販管費は期間原価として発生した期の費用、支払利息や臨時の損失は非原価項目
- 製造原価は、材料費・労務費・経費（原価の3要素）に分け、さらに直接費と間接費に分ける
- 直接費は仕掛品へ賦課し、間接費は製造間接費に集めてから仕掛品へ配賦する
- 勘定の流れは、材料・賃金・経費 → （製造間接費）→ 仕掛品 → 製品 → 売上原価
- 月末の仕掛品と製品は資産として次月に繰り越され、製品が売れたときに初めて売上原価になる
- 1本あたりの損益だけでなく、限られた資源1単位あたりの稼ぎで、生産の配分を判断する
::
