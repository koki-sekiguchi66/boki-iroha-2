::mystery 1本の酒に、銀行の利息が入っていた
10月16日、金曜日、午後2時。長岡から、顧問の公認会計士・椎名涼子がやって来た。月に1度の訪問だ。黒いパンツスーツに、使い込んだ革の鞄。名刺を渡す手つきに、無駄がない。
澪は、序章で作り直した表を差し出した。作業時間で配り直すと、大吟醸は1本300円の損になる。これを根拠に、来期は大吟醸を減らす計画を信金に出すつもりだった。
澪：「本数で割っていた帳面を、作業時間で割り直しました。数字は嘘をつきません」
椎名は表を眺め、「給料・燃料などの費用　2億5,200万円」の行に、人差し指を置いた。
椎名：「この2億5,200万円の中に、何が入っていますか」
澪は岩倉の帳面を開き、中身を書き出した。蔵人の給料、精米機の減価償却費、ボイラーの燃料代。そこまではいい。だが、その下に、東京の展示会の費用、営業部の給料、そして――
澪：「社長の交際費……と、信金に払った借入金の利息」
椎名：「酒を造るのに、銀行の利息はかかりましたか。社長が取引先と食事をしたら、醪は1日でも早く発酵しましたか」
澪：「でも、蔵で使ったお金は、全部、酒のためのお金です」
椎名は、それには答えなかった。代わりに、鞄から3枚の付箋を出した。
**大吟醸は、本当に1本300円の損なのか。そもそも、酒の「原価」とは、どこからどこまでなのか？**

## 3枚の付箋 ― 原価に入れるもの、入れないもの

椎名が机に並べた付箋には、それぞれ1語ずつ書いてあった。「製造」「販売・管理」「その他」。
椎名：「帳面の費用を1行ずつ、この3つのどれかに貼ってください。迷ったら、こう聞くんです。『この費用がなかったら、酒は造れなかったか』」
澪は1行目の「蔵人・杜氏の給料」に「製造」を貼った。精米機の減価償却費も、ボイラーの燃料も「製造」だ。手が止まったのは、「東京の展示会の費用」だった。
澪：「展示会がなかったら、酒は……造れます。でも、売れません」
椎名：「売るための費用ですね。それは酒の原価ではなく、売った期間の費用です」
陸：「じゃあ、社長の交際費は？」
いつの間にか、見習いの陸が戸口から首を出していた。
澪：「造るためでも、売るためでもなくて……会社を回すための費用、かな」
椎名：「そうです。では、最後の利息は」
澪は、しばらく考えた。利息は、お金を借りたから払っている。同じ酒を造っても、借金の多い蔵ほど払う額が大きくなる。
澪：「酒の造り方とは、関係ない」
椎名：「だから、原価に入れないんです。借金の多い蔵の酒ほど原価が高い、ということになってしまいますから」

::point メモ ― 費用の3つの箱
**製造原価**は、製品を作るためにかかった費用。**販売費及び一般管理費**（販管費）は、製品を売るため（販売費）と、会社全体を管理するため（一般管理費）の費用。**非原価項目**は、製造とも販売・管理とも関係のない費用や、火事・水害などの臨時の損失で、支払利息や法人税等も含まれる。製造原価と販管費を合わせたものを**総原価**という。
::

::theory 原価は「製品のために、ふつうに使ったもの」だけ
原価に含めるのは、製品を作るために、**通常の状態で**使ったものだけだ。蔵が水害で米を失った損失は、たとえ仕込み蔵で起きても、ふだんの酒造りで生じる費用ではないので原価にしない。
原価の範囲を正しく区切らないと、製品1つあたりの原価は、造り方とは関係のない理由で上下する。原価計算の出発点は、**何を原価に入れないかを決めること**だ。
::

30分後、帳面の2億5,200万円は、3つの箱に分かれた。

::table 2億5,200万円を3つの箱に仕分け直す（単位：万円）
| 中身 | 金額 | 箱 |
| 蔵人・杜氏の給料 | 10,500 | 製造原価 |
| 精米機・タンク・仕込み蔵の減価償却費 | 2,700 | 製造原価 |
| ボイラーの燃料・電気・水道 | 3,000 | 製造原価 |
| 製造設備の修繕・消耗品・保険 | 1,440 | 製造原価 |
| 営業部の給料 | 2,400 | 販管費 |
| 東京の展示会・広告・出荷の運賃 | 2,300 | 販管費 |
| 品評会の出品費 | 200 | 販管費 |
| 事務所の給料・経費 | 1,600 | 販管費 |
| 社長の交際費 | 260 | 販管費 |
| 借入金の支払利息 | 800 | 非原価項目 |
::

製造原価に入るのは、上の4行の合計**1億7,640万円**だけだった。残りの7,560万円は、酒の原価ではなかった。
澪：「7,560万円も、酒の値段に上乗せしていたんですね……」
澪は、自分の表の数字を見直した。どの酒も、余計な重りを背負わされていた。重りを外したら、大吟醸の姿は変わるのか。

::example 同じ電気代の請求書が、2つの箱に分かれる
汐見酒造では、仕込み蔵と事務所の電気をまとめて契約している。10月の請求は500,000円で、メーターの記録から、仕込み蔵（工場）の分が420,000円、事務所の分が80,000円と分かった。普通預金から支払った。
::answer
::journal 工場の分は製造の経費（間接経費）、事務所の分は販管費
製造間接費 420,000 | 普通預金 500,000
水道光熱費 80,000 |
::
工場の電気は、どの酒を造るのにも共通して使うので、製造間接費に集める（間接経費）。事務所の電気は、酒を造るためのものではないので、販管費の水道光熱費とする。
::trap
「電気代＝水道光熱費」と1つの勘定で済ませないこと。試験では「工場の」「本社の」「営業所の」という言葉が、行き先を決める手がかりになる。工場の減価償却費・保険料・修繕費も同じで、製造間接費に入る。

## 杜氏の給料は「直接」か ― 原価の3要素と、直接費・間接費

::scene 10月16日、午後4時 ― 仕込み蔵
椎名は、蔵を見たいと言った。湯気の向こうで、小松が櫂棒でタンクをかき混ぜている。
陸：「椎名先生、杜氏の給料って、どの酒の原価ですか？ 親方、酒に直接さわってますよね」
椎名：「小松さんは、今日、どのタンクの酒を造りましたか」
小松：「全部だ。普通酒のタンクも、大吟醸のタンクも、わしが見ねえ酒はねえ」
椎名：「それなら、小松さんの給料は、どの酒のものと1つに決められませんね」
::

製造原価は、何を使ったかで3つに分ける。これを**原価の3要素**（形態別分類）という。そのうえで、どの製品のために使ったかをはっきり特定できるかどうかで、**直接費**と**間接費**に分ける。

::table 原価の3要素と、直接費・間接費
| 要素 | 直接費（製品に直接たどれる） | 間接費（製品に共通） |
| 材料費（物を使った原価） | 大吟醸の仕込みに使った山田錦 | タンクの洗浄剤、ろ過の消耗材 |
| 労務費（人の労働の原価） | 大吟醸の仕込み作業をした蔵人の賃金 | 杜氏・ボイラー係・品質検査の担当者の給料 |
| 経費（それ以外の原価） | 特定の酒の瓶詰めを外部に頼んだ外注加工賃 | 仕込み蔵の減価償却費、燃料・電気代、保険料 |
::

陸：「親方の給料、間接なんすね。なんか、格下げみたい」
小松：「ばか言え。全部の酒に効いてるから間接なんだ」
直接費は、その製品の原価に**そのまま入れる**（賦課という）。間接費は、いったん**製造間接費**という勘定に集めてから、作業時間などの物差しで製品に**配る**（配賦という）。序章で澪がやったのは、この配賦だった。

::point メモ ― 原価のほかの分け方
原価は、ほかにも次のように分けられる。量に比例して増える**変動費**と、量にかかわらず一定の**固定費**（第4章・第10章）。製品の原価になる**製品原価**（製造原価）と、発生した期間の費用になる**期間原価**（販管費）。実際にかかった**実際原価**、前もって決めた価格や賃率で計算する**予定原価**（第2〜4章）、目標となる**標準原価**（第9章）。
::

::example タンクの洗浄剤は、どの酒の材料費か
10月、倉庫の材料のうち、大吟醸の仕込みに山田錦250,000円、普通酒の仕込みに五百万石1,800,000円を使った。また、全部のタンクの洗浄に使う洗浄剤30,000円分を払い出した。
::answer
::journal 酒米は仕掛品へ（直接材料費）、洗浄剤は製造間接費へ（間接材料費）
仕掛品 2,050,000 | 材料 2,080,000
製造間接費 30,000 |
::
酒米は、どの酒の仕込みに使ったかが分かるので、直接材料費として仕掛品へ入れる。洗浄剤は全部のタンクに共通なので、間接材料費として製造間接費に集め、あとで配賦する。
::trap
「材料＝直接材料費」と決めつけないこと。補助材料・工場消耗品・消耗工具器具備品のように、どの製品に使ったか特定しにくいものは間接材料費になる（第2章）。判断の基準は、物の種類ではなく「特定の製品にたどれるか」だ。
::

## ホワイトボードの5つの箱 ― 米が酒に変わるまでの勘定の流れ

事務所に戻ると、椎名はホワイトボードに5つの箱を描き、矢印でつないだ。
椎名：「3級では、商品を仕入れて、売りました。仕入と売上の間に、何もなかった」
椎名：「工業簿記では、その間に『作る』が入ります。お金が、材料から製品まで、形を変えて流れていくんです」

::steps 工業簿記の勘定の流れ
材料・賃金・給料・経費 | 原価の3要素を、買ったとき・払ったときに記録する勘定
製造間接費 | 間接材料費・間接労務費・間接経費を集める勘定。月末に製品へ配賦する
仕掛品 | 作りかけの製品。直接費と、配賦した製造間接費が集まる。酒蔵なら、仕込み中の醪や、搾ったあと瓶に詰める前の酒
製品 | 完成した製品。完成した分を仕掛品から振り替える
売上原価 | 売れた製品の原価。売れた分を製品から振り替える
::

澪：「お金が、米から醪へ、醪から酒へ、酒から売上原価へ……」
椎名：「では、10月の取引で実際に流してみましょう。数字は丸めます。月初の在庫はないものとして」
澪はペンを取った。1本目は、米を掛けで買った取引だ。借方に書く勘定科目を思い浮かべて、手が止まった。3級なら「仕入」だ。
椎名：「3級の癖ですね。工業簿記では、米は売り物ではありません。造るための材料です」

::journal (1) 10月　酒米3,000,000円を掛けで購入した
材料 3,000,000 | 買掛金 3,000,000
::

::journal (2) 酒米2,500,000円を仕込みに使い（直接材料費）、洗浄剤など300,000円を払い出した（間接材料費）
仕掛品 2,500,000 | 材料 2,800,000
製造間接費 300,000 |
::

::journal (3) 蔵人の賃金9,000,000円を普通預金から支払った（源泉所得税と締め日のずれは考えない。第3章）
賃金・給料 9,000,000 | 普通預金 9,000,000
::

::journal (4) 賃金のうち、仕込み作業の分6,000,000円は直接労務費、杜氏・ボイラー係・精米係の分3,000,000円は間接労務費
仕掛品 6,000,000 | 賃金・給料 9,000,000
製造間接費 3,000,000 |
::

::journal (5) ボイラーの燃料・仕込み蔵の電気代2,500,000円を普通預金から支払った（間接経費）
製造間接費 2,500,000 | 普通預金 2,500,000
::

::journal (6) 仕込み蔵と精米機の減価償却費2,250,000円を計上した（月割額。間接経費）
製造間接費 2,250,000 | 減価償却累計額 2,250,000
::

::journal (7) 製造間接費8,050,000円を、仕掛品に配賦した
仕掛品 8,050,000 | 製造間接費 8,050,000
::

::journal (8) 搾って火入れを終えた酒の製造原価13,500,000円を、製品とした
製品 13,500,000 | 仕掛品 13,500,000
::

::journal (9) 製品のうち12,000,000円分を、18,000,000円で掛けで販売した
売上原価 12,000,000 | 製品 12,000,000
売掛金 18,000,000 | 売上 18,000,000
::

(9)は、売上原価の記録（売上原価／製品）と売上の記録（売掛金／売上）を、同時に行っている。工業簿記では、製品を売るたびに売上原価を記録する方法がふつうだ。
仕訳を転記すると、お金が勘定から勘定へ流れていく様子が見える。

::tgrid
::taccount 製造間接費
材料 300,000 | 仕掛品 8,050,000
賃金・給料 3,000,000 |
普通預金 2,500,000 |
減価償却累計額 2,250,000 |
= 8,050,000 | 8,050,000
::
::taccount 仕掛品
材料 2,500,000 | 製品 13,500,000
賃金・給料 6,000,000 | 次月繰越 3,050,000
製造間接費 8,050,000 |
= 16,550,000 | 16,550,000
::
::taccount 製品
仕掛品 13,500,000 | 売上原価 12,000,000
 | 次月繰越 1,500,000
= 13,500,000 | 13,500,000
::
::

陸：「あれ、10月に払ったお金のほうが、売上原価よりずっと多いっすよ。損してません？」
椎名：「仕掛品の箱に残った305万円は、何でしょう」
澪は、窓の外の仕込み蔵を見た。タンクの中では、今も醪が泡を立てている。
澪：「まだ発酵中の醪……。製品の150万円は、瓶に詰めたけど、まだ売れていない酒」
椎名：「どちらも、まだ費用ではありません。お金が形を変えて、資産として待っているんです」

::theory 原価は「売れたとき」に費用になる
製造にかかったお金は、払った月の費用になるのではない。仕掛品、製品と形を変えながら**資産**として待ち、製品が売れた月に、初めて**売上原価**という費用になる。
だから、造りの季節にどれだけ給料や燃料を払っても、酒が売れるまでは利益は減らない。逆に言えば、売れない酒を造り続けると、資産だけが膨らみ、お金が出ていく。
::

::example 完成した酒が売れた ― 売上原価の相手はどれか
11月、製品（瓶詰めずみの普通酒）のうち原価2,200,000円分を、地元の酒販店に3,300,000円で掛けで販売した。
::answer
::journal 売れた分の原価を製品から売上原価へ。売上は別に記録する
売上原価 2,200,000 | 製品 2,200,000
売掛金 3,300,000 | 売上 3,300,000
::
売上原価の相手は、売れた「製品」だ。仕掛品は、まだ完成していない酒なので、売れることはない。
::trap
「売上原価／仕掛品」と書かないこと。流れは必ず、仕掛品→製品→売上原価の順だ。完成したとき（製品／仕掛品）と、売れたとき（売上原価／製品）の2回に分けて振り替える。
::

## 重りを外した大吟醸 ― 1億7,640万円で配り直す

::scene 10月16日、午後6時 ― 帳場
澪は電卓をたたいた。製造原価だけの1億7,640万円を、作業時間の合計12万6,000時間で割る。1時間あたり1,400円。
大吟醸は1本1.45時間だから、加工にかかる原価は1本2,030円。材料費900円を足して、製造原価は2,930円。出荷価格3,500円から引くと――
澪：「570円の、プラス……？」
::

::table 製造原価だけで配り直した、1本あたりの粗利（単位：円）
| 項目 | 普通酒 | 純米吟醸 | 大吟醸 |
| 出荷価格 | 600 | 1,400 | 3,500 |
| 材料費 | 80 | 260 | 900 |
| 加工費（1時間1,400円×作業時間） | 140 | 350 | 2,030 |
| 製造原価 | 220 | 610 | 2,930 |
| 1本の粗利（出荷価格－製造原価） | 380 | 790 | 570 |
| 1本の作業時間（時間） | 0.1 | 0.25 | 1.45 |
::

売上から製造原価を引いた利益を、**売上総利益**（粗利）という。販管費と支払利息は、酒を売った期間にまとめて費用になるので、1本ずつには配らない。
陸：「大吟醸、黒字じゃないっすか！ じゃあ、序章の計算は間違いで、大吟醸を増やせば……」
澪：「待って。この表、まだ1行足りない気がする」

::challenge 大吟醸の本当の姿は？
序章の結論は「作業時間で配ると、大吟醸は1本300円の損。手間を大吟醸に使うほど、蔵の稼ぎは減る」だった。この章で、原価の範囲を製造原価だけに区切り直すと、上の表のようになった。蔵人の作業時間には限りがある。
::choice A. 序章の表のとおり、大吟醸は1本300円の損をしている
**× 余計な重りを背負ったままの数字。**序章の表には、酒を造るのとは関係のない販管費と支払利息7,560万円が配られていた。重りを外すと、大吟醸は1本570円の粗利を生む黒字の酒だ。
::
::choice B. 1本570円の黒字なのだから、大吟醸を増やすほど蔵は儲かる
**× 陸がはまった落とし穴。**1本あたりの損得と、限られた手間の使い方を取り違えている。大吟醸を1本増やすたびに1.45時間を使い、その時間があれば純米吟醸を5.8本造れる。粗利は790円×5.8本＝約4,580円。大吟醸1本の570円の8倍だ。
::
::choice C. 1本570円の黒字だが、作業1時間あたりの粗利は約393円と最も小さい。手間の使い方としては、大吟醸を減らす結論は変わらない
**◎ 正解。**作業1時間あたりの粗利は、普通酒3,800円（380÷0.1）、純米吟醸3,160円（790÷0.25）、大吟醸約393円（570÷1.45）。原価の範囲を直しても、この順番は変わらない。
::
::choice D. 販管費も酒ごとに配り直さないと、何も言えない
**△ 慎重だが、今回の判断には要らない。**販管費の総額は、どの酒を何本造るかを入れ替えても、ほとんど変わらない。変わらない費用を配っても、どちらの案が有利かは変わらない。ただし、品評会の出品費のように大吟醸のためだけにかかる販管費は、別に見ておく価値がある。
::
::answer
#### 手順1　原価の範囲を区切る
製造原価（1億7,640万円）だけを製品に配る。販管費と非原価項目は、期間の費用であり、製品の原価ではない。
#### 手順2　限られた資源あたりで比べる
1本の粗利（380円・790円・570円）を、1本の作業時間（0.1・0.25・1.45時間）で割る。普通酒3,800円、純米吟醸3,160円、大吟醸約393円。
#### 手順3　判断で変わるものだけを比べる
本数を入れ替えても変わらない費用（販管費の総額など）は、比べなくてよい。この考え方は、第10章の直接原価計算でもう一度登場する。
::
::

::solve 大吟醸は黒字だった。それでも、手間を食う酒だった
交際費と利息を外すと、大吟醸は1本570円の粗利を生む、立派な黒字の酒だった。序章の「1本300円の損」は、酒造りと関係のない7,560万円を背負わされていた数字だ。
だが、表に「1本の作業時間」を足すと、もう1つの顔が見えた。大吟醸は、蔵人の手間を1時間使うごとに、約393円しか稼がない。普通酒の10分の1だ。もし陸の言うとおり大吟醸を増やしていたら、蔵の手間は最も稼ぎの小さい酒に吸い込まれ、7月の審査で見せる数字はさらに細っていた。
**原価の範囲を正しく区切ってから、限られた資源あたりで比べる。**数字は嘘をつかない。だが、どの数字を並べるかを決めるのは、人間の側だ。
::

帰り際、椎名は岩倉の黒い帳面を手に取った。
椎名：「番頭さんの帳面は、1年に1度、在庫を数えて原価を逆算する形ですね。工業簿記の分け方でいえば、商的工業簿記です」
岩倉：「1年に1度では、遅すぎたわけですな」
岩倉は帳面を閉じて、それきり黙った。その夜、帳場の明かりは、日付が変わるまで消えなかった。

### 試験で狙われるパターン ― 勘定の流れの逆算・工場と本社・2つの工業簿記

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 勘定の流れの空欄を逆算する**　仕掛品勘定と製品勘定は、どちらも「月初＋当月の増加－月末」で次の勘定へ流れる。空欄があっても、この関係を使えば逆算できる。

::formula 勘定の流れの基本式
月初仕掛品 ＋ 当月製造費用 － 月末仕掛品 ＝ 当月完成品原価
月初製品 ＋ 当月完成品原価 － 月末製品 ＝ 売上原価
::

::example 月初の在庫があるときの、完成品原価と売上原価
11月の汐見酒造。月初仕掛品3,050,000円、当月製造費用（直接材料費・直接労務費・製造間接費の合計）14,450,000円、月末仕掛品2,500,000円。月初製品1,500,000円、月末製品1,800,000円だった。
::answer
完成品原価＝3,050,000＋14,450,000－2,500,000＝**15,000,000円**
売上原価＝1,500,000＋15,000,000－1,800,000＝**14,700,000円**
::journal 完成と販売の振替
製品 15,000,000 | 仕掛品 15,000,000
売上原価 14,700,000 | 製品 14,700,000
::
10月の月末の在庫は、11月の月初の在庫として引き継がれる。資産として待っていたお金が、次の月の流れに合流する。
::trap
月初の在庫を足し忘れないこと。当月製造費用だけを完成品原価と思い込むのが、最も多い誤りだ。ボックス（箱）を描いて、左に「月初・当月の増加」、右に「完成（払出）・月末」を書く習慣をつけよう。
::
::
::

**② 工場か、本社か**　同じ種類の費用でも、工場の分は製造原価（多くは製造間接費）、本社・営業所の分は販管費になる。減価償却費・電気代・保険料・給料のどれもそうだ。

**③ 完全工業簿記と商的工業簿記**　2級で学ぶのは、材料から売上原価までの流れを、原価計算と結びつけて続けて記録する**完全工業簿記**だ。

::table 工業簿記の2つの種類
| 種類 | 記帳のしかた | 汐見酒造では |
| 商的工業簿記 | 材料や製品の受け払いを続けて記録せず、期末に棚卸をして原価を逆算する。商業簿記に近い形 | 岩倉の帳面 |
| 完全工業簿記 | 材料→仕掛品→製品→売上原価の流れを、原価計算と結びつけて続けて記録する | 澪が始める月次の原価計算 |
::

::table 原価計算の種類（本書の章）
| 分け方 | 種類 | 本書 |
| 生産の形 | 注文ごとに計算する個別原価計算／同じ物を続けて作るときの総合原価計算 | 第6章／第7・8章 |
| 原価の範囲 | すべての製造原価を製品原価にする全部原価計算／変動費だけを製品原価にする直接原価計算 | 第1〜9章／第10章 |
| 使う数字 | 実際にかかった原価の実際原価計算／目標の原価で計算する標準原価計算 | 第2〜8章／第9章 |
| 範囲の広さ | 製造原価だけを計算する製造原価計算／販管費（営業費）まで含める総原価計算 | 本章／第11章 |
::

原価を管理するときは、工場の部門ごとに、その原価に責任を持つ人を決めておく（**責任センター**）。醸造部門なら小松、瓶詰め部門なら宇佐美。第5章の部門別計算と、第9章の差異分析は、この考え方の上に成り立っている。

## 精米機の前で ― 「磨き二割三分」の材料費

::scene 10月22日、早朝 ― 精米所
大吟醸の材料費は、なぜ1本900円と、普通酒の10倍を超えるのか。澪がその疑問を口にすると、小松は精米機の覗き窓を指さした。中では、山田錦が何十時間もかけて削られている。
小松：「大吟醸は、玄米の半分以上を削って、真ん中だけで造る。削った糠は酒にならねえ」
小松：「山口の旭酒造の『獺祭』に、二割三分ってのがあるだろう。玄米の77%を削って、23%しか残さねえ」
::

残った白米の重さが、もとの玄米の何%かを**精米歩合**という。国税庁の表示の基準では、精米歩合60%以下などの条件を満たすと「吟醸酒」、50%以下なら「大吟醸酒」と表示できる。「獺祭 純米大吟醸 磨き二割三分」の精米歩合は23%だ。
事務所に戻った澪は、この章の勘定で確かめた。白米1kgを得るのに要る玄米は「1÷精米歩合」。玄米1kgを600円で仕入れるとすると（仕組みを示すための仮の値段）、

::table 精米歩合と、白米1kgあたりの材料費（玄米1kg＝600円と仮定）
| 精米歩合 | 必要な玄米 | 白米1kgあたりの材料費 |
| 70%（本醸造酒の基準） | 約1.43kg | 約857円 |
| 50%（大吟醸酒の基準） | 2.00kg | 1,200円 |
| 23%（獺祭 磨き二割三分） | 約4.35kg | 約2,609円 |
::

精米歩合23%で白米1,000kgを仕込むなら、玄米は4,350kg要る。

::journal 玄米4,350kg（1kg＝600円）を掛けで買い、精米して、白米1,000kgを大吟醸の仕込みに使った
材料 2,610,000 | 買掛金 2,610,000
仕掛品 2,610,000 | 材料 2,610,000
::

削り落とした3,350kgの米の分も、大吟醸の**直接材料費**に入る。同じ白米1,000kgでも、精米歩合70%の酒なら、材料費は約857,000円で済む。
澪：「磨きの深さは、香りのためでもあり、原価の差でもあるんですね」
小松：「原価のために磨いてるわけじゃねえ。だが、磨いた分の値段をつけねえ蔵は、いずれ潰れる」

::note
出典：[国税庁「清酒の製法品質表示基準の概要」](https://www.nta.go.jp/taxes/sake/hyoji/seishu/gaiyo/02.htm)、[高島屋オンラインストア「獺祭 純米大吟醸 磨き二割三分」の商品説明](https://www.takashimaya.co.jp/shopping/food/0400016594/0400001400)
::

::danger 原価の範囲は、利益を動かす入り口にもなる
製造の費用は、売れ残った製品や仕掛品の原価として資産に残るが、販管費はその期の費用になる。製造の費用を販管費に回せばその期の利益は小さく、販管費を製造原価に回せば、在庫に残る分だけ利益は大きく見える。原価の範囲の線引きは、値段を誤る原因にも、利益を操作する入り口にもなる。
::

::exam 工業簿記の仕訳と勘定の流れの急所
- **直接費は仕掛品へ、間接費は製造間接費へ**。第4問の仕訳の基本中の基本
- 工場の設備の減価償却費・電気代・保険料は**製造間接費**。本社の分は販管費。「工場の」「本社の」を読み落とさない
- 支払利息・火災損失などの非原価項目は、原価計算に含めない
- 勘定の流れの空欄は「月初＋当月の増加－月末」で逆算する。月初の在庫を足し忘れない
- 売上原価の相手は製品。仕掛品から直接、売上原価に振り替えない
::

::next 原価計算は、値段と戦略を決める道具になる
1級では、原価計算をさらに意思決定に使う。どの製品を作り、どの製品をやめるか（差額原価収益分析）、設備に投資するか（設備投資の意思決定）。いずれも、この章の「原価の範囲」と「勘定の流れ」の上に成り立っている。
::

::summary
- 製造原価は製品を作るための費用、販管費は売るため・管理するための費用、支払利息や臨時の損失は非原価項目
- 原価に含めるのは、製品のために通常の状態で使ったものだけ
- 製造原価は材料費・労務費・経費に分かれ、製品にたどれる直接費は仕掛品へ、共通の間接費は製造間接費へ集めて配賦する
- 原価は材料→仕掛品→製品→売上原価と流れ、売れたときに初めて費用になる
- 月末の仕掛品と製品は資産として次の月に引き継がれ、「月初＋当月の増加－月末」で次の勘定へ流れる
- 2級で学ぶのは、流れを続けて記録する完全工業簿記
::
