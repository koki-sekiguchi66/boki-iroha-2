::mystery 消えた5,400万円
4月12日、月曜日。造りの季節が終わった。最後の醪を搾り終えた仕込み蔵は、がらんとして、木の匂いだけが残っている。小松は、来週には岩手へ帰る。
澪は、7月から3月までの9か月の数字を締めた。製造にかかった費用は、**1億4,200万円**。米も、人も、燃料も、ボイラーの修理代も、全部入っている。
ところが、9か月の損益計算書の売上原価は、**8,800万円**しかなかった。
その日の午後、叔父の達也が、株主として決算の見通しを聞きに来た。数字を見るなり、テーブルを指でたたいた。
叔父：「1億4,200万円使って、原価が8,800万円？ 5,400万円はどこへ行った」
叔父：「まさか、蔵の中で消えたなんて言うんじゃないだろうな。番頭が、どこかに流したんじゃないのか」
岩倉の顔から、血の気が引いた。審査まで、あと91日。こんな疑いを抱えたまま、信金に出す決算は作れない。
**9か月で使った1億4,200万円のうち、5,400万円はどこへ行ったのか？**
::

## がらんとした仕込み蔵 ― 工業簿記の決算と、在庫の行き先

叔父が帰ったあと、澪は岩倉と2人で、蔵の中を歩いた。
澪：「岩倉さん。蔵の中に、お金が形を変えて残っているとしたら、どこですか」
岩倉：「……タンクに、搾ったあと寝かせている原酒が。それと、倉庫の瓶ですな」
仕込み蔵の奥のタンクには、搾ったあと秋の出荷まで寝かせる原酒が残っている。倉庫には、第10章で見た汐路の売れ残りをはじめ、瓶に詰めた酒が積み上がっていた。
第1章で学んだとおり、製造にかかったお金は、払った月に費用になるのではない。仕掛品、製品と形を変え、売れたときに初めて売上原価になる。

::table sum 5,400万円の行き先（単位：万円）
| 在庫 | 期首（7月1日） | 期末（3月31日） | 増加 |
| 仕掛品（タンクの醪・寝かせている原酒） | 400 | 2,300 | 1,900 |
| 製品（瓶に詰めて倉庫にある酒） | 3,000 | 6,500 | 3,500 |
|= 合計 | 3,400 | 8,800 | 5,400 |
::

澪：「酒は冬に造って、1年かけて売る。造りの季節が終わった4月は、1年でいちばん在庫が多い時期なんだ」
岩倉：「秋の出荷までは、蔵の中で寝かせておくお金ですな」

::point メモ ― 工業簿記の決算
工業簿記の決算では、月次の原価計算を締めたうえで、材料・仕掛品・製品の期末の棚卸高を確かめ、棚卸減耗や評価損を処理し、原価差異を売上原価に振り替える。製造業の会社は、損益計算書に加えて**製造原価報告書**（製造原価明細書）を作り、当期の製造原価の中身を示す。
::

## 1枚の報告書 ― 製造原価報告書

::scene 4月13日、午前9時 ― 帳場
椎名に電話をすると、すぐに答えが返ってきた。
椎名：「叔父さまには、製造原価報告書をお見せしましょう。1億4,200万円が、どこから来て、どこへ流れたかが、1枚で分かります」
椎名：「損益計算書の売上原価は、この報告書の一番下の数字から始まるんです」
::

製造原価報告書は、仕掛品勘定の流れを報告書の形にしたものだ。当期にかかった製造の費用（**当期総製造費用**）に、期首の仕掛品を足し、期末の仕掛品を引くと、当期に完成した製品の原価（**当期製品製造原価**）になる。

::table sum 汐見酒造の製造原価報告書（2026年7月1日〜2027年3月31日の9か月、単位：万円）
| 区分 | 金額 |
| Ⅰ 直接材料費（期首材料300＋当期仕入5,400－期末材料500） | 5,200 |
| Ⅱ 直接労務費 | 3,000 |
| Ⅲ 直接経費（外注加工賃） | 100 |
| Ⅳ 製造間接費（実際発生額5,900－製造間接費配賦差異300） | 5,600 |
|= 当期総製造費用 | 13,900 |
::

::table 当期製品製造原価までの計算（単位：万円）
| 区分 | 金額 |
| 当期総製造費用 | 13,900 |
| ＋ 期首仕掛品棚卸高 | 400 |
| 合計 | 14,300 |
| － 期末仕掛品棚卸高 | 2,300 |
|= 当期製品製造原価 | 12,000 |
::

製造間接費を予定配賦しているので、報告書には、実際の発生額5,900万円から配賦差異300万円（不利）を差し引いた予定配賦額5,600万円が載る。差異の300万円は、損益計算書の売上原価で足し戻す。

::table 損益計算書の売上原価の区分（9か月、単位：万円）
| 区分 | 金額 |
| 期首製品棚卸高 | 3,000 |
| ＋ 当期製品製造原価 | 12,000 |
| 合計 | 15,000 |
| － 期末製品棚卸高 | 6,500 |
| 差引 | 8,500 |
| ＋ 原価差異（製造間接費配賦差異） | 300 |
|= 売上原価 | 8,800 |
::

::theory 製造原価報告書と損益計算書は、当期製品製造原価でつながる
製造原価報告書の最後の数字（当期製品製造原価）が、損益計算書の売上原価の計算に入る。
- 当期総製造費用＋期首仕掛品－期末仕掛品＝当期製品製造原価
- 期首製品＋当期製品製造原価－期末製品＝売上原価（原価差異を加減）
2つの式は、第1章の「月初＋当月の増加－月末」と同じ形だ。仕掛品と製品の2つの箱を、順に通り抜けていく。
::

澪は、9か月の実際の製造の費用を確かめた。当期総製造費用1億3,900万円に、売上原価で足し戻した配賦差異300万円を加えると、1億4,200万円。叔父の言う「使ったお金」と一致する。

::example 原価差異を、会計年度末に売上原価へ振り替える
年度末に、原価差異の勘定に次の残高があった。材料消費価格差異5,800,000円（借方）、賃率差異1,000,000円（借方）、製造間接費配賦差異3,000,000円（借方）、標準原価計算の能率差異200,000円（貸方）。
::answer
::journal 不利差異（借方残高）は売上原価に加算、有利差異（貸方残高）は売上原価から減算
売上原価 9,800,000 | 材料消費価格差異 5,800,000
 | 賃率差異 1,000,000
 | 製造間接費配賦差異 3,000,000
能率差異 200,000 | 売上原価 200,000
::
差し引き9,600,000円が売上原価に加わる。原価計算表の1本あたりの原価には出てこなかった米価の上昇や、ボイラーの故障の影響が、ここで初めて損益計算書の利益を削る。
::trap
借方残高の差異を売上原価から引かないこと。借方残高＝不利差異＝原価が予定より多くかかった分なので、売上原価に**加える**。
::
::
::

澪は、仕掛品と製品の勘定をつなげて、5,400万円の行き先を確かめた。9か月で使った1億4,200万円のうち、売れた酒の原価として費用になったのは8,800万円。残りの5,400万円は、仕掛品が1,900万円、製品が3,500万円増えた分として、タンクと倉庫の中にあった。

::solve 5,400万円は、タンクと倉庫の中で、秋の出荷を待っていた
9か月で使った1億4,200万円のうち、売れた酒の原価（売上原価）になったのは8,800万円。残りの5,400万円は消えたのではなく、寝かせている原酒（仕掛品）が1,900万円、瓶詰めした酒（製品）が3,500万円増えた分として、資産のまま蔵の中に残っていた。
もし叔父の疑いのまま岩倉の帳面を調べ回していたら、蔵でいちばん帳面を知る人の信用を傷つけ、審査の準備は止まっていた。逆に、「在庫がある」というだけで安心するのも危ない。在庫は、売れて初めてお金に戻る。秋に売れなければ、5,400万円はお金に戻らない。
**造るのに使ったお金は、売れるまで在庫として待つ。製造原価報告書は、そのお金の居場所を1枚で示す地図だ。**
::

翌週、澪は製造原価報告書と在庫の表を、叔父に郵送した。返ってきたのは、短いメールだった。「分かった。番頭には悪いことを言った」。岩倉は、そのメールを印刷して、帳面の間にはさんだ。

その夜、澪は父の黒い手帳を開き、最初の1行を見つめた。

::memo 黒い手帳の1行目
斗瓶　一本　いくら
::

9か月の数字と、第5章の部門別の配賦率、第8章の等価係数で、澪は計算をやり直した。大吟醸「斗瓶取り」1本の製造原価は、材料費900円と加工費を合わせて、約2,790円。出荷価格3,500円に対して、粗利は1本約710円だった。
澪は、手帳の余白に、小さく「2,790」と書き込んだ。父に見せるのは、もう少し先にしようと思った。この数字が、父の問いへの答えのすべてではない気がしたからだ。

## 宇佐美の工場元帳 ― 本社工場会計

::scene 4月14日、午後 ― 瓶詰め場の事務室
造りが終わると、瓶詰め場は1年でいちばん忙しくなる。宇佐美は、工場の帳簿を自分の机で付けたいと言い出した。
宇佐美：「材料の出し入れも、賃金も、瓶詰めの原価も、全部、帳場に回してからだと遅いんです。工場の帳簿を、工場で付けさせてください」
椎名：「それなら、本社と工場で帳簿を分けましょう。本社工場会計です」
::

規模が大きくなった会社は、工場の会計を本社から独立させ、工場で材料・賃金・製造間接費・仕掛品などの帳簿を付けることがある。これを**工場会計の独立**（本社工場会計）という。本社と工場の取引は、本社の帳簿では**工場**勘定、工場の帳簿では**本社**勘定で記録する。

::point メモ ― 本社勘定と工場勘定
どの勘定を工場の帳簿に置くかは、問題文で指示される。一般に、材料・賃金・製造間接費・仕掛品は工場に置き、買掛金・普通預金・減価償却累計額・製品・売上は本社に置く。自分の帳簿にない勘定が相手になるとき、工場では「本社」、本社では「工場」を代わりに使う。本社の工場勘定と、工場の本社勘定の残高は、貸借が逆で一致する。
::

::example 本社と工場で、帳簿を分けて仕訳する
工場の帳簿には、材料・賃金・給料・製造間接費・仕掛品の勘定を置き、それ以外は本社に置く。
(1) 本社が材料1,000,000円を掛けで仕入れ、工場に直接届けた。
(2) 本社が工場の従業員の賃金2,000,000円を普通預金から支払った。
(3) 本社が工場の機械の減価償却費500,000円を計上した。
(4) 工場で完成した製品3,000,000円を、本社の倉庫に送った。
::answer
::journal (1) 本社
工場 1,000,000 | 買掛金 1,000,000
::
::journal (1) 工場
材料 1,000,000 | 本社 1,000,000
::
::journal (2) 本社
工場 2,000,000 | 普通預金 2,000,000
::
::journal (2) 工場
賃金・給料 2,000,000 | 本社 2,000,000
::
::journal (3) 本社
工場 500,000 | 減価償却累計額 500,000
::
::journal (3) 工場
製造間接費 500,000 | 本社 500,000
::
::journal (4) 本社
製品 3,000,000 | 工場 3,000,000
::
::journal (4) 工場
本社 3,000,000 | 仕掛品 3,000,000
::
4つの取引の後、本社の工場勘定は借方残高500,000円（1,000,000＋2,000,000＋500,000－3,000,000）、工場の本社勘定は貸方残高500,000円で一致する。
::trap
工場の帳簿に「買掛金」「普通預金」「減価償却累計額」「製品」を書かないこと。工場にない勘定の代わりは、すべて「本社」だ。まず、その勘定がどちらの帳簿にあるかを、問題文で確かめる。
::

## 営業の費用 ― 営業費の分け方

製品の原価にならない販売費及び一般管理費を、原価計算では**営業費**と呼ぶ。営業費は、発生した期間の費用（期間原価）として、月次の損益に直接入る。管理のために、営業費は働きによって分けることがある。

::table 営業費の分け方
| 分け方 | 区分 | 汐見酒造の例 |
| 形態別 | 給料・広告宣伝費・運賃・減価償却費・交際費など | 勘定科目ごとの集計 |
| 機能別 | 注文を取るための費用（**注文獲得費**） | 広告・展示会・営業部の給料 |
| 機能別 | 注文に応えて届けるための費用（**注文履行費**） | 出荷の運賃・倉庫の費用・梱包 |
| 機能別 | 会社全体を管理するための費用（**一般管理費**） | 事務所の給料・経費、社長の交際費 |
::

::journal 3月の営業費（広告宣伝費800,000円、発送費450,000円、事務所の給料1,600,000円）を、月次損益に振り替える
月次損益 2,850,000 | 広告宣伝費 800,000
 | 発送費 450,000
 | 給料 1,600,000
::

製造原価は製品・売上原価を通って費用になるが、営業費は発生した月の費用として月次損益に直接入る。第1章で、2億5,200万円から外した7,560万円が、この営業費と非原価項目だった。

### 試験で狙われるパターン ― 報告書の空欄・差異の位置・製造業の決算

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 製造原価報告書の空欄を逆算する**　材料の期首・期末と当期仕入から直接材料費を、仕掛品の期首・期末から当期製品製造原価を、製品の期首・期末から売上原価を逆算する。3つの箱（材料・仕掛品・製品）を順に描けば迷わない。

**② 原価差異はどこに書くか**　予定配賦の製造間接費は、製造原価報告書では実際発生額から配賦差異を加減して予定配賦額にし、差異そのものは損益計算書の売上原価に加減する。報告書と損益計算書で、差異の符号が逆になることに注意する。

**③ 製造業の決算整理**　第3問では、材料・製品の棚卸減耗や評価損、原価差異の振替えが、商業簿記の決算整理と一緒に出る（第22章）。

::steps 解法の型 ― 製造原価報告書と売上原価
1. 材料の箱 | 期首材料＋当期仕入－期末材料＝当期の材料費（直接と間接に分ける）
2. 製造間接費 | 間接材料費＋間接労務費＋間接経費＝実際発生額。予定配賦なら配賦差異を加減して予定配賦額に
3. 仕掛品の箱 | 当期総製造費用＋期首仕掛品－期末仕掛品＝当期製品製造原価
4. 製品の箱 | 期首製品＋当期製品製造原価－期末製品＝売上原価
5. 原価差異 | 不利差異は売上原価に加算、有利差異は減算
::

## 審査の資料 ― 6割の蔵が欠損か低収益

::scene 4月15日、夕方 ― 応接間
中間の面談に来た高梨は、帰りがけに鞄から薄い冊子を出した。国税庁が毎年まとめている、酒類の製造業者の経営の調査だった。
高梨：「審査で、業界の平均と比べるのに使っています。澪さんの製造原価報告書と、並べてみてください」
高梨：「それと、ここ。清酒の蔵の6割近くが、赤字か、それに近い。汐見酒造だけの問題ではないんです。だからこそ、どこが違うのかを、数字で見せてほしい」
::

国税庁の2020年の調査（令和2年調査分）では、清酒の製造原価のうち**原材料費が占める割合は31.1%**、原材料費のうち**原料米代が占める割合は75.7%**だった。2021年の調査（令和3年調査分）では、清酒製造業者の**58.3%が欠損または低収益**となっていた。
その夜、澪は、この割合を使って、製造原価が1億円の「平均的な蔵」の内訳を描いた（割合は調査の数字、1億円は仕組みを示すための例）。

::table sum 製造原価1億円の蔵の、原材料費とそれ以外（単位：万円）
| 区分 | 金額 |
| 原材料費のうち原料米代（31.1%×75.7%） | 2,354 |
| 原材料費のうちそれ以外（醸造用アルコール・瓶・ラベルなど） | 756 |
| 労務費・経費（人件費・減価償却費・燃料など） | 6,890 |
|= 製造原価 | 10,000 |
::

米価の高騰は、製造原価の約4分の1を占める原料米代を直撃する。仮に原料米代が1.6倍になれば、2,354万円は約3,766万円になり、製造原価は約14%上がる。一方で、製造原価の7割近くは、人と設備と燃料の費用だ。その多くは、造る量を減らしても減らない固定費である。
かつては上場企業の多くが、有価証券報告書に製造原価明細書を載せていた。だが2014年の制度改正で、連結財務諸表でセグメント情報を注記している会社は、個別の製造原価明細書を省略できるようになった。外からは見えにくくなった分、自社の製造原価報告書を自分で読みこなす力の価値は高い。

::note
出典：[国税庁「酒類製造業及び酒類卸売業の概況（令和2年調査分）」](https://www.nta.go.jp/taxes/sake/shiori-gaikyo/seizo_oroshiuri/r02/pdf/all.pdf)、[国税庁「酒類製造業及び酒類卸売業の概況（令和3年調査分）」](https://www.nta.go.jp/taxes/sake/shiori-gaikyo/seizo_oroshiuri/r03/pdf/all.pdf)、[大和総研「単体開示の簡素化に関する府令改正」（2014年5月）](https://www.dir.co.jp/report/research/law-research/commercial/20140509_008509.html)

::danger 在庫の増加は、利益を増やしても、お金を減らす
製造原価が在庫として資産に残る間、損益計算書の費用にはならない。だが、お金はすでに出ていっている。在庫が積み上がる会社は、利益が出ていてもお金が足りなくなる。決算書では、損益計算書と一緒に、貸借対照表の在庫の増減を必ず確かめる。
::

::cfo 去年より原価が600万円減った ― 効率は良くなったのか
高梨は、澪の製造原価報告書を去年のものと並べた。「当期製品製造原価が、去年の1億2,600万円から1億2,000万円に減っていますね。効率が良くなったと考えてよいですか」。
**前提**
- 9か月の当期総製造費用は、去年1億3,300万円、今年1億3,900万円
- 当期製品製造原価は、去年1億2,600万円、今年1億2,000万円
- 完成した酒の量（原酒換算）は、去年450kL、今年400kL
- 当期製品製造原価のうち原料米代は、去年3,000万円、今年3,400万円
- 売上原価は、去年1億100万円、今年8,800万円
- 今年は、ボイラーが2回故障した
::choice A. 良くなった。当期製品製造原価が600万円減ったのだから、効率は上がっている
**× 総額は、造った量に左右される。**今年は完成した量が50kL少ない。総額が減ったのは、造った量が減ったからだ。
::
::choice B. 1kLあたりで比べる。今年は28万円から30万円に上がっていて、上昇の大半は米価だ
**◎ 量の違いをならして比べている。**1kLあたりの製造原価は、去年1億2,600万円÷450kL＝28万円、今年1億2,000万円÷400kL＝30万円。1kLあたりの原料米代は、去年約6.7万円から今年8.5万円に上がっている。2万円の上昇のうち約1.8万円が米価で、残りは量が減って1kLあたりの固定費が重くなった分と読める。
::
::choice C. 売上原価が1,300万円も減ったので、効率は大きく良くなった
**× 売上原価は、売れた量で決まる。**今年は在庫が5,400万円増えた。売上原価が減ったのは、造った酒の多くが、まだ倉庫で売れるのを待っているからだ。
::
::choice D. ボイラーが2回止まったので、効率は悪くなったに違いない
**△ 方向は当たっているかもしれないが、数字で確かめていない。**故障の影響は、配賦差異や手待時間として表れるが、1kLあたりの原価の上昇の大半は、米価で説明できる。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「総額は減ったか」ではなく、「同じ量の酒を造るのに、去年より多く、または少なくかかったか」を問う。量の違いをならすために、1kLあたりで比べる。
#### 手順2　前提の数字で確かめる
::table compact 1kLあたりで比べる（当期製品製造原価）
| 項目 | 去年 | 今年 |
| 当期製品製造原価 | 12,600万円 | 12,000万円 |
| 完成した量 | 450kL | 400kL |
| 1kLあたり | 28万円 | 30万円 |
| うち原料米代（1kLあたり） | 約6.7万円 | 8.5万円 |
::
1kLあたりでは、去年より2万円（約7%）高い。そのうち約1.8万円は原料米代の上昇だ。
#### 手順3　ほかの答えに引かれる理由
Aは、総額が減ったという分かりやすさに、Cは売上原価の大きな減少に引かれる。どちらも、量の違いと在庫の増加を見落としている。Dは直感としては自然だが、数字で確かめる前に結論を出している。当期総製造費用の増加（1億3,300万円→1億3,900万円）は、期末の仕掛品が増えたことも含んでいるので、効率の比較にはそのまま使えない。
#### 持ち帰る考え方
- **総額ではなく、1単位あたりで比べる**：造った量が違えば、総額の比較は意味を持たない
- **上昇の中身を分ける**：米価（変動費の単価）か、量の減少（固定費の重さ）か
#### 前提が変われば
今年の完成した量が去年と同じ450kLなら、1kLあたりの製造原価は約26.7万円になり、米価の上昇を吸収して効率が上がったと言える。量を戻せるかどうかが、来期の原価を決める。
::
::

::exam 製造原価報告書と本社工場会計の急所
- 製造原価報告書：当期総製造費用＋期首仕掛品－期末仕掛品＝**当期製品製造原価**
- 損益計算書：期首製品＋当期製品製造原価－期末製品＝売上原価（**原価差異を加減**）
- 予定配賦の製造間接費は、報告書では実際発生額から配賦差異を加減し、差異は売上原価で加減する
- 本社工場会計：自分の帳簿にない勘定の代わりに、本社では「工場」、工場では「本社」を使う
- 営業費は期間原価。製品・売上原価を通らずに、その期の損益に入る
::

::next 製造業の決算書を、外から読む
第22章では、製造業の会社の決算整理と、報告式の損益計算書・貸借対照表を作る。1級では、製造原価の差異をさらに細かく分析し、予算と実績を比べて業績を評価する方法を学ぶ。上場企業の決算書を読むときは、製造原価明細書がない会社も多いので、売上原価率と在庫の回転を自分で計算して補う。
::

::summary
- 製造にかかったお金は、仕掛品・製品の在庫として待ち、売れたときに売上原価になる
- 製造原価報告書は、当期総製造費用から当期製品製造原価までを示す
- 当期製品製造原価が、損益計算書の売上原価の計算に入る。原価差異は売上原価で加減する
- 本社工場会計では、本社の工場勘定と工場の本社勘定で、本社と工場の取引を記録する
- 営業費は期間原価で、注文獲得費・注文履行費・一般管理費に分けて管理できる
::
