澪には、答えの見当はついていた。だが、それを1枚の表で示す方法を、まだ知らなかった。

## 製造原価報告書 ― 「造るのにいくらかかったか」の1枚

製造業の会社は、損益計算書と貸借対照表に加えて、**製造原価報告書**（Cost Report、C/R）を作る。当期に製品を造るためにかかった原価を、材料費・労務費・経費に分けて示し、当期に完成した製品の原価（**当期製品製造原価**）を計算する表だ。

::table sum 汐見酒造の製造原価報告書（2026年7月1日〜2027年3月31日の9か月、単位：万円）
| 区分 | 金額 |
| Ⅰ 直接材料費（期首材料300＋当期仕入5,400－期末材料500） | 5,200 |
| Ⅱ 直接労務費 | 3,000 |
| Ⅲ 直接経費（外注加工賃） | 100 |
| Ⅳ 製造間接費（実際発生額5,900－製造間接費配賦差異300） | 5,600 |
|= 当期総製造費用 | 13,900 |
::

::table 当期製品製造原価までの計算（単位：万円）
| 区分 | 金額 |
| 当期総製造費用 | 13,900 |
| ＋ 期首仕掛品棚卸高 | 400 |
| 合計 | 14,300 |
| － 期末仕掛品棚卸高 | 2,300 |
|= 当期製品製造原価 | 12,000 |
::
::note
※製造間接費の実際発生額5,900万円の内訳：間接材料費300、間接労務費1,800、減価償却費2,025、燃料・電力1,200、その他575。製造間接費は予定配賦しており、予定配賦額5,600万円との差300万円（不利差異）は製造間接費配賦差異として、製造原価報告書で差し引き、損益計算書の売上原価に加える。
::

::theory 製造原価報告書の2つの合計
- **当期総製造費用**：当期に発生した製造原価の合計（材料費＋労務費＋経費。予定配賦なら製造間接費は予定配賦額）。「今期、造るためにいくら使ったか」
- **当期製品製造原価**：当期に完成した製品の原価＝当期総製造費用＋期首仕掛品－期末仕掛品。「今期、いくら分の製品ができあがったか」
仕掛品勘定の借方と貸方を、そのまま表にしたものだと考えればよい。
::

::tgrid
::taccount 仕掛品（9か月の合計、単位：万円）
前期繰越 400 | 製品 12,000
直接材料費 5,200 | 次期繰越 2,300
直接労務費 3,000 |
直接経費 100 |
製造間接費（予定配賦） 5,600 |
= 14,300 | 14,300
::
::taccount 製品（9か月の合計、単位：万円）
前期繰越 3,000 | 売上原価 8,500
仕掛品 12,000 | 次期繰越 6,500
= 15,000 | 15,000
::
::

## 損益計算書と貸借対照表へ

製造原価報告書の最後の数字、当期製品製造原価1億2,000万円は、損益計算書の売上原価の計算に引き継がれる。

::table 損益計算書の売上原価の区分（9か月、単位：万円）
| 区分 | 金額 |
| 期首製品棚卸高 | 3,000 |
| ＋ 当期製品製造原価 | 12,000 |
| 合計 | 15,000 |
| － 期末製品棚卸高 | 6,500 |
| 差引 | 8,500 |
| ＋ 原価差異（製造間接費配賦差異） | 300 |
|= 売上原価 | 8,800 |
::

そして、期末の材料500万円、仕掛品2,300万円、製品6,500万円は、貸借対照表の**棚卸資産**（流動資産）になる。

::steps 3つの表のつながり
製造原価報告書 | 当期総製造費用から、仕掛品の増減を調整して、当期製品製造原価を出す
損益計算書 | 当期製品製造原価から、製品の増減を調整して、売上原価を出す。原価差異もここで加減する
貸借対照表 | 期末の材料・仕掛品・製品が、棚卸資産として次の期に繰り越される
::

## 答え合わせ ― 5,400万円は、蔵の中にあった

::solve 使ったお金のうち5,400万円は、タンクと倉庫の在庫になっていた
9か月の実際の製造原価（材料5,200万円＋労務費3,000万円＋直接経費100万円＋製造間接費5,900万円）は、合計1億4,200万円。損益計算書の売上原価は8,800万円。差の5,400万円は、在庫の増加だった。
::table sum 5,400万円の行き先（単位：万円）
| 在庫 | 期首 | 期末 | 増加 |
| 仕掛品（タンクの中の醪・搾ったあと熟成中の原酒） | 400 | 2,300 | 1,900 |
| 製品（瓶に詰めて倉庫にある酒） | 3,000 | 6,500 | 3,500 |
|= 合計 | 3,400 | 8,800 | 5,400 |
::
酒は、冬に造って、1年かけて売る。冬に使ったお金の多くは、まだ売れていない酒の姿で、タンクと倉庫に眠っている。それは費用ではなく、貸借対照表の資産だ。第1章で学んだ「原価は売れたときに費用になる」の、9か月分の姿がこれだった。
::

高梨は、仕掛品と製品の2行を指でなぞった。「では、この8,800万円の在庫が、夏から秋にかけて売れていけば、そのたびに売上原価になる。逆に売れ残れば……」
「在庫のまま残って、いずれ評価を下げることになります」と澪は言った。「第14章で、古酒の評価の問題を片づけるつもりです」

::danger 在庫の増加は、利益の質を下げることがある
損益計算書の利益だけを見ていると、「使ったお金」が在庫に姿を変えて資産に残っていることに気づかない。製造業では、売上が伸びないのに在庫が膨らむとき、全部原価計算の利益は大きく見える（第10章）。
決算書を読むときは、製造原価報告書の当期総製造費用と、損益計算書の売上原価を比べ、差がどこへ行ったのか（仕掛品と製品の増減）を確かめる。在庫が売れる見込みのあるものかどうかで、同じ利益でも質がまったく違う。
::

## 原価差異の決算処理

第2章〜第4章、第9章で学んだ原価差異（材料消費価格差異・賃率差異・製造間接費配賦差異・標準原価差異）は、会計年度末にまとめて処理する。

::theory 原価差異は、原則として売上原価に加減する
- 予定価格・予定賃率・予定配賦率・標準原価などが適当に決められていれば、差異は小さく、**売上原価に振り替える**（売上原価加減法）。不利差異（借方）は売上原価に加算、有利差異（貸方）は売上原価から減算する
- 火災や長期の操業停止など、**異常な状態**が原因の差異は、原価に含めず、非原価項目（特別損失など）とする（第4章の臨時休園の例）
::

::example 6月末の決算で、原価差異を処理しなさい
年度の原価差異の残高は、材料消費価格差異5,800,000円（借方）、賃率差異1,000,000円（借方）、製造間接費配賦差異3,000,000円（借方）、標準原価計算の能率差異のうち有利差異200,000円（貸方）だった。異常な原因によるものはない。
::answer
::journal 不利差異は売上原価に加算、有利差異は売上原価から減算
売上原価 9,800,000 | 材料消費価格差異 5,800,000
 | 賃率差異 1,000,000
 | 製造間接費配賦差異 3,000,000
能率差異 200,000 | 売上原価 200,000
::
差し引き9,600,000円が売上原価に加わる。原価計算表の1本あたりの原価には出てこなかった米価の上昇や、ボイラーの故障の影響が、ここで初めて損益計算書の利益を削る。
::
::

## 本社工場会計 ― 帳簿を、事務所と蔵に分ける

造りの季節の間、澪は、毎日のように事務所と蔵を行き来して帳簿をつけた。材料の受け払い、賃金の振り分け、製造間接費の配賦。蔵の帳簿の量は、事務所の帳簿よりはるかに多い。
椎名が提案した。「蔵の帳簿は、蔵で、宇佐美さんにつけてもらいましょう。事務所と蔵で帳簿を分けるんです」

::theory 工場会計の独立（本社工場会計）
工場の規模が大きくなると、工場に独自の帳簿（**工場元帳**）を置き、製造に関する取引は工場で記帳する。本社の帳簿（**本社元帳**）には、お金の出入りや販売など、それ以外の取引を記帳する。
本社と工場の間の取引は、本社の帳簿に**工場勘定**、工場の帳簿に**本社勘定**を設けて記録する。2つの勘定は、貸借が反対で金額が一致する（**照合勘定**）。
::

汐見酒造では、蔵（工場）の帳簿に、材料・賃金・給料・製造間接費・仕掛品と本社勘定を置き、事務所（本社）の帳簿に、現金預金・売掛金・買掛金・製品・売上・売上原価・減価償却累計額と工場勘定を置くことにした。

::example 次の取引を、本社と工場のそれぞれの帳簿に仕訳しなさい
(1) 本社は、工場で使う酒米1,000,000円を掛けで購入し、工場の倉庫に直接運び込ませた。
(2) 本社は、工場の蔵人の賃金2,000,000円を普通預金から支払った（源泉所得税などは考えない）。
(3) 工場の機械の減価償却費500,000円を計上した。減価償却累計額は本社の帳簿で記録している。
(4) 工場で酒が完成し、製造原価3,000,000円の製品を本社の倉庫に送った。
::answer
::journal (1) 本社
工場 1,000,000 | 買掛金 1,000,000
::
::journal (1) 工場
材料 1,000,000 | 本社 1,000,000
::
::journal (2) 本社
工場 2,000,000 | 普通預金 2,000,000
::
::journal (2) 工場
賃金・給料 2,000,000 | 本社 2,000,000
::
::journal (3) 本社
工場 500,000 | 減価償却累計額 500,000
::
::journal (3) 工場
製造間接費 500,000 | 本社 500,000
::
::journal (4) 本社
製品 3,000,000 | 工場 3,000,000
::
::journal (4) 工場
本社 3,000,000 | 仕掛品 3,000,000
::
工場の帳簿にない勘定（買掛金・普通預金・減価償却累計額・製品）が相手になるときは、工場では「本社」、本社では「工場」を使う。4つの取引の後、本社の工場勘定は借方残高500,000円（1,000,000＋2,000,000＋500,000－3,000,000）、工場の本社勘定は貸方残高500,000円で一致する。
::
::

::exam 製造原価報告書と本社工場会計の急所
- 製造原価報告書は「当期総製造費用＋期首仕掛品－期末仕掛品＝当期製品製造原価」。損益計算書は「期首製品＋当期製品製造原価－期末製品＝売上原価（＋原価差異）」
- 予定配賦をしている場合、製造原価報告書では製造間接費の実際発生額から**配賦差異を加減**して予定配賦額にし、差異は損益計算書の売上原価で加減する
- 原価差異の処理：不利差異は「売上原価／○○差異」、有利差異は「○○差異／売上原価」
- 本社工場会計：まず、その勘定が「どちらの帳簿にあるか」を問題文で確かめる。自分の帳簿にない勘定の代わりに、本社では「工場」、工場では「本社」を使う
- 製造業の決算の問題（第3問）では、材料・仕掛品・製品の棚卸減耗や評価損、原価差異の振替えが、商業簿記の決算整理と一緒に出る（第22章）
::

::real 清酒の製造原価のうち、米の代金は4分の1に満たない
国税庁は、酒類の製造業者に毎年アンケートを行い、経営の状況をまとめている。2020年の調査（令和2年調査分）では、清酒の製造原価のうち**原材料費が占める割合は31.1%**、原材料費のうち**原料米代が占める割合は75.7%**だった。また、2021年の調査（令和3年調査分）では、清酒製造業者の**58.3%が欠損または低収益**となっていた。

**この章の道具で読む ― 平均的な蔵の製造原価報告書**
この割合を使って、製造原価が1億円の蔵の製造原価報告書を描いてみる（割合は調査の数字、1億円は仕組みを示すための例。原料米代は31.1%×75.7%で約23.5%）。
::table sum 製造原価1億円の蔵の、原材料費とそれ以外（単位：万円）
| 区分 | 金額 |
| 原材料費のうち原料米代（31.1%×75.7%） | 2,354 |
| 原材料費のうちそれ以外（醸造用アルコール・瓶・ラベルなど） | 756 |
| 労務費・経費（人件費・減価償却費・燃料など） | 6,890 |
|= 製造原価 | 10,000 |
::
第2章で見た米価の高騰は、製造原価の約4分の1を占める原料米代を直撃する。仮に原料米代が1.6倍になれば、2,354万円は約3,766万円になり、製造原価は約14%上がる。
一方で、製造原価の7割近くは、人と設備と燃料の費用だ。その多くは、造る量を減らしても減らない固定費である。造る量が減れば、1本あたりの固定費が重くなる（序章・第10章）。6割近い蔵が欠損か低収益という数字の裏には、米価という変動費の上昇と、量の減少による固定費の重さという、2つの圧力が重なっている。
製造原価報告書は、その2つを1枚の表で分けて見せてくれる。かつては上場企業の多くが有価証券報告書にこの表を載せていたが、2014年の制度改正で、連結財務諸表でセグメント情報を注記している会社は、個別の製造原価明細書を省略できるようになった。外からは見えにくくなった分だけ、自社の製造原価報告書を自分で読みこなす力の価値は高い。
::note
出典：[国税庁「酒類製造業及び酒類卸売業の概況（令和2年調査分）」](https://www.nta.go.jp/taxes/sake/shiori-gaikyo/seizo_oroshiuri/r02/pdf/all.pdf)、[国税庁「酒類製造業及び酒類卸売業の概況（令和3年調査分）」](https://www.nta.go.jp/taxes/sake/shiori-gaikyo/seizo_oroshiuri/r03/pdf/all.pdf)、[大和総研「単体開示の簡素化に関する府令改正」（2014年5月）](https://www.dir.co.jp/report/research/law-research/commercial/20140509_008509.html)
::

::cfo 高梨の質問 ― 今年の酒造りは、去年より効率がよくなったか
製造原価報告書を見た高梨が、去年の同じ時期の表と並べて言った。「当期製品製造原価は、去年の9か月が1億2,600万円、今年が1億2,000万円。600万円減っています。経費の管理が効いてきたということでしょうか」
::table 去年と今年の9か月の比較
| 項目 | 去年 | 今年 |
| 当期総製造費用 | 13,300万円 | 13,900万円 |
| 当期製品製造原価 | 12,600万円 | 12,000万円 |
| 売上原価 | 10,100万円 | 8,800万円 |
| 完成した酒の量（原酒換算） | 450kL | 400kL |
| うち原料米代 | 3,000万円 | 3,400万円 |
::
まず、完成した酒1kLあたりの製造原価を、去年と今年で計算してから選んでほしい。
::choice A. 当期製品製造原価が600万円減ったので、効率はよくなった
**× 総額は、造った量に左右される。**今年は完成した量が50kL少ない。1kLあたりに直すと、去年は1億2,600万円÷450kL＝**28万円**、今年は1億2,000万円÷400kL＝**30万円**。1kLあたりでは、むしろ7%以上高くなっている。総額が減ったのは、造った量が減ったからだ。
::
::choice B. 完成した酒1kLあたりの製造原価で比べる。今年は28万円から30万円に上がった
**◎ 量の違いをならして比べている。**1kLあたり2万円の上昇のうち、原料米代は去年の6.7万円（3,000万円÷450kL）から今年の8.5万円（3,400万円÷400kL）に1.8万円上がっている。上昇の大半は米価だ。残りの0.2万円は、造る量が減って1kLあたりの固定費が重くなった分と読める。経費の管理が悪化したわけでも、改善したわけでもない。
::
::choice C. 売上原価が1,300万円も減ったので、大幅に効率化した
**× 売上原価は、売れた量と在庫の増減で決まる。**売上原価には、期首と期末の製品の在庫の差が入る。今年は在庫が大きく増えたので、売上原価が小さくなっただけだ。造る効率を見るのに、売上原価は使えない。
::
::choice D. 当期総製造費用が600万円増えたので、効率は悪化した
**△ 方向は合っているが、理由がずれる。**当期総製造費用には、まだ完成していない仕掛品に使った分も含まれる。今年は熟成中の原酒（仕掛品）が多いので、その分だけ大きく見える。効率を比べるなら、完成した量あたりの原価を見るのが筋だ。
::
::answer 考え方の例を見る
製造の効率は、総額ではなく、**完成した量1単位あたりの原価**で比べる。総額は造った量で、売上原価は売れた量と在庫で動く。そして単位原価の変化を、米価のような価格の要因と、量の減少による固定費の重さの要因に分けて読む。
澪は、高梨の前で電卓をたたき直し、「効率がよくなったわけではありません。米価で1kLあたり1.8万円上がっています」と答えた。高梨は、メモに「正直」と書いた。
::
::

::next 工業簿記の決算と、その先
1級では、本社と工場の間で、原価に利益を上乗せした価格（振替価格）で製品を受け渡す場合の**内部利益**の処理や、原価差異を売上原価と期末の棚卸資産に配分する方法などを学ぶ。また、製造原価報告書は、第22章の製造業の決算で、損益計算書・貸借対照表と一緒に作ることになる。

::summary
- 製造原価報告書は、当期総製造費用（今期造るために使った原価）から、仕掛品の増減を調整して当期製品製造原価（今期完成した製品の原価）を示す
- 損益計算書の売上原価は、期首製品＋当期製品製造原価－期末製品に、原価差異を加減して求める
- 使ったお金と売上原価の差は、仕掛品と製品の在庫の増減。在庫は貸借対照表の棚卸資産になる
- 原価差異は、原則として売上原価に加減する。異常な原因の差異は非原価項目
- 本社工場会計では、本社の帳簿に工場勘定、工場の帳簿に本社勘定を置き、互いの取引を貸借反対で記録する
- 製造の効率は、総額ではなく、完成した量1単位あたりの原価で比べる
