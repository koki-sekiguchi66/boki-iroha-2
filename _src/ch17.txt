## 試験場の請求書 ― 研究開発費は、発生した期の費用

::table 今期の研究の支出（単位：万円）
| 項目 | 金額 |
| 醸造試験場への委託研究費 | 900 |
| 研究専用の分析機器（ガスクロマトグラフ） | 800 |
| 研究担当の社員の給料 | 600 |
| 試験醸造の原材料・瓶 | 300 |
|= 合計 | 2,600 |
::

椎名：「工場は、建てた時点で、それが何年も使えることが分かっています。では、研究はどうですか」
澪：「……新しい酵母が、本当にいい酒になるかは、まだ分かりません」
椎名：「そうです。研究は、成功するかどうか、成功しても何年稼ぐかが分からない。だから、使った年に全額を費用にすると決められています」
新しい知識の発見を目指す調査（**研究**）と、その知識を製品や工程に具体化する活動（**開発**）にかかった費用を**研究開発費**という。研究開発費は、資産にせず、**発生した期の費用**とする。

::theory 研究開発費は、使った年に全額が費用になる
研究開発の成果が将来の収益につながるかどうかは、支出の時点では分からない。そのため、研究開発費は、すべて発生したときの費用とする（研究開発費等に係る会計基準）。
研究にだけ使う機械や装置は、何年使えるものでも、取得したときに研究開発費とする。ほかの目的にも使える機械なら、ふつうの固定資産として計上し、研究に使った期間の減価償却費を研究開発費とする。
::

::example 今期の研究の支出を記録する
(1) 県の醸造試験場への委託研究費9,000,000円を、普通預金から支払った。
(2) 研究専用の分析機器8,000,000円を購入し、普通預金から支払った。ほかの目的には使えない。
(3) 研究担当の社員の給料6,000,000円を、普通預金から支払った。
(4) 試験醸造に使った原材料と瓶3,000,000円を、普通預金から支払った。
::answer
::journal (1)
研究開発費 9,000,000 | 普通預金 9,000,000
::
::journal (2) 研究専用の機械は、取得したときに研究開発費
研究開発費 8,000,000 | 普通預金 8,000,000
::
::journal (3)
研究開発費 6,000,000 | 普通預金 6,000,000
::
::journal (4)
研究開発費 3,000,000 | 普通預金 3,000,000
::
研究開発費は、損益計算書では、原則として販売費及び一般管理費（製造のための研究なら当期製造費用）に表示する。今期の研究開発費は合計26,000,000円だ。
::trap
研究専用の分析機器を「機械装置」として資産にしないこと。研究にしか使えない機械は、取得した期の研究開発費になる。ほかにも使える機械なら固定資産として減価償却し、研究に使った分の減価償却費が研究開発費になる。
::
::
::

澪は、AI企業の表を見つめた。売上総利益よりはるかに大きな研究開発費が、使った年に全額、費用になっている。巨額の赤字の、いちばん大きな原因だった。
澪：「研究の費用を資産にできたら、あの会社の赤字も、うちの赤字も、小さく見える。でも、ルールがそれを許さない」
椎名：「許さないのは、研究が当たるかどうか、誰にも分からないからです。当たらなかった研究を資産に積み上げたら、何も生まない資産が貸借対照表に残ります」

::solve 2,600万円は、資産ではなく今期の費用。それが、営業赤字の大きな原因だった
新しい酵母の研究に使った2,600万円は、委託研究費も、研究専用の分析機器も、研究の給料も、試験醸造の費用も、すべて**研究開発費**として今期の費用になる。研究は成功するか分からないので、資産にはできない。
もし澪の思ったとおり資産にしていたら、今期の営業利益は2,400万円の黒字に見えた。だが、それはルールに反する決算書で、審査では通らない。もし研究が実らなければ、何も生まない「資産」だけが残る。
**将来のための支出でも、何年稼ぐか分からないものは、使った年に費用にする。**だからこそ、決算書を読む人は、赤字の中に研究開発費がいくら入っているかを、分けて読む必要がある。
::

## 蔵のECサイト ― ソフトウェアとソフトウェア仮勘定

研究開発費とは逆に、資産になる「目に見えないもの」もある。3月から作ってきた、蔵の直販のECサイトだ。注文と在庫と出荷をつなぐ仕組みで、外部の会社に600万円で制作を頼んだ。6月1日に完成し、使い始めた。
会社が自分で使うソフトウェアのうち、それを使うことで将来の収益が得られる、または費用が減ることが確実なものは、**ソフトウェア**（無形固定資産）として資産にし、利用できる期間（原則5年以内）で償却する。制作の途中で払った代金は、**ソフトウェア仮勘定**に集めておく。

::example ECサイトの制作を頼み、完成して使い始めた
(1) 3月10日、ECサイトの制作を外部に委託し、着手金2,000,000円を普通預金から支払った。
(2) 6月1日、ECサイトが完成して使い始め、残額4,000,000円を普通預金から支払った。
(3) 6月30日、ソフトウェアを利用可能期間5年で償却する（定額法、月割、直接法）。
::answer
::journal (1) 制作途中なので、ソフトウェア仮勘定
ソフトウェア仮勘定 2,000,000 | 普通預金 2,000,000
::
::journal (2) 完成して使用開始
ソフトウェア 6,000,000 | ソフトウェア仮勘定 2,000,000
 | 普通預金 4,000,000
::
::journal (3) 6,000,000円÷5年×1か月÷12か月。資産から直接減らす
ソフトウェア償却 100,000 | ソフトウェア 100,000
::
ソフトウェア仮勘定は、建設仮勘定（第15章）と同じく、完成するまでの支出を集める仮の勘定で、償却はしない。
::trap
無形固定資産の償却は、ふつう**直接法**（資産の勘定を直接減らす）で記帳し、残存価額はゼロ。減価償却累計額の勘定は使わない。また、使い始めた月から月割で償却する。
::
::
::

## 「汐路」の名前を守る ― 無形固定資産の償却

ECサイトで全国に売るなら、銘柄の名前を守らなければならない。澪は、純米吟醸「汐路」の商標を登録した。登録の費用は30万円。
形はないが、長い期間にわたって会社の役に立つ権利などを**無形固定資産**という。特許権・商標権・ソフトウェア・のれんなどがある。

::table 主な無形固定資産
| 勘定科目 | 内容 | 償却 |
| ソフトウェア | 自社で使うソフトウェア（将来の収益の獲得や費用の削減が確実なもの） | 利用可能期間（原則5年以内）で定額法 |
| ソフトウェア仮勘定 | 制作途中のソフトウェア | 償却しない。完成・使用開始でソフトウェアへ |
| 特許権 | 特許を受けた発明を独占して使う権利 | 8年など、問題の指示で定額法 |
| 商標権 | 商品の名前やマークを独占して使う権利 | 10年など、問題の指示で定額法 |
| のれん | 他の会社や事業を買ったときに、受け入れた純資産を上回って払った額 | 20年以内で定額法（第25章） |
::

::example 商標権を登録し、償却した
(1) 6月1日、純米吟醸「汐路」の商標を登録し、登録の費用300,000円を普通預金から支払った。
(2) 6月30日、商標権を10年で償却する（定額法、月割）。
::answer
::journal (1)
商標権 300,000 | 普通預金 300,000
::
::journal (2) 300,000円÷10年×1か月÷12か月
商標権償却 2,500 | 商標権 2,500
::
::trap
無形固定資産の償却の勘定は「〇〇償却」（ソフトウェア償却・商標権償却・のれん償却など）。減価償却費としないこと（問題で指示がある場合は従う）。
::
::
::

## 3年分の保守料 ― 長期前払費用

新しい瓶詰めラインの保守を、メーカーと3年契約で結んだ。保守料は3年分108万円を、6月1日に一括で前払いする。
1年以内に費用になる前払いは**前払費用**（流動資産）、決算日の翌日から1年を超えて費用になる部分は**長期前払費用**（投資その他の資産）として表示する。これを**1年基準**という。

::example 3年分の保守料を前払いし、決算で分けた
(1) 6月1日、瓶詰めラインの3年分の保守料1,080,000円（月30,000円×36か月）を普通預金から支払い、長期前払費用とした。
(2) 6月30日の決算で、6月分を費用とし、翌期（7月〜翌6月）に費用になる12か月分を前払費用に振り替えた。
::answer
::journal (1)
長期前払費用 1,080,000 | 普通預金 1,080,000
::
::journal (2) 1か月分30,000円は当期の費用、12か月分360,000円は1年以内に費用になる前払費用
支払保守料 30,000 | 長期前払費用 390,000
前払費用 360,000 |
::
決算日の翌日から1年を超えて費用になる部分（23か月分の690,000円）は、長期前払費用として残る。
::trap
全額を「前払費用」としないこと。1年を超える部分は長期前払費用だ。逆に、1年以内に費用になる部分を長期前払費用のまま残さないこと。
::
::
::

### 試験で狙われるパターン ― 研究専用か汎用か・償却の月割・1年基準

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 研究専用の機械か、ほかにも使える機械か**　研究専用なら取得時に研究開発費、ほかにも使えるなら固定資産として計上し、研究に使った期間の減価償却費が研究開発費になる。

**② 無形固定資産の月割**　期中に取得したら、使い始めた月から決算日までの月数で償却する。前期以前に取得したものは、取得日から数えて残りの期間で計算する。

**③ 1年基準**　前払費用と長期前払費用、短期と長期の借入金・貸付金は、決算日の翌日から1年以内かどうかで分ける。

::steps 解法の型 ― 研究開発費と無形固定資産
1. 研究開発のための支出か | 研究開発なら、研究専用の機械も含めて研究開発費（発生時の費用）
2. 自社利用のソフトウェアか | 制作中はソフトウェア仮勘定、完成・使用開始でソフトウェア
3. 償却 | 無形固定資産は残存価額ゼロ・定額法・直接法。使い始めた月から月割
4. 前払いの期間 | 決算日の翌日から1年以内は前払費用、1年超は長期前払費用
::

## 桐生の電話 ― AI企業の赤字の、いちばん大きな原因

::scene 6月15日、夜 ― ビデオ通話
椎名が置いていった表のことを話すと、桐生は画面の向こうでうなずいた。
桐生：「あの会社の赤字のいちばん大きな原因は、研究開発費なんだよ。次のAIを作るための計算資源が、使った年に全部、費用になる」
桐生：「工場なら資産になって、何十年かに分けて費用になるのにね」
::

Anthropicの上場の届出書の注記には、費用を機能別に分けた内訳が載っている。

::table Anthropic の費用の機能別の内訳（単位：百万ドル）
| 項目 | 2024年 | 2025年 | 2026年1〜6月 |
| 売上高 | 386 | 4,585 | 16,286 |
| 売上原価 | 752 | 2,773 | 2,380 |
| 売上総利益 | △366 | 1,812 | 13,906 |
| 研究開発費 | 2,275 | 6,338 | 9,741 |
| 販売費 | 163 | 911 | 3,808 |
| 一般管理費 | 176 | 1,123 | 1,050 |
| 著作権訴訟の和解金 | ― | 1,500 | ― |
| 営業損益 | △2,980 | △8,060 | △693 |
::

売上原価は、ほぼすべてが顧客向けにAIを動かす計算資源で、研究開発費は、主にモデルの開発・研究のための計算資源と人件費だ。澪は、この章の勘定で、2025年の研究開発費を仕訳にした（内訳を単純化、単位：百万ドル）。

::journal 2025年：モデルの開発・研究のための支出は、使った年の研究開発費
研究開発費 6,338 | 現金預金 6,338
::

この6,338百万ドルが、2025年の営業損失の最大の原因だった。売上総利益1,812百万ドルに対して、研究開発費はその3.5倍。顧客に提供する部分（売上－売上原価）では、すでに利益が出ていた。
研究開発費と一度きりの和解金を除いて計算すると、2025年の営業損益は△8,060＋6,338＋1,500＝**△222百万ドル**。2026年1〜6月では、売上総利益13,906百万ドルが研究開発費9,741百万ドルを上回り、営業損失は△693百万ドルまで縮んでいる。
澪は、そこで手を止めた。研究開発費を「除いてよい費用」と読んではいけない。同社自身が届出書で、モデルの開発は売上を生むために欠かせないと説明している。開発をやめれば、顧客はより優れたモデルを求めて離れていく。研究開発費は、将来への投資であると同時に、事業を続けるための毎年の費用でもある。
桐生：「だから、研究開発費を除いた数字だけ見て『実は黒字』と言うのは危ない。でも、赤字の中身を分けて読まないのも、同じくらい危ない」

::note
出典：[Anthropic, PBC「Form S-1」（米国証券取引委員会、2026年10月26日提出、Note 8 Supplemental Operating Expense Information）](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm)。売上総利益は、売上高と売上原価から計算した
::

::danger 研究開発費を「資産」に付け替えると、赤字は消える
研究開発の支出を、ソフトウェアや機械などの資産に紛れ込ませれば、その期の費用は減り、赤字は小さく見える。だが、その資産は何も生まないかもしれない。研究開発費の総額と、ソフトウェア・機械の増加を、毎期あわせて確かめる。
::

::cfo 審査で、営業赤字をどう説明するか ― 研究開発費を除いてよいか
6月の決算の見込みが固まった。澪は、高梨に営業赤字をどう説明するかを考えた。
**前提**
- 今期の営業損益は、約200万円の赤字の見込み
- 販管費には、研究開発費2,600万円と、スパークリングの立ち上げ費用（広告など）1,200万円が入っている。どちらも今期に集中した支出だ
- 研究開発費のうち800万円は研究専用の分析機器で、来期以降も研究に使える
- 来期の研究開発は、試験場との共同研究を続けるかどうかを、まだ決めていない
- AI企業も、研究開発費と和解金を除くと、2025年の営業損益はほぼ均衡していた
- 県の醸造試験場の早瀬は、研究の成果を学会で発表する予定だ
::choice A. 研究開発費と立ち上げ費用を除いた営業利益3,600万円を、「本当の利益」として示す
**△ 中身を分けるのはよいが、「本当の利益」と言い切ると、高梨は信じなくなる。**来期も研究開発を続けるなら、それは毎年の費用だ。除いた数字だけを強調すれば、都合のよい数字を選んだと受け取られる。
::
::choice B. 研究開発費を資産に直した決算書を別に作り、黒字の姿を見せる
**× ルールに反する決算書を、審査の資料にすることになる。**研究開発費は発生した期の費用で、資産にはできない。別の決算書を作っても、正式な決算書と食い違い、信頼を失う。
::
::choice C. 段階ごとの損益に、研究開発費と立ち上げ費用を分けて示し、来期の研究開発の上限と回収の見通しを添える
**◎ 中身を分けたうえで、来期にも続く費用かどうかに答えている。**今期の赤字の中身は、研究開発費2,600万円と立ち上げ費用1,200万円で、どちらも今期に集中した支出だ。来期の研究開発の上限と、スパークリングで回収する計画を添えれば、高梨は来期の営業利益を自分で見積もれる。
::
::choice D. 赤字の説明は言い訳に聞こえるので、決算書の数字だけを出し、説明はしない
**× 説明しなければ、高梨は営業赤字という見出しで判断するしかない。**赤字の中身を分けて示すのは、言い訳ではなく、決算書を正しく読んでもらうための材料だ。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「赤字を小さく見せるには」ではなく、「高梨が来期の営業利益を見積もるのに、どの情報が要るか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 今期の営業損益の中身（見込み、単位：万円）
| 項目 | 金額 |
| 営業損益 | △200 |
| うち研究開発費 | 2,600 |
| うちスパークリングの立ち上げ費用 | 1,200 |
| 2つを除いた営業損益 | 3,600 |
::
来期の営業利益は、研究開発費をいくらに抑えるか、立ち上げ費用がなくなるか、スパークリングがいくら稼ぐかで決まる。その3つを示せば、3,600万円という数字に意味が出る。
#### 手順3　ほかの答えに引かれる理由
Aは分かりやすい黒字の数字に、Bは「研究は投資だ」という直感に、Dは説明しない潔さに引かれる。AI企業の例は、研究開発費を除くと均衡する会社もある、という参考にはなるが、汐見酒造の来期の研究開発をどうするかには答えていない。早瀬の学会発表は、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **赤字の中身を分けて示すことと、都合のよい数字を選ぶことは違う**：除いた費用が来期にも続くかを、必ず添える
- **読む人が自分で見積もれる材料を渡す**：段階ごとの損益と、来期の計画
#### 前提が変われば
試験場との共同研究を今期で終えると決めているなら、研究開発費は一度きりの支出に近くなり、除いた営業利益3,600万円は来期の姿にかなり近づく。そのときは、Aの見せ方にも根拠が出てくる。
::
::

::exam 研究開発費と無形固定資産の急所
- 研究開発費は**発生した期の費用**。研究専用の機械も取得時に研究開発費
- 自社利用のソフトウェア：制作中は**ソフトウェア仮勘定**、完成・使用開始で**ソフトウェア**。償却は原則5年以内
- 無形固定資産の償却は、残存価額ゼロ・定額法・**直接法**。勘定は「ソフトウェア償却」「商標権償却」など
- 前払いのうち、決算日の翌日から1年超の部分は**長期前払費用**
- のれんは20年以内で償却（第25章）
::

::next 研究の成果を、どう資産にするか
1級では、市場で売るためのソフトウェアの制作費（研究開発の終了後の制作費は資産になる）や、受注で作るソフトウェアの収益の認識を学ぶ。国際的な会計基準では、開発の段階の支出を一定の条件で資産にする考え方もあり、日本の基準との違いが議論されている。
::

::summary
- 研究開発費は、成果が将来の収益につながるか分からないため、発生した期の費用とする
- 研究専用の機械は取得時に研究開発費、ほかにも使える機械は固定資産として減価償却する
- 自社利用のソフトウェアは、制作中はソフトウェア仮勘定、使い始めたらソフトウェアとして償却する
- 特許権・商標権などの無形固定資産は、残存価額ゼロ・直接法で償却する
- 1年を超えて費用になる前払いは長期前払費用、1年以内は前払費用とする
::

## 確認問題

::quiz
::problem 次の取引を仕訳しなさい。
(1) 新製品の研究のため、外部の研究機関への委託費1,900,000円を普通預金から支払った。
(2) 研究専用の測定装置2,000,000円を購入し、代金は月末に支払うことにした。
::answer
::journal (1)
研究開発費 1,900,000 | 普通預金 1,900,000
::
::journal (2) 研究専用なので研究開発費
研究開発費 2,000,000 | 未払金 2,000,000
::
研究専用の装置は、取得したときに研究開発費になる。固定資産の購入代金の未払いなので、相手は未払金。
::
::
::problem 次の取引を仕訳しなさい（決算日は3月31日）。
(1) 7月1日、自社利用のソフトウェアの開発を外部に委託し、着手金600,000円を普通預金から支払った。
(2) 10月1日、ソフトウェアが完成して使い始め、残額1,800,000円を普通預金から支払った。
(3) 3月31日、ソフトウェアを利用可能期間5年で償却する（定額法、月割）。
::answer
::journal (1)
ソフトウェア仮勘定 600,000 | 普通預金 600,000
::
::journal (2)
ソフトウェア 2,400,000 | ソフトウェア仮勘定 600,000
 | 普通預金 1,800,000
::
::journal (3) 2,400,000円÷5年×6か月÷12か月
ソフトウェア償却 240,000 | ソフトウェア 240,000
::
償却は使い始めた10月から3月までの6か月分。着手金を払った7月からではない。
::
::
::problem 前期の期首に取得した特許権（取得原価800,000円、8年で償却）について、当期の決算で償却する。当期の償却額と、償却後の帳簿価額を答えなさい。
当期の償却額 [[100,000]] 円、償却後の帳簿価額 [[600,000]] 円
::answer
毎期の償却額は800,000円÷8年＝**100,000円**。前期に100,000円償却ずみなので、当期の償却後の帳簿価額は800,000－100,000×2＝**600,000円**。直接法なので、特許権の勘定にこの額が残る。
::
