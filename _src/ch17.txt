## 研究開発費 ― 将来のための支出を、今期の費用にする

::theory 研究開発費は、発生したときに全額を費用にする
**研究**は、新しい知識を発見するための調査・探究、**開発**は、新しい製品や製法を作るために、研究の成果などを具体化することだ。そのための支出を**研究開発費**という。
研究開発費は、すべて**発生したときの費用**として処理し、資産にはしない。研究の成果が将来の収益につながるかどうかは、支出した時点では極めて不確かだからだ。資産にするかどうかを会社ごとの判断に任せれば、同じ研究でも、ある会社は資産にして利益を大きく見せ、ある会社は費用にする。比べられなくなる。
研究開発費に含まれるのは、研究に携わる人の人件費、原材料費、外部への委託費、そして**特定の研究開発の目的だけに使う機械などの取得原価**だ。ほかの目的にも使える設備を研究に使う場合は、その設備は固定資産にして、研究に使った分の減価償却費を研究開発費にする。
::

::example 今期の研究の支出を仕訳しなさい
(1) 醸造試験場との共同研究の委託研究費9,000,000円を普通預金から支払った。
(2) この研究の目的だけに使う分析機器8,000,000円を購入し、代金は普通預金から支払った。ほかの目的には使わない。
(3) 研究担当の社員の給料6,000,000円（年間の合計）を普通預金から支払った（源泉所得税などは考えない）。
(4) 試験醸造の原材料と瓶3,000,000円を普通預金から支払った。
::answer
::journal (1)
研究開発費 9,000,000 | 普通預金 9,000,000
::
::journal (2) 研究専用の機械は、取得したときに研究開発費
研究開発費 8,000,000 | 普通預金 8,000,000
::
::journal (3)
研究開発費 6,000,000 | 普通預金 6,000,000
::
::journal (4)
研究開発費 3,000,000 | 普通預金 3,000,000
::
研究開発費は、損益計算書では、原則として**販売費及び一般管理費**（製造のための研究なら当期製造費用）に表示する。今期の研究開発費は合計26,000,000円だ。

## 答え合わせ ― 機械でも、研究のためなら費用

::solve 将来の収益が不確かだから、研究のための支出は、機械も含めて発生した年の費用
新しい酵母の研究が成功するかどうか、成功してもスパークリングが売れ続けるかどうかは、今は誰にも分からない。将来の収益につながる確かさがないものは、資産にしない。研究開発費は、発生した年に全額が費用になる。
分析機器の800万円も同じだ。この機械は、この研究のためだけに買った。研究が終われば、使い道がない。だから、機械の形をしていても、研究の支出の一部として、買った年の研究開発費になる。もし蔵の品質管理にも使える汎用の機械なら、固定資産にして、研究に使った分の減価償却費だけを研究開発費にする。
::

岩倉は、しばらく黙っていた。「では、研究をすればするほど、決算は赤字になるわけですな」
「その年の決算は、そうです」と澪は答えた。「研究が実を結ぶのは、来年か、再来年か、もっと先です。今期の損益計算書には、費用だけが載ります」
「瓶詰めラインは10年に分けて費用にするのに、酵母の研究は一度に、ですか」
「はい。だから、研究開発費が多い会社の赤字は、中身を分けて読まないといけないんです」
澪の頭には、半年前に読んだ、あの届出書の数字が浮かんでいた。

## 無形固定資産 ― 形はないが、資産になるもの

研究開発費と違い、将来の収益や費用の削減につながることが確かな、形のない資産もある。**無形固定資産**だ。

::table 主な無形固定資産
| 勘定科目 | 内容 | 償却 |
| ソフトウェア | 自社で使うソフトウェア（将来の収益の獲得や費用の削減が確実なもの） | 利用可能期間（原則5年以内）で定額法 |
| ソフトウェア仮勘定 | 制作途中のソフトウェア | 償却しない。完成・使用開始でソフトウェアへ |
| 特許権 | 特許を受けた発明を独占して使う権利 | 法定の期間内（8年など、問題の指示）で定額法 |
| 商標権 | 商品の名前やマークを独占して使う権利 | 10年など、問題の指示で定額法 |
| のれん | 他の会社や事業を買ったときに、受け入れた純資産を上回って払った額 | 20年以内で定額法（第25章） |
::

無形固定資産は、**残存価額をゼロ**とし、定額法で償却する。償却額は、累計額の勘定を使わず、**資産の勘定から直接減らす**（直接法）。

### ECサイトの構築 ― ソフトウェアとソフトウェア仮勘定

スパークリングの発売に合わせて、蔵は自社の通販サイト（ECサイト）を作った。外部の会社に開発を頼み、3月に着手、6月1日に公開した。

::example ECサイトの構築を仕訳しなさい
(1) 3月10日、ECサイトの開発を外部に委託し、着手金2,000,000円を普通預金から支払った。
(2) 6月1日、ECサイトが完成して使用を開始し、残金4,000,000円を普通預金から支払った。このECサイトは自社で利用し、将来の収益の獲得が確実と認められる。
(3) 6月30日、決算。ソフトウェアを利用可能期間5年で償却する（月割）。
::answer
::journal (1) 制作途中なので、ソフトウェア仮勘定
ソフトウェア仮勘定 2,000,000 | 普通預金 2,000,000
::
::journal (2) 完成して使用開始
ソフトウェア 6,000,000 | ソフトウェア仮勘定 2,000,000
 | 普通預金 4,000,000
::
::journal (3) 6,000,000円÷5年×1か月÷12か月。資産から直接減らす
ソフトウェア償却 100,000 | ソフトウェア 100,000
::
{{new:2027年度〜}} ソフトウェア仮勘定は、2027年度からの出題区分表で2級の論点として明記された。建設仮勘定（第15章）と同じく、完成するまでの支出を集める仮の勘定で、償却はしない。
::
::

研究開発費とソフトウェアの違いは、**将来の収益につながることが確かかどうか**だ。ECサイトは、完成すれば注文を受け付けて売上を生む。酵母の研究は、成功するかどうか分からない。同じ「将来のための支出」でも、確かさが違えば、帳簿の扱いが正反対になる。

::example 商標権の取得と償却を仕訳しなさい
(1) 6月1日、「汐見スパークリング」のロゴを商標として登録し、出願と登録の費用300,000円を普通預金から支払った。
(2) 6月30日、決算。商標権を10年で償却する（月割）。
::answer
::journal (1)
商標権 300,000 | 普通預金 300,000
::
::journal (2) 300,000円÷10年×1か月÷12か月
商標権償却 2,500 | 商標権 2,500
::
::

::sort 次の支出を、資産にするもの（無形固定資産など）と、発生した期の費用にするもの（研究開発費など）に分けなさい。
@cats 資産にする | 発生した期の費用にする
新しい酵母の研究のための委託研究費 => 発生した期の費用にする
新しい酵母の研究の目的だけに使う分析機器 => 発生した期の費用にする
完成して使用を始めた自社のECサイト（収益の獲得が確実） => 資産にする
開発途中の在庫管理システムへの支払い => 資産にする
商品名の商標登録の費用 => 資産にする
研究担当の社員の給料 => 発生した期の費用にする
::

::exam 無形固定資産と研究開発費の急所
- **研究開発費**は発生時に全額費用。研究専用の機械も、取得原価をそのまま研究開発費にする（固定資産にしない）
- **ソフトウェア仮勘定**は制作途中の支出。完成・使用開始でソフトウェアへ振り替える。償却は使用開始から
- 無形固定資産の償却は**残存価額ゼロ・定額法・直接法**（「○○償却／○○」）。月割に注意
- 期の途中で取得した無形固定資産の償却額は、問題文の償却期間（ソフトウェアは5年が多い）で月割計算
- **のれん**の償却は20年以内（第25章）。**長期前払費用**（1年を超える前払費用）は投資その他の資産
- 固定資産台帳：取得日・取得原価・償却方法・耐用年数・期首の帳簿価額・当期の償却額を記録する台帳。台帳から決算の償却額を計算する問題も出る
::

::real AI企業の赤字の最大の原因は、研究開発費だった
序章の届出書で見た Anthropic の2025年の営業損失80億6,000万ドル。その中身は、注記にあった費用の**機能別**の内訳を使うと、はっきり見える。売上原価は「ほぼすべてが顧客向けの処理に使った計算資源」、研究開発費は「主にモデルの開発・研究・社内での利用に使った計算資源と、人件費など」だと説明されている。

::table Anthropic の費用の機能別の内訳（単位：百万ドル）
| 項目 | 2024年 | 2025年 | 2026年1〜6月 |
| 売上高 | 386 | 4,585 | 16,286 |
| 売上原価 | 752 | 2,773 | 2,380 |
| 売上総利益 | △366 | 1,812 | 13,906 |
| （売上総利益率） | △95% | 39.5% | 85.4% |
| 研究開発費 | 2,275 | 6,338 | 9,741 |
| 販売費 | 163 | 911 | 3,808 |
| 一般管理費 | 176 | 1,123 | 1,050 |
| 著作権訴訟の和解金（Bartz） | ― | 1,500 | ― |
| 営業損益 | △2,980 | △8,060 | △693 |
::

**この章の道具で読む ― 研究開発費を、発生した年の費用にすると**
AIのモデルを学習させるための計算資源は、汐見酒造の酵母の研究と同じく、将来の製品（次のモデル）を作るための支出だ。米国の会計基準でも、研究開発費は発生した期の費用になる。
::journal ① 2025年：モデルの開発・研究のための支出（単位：百万ドル、内訳を単純化）
研究開発費 6,338 | 現金預金など 6,338
::
この6,338百万ドルが、2025年の営業損失の最大の原因だった。売上総利益1,812百万ドルに対して、研究開発費はその3.5倍。顧客に提供する部分（売上－売上原価）では、すでに利益が出ていた。2025年の営業損失80億ドルは、ざっくり言えば「顧客向けの事業で得た18億ドルの粗利を、63億ドルの研究開発と、一度きりの和解金15億ドルなどが上回った」結果だ。
研究開発費と和解金を除いて計算すると、2025年の営業損益は△8,060＋6,338＋1,500＝**△222百万ドル**。ほぼ収支が釣り合う水準だった。2026年1〜6月では、売上総利益13,906百万ドルが研究開発費9,741百万ドルを上回り、営業損失は△693百万ドルまで縮んでいる。
**ただし、研究開発費を「除いてよい費用」と読んではいけない。**同社自身が届出書で、AIのモデルの開発は売上を生むために欠かせず、研究と顧客向けの処理は互いに支え合っている、と説明している。モデルの開発をやめれば、顧客はより優れたモデルを求めて離れていく。研究開発費は、将来への投資であると同時に、事業を続けるための経常的な費用でもある。
決算書が教えてくれるのは、「赤字の中身」までだ。顧客向けの事業の粗利率が上がり続けているか、研究開発費が売上に対してどれだけの重さか（2024年は売上の約5.9倍、2025年は約1.4倍、2026年1〜6月は約0.6倍）。その推移を読むことで、「一時的な赤字か、続く赤字か」を判断する材料が手に入る。
::note
出典：[Anthropic, PBC「Form S-1」（米国証券取引委員会、2026年10月26日提出、Note 8 Supplemental Operating Expense Information）](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm)。売上総利益と売上総利益率は、売上高と売上原価から計算した。
::
::

::cfo 東京の同期からの電話 ― AI企業の決算書を、どう読むか
6月の夜、東京の商社時代の同期から電話が来た。序章で「AIバブルもおしまいだ」と言った、あの同期だ。
「例のAIの会社、上場するらしい。届出書を見たら、去年は営業損失だけで80億ドル。やっぱり赤字の会社だよな？　お前、簿記を勉強してるんだろう。この損益計算書、どう読む？」
澪は、上の機能別の内訳の表を開いた。まず、売上総利益率と、研究開発費の売上高に対する割合を、2024年・2025年・2026年1〜6月で計算してから選んでほしい。
::choice A. 営業損失は売上の約1.8倍。事業として成り立っていない
**× 赤字を1つの数字で見ている。**2025年の営業損失8,060百万ドルは売上4,585百万ドルの約1.76倍だ。だが、中身を分けると、顧客向けの事業の売上総利益は1,812百万ドルの黒字で、粗利率は2024年の△95%から39.5%、2026年1〜6月には85.4%へ上がっている。赤字の主な原因は、研究開発費と一度きりの和解金だ。「成り立っていない」と言い切るには、事業そのものの粗利が赤字で、しかも悪化している必要がある。
::
::choice B. 粗利と研究開発費に分けて、それぞれの推移を見る。顧客向けの事業は粗利が出ていて、研究開発費の売上に対する重さは下がっている
**◎ 赤字の中身を分けて、推移で読んでいる。**粗利率は△95%→39.5%→85.4%、研究開発費の売上高比は約589%→約138%→約60%。顧客向けの事業は大きく改善し、研究開発費は、売上の伸びに対して相対的に軽くなっている。
ただし、そこから先は判断になる。研究開発費は事業を続けるために欠かせない費用でもあり、同社は将来の計算資源に巨額の支払いを約束している（第16章）。粗利が研究開発費を上回り続けるか、売上の伸びが続くかは、決算書の外の問題だ。簿記ができるのは、「どこを見ればよいか」を示すところまでだ。
::
::choice C. 研究開発費は将来への投資で資産のようなものだから、全額を足し戻した数字が本当の利益だ
**△ 方向は分かるが、行きすぎだ。**研究開発費を全額足し戻せば、2025年の営業損益は△1,722百万ドル、和解金も除けば△222百万ドル。だが、AIのモデルの開発は、一度やれば終わりではなく、毎年続けなければ競争に負ける。毎年かかる費用を「なかったこと」にした利益は、本当の利益とは言えない。会計の基準が研究開発費を資産にさせないのは、この「将来につながるかどうか」の見極めが難しいからだ。
::
::choice D. 当期純損失の420億ドルこそが会社の実力だ。営業損失より5倍以上大きい
**× 最後の段だけを見て、中身を見ていない。**当期純損失41,965百万ドルのうち、34,308百万ドルは、企業価値の上昇で転換社債などの評価額が上がったことによる損失で、現金は出ていかない（第18章・第22章）。営業の段階の損失と、評価の上だけの損失を足し合わせた数字を「実力」と呼ぶのは、序章で同期がした読み方そのものだ。
::
::answer 考え方の例を見る
研究開発費の多い会社の損益計算書は、**売上総利益（今の事業の稼ぐ力）**と、**研究開発費（将来のための支出）**を分けて読む。そして、1年分ではなく、粗利率と研究開発費の重さの**推移**を見る。会計のルールは、研究開発費を発生した年の費用にする。だから、研究に力を入れている会社ほど、今の損益計算書は厳しく見える。その厳しさを、正しく分解して読むことが、決算書を読む力だ。
電話の向こうで、同期は「じゃあ、買いなのか」と聞いた。澪は笑って答えた。「それは、簿記では分からない。でも、少なくとも『売上の9倍の赤字だからおしまい』ではない。それと、うちの蔵の研究開発費2,600万円も、同じ読み方をしてもらうつもり」
::

::next 研究開発と無形資産の会計の先にある論点
1級では、市場で販売するソフトウェア（受注制作・市場販売目的）の会計処理、のれんの減損、企業結合で受け入れた研究開発の成果の扱いなどを学ぶ。また、国際会計基準（IFRS）では、一定の要件を満たす**開発**の支出を資産にする（開発費の資産計上）点で、日本や米国の基準と違う。同じ支出でも、基準によって赤字の大きさが変わる。決算書を比べるときは、どの基準で作られているかを確かめる必要がある。

::problem 前期の期首に取得した特許権（取得原価800,000円、8年で償却）について、当期の決算で償却する。当期の償却額と、償却後の帳簿価額を答えなさい。
当期の償却額 [[100,000]] 円、償却後の帳簿価額 [[600,000]] 円
::answer
800,000円÷8年＝**100,000円**。前期と当期の2年分を償却するので、帳簿価額は800,000円－100,000円×2年＝**600,000円**。無形固定資産は直接法なので、特許権の勘定の残高がそのまま帳簿価額になる。

::summary
- 研究開発費は、将来の収益が不確かなので、発生したときに全額を費用にする。研究専用の機械の取得原価も研究開発費
- 自社利用のソフトウェアは、将来の収益の獲得や費用の削減が確実なら無形固定資産。制作途中はソフトウェア仮勘定、完成・使用開始でソフトウェアへ振り替え、5年以内で償却する
- 無形固定資産は、残存価額ゼロの定額法で、資産から直接減らす（直接法）
- 研究開発費の多い会社の赤字は、売上総利益（今の事業の稼ぐ力）と研究開発費（将来のための支出）に分け、その推移で読む。研究開発費は「除いてよい費用」ではない
::
