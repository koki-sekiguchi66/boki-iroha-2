### (2) 総合原価計算（16点：各4点）

当工場では、単一の製品を製造し、単純総合原価計算（平均法）を採用している。直接材料は工程の始点で投入し、加工費は工程の進み具合に応じて平均的に発生する。正常減損は工程の終点で発生し、度外視法により完成品だけに負担させる。

| 月初仕掛品 | 200個（進捗度50%） | 80,000円 | 45,000円 |
| 当月投入 | 1,000個 | 400,000円 | 843,000円 |
| 完成品 | 1,000個 | | |
| 正常減損（終点） | 50個 | | |
| 月末仕掛品 | 150個（進捗度40%） | | |

::quiz
::problem 月末仕掛品原価と完成品総合原価を求めなさい。
月末仕掛品の直接材料費 [[60,000@7]] 円、月末仕掛品の加工費 [[48,000@7]] 円、完成品総合原価 [[1,260,000@7]] 円、完成品単位原価 [[1,260@7]] 円

## 第5問（12点：各3点）

当工場では、標準原価計算を採用している。製品1個あたりの標準作業時間は2時間。製造間接費は直接作業時間を基準に配賦し、公式法変動予算による。月間の基準操業度は1,500時間、変動費率は1時間800円、固定費予算は1,800,000円である。当月の生産量は700個（月初・月末の仕掛品はない）、実際の直接作業時間は1,450時間、製造間接費の実際発生額は2,980,000円だった。

::quiz
::problem 製造間接費の差異を答えなさい。不利差異はマイナスで答える。能率差異は標準配賦率で計算する。
製造間接費の総差異 [[-180,000@9]] 円、予算差異 [[-20,000@4・9]] 円、能率差異 [[-100,000@9]] 円、操業度差異 [[-60,000@4・9]] 円
::answer
- 固定費率＝1,800,000円÷1,500時間＝1,200円、標準配賦率＝800円＋1,200円＝2,000円
- 標準作業時間＝700個×2時間＝1,400時間、標準配賦額＝1,400時間×2,000円＝2,800,000円
- 総差異：2,800,000円－2,980,000円＝**△180,000円**
- 予算差異：(1,450時間×800円＋1,800,000円)－2,980,000円＝**△20,000円**
- 能率差異：(1,400時間－1,450時間)×2,000円＝**△100,000円**
- 操業度差異：(1,450時間－1,500時間)×1,200円＝**△60,000円**
（第9章）

模擬試験モードは、大問ごとに、正解した設問の割合で配点を掛けて自動で採点する。採点後は、間違えた問題が扱っている章へのリンクが表示される。

::steps 採点したら、次の順で復習する
70点以上なら合格圏 | 間違えた問題の章の「試験の急所」を読み直し、同じ問題をもう一度解く
第4問・第5問が30点未満なら | 第1部の例題を、勘定の流れの図とボックス図を描きながら解き直す
第1問が12点以下なら | 付録Cの仕訳道場を、1問30秒になるまでくり返す
第2問・第3問が20点未満なら | 第22章（決算）と第26章（連結精算表）の例題を、白紙から解き直す

::summary 模擬試験のまとめ
- 解く順番は、第1問→第4問→第5問→第3問→第2問。型の決まった工業簿記で得点を固める
- 連結は「開始仕訳→のれんの償却→当期純利益の配分→配当の修正→内部取引→未実現利益→債権債務」の順に、すべての修正仕訳を書き出してから集計する
- 損益計算書は、決算整理事項を1つずつ仕訳し、未処理事項（リース料の支払いなど）を見落とさない
- 差異分析は、図を描いて、標準・予算許容額・実際の3つの金額を並べてから計算する
::
