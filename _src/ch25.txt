::mystery 600万円の差額
9月6日、月曜日。澪は、芹沢酒造の帳簿を持って、隣町の蔵を訪ねた。跡取りの芹沢千尋は、子どものころに夏祭りで一緒に金魚すくいをした仲だ。
「お父さんには、本当に感謝してる。あのとき助けてもらわなかったら、うちは去年で終わってた」
父が株を買った2026年6月30日の芹沢酒造の貸借対照表では、資産から負債を引いた純資産は**5,000万円**だった。その60%なら**3,000万円**。ところが、父が払ったのは**3,600万円**。600万円多い。
「お父さんが、相場より高く買ってくれたんだと思う」と千尋は言った。
だが、椎名の見方は違った。「600万円は、ただの上乗せではありません。帳簿の純資産には載っていない何かに、お父さんはお金を払ったんです」
**純資産3,000万円分の株を、なぜ父は3,600万円で買ったのか？ その600万円は、帳簿のどこに載るのか？**

## 2つの統合のかたち ― 合併と子会社化

会社が別の会社を自分の傘下に入れる方法は、大きく2つある。

::table 合併と子会社化
| 方法 | 何が起きるか | 帳簿 |
| 合併（吸収合併） | 相手の会社が消滅し、その資産と負債をまるごと引き継ぐ。1つの会社になる | 合併した会社の帳簿に、相手の資産・負債を直接受け入れる |
| 子会社化 | 相手の会社の株式の過半数を買い、支配する。相手の会社は別の会社として残る | 自分の帳簿には「子会社株式」を載せるだけ。グループ全体の姿は**連結財務諸表**で示す |
::

父が選んだのは、子会社化だった。芹沢酒造という会社と、その蔵の名前と、清酒の製造免許を残したかったからだ。

## のれん ― 帳簿の純資産に載っていない価値

::theory のれん
会社や事業を買うとき、支払った対価が、受け入れた純資産（資産－負債）の時価を上回ることがある。その差額が**のれん**だ。帳簿の資産には載っていない、その会社の「稼ぐ力」― 歴史ある銘柄、得意先との関係、職人の技、免許 ― に対して払った代金と考える。
のれんは**無形固定資産**として計上し、**20年以内**に定額法で償却する（のれん償却）。逆に、対価が純資産の時価を下回るときの差額は**負ののれん発生益**（特別利益）とする。
::

芹沢酒造の帳簿には、「芹沢」という130年の銘柄の価値も、清酒の製造免許の価値も載っていない。日本では、国内向けの清酒の製造免許は、原則として新しく交付されない。新しく蔵を始めたくても、免許を得るには、既存の蔵を引き継ぐしかない。父の600万円は、そうした帳簿の外の価値への代金だった。

## 合併の会計

先に、合併の場合の仕訳を確かめておこう。汐見酒造は芹沢酒造を合併しなかったが、合併すれば、のれんは汐見酒造の帳簿に直接載る。

::example 吸収合併を仕訳しなさい（別の会社の例）
A社はB社を吸収合併し、B社の株主に、A社の株式100株（時価1株60,000円、合計6,000,000円）を交付した。B社の資産の時価は15,000,000円、負債の時価は10,000,000円だった。A社は、交付した株式の価額のうち、3,000,000円を資本金、残りを資本準備金とした。
::answer
::journal 受け入れた純資産5,000,000円と、交付した株式6,000,000円の差がのれん
諸資産 15,000,000 | 諸負債 10,000,000
のれん 1,000,000 | 資本金 3,000,000
 | 資本準備金 3,000,000
::
合併では、相手の会社の資産と負債を**時価**で受け入れる。対価として株式を交付したときは、その価額を資本金・資本準備金（その他資本剰余金とすることもある）にする。
{{new:2027年度〜}} 会社の合併は、2027年度からの出題区分表で2級の論点として明記された。
::
::

## 連結財務諸表 ― グループを1つの会社として見る

::theory 連結財務諸表と子会社
ある会社（**親会社**）が、別の会社の意思決定機関を支配しているとき、その会社を**子会社**という。2級では、議決権の**過半数**（50%超）を持っていれば、子会社と判定する。
親会社は、自分の帳簿（個別財務諸表）では子会社株式を取得原価で載せるだけだ（第18章）。だが、子会社の資産・負債・損益は、実質的には親会社が動かしている。そこで、親会社と子会社を1つの会社とみなして、グループ全体の財務諸表（**連結財務諸表**）を作る。
連結財務諸表は、帳簿を新しくつけるのではなく、親会社と子会社の個別財務諸表を**合算**し、グループの中の重複や取引を消す**連結修正仕訳**をして作る。
::

## 支配獲得日の資本連結

連結修正仕訳の最初は、親会社の「子会社株式」と、子会社の「純資産（資本）」の相殺だ。親会社が子会社株式に払ったお金は、子会社の純資産の形で、グループの中にすでに存在している。合算したままでは、同じものを2度数えることになる。

::example 支配獲得日（2026年6月30日）の資本連結を仕訳しなさい（単位：万円）
汐見酒造は、芹沢酒造の株式の60%を3,600万円で取得し、支配を獲得した。この日の芹沢酒造の純資産は、資本金3,000万円、利益剰余金2,000万円。資産・負債の帳簿価額は時価と一致している。
::answer
- 親会社の持分：5,000万円×60%＝3,000万円 → のれん＝3,600万円－3,000万円＝600万円
- 非支配株主（芹沢家）の持分：5,000万円×40%＝2,000万円
::journal 投資と資本の相殺消去（単位：万円）
資本金 3,000 | 子会社株式 3,600
利益剰余金 2,000 | 非支配株主持分 2,000
のれん 600 |
::
子会社の純資産5,000万円はすべて消し、そのうち親会社の分（60%）は子会社株式と相殺し、残りの40%は**非支配株主持分**（連結貸借対照表の純資産）に振り替える。子会社株式と親会社の持分の差が**のれん**だ。
::
::

::boxes 支配獲得日の芹沢酒造の純資産と、汐見酒造の投資（単位：万円）
H 芹沢酒造の純資産と、のれん | 誰のものか
L e 30 親会社の持分<br>5,000×60%＝3,000
L e 20 非支配株主の持分<br>5,000×40%＝2,000
L a 6 のれん<br>600
R a 36 子会社株式<br>3,600（汐見酒造の投資）

## 答え合わせ ― 600万円は「のれん」

::solve 600万円は、帳簿の純資産に載っていない「芹沢酒造の稼ぐ力」への代金
芹沢酒造の純資産5,000万円のうち、父が買った60%は3,000万円分だった。父は、それより600万円多い3,600万円を払った。この600万円が**のれん**だ。銘柄、免許、杜氏の技、得意先 ― 帳簿の資産には載らないが、将来の稼ぎを生むと見込んだものへの代金だ。
汐見酒造の個別の貸借対照表では、この600万円は「子会社株式3,600万円」の中に埋もれていて、見えない。連結貸借対照表を作って初めて、**のれん600万円**として姿を現し、20年かけて償却されていく。
::

千尋は、のれんの説明を聞いて、少し照れたように笑った。「うちの蔵に、600万円の値打ちがあると思ってくれたんだ」
「父は、そう見込みました」と澪は言った。「でも、その見込みが当たったかどうかは、この1年の数字が教えてくれます」
芹沢酒造の6月期の当期純損益は、**△500万円**。3期続けての赤字だった。

## 支配獲得後の連結 ― 1年後の連結修正

支配を獲得した翌年度からは、毎年の連結財務諸表を作る。連結修正仕訳は帳簿に記録されないので、毎年、過去の修正を最初からやり直す。

::theory 支配獲得後の主な連結修正仕訳
1. **開始仕訳**：支配獲得日の資本連結（と、前期までの連結修正）をもう一度行う。前期までの修正で損益に関わるものは、**利益剰余金当期首残高**として修正する
2. **のれんの償却**：のれんを償却する（のれん償却／のれん）
3. **子会社の当期純損益の配分**：子会社の当期純利益のうち非支配株主の持分を、**非支配株主に帰属する当期純利益**として非支配株主持分に振り替える（損失なら逆）
4. **子会社の配当の修正**：子会社が払った配当のうち、親会社が受け取った分は受取配当金と相殺し、非支配株主が受け取った分は非支配株主持分を減らす
::

::example 2027年6月期の連結修正仕訳をしなさい（単位：万円）
芹沢酒造の当期純損失は500万円、配当はなし。のれんは20年で定額法により償却する。
::answer
::journal (1) 開始仕訳：支配獲得日の資本連結を再び行う
資本金当期首残高 3,000 | 子会社株式 3,600
利益剰余金当期首残高 2,000 | 非支配株主持分当期首残高 2,000
のれん 600 |
::
::journal (2) のれんの償却：600万円÷20年
のれん償却 30 | のれん 30
::
::journal (3) 子会社の当期純損失のうち非支配株主の分（500万円×40%）を、非支配株主持分から差し引く
非支配株主持分当期変動額 200 | 非支配株主に帰属する当期純利益 200
::
(3)は、子会社が損失を出したので、非支配株主の持分も40%分だけ減る。損益計算書では「非支配株主に帰属する当期純利益」が△200万円（損失）となり、連結の当期純損失のうち親会社株主に帰属する部分が、その分だけ小さくなる。
連結の株主資本等変動計算書で純資産の項目ごとの期首残高と変動を示すため、連結修正仕訳では「資本金当期首残高」「非支配株主持分当期変動額」のような科目を使う。問題によっては、単に「資本金」「非支配株主持分」とすることもある。
::
::

::exam 資本連結の急所
- 子会社の判定は**議決権の過半数**。支配獲得日の子会社の純資産（資本金・資本剰余金・利益剰余金）を全額消去する
- **のれん＝子会社株式－子会社の純資産×親会社の持分比率**。**非支配株主持分＝子会社の純資産×非支配株主の持分比率**
- のれんは**20年以内の定額法**で償却（連結損益計算書では販売費及び一般管理費）
- 子会社の当期純利益×非支配株主の持分比率を「非支配株主に帰属する当期純利益／非支配株主持分」で振り替える（損失なら逆）
- 子会社の配当：親会社分は「受取配当金／利益剰余金（剰余金の配当）」、非支配株主分は「非支配株主持分／利益剰余金（剰余金の配当）」
- 2年目以降は**開始仕訳**で前期までの修正を引き継ぐ。損益の科目は「利益剰余金当期首残高」に置き換える
- 2級では、子会社の資産・負債の時価評価（評価差額）は扱わないことが多い（問題文に従う）
::

## 千尋の不安 ― のれんは、消えることもあるのか

::scene 9月6日、夕方 ― 芹沢酒造の帳場
のれんの説明を聞き終えた千尋は、少し不安そうに聞いた。
「600万円の『稼ぐ力』って、もしうちがこのまま赤字を続けたら、どうなるの」
澪は、椎名から聞いた話を思い出していた。「消えることがあるの。何千億円という単位で、一度に消えた例もある」
「何千億円？」
「日本郵政。オーストラリアの物流会社を買ったときの話」
::

2015年、日本郵政は、オーストラリアの大手物流会社トール・ホールディングスを買収した。買収のときに計上した、のれんと商標権は、約52.8億豪ドル（約5,048億円）にのぼった。
だが、資源価格の下落とオーストラリア経済の減速で、トールの業績は買収時の見込みを大きく下回った。日本郵政は、2017年3月期の決算で、トールののれんなどの全額にあたる**3,923億円**と、有形固定資産の80億円、合わせて**4,003億円**の減損損失を特別損失に計上した。同社は、2007年の民営化以来初めて、連結の当期純損失（289億円）に転落した。
澪は、帳場の黒板に、2本の仕訳を書いた（単位：億円）。

::journal ① 買収時の資本連結のうち、のれんの部分：子会社株式の取得原価のうち、子会社の純資産を超えた部分（のれん・商標権）
のれん 5,048 | 子会社株式 5,048
::
::journal ② 見込みが外れたとき：のれんを減損する（1級の範囲の処理）
減損損失 3,923 | のれん 3,923
::

「①の時点では、のれんは5,048億円の資産として、連結の貸借対照表に載る。でも、それは、トールが将来稼ぐという見込みの上に成り立つ数字だった」と澪は言った。「②の減損は、その見込みが崩れたことを、一度に損失として認めたもの」
千尋は、黒板の数字をしばらく見ていた。「600万円も、同じなんだね。うちが稼げなければ、ただの数字になる」
「のれんの大きさは、買った側の自信の大きさで、同時に、将来の損失の種の大きさでもある。父は、芹沢酒造に600万円分の自信を持った。それを本当の稼ぎに変えられるかは、これからの私たちしだい」
千尋は、黒板消しを手に取り、②の仕訳だけを消した。「じゃあ、こっちは書かせないようにしよう」

::note
出典：[ニュースイッチ（日刊工業新聞）による日本郵政のトールの減損の報道（2017年）](https://newswitch.jp/p/9085)
::

高梨との約束の期限まで、あと3週間。澪は、千尋と椎名と一緒に、4つの案を比べた。

まず、各案で、汐見酒造の現金・連結の損益・保証のリスクがどう変わるかを考えてから選んでほしい。
::choice A. 何もしない。子会社のままなら、芹沢酒造の赤字は汐見酒造の個別の決算書には出ない
**× 個別の決算書に出ないだけで、グループの損失は消えない。**連結財務諸表では、芹沢酒造の赤字はそのまま載る。そして、8,000万円の保証は、汐見酒造の純資産5,095万円を上回る。芹沢酒造の赤字が続けば、いずれ保証が現実の負担になる。高梨は注記まで読んでいる（第22章）。「見えないから問題ない」は、カネボウの連結外しと同じ発想だ（第26章）。
::
::choice B. 1年後に吸収合併する。それまでは連結で毎月の数字を管理し、合併で管理費と固定費を減らす
**◎ 保証を自分の負債として正面から扱い、効果も数字で示せる。**合併すれば、芹沢酒造の借入金8,000万円は汐見酒造の借入金になり、保証という「見えない負債」が、貸借対照表の「見える負債」になる。信金とは、2つの蔵の借入金を一本化して交渉できる。管理部門の統合（年600万円）と精米の受託による固定費の吸収（年400万円）で、年1,000万円の改善が見込める。
芹沢家には汐見酒造の株式を交付するので、合併のために現金は要らない。銘柄「芹沢」と製造免許は残り、のれん600万円の「稼ぐ力」を、本当に稼ぐ力に変える道が開ける。1年の準備期間で、連結の数字を毎月確かめられるのも大きい。
::
::choice C. 残り40%をすぐ現金で買い取り、完全子会社にする
**△ 意思決定は速くなるが、現金が足りない。**完全子会社にすれば、非支配株主との調整は不要になる。だが、約1,800万円の現金は、増資の1,000万円を使っても足りず、信金の条件（研究開発費の上限など）のもとで新たな借入れは難しい。しかも、保証の問題は何も解決しない。
::
::choice D. 芹沢酒造を清算して、保証を整理する
**× 最も大きな損失を、確定させてしまう。**清算すれば、芹沢酒造の資産を売っても借入金を返しきれない可能性が高く、汐見酒造が保証を履行して、数千万円の損失を負うことになりかねない。そして、のれん600万円で買った銘柄と免許も消える。父が守ろうとしたものを、帳簿の整理のために捨てることになる。
::
::answer 考え方の例を見る
子会社を持つ会社の本当の姿は、個別財務諸表ではなく、連結財務諸表に表れる。子会社の赤字も、子会社の借金の保証も、グループの外から見れば、親会社のものと同じだ。統合の方法を選ぶときは、連結で見たときの損益・現金・負債（保証を含む）がどう変わるかを比べる。
9月28日、澪は高梨に計画書を出した。表紙には、こう書いた。「芹沢酒造との1年後の合併に向けた計画。それまでの1年は、連結の試算表を毎月お届けします」。最初の連結の試算表を作るために、澪は、2つの蔵の間の取引を洗い出し始めた。そこには、思いもよらない「利益」が隠れていた。
::
::

::next 合併と連結の先にある論点
1級では、子会社の資産・負債の**時価評価**（評価差額）、のれんの**減損**、段階取得や持分の追加取得・一部売却、**持分法**（関連会社の会計）、在外子会社の換算、企業結合のさまざまな形（株式交換・株式移転・会社分割）などを学ぶ。日本郵政の例のように、のれんは上場企業の決算を大きく動かす。連結財務諸表を読む力は、2級の資本連結の手順から始まる。
::

::summary
- 合併では、相手の資産・負債を時価で受け入れ、対価（交付した株式など）との差額をのれんとする。子会社化では、個別の帳簿には子会社株式を載せ、グループの姿は連結財務諸表で示す
- 議決権の過半数を持つ会社は子会社。連結財務諸表は、親会社と子会社の個別財務諸表を合算し、連結修正仕訳をして作る
- 支配獲得日の資本連結：子会社の純資産を消去し、親会社の持分は子会社株式と相殺、差額はのれん、残りは非支配株主持分
- 支配獲得後は、開始仕訳・のれんの償却（20年以内）・子会社の損益の非支配株主への配分・配当の修正を行う
- のれんは将来の稼ぎへの見込みの値段。見込みが外れれば減損で一度に消える
::
