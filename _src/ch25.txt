## 2つの統合のかたち ― 合併と子会社化

会社が、別の会社を自分の傘下に入れる方法は、大きく2つある。

::table 合併と子会社化
| 方法 | 何が起きるか | 帳簿 |
| 合併（吸収合併） | 相手の会社が消滅し、その資産と負債をまるごと引き継ぐ。1つの会社になる | 合併した会社の帳簿に、相手の資産・負債を直接受け入れる |
| 子会社化 | 相手の会社の株式の過半数を買い、支配する。相手の会社は別の会社として残る | 自分の帳簿には「子会社株式」を載せるだけ。グループ全体の姿は**連結財務諸表**で示す |
::

父が選んだのは、子会社化だった。芹沢酒造という会社と、その蔵の名前と、清酒の製造免許を残したかったからだ。

## のれん ― 帳簿の純資産に載っていない価値

::theory のれん
会社や事業を買うとき、支払った対価が、受け入れた純資産（資産－負債）の時価を上回ることがある。その差額が**のれん**だ。帳簿の資産には載っていない、その会社の「稼ぐ力」― 歴史ある銘柄、得意先との関係、職人の技、免許 ― に対して払った代金と考える。
のれんは**無形固定資産**として計上し、**20年以内**に定額法で償却する（のれん償却）。逆に、対価が純資産の時価を下回るときの差額は**負ののれん発生益**（特別利益）とする。
::

芹沢酒造の帳簿には、130年の「芹沢」という銘柄の値打ちも、清酒の製造免許の値打ちも載っていない。
清酒の製造免許は、新しく始めたい人がお金を払っても、国から買えるものではない。国税庁の通達は、酒の需給の均衡を保つため、清酒の製造免許を、すでに清酒を造っている会社が合理化のために新しい製造場を設ける場合や、輸出するために造る場合などに限って与えるとしている。国内向けの清酒を造りたければ、免許を持つ蔵を引き継ぐしかない。
「免許は金で買えぬ」。だから父は、免許を持つ蔵を、人ごと守った。600万円は、その帳簿の外の値打ちへの代金だった。

::note
出典：[国税庁「酒税法及び酒類行政関係法令等解釈通達 第10条 製造免許等の要件（第11号関係）」](https://www.nta.go.jp/law/tsutatsu/kihon/sake/2-08.htm)。輸出用に限った清酒の製造免許は、2021年4月から申請の受付が始まった
::

## 合併の会計 ― のれんが、自分の帳簿に載る

先に、合併した場合の仕訳を確かめておこう。芹沢酒造を合併すれば、のれんは汐見酒造の帳簿に直接載る。

::example 吸収合併を仕訳する（別の会社の例）
A社はB社を吸収合併し、B社の株主に、A社の株式100株（時価1株60,000円、合計6,000,000円）を交付した。B社の資産の時価は15,000,000円、負債の時価は10,000,000円だった。A社は、交付した株式の価額のうち、3,000,000円を資本金、残りを資本準備金とした。
::answer
::journal 受け入れた純資産5,000,000円と、交付した株式6,000,000円の差がのれん
諸資産 15,000,000 | 諸負債 10,000,000
のれん 1,000,000 | 資本金 3,000,000
 | 資本準備金 3,000,000
::
合併では、相手の会社の資産と負債を**時価**で受け入れる。対価として株式を交付したときは、その価額を資本金・資本準備金（その他資本剰余金とすることもある）にする。
::trap
受け入れる資産・負債は、相手の帳簿価額ではなく**時価**。交付した株式の価額が純資産の時価を下回れば、差額は負ののれん発生益（特別利益）になる。
::
::
::

## 連結財務諸表 ― グループを1つの会社として見る

::theory 連結財務諸表と子会社
ある会社（**親会社**）が、別の会社の意思決定機関を支配しているとき、その会社を**子会社**という。議決権の**過半数**（50%超）を持っていれば、子会社と判定する。
親会社は、自分の帳簿（個別財務諸表）では、子会社株式を取得原価で載せるだけだ（第18章）。だが、子会社の資産・負債・損益は、実質的には親会社が動かしている。そこで、親会社と子会社を1つの会社とみなして、グループ全体の財務諸表（**連結財務諸表**）を作る。
連結財務諸表は、帳簿を新しくつけるのではなく、親会社と子会社の個別財務諸表を**合算**し、グループの中の重複や取引を消す**連結修正仕訳**をして作る。
::

## 支配獲得日の資本連結 ― 同じものを2度数えない

連結修正仕訳の最初は、親会社の「子会社株式」と、子会社の「純資産（資本）」の相殺だ。親会社が子会社株式に払ったお金は、子会社の純資産の形で、グループの中にすでにある。合算したままでは、同じものを2度数えることになる。

::example 支配獲得日（2026年6月30日）の資本連結を仕訳する（単位：万円）
汐見酒造は、芹沢酒造の株式の60%を3,600万円で取得し、支配を獲得した。この日の芹沢酒造の純資産は、資本金3,000万円、利益剰余金2,000万円。資産・負債の帳簿価額は時価と一致している。
::answer
- 親会社の持分：5,000万円×60%＝3,000万円 → のれん＝3,600万円－3,000万円＝600万円
- 非支配株主（芹沢家）の持分：5,000万円×40%＝2,000万円
::journal 投資と資本の相殺消去（単位：万円）
資本金 3,000 | 子会社株式 3,600
利益剰余金 2,000 | 非支配株主持分 2,000
のれん 600 |
::
子会社の純資産5,000万円はすべて消し、そのうち親会社の分（60%）は子会社株式と相殺し、残りの40%は**非支配株主持分**（連結貸借対照表の純資産）に振り替える。子会社株式と親会社の持分の差が**のれん**だ。
::trap
非支配株主持分を、子会社株式の取得原価から計算しないこと。子会社の純資産×非支配株主の持分比率で求める。
::
::
::

::boxes 支配獲得日の芹沢酒造の純資産と、汐見酒造の投資（単位：万円）
H 芹沢酒造の純資産と、のれん | 誰のものか
L e 30 親会社の持分<br>5,000×60%＝3,000
L e 20 非支配株主の持分<br>5,000×40%＝2,000
L a 6 のれん<br>600
R a 36 子会社株式<br>3,600（汐見酒造の投資）
R e 20 非支配株主持分<br>2,000（芹沢家）
::

::solve 600万円は、帳簿の純資産に載っていない「芹沢酒造の稼ぐ力」への代金。連結の貸借対照表で、のれんとして姿を現す
芹沢酒造の純資産5,000万円のうち、父が買った60%は3,000万円分だった。父は、それより600万円多い3,600万円を払った。この600万円が**のれん**だ。銘柄、免許、杜氏の技、得意先 ― 帳簿の資産には載らないが、将来の稼ぎを生むと見込んだものへの代金だ。とりわけ清酒の製造免許は、お金を出しても国からは新しく買えない。
汐見酒造の個別の貸借対照表では、この600万円は「子会社株式3,600万円」の中に埋もれていて、見えない。連結貸借対照表を作って初めて、**のれん600万円**として姿を現し、20年かけて償却されていく。
::

千尋は、のれんの説明を聞いて、少し照れたように笑った。
千尋：「うちの蔵に、600万円の値打ちがあると思ってくれたんですね」
澪：「父は、そう見込みました。でも、その見込みが当たったかどうかは、この1年の数字が教えてくれます」
芹沢酒造の6月期の当期純損益は、**△500万円**。3期続けての赤字だった。

## 支配獲得後の連結 ― 1年後の連結修正

支配を獲得した翌年度からは、毎年、連結財務諸表を作る。連結修正仕訳は個別の帳簿に記録されないので、毎年、過去の修正を最初からやり直す。

::theory 支配獲得後の主な連結修正仕訳
1. **開始仕訳**：支配獲得日の資本連結（と、前期までの連結修正）をもう一度行う。前期までの修正で損益に関わるものは、**利益剰余金当期首残高**として修正する
2. **のれんの償却**：のれんを償却する（のれん償却／のれん）
3. **子会社の当期純損益の配分**：子会社の当期純利益のうち非支配株主の持分を、**非支配株主に帰属する当期純利益**として非支配株主持分に振り替える（損失なら逆）
4. **子会社の配当の修正**：子会社が払った配当のうち、親会社が受け取った分は受取配当金と相殺し、非支配株主が受け取った分は非支配株主持分を減らす
::

::example 2027年6月期の連結修正仕訳をする（単位：万円）
芹沢酒造の当期純損失は500万円、配当はなし。のれんは20年で定額法により償却する。
::answer
::journal (1) 開始仕訳：支配獲得日の資本連結を、もう一度行う
資本金当期首残高 3,000 | 子会社株式 3,600
利益剰余金当期首残高 2,000 | 非支配株主持分当期首残高 2,000
のれん 600 |
::
::journal (2) のれんの償却：600万円÷20年
のれん償却 30 | のれん 30
::
::journal (3) 子会社の当期純損失のうち、非支配株主の分（500万円×40%）を非支配株主持分から差し引く
非支配株主持分当期変動額 200 | 非支配株主に帰属する当期純利益 200
::
(3)は、子会社が損失を出したので、非支配株主の持分も40%分だけ減る。連結損益計算書では「非支配株主に帰属する当期純利益」が△200万円（損失）となり、連結の当期純損失のうち親会社株主に帰属する部分が、その分だけ小さくなる。
連結の株主資本等変動計算書で項目ごとの期首残高と変動を示すため、連結修正仕訳では「資本金当期首残高」「非支配株主持分当期変動額」のような科目を使う。問題によっては、単に「資本金」「非支配株主持分」とすることもある。
::trap
2年目以降の開始仕訳では、前期ののれん償却や非支配株主への損益の配分も、「利益剰余金当期首残高」に置き換えて引き継ぐ。前期の損益の科目のまま書かないこと。
::
::
::

### 試験で狙われるパターン ― 資本連結の4つの型

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 支配獲得日の資本連結**　子会社の純資産（資本金・資本剰余金・利益剰余金）を全部消し、のれん＝子会社株式－子会社の純資産×親会社の持分比率、非支配株主持分＝子会社の純資産×非支配株主の持分比率。

**② 2年目以降の開始仕訳**　支配獲得日の仕訳に、前期までの「のれん償却」「非支配株主に帰属する当期純利益」を、利益剰余金当期首残高として加える。

**③ 子会社の配当**　親会社の分は「受取配当金／利益剰余金（剰余金の配当）」、非支配株主の分は「非支配株主持分／利益剰余金（剰余金の配当）」。

::example 子会社の配当を修正する（別の会社の例）
親会社P社は、子会社S社の株式の80%を持っている。当期、S社は配当500,000円を支払い、P社はそのうち400,000円を受け取って受取配当金とした。連結修正仕訳をしなさい。
::answer
::journal 親会社の分は受取配当金と、非支配株主の分は非支配株主持分と相殺する
受取配当金 400,000 | 剰余金の配当 500,000
非支配株主持分当期変動額 100,000 |
::
親会社が受け取った400,000円は、グループの中でお金が移っただけなので、連結では収益にならない。非支配株主に払った100,000円は、グループの外に出たお金なので、非支配株主持分を減らす。「剰余金の配当」は、子会社の利益剰余金を減らした項目を取り消す科目だ。
::trap
子会社の配当の全額を受取配当金と相殺しないこと。親会社が受け取ったのは持分比率（80%）の分だけだ。
::
::
::

**④ 合併**　資産・負債を時価で受け入れ、交付した株式の価額との差をのれん（または負ののれん発生益）にする。

::steps 解法の型 ― 資本連結
1. 持分比率を確かめる | 議決権の過半数なら子会社。親会社と非支配株主の比率を書き出す
2. 支配獲得日 | 子会社の純資産を消去。親会社の分は子会社株式と相殺、差額はのれん、残りは非支配株主持分
3. 開始仕訳 | 2年目以降は、前期までの損益の修正を利益剰余金当期首残高に置き換える
4. 当期の修正 | のれん償却、子会社の当期純損益×非支配株主の比率の振替え、配当の修正
5. 確かめる | のれんと非支配株主持分の期末残高を、ボックス図で検算する
::

## 千尋の不安 ― のれんは、消えることもあるのか

::scene 9月10日、夕方 ― 芹沢酒造の帳場
のれんの説明を聞き終えた千尋は、少し不安そうに聞いた。
千尋：「600万円の『稼ぐ力』は、もし、うちがこのまま赤字を続けたら、どうなるんですか」
澪は、椎名から聞いた話を思い出していた。
澪：「消えることがあります。何千億円という単位で、一度に消えた例もあるんです」
千尋：「何千億円？」
澪：「日本郵政が、オーストラリアの物流会社を買ったときの話です」
::

2015年、日本郵政は、オーストラリアの大手物流会社トール・ホールディングスを買収した。買収のときに計上したのれんと商標権は、約52.8億豪ドル（約5,048億円）にのぼった。
だが、資源価格の下落とオーストラリア経済の減速で、トールの業績は買収時の見込みを大きく下回った。日本郵政は、2017年3月期の決算で、トールののれんなどの全額にあたる**3,923億円**と、有形固定資産の80億円、合わせて**4,003億円**の減損損失を特別損失に計上した。同社は、2007年の民営化以来初めて、連結の当期純損失（289億円）に転落した。
澪は、帳場の黒板に、2本の仕訳を書いた（単位：億円）。

::journal ① 買収時の資本連結のうち、のれんの部分：子会社の純資産を超えて払った部分（のれん・商標権）
のれん 5,048 | 子会社株式 5,048
::

::journal ② 見込みが外れたとき：のれんを減損する（1級の範囲の処理）
減損損失 3,923 | のれん 3,923
::

澪：「①の時点では、のれんは5,048億円の資産として、連結の貸借対照表に載ります。でも、それは、トールが将来稼ぐという見込みの上に成り立つ数字でした。②は、その見込みが崩れたことを、一度に損失として認めたものです」
千尋は、黒板の数字をしばらく見ていた。
千尋：「600万円も、同じなんですね。うちが稼げなければ、ただの数字になる」
澪：「のれんの大きさは、買った側の自信の大きさで、同時に、将来の損失の種の大きさでもあります。父は、芹沢酒造に600万円分の自信を持った。それを本当の稼ぎに変えられるかは、これからの私たちしだいです」
千尋は、黒板消しを手に取り、②の仕訳だけを消した。
千尋：「じゃあ、こっちは書かせないようにしましょう」

::note
出典：[ニュースイッチ（日刊工業新聞）による日本郵政のトールの減損の報道（2017年）](https://newswitch.jp/p/9085)
::

::danger のれんは、買った側の「見込み」の値段
のれんは、帳簿の外の稼ぐ力に払った代金だが、その中身は、買った側の見込みだ。高く買うほど、のれんは大きくなり、見込みが外れたときの損失も大きくなる。買収の発表で「シナジー」が語られたら、のれんの額と、それが純資産のどれだけを占めるかを確かめる。決算書の上では、のれんは、毎年少しずつの償却か、一度の大きな減損で、必ず費用になる。
::

::cfo 9月28日の計画 ― 芹沢酒造を、どうするか
高梨との約束の期限まで、あと18日。澪は、千尋と椎名と一緒に、4つの案を比べた。
**前提**
- 芹沢酒造の6月末の純資産は4,500万円で、3期続けて赤字。借入金8,000万円は汐見酒造が保証している
- 芹沢酒造の強みは、銘柄「芹沢」の固定客、清酒の製造免許、若い蔵人2人
- 合併すれば、管理部門の統合で年600万円、精米を芹沢の新しい精米機に集約し、汐見の精米係2人を醸造に回して年400万円の費用を減らせる見込み（第8章）
- 残り40%を現金で買い取るなら、約1,800万円（純資産4,500万円×40%）が要る
- 汐見酒造の6月末の純資産は5,158万円で、預金に余裕はない
- 芹沢酒造の創業は1890年で、汐見酒造より古い
::choice A. 何もしない。子会社のままなら、芹沢酒造の赤字は汐見酒造の個別の決算書には出ない
**× 個別の決算書に出ないだけで、グループの損失は消えない。**連結財務諸表には、芹沢酒造の赤字がそのまま載る。そして、8,000万円の保証は、汐見酒造の純資産5,158万円を上回る。赤字が続けば、いずれ保証が現実の負担になる。高梨は注記まで読んでいる（第22章）。
::
::choice B. 残り40%をすぐ現金で買い取り、完全子会社にする
**△ 意思決定は速くなるが、現金が足りない。**非支配株主との調整は要らなくなる。だが、約1,800万円の現金は、増資の1,000万円を使っても足りず、審査の条件のもとで新しい借入れも難しい。しかも、保証の問題は何も解決しない。
::
::choice C. 1年後に吸収合併する。それまでは連結で毎月の数字を管理し、合併で固定費を減らす
**◎ 保証を自分の負債として正面から扱い、効果も数字で示せる。**合併すれば、芹沢酒造の借入金8,000万円は汐見酒造の借入金になり、「見えない負債」が「見える負債」になる。信用金庫とは、2つの蔵の借入金をまとめて交渉できる。管理部門の統合と精米の集約で、年1,000万円の改善が見込める。芹沢家には汐見酒造の株式を交付するので、現金は要らず、銘柄と免許も残る。
::
::choice D. 芹沢酒造を清算して、保証を整理する
**× 最も大きな損失を、確定させてしまう。**清算すれば、資産を売っても借入金を返しきれない可能性が高く、汐見酒造が保証を履行して、数千万円の損失を負いかねない。のれん600万円で買った銘柄と免許も、二度と手に入らない形で消える。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「芹沢酒造の赤字をどう見せないか」ではなく、「グループ全体で見たとき、損益・現金・負債（保証を含む）は、それぞれの案でどう変わるか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 4つの案を、グループ全体で比べる
| 案 | 現金 | 年の損益の改善 | 保証8,000万円 | 免許 |
| A 何もしない | 0 | 0 | 注記のまま | 残る |
| B 完全子会社化 | △1,800万円 | 0 | 注記のまま | 残る |
| C 1年後に合併 | 0（株式を交付） | ＋1,000万円 | 自社の借入金へ | 残る |
| D 清算 | 保証の履行で大きく減る | ― | 損失として確定 | 消える |
::
#### 手順3　ほかの答えに引かれる理由
Aは「個別の決算書に出ない」という見た目に、Bは「早く決着をつけたい」という焦りに、Dは「損を切ってすっきりしたい」という気持ちに引かれる。芹沢酒造が汐見酒造より古いことは、どの案を選ぶかとは関係のない前提だ。
#### 持ち帰る考え方
- **子会社の赤字も、子会社の借金の保証も、グループの外から見れば親会社のものと同じ**：連結で見て判断する
- **統合のかたちは、現金・損益・負債の3つで比べる**：帳簿の見た目ではなく、グループの中身がどう変わるか
#### 前提が変われば
芹沢酒造の赤字が一時的で、来期に自力で黒字に戻る見込みがはっきりしていれば、子会社のまま連結で見守る（A）のも選べる。汐見酒造に現金の余裕があれば、完全子会社化（B）で意思決定を速くする道もある。
::
::

::exam 資本連結の急所
- 子会社の判定は**議決権の過半数**。支配獲得日の子会社の純資産（資本金・資本剰余金・利益剰余金）を全額消去する
- **のれん＝子会社株式－子会社の純資産×親会社の持分比率**。**非支配株主持分＝子会社の純資産×非支配株主の持分比率**
- のれんは**20年以内の定額法**で償却（連結損益計算書では販売費及び一般管理費）
- 子会社の当期純利益×非支配株主の持分比率を「非支配株主に帰属する当期純利益／非支配株主持分」で振り替える（損失なら逆）
- 2年目以降は**開始仕訳**で前期までの修正を引き継ぐ。損益の科目は「利益剰余金当期首残高」に置き換える
- 合併は、資産・負債を**時価**で受け入れ、交付した株式との差をのれん（負ののれんは特別利益）にする
::

::next 合併と連結の先にある論点
1級では、子会社の資産・負債の**時価評価**（評価差額）、のれんの**減損**、段階取得や持分の追加取得・一部売却、**持分法**（関連会社の会計）、在外子会社の換算、株式交換・株式移転・会社分割などを学ぶ。日本郵政の例のように、のれんは上場企業の決算を大きく動かす。連結財務諸表を読む力は、2級の資本連結の手順から始まる。
::

::summary
- 合併では、相手の資産・負債を時価で受け入れ、対価（交付した株式など）との差額をのれんとする。子会社化では、個別の帳簿には子会社株式を載せ、グループの姿は連結財務諸表で示す
- 議決権の過半数を持つ会社は子会社。連結財務諸表は、親会社と子会社の個別財務諸表を合算し、連結修正仕訳をして作る
- 支配獲得日の資本連結：子会社の純資産を消去し、親会社の持分は子会社株式と相殺、差額はのれん、残りは非支配株主持分
- 支配獲得後は、開始仕訳・のれんの償却（20年以内）・子会社の損益の非支配株主への配分・配当の修正を行う
- のれんは将来の稼ぎへの見込みの値段。見込みが外れれば、減損で一度に消える
::
