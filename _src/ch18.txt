6月14日、月曜日。決算の準備で、前期末の貸借対照表を1行ずつ確かめていた澪は、「投資その他の資産」の欄で手を止めた。
**子会社株式 3,600万円**。
汐見酒造に、子会社などあっただろうか。岩倉に聞くと、彼は珍しく言いよどんだ。「社長から、専務には自分の口から話すと言われとりまして……」
その夜、病院のベッドの上で、父はゆっくりと話した。去年の6月30日、隣町の芹沢酒造の株式の60%を、3,600万円で買い取った。芹沢酒造は後継者がおらず、借金も重く、廃業の寸前だった。創業130年を超える蔵の火を、消したくなかったのだという。
帳簿には、ほかにも株と債券があった。取引先の食品卸、越後物産の株は**3,000万円**で買ったものが、いまは時価で**3,300万円**。満期まで持つつもりの国債もある。
越後物産の株は、時価に合わせて帳簿の金額を変える。だが、芹沢酒造の株は、買った値段の3,600万円のまま。しかも、越後物産の株の値上がりの300万円は、損益計算書の利益にはならないという。
**同じ「株」なのに、なぜ扱いがこんなに違うのか？**
::

## 有価証券の4つの分類 ― 「なぜ持っているか」で決まる

株式や社債、国債などの**有価証券**は、同じ1株・1枚でも、**なぜ持っているか（保有目的）**によって、期末の評価の方法が違う。

::table 有価証券の4つの分類
| 分類 | 保有の目的 | 期末の評価 | 評価差額の行き先 | 貸借対照表の表示 |
| 売買目的有価証券 | 時価の変動で利益を得るために、頻繁に売買する | 時価 | **有価証券評価損益**（損益計算書・営業外損益） | 有価証券（流動資産） |
| 満期保有目的債券 | 満期まで持ち続けて、利息と元本を受け取る | 償却原価（取得原価と額面の差を期間に配分） | 有価証券利息（損益計算書） | 投資有価証券（固定資産）。1年以内に満期なら流動資産 |
| 子会社株式・関連会社株式 | 他の会社を支配する、または大きな影響を与える | 取得原価 | ― | 関係会社株式（固定資産） |
| その他有価証券 | 上のどれにもあたらない（取引先との関係の維持など） | 時価 | **その他有価証券評価差額金**（純資産。損益計算書に載せない） | 投資有価証券（固定資産） |
::

::theory なぜ、目的で評価が変わるのか
- **売買目的**の株は、時価の変動そのものが儲けの源だ。だから、時価で評価し、その差額を毎期の損益にする
- **満期保有目的**の債券は、途中の時価の上下に関係なく、満期に額面を受け取る。だから、時価は使わない
- **子会社株式**は、売るためではなく、その会社を支配するために持っている。時価で売ることを前提にしていないので、取得原価のままにする（子会社の実態は、連結財務諸表で示す。第25章・第26章）
- **その他有価証券**は、すぐに売るつもりはないが、いつか売るかもしれない。だから、時価で貸借対照表に載せて財政状態を示すが、その差額はまだ実現していない利益として損益計算書には入れず、純資産に直接計上する（**全部純資産直入法**）
::

## 売買目的有価証券 ― 時価の変動を、毎期の損益に

汐見酒造には売買目的の株はない。2級の試験でよく出る形を、例題で確かめておこう。

::example 売買目的有価証券の取引を仕訳しなさい
(1) 売買目的で、A社株式1,000株を1株1,200円で購入し、買入手数料20,000円とともに普通預金から支払った。
(2) 決算日に、A社株式の時価は1株1,150円だった（切放法）。
(3) 翌期、A社株式のうち600株を1株1,250円で売却し、代金は普通預金に入金された。
::answer
::journal (1) 取得原価は付随費用（手数料）を含む：1,000株×1,200円＋20,000円
売買目的有価証券 1,220,000 | 普通預金 1,220,000
::
::journal (2) 時価1,150,000円との差額
有価証券評価損 70,000 | 売買目的有価証券 70,000
::
::journal (3) 切放法なので、帳簿価額は1株1,150円。600株×(1,250円－1,150円)
普通預金 750,000 | 売買目的有価証券 690,000
 | 有価証券売却益 60,000
::
売買目的有価証券の評価差額は、損益計算書の営業外損益になる。評価差額を翌期首に戻す**洗替法**なら、(3)の帳簿価額は1株1,220円となり、売却益は600株×30円＝18,000円になる。どちらの方法かは問題文に従う。
::
::

### 端数利息 ― 利払日の間に債券を買うと

債券を、利払日と利払日の間に売買すると、前の利払日から売買の日までの利息（**端数利息**）は、売り手のものだ。だが、次の利払日に利息を受け取るのは買い手なので、買い手は売買のときに、端数利息を売り手に先に払っておく。

::example 端数利息を含む債券の購入を仕訳しなさい
売買目的で、額面2,000,000円の社債（年利1.46%、利払日は6月末と12月末）を、9月11日に額面100円につき98円で購入し、端数利息とともに普通預金から支払った。端数利息は1年を365日とし、前の利払日の翌日（7月1日）から購入日（9月11日）までの73日分で計算する。
::answer
- 購入代価：2,000,000円×98円÷100円＝1,960,000円
- 端数利息：2,000,000円×1.46%×73日÷365日＝5,840円
::journal 端数利息は有価証券利息の借方（あとで受け取る利息から差し引かれる）
売買目的有価証券 1,960,000 | 普通預金 1,965,840
有価証券利息 5,840 |
::
12月末に6か月分の利息14,600円を受け取ると、有価証券利息は差し引き8,760円（購入日の翌日からの分）になる。売った側は、端数利息を「有価証券利息」の貸方に記録する。
::
::

## 満期保有目的債券 ― 償却原価法

前期の7月1日、蔵は、満期まで持つつもりで国債を買っていた。額面は1,000万円、買った値段は980万円。差の20万円は、満期までの5年間に、利息の一部として少しずつ受け取るものと考える。

::theory 償却原価法（定額法）
満期保有目的債券を額面と異なる金額で取得し、その差額が金利の調整と認められるときは、差額を満期までの期間に毎期均等に配分し、帳簿価額に加減する。相手の勘定は**有価証券利息**だ。満期には、帳簿価額がちょうど額面になる。
::

::example 国債（満期保有目的）について、6月30日の決算の仕訳をしなさい
前期7月1日に、額面10,000,000円の国債（満期は5年後の6月30日、年利0.6%、利払日は12月末と6月末）を9,800,000円で購入し、満期保有目的債券とした。当期の利息は、12月末と6月末に普通預金に入金済み（仕訳済み）である。
::answer
::journal 償却原価法：(10,000,000円－9,800,000円)÷5年
満期保有目的債券 40,000 | 有価証券利息 40,000
::
当期の有価証券利息は、受け取った利息60,000円（10,000,000円×0.6%）と償却額40,000円の合計100,000円。満期保有目的債券の帳簿価額は、前期末の9,840,000円から9,880,000円になる。
::
::

## その他有価証券 ― 時価で載せるが、利益にはしない

越後物産の株式は、売るためではなく、長年の取引の関係を保つために持っている。**その他有価証券**だ。

::example 越後物産の株式（その他有価証券）について、決算の仕訳をしなさい
越後物産の株式2万株は、取得原価30,000,000円（1株1,500円）。6月30日の時価は1株1,650円である。全部純資産直入法による（税効果会計は第21章で扱うので、ここでは考えない）。
::answer
::journal 時価33,000,000円との差額を、純資産の部に直接計上する
その他有価証券 3,000,000 | その他有価証券評価差額金 3,000,000
::
::journal 翌期首：評価差額を戻す（洗替法）
その他有価証券評価差額金 3,000,000 | その他有価証券 3,000,000
::
その他有価証券の評価差額は、毎期、**洗替法**で処理する。期末に時価に合わせ、翌期首に取得原価に戻す。時価が取得原価を下回るときは、借方に「その他有価証券評価差額金」が出る（純資産のマイナス）。
受け取った配当金は、受取配当金（営業外収益）になる。今期、越後物産から1株50円、合計1,000,000円の配当があった。
::
::

::point 売買目的有価証券は「分記法」で記録する
この章の例題では、売買目的有価証券を売ったとき、帳簿価額だけを有価証券の勘定から減らし、売った値段との差を**有価証券売却益（売却損）**として別に記録した。このように、売却の損益を分けて記録する方法を**分記法**という。2級の売買目的有価証券は、分記法で処理する。売った値段の全額を有価証券の勘定の貸方に記録し、損益を期末にまとめて計算する総記法は、1級の範囲だ。
::

::exam 有価証券の急所
- 取得原価には**買入手数料**などの付随費用を含める。売却時の手数料は、売却損益に含めるか支払手数料にする（問題の指示）
- **売買目的**：時価評価し、差額は有価証券評価損益。切放法と洗替法で、売却時の帳簿価額が違う
- **満期保有目的**：償却原価法（定額法）。差額÷期間を、毎期「満期保有目的債券／有価証券利息」。期中に取得したら月割
- **子会社・関連会社株式**：取得原価のまま（時価が著しく下落したときの強制評価減は1級）
- **その他有価証券**：全部純資産直入法・洗替法。税効果を適用すると、評価差額の30%（税率）が繰延税金負債（資産）になり、残りがその他有価証券評価差額金（第21章）
- **端数利息**：前の利払日の翌日から売買の日まで（日割）。買い手は有価証券利息の借方、売り手は貸方
- 同じ銘柄を何回かに分けて買ったときは、平均原価法で売却原価を計算する
::

## 答え合わせ ― 目的が違えば、同じ株でも物差しが違う

::solve 株の扱いは、「持っている理由」で決まる
芹沢酒造の株は、汐見酒造が芹沢酒造を**支配するため**に持っている。売るつもりはない。だから、時価ではなく、取得原価の3,600万円のまま載せる。芹沢酒造が本当にいくらの価値を生んでいるかは、汐見酒造と芹沢酒造を1つのグループとして見る**連結財務諸表**で示す。
越後物産の株は、取引の関係を保つための**その他有価証券**だ。時価で貸借対照表に載せるが、値上がりの300万円は、売るまでは実現していない利益なので、損益計算書には入れず、純資産の「その他有価証券評価差額金」に直接計上する。
同じ株という紙切れでも、物差しは、持つ理由で変わる。
::

病院からの帰り道、澪は、父の言葉を何度も思い返していた。「あの蔵の株は、儲けるために買ったんじゃない」。帳簿は、その言葉どおりに記録していた。取得原価の3,600万円という数字は、父の決断の値段だった。その決断が蔵にとって何を意味するのかを知るには、芹沢酒造の帳簿を、汐見酒造の帳簿と1つに合わせてみるしかない。それは、第3部の仕事になる。

## 財務部の先輩の電話 ― 企業価値が上がると、持つ側は利益、発行した側は損失

::scene 6月15日、昼休み ― 蔵の裏の土手
父の話を聞いた翌日、澪は、商社の財務部にいた先輩に電話をかけた。会社の余った資金を株や債券で運用していた人だ。子会社株式と、取引先の株と、国債。同じ「有価証券」の扱いが、なぜこれほど違うのか。
先輩は、電話の向こうで笑った。「いい質問だ。ちょうどいい例がある。アマゾンと、例のAIの会社だよ。同じ1つの出来事が、片方では何兆円もの利益になって、もう片方では何兆円もの損失になっている」
::

先輩の話はこうだった。AI企業 Anthropic に早くから出資してきたアマゾンは、2025年7〜9月期の決算で、Anthropic への投資から生じた税引前の利益**95億ドル**を、営業外の収益に計上した。株を売ったわけではない。Anthropic が新たな資金を、より高い企業価値で集めたことで、アマゾンが持つ株式の評価額が上がったのだ。2026年4〜6月期には、主に Anthropic への投資から生じた**534億ドル**の営業外の利益を計上した。この四半期のアマゾンの営業利益は275億ドル、当期純利益は626億ドル。本業の利益の2倍近い「評価の上の利益」が、純利益を押し上げていた。
一方、序章で見たとおり、Anthropic の2025年の損益計算書には、**343億ドル**の損失が載っていた。届出書は、その原因を「企業価値の上昇によって、発行済みの転換約束手形（将来、株式に転換される約束の借入れ）の公正価値が上がったこと」と説明している。
「会社の価値が上がると、その会社の株や、株に変わる権利を持つ側から見れば、資産の価値が上がる」と先輩は言った。「逆に、その会社から見れば、将来、価値の上がった株を渡さなければならない約束の重さが増す。同じ出来事の、表と裏だ」
電話を切った後、澪は、2つの仕訳を並べてみた（単位：億ドル、金額は報道と届出書の数字）。

::journal ① 持つ側（アマゾン、米国の会計基準）：投資の評価額の上昇を利益に
投資有価証券 95 | 投資評価益 95
::
::journal ② 発行した側（Anthropic）：転換社債の公正価値の上昇を損失に
転換社債評価損 343 | 転換社債 343
::

①は、この章でいう「時価で評価して、差額を損益にする」処理に近い。もし日本の会計基準で、この株を**その他有価証券**に分類していれば、評価差額は損益計算書に入らず、純資産の「その他有価証券評価差額金」になる。同じ値上がりでも、基準と分類によって、利益になるかどうかが変わる。
②は、負債を時価で測り直す処理で、2級の範囲を超える。だが、仕組みは①の裏返しだ。会社の評判が上がるほど、帳簿の損失が増える。Anthropic の2025年の当期純損失420億ドルのうち、8割を超える343億ドルは、この評価の上の損失だった。現金は1ドルも出ていっていない。
澪は、越後物産の株の300万円の値上がりを思い浮かべた。その他有価証券だから、損益には入れない。父の芹沢酒造の株は、子会社株式だから、時価で測り直さない。決算書の利益や損失が、本業の稼ぎなのか、持っている資産や負債の評価の変化なのか。アマゾンの利益も、Anthropic の損失も、そして汐見酒造の帳簿も、その区別なしには読めない。

::table 越後物産の株式の資料

| 6月30日の時価 | 3,300万円（1株1,650円） |
| 越後物産との関係 | 蔵の普通酒の最大の卸先。先方も汐見酒造の株を少し持っている |
::
まず、それぞれの案で、損益計算書と貸借対照表がどう変わるかを考えてから選んでほしい。
::choice A. 売買目的有価証券に分類を変え、評価益300万円を損益に入れる
**× 分類は「目的」で決まり、決算の都合では変えられない。**売買目的有価証券は、時価の変動で利益を得るために頻繁に売買するものに限られる。20年間売買したこともない取引先の株を、決算の直前に売買目的とするのは、利益を作るための分類の変更だ。会計の基準でも、売買目的への分類の変更は、原則として認められない。経常損失は300万円小さく見えるが、中身を知った高梨の信頼を失う。
::
::choice B. その他有価証券のまま、評価差額300万円を純資産に計上する
**◎ 持っている理由に合った処理だ。**貸借対照表には時価の3,300万円が載り、純資産の「その他有価証券評価差額金」が増える（税効果を考えると、300万円の30%の90万円は繰延税金負債、残り210万円が評価差額金。第21章）。損益計算書は変わらない。
値上がりは、売れば実現する利益だが、越後物産との関係を考えれば、売るつもりはない。まだ実現していない利益を、本業の成績と混ぜない。それが、全部純資産直入法の意味だ。
::
::choice C. 決算の前に売って利益を実現させ、決算の後にすぐ買い戻す
**× 形の上では実現するが、実態は何も変わっていない。**売れば有価証券売却益300万円が出る。だが、すぐに買い戻すなら、蔵の財産も、越後物産との関係も、売る前と何も変わらない。決算の数字のためだけの売り買いは、売買手数料の分だけ損をして、決算書を読む人を欺く。売ってすぐ買い戻す取引は、会計上も売却として扱われないことがある。
::
::choice D. 子会社株式と同じく、取得原価の3,000万円のままにしておく
**× 子会社でも関連会社でもない株は、時価で評価する。**越後物産を支配しているわけでも、大きな影響を与えているわけでもない。その他有価証券は、時価で貸借対照表に載せなければならない。取得原価のままにすれば、貸借対照表の資産が300万円小さく表示される。今回は控えめな誤りだが、時価が下がっていたら、損失を隠すことになる。
::
::answer 考え方の例を見る
有価証券の分類は、**保有の目的**で決まり、決算の都合で変えることはできない。同じ値上がりでも、売買目的なら利益、その他有価証券なら純資産、子会社株式なら記録しない。分類を変えれば利益を作れてしまうからこそ、分類の変更は厳しく制限されている。
澪は、越後物産の株をその他有価証券のまま評価した。そして、決算書に添える説明の資料に、こう書いた。「投資有価証券：取引先の株式。時価の上昇300万円は純資産に計上（損益には含めていない）」。
::
::

::next 有価証券の会計の先にある論点
1級では、子会社株式・関連会社株式やその他有価証券の時価が著しく下がったときの**減損処理**（強制評価減）、その他有価証券の**部分純資産直入法**、債券の償却原価法の**利息法**、保有目的の変更、デリバティブ（先物・オプション・スワップ）などを学ぶ。Anthropic の転換社債のように、株に変わる権利のついた負債（新株予約権付社債）の会計も1級の範囲だ。

::summary
- 有価証券は、保有目的で4つに分類する。売買目的（時価・評価差額は損益）、満期保有目的（償却原価）、子会社・関連会社株式（取得原価）、その他有価証券（時価・評価差額は純資産）
- 満期保有目的債券は、額面との差額を償却原価法（定額法）で毎期配分し、有価証券利息とする
- その他有価証券は、全部純資産直入法・洗替法。評価差額は損益計算書に載せない
- 端数利息は、前の利払日の翌日から売買日までの日割。買い手は有価証券利息の借方に記録する
- 分類は目的で決まり、決算の都合で変えられない
- 同じ企業価値の上昇が、持つ側には利益、発行した側（転換社債などの負債）には損失として表れることがある。利益・損失が本業の稼ぎか、評価の変化かを区別して読む
::
