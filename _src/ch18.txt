## 持つ目的で、物差しが変わる ― 有価証券の4つの分類

その夜、澪は金庫の中身を机に並べた。国債、越後物産の株、芹沢酒造の株。
澪：「どれも有価証券ですよね。決算では、全部その日の値段で測り直せばいい。越後物産の株は、買ったときより300万円上がっています。利益にすれば、決算が少し良くなる」
翌朝、椎名に電話をすると、すぐに止められた。
椎名：「有価証券は、持っている目的で、4つに分けます。目的が違えば、決算の物差しも、差額の行き先も違うんです」

::table 有価証券の4つの分類と、期末の評価
| 分類 | 持つ目的 | 期末の評価 | 評価差額の行き先 |
| 売買目的有価証券 | 値上がりで儲けるため、短期で売り買いする | 時価 | 損益（有価証券評価損益） |
| 満期保有目的債券 | 満期まで持ち続けて、利息と元本を受け取る | 償却原価（取得原価と額面の差を期間で配分） | 有価証券利息 |
| 子会社株式・関連会社株式 | ほかの会社を支配する、または大きな影響を与える | 取得原価のまま | なし |
| その他有価証券 | 上のどれにもあたらない（取引先との関係のための株など） | 時価 | 純資産（その他有価証券評価差額金） |
::

::theory 時価で測るのは、時価で売るつもりのものだけ
売買目的有価証券は、時価で売ることが目的なので、時価の変化がそのまま成果になり、損益に入れる。
満期保有目的債券は、満期まで売らないので、途中の時価の上下は関係がない。子会社株式・関連会社株式は、会社を支配するために持つもので、売るつもりがないので、取得原価のまま置く。
その他有価証券は、すぐには売らないが、売れなくもない。時価で測るが、その差額は売って確定するまで利益にせず、純資産に直接入れる（全部純資産直入法）。
::

## 売買目的有価証券 ― 時価法と、端数利息

蔵には、売買目的の株はない。椎名は、試験でいちばん出る形として、売り買いの流れを見せてくれた。

::example 売買目的の株を買い、決算で時価に合わせ、翌期に売った
(1) 売買目的でA社の株式1,000株を1株1,200円で購入し、手数料20,000円とともに普通預金から支払った。
(2) 決算日の時価は1株1,150円だった（切放法）。
(3) 翌期、600株を1株1,250円で売却し、代金は普通預金に入金された。
::answer
::journal (1) 取得原価は付随費用（手数料）を含む：1,000株×1,200円＋20,000円
売買目的有価証券 1,220,000 | 普通預金 1,220,000
::
::journal (2) 時価1,150,000円との差額
有価証券評価損 70,000 | 売買目的有価証券 70,000
::
::journal (3) 切放法なので、帳簿価額は1株1,150円。600株×(1,250円－1,150円)
普通預金 750,000 | 売買目的有価証券 690,000
 | 有価証券売却益 60,000
::
売買目的有価証券の評価差額は、損益計算書の営業外損益になる。評価差額を翌期首に戻す**洗替法**なら、(3)の帳簿価額は1株1,220円となり、売却益は600株×30円＝18,000円になる。
::trap
切放法か洗替法かで、翌期の帳簿価額が変わる。問題文の指示を必ず確かめる。また、売却時の手数料は、売却益から差し引く（支払手数料とする指示もある）。
::
::
::

債券を利払日の途中で買うと、前の利払日から買った日までの利息（**端数利息**）を、売り手に払わなければならない。次の利払日に、半年分の利息をまるごと受け取るからだ。

::example 利払日の途中で、売買目的の国債を買った
12月12日、売買目的で国債（額面2,000,000円、年利率1.46%、利払日は3月末と9月末）を、額面100円につき98円で購入した。前の利払日の翌日（10月1日）から購入日までの73日分の端数利息（1年を365日とする日割り）とともに、普通預金から支払った。
::answer
::journal 端数利息：2,000,000円×1.46%×73日÷365日＝5,840円。有価証券利息の借方に記録する
売買目的有価証券 1,960,000 | 普通預金 1,965,840
有価証券利息 5,840 |
::
3月末に6か月分の利息14,600円（2,000,000円×1.46%×6÷12）を受け取ると、有価証券利息は差し引き8,760円（自分が持っていた期間の分）になる。売った側は、端数利息を「有価証券利息」の貸方に記録する。
::trap
端数利息を、有価証券の取得原価に含めないこと。また、日数の数え方（片落としか両端入れか）は問題文に従う。
::
::
::

::point メモ ― 分記法
有価証券を売ったとき、売った分の帳簿価額だけ有価証券を減らし、売価との差額を「有価証券売却益（売却損）」として、その都度記録する方法を**分記法**という。最初の例題の(3)の仕訳がこの形だ。同じ銘柄を何回かに分けて買ったときは、平均した単価（移動平均法など、問題文の指示による）で帳簿価額を計算する。
::

## 父が買った国債 ― 満期保有目的債券と償却原価法

金庫の国債の預り証には、父の字でメモが貼ってあった。「満期まで持つ。孫の代の資金」。
前の期の7月1日に、額面1,000万円の国債（期間5年、年利率0.6%）を980万円で買っていた。満期には、額面の1,000万円が戻ってくる。

::point メモ ― 償却原価法
満期保有目的債券を額面と違う価格で買ったとき、その差額（金利の調整の分）を、満期までの期間に配分して、毎期の帳簿価額と有価証券利息に加減する方法を**償却原価法**という。2級では、毎期同じ額を配分する定額法で計算する。
::

::example 満期保有目的の国債を、償却原価法で評価する
前期の7月1日に、満期保有目的で国債（額面10,000,000円、期間5年、年利率0.6%）を9,800,000円で購入した。当期の決算（6月30日）で、償却原価法（定額法）を適用する。利息60,000円は、当期に受け取りずみである。
::answer
::journal 償却原価法：(10,000,000円－9,800,000円)÷5年
満期保有目的債券 40,000 | 有価証券利息 40,000
::
当期の有価証券利息は、受け取った利息60,000円と償却額40,000円の合計100,000円。満期保有目的債券の帳簿価額は、前期末の9,840,000円から9,880,000円になる。
::trap
満期保有目的債券は、決算日の時価で評価しない。期中に買ったときは、償却額を月割で計算する（持っていた月数÷満期までの月数）。
::
::
::

## 越後物産の株 ― その他有価証券と、全部純資産直入法

越後物産は、蔵の酒を県内の酒屋に卸してくれる、いちばん古い取引先だ。父は、取引の関係のために、越後物産の株を2万株、3,000万円で持っていた。6月30日の時価は3,300万円。
売るために持っているわけでも、満期があるわけでも、支配しているわけでもない。こういう株は**その他有価証券**になる。時価で評価するが、評価差額は損益に入れず、純資産の部の**その他有価証券評価差額金**に直接入れる（**全部純資産直入法**）。

::example 越後物産の株を、決算で時価に合わせた
越後物産の株式（その他有価証券、取得原価30,000,000円）の決算日の時価は33,000,000円だった。全部純資産直入法で処理する（税効果は考えない）。
::answer
::journal 時価33,000,000円との差額を、純資産の部に直接計上する
その他有価証券 3,000,000 | その他有価証券評価差額金 3,000,000
::
::journal 翌期首：評価差額を戻す（洗替法）
その他有価証券評価差額金 3,000,000 | その他有価証券 3,000,000
::
その他有価証券の評価差額は、毎期、洗替法で処理する。時価が取得原価を下回るときは、借方に「その他有価証券評価差額金」が出る（純資産のマイナス）。受け取った配当金は受取配当金（営業外収益）になる。今期、越後物産から1株50円、合計1,000,000円の配当があった。
::trap
その他有価証券の評価差額を「有価証券評価益」として損益に入れないこと。税効果会計を適用する問題では、評価差額の一部を繰延税金負債（または資産）にする（第21章）。
::
::
::

澪：「300万円上がっていても、利益にはならないんですね」
椎名：「売るまでは、利益として確定していませんから。純資産の部で、上がったことだけを示しておくんです」

## 芹沢酒造の60% ― 子会社株式と関連会社株式

最後に、澪は芹沢酒造の契約書を広げた。ほかの会社の議決権の過半数を持つなどして、その会社の意思決定を支配しているとき、その会社を**子会社**といい、持っている株を**子会社株式**とする。支配はしていないが、議決権の20%以上を持つなどして重要な影響を与えている会社の株は、**関連会社株式**とする。
子会社株式・関連会社株式は、会社を支配したり、大きな影響を与えたりするために持つもので、売るつもりがない。だから、期末に時価で測り直さず、**取得原価のまま**置く。

::example 芹沢酒造の株式の取得と、期末の評価
(1) 前期の6月30日、芹沢酒造の発行済株式の60%を36,000,000円で取得し、普通預金から支払った。
(2) 当期の決算日（6月30日）、芹沢酒造の株式の時価は分からない。
::answer
::journal (1) 前期：議決権の過半数を取得したので、子会社株式
子会社株式 36,000,000 | 普通預金 36,000,000
::
(2) 子会社株式は、取得原価のまま評価するので、仕訳はない。当期の貸借対照表にも、36,000,000円のまま載る。
::trap
子会社株式・関連会社株式を、時価で評価替えしないこと。売買目的の株と同じように評価損益を計上する誤りが多い。ただし、子会社の財政状態が大きく悪化したときの評価の切下げ（減損）は1級の範囲だ。
::
::
::

::table 6月30日の汐見酒造の有価証券（単位：万円）
| 有価証券 | 分類 | 取得原価 | 6月30日の帳簿価額 | 評価差額の行き先 |
| 国債（額面1,000万円） | 満期保有目的債券 | 980 | 988 | 償却額4万円は有価証券利息 |
| 越後物産の株 | その他有価証券 | 3,000 | 3,300 | 300万円はその他有価証券評価差額金（純資産） |
| 芹沢酒造の株（60%） | 子会社株式 | 3,600 | 3,600 | なし |
::

澪は、3つの有価証券を表に並べて、ようやく分かった。同じ「株」や「債券」でも、持つ目的が違えば、帳簿の値段も、差額の行き先も違う。そして、父が買った3,600万円の株は、値上がりを待つためのものではなかった。

::solve 父が買ったのは、芹沢酒造という会社そのものだった。3,600万円は、取得原価のまま載る
父は、2026年6月30日に、隣町の芹沢酒造の株式の60%を3,600万円で買っていた。議決権の過半数を持つので、芹沢酒造は汐見酒造の**子会社**になり、株は**子会社株式**として、取得原価の3,600万円のまま貸借対照表に載っている。前期の貸借対照表から、ずっと。
もし澪の思ったとおり、全部の有価証券を時価で測り直して差額を利益にしていたら、越後物産の株の300万円の値上がりを利益に入れ、芹沢酒造の株の値段も勝手に付け替えて、ルールに反する決算書を作っていた。
**有価証券の値段は、持つ目的で決まる。**そして、子会社株式の1行は、値段ではなく、父がほかの会社を支配したという事実を告げていた。なぜ父は、借金を抱える隣の蔵を買ったのか。その答えは、まだ手帳の別の行に隠れている。
::

### 試験で狙われるパターン ― 分類の判断・期中の償却原価法・評価差額のマイナス

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 分類を、持つ目的と持ち株の割合で判断する**　「売買目的で」「満期まで保有する目的で」「議決権の60%を取得して支配した」「取引関係の維持のため」など、問題文の言葉で4つに分ける。議決権の20%以上50%以下で重要な影響があれば関連会社株式。

**② 期中に買った満期保有目的債券**　償却額は、持っていた月数で按分する。たとえば10月1日に5年の債券を買い、3月31日に決算なら、1年目の償却額は(額面－取得原価)×6か月÷60か月。

**③ その他有価証券の時価が取得原価を下回る**　「その他有価証券評価差額金／その他有価証券」と、評価差額金が借方に出る。損益にはしない（全部純資産直入法）。

::steps 解法の型 ― 有価証券の期末の評価
1. 分類する | 売買目的・満期保有目的・子会社と関連会社・その他
2. 売買目的 | 時価に合わせ、差額は有価証券評価損益（切放法か洗替法かを確かめる）
3. 満期保有目的 | 償却原価法（定額法）。(額面－取得原価)×当期の月数÷満期までの月数を有価証券利息へ
4. 子会社・関連会社 | 取得原価のまま。仕訳なし
5. その他 | 時価に合わせ、差額はその他有価証券評価差額金（純資産）。翌期首に戻す
::

## 商社の先輩の電話 ― 同じ出来事が、片方で利益、片方で損失

::scene 6月19日、夜 ― ビデオ通話
澪が有価証券の分類の話をすると、画面の向こうの桐生は、財務部の先輩を通話に呼んでくれた。
先輩：「いい質問だ。ちょうどいい例がある。アマゾンと、例のAIの会社だよ」
先輩：「同じ1つの出来事が、片方では何兆円もの利益になって、もう片方では何兆円もの損失になっている」
::

AI企業 Anthropic に早くから出資してきたアマゾンは、2025年7〜9月期の決算で、Anthropic への投資から生じた税引前の利益**95億ドル**を、営業外の収益に計上した。株を売ったわけではない。Anthropic がより高い企業価値で資金を集めたことで、アマゾンが持つ株式の評価額が上がったのだ。2026年4〜6月期には、主に Anthropic への投資から生じた**534億ドル**の営業外の利益を計上した。この四半期のアマゾンの営業利益は275億ドル、当期純利益は626億ドル。本業の利益の2倍近い「評価の上の利益」が、純利益を押し上げていた。
一方、序章で見たとおり、Anthropic の2025年の損益計算書には、**343億ドル**の評価の損失が載っていた。届出書は、その原因を、企業価値の上昇で、将来その会社の株に変わる約束の借入れ（転換約束手形など）の公正価値が上がったことだと説明している。
先輩：「会社の価値が上がると、株を持つ側から見れば資産の価値が上がる。その会社から見れば、将来、価値の上がった株を渡す約束の重さが増す。同じ出来事の、表と裏だ」
澪は、2つの仕訳を並べた（単位：億ドル、金額は報道と届出書の数字。勘定は仕組みを示すための仮の名前）。

::journal ① 持つ側（アマゾン、米国の会計基準）：投資の評価額の上昇を利益に
投資有価証券 95 | 投資評価益 95
::

::danger 「評価の上の利益」で決算を飾る
売買目的の株の評価益や、持ち合いの株の売却益は、本業とは関係なく利益を大きくする。決算の前に含み益のある株を売って利益を出す「益出し」や、売ってすぐ買い戻す取引は、利益の中身を見えにくくする。損益計算書では、営業利益と、営業外・特別の損益を分けて読む。

::cfo 越後物産の株を売るか ― 300万円の含み益
6月の決算を前に、営業の担当者が言った。「越後物産の株を売れば、300万円の売却益が出ます。少しでも赤字を小さくできますよ」。
**前提**
- 越後物産の株は、取得原価3,000万円、6月30日の時価3,300万円のその他有価証券
- 売れば、投資有価証券売却益300万円が計上され、今期の当期純利益が増える（税金もかかる）
- 越後物産は、県内の酒屋に蔵の酒を卸す、いちばん古い取引先だ。父と先代の社長どうしで、株を持ち合ってきた
- 毎年の配当は100万円（取得原価の3.3%）
- 7月以降の資金繰りには、今のところ余裕がある
- 越後物産の株価は、この1年で1割上がった
::choice A. 売って、売却益300万円で今期の赤字を小さくする
**△ 赤字は小さく見えるが、中身は変わらない。**売却益は一度きりで、営業利益には何の影響もない。審査で高梨は、段階ごとに読む。しかも、持ち合いの株を一方的に売れば、いちばん古い取引先との関係を損なう。
::
::choice B. 売らずに持ち続け、評価差額は純資産で示しておく
**◎ 持つ目的に合った判断だ。**取引の関係のために持つ株で、資金繰りにも余裕がある。300万円の値上がりは、売らなくても純資産の部に示される。年100万円の配当も続く。一度きりの売却益で決算を飾る理由はない。
::
::choice C. 売ってすぐに買い戻し、売却益だけを計上する
**× 実態のない取引で利益を作っている。**売ってすぐ買い戻せば、持っている株は何も変わらないのに、利益だけが出る。このような取引で利益を出すことは、決算書の信頼を損なう。
::
::choice D. 売買目的有価証券に分類を変えて、評価益300万円を損益に入れる
**× 分類は、持つ目的で決まり、都合で変えられない。**取引の関係のために持つ株を、決算の直前に売買目的に変えることは認められない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「赤字を小さくできるか」ではなく、「この株を持つ目的は何で、売ると何を得て、何を失うか」を問う。
#### 手順2　前提の数字で確かめる
売って得るのは、一度きりの売却益300万円（税金がかかる）。失うのは、年100万円の配当と、いちばん古い取引先との関係。営業利益は、どちらでも1円も変わらない。
#### 手順3　ほかの答えに引かれる理由
Aは「少しでも赤字を小さく」という焦りに、Cは「株は手元に残る」という安心に、Dは「ルールの中で評価益を出せる」という誤解に引かれる。株価が1年で1割上がったことは、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **有価証券の扱いは、持つ目的で決まる**：目的が変わらないのに、決算のために分類や売買を変えない
- **一度きりの利益は、読む人に割り引かれる**：営業利益を変えない取引で、決算の見出しを飾らない
#### 前提が変われば
7月以降の資金繰りが苦しく、借入れより株を売るほうが安く資金を作れるなら、売る理由がある。そのときは、越後物産に事情を説明し、関係を保ったまま売る方法を相談する。
::

::exam 有価証券の急所
- 4つの分類：売買目的（時価・損益）、満期保有目的（償却原価）、子会社・関連会社（**取得原価**）、その他（時価・**純資産**）
- 取得原価には手数料を含める。端数利息は取得原価に入れず、有価証券利息で処理する
- 満期保有目的債券の償却原価法（定額法）：差額×当期の月数÷満期までの月数を有価証券利息に加える
- その他有価証券の評価差額は**その他有価証券評価差額金**（全部純資産直入法）で、翌期首に戻す
- 売買目的有価証券は切放法か洗替法かで、翌期の帳簿価額が変わる
::

::next 子会社を持ったら、連結へ
子会社株式を持つ会社は、親会社として、子会社を含めたグループ全体の決算書（連結財務諸表）を作る。第25章・第26章では、父が買った芹沢酒造を連結する。1級では、関連会社に持分法を使う方法や、有価証券の減損、外貨建ての有価証券の換算を学ぶ。
::

::summary
- 有価証券は、売買目的・満期保有目的・子会社と関連会社・その他の4つに分類する
- 売買目的有価証券は時価で評価し、差額は損益にする
- 満期保有目的債券は償却原価法（定額法）で評価し、差額の配分は有価証券利息にする
- 子会社株式・関連会社株式は取得原価のまま評価する
- その他有価証券は時価で評価し、差額は純資産のその他有価証券評価差額金にする（全部純資産直入法）
::
