赤字の年だから、法人税はかからない。7万円は、利益がなくても会社の規模に応じてかかる、住民税の**均等割**だと椎名は言った。そこまではいい。
分からないのは、その下の「法人税等調整額 △300万円」だ。税金の欄がマイナスになり、そのぶん当期純損失が300万円小さくなっている。
澪：「300万円、税金が戻ってくるんですか」
椎名：「いいえ。1円も戻ってきません」
澪：「じゃあ、赤字を小さく見せるための数字ですか」
椎名：「この300万円は、蔵の資産です。将来、蔵が利益を出せれば、ですが」
**税金を払わない赤字の年に、なぜ税金の欄が「マイナス300万円」になるのか？**

## 法人税、住民税及び事業税 ― 1年分の税金の流れ

会社の利益（所得）にかかる税金は、法人税・住民税・事業税だ。損益計算書では、まとめて**法人税、住民税及び事業税**（法人税等）と表示する。
利益の出ている会社は、期の途中で、前の年の税額の半分などを先に納める（**中間納付**）。決算で1年分の税額が決まったら、中間納付の分を差し引いた残りを、決算日から2か月以内に納める（**確定申告**）。

::example 法人税等の流れを仕訳する
(1) 中間申告で、法人税等の中間納付額1,500,000円を普通預金から納付した。
(2) 決算で、当期の法人税等が3,800,000円と計算された。
(3) 確定申告で、未払法人税等を普通預金から納付した。
::answer
::journal (1) 中間納付は、1年分の税額が確定するまで仮払法人税等
仮払法人税等 1,500,000 | 普通預金 1,500,000
::
::journal (2) 中間納付額を差し引いた残りを未払法人税等
法人税、住民税及び事業税 3,800,000 | 仮払法人税等 1,500,000
 | 未払法人税等 2,300,000
::
::journal (3)
未払法人税等 2,300,000 | 普通預金 2,300,000
::
中間納付額が1年分の税額より多ければ、差額は戻ってくる。そのときは、(2)で「未収還付法人税等」（資産）を計上する。
::trap
中間納付のときに「法人税、住民税及び事業税」（費用）を使わないこと。1年分の税額が決まるまでは、仮払法人税等（資産）にしておく。
::
::
::

## 会計の利益と、税金の所得 ― 課税所得

澪：「税金は、利益に税率を掛ければいいんですよね。赤字なら0円」
椎名：「税率を掛けるのは、会計の利益ではありません。税法のルールで計算した**課税所得**です」

::theory 益金・損金と、加算・減算
- 会計の**収益**にあたるのが税法の**益金**、会計の**費用**にあたるのが**損金**。課税所得＝益金－損金
- 会計では費用でも、税法では今期の損金にならないもの（**損金不算入**）がある。例：賞与引当金・退職給付引当金・修繕引当金などの繰入額（実際に払ったときに損金になる）、税法の限度を超える貸倒引当金の繰入額や減価償却費（**減価償却超過額**）
- 申告では、会計の利益から出発し、損金不算入額などを**加算**し、益金不算入額などを**減算**して、課税所得を求める
::

::example 汐見酒造の課税所得を計算する
税引前当期純損失は17,200,000円。次の損金不算入額がある（当期に繰り入れた額から、当期に取り崩して損金になった額を差し引いた純額）。
- 賞与引当金の増加 500,000円（期首5,500,000円→期末6,000,000円）
- 退職給付引当金の増加 3,000,000円（繰入4,000,000円－退職金の支払いによる取崩し1,000,000円）
- 修繕引当金の増加 3,000,000円
- 貸倒引当金の繰入のうち、税法の限度を超える額 500,000円
- 減価償却超過額 3,000,000円
::answer
課税所得＝△17,200,000円＋(500,000円＋3,000,000円＋3,000,000円＋500,000円＋3,000,000円)＝**△7,200,000円**
課税所得がマイナス（欠損）なので、法人税はかからない。住民税の均等割70,000円だけを、法人税、住民税及び事業税として計上する（今期は中間納付がなかったものとする）。
::journal 決算：法人税、住民税及び事業税
法人税、住民税及び事業税 70,000 | 未払法人税等 70,000
::
実際の申告には、研究用の機器を税法では資産として扱うなど、ほかの調整もある。ここでは、2級で問われる引当金と減価償却の差異に絞って示した。
::trap
加算・減算の向きを逆にしないこと。会計で費用にしたが税法では損金にならない額は、会計の利益に**加える**。
::
::
::

## 税効果会計 ― 会計と税金の「時期のずれ」を直す

ここで、加算した1,000万円の中身を見直してみよう。賞与引当金は、7月に賞与を払えば損金になる。退職給付引当金は、小松の退職金を払えば損金になる。修繕引当金は、修繕したときに損金になる。どれも、会計では**今期**の費用、税法では**将来**の損金だ。費用になるかならないかではなく、**いつ**費用になるかの違いにすぎない。
このような、会計と税法の時期のずれを**一時差異**という。

::theory 税効果会計
会計と税法で、費用や収益を計上する時期がずれると、損益計算書の「税引前の利益」と「税金」が対応しなくなる。そこで、一時差異に税率を掛けた額を、税金の前払いや後払いのように調整する。これを**税効果会計**という。
- **将来減算一時差異**（今期は損金にならず、将来、損金になる差異。引当金・減価償却超過額など）：将来の税金を減らす効果があるので、一時差異×税率を**繰延税金資産**（資産）とし、相手を**法人税等調整額**（損益計算書の税金の欄で差し引く）とする
- **将来加算一時差異**（将来、課税所得を増やす差異）：一時差異×税率を**繰延税金負債**（負債）とする
- 一時差異が解消したら（賞与を払った、退職金を払った）、繰延税金資産を取り崩し、法人税等調整額を逆に計上する
2級では、引当金・減価償却・その他有価証券の一時差異に限って出題される。
::

::example 税効果会計を仕訳する（法定実効税率30%）
(1) 6月30日、当期に増加した将来減算一時差異10,000,000円について、税効果を適用した。
(2) 翌期の7月10日、賞与を支給した（賞与引当金6,000,000円の取崩しにより、将来減算一時差異6,000,000円が解消した）。
::answer
::journal (1) 10,000,000円×30%
繰延税金資産 3,000,000 | 法人税等調整額 3,000,000
::
::journal (2) 解消した一時差異の分を取り崩す：6,000,000円×30%
法人税等調整額 1,800,000 | 繰延税金資産 1,800,000
::
(1)の法人税等調整額は貸方なので、損益計算書の税金の欄で**差し引く**（マイナスとして表示する）。(2)は借方なので、翌期の税金の欄に**加える**。
::trap
期首と期末の一時差異が示されたときは、その**差額**（増えた分）にだけ税率を掛けて仕訳する。期末の残高にまるごと税率を掛けて、繰延税金資産を二重に計上しないこと。
::
::
::

## 越後物産の株 ― その他有価証券の税効果

第18章で、越後物産の株の値上がり300万円を、その他有価証券評価差額金として純資産に計上した。この300万円は、将来、株を売れば課税所得を増やす**将来加算一時差異**だ。

::example 越後物産の株（その他有価証券）を、税効果を適用して評価替えする（法定実効税率30%）
取得原価30,000,000円、期末の時価33,000,000円。全部純資産直入法による。
::answer
::journal 評価差額3,000,000円のうち30%は繰延税金負債、残りが評価差額金
その他有価証券 3,000,000 | 繰延税金負債 900,000
 | その他有価証券評価差額金 2,100,000
::
その他有価証券の評価差額は損益計算書を通らないので、税効果も**法人税等調整額を使わず**、評価差額金から直接差し引く。時価が取得原価を下回るときは、借方に「繰延税金資産」と「その他有価証券評価差額金」が出る。
::trap
翌期首の洗替えでは、評価差額金だけでなく、繰延税金負債（資産）の部分も戻す。
::
::
::

その夜、澪は、決算書の案を持って、リハビリの病院に行った。父は、右手で紙を押さえ、左手の指で、税金の欄の「△300」をなぞった。それから、ゆっくりと言った。
父：「……来年。……税金を、払える蔵に、しろ」
帰りの車の中で、澪は、その言葉の意味が分かった。

::solve 法人税等調整額△300万円は、今期の費用で、将来の税金が減る分。その値打ちは、将来、税金を払えるほど稼げるかで決まる
汐見酒造は今期、引当金と減価償却で、税法より1,000万円多く費用を計上した。この1,000万円は、将来、賞与や退職金や修繕を払ったときに、税法でも損金になる。そのとき、課税所得が1,000万円小さくなり、税金が1,000万円×30%＝**300万円**少なくなる。
税効果会計は、この「将来の税金の減少」を、原因の費用を計上した今期に、**繰延税金資産**として先に計上する。相手の法人税等調整額は、損益計算書の税金の欄でマイナスになる。

::table 税効果会計がない場合とある場合（単位：万円）
| 項目 | 税効果なし | 税効果あり |
| 税引前当期純損失 | △1,720 | △1,720 |
| 法人税、住民税及び事業税 | 7 | 7 |
| 法人税等調整額 | ― | △300 |
| 当期純損失 | △1,727 | △1,427 |
::

300万円は、今期に戻ってくるお金ではない。将来、利益が出て税金を払うとき、そのぶん少なく払えるという**見込み**だ。だから、税金を払う年が来なければ、1円にもならない。
父の言葉は、そのことだった。**繰延税金資産を本物の資産にする方法は、1つしかない。税金を払えるほど、稼ぐことだ。**
::

### 試験で狙われるパターン ― 課税所得・差額の仕訳・評価差額・表示

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 課税所得と法人税等を求める**　税引前当期純利益に、損金不算入額（貸倒引当金の超過額、減価償却超過額など）を加算して課税所得を出し、税率を掛ける。

**② 期首と期末の一時差異から、差額だけを仕訳する**　期首の一時差異4,000万円、期末5,000万円なら、増えた1,000万円×30%＝300万円だけ「繰延税金資産／法人税等調整額」。減っていれば逆の仕訳になる。

**③ その他有価証券の税効果**　評価差額×税率を繰延税金負債（評価差損なら繰延税金資産）にし、残りを評価差額金に。法人税等調整額は使わない。

**④ 表示**　貸借対照表では、繰延税金資産と繰延税金負債を相殺して、純額を**投資その他の資産**（または**固定負債**）に表示する。損益計算書では、法人税、住民税及び事業税のすぐ下に、法人税等調整額を加減する。

::steps 解法の型 ― 税金と税効果
1. 課税所得 | 税引前当期純利益＋加算（損金不算入など）－減算（益金不算入など）
2. 法人税等 | 課税所得×税率。中間納付（仮払法人税等）を差し引いた残りを未払法人税等
3. 一時差異の増減 | 期末－期首の差額×税率。増えたら「繰延税金資産／法人税等調整額」、減ったら逆
4. その他有価証券 | 評価差額×税率を繰延税金負債（資産）に。法人税等調整額は使わない
5. 表示 | 繰延税金資産と負債は相殺して固定の区分へ。損益計算書は法人税等の下で調整額を加減
::

## 信用金庫の研修の話 ― 「3年分しか認めない」と言われた銀行

::scene 7月7日、水曜日 ― 越後みなと信用金庫の応接室
審査の前の、最後の打ち合わせ。決算書の案の説明が、繰延税金資産の行に来たとき、高梨の表情が変わった。
高梨：「澪さん、この1,500万円。私たちが入庫したときの研修で、必ず教わる話があるんです。2003年の、りそな銀行の話です」
澪：「繰延税金資産で、ですか」
高梨：「繰延税金資産で、です。大手の銀行が、それで公的資金を受けることになった」
::

2003年5月、大手銀行のりそな銀行に、預金保険法にもとづく公的資金の注入が決まった。金融危機対応会議の答申によれば、同行の自己資本比率は、健全な銀行の目安である4%を大きく下回る**2%程度**に下がる見込みだった。6月10日、金融庁は**1兆9,600億円**の資本増強を決定した。
自己資本比率を一気に押し下げたのは、繰延税金資産だった。当時の銀行は、不良債権の処理で巨額の引当金を積んでいた。引当金は、将来、貸倒れが確定すれば税法でも損金になる。その税効果を繰延税金資産として計上し、自己資本の大きな部分がそれで占められていた。
高梨：「繰延税金資産に値打ちがあるのは、将来、税金を払う利益が出る場合だけです。りそなの監査を担当した監査法人は、将来の利益の見込みを厳しく見て、繰延税金資産を**3年分**の見込みの利益に対応する額に限りました。それまでの計上額との差が、資産と自己資本から削られたんです」
澪は、この章の勘定で、その仕組みを確かめた。仮に、ある銀行が繰延税金資産4,000億円を計上していて、監査の結果、将来の利益で回収できる見込みが2,000億円分しかないと判断されたとする（仕組みを示すための例、単位：億円）。

::journal 回収できない見込みの繰延税金資産を取り崩す
法人税等調整額 2,000 | 繰延税金資産 2,000
::

法人税等調整額は借方なので、損益計算書の税金の欄が2,000億円増え、当期純損失が2,000億円膨らむ。お金は1円も動いていない。だが、純資産（自己資本）は2,000億円減る。
澪：「2級の試験では、この回収できるかどうかの判断は問われないんですよね」
高梨：「試験では。でも私たちは、繰延税金資産がある会社を見たら、必ず聞きます。この会社は将来、本当に税金を払えるほど利益を出せるのか、と。今日、私が澪さんに聞いているのも、それです」

::note
出典：[金融庁「株式会社りそな銀行に対する資本増強の決定等について」（2003年6月10日）](https://www.fsa.go.jp/news/newsj/14/ginkou/f-20030610-1.html)、[金融庁「第1回金融危機対応会議 議事要旨」（2003年5月17日）](https://www.fsa.go.jp/singi/kinyukiki/gijiroku/20030517.html)、[新日本法規「りそな銀行、公的資金の注入へ 繰延税金資産の評価を巡り、監査法人と対立」（2003年6月2日）](https://www.sn-hoki.co.jp/article/tamasters/ta578/)
::

::danger 繰延税金資産で、純資産を厚く見せる
繰延税金資産は、将来の利益の見込みしだいで大きくも小さくもなる。見込みを甘くすれば、資産と純資産は厚く見え、当期純損失は小さく見える。赤字が続く会社の繰延税金資産は、決算書の中でいちばん疑ってかかるべき資産の1つだ。読む側は、純資産のうち繰延税金資産がどれだけを占めているかを確かめる。
::

::cfo 繰延税金資産1,500万円を、高梨にどう説明するか
審査の前の晩、岩倉が心配そうに言った。「赤字なのに、繰延税金資産が300万円増えて1,500万円。銀行から見たら、ごまかしに見えませんか」。
**前提**
- 将来減算一時差異は、期首4,000万円から期末5,000万円に増えた（引当金と減価償却超過額）
- 繰延税金資産（30%）は、期首1,200万円から期末1,500万円になった
- 今期の課税所得はマイナスで、法人税は0円
- 来期からの計画では、課税所得は毎年1,000万〜2,000万円
- 一時差異が解消する時期は、賞与（7月）、タンクの修繕（2028年の夏）、小松の退職金（2029年3月）など
- 法人税、住民税及び事業税は、住民税の均等割の7万円だけ
::choice A. 会計のルールどおりに計上したものなので、特に説明はいらないと伝える
**△ ルールは守っているが、それだけでは足りない。**繰延税金資産は、将来の課税所得の見込みの上に成り立つ。赤字の年に資産が増えれば、融資の担当者は当然、その見込みを問う。説明のない繰延税金資産は、りそなの例のように「本当に回収できるのか」と疑われる。
::
::choice B. 誤解を避けるため、今期だけ税効果会計を適用しないで決算書を作る
**× 会計の方針を、その年の見え方で変えることになる。**税効果会計を外せば当期純損失は1,727万円になり、見かけは「慎重」だが、費用と税金の対応がずれた損益計算書は、かえって正しい姿を映さない。方針は継続して使うもので、都合で外すものではない。
::
::choice C. 一時差異が解消する時期と、その時期の課税所得の見込みを並べて説明する
**◎ 繰延税金資産の値打ちの根拠そのものを示している。**7月の賞与600万円は、来期にすぐ解消する。来期の課税所得が計画どおり1,000万円以上出れば、その税金を減らすのに使える。修繕や退職金のような先のものは、それまでの見込みで説明する。そのうえで「来期以降も赤字なら、この1,500万円は値打ちを失う」と正直に伝える。
::
::choice D. 繰延税金資産は「税金の前払い」で、いつでも現金に戻せる資産だと説明する
**× 事実と違う。**繰延税金資産は、国に先に払ったお金ではなく、将来の税金が減るという見込みだ。課税所得が出なければ、1円にもならない。現金のような資産だと説明すれば、見込みが外れたときに、決算書全体の信頼を失う。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「繰延税金資産は正しく計上されているか」ではなく、「この1,500万円は、将来、本当に税金を減らせるのか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 一時差異が解消する時期と、税金が減る額（見込み、単位：万円）
| 解消するもの | 時期 | 一時差異 | 減る税金（30%） |
| 夏の賞与 | 2027年7月 | 600 | 180 |
| タンクの修繕（引当金の残高） | 2028年の夏 | 600 | 180 |
| 小松の退職金（引当金のうち小松の分） | 2029年3月 | 1,100 | 330 |
::
来期の賞与の600万円は、来期の課税所得が600万円以上あれば、すぐに180万円の税金を減らす。計画の1,000万〜2,000万円が出れば足りる。遠い時期のものほど、見込みの確かさが問われる。
#### 手順3　ほかの答えに引かれる理由
Aは「ルールを守っている」という安心に、Bは「保守的に見せたほうが安全」という思い込みに、Dは「資産と言うからにはお金だ」という誤解に引かれる。法人税等が均等割の7万円だけということは、繰延税金資産の値打ちとは関係のない前提だ。
#### 持ち帰る考え方
- **繰延税金資産の値打ちは、将来の課税所得で決まる**：だから、その説明は、会社の将来の稼ぐ力の説明と同じになる
- **赤字の会社ほど、根拠を自分から示す**：解消の時期と、その時期の利益の見込みを並べる
#### 前提が変われば
来期以降も赤字が続く見込みなら、繰延税金資産は取り崩す（法人税等調整額を借方に計上する）ことになる。その判断は1級の範囲だが、銀行は2級の段階からそこを見ている。
::
::

::exam 税金と税効果会計の急所
- 中間納付は**仮払法人税等**。決算で「法人税、住民税及び事業税／仮払法人税等・未払法人税等」
- 課税所得＝税引前当期純利益＋加算（損金不算入・益金算入）－減算（益金不算入・損金算入）
- **将来減算一時差異×税率＝繰延税金資産**、相手は**法人税等調整額**（貸方なら税金の欄でマイナス）。解消したら逆の仕訳
- 期首と期末が示されたら、**差額**だけ仕訳する
- **その他有価証券**：評価差額×税率を繰延税金負債（資産）とし、法人税等調整額は使わない。翌期首の洗替えでは、税効果の部分も戻す
- 貸借対照表では、繰延税金資産と繰延税金負債を相殺して、**投資その他の資産**または**固定負債**に表示する
::

::next 税金と税効果会計の先にある論点
1級では、繰延税金資産の**回収可能性**の判断、繰越欠損金の税効果、永久差異と一時差異の区別、税率の変更などを学ぶ。また、消費税の会計処理（税抜方式・税込方式）や源泉所得税の扱いなど、税金の会計は実務の土台になる。
::

::summary
- 法人税等は、中間納付を仮払法人税等、決算の残額を未払法人税等とする。損益計算書では「法人税、住民税及び事業税」
- 課税所得は、会計の利益に損金不算入額などを加算し、益金不算入額などを減算して求める
- 一時差異に税率を掛け、将来減算一時差異は繰延税金資産、将来加算一時差異は繰延税金負債とし、相手は法人税等調整額（その他有価証券は評価差額金から直接差し引く）
- 法人税等調整額がマイナスでも、税金が戻ってくるわけではない。将来の税金が減る見込みを、今期に先に計上しているだけ
- 繰延税金資産の値打ちは、将来の課税所得しだい。見込みが崩れれば消える
::
