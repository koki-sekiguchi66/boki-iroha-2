## 法人税、住民税及び事業税 ― 1年分の税金の流れ

会社の利益（所得）にかかる税金は、法人税・住民税・事業税だ。損益計算書では、まとめて**法人税、住民税及び事業税**（法人税等）と表示する。

::example 法人税等の取引を仕訳しなさい
(1) 中間申告で、法人税等の中間納付額1,500,000円を普通預金から納付した。
(2) 決算で、当期の法人税等が3,800,000円と計算された。
(3) 確定申告で、未払法人税等を普通預金から納付した。
::answer
::journal (1) 中間納付は、確定するまで仮払法人税等
仮払法人税等 1,500,000 | 普通預金 1,500,000
::
::journal (2) 中間納付額を差し引いた残りを未払法人税等
法人税、住民税及び事業税 3,800,000 | 仮払法人税等 1,500,000
 | 未払法人税等 2,300,000
::
::journal (3)
未払法人税等 2,300,000 | 普通預金 2,300,000
::
中間納付額が年間の税額より多ければ、差額は還付される。そのときは、(2)で「未収還付法人税等」（資産）を計上する。
::
::

## 会計の利益と、税金の所得

法人税は、損益計算書の利益にそのまま税率を掛けて計算するのではない。税法のルールで計算した**課税所得**に、税率を掛ける。

::theory 益金・損金と、加算・減算
- 会計の**収益**に対応するのが税法の**益金**、会計の**費用**に対応するのが**損金**。課税所得＝益金－損金
- 会計では費用でも、税法では損金にならないもの（**損金不算入**）がある。例：賞与引当金・退職給付引当金・修繕引当金などの繰入額（実際に払ったときに損金になる）、税法の限度を超える減価償却費（**減価償却超過額**）、税法の基準を超える貸倒引当金の繰入額、大企業の交際費など
- 実際の申告では、会計の利益をスタートにして、損金不算入額などを**加算**し、益金不算入額などを**減算**して、課税所得を求める
::

::example 汐見酒造の課税所得を計算しなさい
税引前当期純損失は17,200,000円。次の損金不算入額がある（当期に繰り入れた額から、当期に取り崩して損金になった額を差し引いた純額）。
- 賞与引当金の増加 500,000円
- 退職給付引当金の増加 3,000,000円（繰入4,000,000円－退職金の支払いによる取崩し1,000,000円）
- 修繕引当金の増加 3,000,000円
- 貸倒引当金の個別評価のうち、税法の基準を超える額 2,500,000円
- 減価償却超過額 1,000,000円
::answer
課税所得＝△17,200,000円＋(500,000円＋3,000,000円＋3,000,000円＋2,500,000円＋1,000,000円)＝**△7,200,000円**
課税所得がマイナス（欠損）なので、法人税はかからない。住民税の均等割など700,000円だけを、法人税、住民税及び事業税として計上する。
::journal 決算：法人税、住民税及び事業税
法人税、住民税及び事業税 700,000 | 未払法人税等 700,000
::
（中間納付はなかったものとする。）
::
::

## 税効果会計 ― 会計と税金の「時期のずれ」を直す

ここで、加算した1,000万円の中身を見直してみよう。賞与引当金は、7月に賞与を払えば損金になる。退職給付引当金は、小松が退職して退職金を払えば損金になる。修繕引当金も、修繕したときに損金になる。どれも、会計では**今期**の費用、税法では**将来**の損金だ。費用になるか、ならないかの違いではなく、**いつ**費用になるかの違いにすぎない。
このような、会計と税法の時期のずれを**一時差異**という。

::theory 税効果会計
会計と税法で費用や収益を計上する時期がずれると、損益計算書の「税引前の利益」と「税金」が対応しなくなる。そこで、一時差異に税率を掛けた額を、税金の前払いや後払いとして調整する。これを**税効果会計**という。
- **将来減算一時差異**（今期は損金にならず、将来、損金になる差異。引当金・減価償却超過額など）：将来の税金を減らす効果があるので、一時差異×税率を**繰延税金資産**（資産）とし、相手を**法人税等調整額**（損益計算書の税金の欄で差し引く）とする
- **将来加算一時差異**（将来、課税所得を増やす差異）：一時差異×税率を**繰延税金負債**（負債）とする
- 一時差異が解消したら（賞与を払った、退職金を払った）、繰延税金資産を取り崩し、法人税等調整額を逆に計上する
2級では、引当金・減価償却・その他有価証券の一時差異に限って出題される。
::

::example 税効果会計の仕訳をしなさい（法定実効税率30%）
(1) 6月30日、当期に増加した将来減算一時差異10,000,000円について、税効果を適用した。
(2) 翌期の7月10日、賞与を支給した（賞与引当金6,000,000円の取崩しにより、将来減算一時差異6,000,000円が解消した）。
::answer
::journal (1) 10,000,000円×30%
繰延税金資産 3,000,000 | 法人税等調整額 3,000,000
::
::journal (2) 解消した一時差異の分を取り崩す：6,000,000円×30%
法人税等調整額 1,800,000 | 繰延税金資産 1,800,000
::
(1)の法人税等調整額は貸方なので、損益計算書の税金の欄で**差し引く**（マイナスとして表示する）。(2)は借方なので、翌期の税金の欄に**加える**。
::
::

## 答え合わせ ― マイナス300万円は「将来の税金の減少」

::solve 法人税等調整額△300万円は、「今期の費用で、将来の税金が減る分」
汐見酒造は今期、賞与引当金・退職給付引当金・修繕引当金・貸倒引当金・減価償却費で、税法より1,000万円多く費用を計上した。この1,000万円は、将来、賞与や退職金や修繕を払ったときに、税法でも損金になる。そのとき、課税所得が1,000万円小さくなり、税金が1,000万円×30%＝**300万円**少なくなる。
税効果会計は、この「将来の税金の減少」を、原因となった費用を計上した今期に、**繰延税金資産**として先に計上する。相手の法人税等調整額は、損益計算書の税金の欄でマイナスになる。
::table 税効果会計がない場合とある場合（単位：万円）
| 項目 | 税効果なし | 税効果あり |
| 税引前当期純損失 | △1,720 | △1,720 |
| 法人税、住民税及び事業税 | 70 | 70 |
| 法人税等調整額 | ― | △300 |
| 当期純損失 | △1,790 | △1,490 |
::
300万円は、今期に戻ってくるお金ではない。将来、利益が出て税金を払うとき、そのぶん少なく払えるという**権利の見込み**だ。だから、資産になる。
::

「では、もし将来も赤字が続いて、税金を払う年が来なかったら？」
澪の問いに、椎名は少し間を置いた。「この300万円は、価値がなくなります。将来、税金を減らす相手がいないんですから」
「2級の試験では、その見込みは考えなくていいんですよね」
「試験では。でも、現実には、それで銀行が1つ潰れかけたことがあります」

## その他有価証券の税効果

第18章で、越後物産の株式の値上がり300万円を、その他有価証券評価差額金として純資産に計上した。この300万円は、将来、株を売れば課税所得になる**将来加算一時差異**だ。

::example 越後物産の株式（その他有価証券）について、税効果を適用した評価替えの仕訳をしなさい（法定実効税率30%）
取得原価30,000,000円、期末の時価33,000,000円。全部純資産直入法による。
::answer
::journal 評価差額3,000,000円のうち30%は繰延税金負債、残りが評価差額金
その他有価証券 3,000,000 | 繰延税金負債 900,000
 | その他有価証券評価差額金 2,100,000
::
その他有価証券の評価差額は損益計算書を通らないので、税効果も**法人税等調整額を使わず**、評価差額金から直接差し引く。時価が取得原価を下回るときは、借方に「繰延税金資産」と「その他有価証券評価差額金」が出る。
::
::

::exam 税金と税効果会計の急所
- 中間納付は**仮払法人税等**、決算で「法人税、住民税及び事業税／仮払法人税等・未払法人税等」
- 課税所得＝税引前当期純利益＋加算（損金不算入・益金算入）－減算（益金不算入・損金算入）
- **将来減算一時差異×税率＝繰延税金資産**、相手は**法人税等調整額**（貸方なら税金の欄でマイナス）。解消したら逆仕訳
- **その他有価証券**：評価差額×税率を繰延税金負債（資産）とし、法人税等調整額は使わない。翌期首の洗替えでは、税効果の部分も戻す
- 貸借対照表では、繰延税金資産と繰延税金負債は相殺して、**投資その他の資産**または**固定負債**に表示する
- 損益計算書：税引前当期純利益 → 法人税、住民税及び事業税 → 法人税等調整額（±）→ 当期純利益
::

## 信用金庫の新人研修 ― 「3年分しか認めない」と言われた銀行

::scene 6月29日、火曜日 ― 越後みなと信用金庫の応接室
決算の見込みの説明で、繰延税金資産の行に来たとき、高梨の表情が変わった。
「澪さん、この1,500万円。私たちが入庫したときの研修で、必ず教わる話があるんです。2003年の、りそな銀行の話です」
「繰延税金資産で、ですか」
「繰延税金資産で、です。大手の銀行が、それで公的資金を受けることになった」
::

2003年5月、大手銀行のりそな銀行に、預金保険法にもとづく公的資金の注入が決まった。金融危機対応会議の答申によれば、同行の自己資本比率は、健全な銀行の目安である4%を大きく下回る**2%程度**に低下する見込みだった。6月10日、金融庁は**1兆9,600億円**の資本増強を決定した。
自己資本比率を一気に押し下げたのは、繰延税金資産だった。当時の銀行は、不良債権の処理で巨額の引当金を積んでいた。引当金は、将来、貸倒れが確定すれば税法でも損金になる。だから、その税効果を繰延税金資産として計上し、自己資本の大きな部分がそれで占められていた。
「繰延税金資産が価値を持つのは、将来、税金を払う利益が出る場合だけです」と高梨は言った。「りそなの監査を担当した監査法人は、将来の利益の見込みを厳しく評価して、繰延税金資産の計上を**3年分**の見込みの利益に対応する額に限った。それまでの計上額との差が、資産と自己資本から削られたんです」
澪は、この章の勘定で、その仕組みを確かめた。仮に、ある銀行の将来減算一時差異が1兆円、税率40%で、繰延税金資産4,000億円を計上していたとする。監査の結果、将来の利益で回収できる見込みが2,000億円分しかないと判断されれば（仕組みを示すための例、単位：億円）、

::journal 回収できない見込みの繰延税金資産を取り崩す
法人税等調整額 2,000 | 繰延税金資産 2,000
::

法人税等調整額は借方なので、損益計算書の税金の欄が2,000億円増え、当期純損失が2,000億円膨らむ。お金は1円も動いていない。だが、純資産（自己資本）は2,000億円減る。
「2級の試験では、この回収可能性は問われないんですよね」と澪が言うと、高梨はうなずいた。
「試験では。でも、私たちは、繰延税金資産がある会社を見たら、必ず聞きます。この会社は将来、本当に税金を払えるほど利益を出せるのか、と。今日、私が澪さんに聞いているのも、それです」

::note
出典：[金融庁「株式会社りそな銀行に対する資本増強の決定等について」（2003年6月10日）](https://www.fsa.go.jp/news/newsj/14/ginkou/f-20030610-1.html)、[金融庁「第1回金融危機対応会議 議事要旨」（2003年5月17日）](https://www.fsa.go.jp/singi/kinyukiki/gijiroku/20030517.html)、[新日本法規「りそな銀行、公的資金の注入へ 繰延税金資産の評価を巡り、監査法人と対立」（2003年6月2日）](https://www.sn-hoki.co.jp/article/tamasters/ta578/)
::

::cfo 繰延税金資産300万円を、高梨にどう説明するか
決算書を高梨に出す前日、岩倉が心配そうに言った。「繰延税金資産300万円。赤字なのに資産が増えるのは、銀行から見たらごまかしに見えませんか」
::table 汐見酒造の繰延税金資産（6月30日の見込み）
| 項目 | 金額 |
| 将来減算一時差異（引当金・減価償却超過額） | 期首 4,000万円 → 期末 5,000万円 |
| 繰延税金資産（30%） | 期首 1,200万円 → 期末 1,500万円 |
| 来期以降の課税所得の見込み | 第22章の計画では、来期から毎年1,000万〜2,000万円 |
| 一時差異が解消する時期 | 賞与（7月）、タンクの修繕（2028年の夏）、小松の退職金（2029年3月）など |
::
まず、繰延税金資産1,500万円が「価値のある資産」であるための条件は何かを考えてから選んでほしい。
::choice A. 繰延税金資産は会計のルールで計上するものなので、説明はいらない
**× ルールで計上したからこそ、根拠を説明する必要がある。**繰延税金資産は、将来の課税所得の見込みの上に成り立つ。赤字の年に資産が増えれば、融資の担当者は当然、その見込みを問う。説明のない繰延税金資産は、りそなの例のように、「本当に回収できるのか」と疑われる。
::
::choice B. 一時差異が解消する時期と、その時期の課税所得の見込みを並べて説明する
**◎ 繰延税金資産の価値の根拠そのものを示している。**7月の賞与（600万円）は、来期にすぐ解消する。来期の課税所得が計画どおり1,000万円以上出れば、その税金を減らすのに使える。タンクの修繕（2028年の夏）や小松の退職金（2029年3月）のように先のものは、それまでの課税所得の見込みで説明する。
同時に、「もし来期以降も赤字なら、この1,500万円は価値を失う」とも正直に伝える。繰延税金資産は、会社の将来の稼ぐ力への賭けでもある。
::
::choice C. 誤解を避けるため、税効果会計を適用しないで決算書を作る
**× 中小企業でも、税効果会計を適用するなら、都合で外すことはできない。**税効果を適用しなければ、当期純損失は1,790万円になる。見かけの損失は大きくなるが、そのほうが「慎重」というわけではない。費用と税金の対応がずれた損益計算書は、かえって正しい姿を映さない。適用するかどうかは会社の会計方針として継続して決めるもので、その年の見え方で変えるものではない。
::
::choice D. 繰延税金資産は「税金の前払い」で、いつでも現金に戻せる資産だと説明する
**× 事実と違う。**繰延税金資産は、国に先に払ったお金ではなく、将来の税金が減るという見込みだ。課税所得が出なければ、1円にもならない。現金のような資産だと説明すれば、後で見込みが外れたときに、決算書全体の信頼を失う。
::
::answer 考え方の例を見る
繰延税金資産は、「将来、利益を出して税金を払う」という見込みの上に成り立つ。だから、その価値の説明は、会社の将来の稼ぐ力の説明と同じになる。赤字の会社ほど、繰延税金資産の根拠を問われる。
澪は、決算書の説明資料に、一時差異が解消する時期の表を1枚加えた。そして、その表の最後に1行を書いた。「来期の課税所得の見込みの根拠は、第22章の資料（売上総利益の改善と、研究開発・立ち上げ費用の一巡）による」。
::
::

::next 税金と税効果会計の先にある論点
1級では、繰延税金資産の**回収可能性**の判断、繰越欠損金の税効果、永久差異と一時差異の区別、税率の変更、法人税等の申告調整のより詳しい計算などを学ぶ。また、消費税の会計処理（税抜方式・税込方式）や、源泉所得税の扱いなど、税金の会計は実務の土台になる。

課税所得＝5,000,000円＋200,000円＋300,000円＝**5,500,000円**。法人税等＝5,500,000円×30%＝**1,650,000円**。
税効果会計を適用すると、将来減算一時差異500,000円×30%＝150,000円を「繰延税金資産／法人税等調整額」で計上し、損益計算書の税金は1,650,000円－150,000円＝1,500,000円（税引前当期純利益の30%）になる。

::summary
- 法人税等は、中間納付を仮払法人税等、決算の残額を未払法人税等とする。損益計算書では「法人税、住民税及び事業税」
- 課税所得は、会計の利益に損金不算入額などを加算し、益金不算入額などを減算して求める
- 会計と税法の時期のずれ（一時差異）に税率を掛け、将来減算一時差異は繰延税金資産、将来加算一時差異は繰延税金負債とし、相手は法人税等調整額（その他有価証券は評価差額金から直接差し引く）
- 法人税等調整額がマイナスでも、税金が戻ってくるわけではない。将来の税金が減る見込みを、今期に先に計上しているだけ
- 繰延税金資産の価値は、将来の課税所得しだい。見込みが崩れれば消える
::
