10月の終わり、統一試験の3週間前。澪は、付録Dの模擬試験を90分で解いた。62点。
工業簿記は36点。満点の40点に近い。なのに、商業簿記の第2問は4点、第3問は9点だった。第3問は、決算整理事項の4つ目で時間が尽きていた。

**同じ知識で、合否を分けるものは何か？**

## 試験の基本

::table 日商簿記2級の試験の概要
| 項目 | 内容 |
| 試験方式 | 統一試験（ペーパー試験。例年6月・11月・2月）／ネット試験（テストセンターで随時） |
| 試験時間 | 90分 |
| 試験科目 | 商業簿記、工業簿記（原価計算を含む）。5題以内 |
| 合格基準 | 70%以上 |
| 合格率 | 統一試験 23.6%（第171回）、15.1%（第172回）、15.1%（第173回）／ネット試験 32.9%（2025年度）、31.9%（2026年4〜6月） |
::

::note
出典：[日本商工会議所「受験者データ」](https://www.kentei.ne.jp/bookkeeping/candidate-data)（2026年11月14日に確認）。受験の前に、必ず日本商工会議所と受験地の商工会議所の最新の情報を確かめること。
::

::table 統一試験とネット試験の違い
| 項目 | 統一試験 | ネット試験 |
| 日程 | 年3回の決まった日 | テストセンターで、都合のよい日時を予約 |
| 解答 | 紙の問題用紙と答案用紙 | パソコンの画面で入力（勘定科目は選択式） |
| 合否 | 後日、受験地の商工会議所が発表 | 試験の終了後、その場で採点 |
| 向いている人 | 下書きを紙に大きく書きたい人 | 日程を自分で決めたい人、早く結果を知りたい人 |
::

## 大問ごとの型と配点

公式には配点の内訳は示されていないが、一般的な出題の型は次のとおりだ。

::table 一般的な出題の型（配点は目安）
| 大問 | 分野 | 主な出題 | 配点の目安 |
| 第1問 | 商業簿記 | 仕訳5問。ほぼすべての論点から出る | 20点 |
| 第2問 | 商業簿記 | 個別の論点（連結精算表、株主資本等変動計算書、有価証券・固定資産の勘定記入、銀行勘定調整表、理論の穴埋めなど） | 20点 |
| 第3問 | 商業簿記 | 損益計算書・貸借対照表の作成、精算表、決算整理後残高試算表、本支店、製造業の決算など | 20点 |
| 第4問 | 工業簿記 | (1) 仕訳3問、(2) 個別・総合・部門別原価計算、製造原価報告書など | 28点 |
| 第5問 | 工業簿記 | 標準原価計算の差異分析、直接原価計算・CVP分析など | 12点 |
::

::kpi 合格ラインの作り方（例）
第1問 | 16点／20点 | 仕訳5問中4問
第2問 | 10点／20点 | 半分取れれば十分
第3問 | 14点／20点 | 決算整理の7割を正確に
第4問・第5問 | 36点／40点 | 工業簿記で9割
合計 | 76点 | 70点の合格ラインを超える
::

::theory 工業簿記で36点を「固める」
工業簿記（第4問・第5問）は、出題の型が少なく、手順どおりに解けば満点に近い点が取れる。工業簿記で36点を取れれば、商業簿記は60点中34点で合格に届く。
本書の第1部を、勘定の流れの図（第1章）と、ボックス図（第7章・第9章）を自分で描きながら、何度も解き直そう。
::

## 90分の時間配分と、解く順番

::steps おすすめの解く順番（合計90分）
1. 第1問（約15分） | 仕訳5問で20点。1問3分。迷ったら印をつけて先へ進む
2. 第4問（約20分） | 工業簿記は型が決まっていて満点を狙える。仕訳3問と計算問題
3. 第5問（約12分） | 差異分析・CVPは、図と公式どおりに解けば満点が取れる
4. 第3問（約25分） | 決算整理事項を1つずつ仕訳して、試算表の横にメモしていく
5. 第2問（約13分） | 論点によって難しさの差が大きい。解ける設問から確実に
6. 見直し（約5分） | 第1問の勘定科目名、計算問題の単位（千円・円）
::

::point なぜ第2問を最後にするのか
第2問は、連結精算表、株主資本等変動計算書、理論の穴埋めなど、回によって形が大きく変わる。最初に手をつけて時間を取られると、型の決まった第3問の時間がなくなる。澪の62点は、この順番の失敗だった。
::

## 第1問の攻略 ― 仕訳5問

::exam 第1問で点を落とさない5つの鉄則
- 勘定科目は、問題文の「勘定科目の一覧」から選ぶ。一覧にない科目を書かない
- 「営業外」かどうかを確かめる。設備の売買の電子記録債権・債務は**営業外電子記録債権・債務**
- 2027年度からは、賃貸借処理する不動産の賃料も**支払リース料**。支払家賃と書かない
- 端数利息・為替・未達など、日付や率で金額が変わる論点は、計算を下書きに残す
- 1問に3分以上かけない。迷ったら印をつけて先へ進み、最後に戻る
::

## 第3問の攻略 ― 決算

::steps 第3問を解く手順
1. 未処理事項から | 記帳漏れ・誤記入を先に直し、試算表の横に変わった額をメモする
2. 決算整理を1つずつ | 棚卸資産 → 引当金 → 減価償却 → 有価証券 → 外貨 → 見越し・繰延べ → 税金の順に、1つ仕訳したら1つメモする
3. 段ごとに利益を出す | 売上総利益 → 営業利益 → 経常利益 → 税引前当期純利益 → 当期純利益
4. 貸借対照表を確かめる | 繰越利益剰余金に当期純利益を加え、資産合計と負債・純資産合計が一致するか
::

## よくある失点のパターン

::table 失点のパターンと対策
| パターン | 対策 | 章 |
| 予定配賦の差異の符号（有利・不利）を逆にする | 「予定－実際」がマイナスなら不利（借方）。差異の勘定が借方にあるか貸方にあるかで確かめる | 第2〜4章 |
| 消費賃金に支払額をそのまま使う | 当月支払－前月未払＋当月未払 | 第3章 |
| 先入先出法で、月初仕掛品の換算量を引き忘れる | 当月の換算量＝完成品－月初＋月末 | 第7章 |
| 減損の発生点（始点・終点）を読み落とす | 終点なら完成品だけ、始点なら両者が負担 | 第7章 |
| 能率差異を変動費率だけで計算する | 指示がなければ標準配賦率で計算 | 第9章 |
| 固定費調整の向きを逆にする | 全部原価の利益＝直接原価の利益＋期末在庫の固定費－期首在庫の固定費 | 第10章 |
| 契約負債を売上にしてしまう | 履行義務を果たしたときに売上へ | 第13章 |
| 評価損の数量に帳簿数量を使う | 減耗は帳簿－実地、評価損は実地数量 | 第14章 |
| 圧縮記帳の後、取得原価で減価償却する | 圧縮後の帳簿価額で償却 | 第15章 |
| その他有価証券の評価差額を損益にする | 全部純資産直入法。税効果は評価差額金から直接引く | 第18章・第21章 |
| 退職給付費用を「退職給付引当金繰入」と書く | 勘定科目は退職給付費用 | 第19章 |
| 外貨建の前受金を決算日レートで換算し直す | 前受金・前払金は換算し直さない | 第20章 |
| 法人税等調整額の加減を逆にする | 貸方残高なら税金の欄から差し引く | 第21章 |
| アップストリームの未実現利益で、非支配株主の負担を忘れる | 消去額×非支配株主の持分比率を振り替える | 第26章 |
::

## 2027年度からの出題範囲の変更点

本書は、2027年4月1日以降の試験（統一・ネット・団体）に適用される出題区分表（2026年7月31日公表の確定版）に準拠している。2027年3月までの試験は、2022年度適用の出題区分表にもとづいて出題される。2級に関係する主な変更は次のとおりだ。

::table 商業簿記の主な変更点（2級）
| 論点 | 2027年3月までの試験 | 2027年4月以降の試験 | 章 |
| 普通預金 | 区分表に記載なし | 現金預金に「普通預金」を追加 | 第12章 |
| 手形・小切手 | 受取手形・支払手形、手形の裏書・割引・不渡り、営業外手形 | 紙の手形・小切手の廃止に伴い、**手形関連はすべて削除** | 第12章 |
| 電子記録債権・債務 | 出題範囲 | 売掛金・買掛金と同じ区分へ。**営業外電子記録債権・債務**を明記。決済されなかった場合の処理は範囲外 | 第12章 |
| 売掛債権の譲渡 | その他の債権譲渡 | **売掛債権の譲渡（ファクタリング）**と明確化。2級は買取型（2社間・3社間）の簡易な出題。売掛債権売却損 | 第12章 |
| クレジット売掛金 | クレジット売掛金 | キャッシュレス決済を含むと追記 | 第13章 |
| 売上原価対立法 | 2級 | **3級へ移行** | 第14章 |
| 有形固定資産の除却・廃棄、定率法 | 2級 | **3級へ移行**（定率法は償却率を示す簡易な出題） | 第15章 |
| リース | ファイナンス・リース取引とオペレーティング・リース取引の区分 | 区分を削除。借手は**使用権資産・リース負債**（利子込み法・利子抜き法。利子抜き法の利息は定額法）。短期・少額のリースは賃貸借処理で**支払リース料**。不動産の賃借も、賃貸借処理なら支払リース料。リースの識別は問わない | 第16章 |
::

::note
※工業簿記・原価計算の出題区分には変更がない。出典：[日本商工会議所「紙媒体による手形・小切手の廃止および企業会計基準第34号『リースに関する会計基準』等の適用にともなう商工会議所簿記検定試験出題区分表などの改定について【確定版】」（2026年7月31日）](https://www.kentei.ne.jp/wp/wp-content/uploads/2014/10/2027_kaitei_shushi_fixed.pdf)、[日本商工会議所「出題区分表等」](https://www.kentei.ne.jp/bookkeeping/exam-list)
::

## 合格までの学習計画（目安）

::steps 3か月で合格を目指す場合
1. 1か月目：工業簿記 | 第1部（第1〜11章）を通読し、例題と確認問題を2周。勘定の流れとボックス図を自分で描けるようにする
2. 2か月目：商業簿記 | 第2部・第3部（第12〜26章）を通読し、各章の仕訳を付録Cの仕訳道場で反復。連結は第25・26章を3回解く
3. 3か月目の前半：決算と連結 | 第22章（決算）と第26章（連結精算表）を白紙から解く。第3問の型を体に覚え込ませる
4. 3か月目の後半：模擬試験 | 付録Dの模擬試験を90分で解き、間違えた章に戻る。ネット試験の模擬問題や過去の問題で、別の問題も解く
::

::summary 試験直前に確かめること
- 受験票（統一試験）や予約の内容（ネット試験）、本人確認書類、使い慣れた電卓を用意した
- 解く順番（第1問 → 第4問 → 第5問 → 第3問 → 第2問）と、時間配分を決めた
- 各章の「急所」の箱と、この付録の「解法の型の一覧」を読み返した
- 付録Aの勘定科目辞典で、2027年度からの科目（使用権資産・リース負債・支払リース料・営業外電子記録債権など）を確かめた
- 工業簿記のボックス図・シュラッター図と、連結のボックス図を、白紙に描けるか試した
::
