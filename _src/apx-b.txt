## 試験の基本

::table 日商簿記2級の試験の概要
| 項目 | 内容 |
| 試験方式 | 統一試験（ペーパー試験：例年6月・11月・2月）／ネット試験（随時。テストセンターで受験） |
| 試験時間 | 90分 |
| 試験科目 | 商業簿記、工業簿記（原価計算を含む）。5題以内 |
| 合格基準 | 70%以上 |
| 合格率 | 統一試験 15.1%（第173回、2026年6月）／ネット試験 31.9%（2026年4〜6月） |

## 大問ごとの型

公式には配点の内訳は示されていないが、一般的な出題の型は次のとおりだ。

::table 一般的な出題の型（配点は目安）
| 大問 | 分野 | 主な出題 | 配点の目安 |
| 第1問 | 商業簿記 | 仕訳5問。ほぼすべての論点から出る | 20点 |
| 第2問 | 商業簿記 | 個別の論点（連結精算表、株主資本等変動計算書、有価証券・固定資産の勘定記入、銀行勘定調整表、理論の穴埋めなど） | 20点 |
| 第3問 | 商業簿記 | 財務諸表の作成（損益計算書・貸借対照表）、精算表、決算整理後残高試算表、本支店、製造業の決算など | 20点 |
| 第4問 | 工業簿記 | (1) 仕訳3問、(2) 個別・総合・部門別原価計算、製造原価報告書など | 28点 |
| 第5問 | 工業簿記 | 標準原価計算の差異分析、直接原価計算・CVP分析など | 12点 |
::

## 90分の時間配分と、解く順番

::steps おすすめの解く順番（合計90分）
1 第1問（約15分） | 仕訳5問で20点。1問3分。迷ったら印をつけて先へ進む
2 第4問（約20分） | 工業簿記は型が決まっていて満点を狙える。仕訳3問と計算問題
3 第5問（約12分） | 差異分析・CVPは公式どおりに解けば満点が取れる
4 第3問（約25分） | 決算整理事項を1つずつ仕訳して、試算表の横にメモしていく
5 第2問（約13分） | 論点によって難易度の差が大きい。解ける設問から確実に
6 見直し（約5分） | 第1問の勘定科目名、計算問題の単位（千円・円）
::

::theory 工業簿記で40点を「固める」
工業簿記（第4問・第5問）は、出題の型が少なく、手順どおりに解けば満点に近い点が取れる。工業簿記で35点以上を取れれば、商業簿記は60点中35点で合格に届く。
本書の第1部を、勘定の流れの図（第1章）と、ボックス図（第7章・第9章）を自分で描きながら、何度も解き直そう。
::

## 2027年度からの出題範囲の変更点

本書は、2027年4月1日以降の試験に適用される出題区分表（2026年7月31日公表の確定版）に準拠している。2027年3月までの試験を受ける人は、次の違いに注意すること。

::table 商業簿記の主な変更点（2級）
| 論点 | 2027年3月までの試験 | 2027年4月以降の試験 | 章 |
| 手形 | 受取手形・支払手形、手形の裏書・割引・不渡り、営業外手形 | **すべて削除**。電子記録債権・債務へ | 第12章 |
| 電子記録債権・債務 | 出題範囲 | 売掛金・買掛金と同じ区分。**営業外電子記録債権・債務**を明記 | 第12章 |
| ファクタリング | ― | **売掛債権の譲渡（2社間・3社間）**、売掛債権売却損 | 第12章 |
| リース | ファイナンス・リース取引（リース資産・リース債務）、オペレーティング・リース取引 | **使用権資産・リース負債**（利子込み法・利子抜き法）、短期・少額は**支払リース料**。不動産の賃借も支払リース料 | 第16章 |
| 売上原価対立法 | 2級 | **3級へ移行** | ― |
| 有形固定資産の除却・廃棄、定率法 | 2級 | **3級へ移行**（2級の決算問題では引き続き使う） | 第15章 |
| 収益認識 | 契約資産・契約負債、役務収益など | 出荷・検収・着荷基準、複数の履行義務、変動対価などを**明記** | 第13章 |
| 引当金 | 貸倒引当金など | **退職給付引当金**、貸倒引当金の**個別評価**を明記 | 第19章 |
| 純資産 | 剰余金の配当など | 資本準備金・その他資本剰余金、株主資本の計数の変動、**会社の合併**を明記 | 第23章・第25章 |
::
::note
※工業簿記・原価計算の出題区分には変更がない。出典：[日本商工会議所「出題区分表等」](https://www.kentei.ne.jp/bookkeeping/exam-list)
::

## よくある失点のパターン

::table 失点のパターンと対策
| パターン | 対策 | 章 |
| 予定配賦の差異の符号（有利・不利）を逆にする | 「予定－実際」がマイナスなら不利（借方）。差異の勘定が借方にあるか貸方にあるかで確かめる | 第2〜4章 |
| 消費賃金に支払額をそのまま使う | 当月支払－前月未払＋当月未払 | 第3章 |
| 先入先出法で、月初仕掛品の換算量を引き忘れる | 当月の換算量＝完成品－月初＋月末 | 第7章 |
| 減損の発生点（始点・終点）を読み落とす | 終点なら完成品だけ、始点なら両者が負担 | 第7章 |
| 能率差異を変動費率だけで計算する | 指示がなければ標準配賦率で計算 | 第9章 |
| 固定費調整の向きを逆にする | 全部原価の利益＝直接原価の利益＋期末在庫の固定費－期首在庫の固定費 | 第10章 |
| 契約負債を売上にしてしまう | 履行義務を果たしたときに売上へ | 第13章 |
| 評価損の数量に帳簿数量を使う | 減耗は帳簿－実地、評価損は実地数量 | 第14章 |
| 圧縮記帳の後、取得原価で減価償却する | 圧縮後の帳簿価額で償却 | 第15章 |
| その他有価証券の評価差額を損益にする | 全部純資産直入法。税効果は評価差額金から直接引く | 第18章・第21章 |
| 退職給付費用を「退職給付引当金繰入」と書く | 勘定科目は退職給付費用 | 第19章 |
| 外貨建の前受金を決算日レートで換算し直す | 前受金・前払金は換算し直さない | 第20章 |
| 法人税等調整額の加減を逆にする | 貸方残高なら税金の欄から差し引く | 第21章 |
| アップストリームの未実現利益で、非支配株主の負担を忘れる | 消去額×非支配株主の持分比率を振り替える | 第26章 |
::

## 合格までの学習計画（目安）

::steps 3か月で合格を目指す場合
1か月目：工業簿記 | 第1部（第1〜11章）を通読し、例題と確認問題を2周。勘定の流れとボックス図を自分で描けるようにする
2か月目：商業簿記 | 第2部・第3部（第12〜26章）を通読し、各章の仕訳を付録Cの仕訳道場で反復。連結は第25・26章を3回解く
3か月目前半：決算と連結 | 第22章（決算）と第26章（連結精算表）を白紙から解く。第3問の型を体に覚え込ませる
3か月目後半：模擬試験 | 付録Dの模擬試験を90分で解き、間違えた章に戻る。ネット試験の模擬問題や過去問で、別の問題を解く
::

::summary 試験攻略のまとめ
- 2級は90分・5題・70%で合格。工業簿記（第4問・第5問）で得点を固め、商業簿記は第1問の仕訳から積み上げる
- 解く順番の目安：第1問 → 第4問 → 第5問 → 第3問 → 第2問
- 2027年度から、手形が削除され、リースは使用権資産・リース負債に、ファクタリングや合併などが明記された
- 失点のパターンの多くは、符号・数量・換算レート・勘定科目名の取り違え。本書の「試験の急所」を直前に読み返す
::
