4月20日、火曜日、午前10時。造りの季節が終わり、蔵は静かになった。だが、帳場は静かではなかった。
10日後の4月30日に、大きな支払いが2つ重なる。3月に出荷した酒の**酒税1,500万円**と、春に届いた米の代金**1,800万円**。合わせて3,300万円。
帳簿の当座預金の残高は1,250万円。月末までの売掛金の入金を足しても、1,000万円足りない計算だった。それだけでも頭が痛いのに、銀行から取り寄せた残高証明書を見て、澪は息を止めた。
銀行の残高は、**1,191万円**。帳簿より59万円少ない。
陸：「59万円、どこ行ったんすか。まさか、誰かが引き出したとか……」
岩倉：「通帳と印鑑は、わしの金庫から一歩も出とらん」
澪の頭に、序章で見た叔父の顔が浮かんだ。支払日に払えなければ、審査を待たずに蔵の信用は終わる。
**帳簿と銀行の59万円の差は、どこから来たのか。そして、足りない1,000万円を、10日でどう用意するのか？**
::

## 帳簿と通帳の59万円 ― 銀行勘定調整表

::scene 4月20日、午後1時 ― 帳場
澪は、帳簿の当座預金のページと、ネットバンキングの入出金明細を、1行ずつ並べた。岩倉が鉛筆で、合う行に印をつけていく。陸はATMの利用明細の束をめくった。
陸：「あ、これ。19日の夜に、蔵の売店の売上を俺がATMで入れたやつです。30万円」
銀行の明細では、その30万円は20日の入金になっていた。夜間のATMの預け入れは、翌営業日の扱いになるからだ。
::

帳簿の当座預金の残高と、銀行の残高が合わないとき、その原因を調べて両方の残高を一致させる表を**銀行勘定調整表**という。原因は、だいたい次のどれかだ。

::table 帳簿と銀行のずれの原因（4月20日）
| 原因 | 内容 | 直すのは |
| ① 時間外の預け入れ | 4月19日の夜、ATMで300,000円を預けた。銀行は翌営業日の入金として処理 | 銀行の側（時期のずれ。帳簿は正しい） |
| ② 引落しの未記帳 | 電気料金450,000円が自動引落しされていたが、通知が届かず帳簿に記録していない | 帳簿の側 |
| ③ 入金の未記帳 | 酒販店から売掛金250,000円の振込があったが、連絡が届かず帳簿に記録していない | 帳簿の側 |
| ④ 誤記入 | 買掛金320,000円の振込を、帳簿に230,000円と記録していた | 帳簿の側 |
::

::table 銀行勘定調整表（両者区分調整法、4月20日、単位：円）
| 項目 | 金額 |
| 帳簿の残高 | 12,500,000 |
| (減算) ② 電気料金の引落しの未記帳 | △450,000 |
| (加算) ③ 売掛金の振込の未記帳 | 250,000 |
| (減算) ④ 買掛金の支払いの誤記入（320,000円－230,000円） | △90,000 |
| 調整後の帳簿の残高 | 12,210,000 |
| 銀行の残高証明書の残高 | 11,910,000 |
| (加算) ① 時間外の預け入れ | 300,000 |
| 調整後の銀行の残高 | 12,210,000 |
::

::theory 直すのは、帳簿が間違っているときだけ
銀行勘定調整表で見つかったずれのうち、**帳簿の記録漏れや誤り**（引落し・振込の未記帳、誤記入）は、帳簿を修正する仕訳を切る。**銀行の側の時期のずれ**（時間外の預け入れなど）は、帳簿が正しいので、仕訳はしない。時間がたてば銀行の側で自然に解消する。
::

::example 銀行勘定調整表で見つかった、帳簿の側のずれを直す
上の調整表の②③④について、帳簿を修正する。
::answer
::journal ② 電気料金の引落しの記帳漏れ
水道光熱費 450,000 | 当座預金 450,000
::
::journal ③ 売掛金の振込の記帳漏れ
当座預金 250,000 | 売掛金 250,000
::
::journal ④ 誤記入の訂正：不足の90,000円を追加で記録する
買掛金 90,000 | 当座預金 90,000
::
3つの修正で、帳簿の当座預金は12,500,000円－450,000円＋250,000円－90,000円＝12,210,000円になり、調整後の銀行の残高と一致する。①の時間外の預け入れは、帳簿が正しいので仕訳しない。
::trap
誤記入の訂正は、正しい金額と記録した金額の**差額**だけを仕訳する。320,000円をもう一度全額書かないこと。また、時間外の預け入れに仕訳を切ると、帳簿が二重に増えてしまう。
::
::
::

::note
※2027年3月までの区分表では、未取付小切手（振り出した小切手を相手がまだ銀行に持ち込んでいない）、未渡小切手（振り出したが相手に渡していない）なども調整項目として出題されてきた{{old:2027年度〜範囲外}}。紙の小切手の廃止に伴い、2027年4月以降の試験では、小切手に関する論点は出題区分表から削除されている。
::

## 紙の手形が消えた年 ― 電子記録債権・債務

足りない1,000万円の手がかりは、金庫の中にあった。岩倉が出してきたのは、紙ではなく、ノートパソコンの画面だった。
岩倉：「売掛金のうち、大口の取引先の分は、でんさいで受け取っております。7月14日に期日が来る分が、ちょうど1,000万円」
**電子記録債権**は、電子債権記録機関に記録することで発生する、売掛金を形を変えた債権だ。全国の銀行が参加する「でんさい」がその代表で、紙の手形の代わりに使われている。

::point メモ ― 電子記録債権・債務
得意先との合意で、売掛金について電子記録債権を発生させると、債権者は「電子記録債権／売掛金」、債務者は「買掛金／電子記録債務」と仕訳する。電子記録債権は、期日前に**譲渡**（ほかの支払いに充てる）したり、銀行で**割引**（期日までの利息分を差し引いて売る）したりできる。割引で差し引かれた額は**電子記録債権売却損**とする。
::

::example 4月のでんさいの動き
(1) 4月1日、得意先の酒販チェーンに対する売掛金6,000,000円について、電子記録債権の発生記録が行われた。
(2) 4月10日、電子記録債権のうち4,000,000円を信金で割引き、割引料48,000円を差し引かれた残額が当座預金に入金された。
(3) 4月15日、米の仕入先に対する買掛金1,000,000円の支払いのため、電子記録債権1,000,000円を譲渡記録により譲渡した。
(4) 4月16日、電子記録債権1,000,000円の期日が到来し、当座預金に入金された。
::answer
::journal (1)
電子記録債権 6,000,000 | 売掛金 6,000,000
::
::journal (2) 割引料は電子記録債権売却損
当座預金 3,952,000 | 電子記録債権 4,000,000
電子記録債権売却損 48,000 |
::
::journal (3)
買掛金 1,000,000 | 電子記録債権 1,000,000
::
::journal (4)
当座預金 1,000,000 | 電子記録債権 1,000,000
::
割引は、期日までの利息にあたる割引料を差し引いて、債権を銀行に売ることだ。だから差額は「支払利息」ではなく「売却損」とする。
::trap
割引の差額を「支払利息」にしないこと。また、債務者の側は、支払期日に「電子記録債務／当座預金」と仕訳する。どちらの立場の仕訳かを、問題文の「得意先」「仕入先」で確かめる。
::
::
::

商品や製品の売り買い以外の取引、たとえば設備の購入や売却で電子記録債権・債務が発生したときは、**営業外電子記録債権**・**営業外電子記録債務**を使う。売掛金・買掛金から生じたものと、区別して表示するためだ。

::example 保冷車を、でんさいで買った
4月25日、出荷用の保冷車3,000,000円を購入し、代金は電子記録債務の発生記録で支払うことにした。また、使わなくなった古い瓶詰め用の機械（減価償却は直接法で記帳しており、帳簿価額800,000円）を800,000円で売却し、代金は電子記録債権の発生記録で受け取ることにした。
::answer
::journal (1) 設備の購入代金の電子記録債務
車両運搬具 3,000,000 | 営業外電子記録債務 3,000,000
::
::journal (2) 設備の売却代金の電子記録債権
営業外電子記録債権 800,000 | 機械装置 800,000
::
{{new:2027年度〜}} 営業外電子記録債権・債務は、2027年度からの出題区分表で2級の論点として明記された。
::trap
固定資産の売買なのに「電子記録債務」「電子記録債権」と書かないこと。商品・製品の取引から生じたものだけが、売掛金・買掛金と同じ区分の電子記録債権・債務になる。
::
::
::

## 売掛金を売る ― ファクタリング

でんさいの割引で1,000万円は用意できる。だが、澪には気がかりがあった。5月末にも、まだ払いが続く。でんさいになっていない売掛金も、早く現金にできないか。
椎名：「売掛金そのものを、ファクタリング会社に売る方法があります。手数料は高めですが」
売掛金などの売上債権を、期日前にファクタリング会社に売って資金を得ることを**ファクタリング**（売掛債権の譲渡）という。2級では、債権を買い取ってもらう形の、2社間と3社間のファクタリングが出題される。

::table 2社間と3社間のファクタリング
| 種類 | 当事者 | 得意先への通知 | 手数料の目安 |
| 3社間 | 会社・ファクタリング会社・得意先 | 得意先が承諾し、得意先からファクタリング会社に直接払う | 低め |
| 2社間 | 会社・ファクタリング会社 | 得意先には知らせず、会社が回収してファクタリング会社に渡す | 高め |
::

::example ファクタリングで売掛金を譲渡する
(1) 得意先A社に対する売掛金2,000,000円を、3社間ファクタリングでファクタリング会社に譲渡した。手数料3%を差し引かれた額が普通預金に入金された。
(2) 得意先B社に対する売掛金1,100,000円を、2社間ファクタリングで譲渡した（債権譲渡登記ずみ）。手数料9%を差し引かれた額が普通預金に入金された。
(3) (2)の売掛金の期日が来て、B社から1,100,000円が当社の普通預金に振り込まれた。
(4) (3)の1,100,000円を、普通預金からファクタリング会社に支払った。
::answer
::journal (1) 3社間
普通預金 1,940,000 | 売掛金 2,000,000
売掛債権売却損 60,000 |
::
::journal (2) 2社間：売掛金を売った時点の処理は3社間と同じ
普通預金 1,001,000 | 売掛金 1,100,000
売掛債権売却損 99,000 |
::
::journal (3) 得意先から受け取ったお金は、ファクタリング会社に渡すために預かっている
普通預金 1,100,000 | 預り金 1,100,000
::
::journal (4)
預り金 1,100,000 | 普通預金 1,100,000
::
::trap
(3)で「売掛金」を減らさないこと。売掛金は、(2)で譲渡した時点ですでに帳簿から消えている。2社間では、得意先からのお金は自社のものではなく、ファクタリング会社に渡すために預かっているお金だ。
::
::
::

{{new:2027年度〜}} 売掛債権の譲渡（ファクタリング）は、2027年度からの出題区分表で明確化された。2級は、買取型の2社間・3社間の簡単な出題に限られる。
その日の夕方、澪は帳場のホワイトボードに、59万円の内訳と、支払日までの資金の動きを書き出した。59万円のうち、帳簿の記帳漏れと誤記入で帳簿を直すべき分が29万円（450,000円－250,000円＋90,000円）、銀行の処理を待つだけの時期のずれが30万円。どこにも、誰かが抜いたお金はなかった。

::solve 59万円は、時間差と記帳漏れだった。1,000万円は、でんさいが埋める
帳簿と銀行の59万円の差は、夜間のATMの預け入れ30万円（銀行の時期のずれ）と、電気料金の引落しの未記帳45万円・売掛金の振込の未記帳25万円・買掛金の誤記入9万円（帳簿の側の誤り）の組み合わせだった。帳簿を直すと、残高はどちらも1,221万円で一致した。
もし陸の言うとおり「誰かが引き出した」と騒いでいたら、通帳と印鑑を守ってきた岩倉を疑い、肝心の支払いの準備が止まっていた。
足りない1,000万円は、7月14日に期日の来るでんさいを割り引いて用意した。割引料は6万1,643円。4月30日、酒税と米代は、1円も遅れずに払われた。
**残高が合わないときは、人を疑う前に、時間差と記帳漏れを1行ずつ確かめる。**そして、売掛金は、待つだけの資産ではない。割り引き、譲渡し、売ることができる。
::

### 試験で狙われるパターン ― 調整表の3つの形式・割引料の日割り・2社間の預り金

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 銀行勘定調整表の3つの形式**　帳簿と銀行の両方の残高から調整後の残高を出す**両者区分調整法**のほか、帳簿の残高から銀行の残高に合わせる**企業残高基準法**、銀行の残高から帳簿の残高に合わせる**銀行残高基準法**がある。どの形式でも、修正仕訳が必要なのは帳簿の側の誤りだけだ。

**② 割引料を日割りで計算する**　割引料が「年3%、期日まで75日」のように与えられたら、額面×年利率×日数÷365で計算する。

::example でんさい1,000万円を、年3%で75日前に割り引いた
4月30日、7月14日に期日の来る電子記録債権10,000,000円を信金で割り引いた。割引料は年3%で日割り計算（1年365日、円未満切捨て）し、残額は当座預金に入金された。4月30日から7月14日までは75日である。
::answer
割引料＝10,000,000円×3%×75日÷365日＝61,643円
::journal 割引料は電子記録債権売却損
当座預金 9,938,357 | 電子記録債権 10,000,000
電子記録債権売却損 61,643 |
::
::trap
日数の数え方は問題文に従う。「片落とし」（初日を数えない）が一般的だ。年利率をそのまま額面に掛けて300,000円としないこと。
::
::
::

**③ 2社間ファクタリングの回収**　得意先から回収したお金は「預り金」。ファクタリング会社に渡したときに預り金を減らす。

::steps 解法の型 ― 預金・債権の問題
1. 銀行勘定調整表 | ずれの原因を「帳簿の誤り」と「銀行の時期のずれ」に分ける
2. 修正仕訳 | 帳簿の誤りだけを仕訳する（誤記入は差額だけ）
3. 電子記録債権 | 発生・譲渡・割引・期日。割引の差額は電子記録債権売却損
4. 営業外か | 商品・製品の取引なら電子記録債権・債務、設備の売買なら営業外電子記録債権・債務
5. ファクタリング | 譲渡時に売掛金を消し、手数料は売掛債権売却損。2社間の回収は預り金
::

## 手形と小切手の終わり ― 120日が60日になった

::scene 4月21日、夜 ― 帳場
支払いの算段がついた夜、岩倉は、金庫の奥から古い手形帳を出してきた。表紙に「昭和」の文字がある。
岩倉：「先代のころは、得意先から120日の手形をもらって、それを銀行で割り引いて米代を払っとりました。割引料が、ばかにならんかった」
岩倉：「その手形も、もう使えんのでしょう」
::

全国銀行協会は、2026年度末をもって電子交換所での手形・小切手の交換を終えると決めた。交換は2027年3月31日で終わり、多くの金融機関は、手形・小切手の最終振出期限を2026年9月30日に置いた。下請取引のルールも変わった。2026年1月1日に施行された中小受託取引適正化法（取適法）では、中小の受託事業者への代金を手形で払うことが禁じられた。
澪は、岩倉の手形帳と、いまのでんさいを、この章の仕訳で並べた。得意先からの1,000万円の売掛金を、昔は120日の手形で、いまは60日のでんさいで受け取り、どちらもすぐに年3%で割り引いたとする（割引料は円未満切捨て、仕組みを示すための例）。

::journal ① 以前：120日の約束手形で受け取り、割り引く（割引料98,630円）
受取手形 10,000,000 | 売掛金 10,000,000
当座預金 9,901,370 | 受取手形 10,000,000
手形売却損 98,630 |
::

::journal ② いま：60日の電子記録債権で受け取り、割り引く（割引料49,315円）
電子記録債権 10,000,000 | 売掛金 10,000,000
当座預金 9,950,685 | 電子記録債権 10,000,000
電子記録債権売却損 49,315 |
::

支払いのサイトが半分になれば、割り引くときの売却損も半分になる。紙の手形がなくなることは、受け取る側にとって、資金繰りの負担が軽くなることでもあった。
岩倉：「時代が変わりましたな」
岩倉は、手形帳を金庫に戻し、鍵をかけた。

::danger 帳簿の預金を、毎月銀行の残高と照らし合わせない会社は、不正にも気づけない
引落しや振込の記帳漏れが放っておかれると、帳簿の預金はいつまでも現実とずれる。そのずれの中に、使い込みが紛れても分からない。毎月の末に銀行勘定調整表を作り、ずれの原因を1つずつ消しておくことが、不正を防ぐいちばん安い方法だ（内部統制。試験には直接出ない）。

::cfo 支払日まで10日 ― 1,000万円を、どこから用意するか
4月30日の支払いに、あと1,000万円足りない。澪の手元には、次の4つの方法があった。
**前提**
- 必要な額は1,000万円で、4月30日までに用意しなければならない
- 手元の電子記録債権のうち、7月14日に期日の来る分が1,000万円ある。信金の割引料は年3%（4月30日から75日）で、割り引いた当日に入金される
- 酒販店への売掛金1,100万円を2社間ファクタリングで売ると、手数料は9%で、3日で入金される
- 別の得意先への売掛金1,050万円を3社間ファクタリングで売ると、手数料は3%だが、得意先の承諾に2〜3週間かかる
- 酒税の納付を1か月遅らせると、延滞税がかかる
- 酒販店は、汐見酒造の最大の取引先だ
::choice A. 3社間ファクタリングで、手数料3%で売掛金を売る
**△ 手数料は低いが、間に合わない。**得意先の承諾に2〜3週間かかるので、4月30日の支払いには届かない。急がない資金なら、よい選択肢になる。
::
::choice B. 7月14日に期日の来るでんさいを、信金で割り引く
**◎ 安く、早く、確実だ。**割引料は1,000万円×3%×75日÷365日＝6万1,643円。割り引いた当日に入金されるので、支払日に間に合う。費用は、2社間ファクタリングの約16分の1だ。
::
::choice C. 2社間ファクタリングで、酒販店への売掛金を売る
**× 間に合うが、高すぎる。**手数料は1,100万円×9%＝99万円で、割引の16倍。手取り1,001万円のために99万円を払うのは、年利に直せば非常に高い資金だ。
::
::choice D. 酒税の納付を1か月遅らせ、延滞税を払う
**× 費用は小さくても、失うものが大きい。**国税の滞納は、信金の審査の前に、蔵の信用そのものを傷つける。払える手段があるのに税金を遅らせる理由はない。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「どれが安いか」だけでなく、「4月30日に間に合い、しかも費用が最も小さい方法はどれか」を問う。期限と費用の2つの条件で絞る。
#### 手順2　前提の数字で確かめる
::table compact 1,000万円を用意する4つの方法
| 方法 | 費用 | 間に合うか |
| でんさいの割引 | 約6.2万円 | 当日に入金され、間に合う |
| 2社間ファクタリング | 99万円 | 3日で間に合う |
| 3社間ファクタリング | 31.5万円 | 2〜3週間かかり、間に合わない |
| 酒税の延納 | 延滞税＋信用の毀損 | ― |
::
#### 手順3　ほかの答えに引かれる理由
Aは手数料の低さに、Cは手続きの早さに、Dは目先の費用の小ささに引かれる。どれも、期限と費用のどちらか一方しか見ていない。酒販店が最大の取引先であることは、2社間なら知られずに済むという安心にもつながるが、費用の差を埋める理由にはならない。
#### 持ち帰る考え方
- **資金の手当ては、期限と費用の両方で選ぶ**：間に合わない安い方法も、間に合う高い方法も、正解ではない
- **割引料・手数料は年利に直して比べる**：99万円の手数料は、数か月の資金としては非常に高い
#### 前提が変われば
もし手元にでんさいがなければ、3社間ファクタリングの承諾を待つ間のつなぎとして、信金に短期の借入れを相談するのが筋になる。手数料9%の2社間ファクタリングは、ほかに手段がないときの最後の選択肢だ。
::
::

::exam 預金と債権の急所
- 銀行勘定調整表：修正仕訳は**帳簿の誤り**（引落し・振込の未記帳、誤記入）だけ。時間外の預け入れは仕訳しない
- 誤記入は差額だけを修正する
- 電子記録債権の割引：差額は**電子記録債権売却損**（支払利息ではない）
- 設備の売買で生じたものは**営業外**電子記録債権・債務
- ファクタリング：手数料は**売掛債権売却損**。2社間で得意先から回収したお金は**預り金**
::

::next 資金繰りの判断は、キャッシュ・フローの分析へ
1級では、資金の動きをまとめたキャッシュ・フロー計算書を作り、売掛金の回収や在庫の増減がお金にどう効くかを分析する。ファクタリングで売った債権に買い戻す義務が残る場合の処理（買戻権・遡求義務）も、1級の範囲だ。
::

::summary
- 銀行勘定調整表で、帳簿と銀行の残高のずれを原因ごとに分け、帳簿の誤りだけを修正する
- 電子記録債権・債務は、発生・譲渡・割引・期日で仕訳する。割引の差額は電子記録債権売却損
- 設備の売買から生じたものは、営業外電子記録債権・債務とする
- ファクタリングは売掛金を売る取引で、手数料は売掛債権売却損。2社間の回収金は預り金
- 紙の手形・小切手は2027年3月末で交換が終わり、2027年度からの試験では小切手・手形の論点は削除された
::
