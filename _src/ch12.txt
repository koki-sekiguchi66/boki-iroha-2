::mystery 帳簿と銀行が合わない。しかも、月末にお金が足りない
4月20日、火曜日。澪は、信金から届いた預金の残高証明書と、帳簿の普通預金の残高を並べて、首をかしげた。帳簿は**1,250万円**。銀行の残高は**1,191万円**。59万円合わない。
それよりも深刻なのは、月末の支払いだった。4月30日には、3月に蔵から出荷した酒の**酒税1,500万円**と、冬に仕入れた酒米の残金**1,800万円**を払わなければならない。合わせて**3,300万円**。
売掛金はある。酒販店や問屋への売掛金は合わせて4,000万円を超える。だが、その多くは電子記録債権（でんさい）に変わっていて、入金は7月だ。以前なら、問屋は120日の約束手形で払ってきた。その紙の手形も、銀行の手形交換が3月末で終わり、もう来ない。
9か月の損益計算書は、黒字を示している。それなのに、月末のお金が足りない。
**帳簿と銀行の残高はなぜ違うのか。そして、黒字の蔵は、月末の3,300万円をどう払うのか？**
::

## 銀行勘定調整表 ― 帳簿と銀行の、どちらが正しいか

椎名は、残高証明書と預金の帳簿を受け取ると、日付を1行ずつ照らし合わせ始めた。
「差の原因は、たいてい4種類です。銀行が知らないこと、会社が知らないこと、記録の時期のずれ、そして間違い」
1時間後、ずれの原因が4つ見つかった。

::table 帳簿と銀行のずれの原因（4月20日）
| 原因 | 内容 | 直すのは |
| ① 時間外の預け入れ | 4月19日の夜、ATMで300,000円を預けた。銀行は翌営業日の入金として処理 | 銀行の側（時期のずれ。帳簿は正しい） |
| ② 引落しの未記帳 | 電気料金450,000円が自動引落しされていたが、通知が届かず帳簿に記録していない | 帳簿の側 |
| ③ 入金の未記帳 | 酒販店から売掛金250,000円の振込があったが、連絡が届かず帳簿に記録していない | 帳簿の側 |
| ④ 誤記入 | 買掛金320,000円の振込を、帳簿に230,000円と記録していた | 帳簿の側 |
::

銀行と会社の残高のずれを、表で整理したものを**銀行勘定調整表**という。2級では、両方の残高を正しい残高に近づける**両者区分調整法**が基本だ。

::table 銀行勘定調整表（両者区分調整法、4月20日、単位：円）
| 項目 | 金額 |
| 帳簿の残高 | 12,500,000 |
| (減算) ② 電気料金の引落し未記帳 | △450,000 |
| (加算) ③ 売掛金の振込の未記帳 | 250,000 |
| (減算) ④ 買掛金の支払いの誤記入（320,000円－230,000円） | △90,000 |
| 調整後の帳簿残高 | 12,210,000 |
| 銀行の残高証明書の残高 | 11,910,000 |
| (加算) ① 時間外の預け入れ | 300,000 |
| 調整後の銀行残高 | 12,210,000 |
::

::theory 修正仕訳が必要なのは「帳簿の側」の項目だけ
銀行勘定調整表で、帳簿の残高を加減した項目（②③④）は、会社の記録が漏れていたり、誤っていたりしたものなので、**修正仕訳**が必要だ。銀行の残高を加減した項目（①）は、銀行の処理が遅れているだけなので、仕訳はいらない。
{{old:2027年3月までの試験}} 紙の小切手を使う取引では、振り出した小切手が銀行にまだ持ち込まれていない**未取付小切手**（銀行の側を減算、仕訳なし）や、小切手を作成したが相手に渡していない**未渡小切手**（帳簿の側を加算、修正仕訳あり）も、ずれの原因として出題された。
::

::example 銀行勘定調整表の②③④について、修正仕訳をしなさい
::answer
::journal ② 電気料金の引落しの記帳漏れ
水道光熱費 450,000 | 普通預金 450,000
::
::journal ③ 売掛金の入金の記帳漏れ
普通預金 250,000 | 売掛金 250,000
::
::journal ④ 誤記入の訂正：不足の90,000円を追加で記録する
買掛金 90,000 | 普通預金 90,000
::
3つの修正で、帳簿の普通預金は12,500,000円－450,000円＋250,000円－90,000円＝12,210,000円になり、調整後の銀行残高と一致する。
::
::

正しい預金残高は1,221万円。月末に必要な3,300万円まで、2,000万円以上足りない。

## 電子記録債権 ― 紙の手形の、その後

汐見酒造の売上の多くは、酒販店や問屋への掛け売りだ。以前は、問屋の多くが代金を約束手形で払っていた。2027年3月末で銀行の手形交換が終わり、取引は**電子記録債権**に置き換わった。

::theory 電子記録債権と電子記録債務
電子記録債権は、電子債権記録機関の記録原簿に電子的に記録することで発生する金銭債権だ。取引銀行を通じて「発生記録」をすると、債権者は**電子記録債権**（資産）、債務者は**電子記録債務**（負債）を計上する。支払期日に、債務者の口座から自動的に引き落とされ、債権者の口座に入金される。
紙の手形と同じように、支払期日の前に、銀行で**割引**を受けて現金化したり、自分の仕入先への支払いに**譲渡**したりできる。割引や譲渡で、額面より少ない金額しか受け取れないときの差額は、**電子記録債権売却損**（費用）とする。
{{new:2027年度〜}} 手形に関する論点（受取手形・支払手形・手形の裏書・割引・不渡り）は、2027年度からの出題区分表で削除された。
::

::example 電子記録債権の取引を仕訳しなさい
(1) 問屋に対する売掛金6,000,000円について、問屋の承諾を得て、電子記録債権の発生記録を行った（支払期日は7月14日）。
(2) 上記の電子記録債権のうち4,000,000円を、取引銀行で割引に出した。割引料48,000円が差し引かれ、残額が普通預金に入金された。
(3) 上記の電子記録債権のうち1,000,000円を、ラベルの印刷会社に対する買掛金の支払いのために譲渡記録を行った。
(4) 7月14日、残りの電子記録債権1,000,000円の支払期日が到来し、普通預金に入金された。
::answer
::journal (1)
電子記録債権 6,000,000 | 売掛金 6,000,000
::
::journal (2) 割引料は電子記録債権売却損
普通預金 3,952,000 | 電子記録債権 4,000,000
電子記録債権売却損 48,000 |
::
::journal (3)
買掛金 1,000,000 | 電子記録債権 1,000,000
::
::journal (4)
普通預金 1,000,000 | 電子記録債権 1,000,000
::
割引は、満期までの期間の利息にあたる割引料を差し引いて、債権を銀行に売ることだ。だから差額は「支払利息」ではなく「売却損」とする。
::
::

### 営業外電子記録債権・債務 ― 設備の代金を、でんさいで払う

商品・製品の売買以外の取引（設備の購入や売却など）で電子記録債権・債務が発生したときは、**営業外電子記録債権**・**営業外電子記録債務**の勘定を使う。売掛金・買掛金から生まれたものと区別するためだ。

::example 次の取引を仕訳しなさい
(1) 4月25日、配送用の保冷車3,000,000円を購入し、代金について電子記録債務の発生記録を行った（支払期日は8月25日）。
(2) 不要になった古い配送用の冷蔵庫を800,000円（帳簿価額800,000円）で売却し、代金は電子記録債権の発生記録により受け取ることにした。
::answer
::journal (1) 設備の購入代金の電子記録債務
車両運搬具 3,000,000 | 営業外電子記録債務 3,000,000
::
::journal (2) 設備の売却代金の電子記録債権
営業外電子記録債権 800,000 | 備品 800,000
::
{{new:2027年度〜}} 営業外電子記録債権・債務は、2027年度からの出題区分表で2級の論点として明記された。売掛金・買掛金と同じ区分の「電子記録債権・債務」と、勘定を分けて使うこと。
::
::

## ファクタリング ― 売掛金を、売って現金にする

電子記録債権にしていない売掛金も、期日前に現金化できる。売掛金を専門の会社（**ファクタリング会社**）に売る方法を**ファクタリング**（売掛債権の譲渡）という。

::theory 2社間ファクタリングと3社間ファクタリング
- **3社間ファクタリング**：得意先の承諾を得て、売掛金をファクタリング会社に譲渡する。得意先は、期日にファクタリング会社に直接支払う。手数料は比較的安いが、得意先の承諾が必要で、時間がかかる
- **2社間ファクタリング**：得意先には知らせずに、売掛金をファクタリング会社に譲渡する。期日には、得意先から会社にいつもどおり入金があり、会社はそれをファクタリング会社に渡す。速いが、手数料が高い
売掛金を額面より安く売った差額は、**売掛債権売却損**（費用）とする。2社間で、得意先から受け取ってファクタリング会社に渡すまでのお金は、自分のお金ではないので**預り金**（負債）とする。
{{new:2027年度〜}} 売掛債権の譲渡（ファクタリング）は、2027年度からの出題区分表で2級に新たに加わった。
::

::example ファクタリングの取引を仕訳しなさい
(1) 3社間：居酒屋チェーンに対する売掛金2,000,000円を、居酒屋チェーンの承諾を得てファクタリング会社に譲渡した。手数料60,000円を差し引いた残額が普通預金に入金された。
(2) 2社間：酒販店に対する売掛金1,100,000円を、ファクタリング会社に譲渡した。手数料99,000円を差し引いた残額が普通預金に入金された。
(3) (2)の売掛金の期日に、酒販店から1,100,000円が普通預金に入金された。
(4) (3)の1,100,000円を、ファクタリング会社に普通預金から支払った。
::answer
::journal (1) 3社間
普通預金 1,940,000 | 売掛金 2,000,000
売掛債権売却損 60,000 |
::
::journal (2) 2社間：売掛金を売った時点の処理は3社間と同じ
普通預金 1,001,000 | 売掛金 1,100,000
売掛債権売却損 99,000 |
::
::journal (3) 得意先から受け取ったお金は、ファクタリング会社に渡すために預かっている
普通預金 1,100,000 | 預り金 1,100,000
::
::journal (4)
預り金 1,100,000 | 普通預金 1,100,000
::
(3)で「売掛金」を減らさないことに注意する。売掛金は、(2)で譲渡した時点ですでに帳簿から消えている。
::
::

::exam 債権と現金預金の急所
- **銀行勘定調整表**：修正仕訳が必要なのは、帳簿の側の項目（引落し・入金の未記帳、誤記入）だけ。時間外預け入れなど、銀行の側の項目は仕訳なし
- **電子記録債権**：発生「電子記録債権／売掛金」、割引「普通預金・電子記録債権売却損／電子記録債権」、譲渡「買掛金／電子記録債権」
- 設備などの取引から生じたものは**営業外電子記録債権・債務**
- **ファクタリング**：差額は売掛債権売却損。2社間で得意先から入金があったら「預り金」、ファクタリング会社に払ったら預り金を減らす
- {{old:2027年3月までの試験}} 受取手形・支払手形、手形の裏書・割引（手形売却損）・不渡り（不渡手形）、保証債務の計上も出題範囲
::

## 答え合わせ ― 黒字の蔵の、お金の行方

::solve 帳簿と銀行のずれは「記録の漏れと時期」、お金の不足は「利益と現金の時期」のずれ
帳簿1,250万円と銀行1,191万円の差59万円は、銀行勘定調整表で4つの原因に分かれた。修正仕訳をすると、正しい預金残高は**1,221万円**。
そして、損益計算書が黒字なのにお金が足りないのは、売上を計上した時点と、代金が入る時点がずれているからだ。蔵の売上は、出荷した時点で計上される。だが、代金は電子記録債権に姿を変え、7月まで入ってこない。一方、酒税と米代は待ってくれない。黒字でも、払う日に現金がなければ、会社はつぶれる。3級で学んだ「黒字倒産」の構図そのものだった。
::

::real 紙の手形が消えた日 ― 4億4,000万枚から、ゼロへ
日本の企業間の支払いを長く支えてきた約束手形と小切手が、姿を消そうとしている。全国銀行協会によると、手形・小切手の交換枚数は、1979年の約**4億4,000万枚**から、2024年には**1,967万枚**にまで減った。全銀協は、電子交換所での紙の手形・小切手の交換を**2027年3月31日**に廃止すると決め、多くの金融機関は、2026年9月30日を最終の振出期限とした。
法律も動いた。下請法を改正した中小受託取引適正化法（取適法）が2026年1月1日に施行され、対象となる取引では、代金を手形で支払うことが禁止された。支払期日は、物品を受け取った日から60日以内が原則とされている。

**この章の道具で読む ― 120日の手形が、60日のでんさいに変わると**
酒類の業界では、問屋が蔵に120日もの手形で支払う慣行が長く続いてきた。仮に、ある蔵が問屋に1,000万円の酒を売り、以前なら120日の約束手形、いまなら60日の電子記録債権で受け取るとする（仕組みを示すための例）。
::journal ① 以前：120日の約束手形で受け取り、資金が必要なので割引に出す（年3%、120日の割引料98,630円）
受取手形 10,000,000 | 売掛金 10,000,000
普通預金 9,901,370 | 受取手形 10,000,000
手形売却損 98,630 |
::
::journal ② いま：60日の電子記録債権で受け取り、割引に出す（年3%、60日の割引料49,315円）
電子記録債権 10,000,000 | 売掛金 10,000,000
普通預金 9,950,685 | 電子記録債権 10,000,000
電子記録債権売却損 49,315 |
::
勘定の名前が変わっただけではない。代金が入るまでの日数が半分になれば、割引に出したときの費用も半分になり、そもそも割引に出さずに期日を待てる会社も増える。売上から入金までの期間が短くなることは、黒字倒産のリスクを下げる。
2027年度からの簿記の出題範囲から手形がそっくり消えたのは、こうした現実の変化に合わせたものだ。
::note
出典：[全国銀行協会「紙の手形・小切手利用廃止へ」](https://www.zenginkyo.or.jp/tegata-kogitte-haishi/)、[全国銀行協会「電子交換所の交換廃止時期の決定および手形・小切手交換廃止時期の明確化について」（2026年6月）](https://www.zenginkyo.or.jp/news/2026/n061802/)、[ミラサポplus（中小企業庁）「取適法（中小受託取引適正化法）」](https://mirasapo-plus.go.jp/infomation/30416/)
::
::

::cfo 4月30日の1,000万円 ― どうやって用意するか
預金の1,221万円に、4月下旬に入る売掛金の回収80万円を合わせても1,301万円。月末の3,300万円には約2,000万円足りない。米代の残金1,800万円のうち1,000万円は、農協に頼んで、手元の電子記録債権の譲渡で払えることになった。残るのは、**酒税**の支払いに充てる現金の不足、約1,000万円だ。
::table 資金を用意する方法（必要額1,000万円、4月30日まで10日）
| 方法 | 費用 | 時間 |
| A 手元の電子記録債権（7月14日期日）1,000万円を信金で割引 | 割引料 年3.0%（4月30日から75日） | 2日 |
| B 酒販店への売掛金1,100万円を2社間ファクタリング | 手数料 9% | 3日 |
| C 酒販店への売掛金1,050万円を3社間ファクタリング | 手数料 3% | 得意先の承諾に2〜3週間 |
| D 酒税の納付を1か月遅らせる | 延滞税（年2%台） | 0日 |
::
まず、A〜Dそれぞれで1,000万円を用意するのにかかる費用を計算してから選んでほしい。
::choice A. 電子記録債権を割引に出す
**◎ 最も安く、間に合う。**割引料は1,000万円×3.0%×75日÷365日＝**約6万1,600円**。2日で現金になる。仕訳は「普通預金 9,938,357／電子記録債権 10,000,000、電子記録債権売却損 61,643」。
電子記録債権は、手形と違って分割して割り引けるので、必要な額だけを現金化できる。
::
::choice B. 2社間ファクタリングで、売掛金を売る
**△ 間に合うが、高すぎる。**手数料は1,100万円×9%＝**99万円**。割引の約16倍だ。年率に直すと、およそ40%を超える。得意先に知られずに済む利点はあるが、この費用を払えば、4月の利益の大半が消える。ほかに手段がないときの最後の手だ。
::
::choice C. 3社間ファクタリングで、安く売掛金を売る
**△ 手数料は安いが、間に合わない。**手数料は1,050万円×3%＝31万5,000円。Bより安いが、割引の5倍以上で、しかも得意先の承諾に2〜3週間かかる。4月30日の支払いには使えない。資金繰りは、費用だけでなく「いつ現金になるか」で比べる。
::
::choice D. 酒税の納付を遅らせる
**× 最も安く見えて、最も危ない。**延滞税は1か月で数万円かもしれない。だが、酒税は蔵の生命線である酒類製造免許と結びついた税だ。滞納が続いて滞納処分を受ければ、免許の取消しにつながるおそれがある。信金も、税金を滞納した会社への借換えには慎重になる。費用の比較の外にある、致命的なリスクだ。
::
::answer 考え方の例を見る
資金繰りの判断は、**費用**（何%か）と**時間**（いつ現金になるか）と**リスク**（信用・免許・取引先との関係）の3つで比べる。電子記録債権の割引は、そのすべてで最もバランスがよかった。
澪はA案で1,000万円を用意し、4月30日の酒税を期日どおりに納めた。同じ日、高梨に資金繰り表を送った。7月まで、毎週の入金と支払いを並べた表だ。「黒字なのにお金が足りない月がある」ことを、先に見せておくためだった。
::
::

::next 資金繰りは、キャッシュ・フロー計算書へ
1級では、営業活動・投資活動・財務活動に分けてお金の流れを示す**キャッシュ・フロー計算書**を作る。売掛金や在庫が増えると営業活動のキャッシュ・フローが減る、という3級終章の考え方を、間接法で体系的に計算する。また、電子記録債権の不渡りに相当する処理や、手形の更改など、2級では扱わない論点も学ぶ。
::
