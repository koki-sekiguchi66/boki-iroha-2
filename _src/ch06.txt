## 1枚の注文書 ― 個別原価計算と製造指図書

ベイサイド迎賓館の酒は、ふだんの純米吟醸とは違う。名前入りのラベル、特注の瓶、化粧箱。同じ酒は、二度と造らない。
澪：「この酒の原価を、普通酒と同じ1か月の平均で計算したら、おかしなことになりますよね」
岩倉：「なります。注文ごとに、伝票を分けておりました。先代のころから」
岩倉が出してきたのは、注文ごとに1枚ずつの、くたびれた「仕込み指示書」の束だった。

::table 個別原価計算と総合原価計算
| 項目 | 個別原価計算 | 総合原価計算 |
| 向いている造り方 | 注文ごとに、仕様の違う製品を造る（受注生産） | 同じ規格の製品を続けて大量に造る（見込み生産） |
| 原価を集める単位 | 注文（製造指図書）ごと | 1か月（原価計算期間）ごと |
| 例 | 船・ビル・特注の機械・名入れラベルの酒 | 普通酒・純米吟醸の定番品・ビール |
| 本書の章 | 第6章 | 第7章・第8章 |
::

::point メモ ― 製造指図書と原価計算表
**製造指図書**は、工場に「この製品を、この仕様で、いくつ造れ」と命じる書類で、注文ごとに番号（No.201など）がつく。製造指図書ごとに、直接材料費・直接労務費・直接経費を集計し、製造間接費を配賦した表を**原価計算表**（指図書別原価計算表）という。仕掛品勘定は、すべての指図書の原価計算表をまとめた勘定になる。
::

岩倉の指示書が、そのまま製造指図書だった。No.201の原価計算表には、見積りの欄と実際の欄が並んでいる。

::table No.201（ベイサイド迎賓館・名入れ純米吟醸500本）の原価計算表（単位：円）
| 費目 | 見積り | 実際 | 実際の計算 |
| 直接材料費（酒米・特注の瓶・ラベル・化粧箱） | 300,000 | 320,000 | 特注の瓶の値上がり |
| 直接労務費 | 180,000 | 234,000 | 130時間×1,800円 |
| 製造間接費（醸造部門） | 256,000 | 332,800 | 130時間×2,560円 |
| 製造間接費（瓶詰め部門） | 72,000 | 86,400 | 12時間×7,200円 |
| 仕損費 | 0 | 124,800 | 補修指図書No.201-1から |
|= 合計 | 808,000 | 1,098,000 | |
::

見積りは、直接作業時間100時間、瓶詰めラインの機械運転時間10時間で作っていた。製造間接費の配賦には、第5章の部門別の予定配賦率（醸造部門2,560円、瓶詰め部門7,200円）を使っている。

## 貼り直しの500枚 ― 補修指図書と仕損費

::scene 2月21日、午後 ― 瓶詰め場
陸は、1人で500本のラベルをはがしていた。爪の先が、糊で白くなっている。宇佐美は見ないふりをして、刷り直したラベルの箱を、陸の横にそっと置いた。
澪：「この貼り直しの費用、どこに記録すればいいですか」
岩倉：「新しい指示書を切ります。No.201-1。直すための指示書です」
::

製品が基準に合わず、作り直しや手直しが必要になることを**仕損**（しそんじ）という。仕損を直すために出す指図書を**補修指図書**、まるごと作り直すために出す指図書を**代品指図書**という。補修や代品にかかった原価が、**仕損費**だ。
補修指図書No.201-1には、刷り直しのラベル代38,400円、貼り直しの直接作業24時間分の賃金43,200円（24時間×1,800円）、瓶詰め部門の機械6時間分の製造間接費43,200円（6時間×7,200円）が集まった。合計124,800円。

::theory 正常な仕損費は、その注文の原価になる
通常の作業で起こりうる程度の**正常な仕損**の費用は、製品を造るのに必要だった原価だ。仕損が生じた指図書に**直接経費として賦課**する（特定の指図書との関係が分からなければ、製造間接費として配賦する）。
火災や重大な過失のような**異常な仕損**の費用は、ふだんの製造では生じない損失なので、原価に含めず**非原価項目**とする。
::

::example 補修指図書の原価を、元の指図書に賦課する
補修指図書No.201-1に集計された原価は124,800円（材料38,400円、直接労務費43,200円、製造間接費43,200円）で、正常な仕損と認められた。この仕損費を、元の製造指図書No.201に賦課する。
::answer
::journal (1) 補修指図書の原価を仕損費に振り替える
仕損費 124,800 | 仕掛品 124,800
::
::journal (2) 仕損費をNo.201に直接経費として賦課する
仕掛品 124,800 | 仕損費 124,800
::
補修のための材料・労務費・製造間接費は、いったん補修指図書No.201-1の原価として仕掛品勘定に集められている（補修も製造だからだ）。それを仕損費に振り替え、元の指図書No.201の原価に加える。仕掛品勘定の中で、原価が補修指図書から元の指図書へ移るだけなので、(1)と(2)はまとめて省略されることもある。
::trap
仕損費を「その注文の損失」として、営業外費用や特別損失にしないこと。正常な仕損費は**製品の原価**だ。非原価にするのは異常な仕損だけ。問題文の「正常な」「異常な」を必ず確かめる。
::
::
::

::example 代品を造ったとき ― 仕損品に売れる価値がある場合
酒販店のPB酒（No.202）の一部が、瓶詰めの不良で使えなくなり、代品指図書No.202-1で造り直した。代品の原価は90,000円。不良品は料理酒として6,000円で引き取ってもらえる見込みである。正常な仕損と認められた。
::answer
::journal (1) 代品指図書の原価から、仕損品の評価額を除いて仕損費とする
仕損品 6,000 | 仕掛品 90,000
仕損費 84,000 |
::
::journal (2) 仕損費をNo.202に賦課する
仕掛品 84,000 | 仕損費 84,000
::
代品の原価90,000円から、転用できる仕損品の価値6,000円を引いた84,000円が仕損費になる。仕損品の評価額は、資産として**仕損品**勘定に振り替える。
::trap
仕損品に売れる価値があるときは、その評価額を仕損費から**差し引く**。評価額まで仕損費に入れると、原価が過大になる。
::
::
::

## 29万円の内訳 ― 誰が膨らませたのか

陸を責める声が収まらない帳場で、澪は原価計算表の「見積り」と「実際」の差を、原因ごとに分け始めた。
澪：「陸くんのミスで増えたのは、仕損費の124,800円です。でも、差は29万円ある」
岩倉：「残りは、何です」
澪は作業日報をめくった。小仕込みのタンクは、仕込みの量が少ないぶん温度が変わりやすい。小松が夜中に何度も見回り、櫂入れの回数も増えていた。

::case No.201の作業日報から
- 醸造の直接作業時間：見積り100時間 → 実際130時間（小仕込みで温度管理の手間が増えた）
- 瓶詰めの機械運転時間：見積り10時間 → 実際12時間（特注の瓶の形でラインの速度を落とした）
- 特注の瓶：見積りの後に、仕入先が1本40円値上げした（500本で20,000円）
- ラベルの貼り直し：補修指図書No.201-1、124,800円
::

::challenge 29万円の超過の、いちばん大きな原因は何か
上の手がかりと、原価計算表（予定賃率1,800円、醸造部門の予定配賦率2,560円、瓶詰め部門の予定配賦率7,200円）から考える。
::choice A. 陸のラベルの打ち間違い。仕損費がなければ、見積りどおりだった
**× 宇佐美がはまった落とし穴。**仕損費は124,800円で、29万円の4割ほどにすぎない。仕損がなくても、原価は見積りより165,200円多かった。目立つ失敗が1つあると、ほかの原因が見えなくなる。
::
::choice B. 特注の瓶の値上がり。仕入先が値段を変えたせいだ
**△ 原因の1つだが、小さい。**値上がりの影響は20,000円で、超過の1割に満たない。
::
::choice C. 作業時間の見積りの甘さ。時間の延びが、労務費と製造間接費を通じて145,200円も原価を押し上げた
**◎ 正解。**直接作業30時間の延びで、直接労務費54,000円（30×1,800円）と醸造部門費76,800円（30×2,560円）。瓶詰め2時間の延びで瓶詰め部門費14,400円（2×7,200円）。合計145,200円は、仕損費124,800円より大きい。しかも、時間が延びると、労務費だけでなく製造間接費まで一緒に膨らむ。
::
::choice D. 製造間接費の予定配賦率が高すぎた。率を下げれば、見積りどおりになる
**× 率は第5章の部門別予定配賦率のままで、見積りと実際で同じ率を使っている。**差を生んだのは率ではなく、率に掛ける時間のほうだ。
::
::answer
#### 手順1　見積りと実際を、費目ごとに並べる
直接材料費＋20,000円、直接労務費＋54,000円、醸造部門費＋76,800円、瓶詰め部門費＋14,400円、仕損費＋124,800円。合計＋290,000円。
#### 手順2　原因ごとにまとめ直す
時間の延び（労務費＋2つの部門費）145,200円、仕損費124,800円、瓶の値上がり20,000円。
#### 手順3　個別原価計算の強みを使う
注文ごとに原価計算表があるので、「どの注文の、どの費目が、なぜ」まで分解できる。試験では、指図書別の原価計算表から、完成品原価・月末仕掛品原価・売上原価を集計させる問題がよく出る。
::
::

::solve 29万円の主犯は、陸のミスではなく、時間の見積りだった
29万円の超過のうち、陸のラベルの打ち間違いによる仕損費は124,800円。最も大きかったのは、小仕込みの手間を見込めていなかった**作業時間の見積りの甘さ**で、労務費と製造間接費を合わせて145,200円だった。残りの20,000円は瓶の値上がりだ。
もし宇佐美の言うとおり陸に始末書を書かせて終わりにしていたら、次の名入れの注文も同じ100時間で見積もり、同じように赤字を重ねていた。
澪は、陸を帳場に呼んだ。
澪：「ミスは、ミス。でも、29万円の半分は、私の見積りの責任だった」
陸：「……専務のせいじゃないっすよ」
澪：「次から、名入れの原稿は2人で読み合わせる。それと、小仕込みの時間は、今回の130時間で見積もる」
**個別原価計算の原価計算表は、責める相手を探す道具ではない。次の見積りを当てるための、いちばん正直な記録だ。**
::

2月の終わり、澪は月末の締めをした。2月に原価を集めた指図書は3つ。月初から仕込んでいたNo.202（酒販店のPB酒）と、No.201、そして3月に完成予定の料亭の記念酒No.203だ。

::

完成した指図書の合計が「製品」、引き渡した指図書が「売上原価」、未完成の指図書が「月末仕掛品」になる。個別原価計算では、月末仕掛品の金額は、未完成の指図書の原価計算表を足すだけで分かる。

### 試験で狙われるパターン ― 指図書の状態の判断・全部仕損・作業屑

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 指図書の状態から、勘定の金額を決める**　月初・月末に、それぞれの指図書が「未完成」「完成・未引渡し」「引渡し済み」のどれかを確かめ、仕掛品・製品・売上原価に振り分ける。前月に完成して今月引き渡した指図書は、今月の売上原価だが、今月の製造原価には入らない。

**② 元の指図書が全部仕損になった**　元の指図書の製品がすべて使えなくなり代品を造る場合は、元の指図書に集めた原価（から仕損品の評価額を引いた額）が仕損費になる。

::example 元の指図書が、まるごと仕損になった
指図書No.301の製品（原価300,000円）が全部仕損となり、代品指図書No.301-1を発行した。仕損品は20,000円で売却できる見込みである。正常な仕損であり、仕損費はNo.301-1に賦課する。
::answer
::journal (1) 全部仕損：元の指図書の原価－評価額
仕損品 20,000 | 仕掛品 300,000
仕損費 280,000 |
::
::journal (2) 仕損費を代品の指図書に賦課する
仕掛品 280,000 | 仕損費 280,000
::
全部仕損のときは、元の指図書No.301の原価そのものが仕損費の出発点になる。代品の指図書は、代品を造る原価をそのまま集計していく。
::trap
一部仕損（補修・一部の代品）では「新しい指図書の原価」が仕損費、全部仕損では「元の指図書の原価」が仕損費。どちらの原価を仕損費にするかを、取り違えないこと。
::
::
::

**③ 作業屑**　加工のときに出る材料の削りくずのうち、売れる価値があるものを**作業屑**という。評価額を、発生した指図書の原価（または製造間接費）から差し引く（作業屑／仕掛品）。

::steps 解法の型 ― 個別原価計算
1. 指図書ごとに原価計算表を作る | 直接材料費・直接労務費・直接経費、製造間接費（予定配賦率×その指図書の時間）
2. 仕損費を処理する | 補修・一部代品は新しい指図書の原価、全部仕損は元の指図書の原価。評価額を引いて、元（または代品）の指図書に賦課
3. 指図書の状態を確かめる | 月初・月末に、未完成・完成・引渡し済みのどれか
4. 勘定に振り分ける | 完成→製品、引渡し→売上原価、未完成→月末仕掛品
::

## 長崎の大型客船 ― 1つの注文が、会社を揺らした

::scene 2月26日、夜 ― 帳場
桐生から、久しぶりにビデオ通話が来た。澪が名入れの酒の話をすると、桐生は笑った。
桐生：「29万円の超過で、蔵じゅう大騒ぎか。商社の頃、造船の担当が言ってたよ。たった2隻の注文で、2,500億円の損を出したって話」
::

三菱重工業は2011年、ドイツのクルーズ会社から大型客船2隻を、合わせて約1,000億円で受注した。初めて手がける本格的な豪華客船で、1番船の引き渡しは当初の2015年3月から3度延期されて2016年3月になった。2017年に2番船を引き渡したとき、大型客船事業の累計の損失は2,500億円を超えていた。同社は、大型客船の新規受注を凍結した。
客船は、1隻ずつ仕様が違う。典型的な個別原価計算の世界だ。澪は、蔵の指図書と同じ形で、その流れを描いてみた（受注額と損失は報道による概数、原価の内訳は仕組みを示すための仮の数字。単位：億円）。

::journal ① 2隻の製造指図書に、原価が積み上がる（受注額1,000億円＋損失2,500億円）
仕掛品 3,500 | 材料 1,400
 | 賃金・給料 1,100
 | 製造間接費 1,000
::

::journal ② 引き渡し：売上は受注額の1,000億円のまま
製品 3,500 | 仕掛品 3,500
売上原価 3,500 | 製品 3,500
売掛金 1,000 | 売上 1,000
::

受注した値段は、契約の時点で決まっている。原価計算表の「実際」の欄が膨らみ続けても、売上の欄は1円も増えない。29万円と2,500億円。桁は違っても、見積りを外したときに何が起きるかは、同じだった。
桐生：「1隻目の原価計算表を見て、2隻目の見積りを直せれば、まだ救いがあったんだろうけどね」

::note
出典：[ニュースイッチ（日刊工業新聞）「三菱重工、大型客船事業2500億円超えの損失。最後の２番船引き渡し」（2017年5月3日）](https://newswitch.jp/p/8898)。2級の範囲を超えるが、工事が終わる前に損失が見込まれるときは「受注損失引当金」を計上して、損失を早めに認識する（1級）
::

::danger 見積りの「実績の欄」を見ない会社は、同じ赤字を繰り返す
個別原価計算の原価計算表には、注文ごとの見積りと実際が残る。実際の時間や仕損の記録を次の見積りに使わなければ、同じ種類の注文で同じ赤字を繰り返す。特に、初めて受ける種類の注文は、時間を多めに見積もる。
::

::cfo 長岡の酒販店のPB酒、1,000本をいくらで受けるか
3月、長岡の酒販店から、店の名前を入れたPB（自社ブランド）の純米吟醸を1,000本、という相談が来た。先方の希望は1本1,500円。澪の手元の資料は次のとおり。
- 直接材料費 520,000円
- 直接作業時間 180時間（No.201の実績1本あたり0.26時間を参考に、量が多いぶん少し効率化）
- 瓶詰めラインの機械運転時間 15時間
- 予定賃率1,800円、部門別の予定配賦率 醸造部門2,560円・瓶詰め部門7,200円
- 正常な仕損の見込み：過去の名入れの注文の平均で、製造原価の2%
::choice A. 1本1,500円で受ける。原価は1本1,412円なので、88円の儲けが出る
**△ 仕損の見込みが抜けている。**直接材料費520,000円＋直接労務費324,000円＋醸造部門費460,800円＋瓶詰め部門費108,000円＝1,412,800円。ここに正常な仕損の見込み2%（28,256円）を加えると1,441,056円で、1本約1,441円。儲けは約59円に縮む。
::
::choice B. 仕損を見込んで原価を約1,441円と見積もり、1本1,550円を提示する
**◎ No.201の教訓を、数字で生かしている。**時間は実績から、仕損は過去の平均から見込んだ。1,550円なら1本約109円、1,000本で約11万円の儲けになる。希望の1,500円との差は、名入れの読み合わせなどの手間で説明できる。
::
::choice C. 工場全体の予定配賦率（4,000円）で見積もる。そのほうが計算が早い
**× 第5章で直した物差しに戻っている。**180時間×4,000円＝720,000円で製造間接費を見積もると、部門別（568,800円）より151,200円も多くなり、原価は1本1,592円になる。高すぎる見積りで、受けられる注文を逃す。
::
::choice D. No.201は赤字だったので、名入れの注文はもう受けない
**× 失敗から学ぶ前に、市場を捨てている。**No.201の赤字の原因は、時間の見積りと仕損だった。原因が分かっていれば、正しく見積もれば利益が出る。
::
::answer 考え方の例を見る
#### 手順1　実績で見積もる
時間は、似た注文の実績を使う。No.201の実績から、1本あたりの時間を出して、量に合わせて調整する。
#### 手順2　見込める仕損は、最初から原価に入れる
過去に毎回起きている程度の仕損は、正常な仕損として原価の一部になる。見積りの段階から入れておく。
#### 手順3　部門別の配賦率を使う
製品が使う部門と時間に合わせて配る。工場全体の率は、使う部門の偏った注文では、原価を大きくゆがめる。
#### その後の蔵
酒販店は1,550円で注文を決めた。名入れのラベルは、陸と宇佐美が2人で読み合わせた。
::

::exam 個別原価計算の急所
- 原価計算表の合計＝その指図書の製造原価。完成→製品、引渡し→売上原価、未完成→月末仕掛品
- 製造間接費は、予定配賦率×**その指図書の**作業時間（または機械運転時間）
- 一部仕損：**新しい指図書（補修・代品）の原価**が仕損費。全部仕損：**元の指図書の原価**が仕損費
- 仕損品に評価額があれば、仕損費から差し引いて仕損品勘定へ
- 正常な仕損費は元の指図書に賦課（または製造間接費として配賦）。異常な仕損費は非原価項目
::

::next 受注の判断は、差額原価へ
1級では、注文を受けるかどうか、追加で引き受けるかどうかを、その注文で増える収益と費用（差額原価・差額収益）で判断する方法を学ぶ。長い工事の収益を進み具合に応じて計上する方法や、損失が見込まれる工事の受注損失引当金も、1級の範囲だ。
::

::summary
- 個別原価計算は、注文ごとに製造指図書を発行し、原価計算表に原価を集める方法
- 仕掛品勘定は指図書の原価計算表のまとめで、完成した指図書は製品、引き渡した指図書は売上原価になる
- 仕損を直す補修指図書、作り直す代品指図書の原価が仕損費になる
- 正常な仕損費は元の指図書に賦課し、仕損品に評価額があれば差し引く
- 見積りと実際の差を原因ごとに分けると、次の見積りが当たるようになる
::

::quiz
::problem 次の資料から、当月の完成品原価・月末仕掛品原価・売上原価を求めなさい。
No.11（前月から繰り越した未完成品、前月までの原価200,000円。当月の製造原価300,000円。当月完成・当月引渡し）
No.12（当月着手、当月の製造原価450,000円。当月完成・未引渡し）
No.13（当月着手、当月の製造原価180,000円。月末未完成）
完成品原価 [[950,000]] 円、月末仕掛品原価 [[180,000]] 円、売上原価 [[500,000]] 円
::answer
完成品原価＝No.11（200,000＋300,000）＋No.12（450,000）＝**950,000円**。月末仕掛品＝No.13の**180,000円**。売上原価＝引き渡したNo.11の**500,000円**。No.12は完成したが未引渡しなので、月末の製品になる。
::

::problem 次の取引を仕訳しなさい。いずれも正常な仕損である。
(1) 製造指図書No.21の製品の一部に仕損が生じたため、補修指図書No.21-1を発行して補修した。No.21-1に集計された原価は45,000円であり、これをNo.21に賦課した。
(2) 製造指図書No.22の製品が全部仕損となり、代品指図書を発行した。No.22に集計された原価は300,000円で、仕損品の評価額は20,000円である。仕損費は代品の指図書に賦課する。
::answer
::journal (1) 補修指図書の原価を仕損費とし、元の指図書に賦課する
仕損費 45,000 | 仕掛品 45,000
仕掛品 45,000 | 仕損費 45,000
::
::journal (2) 全部仕損：元の指図書の原価－評価額
仕損品 20,000 | 仕掛品 300,000
仕損費 280,000 |
::
(2)では、さらに「仕掛品 280,000／仕損費 280,000」で代品の指図書に賦課する。全部仕損では、元の指図書の原価が仕損費の出発点になる。

::problem 指図書No.31の資料から、製造原価を求めなさい。
直接材料費 150,000円、直接作業時間 40時間（予定賃率 1,500円）、機械運転時間 10時間（製造間接費の予定配賦率 機械運転時間1時間あたり 6,000円）
製造原価 [[270,000]] 円
::answer
直接労務費＝40時間×1,500円＝60,000円。製造間接費＝10時間×6,000円＝60,000円。製造原価＝150,000＋60,000＋60,000＝**270,000円**。配賦の物差し（機械運転時間）に、作業時間を掛けないよう注意する。
