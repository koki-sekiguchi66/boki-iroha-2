::mystery 黒字の見積りが、完成したら赤字に
1月の初め、新潟市の結婚式場「ベイサイド迎賓館」から電話が来た。春の結婚式で、新郎新婦の名前と式の日付をラベルに入れた純米吟醸を、引き出物として**500本**ほしいという。値段は1本2,000円、合計100万円。
蔵で初めての注文生産だった。澪は、小松と相談して、この注文のためだけに小さなタンクを1本仕込むことにした。見積りの原価は80万8,000円。差し引き**19万2,000円**の黒字になるはずだった。
2月の終わり、酒は完成した。だが、出来上がった原価計算表を見て、澪は青ざめた。原価の合計は**109万8,000円**。100万円で売れば、約10万円の赤字だ。
原因の1つは分かっていた。ラベルの新郎の名前の漢字が、1文字間違っていたのだ。だが、それだけで30万円近くもずれるものだろうか。
**見積りは黒字だったのに、なぜ完成したら赤字だったのか？**
::

## 注文ごとに原価を集める ― 個別原価計算

これまでの章で、澪は原価の3要素（材料費・労務費・経費）を集め、製造間接費を部門ごとに配賦してきた。集めた原価を、最後に**製品**ごとに計算する方法は、造り方によって2つに分かれる。

::table 個別原価計算と総合原価計算
| 項目 | 個別原価計算 | 総合原価計算 |
| 向いている造り方 | 注文ごとに、仕様の違う製品を造る（受注生産） | 同じ規格の製品を、続けて大量に造る（見込み生産） |
| 原価を集める単位 | 注文（製造指図書）ごと | 1か月（原価計算期間）ごと |
| 例 | 船・ビル・特注の機械・オリジナルラベルの酒 | 普通酒・純米吟醸の定番品・ビール・食品 |
| 本書の章 | 第6章 | 第7章・第8章 |
::

個別原価計算では、注文を受けるたびに**製造指図書**を発行し、番号をつける。そして、指図書ごとに**原価計算表**（指図書別原価計算表）を作り、直接材料費・直接労務費・直接経費を**賦課**し、製造間接費を**配賦**していく。
結婚式場の注文には、**No.201**の番号がついた。

::theory 個別原価計算の仕掛品と製品
個別原価計算では、月末に**完成していない指図書**の原価の合計が月末の仕掛品、**完成したがまだ引き渡していない指図書**の原価が月末の製品、**引き渡した指図書**の原価が売上原価になる。
総合原価計算のように「月末に何%できているか」を計算する必要はない。指図書ごとに原価が集まっているので、その指図書の状態（未完成・完成・引渡済み）を見れば、どの勘定に入るかが決まる。
::

## 見積りと実際 ― No.201の原価計算表

澪の見積りは、第5章で決めた部門別の予定配賦率（醸造部門 直接作業時間1時間2,560円、瓶詰め部門 機械運転時間1時間7,200円）と、予定賃率1時間1,800円を使っていた。実際には、どうだったか。

::table No.201（ベイサイド迎賓館・オリジナル純米吟醸500本）の原価計算表（単位：円）
| 費目 | 見積り | 実際 | 実際の計算 |
| 直接材料費（酒米・特注の瓶・ラベル・化粧箱） | 300,000 | 320,000 | 特注の瓶の値上がり |
| 直接労務費 | 180,000 | 234,000 | 130時間×1,800円 |
| 製造間接費（醸造部門） | 256,000 | 332,800 | 130時間×2,560円 |
| 製造間接費（瓶詰め部門） | 72,000 | 86,400 | 12時間×7,200円 |
| 仕損費 | 0 | 124,800 | 補修指図書No.201-1から賦課 |
|= 合計 | 808,000 | 1,098,000 | |
::

見積りとの差29万円は、3つに分かれていた。直接作業時間が見積りの100時間から130時間に延びた分（労務費と醸造部門費で13万800円）、瓶の値上がりと瓶詰めの延び（3万4,400円）、そして、ラベルの誤植の**仕損費**12万4,800円だ。

小仕込みは、大きなタンクより温度の管理が難しく、蔵人が付きっきりになる。初めての注文生産で、そこを甘く見積もっていた。

## 仕損費 ― 失敗のコストを、誰が負担するか

ラベルの誤植は、式場から預かった名簿の手書きの字を、営業担当が読み違えたのが原因だった。500本すべてのラベルを貼り替えるしかない。このように、製造の途中や後で、規格に合わない不良品が出ることを**仕損**といい、その損失を**仕損費**という。
仕損が出たときは、元の指図書とは別に、手直しや作り直しのための指図書を発行する。

::theory 仕損費の計算
- **補修**できるとき：**補修指図書**を発行し、補修にかかった原価を集める。仕損費＝**補修指図書に集めた原価**
- 補修できず、**代品**を作るとき：**代品指図書**を発行して作り直す
  - 全部が仕損になり、作り直したとき：仕損費＝**元の指図書の原価**－仕損品の評価額（売却・転用できる価値）
  - 一部が仕損になり、その分の代品を作ったとき：仕損費＝**代品指図書の原価**－仕損品の評価額
**仕損費の処理**：その指図書に固有の仕損なら、仕損費を元の指図書に**直接経費として賦課**する。どの指図書でも毎期ある程度生じる仕損なら、製造間接費として予定配賦率に含めておき、各指図書に配賦する。
::

::example 補修と代品の仕損費を計算し、仕訳しなさい
(1) No.201のラベルの誤植について、補修指図書No.201-1を発行して貼り替えた。補修指図書に集計された原価は、ラベルの再印刷60,000円、直接労務費36,000円（20時間）、製造間接費（瓶詰め部門）28,800円（4時間）だった。この仕損費をNo.201に賦課する。
(2) 別の注文No.202（酒販店のプライベートブランド1,200本、原価1,500,000円）の瓶詰めで、ラインの故障により60本が割れて仕損となった。代品指図書No.202-1を発行して60本を作り直し、その原価は90,000円だった。割れずに回収できた酒は料理酒として転用でき、評価額は6,000円である。仕損費はNo.202に賦課する。
::answer
::journal (1-a) 補修指図書の原価を仕損費に振り替える
仕損費 124,800 | 仕掛品 124,800
::
::journal (1-b) 仕損費をNo.201に賦課する
仕掛品 124,800 | 仕損費 124,800
::
::journal (2-a) 代品指図書の原価から、仕損品の評価額を除いて仕損費とする
仕損品 6,000 | 仕掛品 90,000
仕損費 84,000 |
::
::journal (2-b) 仕損費をNo.202に賦課する
仕掛品 84,000 | 仕損費 84,000
::
(1)の補修指図書No.201-1の原価は、いったん仕掛品勘定に集められている（補修も「製造」だから）。それを仕損費に振り替え、元の指図書No.201の原価に加える。仕掛品勘定の中で、補修指図書から元の指図書へ原価が移るだけなので、(1-a)と(1-b)は1本にまとめて書かれることもある。
(2)は、代品の原価90,000円から、転用できる仕損品の価値6,000円を引いた84,000円が仕損費だ。仕損品の評価額は**仕損品**勘定（資産）に振り替える。
::
::

::sort 次の仕損費を、元の指図書に賦課するか、製造間接費として配賦するかに分けなさい。
@cats 元の指図書に賦課する | 製造間接費として配賦する
特定の注文のラベルの誤植による貼り替えの費用 => 元の指図書に賦課する
特定の注文の特殊な瓶が割れて作り直した費用 => 元の指図書に賦課する
どの注文の瓶詰めでも毎月ほぼ一定量出る、王冠の打ち損じ => 製造間接費として配賦する
どの仕込みでも一定の割合で出る、ろ過の失敗による手直し => 製造間接費として配賦する
::

## 原価計算表から、勘定へ

2月末の汐見酒造の注文生産は、3つの指図書があった。原価計算表を集計すると、仕掛品・製品・売上原価の金額がそのまま決まる。

::example 2月の指図書別原価計算表から、月末の仕掛品・製品と、売上原価を求めなさい
::table 2月の指図書別原価計算表の要約（単位：円）
| 指図書 | 月初仕掛品 | 当月の製造原価（仕損費を含む） | 合計 | 2月末の状態 |
| No.201（結婚式の酒） | 0 | 1,098,000 | 1,098,000 | 完成・3月に引き渡し予定 |
| No.202（酒販店のPB） | 420,000 | 1,164,000 | 1,584,000 | 完成・2月に引き渡し済み |
| No.203（料亭の記念酒） | 0 | 350,000 | 350,000 | 未完成 |
::
::answer
- 月末仕掛品：未完成のNo.203 → **350,000円**
- 月末製品：完成して未引渡しのNo.201 → **1,098,000円**
- 売上原価：引き渡したNo.202 → **1,584,000円**
::journal 2月に完成した指図書（No.201とNo.202）を製品へ
製品 2,682,000 | 仕掛品 2,682,000
::
::journal 引き渡したNo.202の売上原価
売上原価 1,584,000 | 製品 1,584,000
::
::tgrid
::taccount 仕掛品（注文生産）
前月繰越 420,000 | 製品 2,682,000
当月製造原価 2,612,000 | 次月繰越 350,000
= 3,032,000 | 3,032,000
::
::taccount 製品（注文生産）
仕掛品 2,682,000 | 売上原価 1,584,000
 | 次月繰越 1,098,000
= 2,682,000 | 2,682,000
::
::
当月製造原価2,612,000円は、No.201の1,098,000円、No.202の1,164,000円、No.203の350,000円の合計。仕損費は元の指図書の原価に含まれているので、別に数える必要はない。
::
::

## 答え合わせ ― 赤字の内訳

::scene 2月の最終週 ― 蔵の事務所
「誤植の12万4,800円は、私たちのミスです。でも、残りの16万5,200円は」
澪は、見積りと実際の原価計算表を並べた。椎名は「差を、項目ごとに分けてみてください」とだけ言った。
::

::solve 黒字が赤字になったのは、見積りの甘さと、仕損費の賦課
::table No.201の見積りと実際の差（単位：円）
| 差の原因 | 金額 |
| 直接作業時間の延び（100時間→130時間）による直接労務費 | 54,000 |
| 同じく、醸造部門費の配賦額 | 76,800 |
| 瓶詰めの延び（10時間→12時間）による瓶詰め部門費 | 14,400 |
| 特注の瓶の値上がり | 20,000 |
| ラベルの誤植の仕損費（補修指図書から賦課） | 124,800 |
|= 合計 | 290,000 |
::
見積り80万8,000円は、2つの点で甘かった。1つは、小仕込みにかかる作業時間を大きなタンクと同じ感覚で見積もったこと（差の約半分、14万5,200円）。もう1つは、仕損の可能性を見積りに入れていなかったこと。仕損費12万4,800円は、この指図書に固有の失敗なので、No.201の原価に賦課される。
個別原価計算は、注文ごとに「いくらかかったか」を正直に映す。見積りが甘ければ、その甘さは、そのまま原価計算表に表れる。
::

式場との約束の値段は変えられない。No.201は約10万円の赤字で引き渡すことになった。ただ、澪の手元には、初めての注文生産の「実際の原価計算表」が残った。小仕込みにかかる作業時間、特注の瓶の値段、名前入りのラベルの確認の手順。次の見積りは、この表から始められる。

::danger 個別原価計算で、原価の「付け替え」が起きる理由
個別原価計算では、作業時間の記録しだいで、ある指図書の原価を別の指図書に移せてしまう。赤字になりそうな注文の作業時間を、余裕のある注文の作業日報に書けば、赤字は見えなくなる。造船や建設のような受注産業で、原価の付け替えが不正の手口として繰り返し問題になってきたのは、このためだ。
作業日報を製造指図書の番号ごとに正確につけること、見積りと実際の差を指図書ごとに検証することが、注文生産の採算を守る基本になる。
::

## 商社時代の記憶 ― 1隻500億円で受けた豪華客船

::scene 2月の最終週、夜 ― 蔵の事務所
No.201の赤字の原価計算表を前に、澪は、商社にいたころのことを思い出していた。鉄鋼の輸出入を担当していた澪は、造船所に厚板を納める仕事にも関わった。そのころ、取引先の造船所の人たちの間で、繰り返し語られていた話がある。
「見積りを外すと、船は1隻で会社を傾ける」
そう言って彼らが挙げたのが、三菱重工業の大型客船だった。
::

2011年、三菱重工業は、ドイツのクルーズ会社アイーダ・クルーズから、大型客船2隻を約**1,000億円**で受注した。総トン数は約12万5,000トン、全長300m、客室1,643室。建造は難航した。1番船「アイーダ・プリマ」の引き渡しは、当初の2015年3月から3度延期され、2016年3月になった。2017年に2番船「アイーダ・ペルラ」を引き渡したとき、大型客船事業の累計の損失は**2,500億円**を超えていた。同社は、大型客船の新規受注を凍結した。
船は、典型的な個別原価計算の製品だ。1隻ごとに製造指図書が発行され、設計・鋼材・艤装・労務・設備の費用が、その指図書の原価計算表に積み上がっていく。澪は、仕組みを示すために単純化して、受注額1,000億円の2隻分の指図書に、受注額と損失の合計にあたる約3,500億円の原価が集まったとして、勘定の流れを描いてみた（実際の損失には、引当金など複数の項目が含まれる。単位：億円）。

::journal ① 2隻の製造指図書に、原価が積み上がる
仕掛品 3,500 | 材料・賃金・製造間接費など 3,500
::
::journal ② 引き渡し：受注額（売上）は1,000億円で変わらない
製品 3,500 | 仕掛品 3,500
売上原価 3,500 | 製品 3,500
売掛金 1,000 | 売上 1,000
::

受注生産の値段は、注文を受けたときの見積りで決まる。完成までに原価がいくら膨らんでも、受注額は増えない。結婚式の500本の酒の赤字10万円と同じ構図が、何百万倍もの規模で起きたのだ。報道では、初めて手がける仕様の設計のやり直しや、工程の遅れが原因として挙げられた。
翌朝、澪は、No.201の見積りと実際の差を、営業担当と小松と一緒に1行ずつ確かめた。小仕込みの作業時間、特注の瓶、ラベルの校正。「次の見積りから、この3つは必ず確かめる」。その日、事務所の壁に、新しい確認表が貼られた。

::note
出典：[ニュースイッチ（日刊工業新聞）「三菱重工、大型客船事業2500億円超えの損失。最後の２番船引き渡し」（2017年5月3日）](https://newswitch.jp/p/8898)
::

::cfo 次の注文の見積り ― 何を原価に入れて、値段を決めるか
3月、長岡の酒販店から、プライベートブランドの純米吟醸1,000本の注文の打診が来た。「1本1,500円なら、すぐに決めます」
澪は、No.201の反省を生かして、見積りの資料を作った。
::table 酒販店のPB 1,000本の見積りの資料
| 項目 | 見積り |
| 直接材料費 | 520,000円 |
| 直接作業時間（小仕込み・No.201の実績から） | 180時間 |
| 瓶詰めラインの機械運転時間 | 15時間 |
| 予定賃率 | 1時間1,800円 |
| 部門別の予定配賦率 | 醸造部門2,560円、瓶詰め部門7,200円 |
| 工場全体の予定配賦率（第4章、直接作業時間あたり） | 4,000円 |
| 正常な仕損の見込み（過去の注文生産の平均） | 製造原価の2% |
::
まず、部門別の配賦率で計算した原価と、正常な仕損の見込みを含めた1本あたりの原価を計算してから選んでほしい。
::choice A. 直接材料費と直接労務費だけを原価とし、2割の利益を乗せて1本約1,013円で出す
**× 製造間接費を忘れている。**直接材料費52万円＋直接労務費32万4,000円＝84万4,000円に2割を乗せると、101万2,800円。1本約1,013円だ。だが、この注文も、醸造部門と瓶詰め部門の人・設備・ボイラーを使う。部門別に配賦される製造間接費は、180時間×2,560円＋15時間×7,200円＝**56万8,800円**。これを含めると原価は141万2,800円で、売るほど赤字が増える。
::
::choice B. 部門別に配賦した製造間接費と、正常な仕損の見込みを含めた原価に、利益を乗せる
**◎ No.201の教訓をすべて生かしている。**直接材料費52万円＋直接労務費32万4,000円＋製造間接費56万8,800円＝141万2,800円。仕損の見込み2%の2万8,256円を加えて**約144万1,000円**、1本約1,441円になる。
酒販店の提示した1,500円なら、1本あたり約59円、全体で約6万円の利益だ。薄利だが赤字ではない。1割の利益を確保したいなら、1本約1,590円を提示して交渉することになる。
::
::choice C. No.201の実際原価（1本2,196円）を使い、1本2,400円で出す
**△ 実績に学ぶのはよいが、使い方を誤っている。**No.201の原価には、ラベルの誤植という、その指図書に固有の失敗（仕損費12万4,800円）が含まれている。しかも、500本と1,000本では、1本あたりの作業時間も違う。2,400円では、酒販店は他の蔵へ行くだろう。過去の実績は「作業時間の見積り」に使い、失敗の費用は「正常な仕損の見込み」として平均の率で織り込むのが筋だ。
::
::choice D. 第4章の工場全体の配賦率（1時間4,000円）で製造間接費を計算する
**× 第5章で捨てた物差しに戻っている。**工場全体の率で計算すると、製造間接費は180時間×4,000円＝72万円。部門別より15万1,200円多い。この注文は小仕込みで手間がかかる一方、瓶詰めラインはほとんど使わない。人の時間で機械の費用まで割り振れば、原価を過大に見積もり、取れる注文を逃してしまう。
::
::answer 考え方の例を見る
見積りの原価には、直接費だけでなく、その注文が使う部門の製造間接費を、正しい物差しで含める。そして、仕損のように「いつかは起きる失敗」は、過去の実績から平均の率で織り込む。個別の失敗の費用をそのまま次の見積りに乗せるのではなく、失敗の原因を断つ手順（今回なら、名簿の確認）で防ぐ。
澪は、1本1,580円で交渉し、1,550円で折り合った。ラベルの校正は、酒販店の担当者の確認の署名をもらう手順にした。
::
::

::exam 個別原価計算の出題の急所
- 指図書ごとの**原価計算表**から、月末の状態で振り分ける：未完成→**月末仕掛品**、完成・未引渡し→**月末製品**、引渡済み→**売上原価**
- 前月から続いている指図書は、**月初仕掛品**の金額を忘れずに加える
- **仕損費**：補修なら補修指図書の原価、代品なら代品の原価（全部仕損なら元の指図書の原価）から仕損品の評価額を引く。仕損品の評価額は「仕損品」勘定へ
- 仕損費は、元の指図書に**賦課**（仕掛品／仕損費）するか、**製造間接費**として配賦する。問題文の指示に従う
- 製造間接費は、部門別の予定配賦率で配賦することが多い。指図書ごとの部門別の作業時間・機械時間を読み落とさない
::

::next 受注生産の採算は、見積りと「一定期間の収益認識」へ
個別原価計算は、造船・建設・システム開発などの受注産業の原価計算の基本だ。完成まで何年もかかる受注では、完成を待たずに、工事の進み具合に応じて売上と原価を計上する方法もある（第13章の「一定の期間にわたり充足される履行義務」）。その場合、見積りの総原価が受注額を上回ることが分かった時点で損失を見込む処理が必要になり、1級で「工事契約」として学ぶ。
::

## 確認問題

::quiz
::problem 次の資料から、当月の売上原価、月末の仕掛品、月末の製品を求めなさい。
No.1：前月から繰り越した仕掛品 200,000円、当月の製造原価 300,000円。当月完成し、当月引き渡した。
No.2：当月着手、当月の製造原価 450,000円。当月完成し、翌月引き渡す予定。
No.3：当月着手、当月の製造原価 180,000円。月末未完成。
売上原価 [[500,000]] 円、月末仕掛品 [[180,000]] 円、月末製品 [[450,000]] 円
::answer
引渡済みのNo.1は前月分と当月分の合計500,000円が**売上原価**。完成・未引渡しのNo.2の450,000円が**月末製品**。未完成のNo.3の180,000円が**月末仕掛品**。
::
::
::problem 次の取引を仕訳しなさい。
(1) 製造指図書No.5の製品の一部に仕損が生じ、補修指図書No.5-1を発行して補修した。補修指図書に集計された原価は45,000円である。この仕損費は、No.5に直接経費として賦課する（仕損費勘定を経由する）。
(2) 製造指図書No.8の製品がすべて仕損となり、代品を製造した。No.8に集計されていた原価は300,000円、仕損品の評価額は20,000円である。仕損費は仕損費勘定に計上する。
::answer
::journal (1)
仕損費 45,000 | 仕掛品 45,000
仕掛品 45,000 | 仕損費 45,000
::
::journal (2) 全部仕損：元の指図書の原価－評価額
仕損品 20,000 | 仕掛品 300,000
仕損費 280,000 |
::
(2)のように、元の指図書全体が仕損になったときは、元の指図書の原価から評価額を引いた額が仕損費になる。代品を作るための新しい指図書の原価は、そのまま代品の原価として集計していく。
::
::
::problem 指図書No.11の当月の原価を計算しなさい。直接材料費 250,000円、直接作業時間 60時間（予定賃率 1,500円）、製造間接費は直接作業時間を基準に予定配賦率1時間2,000円で配賦する。
No.11の当月の製造原価 [[460,000]] 円
::answer
250,000円＋60時間×1,500円＋60時間×2,000円＝250,000円＋90,000円＋120,000円＝**460,000円**
::

::summary
- 個別原価計算は、受注生産で、製造指図書ごとに原価計算表を作って原価を集める方法。直接費は賦課、製造間接費は（部門別の）予定配賦率で配賦する
- 月末に、未完成の指図書は仕掛品、完成・未引渡しは製品、引渡済みは売上原価になる
- 仕損費は、補修なら補修指図書の原価、代品なら代品の原価（全部仕損なら元の指図書の原価）から仕損品の評価額を引いた額
- 仕損費は、その指図書に固有なら元の指図書に賦課し、毎期ある程度生じるものは製造間接費として配賦する
- 見積りの原価には、製造間接費と正常な仕損の見込みを含める。受注の値段は見積りで決まり、実際の原価が膨らんでも増えない
::
