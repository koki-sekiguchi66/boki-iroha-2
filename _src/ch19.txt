## まだ起きていない費用 ― 引当金の4つの条件

澪は、椎名の一覧を指でたどった。
澪：「賞与も退職金も修繕も、まだ1円も払っていません。払ったときに費用にすればいいのでは？」
椎名：「小松さんの40年の仕事は、いつ行われましたか？」
澪：「……今期までに、です」
椎名：「退職金は、その40年の仕事への対価です。払うのは再来年でも、原因は今期までにある。だから、今期までの分を、今期までの費用にしておくんです」

::theory 引当金の4つの条件
次の4つの条件をすべて満たすとき、当期の費用（または損失）として**引当金**を計上する。
1. 将来の、特定の費用または損失である
2. その発生が、当期以前の出来事に起因している
3. 発生する可能性が高い
4. 金額を合理的に見積もることができる
引当金は、費用（○○引当金繰入など）の相手として、貸借対照表の負債（貸倒引当金は資産の控除）に計上する。将来、実際に支払いが起きたら、引当金を取り崩す。
::

小松の退職金は、4つの条件をすべて満たす。払う相手と額が決まっていて（1）、原因は40年の勤務にあり（2）、払うことはほぼ確実で（3）、額は規程で決まっている（4）。だから、今期までの勤務に対応する分を、今期までの費用にする。

## 貸倒引当金 ― 一括評価と個別評価

3級では、売掛金の残高に一定の率を掛けて貸倒引当金を設定した。2級では、相手の状態に応じて、2つの方法を使い分ける。

::theory 一括評価と個別評価
- **一括評価**：経営に問題のない相手への債権（一般債権）は、まとめて、過去の貸倒実績率などを掛けて見積もる
- **個別評価**：経営が破綻した、または破綻のおそれが大きい相手への債権は、1件ずつ、回収できない見込みの額を見積もる。担保や保証金があれば、その分を差し引いた残りが対象になる
- 売掛金・電子記録債権など**営業債権**の貸倒引当金繰入は**販売費及び一般管理費**、貸付金など**営業外債権**の繰入は**営業外費用**に表示する
::

::example 6月30日、蔵の決算で貸倒引当金を設定する
(1) 売掛金と電子記録債権の期末残高50,000,000円について、貸倒実績率2%で一括評価する。貸倒引当金の残高は600,000円である（差額補充法）。
(2) 芹沢酒造への長期貸付金10,000,000円について、2%で一括評価する（貸倒引当金の残高はない）。
::answer
::journal (1) 50,000,000円×2%＝1,000,000円。残高600,000円との差額だけ繰り入れる
貸倒引当金繰入 400,000 | 貸倒引当金 400,000
::
::journal (2) 営業外債権の分。繰入額は営業外費用に表示する
貸倒引当金繰入 200,000 | 貸倒引当金 200,000
::
勘定科目は同じ「貸倒引当金繰入」でも、(1)は販売費及び一般管理費、(2)は営業外費用になる。損益計算書の区分が違う。
::trap
見積額より残高のほうが多いときは、多すぎる分を「貸倒引当金戻入」（収益）として戻す。残高を見落として、見積額をまるごと繰り入れないこと。
::
::
::

蔵の得意先には、今のところ破綻した相手はない。椎名は、別の顧問先で去年あった例を見せてくれた。

::example 民事再生を申し立てた得意先 ― 個別評価と一括評価を合わせる
県内のある酒販店の決算。得意先の居酒屋チェーンが民事再生を申し立てた。この得意先への売掛金3,000,000円から、取引を始めるときに預かった営業保証金1,000,000円を差し引いた残額の50%を、個別に引き当てる。ほかの売掛金20,000,000円は、貸倒実績率1%で一括評価する。貸倒引当金の残高は150,000円である（差額補充法）。
::answer
::journal 個別評価(3,000,000円－1,000,000円)×50%＝1,000,000円、一括評価20,000,000円×1%＝200,000円。合計1,200,000円－残高150,000円
貸倒引当金繰入 1,050,000 | 貸倒引当金 1,050,000
::
::trap
個別評価した債権は、一括評価の対象から除く。また、担保や保証金を先に差し引いてから、率を掛ける。
::
::
::

## 賞与・退職給付・修繕・製品保証 ― 4つの引当金

::table 2級で学ぶ引当金（貸倒引当金のほか）
| 引当金 | 何のための引当金か | 繰入の勘定 | 取り崩すとき |
| 賞与引当金 | 次の期に払う賞与のうち、当期の勤務に対応する分 | 賞与引当金繰入 | 賞与を支給したとき |
| 退職給付引当金 | 将来払う退職金のうち、当期末までの勤務に対応する分 | 退職給付費用 | 退職金を支払ったとき |
| 修繕引当金 | 毎年使って傷んだ設備を、将来まとめて修繕する費用 | 修繕引当金繰入 | 修繕したとき |
| 製品（商品）保証引当金 | 売った製品を、保証の期間内に無料で修理・交換する費用 | 製品保証引当金繰入 | 修理・交換したとき |
::

::example 蔵の4つの引当金を仕訳する
(1) 6月30日、7月に支給する夏の賞与6,000,000円（支給対象期間は1月〜6月）を、賞与引当金として計上した。
(2) 7月10日（翌期）、夏の賞与6,000,000円を普通預金から支給した（源泉所得税などは考えない）。
(3) 6月30日、退職給付引当金の当期の繰入額4,000,000円を計上した。
(4) 4月に、勤続12年の瓶詰めの担当者が退職し、退職金1,000,000円を普通預金から支払った（退職給付引当金を取り崩す）。
(5) 6月30日、3年に1度のタンクの定期修繕（次回は来年の夏、見積額9,000,000円）に備え、当期の負担分3,000,000円を修繕引当金に繰り入れた。
(6) 6月30日、6月に売ったスパークリング1,000本について、噴きこぼれによる交換の見込み（交換率2%、1本の交換費用1,200円）を製品保証引当金として計上した。
::answer
::journal (1) 支給対象期間の6か月は、すべて当期
賞与引当金繰入 6,000,000 | 賞与引当金 6,000,000
::
::journal (2) 支給：引当金を取り崩す
賞与引当金 6,000,000 | 普通預金 6,000,000
::
::journal (3) 勘定は「退職給付費用」
退職給付費用 4,000,000 | 退職給付引当金 4,000,000
::
::journal (4)
退職給付引当金 1,000,000 | 普通預金 1,000,000
::
::journal (5)
修繕引当金繰入 3,000,000 | 修繕引当金 3,000,000
::
::journal (6) 1,000本×2%×1,200円
製品保証引当金繰入 24,000 | 製品保証引当金 24,000
::
来年の夏、タンクの修繕に9,500,000円かかったら、引当金の9,000,000円を取り崩し、足りない500,000円は修繕費とする。製品保証引当金は、期末に残っていたら取り崩して（製品保証引当金戻入）、新しく見積もり直す（洗替法）のがふつうだ。
::trap
退職給付引当金の繰入の勘定は「退職給付引当金繰入」ではなく**退職給付費用**。2級では、退職給付費用の額は問題文で与えられる（計算は1級）。
::
::
::

## 載らない8,000万円 ― 債務の保証と対照勘定

澪：「引当金のことは分かりました。でも、8,000万円の保証は？　これこそ、いちばん大きな『将来の支出』じゃないですか」
椎名：「4つ目までの条件を、もう一度見てください。3つ目は？」
澪：「発生する可能性が高い……」
椎名：「芹沢酒造は、いまも毎月、自分で返済しています。返済が続くかぎり、汐見酒造が払うことはない。払う可能性が高い、とまではまだ言えないんです」

::theory 債務の保証と対照勘定
他人の借金の保証人になることを**債務の保証**という。お金を借りた本人（主たる債務者）が払えなくなったとき、保証人が代わりに払う義務を負う。
保証しただけでは、まだ払う義務が現実になったわけではない（**偶発債務**）。だから、貸借対照表の負債には計上せず、**注記**で示す。そのうえで、保証の事実を帳簿に残しておくために、**保証債務見返**（資産）と**保証債務**（負債）という一対の勘定（**対照勘定**）で、同じ金額を両側に記録する。2つは同時に増え、同時に消えるので、資産と負債の差し引きには影響しない。
本人が払えなくなり、保証人が代わりに払ったときは、払った額を本人に請求する権利（**未収入金**など）とし、対照勘定は取り消す。
::

::example 芹沢酒造の借入金の保証を仕訳する
(1) 前期の6月30日、芹沢酒造が信用金庫から借りている80,000,000円について、汐見酒造が保証人となった（対照勘定で記録する）。
(2) 仮に、芹沢酒造が返済できなくなり、汐見酒造が保証人として5,000,000円を普通預金から代わりに支払ったとする。この5,000,000円の分の保証は、それで終わったものとする。
::answer
::journal (1) 保証の引受け：同じ額を、資産と負債の両側に記録する
保証債務見返 80,000,000 | 保証債務 80,000,000
::
::journal (2) 保証の履行：代わりに払った額は、芹沢酒造に請求できる
未収入金 5,000,000 | 普通預金 5,000,000
保証債務 5,000,000 | 保証債務見返 5,000,000
::
(2)の未収入金は、芹沢酒造が払えないから代わりに払ったのだから、回収が危うい。個別評価で貸倒引当金を設定することになる。保証は、相手が払えなくなったとき、一気に「回収できない債権」に姿を変える。
::trap
対照勘定は、保証の事実を記録するためのもので、損益には影響しない。履行したときに、対照勘定の取消しを忘れないこと。
::
::
::

父は、(1)の仕訳を岩倉に頼まなかった。だから、汐見酒造の帳簿には、保証の記録も注記もなかった。
その夜、澪は千尋に電話をした。千尋は長いあいだ黙っていたが、翌朝、芹沢酒造の決算書の写しを送ってくれた。売上は汐見酒造の4分の1ほど。借入金は8,000万円。直近の2期は、続けて赤字だった。
父が保証人になった理由は、分かった。借金を抱えた隣の蔵は、汐見酒造の保証がなければ、信用金庫から借りられなかったのだ。

::solve 退職金は「払う可能性が高い」から今期の費用にする。保証は「まだ高いとは言えない」から、対照勘定と注記で示す
小松の退職金、夏の賞与、タンクの修繕、スパークリングの交換。どれも、今期までの出来事が原因で、来期以降に払う可能性が高く、額も見積もれる。だから、**引当金**として今期の費用にする。
芹沢酒造の8,000万円の保証は違う。芹沢酒造が自分で返済を続けているかぎり、汐見酒造が払うことはない。払う可能性が高いとまでは言えないので、負債には載せず、**偶発債務**として注記で示し、帳簿では**対照勘定**（保証債務見返／保証債務）で記録する。
「保証は帳簿に出ない」のではない。**負債には載せないが、記録と注記で必ず示す**。前期の決算書は、その両方が漏れていた。
ただし、芹沢酒造の経営がさらに悪くなり、汐見酒造が払う可能性が高くなれば、話は変わる。そのときは、保証で出る損失を見込んで、引当金を計上する（債務保証損失引当金、1級の範囲）。載せない借金は、消えた借金ではない。いつでも、本物の負債に変わりうる。
::

### 試験で狙われるパターン ― 月割り・合算・不足・洗替

ここからは、試験で形を変えて出題される4つのパターンを押さえておこう。

**① 賞与引当金の月割り**　決算日と支給対象期間がずれる。たとえば3月決算で、6月に払う賞与（対象期間12月〜5月）なら、12月〜3月の4か月分だけを当期の賞与引当金にする。支給したときは、引当金を取り崩し、残りの2か月分は当期の賞与とする。

**② 個別評価と一括評価の合算**　個別評価した債権を除いてから一括評価し、2つの合計と残高を比べる（差額補充法）。営業外債権の分は、別に営業外費用とする。

**③ 修繕引当金を超える修繕と、資本的支出**　修繕引当金を取り崩し、足りない分は修繕費。資本的支出（性能を高めた分）が含まれていれば、その分は固定資産の取得原価に加える（第15章）。

**④ 製品保証引当金の洗替**　期末の残高を「製品保証引当金戻入」で戻し、新しい見積額を繰り入れる。

::steps 解法の型 ― 引当金と保証の決算整理
1. 当期末に必要な額を出す | 率・月数・見積額は問題文から。個別評価の債権は一括評価から除く
2. 残高と比べる | 差額補充法なら差額だけ繰り入れる。多すぎれば戻し入れる
3. 区分を決める | 営業債権は販管費、営業外債権は営業外費用。退職給付は「退職給付費用」
4. 支払ったら取り崩す | 不足は当期の費用、資本的支出は固定資産へ
5. 保証は対照勘定 | 保証債務見返／保証債務。履行したら未収入金とし、対照勘定を取り消す
::

## 信用金庫の応接室 ― 社長の判子が、継ぐ人の足を止める

::scene 6月25日、金曜日 ― 越後みなと信用金庫の応接室
澪と椎名は、審査を待たずに、保証のことを自分たちから高梨に伝えに来た。前期の決算書に注記が漏れていたこと。今期の決算書には必ず書くこと。
高梨は、しばらく黙ってから言った。
高梨：「芹沢さんの借入れは、うちの金庫です。保証のことは、こちらでは最初から分かっていました」
澪：「……知っていて、黙っていたんですか」
高梨：「載っていないものを、自分から出してくるかどうか。審査で私が見ているのは、数字だけじゃありません」
高梨は、少し言いにくそうに続けた。
高梨：「もう1つ。いまの4億円の借入金には、お父さまが個人で保証人になっておられます。澪さんが蔵を継がれるなら、その保証をどうするかも、考えておかないといけません」
::

日本の中小企業の多くは、金融機関から借りるとき、社長が会社の借金の**保証人**になってきた（経営者保証）。会社が払えなくなれば、社長の自宅や預金まで返済に充てられる。その重さが、後を継ぐ人の足を止めてきた。
高梨の話はこうだった。簿記の検定と同じ日本商工会議所と、全国銀行協会が事務局を務めた研究会が、2013年12月に「経営者保証に関するガイドライン」をまとめ、2014年2月から適用された。会社と経営者の財産がはっきり分かれているなどの条件を満たせば、保証を求めない融資を検討することなどを定めている。2019年12月には、事業承継に焦点を当てた**特則**がまとめられ、2020年4月から適用された。前の社長と後継者の両方から保証をとる「二重の保証」を、原則として求めないことなどを定めている。
高梨：「金融庁の集計では、2025年度に民間の金融機関が新しく貸した件数のうち、55.7%は、経営者保証に頼らない融資でした。社長が交代した先で、新しい社長が保証人にならなかった例は、合わせて56.4%。二重の保証は3.0%です」
高梨：「条件の1つは、会社と家族のお金が、帳簿の上ではっきり分かれていることです。毎月の試算表が正確に出てきて、載せるべきものを自分から載せる会社なら、保証を外す話もしやすくなります」
帰りの車の中で、澪は、2つの保証を、この章の勘定で並べてみた。

::journal 会社が、ほかの会社の借金を保証したとき（汐見酒造の帳簿、単位：万円）
保証債務見返 8,000 | 保証債務 8,000
::

社長個人が、自分の会社の借金を保証したとき（汐見酒造の帳簿）：**仕訳なし**。
会社から見れば、自分の借金はすでに借入金として載っている。だから、社長がいくらの保証を背負っているかは、会社の決算書を見ても分からない。継ぐかどうかを考える人にとって、本当に重いのは、この帳簿に載らない保証であることが多い。
父は、蔵の4億円を個人で保証し、そのうえ社長として、芹沢酒造の8,000万円の保証を会社に引き受けさせていた。どちらも、誰にも相談せずに。澪は、ハンドルを握る手に力が入るのを感じた。

::danger 判子1つで、帳簿の外に借金が増える
保証は、契約書に判子を押すだけで生まれ、記録しなければ帳簿のどこにも現れない。しかも、連帯保証人は、お金を貸した側から請求されたとき、「先に本人に請求してほしい」「本人の財産から取ってほしい」と言えない。会社として保証するなら、社内の正式な手続を経て、対照勘定の記録と注記を漏らさない。決算書を読む側は、注記の偶発債務を必ず確かめる。
::

::cfo 小松の退職金1,200万円 ― 引当金を積めば、払えるのか
決算整理の一覧を閉じて、岩倉が安心したように言った。「これで小松さんの退職金も、引当金に積み上がりました。再来年の1,200万円は、もう準備ができとるわけですな」。
**前提**
- 小松の退職金は1,200万円。2029年3月に払う（父と約束し、規程にもある）
- 6月30日の退職給付引当金のうち、小松の分は1,100万円
- 退職給付引当金の残高は、前期より300万円増えた
- 6月30日の普通預金は、約1,500万円の見込み
- 来期の資金繰りは、酒税・米代・借入金の返済で、毎月ぎりぎり
- 支払いまでは、あと20か月ある（2027年7月〜2029年2月）
::choice A. 引当金に1,100万円を積んであるので、退職金の準備はもうできている
**× 引当金は、お金の準備ではない。**1,100万円は「払う義務のうち、今までの分」を負債として示した数字だ。「退職給付費用／退職給付引当金」の仕訳で、預金は1円も動いていない。2029年3月に1,200万円の現金があるかどうかは、まったく別の問題だ。
::
::choice B. いまある普通預金から1,200万円を、すぐに別の定期預金に移しておく
**○ お金を分けて準備する方向は正しいが、時期が早すぎる。**1,500万円のうち1,200万円を今動かせば、残りは300万円。毎月ぎりぎりの資金繰りでは、酒税や米代を払えなくなるおそれがある。
::
::choice C. 小松に、退職金を何回かに分けて受け取ってもらうよう、今から頼んでおく
**△ 選べる手ではあるが、順番が逆だ。**40年の仕事への対価を、蔵の都合で後回しにする前に、まず蔵の側で準備の計画を立てる。それでも足りないときに、事情を話して誠実に相談するのが筋だ。
::
::choice D. 引当金とは別に、資金繰り表に毎月60万円の退職金の積立てを組み込む
**◎ 帳簿の準備と、お金の準備を分けている。**60万円×20か月＝1,200万円で、2029年3月に間に合う。引当金で費用と負債を正しく示したうえで、お金は毎月の資金繰りの中で準備する。苦しい資金繰りから毎月60万円をどう生み出すかは、来期の経営の課題そのものだ。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「引当金を積んだか」ではなく、「2029年3月に、1,200万円の現金が手元にあるか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 帳簿の準備と、お金の準備（単位：万円）
| 項目 | 退職給付引当金（小松の分） | 退職金のための預金 |
| 6月30日（いま） | 1,100 | 0 |
| 毎月60万円を20か月積み立てた後 | 1,200 | 1,200 |
::
引当金の1,100万円があっても、退職金のための預金は0円だ。毎月60万円ずつ積み立てて、はじめて支払いの月に1,200万円がそろう。
#### 手順3　ほかの答えに引かれる理由
Aは「引当金」という名前に、Bは「早く安心したい」という焦りに、Cは「小松さんなら分かってくれる」という甘えに引かれる。退職給付引当金が前期より300万円増えたことは、お金の準備とは関係のない前提だ。
#### 持ち帰る考え方
- **引当金は帳簿の準備、積立てはお金の準備**：費用の計上と、資金の手当ては、別々に考える
- **将来の大きな支払いは、資金繰り表に月割りで入れる**：準備ができたかは、引当金ではなく預金の残高で測る
#### 前提が変われば
資金に余裕があれば、一度に別の口座へ移す（B）のもよい。毎月60万円を出せないほど苦しいなら、借入金の返済の条件を高梨と相談するか、小松に事情を話して支払い方を相談する（C）ことになる。
::
::

::exam 引当金と保証の急所
- 引当金の4条件：将来の特定の費用・損失／当期以前の出来事に起因／発生の可能性が高い／金額を合理的に見積もれる
- 貸倒引当金は**差額補充法**。個別評価は「債権額－担保・保証金」に問題文の率を掛ける。個別評価した債権は一括評価から除く
- 営業債権の繰入は販管費、**営業外債権（貸付金など）**の繰入は営業外費用
- 賞与引当金は、**支給対象期間のうち当期に属する月数分**
- 退職給付引当金の繰入は**退職給付費用**。修繕引当金の不足は修繕費、資本的支出は固定資産
- 債務の保証は**偶発債務**。負債には載せず、**保証債務見返／保証債務**の対照勘定で記録し、注記する。履行したら未収入金とし、対照勘定を取り消す
::

::next 引当金と負債の会計の先にある論点
1級では、退職給付債務の計算（割引計算・年金資産・数理計算上の差異）、債務保証損失引当金、資産除去債務などを学ぶ。引当金は見積りの塊だ。見積りを甘くすれば利益は増え、厳しくすれば減る。決算書の注記の「重要な会計上の見積り」を読むと、会社がどこで見積りをしているかが分かる。
::

::summary
- 引当金は、将来の特定の費用・損失で、当期以前の出来事が原因で、発生の可能性が高く、金額を見積もれるときに計上する
- 貸倒引当金は、一般の債権は一括評価、破綻した相手などへの債権は個別評価。営業債権の繰入は販管費、営業外債権の繰入は営業外費用
- 賞与引当金・退職給付引当金（繰入は退職給付費用）・修繕引当金・製品保証引当金は、繰入で費用と負債を計上し、支払ったときに取り崩す
- 債務の保証は偶発債務。負債には載せず、対照勘定（保証債務見返・保証債務）で記録して注記する
- 引当金は帳簿の上の準備であって、お金の準備ではない
::
