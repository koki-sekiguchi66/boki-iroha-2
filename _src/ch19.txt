## 引当金 ― 将来の支出を、原因のある期の費用にする

::theory 引当金の4つの条件
次の4つの条件をすべて満たすとき、当期の費用（または損失）として**引当金**を計上する。
1. 将来の、特定の費用または損失である
2. その発生が、当期以前の出来事に起因している
3. 発生する可能性が高い
4. 金額を合理的に見積もることができる
引当金は、費用（○○引当金繰入）の相手として、貸借対照表の負債（貸倒引当金は資産の控除）に計上する。将来、実際に支払いが起きたら、引当金を取り崩す。
::

小松の退職金は、40年間の勤務の対価として、2年後に払う。その原因（勤務）は、今期までの40年間にある。払うことはほぼ確実で、金額も退職金の規程で決まっている。4つの条件を満たすから、今期までの勤務に対応する分を、今期までの費用にしておく。

## 貸倒引当金 ― 一括評価と個別評価

3級では、売掛金の残高に一定の率を掛けて貸倒引当金を設定した。2級では、債権の相手の状態に応じて、2つの方法を使い分ける。

::theory 一括評価と個別評価
- **一括評価**：経営に問題のない相手への債権（一般債権）は、まとめて、過去の貸倒実績率などを掛けて見積もる
- **個別評価**：経営破綻した、または破綻のおそれが大きい相手への債権は、1件ずつ、回収できない見込みの額を見積もる。担保や保証金があれば、その分を差し引いた残りが対象になる
- 売掛金・電子記録債権など**営業債権**の貸倒引当金繰入は**販売費及び一般管理費**、貸付金など**営業外債権**の繰入は**営業外費用**に表示する
{{new:2027年度〜}} 貸倒引当金の個別評価は、2027年度からの出題区分表で2級の論点として明記された。
::

::example 6月30日の決算で、貸倒引当金を設定しなさい
(1) 居酒屋チェーンへの売掛金6,000,000円について、相手が民事再生を申し立てた。取引の開始のときに預かった保証金1,000,000円があるので、それを差し引いた残額の全額を個別に引き当てる。
(2) (1)以外の売掛金と電子記録債権の期末残高50,000,000円について、貸倒実績率2%で一括評価する。貸倒引当金の残高は600,000円である（差額補充法）。
(3) 芹沢酒造への貸付金10,000,000円について、2%で一括評価する（貸倒引当金の残高はない）。
::answer
::journal (1) 個別評価：6,000,000円－1,000,000円
貸倒引当金繰入 5,000,000 | 貸倒引当金 5,000,000
::
::journal (2) 一括評価：50,000,000円×2%＝1,000,000円、残高600,000円との差額
貸倒引当金繰入 400,000 | 貸倒引当金 400,000
::
::journal (3) 営業外債権：繰入額は営業外費用
貸倒引当金繰入 200,000 | 貸倒引当金 200,000
::
(1)(2)は販売費及び一般管理費、(3)は営業外費用に表示する。勘定科目は同じ「貸倒引当金繰入」でも、損益計算書の区分が違う。
::
::

## 賞与・退職給付・修繕・製品保証 ― 4つの引当金

::table 2級で学ぶ引当金（貸倒引当金以外）
| 引当金 | 何のための引当金か | 繰入の勘定 | 取り崩すとき |
| 賞与引当金 | 次の期に払う賞与のうち、当期の勤務に対応する分 | 賞与引当金繰入 | 賞与を支給したとき |
| 退職給付引当金 | 将来払う退職金・年金のうち、当期末までの勤務に対応する分 | 退職給付費用 | 退職金を支払ったとき |
| 修繕引当金 | 毎年使って傷んだ設備を、将来まとめて修繕する費用 | 修繕引当金繰入 | 修繕したとき |
| 商品（製品）保証引当金 | 販売した商品・製品を、保証期間内に無料で修理・交換する費用 | 商品（製品）保証引当金繰入 | 修理・交換したとき |
::

::example 4つの引当金の取引を仕訳しなさい
(1) 6月30日、7月に支給する夏の賞与6,000,000円（支給対象期間は1月〜6月）を、賞与引当金として計上した。
(2) 7月10日（翌期）、夏の賞与6,000,000円を普通預金から支給した（源泉所得税などは考えない）。
(3) 6月30日、退職給付引当金の当期の繰入額4,000,000円を計上した。
(4) 4月に、勤続30年の蔵人が退職し、退職金1,000,000円を普通預金から支払った（退職給付引当金を取り崩す）。
(5) 6月30日、3年に1度のタンクの定期修繕（次回は来年の夏、見積額9,000,000円）に備え、当期の負担分3,000,000円を修繕引当金に繰り入れた。
(6) 6月30日、6月に発売したスパークリング1,000本について、噴きこぼれによる交換の見込み（交換率2%、1本の交換費用1,200円）を製品保証引当金として計上した。
::answer
::journal (1)
賞与引当金繰入 6,000,000 | 賞与引当金 6,000,000
::
::journal (2) 支給：引当金を取り崩す
賞与引当金 6,000,000 | 普通預金 6,000,000
::
::journal (3)
退職給付費用 4,000,000 | 退職給付引当金 4,000,000
::
::journal (4)
退職給付引当金 1,000,000 | 普通預金 1,000,000
::
::journal (5)
修繕引当金繰入 3,000,000 | 修繕引当金 3,000,000
::
::journal (6) 1,000本×2%×1,200円
製品保証引当金繰入 24,000 | 製品保証引当金 24,000
::
来年の夏、タンクの修繕に9,500,000円かかったら、引当金の9,000,000円を取り崩し、足りない500,000円は修繕費とする（「修繕引当金 9,000,000・修繕費 500,000／普通預金 9,500,000」）。製品保証引当金は、期末に残っていたら取り崩して（戻入）、新しく見積もり直すのがふつうだ。
{{new:2027年度〜}} 退職給付引当金は、2027年度からの出題区分表で2級の論点として明記された。2級では、退職給付費用の金額は問題文で与えられる（計算は1級）。
::
::

::exam 引当金の急所
- 貸倒引当金：**差額補充法**（見積額－残高を繰入。残高が多ければ戻入）。個別評価は「債権額－担保・保証金」が基本で、その何%を引き当てるかは問題文の指示に従う
- 営業債権の繰入は販管費、**営業外債権（貸付金など）**の繰入は営業外費用
- 賞与引当金は、**支給対象期間のうち当期に属する月数分**を計上する（「12月〜5月の賞与のうち3月決算なら4か月分」など）
- 退職給付費用の勘定名は「退職給付引当金繰入」ではなく**退職給付費用**
- 修繕引当金を取り崩した後の不足は修繕費。資本的支出が含まれていれば、その分は固定資産に加える
- 製品保証引当金：期末の残高を戻し入れ（製品保証引当金戻入）、新たに見積もる洗替法が問われることが多い
::

## 債務の保証 ― 載せない負債を、載せずに記録する

::theory 債務の保証と、対照勘定
他人の借金の保証人になることを**債務の保証**という。主たる債務者が払えなくなったとき、保証人が代わりに払う義務を負う。
保証しただけでは、まだ実際に払う義務が生じたわけではない（**偶発債務**）。だから、貸借対照表の負債には計上せず、注記で示す。ただし、保証の事実を帳簿に残しておくために、**保証債務見返**（資産）と**保証債務**（負債）という一対の勘定（**対照勘定**）で、同じ金額を両側に記録する方法がある。この2つは同時に増え、同時に消えるので、資産と負債の差し引きには影響しない。
主たる債務者が払えなくなって、保証人が代わりに払ったときは、払った額を、主たる債務者に請求する権利（**未収入金**など）とし、対照勘定は取り消す。
::

::example 芹沢酒造の借入金の保証を仕訳しなさい
(1) 前期の6月30日、芹沢酒造が信金から借りている80,000,000円について、汐見酒造が保証人となった（対照勘定で記録する）。
(2) 仮に、芹沢酒造が返済できなくなり、汐見酒造が保証人として元本の一部5,000,000円を普通預金から代わりに支払ったとする。同額の保証は、それで終わったものとする。
::answer
::journal (1) 保証の引受け：資産と負債の両側に同額を記録する
保証債務見返 80,000,000 | 保証債務 80,000,000
::
::journal (2) 保証の履行：代わりに払った額は、芹沢酒造に請求できる
未収入金 5,000,000 | 普通預金 5,000,000
保証債務 5,000,000 | 保証債務見返 5,000,000
::
(2)で、代わりに払った5,000,000円は、芹沢酒造から取り戻す権利として未収入金になる。だが、芹沢酒造が払えないから保証を履行したのだから、この未収入金は回収が危うい。個別評価で貸倒引当金を設定する必要が出てくる。保証は、相手が払えなくなったとき、一気に「回収できない債権」に姿を変える。
::
::

## 答え合わせ ― 載せる費用と、載せない借金

::solve 引当金は「起きる可能性が高い」から載せ、保証は「まだ起きていない」から注記で示す
小松の退職金、夏の賞与、タンクの修繕、スパークリングの交換、居酒屋チェーンの貸倒れ。どれも、今期までの出来事が原因で、来期以降に支出が起きる可能性が高く、金額も見積もれる。だから、引当金として今期の費用にする。
芹沢酒造の8,000万円の保証は違う。芹沢酒造が自分で返済を続けているかぎり、汐見酒造が払うことはない。払う可能性が高いとまでは言えないので、負債には載せず、**偶発債務**として注記で示し、帳簿では対照勘定で記録する。
ただし、芹沢酒造の経営がさらに悪化して、汐見酒造が払う可能性が高くなれば、話は変わる。そのときは、保証による損失を見込んで引当金を計上する（債務保証損失引当金、1級の範囲）。載せない借金は、消えた借金ではない。いつでも、本物の負債に変わりうる。
::

澪は、芹沢酒造の決算書を取り寄せた。売上は汐見酒造の4分の1ほど、借入金は8,000万円。2期続けて赤字だった。父が保証人になった理由は分かった。だが、この保証は、汐見酒造の決算書を読む高梨にとって、注記の1行では済まない重さを持っている。芹沢酒造をどうするか。その答えは、第3部で出すことになる。

## 高梨の確認 ― 社長の個人保証が、事業承継を止める

::scene 6月24日、木曜日 ― 越後みなと信用金庫の応接室
決算の見込みの説明を終えた後、高梨は、少し言いにくそうに切り出した。
「澪さん、もう1つ。いまの4億円の借入金には、お父さまが個人で保証人になっておられます。いずれ澪さんが蔵を継がれるなら、その保証をどうするかも、考えておかないといけません」
「私が、父の代わりに保証人になる、ということですか」
「以前は、それが当たり前でした。後を継ぐ人が、その重さに耐えられずに、継ぐのをやめてしまう。そういう例を、私もいくつも見てきました。だから、国も銀行も、やり方を変えてきたんです」
::

日本の中小企業の多くは、金融機関から借りるとき、会社の借金について、社長が**個人で保証人**になってきた（経営者保証）。会社が払えなくなれば、社長の自宅や預金まで返済に充てられる。その重さが、後を継ぐ人の足を止めてきた。
日本商工会議所と全国銀行協会が事務局を務めた研究会は、2013年12月に「経営者保証に関するガイドライン」をまとめ、2014年2月から適用された。会社と経営者の財産が明確に分かれているなどの条件を満たせば、保証を求めない融資を検討することなどを定めている。さらに2019年12月には、事業承継に焦点を当てた**特則**がまとめられ、2020年4月から適用された。前の経営者と後継者の両方から保証をとる「二重の保証」を原則として求めないことや、後継者に保証を求めない対応を検討することなどが盛り込まれた。
「条件の1つが、会社とご家族のお金が、帳簿の上ではっきり分かれていることです」と高梨は言った。「社長の交際費が酒の原価に入っていた、という話を、この前聞きました（第1章）。ああいうことがなくなって、毎月の試算表が正確に出てくる会社なら、保証を外す話もしやすくなる」
帰りの車の中で、澪は、2つの保証を、この章の勘定で並べてみた。

::journal 会社が他社の借金を保証したとき（汐見酒造の帳簿、単位：万円）
保証債務見返 8,000 | 保証債務 8,000
::

社長個人が自社の借金を保証したとき（汐見酒造の帳簿）：**仕訳なし**
後者は、会社の帳簿には何も記録されない。会社から見れば、自分の借金はすでに借入金として載っているからだ。決算書を見ても、社長がいくらの保証を背負っているかは分からない。事業を継ぐかどうかを考える後継者にとって、本当に重いのは、この「帳簿に載らない保証」であることが多い。
父は、蔵の4億円を個人で保証し、そのうえ社長として、芹沢酒造の8,000万円の保証を会社に引き受けさせていた。どちらも、誰にも相談せずに。澪は、ハンドルを握る手に力が入るのを感じた。

::

::cfo 小松の退職金1,200万円 ― 引当金があれば、払えるのか
決算整理の最後に、岩倉が安心したように言った。「これで小松さんの退職金も、引当金に積み上がりました。2年後の1,200万円は、もう準備ができとるわけですな」
::table 小松の退職金と、蔵のお金
| 項目 | 金額 |
| 小松の退職金（2年後の2029年3月に支払う予定） | 1,200万円 |
| 6月30日の退職給付引当金のうち、小松の分 | 1,100万円 |
| 6月30日の普通預金（決算の見込み） | 約1,500万円 |
| 来期の資金繰りの見込み | 酒税・米代・借入金の返済で、毎月ぎりぎり |
| 中小企業退職金共済（国の制度）への掛金 | 月1万円〜3万円、全額が損金になる |
::
まず、「退職給付引当金1,100万円」と「1,100万円の現金」が同じものかを考えてから選んでほしい。
::choice A. 引当金に1,100万円を積んだので、退職金の準備はできている
**× 引当金は、お金の準備ではない。**退職給付引当金は、「将来、1,200万円を払う義務のうち、今までの分」を負債として示した数字だ。費用を計上しても、お金は1円も蔵の外にも、別の口座にも移っていない。2年後に1,200万円の現金があるかどうかは、引当金とはまったく別の問題だ。今の資金繰りでは、何もしなければ、退職金を払う月に資金が足りなくなるおそれがある。
::
::choice B. 引当金とは別に、2年後の支払いに向けて、毎月の資金繰り表に退職金のための積立てを組み込む
**◎ 帳簿の準備と、お金の準備を分けている。**引当金で費用と負債を正しく示したうえで、実際のお金は、毎月一定額を別の預金に積み立てたり、退職金のための共済の制度を使ったりして準備する。2年で1,200万円なら、月50万円の積立てが必要になる。資金繰りが苦しい中で、それをどう捻出するかは、来期の経営の課題そのものだ。
::
::choice C. 小松に、退職金の一部を分割で受け取ってもらうよう頼む
**△ 選択肢にはなるが、順番が逆だ。**本人の同意があれば、支払い方を変えることはできる。だが、40年の勤務への対価を、蔵の資金繰りの都合で後回しにする前に、まず蔵の側で準備の計画を立てるべきだ。それでも足りないときに、誠実に相談するのが筋だ。
::
::choice D. 退職金の規程を改めて、退職金を減らす
**× 約束を一方的に変えることになる。**退職金の規程は、従業員との約束だ。すでに働いた分の退職金を一方的に減らすことは、労働条件の不利益な変更として、原則として本人の同意なしにはできない。帳簿の負債を減らすために、人との約束を破れば、蔵の信用そのものを失う。
::
::answer 考え方の例を見る
引当金は、将来の支出を、その原因のある期の費用と負債として示す**帳簿の上の準備**だ。お金の準備ではない。引当金を積んでも預金は増えないし、引当金がなくても払う義務は消えない。費用の計上と、お金の手当ては、別々に考える。
澪は、来期の資金繰り表に「小松さん退職金積立て 月50万円」の行を加えた。小松には、何も言わなかった。2年後、その積立ての通帳を、引退の日に澪から渡されたとき、小松は長いこと黙っていた。
::
::

::next 引当金と負債の会計の先にある論点
1級では、退職給付債務の計算（割引計算・年金資産・数理計算上の差異）、債務保証損失引当金、資産除去債務、偶発債務の注記などを学ぶ。また、引当金は見積りの塊だ。見積りを甘くすれば利益は増え、厳しくすれば減る。決算書の注記の「重要な会計上の見積り」を読むと、会社がどこで見積りをしているかが分かる。
::

::summary
- 引当金は、将来の特定の費用・損失で、当期以前の事象に起因し、発生の可能性が高く、金額を合理的に見積もれるときに計上する
- 貸倒引当金は、一般債権は一括評価、破綻した相手などへの債権は個別評価（債権額－担保など）。営業債権の繰入は販管費、営業外債権の繰入は営業外費用
- 賞与引当金・退職給付引当金（繰入は退職給付費用）・修繕引当金・製品保証引当金は、繰入で費用と負債を計上し、支出したときに取り崩す
- 債務の保証は偶発債務。負債には載せず、対照勘定（保証債務見返・保証債務）で記録する。履行したら未収入金などとし、対照勘定を取り消す
- 引当金は帳簿の上の準備であって、お金の準備ではない
::
