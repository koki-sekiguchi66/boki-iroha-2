## 契約書の「5年間」 ― 2027年4月からのリースの会計

::scene 6月1日、午前11時 ― 帳場
澪は契約書を持ったまま、椎名に電話をかけた。
椎名：「その営業さんの話は、少し前までなら半分は当たっていました。でも、2027年4月から始まる事業年度から、ルールが変わります」
椎名：「借りた機械を使う権利を資産に、リース料を払う義務を負債にする。借りた物も、帳簿に載るんです」
::

企業会計基準委員会は2024年9月に、新しいリースの会計基準（企業会計基準第34号）を公表した。2027年4月1日以後に始まる事業年度から適用される。新しい基準では、借りる側（借手）は、リースの対象を使う権利を**使用権資産**（資産）、リース料を払う義務を**リース負債**（負債）として、リースが始まる日に計上する。
汐見酒造の今の事業年度（2026年7月〜2027年6月）は、強制適用の前にあたる。だが、新しい基準は2025年4月1日以後に始まる事業年度から早めに適用することが認められていて、2027年4月からの簿記2級の試験も新しい処理で出題される。椎名の勧めで、汐見酒造は今期から新しい基準で記録することにした。

::point メモ ― リースの会計の変わり目
2027年3月までの区分表では、借手のリースを「ファイナンス・リース取引」（実質は買ったのと同じ。資産と負債に計上）と「オペレーティング・リース取引」（賃貸借として、支払ったときに費用）に分けていた{{old:2027年度〜範囲外}}。2027年度からの区分表では、この区分をなくし、借手は原則として使用権資産とリース負債で記録する{{new:2027年度〜}}。リースかどうかの判断（リースの識別）は2級では問われず、問題文で与えられる。
::

澪：「じゃあ、リースにしても、540万円の機械を借金で買ったのと同じように、資産と負債が載るんですね」
椎名：「そうです。借金に見えない、というのは、もう通りません」

## 年120万円の5年間 ― 利子込み法と利子抜き法

リース料の合計は、年120万円×5年＝600万円。買えば540万円の機械だから、差の60万円は、分割で払うための利息にあたる。
使用権資産とリース負債をいくらで計上するかには、2つの方法がある。リース料の合計600万円で計上する**利子込み法**と、利息分を除いた見積現金購入価額540万円で計上し、利息は期間に配分して**支払利息**にする**利子抜き法**だ。2級では、利子抜き法の利息は、毎期同じ額を配分する定額法で計算する。

::example 充填機のリースを、利子込み法と利子抜き法で記録する
リース期間5年、リース料は年1,200,000円（毎年の期末に後払い）、見積現金購入価額は5,400,000円の充填機のリースが始まった。使用権資産は、リース期間5年、残存価額ゼロの定額法で減価償却する（間接法）。リース開始日と、1年目の期末の仕訳を比べる。
::answer
**利子込み法**
::journal (1) リース開始日：リース料の合計600万円で計上する
使用権資産 6,000,000 | リース負債 6,000,000
::
::journal (2) 1年目の期末：リース料の支払い
リース負債 1,200,000 | 普通預金 1,200,000
::
::journal (3) 1年目の期末：減価償却（6,000,000円÷5年）
減価償却費 1,200,000 | 使用権資産減価償却累計額 1,200,000
::
**利子抜き法**
::journal (1) リース開始日：見積現金購入価額540万円で計上する
使用権資産 5,400,000 | リース負債 5,400,000
::
::journal (2) 1年目の期末：支払額のうち、利息（600,000円÷5年）は支払利息
リース負債 1,080,000 | 普通預金 1,200,000
支払利息 120,000 |
::
::journal (3) 1年目の期末：減価償却（5,400,000円÷5年）
減価償却費 1,080,000 | 使用権資産減価償却累計額 1,080,000
::
どちらの方法でも、1年間の費用の合計は1,200,000円（利子込み法は減価償却費だけ、利子抜き法は減価償却費1,080,000円＋支払利息120,000円）で同じだ。違うのは、使用権資産とリース負債の大きさと、費用の名前（営業費用か、営業外費用か）だ。
::trap
利子抜き法の支払時は、支払額1,200,000円を**リース負債の返済分と利息に分ける**。全額をリース負債から減らさないこと。また、減価償却の累計額の勘定は「使用権資産減価償却累計額」だ。
::
::
::

## 6月30日の決算 ― 期中に始まったリース

汐見酒造は、利子抜き法を選んだ。充填機のリースは6月1日に始まり、1回目の支払いは1年後の5月31日。だが、決算日の6月30日は、すぐにやってくる。

::example 6月1日に始まったリースの、6月30日の決算
6月1日、上の充填機のリース（利子抜き法、見積現金購入価額5,400,000円、利息の総額600,000円、リース料は毎年5月31日に後払い）が始まった。6月30日に決算を迎えた。
::answer
::journal (1) 6月1日：リース開始日
使用権資産 5,400,000 | リース負債 5,400,000
::
::journal (2) 6月30日：減価償却（5,400,000円÷5年×1か月÷12か月）
減価償却費 90,000 | 使用権資産減価償却累計額 90,000
::
::journal (3) 6月30日：1か月分の利息の見越し計上（120,000円×1か月÷12か月）
支払利息 10,000 | 未払利息 10,000
::
翌年の5月31日に1,200,000円を払うときは、期首に未払利息を再振替し、支払いのときに「リース負債 1,080,000・支払利息 120,000／普通預金 1,200,000」とする。差し引き、翌期の支払利息は11か月分の110,000円になる。
::trap
支払日がまだ来ていなくても、決算日までの1か月分の利息は発生している。未払利息として見越し計上するのを忘れないこと。減価償却も、使い始めた6月1日から月割で計算する。
::
::

## 日本橋店の家賃 ― 短期リース・少額リースと、支払リース料

::scene 6月2日、午後 ― 日本橋の直営店
澪は、東京の直営店の店長・戸田に、店の賃貸の契約書を送ってもらった。店舗の賃貸借は、1年ごとの契約だった。
戸田：「家賃も、リースになるんですか。うちの帳簿では、ずっと『支払家賃』でしたけど」
::

新しい基準のもとでも、リース期間が12か月以内の**短期リース**や、1件あたりの金額が小さい**少額リース**は、使用権資産とリース負債に計上せず、賃貸借として、支払ったときに費用にしてよい。
2級以上では、建物や土地を借りる不動産の賃借もリースの一種なので、賃貸借として処理するときは、支払家賃・支払地代ではなく**支払リース料**の勘定を使う（3級は従来どおり支払家賃・支払地代）。

::example 事務機器と日本橋店の店舗の賃借
(1) 事務所のコピー機（少額リース、賃貸借として処理）の今月のリース料30,000円を普通預金から支払った。
(2) 日本橋店の店舗（1年ごとの契約の短期リース、賃貸借として処理）の今月の賃料400,000円を普通預金から支払った。
::answer
::journal (1)
支払リース料 30,000 | 普通預金 30,000
::
::journal (2) 2級以上では、店舗の賃料も支払リース料
支払リース料 400,000 | 普通預金 400,000
::
::trap
2級の問題で「支払家賃」を使わないこと。{{new:2027年度〜}} 2級以上では、不動産の賃借を賃貸借として処理するときも、支払リース料に統一される。使用権資産として計上する方法も、2級の出題の対象だ。
::
::
::

澪は、リース会社の営業担当者に電話をかけた。契約は結ぶ。だが、帳簿には載せる。
澪：「借金に見えないから借りる、のではありません。保守が込みで、総額でも安いから借ります」

::solve 借りた充填機も、使用権資産とリース負債として帳簿に載る
5年間解約できない充填機のリースは、使う権利と払う義務そのものだ。2027年4月からの新しい基準では、リースが始まる日に、使用権資産540万円とリース負債540万円（利子抜き法）を計上する。「借金に見えない」どころか、借入金で買ったのとほとんど同じ形で、貸借対照表に載る。
もし営業担当者の言葉を信じて帳簿に載せなかったら、審査に出す貸借対照表は、払う約束のある540万円を隠したものになっていた。後で見つかれば、帳簿の全体が疑われる。
**借りたか買ったかではなく、使う権利と払う義務があるかで、帳簿に載るかが決まる。**載せないでよいのは、短期と少額のリースだけだ。
::

### 試験で狙われるパターン ― 2つの方法の比較・利息の配分・前払いのリース料

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 利子込み法と利子抜き法の違い**　使用権資産・リース負債の金額、減価償却費、支払利息がどう変わるかを問う。どちらでも、毎年の費用の合計とリース料の合計は同じになる。

**② 利息の配分は定額法**　利子抜き法の利息の総額（リース料総額－見積現金購入価額）を、リース期間で均等に割る。期中に始まったときは月割にし、決算で未払利息を見越す。

**③ リース料を前払いする契約**　期首や開始日に前払いする契約では、支払いのときに「リース負債／普通預金」とし、利息の配分の時期がずれる。問題文の「前払い」「後払い」を必ず確かめる。

::steps 解法の型 ― リースの問題
1. 計上するか | 短期・少額で賃貸借として処理するなら支払リース料。それ以外は使用権資産とリース負債
2. 方法を確かめる | 利子込み法はリース料総額、利子抜き法は見積現金購入価額で計上
3. 支払時 | 利子込み法は全額リース負債を減らす。利子抜き法は利息（定額法）を分ける
4. 減価償却 | 使用権資産をリース期間（など）で償却。期中開始なら月割
5. 決算 | 支払日前の利息は未払利息で見越す
::

## 届出書の注記 ― 契約済み、まだ帳簿に載っていない4,512億ドル

::scene 6月8日、深夜 ― 帳場
充填機のリースを決めた夜、澪は、半年前に読んだあの届出書をもう一度開いた。前に読んだときは損益計算書しか見ていなかった。今夜は、貸借対照表と、その後ろの注記を読む。
澪：「リースで借りた機械は、使う権利として資産になる。なら、あの会社の貸借対照表には、データセンターのリースが山のように載っているはずだ」
::

上場の届出書によると、Anthropicの2026年9月30日の**総資産は1,543億ドル**、そのうちリースの**使用権資産は28億ドル**だった。思ったより、ずっと小さい。
だが、注記には、別の数字が書かれていた。**すでに契約したが、まだ始まっていないリース**の将来の支払額（割引前）が、およそ**4,512億ドル**。2026年から2028年にかけて始まり、期間は平均で約10年。さらに、解約できない購入の約束が別にある。
澪は、この章の言葉で、その意味を確かめた。リース負債と使用権資産は、リースが始まる日に計上する。契約を結んだだけで、まだ使い始めていない段階では、仕訳は1本もない。3級で学んだ「簿記上の取引」は、資産・負債・純資産・収益・費用が増減したときに初めて記録する、という原則のとおりだ。
仮に、年10億ドル・10年のデータセンターのリースが始まったとすると（仕組みを示すための例、利子込み法、単位：億ドル）、
① 契約を結んだ日は、**仕訳なし**（資産も負債も、まだ増減していない）。

::journal ② リース開始日：10年分の使う権利と、払う義務を計上する
使用権資産 100 | リース負債 100
::

::journal ③ 1年後：リース料の支払いと、減価償却
リース負債 10 | 現金預金 10
減価償却費 10 | 使用権資産減価償却累計額 10
::

4,512億ドルの契約が順に始まれば、そのたびに②の仕訳が切られ、貸借対照表の資産と負債が一気に膨らむ。そして、使い始めた計算資源の減価償却費や利息が、売上より先に損益計算書に載り始める。第10章で読んだ「固定費の階段」は、こうして生まれていた。
澪は、ノートに書いた。「貸借対照表の数字だけでなく、注記に書かれた、まだ始まっていない約束を読む」。同社自身も届出書で、計算資源の約束の大部分は解約できず、売上が見込みどおりに伸びなければ支払いが重荷になりうることを、リスクとして挙げている。

::note
出典：[Anthropic, PBC「Form S-1/A（Amendment No.1）」（米国証券取引委員会、2026年11月2日提出、Consolidated Balance Sheets／Contractual Obligations and Commitments）](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm)、[企業会計基準委員会「企業会計基準第34号『リースに関する会計基準』」（2024年9月13日公表）](https://www.asb-j.jp/jp/accounting_standards/y2024/2024-0913.html)
::

::danger 契約を分割して、リースを帳簿から消す
短期リース・少額リースは帳簿に載せなくてよい。この例外を悪用して、5年使うつもりの機械の契約を「1年ごとの更新」に見せかけたり、1つの機械の契約を小分けにしたりすれば、負債を帳簿から消せてしまう。リースかどうか、短期かどうかは、契約の書き方ではなく、実態で判断する。
::

::cfo 充填機を、買うか、借りるか
営業担当者の説明が誤りだと分かった今、澪は、買うのと借りるのを、帳簿の見え方ではなく中身で比べることにした。
**前提**
- 買うなら、現金で買う価格は540万円。信金から540万円を借りて買い、5年で返す。利息の合計は約30万円
- 買った場合の保守は別の契約で、年10万円かかる
- リースなら、年120万円を5年間、毎年の期末に払う。保守はリース料に含まれる。途中で解約はできない
- どちらを選んでも、6月30日の貸借対照表には、約540万円の資産と負債が載る
- 充填機の耐用年数は、メーカーの説明では7年
::choice A. リースにする。保守込みで総額が安く、最初に現金も要らない
**◎ 総額と中身で比べている。**買えば、540万円＋利息約30万円＋保守50万円（10万円×5年）＝約620万円。リースは保守込みで600万円。どちらも帳簿には約540万円の負債が載るので、見え方の差はない。
::
::choice B. 買う。リースは総額600万円で、540万円の購入より60万円も高い
**△ 比べる相手の中身がそろっていない。**買う場合にも、借入金の利息と保守の費用がかかる。それを足すと、買うほうが約20万円高い。
::
::choice C. 審査が終わるまで、充填機の導入を延ばす
**× スパークリングの発売が遅れる。**6月発売の計画（第10章）が崩れ、固定費だけが先に出る。どちらを選んでも負債は同じように載るので、延ばす理由がない。
::
::choice D. 1年ごとの契約に分けて、短期リースとして帳簿に載せない
**× 実態は5年のリースだ。**契約の形を変えて負債を隠せば、審査をだますことになる。見つかれば、決算書の全体が信用を失う。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「どちらが帳簿に載らないか」ではなく、「同じ機械を5年使うのに、どちらが少ないお金で済み、どちらが使いやすいか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 5年間に出ていくお金
| 項目 | 買う | 借りる |
| 機械の代金・リース料 | 540万円 | 600万円 |
| 借入金の利息 | 約30万円 | ― |
| 保守の費用 | 50万円 | リース料に含む |
|= 合計 | 約620万円 | 600万円 |
::
#### 手順3　ほかの答えに引かれる理由
Bは、目に見える600万円と540万円の比較に、Cは審査の前に負債を増やしたくない気持ちに、Dは営業担当者の「載らない」という言葉の残りに引かれる。耐用年数が7年あることは、5年後に機械が残る買う案の利点になりうるが、リースでも満了後の扱いは交渉できるので、この比較では決め手にならない。
#### 持ち帰る考え方
- **リースか購入かは、帳簿の見え方ではなく、総額と中身で比べる**
- **比べるときは、同じものをそろえる**：利息と保守を含めて比べる
#### 前提が変われば
5年たっても充填機を2年以上使い続ける見込みがはっきりしていて、リースの満了後に買い取れないなら、買う案のほうが、残る2年分の価値だけ有利になる。
::
::

::exam リースの急所
- 借手は、リース開始日に**使用権資産／リース負債**（2027年度〜。ファイナンス・オペレーティングの区分はなくなった）
- 利子込み法はリース料総額、利子抜き法は**見積現金購入価額**で計上。利子抜き法の利息は定額法で配分
- 期中に始まったら、減価償却も利息も月割。決算で未払利息を見越す
- 短期リース・少額リースは賃貸借処理で**支払リース料**。2級以上は不動産の賃借も支払リース料
- 契約を結んだだけでは仕訳しない。リースが始まった日に計上する
::

::next 貸す側のリースと、リースの見極めは1級へ
1級では、リースを貸す側（貸手）の処理、リースかどうかの識別、リース期間の決め方、セール・アンド・リースバックやサブリースなどを学ぶ。新しい基準のもとでは、何がリースにあたるかの判断そのものが、会計の大きな論点になる。
::

::summary
- 2027年4月以後に始まる事業年度から、借手はリースを使用権資産とリース負債で記録する
- 利子込み法はリース料総額で、利子抜き法は見積現金購入価額で計上し、利息は定額法で配分する
- 使用権資産は減価償却し、期中に始まったリースは月割で計算する
- 短期リース・少額リースは、賃貸借として支払リース料で処理できる。2級以上は不動産の賃借も同じ
- リースは契約を結んだときではなく、始まったときに計上する

## 確認問題

::quiz
::problem 次の取引を仕訳しなさい（利子抜き法、利息は定額法で配分）。
(1) 期首に、営業用のトラックのリースが始まった。リース期間4年、リース料は年500,000円（毎年の期末に後払い）、見積現金購入価額は1,800,000円である。
(2) 1年目の期末に、リース料500,000円を普通預金から支払った。
(3) 1年目の期末に、使用権資産をリース期間4年、残存価額ゼロの定額法で減価償却した（間接法）。
::answer
::journal (1)
使用権資産 1,800,000 | リース負債 1,800,000
::
::journal (2) 利息総額200,000円÷4年＝50,000円
リース負債 450,000 | 普通預金 500,000
支払利息 50,000 |
::
::journal (3) 1,800,000円÷4年
減価償却費 450,000 | 使用権資産減価償却累計額 450,000
::
利息の総額は、リース料総額2,000,000円－見積現金購入価額1,800,000円＝200,000円。
::
::
::problem 上の問題を利子込み法で処理した場合の、(1)の使用権資産の金額と、1年間の減価償却費を答えなさい。
使用権資産 [[2,000,000]] 円、減価償却費 [[500,000]] 円
::answer
利子込み法では、リース料総額500,000円×4年＝**2,000,000円**で計上し、減価償却費は2,000,000円÷4年＝**500,000円**。支払利息は計上しない。
::
::
::problem 次の取引を仕訳しなさい。
(1) 事務所の家賃（短期リース、賃貸借として処理）250,000円を普通預金から支払った。
(2) 決算日に、期中（決算日の3か月前）に始まったリース（利子抜き法、年間の利息60,000円、リース料は後払い）の利息を見越し計上した。
::answer
::journal (1) 2級以上では支払リース料
支払リース料 250,000 | 普通預金 250,000
::
::journal (2) 60,000円×3か月÷12か月
支払利息 15,000 | 未払利息 15,000
::
支払日が来ていなくても、決算日までに発生した利息は見越し計上する。
