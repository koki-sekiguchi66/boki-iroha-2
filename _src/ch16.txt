::mystery 借りた機械が、自分の資産になる
6月の初め。汐見スパークリングの発売を前に、専用の充填機の手配が最後の課題になった。瓶の中で発泡している酒を、泡を逃さずに詰める特殊な機械だ。メーカーの見積りは、買えば**540万円**。5年のリースなら、**年120万円**を5回、保守つき。
岩倉は、リースを強く推した。「買えば、信金から借りるか、手元のお金を使うしかない。リースなら月々の支払いで済むし、何より借金が増えない。高梨さんに見せる貸借対照表がきれいなままです」
だが、椎名の答えは違った。「今度の決算から、それは通用しません。リースで借りた充填機は、汐見酒造の資産として載ります。払う約束の600万円も、負債になります」
借りただけの機械が、なぜ自分の資産になるのか。そして、借金に見えないはずのリースが、なぜ負債になるのか。
**リースで借りた充填機は、なぜ自分の資産として帳簿に載るのか？**
::

## リースとは ― 「使う権利」を買う取引

リースは、機械などの資産を、リース会社やメーカー（**貸手**）から、一定の期間、使用料（**リース料**）を払って借りる取引だ。借りる側を**借手**という。

::theory 使用権資産とリース負債
借手は、リース期間の始まり（**リース開始日**）に、
- 契約の期間、その資産を使う権利を**使用権資産**（資産）として計上する
- 契約の期間に払うリース料の支払義務を**リース負債**（負債）として計上する
使用権資産は、ほかの固定資産と同じように、リース期間にわたって**減価償却**する。リース料を払ったら、リース負債を減らす。
借りた機械そのものは貸手のものだ。だが、5年間その機械を自由に使える「権利」は、借手が持っている。そして、5年間リース料を払い続ける「義務」も、借手が負っている。その両方を、ありのまま貸借対照表に載せる、というのが新しい考え方だ。
{{new:2027年度〜}} 「リース取引」は「リース」に改められ、借手はファイナンス・リースとオペレーティング・リースの区別なく、原則として使用権資産とリース負債を計上する。2027年3月までの試験では、ファイナンス・リース取引（リース資産・リース債務）とオペレーティング・リース取引（支払リース料）の区別が出題範囲。
::

## 利子込み法と利子抜き法

充填機のリース料の総額は、120万円×5年＝600万円。買えば540万円だから、差の60万円は、リース会社にお金を立て替えてもらう利息にあたる。この利息の扱い方で、2つの方法がある。

::table 利子込み法と利子抜き法
| 方法 | 使用権資産・リース負債の金額 | 利息の処理 |
| 利子込み法 | リース料の総額（600万円） | 利息を区別しない。支払額をそのままリース負債の減少とする |
| 利子抜き法 | リース料の総額から利息を除いた額（見積現金購入価額540万円） | 利息の60万円を、リース期間にわたって**定額法**で支払利息にする（年12万円） |
::

まず、2級の基本の形として、会計期間の初めにリースを始めた場合で仕訳を確かめよう。

::example 充填機のリースを、利子込み法と利子抜き法で仕訳しなさい
リース期間5年、リース料は年1,200,000円（毎年、期末に後払い）、見積現金購入価額5,400,000円。使用権資産は、リース期間で、残存価額ゼロの定額法で減価償却する。会計期間の初日にリースを開始したとする。
::answer
**利子込み法**
::journal (1) リース開始日
使用権資産 6,000,000 | リース負債 6,000,000
::
::journal (2) 1年目の期末：リース料の支払い
リース負債 1,200,000 | 普通預金 1,200,000
::
::journal (3) 1年目の期末：減価償却（6,000,000円÷5年）
減価償却費 1,200,000 | 使用権資産減価償却累計額 1,200,000
::
**利子抜き法**
::journal (1) リース開始日
使用権資産 5,400,000 | リース負債 5,400,000
::
::journal (2) 1年目の期末：支払額のうち、利息（600,000円÷5年）は支払利息
リース負債 1,080,000 | 普通預金 1,200,000
支払利息 120,000 |
::
::journal (3) 1年目の期末：減価償却（5,400,000円÷5年）
減価償却費 1,080,000 | 使用権資産減価償却累計額 1,080,000
::
どちらの方法でも、1年間の費用の合計は1,200,000円（利子込み法は減価償却費だけ、利子抜き法は減価償却費1,080,000円＋支払利息120,000円）で同じだ。違うのは、使用権資産とリース負債の大きさと、費用の名前（営業費用か、営業外費用か）だ。
::
::

### 期の途中で始まったリース ― 利息の見越し

汐見酒造の充填機のリースは、**6月1日**に始まった。決算日は6月30日、最初のリース料の支払いは翌年の5月31日だ。決算日には、1か月分の減価償却費と、まだ払っていない1か月分の利息を計上する。

::example 6月1日に始まった充填機のリースについて、決算整理仕訳をしなさい（利子抜き法、6月30日決算）
::answer
::journal (1) 6月1日：リース開始日
使用権資産 5,400,000 | リース負債 5,400,000
::
::journal (2) 6月30日：減価償却（5,400,000円÷5年×1か月÷12か月）
減価償却費 90,000 | 使用権資産減価償却累計額 90,000
::
::journal (3) 6月30日：1か月分の利息の見越計上（120,000円×1か月÷12か月）
支払利息 10,000 | 未払利息 10,000
::
翌年の5月31日に1,200,000円を払うときは、まず期首に未払利息を再振替し、支払いのときに「リース負債 1,080,000・支払利息 120,000／普通預金 1,200,000」とする。差し引き、翌期の支払利息は11か月分の110,000円になる。
::
::

## 短期リース・少額リース・不動産の賃借

すべての賃借を使用権資産とリース負債で処理するのは、手間がかかりすぎる。そこで、例外が認められている。

::theory 賃貸借処理（支払リース料）
- **短期リース**（リース期間が12か月以内）と**少額リース**は、使用権資産・リース負債を計上せず、支払ったリース料を**支払リース料**（費用）とする（賃貸借処理）
- 2級以上では、不動産（店舗・倉庫など）の賃借も、賃貸借処理をする場合は、**支払家賃ではなく支払リース料**で処理する
- 2級では、その契約がリースにあたるか、短期・少額にあたるかの判断（リースの識別）は、問題文で与えられる
::

::example 次の取引を仕訳しなさい
(1) 造りの最盛期の12月から5月まで、フォークリフトを6か月間借りる契約（短期リース）を結び、6月分までの使用料のうち当月分30,000円を普通預金から支払った。
(2) 日本橋の直営店の店舗の賃料（1年契約の短期リースとして賃貸借処理している）の当月分400,000円を普通預金から支払った。
::answer
::journal (1)
支払リース料 30,000 | 普通預金 30,000
::
::journal (2) 2級以上では、店舗の賃料も支払リース料
支払リース料 400,000 | 普通預金 400,000
::
::
::

::exam リースの急所
- リース開始日に「使用権資産／リース負債」。**利子込み法**はリース料総額、**利子抜き法**は見積現金購入価額
- 利子抜き法の利息は**定額法**（利息総額÷リース期間）。支払いのときに支払利息、決算日には未払分を**未払利息**で見越計上
- 減価償却：使用権資産をリース期間（問題の指示）で、残存価額ゼロの定額法。累計額は**使用権資産減価償却累計額**
- **短期リース・少額リース**は支払リース料。2級以上では不動産の賃借も**支払リース料**（支払家賃としない）
- 利子込み法か利子抜き法かは、問題文の指示に従う。両方の費用の合計が同じになることで検算できる
::

## 答え合わせ ― 借りただけなのに、なぜ資産と負債か

::solve 資産の本体ではなく、「5年間使う権利」と「5年間払う義務」を載せている
リースで借りた充填機そのものは、メーカーのものだ。だが、汐見酒造は、5年間、この機械を蔵で自由に使える。その**使う権利**は、蔵がお金を払って手に入れた、紛れもない資産だ。そして、5年間リース料を払い続けなければならない**義務**は、途中でやめられない負債だ。
新しいリースの会計基準は、その両方を、ありのまま貸借対照表に載せる。買うのとリースで借りるのとで、貸借対照表の見え方がほとんど変わらなくなった。「リースなら借金に見えない」は、もう成り立たない。
::

岩倉は、少し不満そうだった。「では、リースにする意味はなんですか」
「借金に見えるかどうかではなく、中身で比べるんです」と澪は言った。「お金をいつ払うか、保守は誰がするか、途中でやめられるか」

::danger 契約を分割して、リースを帳簿から消す
「短期リース」「少額リース」は帳簿に載せなくてよい。この例外を悪用して、5年使うつもりの機械の契約を「1年ごとの更新」に見せかけたり、1つの機械の契約を小分けにしたりすれば、負債を帳簿から消せてしまう。かつて、オペレーティング・リースが貸借対照表に載らなかった時代には、多額の設備をリースで調達して、負債を小さく見せる会社が少なくなかった。新しい基準は、まさにそれを防ぐために作られた。
リースかどうか、短期かどうかは、契約の書き方ではなく、**実態**で判断する。
::

::real 契約済み、まだ帳簿に載っていない4,512億ドル ― AI企業のリース
序章から追っているアメリカのAI企業 Anthropic は、計算資源（データセンターと、その中の演算装置）を、クラウド事業者との複数年の契約や、データセンターのリースで確保している。2026年11月に提出した上場の届出書の訂正版によると、2026年9月30日の時点で、同社の貸借対照表の**総資産は1,543億ドル**、そのうちオペレーティング・リースの**使用権資産は28億ドル**だった。
ところが、注記には、別の数字が書かれていた。**すでに契約したが、まだ始まっていないリース**の将来の支払額（割引前）が、およそ**4,512億ドル**。2026年から2028年にかけて始まり、期間は平均で約10年。さらに、クラウドの利用などの解約できない購入契約の最低支払額が約3,138億ドルある。

**この章の道具で読む ― リース開始日まで、仕訳はしない**
同社の会計方針は、「リース負債と使用権資産は、リース開始日に計上する」と定めている。日本の新しいリースの会計基準も同じだ。契約を結んだだけで、まだ使い始めていない段階では、仕訳は1本もない。3級で学んだ「簿記上の取引」は、資産・負債・純資産・収益・費用が増減したときに初めて記録する、という原則のとおりだ。
仮に、年10億ドル・10年のデータセンターのリースが始まったとすると（仕組みを示すための例、利子込み法、単位：億ドル）、
① 契約を結んだ日：**仕訳なし**（資産も負債も、まだ増減していない）
::journal ② リース開始日：10年分の使う権利と、払う義務を計上する
使用権資産 100 | リース負債 100
::
::journal ③ 1年後：リース料の支払いと、減価償却
リース負債 10 | 現金預金 10
減価償却費 10 | 使用権資産減価償却累計額 10
::
4,512億ドルの契約が順番に始まれば、そのたびに②の仕訳が切られ、貸借対照表の資産と負債が一気に膨らむ。そして、使い始めた計算資源の減価償却費や利息が、売上より先に損益計算書に載り始める。第10章で見た「固定費の階段」は、こうして生まれる。
決算書を読む人にとって大事なのは、貸借対照表の数字だけでなく、**注記に書かれた、まだ始まっていない約束**を読むことだ。同社自身も、届出書で、計算資源の約束の大部分は解約できず、売上が見込みどおりに伸びなければ支払いが重荷になりうることを、リスクとして挙げている。
::note
出典：[Anthropic, PBC「Form S-1/A（Amendment No.1）」（米国証券取引委員会、2026年11月2日提出、Consolidated Balance Sheets／Contractual Obligations and Commitments）](https://www.sec.gov/Archives/edgar/data/2130357/000162828026068676/anthropicpbc-sx1ax1.htm)、[企業会計基準委員会「企業会計基準第34号『リースに関する会計基準』」（2024年9月13日公表）](https://www.asb-j.jp/jp/accounting_standards/y2024/2024-0913.html)
::

::cfo 充填機は、買うか、借りるか
高梨は「決算が出るまで、新しい借入れの相談は受けられません」と言っていた。6月の手元の預金は、第12章の資金繰り表のとおり、余裕がない。
::table 充填機の調達方法（5年使う見込み）
| 方法 | 支払い | 5年間の支払総額 | その他 |
| A 現金で一括購入 | 6月に540万円 | 540万円 | 保守は別に年10万円 |
| B 5年のリース（解約不能、利子抜き法で処理） | 毎年120万円の後払い | 600万円 | 保守つき |
| C 1年ごとに更新する短期レンタル | 毎年180万円 | 900万円（5年続けた場合） | いつでもやめられる |
| D Bのリースを「1年ごとの更新」と書き換え、短期リースとして帳簿に載せない | 毎年120万円 | 600万円 | 実態は5年使う |
::
まず、保守の費用を含めた5年間の総額と、6月の資金への影響、貸借対照表への載り方を比べてから選んでほしい。
::choice A. 現金で一括購入する。総額が最も安い
**× 安いが、今の蔵には払えない。**保守を含めた5年間の総額は540万円＋50万円＝590万円で、Bの600万円よりわずかに安い。だが、6月に540万円を一度に払えば、酒税と米代の支払いで薄くなった預金がさらに減り、資金繰りが破綻しかねない（第12章）。費用の安さより、払えるかどうかが先だ。
::
::choice B. 5年のリースにする。支払いが使う期間に分かれ、保守もついている
**◎ お金の出方が、充填機を使う期間に合っている。**保守込みで5年間600万円は、購入（保守込み590万円）とほぼ同じで、6月に大きなお金は出ていかない。
貸借対照表には、使用権資産540万円とリース負債540万円が載る。借金が増えたように見えるのは、実際に5年間払う約束をしたのだから、正しい姿だ。高梨には、「リース負債540万円は、スパークリングの充填機の5年分」と注記して説明すればよい。
::
::choice C. 1年ごとの短期レンタルにする。スパークリングが売れなければ、すぐにやめられる
**△ 柔軟だが、高い。**売れ続ければ5年で900万円と、リースより300万円高い。スパークリングの安全余裕率は20%（第10章）。失敗の可能性は否定できないが、その保険に300万円を払うのは割高だ。発売1年目の様子を見たい事情があるなら、レンタル会社に「途中で買い取れる」条件がないかを確かめる手もある。
::
::choice D. Bの契約を1年ごとの更新と書き換え、短期リースにして負債を載せない
**× 基準をすり抜けるための、契約の書き換えだ。**実態は5年使う解約不能の契約なのに、形式だけ1年ごとにすれば、リース負債540万円が帳簿から消える。それは、高梨に負債を隠すことと同じだ。新しい基準は、まさにこうした「契約の形式で負債を消す」ことを防ぐためにある。発覚すれば、決算書全体が信用を失う。
::
::answer 考え方の例を見る
新しい基準のもとでは、買うのとリースで借りるのとで、貸借対照表の見え方はほとんど変わらない。だから、選ぶ理由は「借金に見えるかどうか」ではなく、**総額・お金の出る時期・保守・途中でやめられるか**という中身になる。
澪はB案を選んだ。6月期の決算書には、使用権資産540万円（6月の減価償却9万円を差し引くと531万円）とリース負債540万円が載る。高梨への説明の資料の負債の欄に、澪は1行を足した。「リース負債540万円：スパークリング用の充填機（5年、保守込み）」。
::
::

::next リースの会計の先にある論点
1級では、リース料の総額の現在価値の計算（利息法）、リースの識別（契約がリースを含むかどうかの判断）、リース期間の延長・解約オプション、貸手の会計処理、セール・アンド・リースバックなどを学ぶ。新しい基準の適用で、航空会社・小売業・物流業など、店舗や設備を借りて事業をする会社の貸借対照表は大きく膨らむと見込まれている。
::

## 確認問題

::quiz
::problem 次の取引を、利子抜き法で仕訳しなさい。
(1) 4月1日（期首）、備品のリース契約を結び、使用を開始した。リース期間4年、リース料は年500,000円（毎年3月31日に後払い）、見積現金購入価額は1,800,000円である。
(2) 3月31日、第1回のリース料を普通預金から支払った。利息は定額法で配分する。
(3) 3月31日、使用権資産の減価償却を行った（リース期間で定額法、残存価額ゼロ）。
::answer
::journal (1)
使用権資産 1,800,000 | リース負債 1,800,000
::
::journal (2) 利息総額200,000円÷4年＝50,000円
リース負債 450,000 | 普通預金 500,000
支払利息 50,000 |
::
::journal (3) 1,800,000円÷4年
減価償却費 450,000 | 使用権資産減価償却累計額 450,000
::

::problem 上の問題を利子込み法で処理した場合の、(1)の使用権資産の金額と、1年間の減価償却費を答えなさい。
使用権資産 [[2,000,000]] 円、減価償却費 [[500,000]] 円
::answer
利子込み法では、リース料の総額500,000円×4年＝**2,000,000円**で計上し、2,000,000円÷4年＝**500,000円**ずつ減価償却する。利息は区別しないので、支払時は「リース負債 500,000／普通預金 500,000」。

::summary
- リースの借手は、リース開始日に、使う権利を使用権資産、払う義務をリース負債として計上する。契約しただけでは仕訳しない
- 利子込み法はリース料の総額、利子抜き法は見積現金購入価額で計上し、利息は定額法で支払利息にする。決算日には未払の利息を見越計上する
- 使用権資産は、リース期間で定額法により減価償却する（使用権資産減価償却累計額）
- 短期リース・少額リースは支払リース料。2級以上では不動産の賃借も支払リース料で処理する
- 新しい基準では、買ってもリースでも貸借対照表の見え方はほぼ同じ。選ぶ理由は、総額・お金の出る時期・保守・柔軟性という中身で比べる
- 決算書の注記にある「まだ始まっていない契約」は、将来の資産・負債と費用の大きさを教えてくれる
::
