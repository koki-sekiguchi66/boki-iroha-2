## 報告式の損益計算書 ― 利益の「段」

決算書は、上から下へ順に足し引きしていく**報告式**で作る。損益計算書は、利益を5つの段に分けて示す。

::table 報告式の損益計算書の段
| 段 | 計算 | 何を表すか |
| 売上総利益 | 売上高－売上原価 | 製品そのものの儲け（粗利） |
| 営業利益 | 売上総利益－販売費及び一般管理費 | 本業の儲け |
| 経常利益 | 営業利益＋営業外収益－営業外費用 | 本業に、お金の借り方・運用の損益を加えた、ふだんの儲け |
| 税引前当期純利益 | 経常利益＋特別利益－特別損失 | 臨時の損益を加えた、その期の儲け |
| 当期純利益 | 税引前当期純利益－法人税等±法人税等調整額 | 税金を差し引いた、最後の儲け |
::

::answer
- 売上総利益：50,000－35,000＝**15,000**
- 販売費及び一般管理費：6,000＋1,500＋200＋1,800＝9,500 → 営業利益：15,000－9,500＝**5,500**
- 営業外収益：300＋100＝400、営業外費用：400＋150＝550 → 経常利益：5,500＋400－550＝**5,350**
- 特別利益500、特別損失700 → 税引前当期純利益：5,350＋500－700＝**5,150**
- 法人税等：1,200－150（法人税等調整額が貸方なので差し引く）＝1,050 → 当期純利益：5,150－1,050＝**4,100**
研究開発費は販売費及び一般管理費、為替差損は営業外費用、固定資産の売却益・除却損は特別損益に入れる。

## 精算表 ― 決算の全体を1枚で見る

試験の第3問では、決算整理前の試算表に決算整理を加えて、損益計算書と貸借対照表の金額を1枚にまとめる**精算表**（8桁精算表）が出ることもある。椎名は、澪の練習用に、日本橋店を小さな会社に見立てた精算表を作った。

::example 次の決算整理事項にもとづいて、精算表を完成させる（単位：千円）
1. 期末商品棚卸高は600（期首は500。売上原価は仕入の行で計算する）
2. 売掛金の期末残高に対して2%の貸倒引当金を設定する（残高はない）
3. 備品の減価償却費200を計上する（間接法）
4. 法人税、住民税及び事業税は、税引前当期純利益の30%とする
::table compact sum 精算表（単位：千円）

- 仕入の行で売上原価を計算する：3,000＋期首500－期末600＝**2,900**（修正記入は「仕入 500／繰越商品 500」「繰越商品 600／仕入 600」）
- 貸倒引当金：2,000×2%＝**40**、減価償却費200で累計額は200＋200＝**400**
- 税引前当期純利益：5,000－(2,900＋700＋100＋40＋200)＝1,060、法人税等：1,060×30%＝**318**
- 当期純利益：1,060－318＝**742**。損益計算書の欄では借方に、貸借対照表の欄では貸方に記入し、両方の欄の合計を一致させる

## 会議室 ― 赤字を、段ごとに分ける

澪は、損益計算書の横に、1枚の表を並べた。椎名と3日かけて作った表だ。

::solve 赤字の原因は、すべて「どの段の、何による赤字か」で説明できた
::table 赤字の分解（単位：万円）
| 段 | 前期 | 当期 | 変化の理由 |
| 売上総利益 | 16,500 | 19,000 | 作業時間あたりの稼ぎで生産の配分を変えた（序章・第1章）。米価の上昇で原価差異960を負担したうえで、2,500増加 |
| 研究開発費・立ち上げ費用を除いた営業利益 | 1,500 | 3,600 | 本業の稼ぐ力は2倍以上に |
| 研究開発費（新しい酵母） | 0 | △2,600 | 発生した期に全額費用（第17章）。来期は1,000の予定 |
| スパークリングの立ち上げ費用 | 0 | △1,200 | 発売の年に集中。来期は販売数量に応じた費用に |
| 営業損益 | 1,500 | △200 | |
| 経常損益 | 870 | △820 | 支払利息など。為替予約で来期の輸出の為替のぶれは抑える（第20章） |
| 特別損益 | 0 | △900 | 補助金2,400と圧縮損2,400は相殺。旧ラインの除却損900は一度きり（第15章） |
| 当期純損益（税効果後） | 610 | △1,427 | |
::
営業損失200万円は、研究開発費2,600万円と立ち上げ費用1,200万円を、その年に全額費用にした結果だ。それを除いた本業の営業利益は3,600万円で、前の期の1,500万円の2倍を超え、9か月前の見込みの1,100万円の3倍を超えている。
経常損失は、そこに借入金の利息が加わったもの。当期純損失は、さらに旧ラインの除却損という一度きりの損失が加わったものだ。
「赤字」という1つの言葉の中に、**本業の改善**、**将来への投資**、**一度きりの損失**が、別々の段に、別々の理由で入っていた。
::

高梨は、表を2度読んだ。審査役は、1つだけ質問した。
審査役：「研究開発費2,600万円が、本当に将来の売上を生むかどうか。それは、この表からは分かりませんね」
澪：「分かりません。だから、来期の計画を、毎月の数字で確かめられる形でお持ちしました。スパークリングの損益分岐点は年1万2,000本、月に1,000本です」

### 試験で狙われるパターン ― 第3問の決算

ここからは、試験の第3問で形を変えて出題される4つのパターンを押さえておこう。

**① 何を作るか**　決算整理前残高試算表と決算整理事項から、**損益計算書・貸借対照表**、**決算整理後残高試算表**、または**精算表**を作る。製造業の会社や本支店会計（第24章）の形もある。

**② 未処理事項から片付ける**　「記帳漏れ」「誤記入」などの未処理事項を先に処理し、そのあとで決算整理に進む。未処理事項で変わった残高（売掛金など）を、貸倒引当金の計算に使う。

**③ 区分を間違えない**　研究開発費は販管費、営業外債権の貸倒引当金繰入・為替差損益・有価証券利息は営業外、固定資産の売却損益・除却損・圧縮損・補助金の受贈益は特別損益。

**④ 貸借対照表の表示**　1年以内に返済する長期借入金は流動負債へ。繰延税金資産と負債は相殺して固定の区分へ。保証は注記。

::steps 解法の型 ― 第3問の決算
1. 未処理事項 | 記帳漏れ・誤記入を先に直し、試算表の横に変わった額をメモする
2. 棚卸資産 | 売上原価（仕入の行か売上原価の行か）、棚卸減耗損、評価損
3. 債権と引当金 | 貸倒引当金（差額補充法）、賞与・退職給付・修繕などの引当金
4. 固定資産と有価証券 | 減価償却、無形固定資産の償却、有価証券の評価、外貨の換算
5. 見越し・繰延べと税金 | 前払・未払・前受・未収、法人税等、税効果。最後に段ごとの利益を出す
::

::danger 「赤字」の1語で判断することと、「赤字の中身」で言い訳をすること
赤字の決算書を、段の区別なしに「赤字だからだめ」と判断するのは、最後の段の数字だけを見る読み方だ。だが、逆の危険もある。「研究開発費を除けば黒字」「一度きりの損失を除けば黒字」と、都合のよい費用だけを除いた数字を並べれば、どんな会社も黒字に見せられる。
赤字の中身を説明するときは、除いた費用が**本当に一度きりか**、**将来の収益にどうつながるか**、そして**それをどう確かめるか**まで示す。説明の責任は、除く側にある。

::cfo 毎月、何を報告するか ― 審査の条件の「指標」
高梨は言った。「毎月の報告の中身は、汐見さんが決めてください。何を見れば、この蔵が計画どおりかが分かりますか」。
**前提**
- 来期の計画：売上総利益2億1,000万円、研究開発費1,000万円、営業利益3,000万円、当期純利益1,500万円
- スパークリングの損益分岐点は年1万2,000本（月1,000本）
- 当期の営業損益は△200万円だが、研究開発費と立ち上げ費用を除くと3,600万円
- 当期純損益には、為替差損益や一度きりの損益が混ざる
- 9月末には、酒税と借入金の返済が重なる
- 越後物産の株の時価は、取得原価より300万円高い
::choice A. 毎月の当期純利益を、前の年の同じ月と比べて報告する
**× いちばん下の段だけでは、原因が見えない。**当期純利益には、為替差損益や一度きりの損益が混ざり、月ごとに大きく揺れる。下がったとき、本業が悪いのか、為替が動いただけなのかが分からない。この章で学んだ「段」を、自分で捨てることになる。
::
::choice B. 段ごとの営業損益と、研究開発費・販売本数・資金の見込みを報告する
**◎ 計画の前提を、1つずつ確かめられる。**研究開発費と立ち上げ費用を除いた営業利益で本業の力を、研究開発費の累計で上限1,000万円の約束を、スパークリングの販売本数で損益分岐点の月1,000本を、資金繰りの見込みで9月末の支払いを確かめる。どれかが崩れたら、どこが崩れたかがすぐ分かる。
::
::choice C. 毎月の売上高と、酒の種類ごとの販売本数を報告する
**△ 売れ行きは分かるが、儲けが見えない。**本数と売上高は大事な指標だが、原価や販管費が増えていれば、売れても利益は出ない。研究開発費の上限の約束も確かめられない。
::
::choice D. 毎月末の預金残高と、翌月の支払いの予定を報告する
**○ 資金の行き詰まりは防げるが、原因が見えない。**預金は、蔵が倒れないためのいちばん大事な数字だ。ただ、預金が減ったとき、本業の不振なのか、在庫が増えたのか、投資の支払いなのかは、預金の残高だけでは分からない。Bの一部として報告するのがよい。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「何を報告すれば安心してもらえるか」ではなく、「来期の計画のどの前提が崩れたら、すぐ分かるか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 計画の前提と、それを確かめる指標
| 計画の前提 | 毎月見る指標 | 目安 |
| 本業の力 | 研究開発費・立ち上げ費用を除いた営業利益 | 年3,600万円の水準を保つ |
| 研究開発費の上限 | 研究開発費の累計 | 年1,000万円まで |
| スパークリング | 販売本数 | 月1,000本（損益分岐点） |
| 資金 | 月末の預金と、3か月先までの資金繰りの見込み | 9月末の酒税と返済を払える |
::
#### 手順3　ほかの答えに引かれる理由
Aは「最後の数字がいちばん大事」という思い込みに、Cは「売れていれば大丈夫」という安心に、Dは「お金さえあれば倒れない」という正しさに引かれる。越後物産の株の含み益は、毎月の報告の指標を選ぶこととは関係のない前提だ。
#### 持ち帰る考え方
- **報告する指標は、計画の前提から逆算する**：前提が崩れたことを、早く、場所まで分かる形で知らせる
- **段ごとの数字と、お金の数字を組み合わせる**：損益は原因を、預金は時間の余裕を示す
#### 前提が変われば
新しい事業を始めない年なら、指標はもっと少なくてよい。逆に、芹沢酒造を連結する（第25・26章）なら、グループ全体の数字と、芹沢酒造の本数や資金も報告に加える。
::
::

::exam 決算と財務諸表の急所
- 損益計算書の5つの段：売上総利益 → 営業利益 → 経常利益 → 税引前当期純利益 → 当期純利益。**研究開発費は販管費**、**為替差損益・有価証券利息・営業外債権の貸倒引当金繰入は営業外**、**除却損・圧縮損・補助金の受贈益は特別損益**
- 法人税等調整額は、貸方なら法人税等から差し引き、借方なら加える
- 精算表：試算表±修正記入を、収益・費用は損益計算書の欄へ、資産・負債・純資産は貸借対照表の欄へ。当期純利益は両方の欄の差額
- 貸借対照表：1年以内に返済する長期借入金は**流動負債**、繰延税金資産・負債は相殺して**固定**の区分、保証は**注記**
- 第3問は、未処理事項から片付け、決算整理を1つ処理するたびに試算表の横にメモする
::

::next 決算書の読み方の先にあるもの
1級では、キャッシュ・フロー計算書、包括利益計算書、セグメント情報、1株当たり利益、そして「重要な会計上の見積り」の注記など、決算書の情報がさらに増える。上場企業の決算短信や有価証券報告書を読むときも、この章の「段ごとに分けて読む」ことが出発点になる。
::

::summary
- 製造業の決算整理は、商業簿記の決算整理（棚卸資産・引当金・減価償却・有価証券・外貨・見越し繰延べ・税金）に、原価差異の処理などの工業簿記の決算が加わる
- 報告式の損益計算書は、売上総利益・営業利益・経常利益・税引前当期純利益・当期純利益の5つの段で利益を示す
- 報告式の貸借対照表は、資産を流動・固定（有形・無形・投資その他）、負債を流動・固定に分け、純資産を示す。偶発債務は注記で示す
- 赤字は、どの段で、何が原因かに分けて読む。本業の改善、将来への投資、一度きりの損失、評価の上だけの損失は、別々の段に別々の理由で載る
- 費用を除いた数字で説明するときは、それが本当に一度きりか、将来の収益にどうつながるか、どう確かめるかまで示す
::
