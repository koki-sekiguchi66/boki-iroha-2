## 製造業の決算 ― 1年分の決算整理

決算書を作る前に、澪と椎名は、この1年に学んだ決算整理を1つずつ確かめた。製造業の決算整理は、商業簿記の決算整理に、工業簿記の決算（第11章）が加わる。

::table 汐見酒造の主な決算整理（6月30日）
| 決算整理 | 内容 | 章 |
| 原価差異の処理 | 材料消費価格差異・賃率差異・製造間接費配賦差異などを売上原価に振り替え | 第2〜4章・第11章 |
| 棚卸資産の評価 | 古酒の棚卸減耗と製品評価損、日本橋店の商品の減耗と評価損 | 第14章 |
| 減価償却 | 新ライン（圧縮後）・ボイラー・保冷車（生産高比例法）・使用権資産 | 第15章・第16章 |
| 無形固定資産の償却 | ソフトウェア・商標権 | 第17章 |
| 有価証券の評価 | その他有価証券（全部純資産直入法）、満期保有目的債券（償却原価法） | 第18章 |
| 引当金 | 貸倒引当金（個別・一括）、賞与・退職給付・修繕・製品保証の引当金 | 第19章 |
| 外貨建の債権の換算 | ニューヨークへの売掛金を決算日レートで換算 | 第20章 |
| 費用・収益の見越し・繰延べ | 割賦の前払利息、リースの未払利息、頒布会の契約負債 | 第13章・第15章・第16章 |
| 法人税等と税効果 | 法人税等の計上、繰延税金資産・負債 | 第21章 |
::

::exam 決算の問題（第3問）の急所
- 第3問は、決算整理前残高試算表と決算整理事項から、**損益計算書・貸借対照表**、**決算整理後残高試算表**、または**精算表**を作る問題が多い。製造業の会社や本支店会計（第24章）の形もある
- 決算整理事項を1つ処理するたびに、**関係する勘定の金額を試算表の横にメモ**していく。最後にまとめて計算しようとすると、漏れる
- よく問われる順：①未処理事項（記帳漏れ・誤記入）→ ②棚卸資産（売上原価・減耗・評価損）→ ③貸倒引当金 → ④減価償却 → ⑤有価証券 → ⑥引当金 → ⑦外貨の換算 → ⑧見越し・繰延べ → ⑨法人税等・税効果
- 貸借対照表は、**流動と固定**の区分、引当金や繰延税金資産・負債の表示場所、1年以内に返済する長期借入金の振替えに注意する
::

## 報告式の損益計算書 ― 利益の「段」

決算書は、上から下へ、順に足し引きしていく**報告式**で作る。損益計算書は、利益を5つの段に分けて示す。

::table 報告式の損益計算書の段
| 段 | 計算 | 何を表すか |
| 売上総利益 | 売上高－売上原価 | 製品そのものの儲け（粗利） |
| 営業利益 | 売上総利益－販売費及び一般管理費 | 本業の儲け |
| 経常利益 | 営業利益＋営業外収益－営業外費用 | 本業に、お金の借り方・運用の損益を加えた、ふだんの儲け |
| 税引前当期純利益 | 経常利益＋特別利益－特別損失 | 臨時の損益を加えた、その期の儲け |
| 当期純利益 | 税引前当期純利益－法人税等±法人税等調整額 | 税金を差し引いた、最終の儲け |
::

売上総利益 [[15,000]] 千円、営業利益 [[5,500]] 千円、経常利益 [[5,350]] 千円、税引前当期純利益 [[5,150]] 千円、当期純利益 [[4,100]] 千円
::answer
- 売上総利益：50,000－35,000＝**15,000**
- 販売費及び一般管理費：6,000＋1,500＋200＋1,800＝9,500 → 営業利益：15,000－9,500＝**5,500**
- 営業外収益：300＋100＝400、営業外費用：400＋150＝550 → 経常利益：5,500＋400－550＝**5,350**
- 特別利益500、特別損失700 → 税引前当期純利益：5,350＋500－700＝**5,150**
- 法人税等：1,200－150（法人税等調整額が貸方なので差し引く）＝1,050 → 当期純利益：5,150－1,050＝**4,100**
研究開発費は販売費及び一般管理費、為替差損は営業外費用、固定資産の売却益・除却損は特別損益に入れる。

## 精算表 ― 決算の全体を1枚で見る

試験の第3問では、決算整理前の試算表から、決算整理を加えて、損益計算書と貸借対照表の金額を1枚にまとめる**精算表**（8桁精算表）が出ることもある。椎名は、澪の練習用に、日本橋店を小さな会社に見立てた精算表を作った。

::example 次の決算整理事項にもとづいて、精算表を完成させなさい（単位：千円）
1. 期末商品棚卸高は600（期首は500。売上原価は仕入の行で計算する）
2. 売掛金の期末残高に対して2%の貸倒引当金を設定する（残高はない）
3. 備品の減価償却費200を計上する（間接法）
4. 法人税、住民税及び事業税は、税引前当期純利益の30%とする
::table compact sum 精算表（単位：千円）

- 仕入の行で売上原価を計算する：3,000＋期首500－期末600＝**2,900**（修正記入は「仕入 500／繰越商品 500」「繰越商品 600／仕入 600」）
- 貸倒引当金：2,000×2%＝**40**、減価償却費200で累計額は200＋200＝**400**
- 税引前当期純利益：5,000－(2,900＋700＋100＋40＋200)＝1,060、法人税等：1,060×30%＝**318**（1円未満なし）
- 当期純利益：1,060－318＝**742**。損益計算書の欄では借方に、貸借対照表の欄では貸方に記入し、両方の欄の合計を一致させる
精算表は、試算表の数字に修正記入を加減して、収益・費用の勘定は損益計算書の欄へ、資産・負債・純資産の勘定は貸借対照表の欄へ移す表だ。当期純利益は、損益計算書の欄の差額であり、貸借対照表の欄の差額でもある。

## 答え合わせ ― 赤字を、段ごとに分ける

::scene 7月12日、午後 ― 信用金庫の応接室
澪は、損益計算書の横に、1枚の表を並べた。椎名と一緒に、3日かけて作った表だ。
::

::solve 赤字の原因は、すべて「どの段の、何による赤字か」で説明できた
::table 赤字の分解（単位：万円）
| 段 | 前期 | 当期 | 変化の理由 |
| 売上総利益 | 16,500 | 19,000 | 作業時間あたりの稼ぎで生産の配分を変えた（序章・第1章）。米価の上昇で原価差異960を負担したうえで、2,500増加 |
| 研究開発費・立ち上げ費用を除いた営業利益 | 1,500 | 3,600 | 本業の稼ぐ力は2倍以上に |
| 研究開発費（新しい酵母） | 0 | △2,600 | 発生した期に全額費用（第17章）。来期は1,000の予定 |
| スパークリングの立ち上げ費用 | 0 | △1,200 | 発売の年に集中。来期は販売数量に応じた費用に |
| 営業損益 | 1,500 | △200 | |
| 経常損益 | 870 | △820 | 支払利息など。為替予約で来期の輸出の為替のぶれは抑える（第20章） |
| 特別損益 | 0 | △900 | 補助金2,400と圧縮損2,400は相殺。旧ラインの除却損900は一度きり（第15章） |
| 当期純損益（税効果後） | 610 | △1,490 | |
::
営業損失200万円は、研究開発費2,600万円と立ち上げ費用1,200万円を、その年に全額費用にした結果だ。それを除いた本業の営業利益は3,600万円で、前の期の1,500万円の2倍を超え、10か月前の見込みの1,100万円の3倍を超えている。
経常損失は、そこに借入金の利息が加わったもの。当期純損失は、さらに旧ラインの除却損という一度きりの損失が加わったものだ。
赤字という1つの言葉の中に、「本業の改善」「将来への投資」「一度きりの損失」が、別々の段に、別々の理由で入っていた。
::

高梨は、表を2度読んだ。それから、1つだけ質問した。
「研究開発費2,600万円が、本当に将来の売上を生むかどうか。それは、この表からは分かりませんね」
「分かりません」と澪は答えた。「だから、来期の計画を、毎月の数字で確かめられる形でお持ちしました。スパークリングの損益分岐点は1万2,000本、月に1,000本です。毎月の試算表と一緒に、販売本数を報告します」

::danger 「赤字」の1語で判断することと、「赤字の中身」で言い訳をすること
赤字の決算書を、段の区別なしに「赤字だからだめ」と判断するのは、序章の同期と同じ読み方だ。だが、逆の危険もある。「研究開発費を除けば黒字」「一時的な損失を除けば黒字」と、都合のよい費用だけを除いた数字を並べれば、どんな会社も黒字に見せられる。
赤字の中身を説明するときは、除いた費用が**本当に一度きりか**、**将来の収益にどうつながるか**、そして**それを確かめる方法**まで示さなければならない。説明の責任は、除く側にある。
::

2026年4〜6月は、本業の段である**営業損益が974百万ドルの黒字**だった。それなのに、最後の段の**当期純損失は66,309百万ドル**。営業利益の68倍の赤字だ。差を生んだのは、営業損益の下の段にある、転換社債などの公正価値の変動の損失59,597百万ドルと、その他の損失8,448百万ドルだ。第18章で見たとおり、公正価値の変動の損失は、同社の企業価値が上がったことで、将来株に変わる借入れの評価額が上がったことによる。現金は出ていかない。
澪は、2級の言葉で単純化して並べ直した。

「2025年の通期も、構図は同じです」と澪は言った。「営業損失8,060百万ドルの中には、研究開発費6,338百万ドルと一度きりの和解金1,500百万ドルがあって、その下の段で、評価の上の損失34,308百万ドルが当期純損失を5倍以上に膨らませています」
高梨は、2枚の表を並べて眺めた。「売上の9倍の赤字、という見出しは、最後の段の数字を売上と比べたものだったわけですね。最後の段には、本業の損益も、将来への投資も、一度きりの損失も、評価の上だけの損失も、全部混ざっている」
「どの段に、何が、なぜ載っているのか。それを分けて初めて、会社の輪郭が見えます。汐見酒造も、あの会社も」
「そして、輪郭が見えた後に残る問いがある」と高梨は言った。「研究開発が将来の売上を生み続けるか。巨額の約束に見合う売上が育つか。それは、決算書の外の問いです」

::cfo 高梨の判断 ― 赤字の蔵に、4億円の借換えを認めるか
信用金庫の審査会議。高梨は、汐見酒造の案件の説明を任された。審査役は言った。「規定では、直近の決算が赤字の先の借換えは、原則として認めない。例外にするなら、理由を数字で示してほしい」
::table 審査の資料（単位：万円）
| 項目 | 前期 | 当期 | 来期の計画 |
| 売上総利益 | 16,500 | 19,000 | 21,000 |
| 研究開発費 | 0 | 2,600 | 1,000 |
| 研究開発費・立ち上げ費用を除いた営業利益 | 1,500 | 3,600 | 4,000 |
| 営業損益 | 1,500 | △200 | 3,000 |
| 当期純損益 | 610 | △1,490 | 1,500 |
| 減価償却費（製造原価と販管費の合計） | 3,000 | 3,100 | 3,300 |
| 芹沢酒造の借入金の保証（偶発債務） | 8,000 | 8,000 | 未定 |
| 純資産 | 6,475 | 5,095 | 7,600（増資1,000を含む） |
::
あなたが高梨なら、審査会議にどの案を出すか。まず、当期の赤字のうち、来期に繰り返さないものと、繰り返すものを分けてから選んでほしい。
::choice A. 規定どおり、借換えを断る。赤字は赤字だ
**× 規定の目的を見失っている。**「赤字の先には貸さない」という規定は、返済できない会社に貸さないためのものだ。汐見酒造の赤字は、研究開発費と立ち上げ費用（計3,800万円）、一度きりの除却損（900万円）で説明でき、それらを除いた本業の営業利益は3,600万円と前期の2倍を超える。借換えを断れば、本業を立て直したばかりの蔵を、資金繰りの行き詰まりで潰すことになりかねない。
::
::choice B. 条件をつけて借換えを認める。月次の試算表と販売本数の報告、研究開発費の上限、芹沢酒造の扱いの計画の提出を条件にする
**◎ 赤字の中身を認めたうえで、残るリスクを条件で管理する。**本業の改善（営業利益3,600万円）は数字で確かめられる。一方、研究開発が売上を生むかどうか、スパークリングが損益分岐点の1万2,000本を超えるかは、まだ分からない。だから、毎月の販売本数と試算表で確かめる仕組みを条件にする。
もう1つ見落とせないのが、芹沢酒造の8,000万円の保証だ。貸借対照表には載っていないが、芹沢酒造が払えなくなれば、汐見酒造の純資産5,095万円を超える負担が一気に生じうる。その扱いの計画を出させるのは、決算書の注記まで読んだ審査だ。
::
::choice C. 研究開発費を資産に計上し直させ、黒字の決算書を出してもらってから借換えを認める
**× 会計の基準に反する決算書を求めることになる。**研究開発費は発生時に費用とする（第17章）。資産に付け替えれば営業利益は2,400万円になるが、それはワールドコムが費用を資産に付け替えたのと同じ発想だ（第15章）。黒字に見せかけた決算書で審査を通しても、審査の意味がない。
::
::choice D. 減価償却費を足し戻したキャッシュ・フローの目安が黒字なので、無条件で借換えを認める
**△ 返済の力を見る視点はよいが、リスクを見落としている。**営業損益△200万円に減価償却費3,100万円を足し戻せば、本業で生むお金の目安は約2,900万円で、返済の原資はある。だが、研究開発の成果は不確かで、芹沢酒造の保証という大きな偶発債務も残っている。条件をつけずに認めれば、悪化の兆しを早くつかむ手段がなくなる。
::
::answer 考え方の例を見る
決算書を読む側の仕事は、赤字か黒字かの1語で判断することでも、会社の言い分をそのまま受け入れることでもない。赤字を**段ごと・原因ごと**に分け、繰り返す損失と繰り返さない損失を区別し、不確かな部分は**確かめる仕組み**で補う。そして、貸借対照表の外（注記）にある約束まで読む。
1週間後、高梨から電話が来た。「条件つきで、借換えが通りました。条件は3つ。毎月の試算表と販売本数の報告、来期の研究開発費は1,000万円まで。そして、芹沢酒造をどうするか、9月末までに計画を出してください」
電話を切った澪は、事務所の窓から、隣町の方角を見た。芹沢酒造。父が守ろうとした蔵。第3部は、そこから始まる。
::

::next 決算書の読み方の先にあるもの
1級では、キャッシュ・フロー計算書、包括利益計算書、セグメント情報、1株当たり利益、そして「重要な会計上の見積り」の注記など、決算書の情報がさらに増える。上場企業の決算短信や有価証券報告書を読むときは、この章の「段ごとに分けて読む」ことが出発点になる。研究開発費・減価償却費・一度きりの損益・評価の上の損益が、どの段に、どれだけ入っているか。それを確かめるだけで、新聞の見出しの「赤字」「黒字」の意味が、まったく違って見えてくる。
::

::summary
- 製造業の決算整理は、商業簿記の決算整理（棚卸資産・引当金・減価償却・有価証券・外貨・見越し繰延べ・税金）に、原価差異の処理などの工業簿記の決算が加わる
- 報告式の損益計算書は、売上総利益・営業利益・経常利益・税引前当期純利益・当期純利益の5つの段で利益を示す
- 報告式の貸借対照表は、資産を流動・固定（有形・無形・投資その他）、負債を流動・固定に分け、純資産を示す。偶発債務は注記で示す
- 赤字は、どの段で、何が原因かに分けて読む。本業の改善、将来への投資、一度きりの損失、評価の上だけの損失は、別々の段に別々の理由で載る
- 費用を除いた数字で説明するときは、それが本当に一度きりか、将来の収益にどうつながるか、どう確かめるかまで示す
::
