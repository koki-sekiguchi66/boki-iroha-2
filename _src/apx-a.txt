## 使い方

- 各表は、5つの要素ごとに勘定科目を並べている。**ホームポジション**（増えたときに書く側）は、資産・費用が借方（左）、負債・純資産・収益が貸方（右）だ。
- 3級で学んだ基本の科目（現金・仕入・給料など）は、2級で使い方が広がるものを中心に載せている。
- {{new:2027年度〜}} は2027年度からの出題区分表で2級の論点として明記・追加された科目、{{old:2027年度〜範囲外}} は2027年度から2級の出題範囲から外れた科目。
- 試験では、問題文で指定された勘定科目を使うこと。

## まぎらわしい勘定科目の見分け方

::table 間違えやすいペア
| ペア | 見分け方 |
| 前受金 と 契約負債 | どちらも先に受け取った代金。収益認識の契約にもとづくものは契約負債 |
| 契約資産 と 売掛金 | 請求できる権利が無条件なら売掛金、ほかの義務を果たすまで請求できないなら契約資産 |
| 未払金 と 買掛金 | 商品・材料の代金は買掛金、それ以外（設備・割賦）は未払金 |
| 電子記録債権 と 営業外電子記録債権 | 売掛金から生じたものは電子記録債権、設備の売却などからは営業外電子記録債権 |
| 研究開発費 と ソフトウェア | 将来の収益が不確かな研究は費用、収益の獲得が確実な自社利用ソフトは資産 |
| 子会社株式 と その他有価証券 | 支配していれば子会社株式（原価）、関係の維持だけならその他有価証券（時価） |
| 有価証券評価損益 と その他有価証券評価差額金 | 売買目的の評価差額は損益、その他有価証券の評価差額は純資産 |
| 退職給付費用 と 退職給付引当金繰入 | 2級の勘定科目は「退職給付費用」 |
| 支払家賃 と 支払リース料 | 2級以上で賃貸借処理する不動産の賃料は「支払リース料」 |
| 材料消費価格差異 と 価格差異 | 予定価格を使う実際原価計算なら材料消費価格差異、標準原価計算なら価格差異 |
::
