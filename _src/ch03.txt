::mystery 払った給料と、原価の賃金が合わない
12月25日、金曜日。蔵の事務所で、澪は初めて蔵人たちに給料を支払った。季節の蔵人を含む8人の直接の作業員に、総額**420万円**。源泉所得税と社会保険料を差し引いて、普通預金から振り込む。
その5日後、月末の原価計算をしていた澪は、手を止めた。12月の賃金の消費額が、**460万円**になっている。払った額より40万円多い。
さらに妙なことに、その460万円のうち、酒の原価（仕掛品）に直接入ったのは360万円だけだった。残りは「製造間接費」と、見たことのない「賃率差異」という勘定に分かれていた。
「番頭さん、払っていない40万円を、どうして原価に入れるんですか」
岩倉は、帳面の端に書かれた「21日〜20日」という文字を指でたたいた。「専務、うちの給料は、20日締めの25日払いです」
**払った給料と、原価に入る賃金は、なぜ一致しないのか？**
::

## 労務費の分類 ― 蔵で働く人の、どの支払いが原価になるか

12月の訪問日、椎名は、給与台帳と原価計算表を並べてから言った。「まず、蔵の人件費を全部書き出してみましょう。払っている相手と、払い方で分けます」
澪が書き出したのは、こんな表だった。

::table 労務費の分類（汐見酒造の例）
| 分類 | 内容 | 汐見酒造の例 |
| 賃金 | 製造の現場で働く工員への支払い | 蔵人（直接工）、ボイラー係・精米係（間接工） |
| 給料 | 工場の職員への支払い | 杜氏、品質管理の担当者、工場事務 |
| 雑給 | 臨時・パートタイマーへの支払い | 瓶詰めの繁忙期に頼むパート |
| 従業員賞与手当 | 工場の従業員の賞与・各種手当 | 冬の造りが終わった後の寸志、通勤手当 |
| 退職給付費用 | 工場の従業員の退職金のための費用 | 杜氏・社員の退職金の積立て分（第19章） |
| 法定福利費 | 社会保険料の会社負担分 | 健康保険・厚生年金・雇用保険の会社負担 |
::

このうち、どの製品のための作業かがはっきり分かるのは、**直接工が直接作業をした時間の賃金**だけだ。これが**直接労務費**になり、仕掛品に入る。それ以外は、すべて**間接労務費**として製造間接費に集める。

::theory 直接労務費になるのは「直接工の直接作業時間」の賃金だけ
- **直接工**：製品の加工を直接行う工員（蔵人）
  - 直接作業時間（加工時間と、段取時間）の賃金 → **直接労務費**（仕掛品へ）
  - 間接作業時間（掃除・運搬など）の賃金 → 間接労務費（製造間接費へ）
  - 手待時間（材料待ち・機械の故障などで働けなかった時間）の賃金 → 間接労務費（製造間接費へ）
- **間接工**（ボイラー係・精米係）の賃金、職員の給料、雑給、賞与手当、退職給付費用、法定福利費 → すべて**間接労務費**
同じ蔵人の同じ1時間でも、醪をかき混ぜていれば大吟醸の原価になり、ホースを洗っていれば製造間接費になる。
::

## 支払いと消費 ― 「20日締め」が生むずれ

「お給料を払う期間と、原価を計算する期間が違うんです」と椎名は言った。そして、カレンダーに2本の線を引いた。

::table 2つの「期間」
| 期間 | 範囲 | 何を決めるか |
| 給与計算期間 | 11月21日〜12月20日 | 12月25日に払う額 |
| 原価計算期間 | 12月1日〜12月31日 | 12月の酒の原価に入れる額 |
::

12月25日に払った420万円は、11月21日から12月20日までの働きへの対価だ。その中には、11月の原価に入るべき11月21日〜30日の分が含まれている。逆に、12月21日〜31日の働きの分は、まだ払っていない（1月25日に払う）。
そこで、12月の原価に入れる賃金（**消費賃金**、要支払額）は、次のように計算する。

::formula 消費賃金（要支払額）の計算
当月の消費賃金 ＝ 当月の支払額 － 前月の未払額 ＋ 当月の未払額
::

汐見酒造の12月は、11月21日〜30日の分（前月未払）が90万円、12月21日〜31日の分（当月未払）が130万円だった。年末の仕込みの最盛期で、残業が多かったからだ。
420万円－90万円＋130万円＝**460万円**。これが、12月の酒造りに実際に使われた労働の金額だ。

::example 12月の蔵人（直接工）の賃金を仕訳しなさい
(1) 12月1日、前月末に計上した未払賃金900,000円を、賃金・給料勘定に振り戻した（再振替仕訳）。
(2) 12月25日、11月21日〜12月20日の賃金4,200,000円から、源泉所得税と社会保険料の本人負担分600,000円を差し引き、普通預金から支払った。
(3) 12月31日、12月21日〜31日の未払賃金1,300,000円を計上した。
::answer
::journal (1) 再振替仕訳
未払賃金 900,000 | 賃金・給料 900,000
::
::journal (2) 支払い：総額を賃金・給料の借方に記録する
賃金・給料 4,200,000 | 預り金 600,000
 | 普通預金 3,600,000
::
::journal (3) 当月未払の計上
賃金・給料 1,300,000 | 未払賃金 1,300,000
::
(1)で、賃金・給料勘定の貸方に前月未払の900,000円が入る。(2)で総額4,200,000円、(3)で当月未払1,300,000円が借方に入る。借方の合計5,500,000円から貸方の900,000円を引いた**4,600,000円**が、当月の消費賃金になる。3級の「未払費用」の決算整理と同じ考え方を、毎月行っているわけだ。
::
::

## 予定賃率 ― 1時間あたりの賃金を、先に決める

「では、この460万円を、どう酒に振り分けますか」
澪は、蔵人の作業日報を集計した。12月の蔵人8人の作業時間は、全部で2,400時間。その内訳は、こうだった。

::table 蔵人（直接工）の12月の作業時間
| 作業 | 時間 | 中身 |
| 直接作業時間 | 2,000時間 | 麹づくり・醪の管理・上槽など、どの酒の仕込みか分かる作業 |
| 間接作業時間 | 300時間 | 道具の洗浄・米の運搬・蔵の清掃 |
| 手待時間 | 100時間 | 12月8日のボイラーの故障で、蒸しができなかった時間 |
|= 合計 | 2,400時間 | |
::

実際の賃金460万円を2,400時間で割ると、1時間あたり約1,917円。だが、この「実際の賃率」は月ごとに変わる。12月は残業の割増賃金が多くて高く、仕込みの少ない10月は低い。第2章の材料と同じで、作り方が同じでも、原価が月ごとに揺れてしまう。

::theory 予定賃率と賃率差異
期首に、1年間の賃金の予定総額を、予定の総作業時間で割って**予定賃率**を決めておく。消費した労務費は「実際の作業時間×予定賃率」で計算する。
- 直接作業時間×予定賃率 → 直接労務費（仕掛品へ）
- 間接作業時間・手待時間×予定賃率 → 間接労務費（製造間接費へ）
- 予定消費額と実際の消費賃金との差 → **賃率差異**（予定＜実際なら不利差異＝借方）
::

汐見酒造の今期の予定賃率は、1時間**1,800円**だった。

::example 12月の蔵人の賃金の消費を、予定賃率で仕訳しなさい
予定賃率は1時間1,800円。12月の作業時間は、直接作業2,000時間、間接作業300時間、手待100時間。実際の消費賃金は4,600,000円である。
::answer
::journal (1) 予定賃率による消費
仕掛品 3,600,000 | 賃金・給料 4,320,000
製造間接費 720,000 |
::
::journal (2) 賃率差異：4,320,000円－4,600,000円＝△280,000円（不利差異）
賃率差異 280,000 | 賃金・給料 280,000
::
直接労務費は2,000時間×1,800円＝3,600,000円、間接労務費は(300時間＋100時間)×1,800円＝720,000円。予定消費額は合わせて4,320,000円で、実際より280,000円少ない。この差が、12月の残業の割増賃金などで生じた**賃率差異**だ。
::
::

これで、12月の賃金・給料勘定は、すべての出入りがそろう。

::tgrid
::taccount 賃金・給料（蔵人）
普通預金・預り金 4,200,000 | 未払賃金 900,000
未払賃金 1,300,000 | 仕掛品 3,600,000
 | 製造間接費 720,000
 | 賃率差異 280,000
= 5,500,000 | 5,500,000
::
::taccount 賃率差異
賃金・給料 280,000 |
::
::

## 答え合わせ ― 460万円の行き先

::scene 12月の訪問日、夕方 ― 蔵の事務所
「払った420万円と、消費した460万円の差40万円は、前月未払と当月未払の差なんですね。そして、460万円のうち酒の原価に入ったのは、直接作業の360万円だけ」
澪はT字勘定を指でたどった。「ボイラーが止まって、みんなが待っていた100時間の分も、ちゃんと原価に入っている。ただ、どの酒の原価かは分からないから、製造間接費に」
椎名がうなずいた。「手待時間は、働いていなくても賃金は払います。だから原価から消すわけにはいかない。でも、特定の酒のせいでもない。だから間接です」
::

::solve 支払いと消費は期間が違い、消費のうち直接労務費は「直接作業時間」の分だけ
12月の賃金の流れは、3段階に分かれていた。
1. **支払いと消費のずれ**：20日締めの給料なので、12月に払った420万円は11月21日〜12月20日の分。12月の原価に入れるのは、12月1日〜31日の働きの分＝420万円－前月未払90万円＋当月未払130万円＝**460万円**
2. **直接と間接の振り分け**：460万円のうち、どの酒の仕込みか分かる直接作業2,000時間の分だけが直接労務費（仕掛品）。間接作業と手待の400時間の分は、製造間接費
3. **予定と実際の差**：原価には予定賃率1,800円で計算した額（直接360万円、間接72万円）を入れ、実際との差28万円は賃率差異として取り分ける

::table 12月の蔵人の賃金460万円の行き先（単位：万円）
| 行き先 | 金額 | 計算 |
| 仕掛品（直接労務費） | 360 | 2,000時間×1,800円 |
| 製造間接費（間接労務費） | 72 | 400時間×1,800円 |
| 賃率差異（不利） | 28 | 実際460万円－予定432万円 |
|= 合計 | 460 | |
::
::

岩倉が、自分の帳面の12月のページを開いた。そこには「蔵人給料 420万円」とだけ書かれていた。「わしの帳面では、払った月に払った額を書いて、それを全部、酒の値段に入れとりました。ボイラーが止まって待っとった時間の分まで」
「間違いではありません」と椎名は言った。「お金の出入りの記録としては、正しい。でも、酒1本の原価を知るには、いつの、どの作業の対価かまで分けないといけないんです」

::danger 手待時間を直接労務費に入れると、故障のツケが製品に回る
ボイラーの故障で蔵人が待っていた時間の賃金を、その月に仕込んだ酒の直接労務費に入れてしまうと、その酒の原価は、造り方と関係なく高く見える。12月に仕込んだ大吟醸だけが「高い酒」になり、故障のなかった月の大吟醸と比べられなくなる。
手待時間を製造間接費に分けて集めておけば、「今月は、待ち時間にいくら払ったか」が別に見える。故障の損失を見える形にすることが、設備の修理や点検を判断する材料になる。
::

## 間接工の賃金と、そのほかの労務費

直接工でない人の労務費は、作業時間を細かく記録しなくても、全額が間接労務費になる。消費額は、直接工と同じく「当月の支払額－前月未払＋当月未払」で計算した**要支払額**を使う。

::example 間接工の賃金と、職員の給料・法定福利費を仕訳しなさい
(1) ボイラー係と精米係（間接工）の当月の賃金の支払額は800,000円、前月未払は150,000円、当月未払は200,000円だった。要支払額を消費額とする。
(2) 杜氏と品質管理の担当者の給料（工場の職員）の当月の要支払額は1,100,000円だった。
(3) 工場の従業員の社会保険料の会社負担分280,000円を、普通預金から納付した（法定福利費）。
::answer
::journal (1) 要支払額：800,000円－150,000円＋200,000円
製造間接費 850,000 | 賃金・給料 850,000
::
::journal (2)
製造間接費 1,100,000 | 賃金・給料 1,100,000
::
::journal (3) 法定福利費の発生と、製造間接費への振替え
法定福利費 280,000 | 普通預金 280,000
製造間接費 280,000 | 法定福利費 280,000
::
(3)は、法定福利費の勘定にいったん記録してから、製造間接費に振り替えている。問題によっては、最初から「製造間接費／普通預金」と仕訳する場合もある。どちらでも、工場の従業員の法定福利費が間接労務費になることは同じだ。本社の事務員の分は、製造原価ではなく販売費及び一般管理費になる。
::
::

::sort 次の労務費を、直接労務費と間接労務費に分けなさい。
@cats 直接労務費 | 間接労務費
蔵人が大吟醸の醪を管理した時間の賃金 => 直接労務費
蔵人が純米吟醸の麹づくりの段取りをした時間の賃金 => 直接労務費
蔵人がタンクの掃除をした時間の賃金 => 間接労務費
停電で蔵人が作業を待った時間の賃金 => 間接労務費
ボイラー係の賃金 => 間接労務費
工場の従業員の健康保険料の会社負担分 => 間接労務費
::

::exam 労務費の出題の急所
- **消費賃金＝当月支払－前月未払＋当月未払**。「支払額」をそのまま消費額にしないこと。前月未払は月初の再振替仕訳で賃金・給料の貸方に、当月未払は月末に借方に入る
- **直接工の直接作業時間（加工＋段取）だけが直接労務費**。間接作業時間と手待時間は製造間接費
- **間接工の賃金・職員の給料**は要支払額を全額、製造間接費へ
- **賃率差異**：「予定賃率×実際作業時間」と実際消費額の差。予定＜実際なら借方（不利）、予定＞実際なら貸方（有利）
- 総額で支払う仕訳では、源泉所得税・社会保険料の本人負担分を**預り金**で処理する（3級と同じ）
::

## 瓶詰め場の求人票 ― 最低賃金が、2年続けて過去にない速さで上がった

::scene 12月の第3月曜日 ― 瓶詰め場
年明けの繁忙期に向けて、瓶詰め部門の宇佐美が、パートの求人票を持ってきた。時給の欄には「1,108円〜」とある。
「10月から、新潟の最低賃金が1,108円になりました。今いる4人のパートさんも、全員1,108円に上げています」
澪は、7月に岩倉が作った今期の予算を開いた。パートの賃金の予定の時給は、**1,050円**のままだった。
「番頭さん、この1,050円は」
「7月の時点の最低賃金です。まさか、去年に続いて今年もこんなに上がるとは」
::

厚生労働省によると、2025年度の地域別最低賃金の全国加重平均は**1,121円**で、前年度から66円上がった。1978年度に目安制度が始まってから最大の引上げ額だ。2026年度はさらに56円上がって**1,177円**になった。新潟県は、2024年度の985円から、2025年10月2日に1,050円、2026年10月1日に**1,108円**になっている。季節の作業員やパートを時給で雇う酒蔵にとって、賃金の上昇は、そのまま労務費の上昇になる。
澪は、この章で学んだ予定賃率の仕組みで、蔵のパートの賃金を計算した。パート4人が、10月から月に各180時間働いている（瓶詰めのパートの賃金は、雑給として間接労務費になる）。

::journal ① 予定の時給による消費：720時間×1,050円
製造間接費 756,000 | 賃金・給料 756,000
::
::journal ② 賃率差異：756,000円－720時間×1,108円（797,760円）＝△41,760円
賃率差異 41,760 | 賃金・給料 41,760
::

1か月で約4万円、10月から6月までの9か月で約38万円の不利差異になる。第2章の材料消費価格差異と同じで、差異は年度末に売上原価に加算され、利益を確実に削る。
「この差異は、パートさんの手が遅いせいでも、宇佐美さんの管理のせいでもありません」と澪は言った。「賃金の水準そのものが変わったことを知らせているだけです。来期の予定賃率は、毎年夏に答申される最低賃金の改定を見込んで決めましょう」
岩倉は、予算表の1,050円に赤で線を引いた。「先代の頃は、最低賃金が上がるのは年に十何円でした。帳面の物差しを、毎年見直す時代になったわけですな」

::cfo 1月の仕込み計画 ― 時給の安い人に任せれば、原価は下がるか
年明けの仕込みの最盛期を前に、杜氏の小松が言った。「1月は、大吟醸と純米吟醸の仕込みが重なる。ベテランの手が足りん」
番頭の岩倉は、別の案を持ってきた。「ベテランの時給は2,000円、季節で来てくれる新人さんは1,300円です。新人さんに仕込みもやってもらえば、原価は下がります」
::table 1月の作業計画（ベテラン3人・新人2人。法定福利費を含む1時間あたりの賃金）
| 項目 | ベテラン | 新人 |
| 1時間あたりの賃金 | 2,000円 | 1,300円 |
| 1月に働ける時間（残業なし） | 3人で600時間 | 2人で400時間 |
| 吟醸の仕込み作業（直接作業） | 600時間で終わる | ベテランの1.8倍の時間がかかる |
| 洗い場・米の運搬など（間接作業） | 400時間 | 400時間（速さは同じ） |
| 残業の賃金 | 1時間2,500円（25%増し） | ― |
::
まず、各案の労務費の合計（賃率×時間）を計算してから選んでほしい。残業は、時間外労働の法律の上限にも気をつけること。
::choice A. 時給の安い新人に、仕込み作業をできるだけ任せる
**× 時給は安くても、時間がかかる。**新人2人が400時間すべてを仕込みに使っても、ベテランに換算すると400÷1.8≒222時間分しか進まない。残りの仕込み378時間と洗い場400時間の合計778時間をベテランが担うと、178時間（1人あたり約59時間）の残業になる。労務費は、新人400時間×1,300円＝52万円＋ベテラン600時間×2,000円＝120万円＋残業178時間×2,500円＝44.5万円で、**約216.5万円**。安い賃率に飛びついた結果、最も高くつく案の1つになる。
::
::choice B. ベテランは仕込みに専念し、新人は洗い場と運搬を受け持つ
**◎ 賃率と時間の両方を見ている。**ベテラン600時間×2,000円＝120万円で仕込みがちょうど終わり、新人400時間×1,300円＝52万円で間接作業がちょうど終わる。残業はゼロで、合計**172万円**。4つの案で最も安い。
しかも、直接作業の時間が最も短くなるので、吟醸酒の仕掛品に入る直接労務費も最も小さい。予定賃率1,800円で計算すると、直接労務費は600時間×1,800円＝108万円。A案のように直接作業が778時間に延びれば、140万400円になる。
::
::choice C. 洗い場はベテランと新人で半分ずつ受け持ち、残りの時間で全員が仕込みをする（公平に分ける）
**△ 公平だが、高くつく。**洗い場400時間を200時間ずつ分けると、ベテランの仕込みは400時間、新人の仕込みは200時間。新人の200時間はベテランの約111時間分なので、仕込みは400＋111＝511時間分しか進まず、残り89時間をベテランの残業で補う。労務費は、ベテラン120万円＋新人52万円＋残業89時間×2,500円＝22.25万円で、**約194.3万円**。B案より22万円以上高い。作業の向き不向きを無視すると、そのぶん時間がかかる。
::
::choice D. 新人は雇わず、ベテランの残業ですべてこなす
**× 法律の上限を超える。**必要な時間は仕込み600時間＋洗い場400時間＝1,000時間で、ベテラン3人の600時間を超える400時間が残業になる。1人あたり月約133時間だ。労働基準法の時間外労働の上限は、原則として月45時間・年360時間。労使の特別な合意があっても、休日労働を含めて月100時間未満でなければならない。費用も120万円＋400時間×2,500円＝100万円で**220万円**と、最も高い。
::
::answer 考え方の例を見る
労務費は「賃率×時間」だ。賃率の安さだけを見ても、原価は下がらない。その人がその作業に、何時間かかるかを掛けて初めて、本当の費用が分かる。そして、熟練の人の時間を、熟練が必要な直接作業に集中させることが、製品の原価（直接労務費）を下げる最も確かな道になる。
1月、澪はB案で作業表を組んだ。新人の2人は、洗い場と米の運搬の段取りを1週間で覚え、月の後半には、小松が「麹室の掃除を任せられる」と言うまでになった。岩倉は、作業日報の様式を変えた。「直接」「間接」「待ち」の3つの欄をつけたのだ。
::
::

::next 労務費は、人の「時間」を測る技術になる
標準原価計算（第9章）では、製品1本を作るのにかかるべき**標準作業時間**を決め、実際の作業時間との差を**作業時間差異**として測る。賃率の差（賃率差異）と、時間の差（作業時間差異）を分けることで、「賃金が上がったのか」「作業に時間がかかったのか」を区別できるようになる。1級では、さらに作業の能率や、人の配置の意思決定に使う。
::

::summary
- 労務費は、賃金・給料・雑給・従業員賞与手当・退職給付費用・法定福利費に分かれる
- 直接労務費になるのは、直接工の直接作業時間（加工＋段取）の賃金だけ。間接作業時間・手待時間の賃金、間接工の賃金、職員の給料などは間接労務費（製造間接費）
- 給与計算期間と原価計算期間がずれるので、当月の消費賃金＝当月支払額－前月未払＋当月未払（要支払額）
- 予定賃率×実際作業時間で消費を記録し、実際との差は賃率差異（予定＜実際なら不利差異＝借方）。年度末に売上原価に振り替える
- 労務費は「賃率×時間」。賃率の安さだけでなく、作業にかかる時間を掛けて判断する
::
