::mystery 40万円の水増し
12月25日、金曜日。給料日。澪は初めて、蔵人たちの給料を自分の手で振り込んだ。季節の蔵人を含む8人の直接の作業員に、総額**420万円**。
5日後の12月30日。月末の原価計算をしていた澪の手が、止まった。12月の労務費が、**460万円**になっている。
払った額より、40万円多い。
澪：「払っていない40万円が、どうして原価に……」
そこへ、瓶詰め部門の責任者の宇佐美が、作業日報の束を抱えて入ってきた。年末の出荷で、目の下に隈ができている。
宇佐美：「専務、その数字、見ましたよ。40万円も多いなんて、おかしいでしょう」
宇佐美：「誰かが作業時間を水増ししてるんじゃないですか。日報を書くのは、本人ですからね」
陸が、帳場の隅で小さくなった。陸の日報には、12月8日の午後に「待機　4時間」と書いてある。
奇妙なことは、もう1つあった。460万円のうち、酒の原価（仕掛品）に入っていたのは、360万円だけだったのだ。
**蔵人の時間は、水増しされていたのか。払っていない40万円は、どこから来たのか？**
::

## 給与明細の日付 ― 払った日と、働いた日

澪は、岩倉に給与台帳を見せてもらった。表紙に、手書きで「二十日締め　二十五日払い」とある。
澪：「20日締め……。12月25日に払った給料は、いつ働いた分ですか」
岩倉：「11月21日から12月20日までの分です。蔵では先代のころから、ずっとそうしとります」
澪の頭の中で、カレンダーが2枚並んだ。原価計算をする「12月」は、12月1日から31日まで。給料を計算する「12月分」は、11月21日から12月20日まで。2つの「12月」は、10日分ずれている。

::table 2つの「12月」
| 期間 | 範囲 | 使い道 |
| 原価計算期間 | 12月1日〜12月31日 | 12月の酒の原価を計算する |
| 給与計算期間 | 11月21日〜12月20日 | 12月25日に払う給料を計算する |
::

12月25日に払った420万円には、11月の原価に入るべき11月21日〜30日の分が含まれている。逆に、12月21日〜31日の働きの分は、まだ払っていない。払うのは1月25日だ。
汐見酒造の12月は、11月21日〜30日の分（前月未払）が90万円、12月21日〜31日の分（当月未払）が130万円だった。年末の仕込みの最盛期で、残業が多かったからだ。
420万円－90万円＋130万円＝**460万円**。これが、12月の酒造りに実際に使われた労働の金額だった。
澪：「40万円は、水増しじゃない。払う日と働く日のずれだったんだ」

::point メモ ― 支払賃金と消費賃金
給与計算期間に対して支払う**支払賃金**と、原価計算期間に実際に使われた労働の金額である**消費賃金**（要支払額）は、締め日がずれると一致しない。消費賃金＝当月の支払賃金－前月未払＋当月未払。前月末の未払賃金は月初に**再振替仕訳**で賃金・給料の貸方に戻しておき、支払時は総額を借方に記録する。
::

::example 12月の蔵人の賃金を記録する（支払いから月末まで）
12月1日、前月末に計上した未払賃金900,000円を再振替した。12月25日、蔵人の12月分の賃金4,200,000円から、源泉所得税120,000円と社会保険料380,000円を差し引き、普通預金から振り込んだ。12月31日、12月21日〜31日の未払分1,300,000円を計上した。
::answer
::journal (1) 12月1日　再振替仕訳
未払賃金 900,000 | 賃金・給料 900,000
::
::journal (2) 12月25日　支払い：総額を賃金・給料の借方に
賃金・給料 4,200,000 | 所得税預り金 120,000
 | 社会保険料預り金 380,000
 | 普通預金 3,700,000
::
::journal (3) 12月31日　当月未払の計上
賃金・給料 1,300,000 | 未払賃金 1,300,000
::
賃金・給料勘定の借方は4,200,000円＋1,300,000円＝5,500,000円、貸方の再振替は900,000円。差し引き4,600,000円が、12月の消費賃金になる。
::trap
支払時に借方に書くのは、差し引く前の**総額**4,200,000円だ。手取りの3,700,000円を書かないこと。源泉所得税や社会保険料は、会社が一時的に預かって国などに納めるお金なので、預り金（負債）にする。
::
::
::

## 2,400時間の内訳 ― 直接作業・間接作業・手待時間

::scene 12月30日、午後3時 ― 帳場
澪は、宇佐美が持ってきた日報を1枚ずつめくった。12月の蔵人8人の作業時間は、全部で2,400時間。
陸の日報の12月8日を指さして、宇佐美が言った。
宇佐美：「ほら、これ。『待機　4時間』。働いてない時間まで、つけてるじゃないですか」
陸：「あの日、ボイラーが止まって、米が蒸せなかったんすよ。親方に『動くな、待ってろ』って言われて……」
小松：「待たせたのは、わしだ。蒸せねえ米は、触りようがねえ」
::

澪は、2,400時間を、何をしていた時間かで3つに分けた。

::table 蔵人（直接工）の12月の作業時間
| 作業 | 時間 | 中身 |
| 直接作業時間 | 2,000時間 | 麹づくり・醪の管理・上槽など、どの酒の仕込みか分かる作業 |
| 間接作業時間 | 300時間 | 道具の洗浄・米の運搬・蔵の清掃 |
| 手待時間 | 100時間 | 12月8日のボイラーの故障で、修理と点検が終わるまで蒸しができなかった時間（8人の合計） |
|= 合計 | 2,400時間 | |
::

椎名に電話で聞くと、答えは短かった。
椎名：「手待時間は、働いていなくても賃金を払います。だから原価から消すわけにはいかない。でも、どの酒のせいでもない」
椎名：「どの酒の作業か分かる時間だけが、その酒の原価になる。残りは全部、製造間接費です」

::theory 直接労務費になるのは「直接工の直接作業時間」の賃金だけ
製造の現場で直接、製品の加工をする人を**直接工**、それ以外の修理工・運搬係・検査係などを**間接工**という。直接工の作業時間は次のように分かれ、行き先が違う。
- **直接作業時間**（加工時間と段取時間）の賃金 → **直接労務費**（仕掛品へ）
- **間接作業時間**（掃除・運搬など）の賃金 → 間接労務費（製造間接費へ）
- **手待時間**（材料待ち・機械の故障などで働けなかった時間）の賃金 → 間接労務費（製造間接費へ）
同じ蔵人の同じ1時間でも、醪をかき混ぜていれば大吟醸の原価になり、ホースを洗っていれば製造間接費になる。
::

宇佐美は、表を見て腕を組んだ。
宇佐美：「待ってた時間も払うのは、まあ分かりますよ。でも、それなら酒の原価にしなきゃいいじゃないですか」
澪：「酒の原価にはしていないんです。製造間接費として、全部の酒で薄く負担する。故障のツケを、12月に仕込んだ酒だけに背負わせないために」

## 1時間1,800円 ― 予定賃率と賃率差異

実際の賃金460万円を2,400時間で割ると、1時間あたり約1,917円。だが、この「実際の賃率」は月ごとに変わる。12月は残業の割増賃金が多くて高く、仕込みの少ない10月は低い。第2章の米と同じで、造り方が同じでも、酒の原価が月ごとに揺れてしまう。
澪：「米と同じなら……賃金にも、予定の値段があるんですか」
岩倉：「ございます。今期は1時間1,800円。7月に、社長と決めました」

::point メモ ― 予定賃率
期首に、1年間の賃金の予定総額を予定の総作業時間で割って、**予定賃率**を決めておく。消費した労務費は「実際の作業時間×予定賃率」で計算し、実際の消費賃金との差を**賃率差異**として取り分ける。予定が実際より少なければ不利差異（借方）、多ければ有利差異（貸方）。年度末に売上原価へ振り替えるのは、材料消費価格差異と同じだ。
::

::example 12月の蔵人の賃金の消費を、予定賃率で記録する
予定賃率は1時間1,800円。12月の作業時間は、直接作業2,000時間、間接作業300時間、手待100時間。実際の消費賃金は4,600,000円である。
::answer
::journal (1) 予定賃率による消費：直接2,000時間×1,800円、間接（300時間＋100時間）×1,800円
仕掛品 3,600,000 | 賃金・給料 4,320,000
製造間接費 720,000 |
::
::journal (2) 賃率差異：4,320,000円－4,600,000円＝△280,000円（不利差異）
賃率差異 280,000 | 賃金・給料 280,000
::
予定消費額は4,320,000円で、実際より280,000円少ない。年末の残業の割増賃金などが、この差になって表れた。
::trap
手待時間と間接作業時間を、直接労務費に入れないこと。予定賃率で計算するのは「全部の作業時間」だが、仕掛品に入れるのは直接作業時間の分だけだ。
::
::
::

::tgrid
::taccount 賃金・給料（蔵人）
諸口 4,200,000 | 未払賃金 900,000
未払賃金 1,300,000 | 仕掛品 3,600,000
 | 製造間接費 720,000
 | 賃率差異 280,000
= 5,500,000 | 5,500,000
::
::taccount 賃率差異
賃金・給料 280,000 |
= 280,000 |
::
::

澪は、宇佐美の疑いを、数字で1つずつ確かめた。払った420万円と、消費した460万円の差40万円は、前月未払90万円と当月未払130万円の差だ。
460万円のうち仕掛品に入ったのは、直接作業2,000時間×1,800円＝360万円。間接作業と手待の400時間分72万円は製造間接費へ、予定と実際の差28万円は賃率差異へ分かれていた。どこにも、水増しの入る余地はなかった。

::solve 水増しはなかった。40万円は締め日のずれ、100時間は故障のツケだった
12月に払った420万円は、11月21日から12月20日までの働きへの対価だった。12月の酒造りに使われた労働は、そこから前月未払90万円を除き、当月未払130万円を加えた460万円。40万円は、水増しではなく、カレンダーのずれだった。
460万円のうち、酒の原価（仕掛品）に入ったのは、直接作業2,000時間分の360万円だけ。ボイラーが止まって陸たちが待っていた100時間の分は、間接作業の300時間とともに製造間接費72万円に、残業の割増などで生じた28万円は賃率差異に分かれた。
もし宇佐美の言うとおり日報を疑って、待機の4時間を消させていたら、帳簿から故障の損失が見えなくなり、12月の酒の原価も、来月の判断も、すべて狂っていた。
**払った日ではなく働いた日で数え、どの酒の時間かで分ける。**労務費は、お金ではなく時間の記録から作られる。
::

宇佐美は、しばらく日報の束を見つめていた。
宇佐美：「……悪かったな、陸。待機って書いたのは、正しかったんだ」
陸：「いや、俺も最初、なんで待ってるのに給料もらえるんだろって思ってたんで」
岩倉が、自分の帳面の12月のページを開いた。そこには「蔵人給料　420万円」とだけ書かれていた。
岩倉：「わしの帳面では、払った月に払った額を書いて、全部を酒の値段に入れとりました。待っとった時間の分まで」

::danger 手待時間を直接労務費に入れると、故障のツケが製品に回る
ボイラーの故障で待っていた時間の賃金を、その月に仕込んだ酒の直接労務費に入れると、その酒の原価だけが、造り方と関係なく高く見える。手待時間を製造間接費に分けて集めれば、「今月、待ち時間にいくら払ったか」が別に見え、設備の修理や点検を判断する材料になる。
::

### 試験で狙われるパターン ― 間接工と職員・法定福利費・経費の4分類

ここからは、試験で形を変えて出題される3つのパターンを押さえておこう。

**① 間接工の賃金と、職員の給料**　間接工や工場の事務職員の労務費は、作業時間を細かく記録しなくても、全額が間接労務費になる。消費額は「当月支払－前月未払＋当月未払」の要支払額を使う。工場の社会保険料の会社負担分（**法定福利費**）や、工場の従業員の賞与も、間接労務費だ。

::example 間接工の賃金と、法定福利費
間接工（ボイラー係・精米係）の当月の支払賃金は800,000円、前月未払は150,000円、当月未払は200,000円だった。また、工場の従業員の社会保険料760,000円（給料から預かった従業員負担分380,000円と、会社負担分380,000円）を普通預金から納付し、会社負担分を製造間接費に振り替えた。
::answer
::journal (1) 間接工の要支払額：800,000円－150,000円＋200,000円＝850,000円
製造間接費 850,000 | 賃金・給料 850,000
::
::journal (2) 社会保険料の納付：従業員負担分は預り金を返し、会社負担分は法定福利費
社会保険料預り金 380,000 | 普通預金 760,000
法定福利費 380,000 |
::
::journal (3) 会社負担分を製造間接費に振り替える
製造間接費 380,000 | 法定福利費 380,000
::
間接工の賃金は、どの酒の作業かを特定しないので、全額を製造間接費にする。法定福利費は会社が負担する社会保険料で、工場の分は間接労務費になる。
::trap
従業員負担分は、給料から預かっていたお金（社会保険料預り金）を返すだけなので、原価にならない。原価になるのは、会社負担分の法定福利費だけだ。
::
::
::

**② 経費は、金額の測り方で4つに分ける**　材料費・労務費以外の原価が**経費**だ。何をもとに当月の金額を決めるかで、4つに分かれる。

::table 経費の4分類（汐見酒造の例）
| 分類 | 当月の金額の決め方 | 例 |
| 支払経費 | 当月の支払額（未払・前払があれば調整） | 修繕費、旅費交通費、外注加工賃 |
| 月割経費 | 年額や半年分を月数で割る | 減価償却費、保険料、賃借料（支払リース料） |
| 測定経費 | メーターで測った消費量 | 電気代、ガス代、水道代 |
| 発生経費 | 当月に発生した額 | 棚卸減耗費 |
::

**③ 外注加工賃は、直接経費**　ほとんどの経費は製造間接費（間接経費）になるが、特定の製品の加工を外部に頼んだ**外注加工賃**は、その製品にたどれるので**直接経費**として仕掛品に入れる。

::example 特注ラベルの印刷と貼付けを、外の印刷会社に頼んだ
12月、得意先の注文で造る記念酒の瓶に、特注ラベルを印刷して貼る作業を、外部の印刷会社に委託した。代金250,000円は月末に支払う約束である。同じ月、仕込み蔵の火災保険料（年額1,200,000円）の月割額を計上した。
::answer
::journal (1) 外注加工賃は直接経費として仕掛品へ
仕掛品 250,000 | 未払金 250,000
::
::journal (2) 保険料は月割経費：1,200,000円÷12か月＝100,000円。間接経費
製造間接費 100,000 | 前払保険料 100,000
::
外注加工賃は、記念酒という特定の製品のための加工なので、直接経費。保険料は、仕込み蔵のすべての酒に共通なので、間接経費として製造間接費に入れる（年額を前払いしている場合の月割の例）。
::trap
「経費＝製造間接費」と決めつけないこと。直接経費の代表が外注加工賃だ。逆に、工場の減価償却費・保険料・電気代は、金額が大きくても間接経費になる。
::
::
::

::steps 解法の型 ― 労務費の問題
1. 支払と消費を分ける | 消費賃金＝当月支払－前月未払＋当月未払
2. 直接工の時間を3つに分ける | 直接作業（加工・段取）／間接作業／手待
3. 予定賃率を掛ける | 直接作業時間→仕掛品、間接作業・手待→製造間接費
4. 差異を出す | 予定消費額－実際消費額。マイナスは不利（借方）
5. 間接工・職員・法定福利費・賞与 | すべて製造間接費（間接労務費）
::

## 瓶詰め場の求人票 ― 最低賃金が、2年続けて大きく上がった

::scene 1月6日、仕事始め ― 瓶詰め場
瓶詰め場の壁に、宇佐美が新しい求人票を貼っていた。パートの時給の欄に、「1,108円〜」とある。
宇佐美：「去年の秋までは1,050円で出せたんですけどね。10月から、県の最低賃金が上がったんで」
澪：「1,050円で7月に決めた予定は、もう合わないってことですね」
::

新潟県の最低賃金は、2026年10月1日から、1時間**1,050円**から**1,108円**に、58円（5.52%）上がった。全国の加重平均も**1,177円**と、前の年から56円上がった。前の年の66円に次ぐ、過去2番目の大きさの引上げだ。
澪は、この章の予定賃率の仕組みで、瓶詰め場のパートの賃金を計算した。パート4人が、10月から月に各180時間、瓶詰めラインで働いている。日報でどの酒を詰めたかが分かる作業なので、蔵人と同じく直接工として予定賃率で計算する（ここでは、すべて直接作業時間とする）。7月に決めたパートの予定賃率は、当時の最低賃金と同じ1時間1,050円だった。

::journal ① 予定賃率による消費：720時間×1,050円
仕掛品 756,000 | 賃金・給料 756,000
::

::journal ② 賃率差異：756,000円－720時間×1,108円（797,760円）＝△41,760円（不利差異）
賃率差異 41,760 | 賃金・給料 41,760
::

1か月で約4万円、10月から6月までの9か月で約38万円の不利差異になる。差異は年度末に売上原価に加算され、利益を確実に削る。予定を据え置いたまま「原価計算表の賃金は変わっていない」と安心すると、第2章の米と同じ落とし穴にはまる。
岩倉：「米も人も、7月に決めた値段のままでは、年は越せませんな」

::cfo 1月の仕込みの段取り ― ベテランと新人を、どう組むか
1月は吟醸酒の仕込みが山場を迎える。小松は、ベテランの蔵人3人と、新人2人（陸ともう1人）の割り振りを、澪に相談した。
**前提**
- 法定福利費を含む1時間あたりの賃金は、ベテラン2,000円、新人1,300円
- 1月に残業なしで働ける時間は、ベテラン3人で600時間、新人2人で400時間
- 吟醸酒の仕込み（直接作業）は、ベテランなら600時間で終わる。新人だとベテランの1.8倍の時間がかかる
- 洗い場・米の運搬など（間接作業）は400時間分あり、ベテランも新人も速さは同じ
- 残業の賃金は1時間2,500円（25%増し）
- 今期の予定賃率は1時間1,800円
::choice A. ベテラン3人は仕込みに専念し、新人2人が洗い場と運搬を受け持つ
**◎ 賃率と時間の両方を見ている。**ベテラン600時間×2,000円＝120万円で仕込みがちょうど終わり、新人400時間×1,300円＝52万円で間接作業がちょうど終わる。残業はゼロで、合計**172万円**。4つの案で最も安い。
::
::choice B. 時給の安い新人に仕込みを任せ、足りない分はベテランの残業で補う
**× 時給は安くても、時間がかかる。**新人2人の400時間は、ベテランに直すと約222時間分しか進まない。残りの仕込み378時間と洗い場400時間をベテランが担うと、178時間の残業になる。新人52万円＋ベテラン120万円＋残業44.5万円で、**約216.5万円**。
::
::choice C. 洗い場はベテランと新人で半分ずつ受け持ち、残りの時間で全員が仕込みをする
**△ 公平だが、高くつく。**新人の仕込み200時間はベテランの約111時間分なので、仕込みは511時間分しか進まず、残り89時間をベテランの残業で補う。120万円＋52万円＋残業約22.3万円で、**約194.3万円**。
::
::choice D. 新人2人は1月の勤務を入れず、仕込みも洗い場もベテラン3人の残業でこなす
**× 費用も法律も超える。**必要な1,000時間のうち400時間が残業で、1人あたり月約133時間。時間外労働の上限（原則月45時間、特別な場合も月100時間未満）を超える。費用も120万円＋100万円＝**220万円**で最も高い。
::
::answer 考え方の例を見る
#### 手順1　問いを言い換える
「誰の時給が安いか」ではなく、「仕込みと洗い場を終えるのに、賃金の合計がいちばん少ない組み方はどれか」を問う。
#### 手順2　前提の数字で確かめる
::table compact 4つの組み方の労務費（1月）
| 案 | 残業 | 労務費の合計 |
| A ベテランは仕込み、新人は洗い場 | 0時間 | 172万円 |
| B 新人が仕込み、不足はベテランの残業 | 178時間 | 約216.5万円 |
| C 洗い場を半分ずつ | 89時間 | 約194.3万円 |
| D ベテラン3人だけ | 400時間 | 220万円 |
::
#### 手順3　ほかの答えに引かれる理由
Bは「時給の安い人に任せれば安い」という直感に、Cは「みんなで公平に」という気持ちに引かれる。どちらも、作業ごとにかかる時間の違いを掛けていない。予定賃率1,800円は、この判断には関係のない前提だ。
#### 持ち帰る考え方
- **労務費は賃率×時間**：賃率の安さだけでは、原価は下がらない
- **熟練の時間は、熟練が要る作業に**：直接作業の時間が最も短くなる組み方が、製品の原価（直接労務費）も下げる
#### 前提が変われば
新人が仕込みに慣れて、ベテランの1.2倍の時間で済むようになれば、新人に仕込みを一部任せたほうが安くなる場合もある。人を育てる時間をどう見込むかも、労務費の判断だ。
::
::

::exam 労務費・経費の急所
- 消費賃金＝当月支払－前月未払＋当月未払。支払時は**総額**を借方に、預り金は差し引いた分
- 直接労務費は**直接工の直接作業時間（加工＋段取）**の賃金だけ。間接作業・手待時間は製造間接費
- 間接工・事務職員の賃金、法定福利費、工場の賞与は、すべて製造間接費（間接労務費）
- 賃率差異＝予定賃率×実際作業時間－実際消費額。マイナスは不利（借方）
- 経費のほとんどは間接経費。**外注加工賃は直接経費**として仕掛品へ
::

::next 労務費は、人の「時間」を測る技術になる
第9章の標準原価計算では、製品1本を作るのにかかるべき**標準作業時間**を決め、実際との差を**作業時間差異**として測る。賃率の差と時間の差を分けることで、「賃金が上がったのか」「作業に時間がかかったのか」を区別できる。1級では、人の配置や作業の能率の意思決定にも使う。
::

::summary
- 給与計算期間と原価計算期間がずれるので、消費賃金＝当月支払－前月未払＋当月未払で計算する
- 直接工の直接作業時間の賃金だけが直接労務費。間接作業・手待時間の賃金は製造間接費
- 予定賃率×実際作業時間で消費を記録し、実際との差は賃率差異として年度末に売上原価へ
- 間接工・職員の賃金、法定福利費、賞与は間接労務費
- 経費は支払・月割・測定・発生に分かれ、外注加工賃は直接経費
::

## 確認問題

::quiz
::problem 次の作業時間の賃金を、直接労務費と間接労務費に分けなさい。
::sort
@cats 直接労務費 | 間接労務費
直接工が大吟醸の醪を管理した時間の賃金 => 直接労務費
直接工が純米吟醸の麹づくりの段取りをした時間の賃金 => 直接労務費
直接工がタンクの掃除をした時間の賃金 => 間接労務費
停電で直接工が作業を待った時間の賃金 => 間接労務費
ボイラー係（間接工）の賃金 => 間接労務費
工場の従業員の法定福利費 => 間接労務費
::
::answer
直接労務費になるのは、直接工の直接作業時間（加工と段取）の賃金だけ。掃除などの間接作業時間、停電などの手待時間、間接工の賃金、法定福利費は、すべて間接労務費（製造間接費）になる。
::
::
::problem 次の取引を仕訳しなさい。予定賃率は1時間1,200円である。
(1) 直接工の当月の作業時間は、直接作業時間900時間、間接作業時間80時間、手待時間20時間だった。予定賃率で消費額を計上する。
(2) 直接工の当月の実際の消費賃金は1,215,000円だった。賃率差異を計上する。
::answer
::journal (1) 直接900時間×1,200円、間接（80時間＋20時間）×1,200円
仕掛品 1,080,000 | 賃金・給料 1,200,000
製造間接費 120,000 |
::
::journal (2) 1,200,000円－1,215,000円＝△15,000円（不利差異）
賃率差異 15,000 | 賃金・給料 15,000
::
予定消費額は1,000時間×1,200円＝1,200,000円。実際のほうが15,000円多いので、借方（不利）差異になる。
::
::
::problem 当月の直接工の支払賃金は2,500,000円、前月未払賃金は400,000円、当月未払賃金は550,000円だった。当月の消費賃金（要支払額）を求めなさい。
消費賃金 [[2,650,000]] 円
::answer
2,500,000円－400,000円＋550,000円＝**2,650,000円**。前月未払は、当月の支払額に含まれているが先月の働きの分なので引き、当月未払は、まだ払っていないが今月の働きの分なので足す。
::
::
::problem 次の取引を仕訳しなさい。
(1) 製品の一部の加工を外部の業者に委託し、外注加工賃300,000円を普通預金から支払った。
(2) 工場の建物の減価償却費の月割額150,000円を計上した。
::answer
::journal (1) 外注加工賃は直接経費
仕掛品 300,000 | 普通預金 300,000
::
::journal (2) 工場の減価償却費は間接経費
製造間接費 150,000 | 減価償却累計額 150,000
::
特定の製品の加工を頼んだ外注加工賃は、仕掛品に直接入れる。工場の建物の減価償却費は、すべての製品に共通なので製造間接費。
