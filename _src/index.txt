::theory 重要理論は、藍の帯の札に
簿記のルールの「なぜ」を説明する、最も大切な理論。1級でもそのまま使う知識なので、ここだけは必ず理解してから先へ進もう。

::point 用語や手順の補足は、付箋に
会話の中で出てきた言葉の、正確な定義を補う。
::

::danger 「経営の落とし穴」は、縞のテープの警告票に
会計処理を誤ったり、数字の裏の事実を見落としたりしたとき、会社がどんな危機に陥るかを描く。ルールが生まれた理由は、たいていここにある。
::

::cfo 「考えてみよう」は、稟議書の形の黄色いボックスに
蔵が実際に迷いそうな場面で、**どう見積もり、どう考え、何で確かめるか**を問う、試験の範囲を超えた発展問題。どの選択肢にも一理があり、言葉づかいから正解は透けない。決め手は、前提どうしの組み合わせや、ひと手間の計算の中にある。前提には、判断に関係のないものも混ぜてある。
試験には出ないので、まずは本文・ケース・確認問題を優先してよい。時間に余裕があるときや、2周目に読むときの挑戦問題として取り組もう。
::choice A. 選ぶ前に、自分の考えの理由を一言メモしておく
**◎ それがいちばん効く。**講評を読んだとき、自分の考えのどこが違っていたのかが、はっきり分かる。
::
::choice B. 考えずに、とりあえず選んで講評を読む
**△ もったいない。**講評は読める。だが、迷わずに選んだ答えからは、ほとんど何も残らない。
::
::answer
1つ選ぶと、その選択への講評が開く。最後の「考え方の例」では、見積もり方と確かめ方の筋道をまとめている。
::
::

- 出題のパターン、ひっかけ、時間を短くするテクニック。試験の直前は、この半券だけを拾い読みするのも効果的だ

::teaser 次回予告は、章のいちばん最後に
次の事件の幕開けを、ひとコマだけ見せる。

::point ケースで処理のしかたをつかみ、章末の確認問題は「TRY」で手を動かして解く
- **ケース**：蔵で起きた状況のすぐ下に、その処理のしかたと「間違えやすいポイント」を並べている。まず読んで、型をつかもう。
- **仕訳**：勘定科目をドラッグで記入欄へ入れ（またはタップしてから記入欄をタップ）、金額を入力して「答え合わせ」する。
- **空欄**：計算問題や、表の空欄に数字を入力する。勘定科目や語句の空欄は、タップして選択肢から選ぶ。
- **分類**：項目をドラッグで分類先へ移す。
章末の確認問題では、ネット試験と同じように、自分の手で答えを作ってから解説を開こう。
::

- **勘定科目をタップ**：本文で点線の下線がついた勘定科目をタップすると、付録Aの辞典の説明を確認できる。
