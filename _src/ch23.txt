8月28日、土曜日。蔵の座敷で、汐見酒造の定時株主総会が開かれた。株主は、発行済株式2,000株のうち1,300株を持つ父と、100株の母、そして600株（30%）を持つ分家の叔父だ。父は車椅子で、上座に座っていた。

**1,490万円の赤字の年に、なぜ配当を出すことができるのか？ そして、出すべきなのか？**

## 純資産の部 ― 株主から預かったものと、会社が稼いで貯めたもの

貸借対照表の**純資産の部**は、大きく2つに分かれる。株主が出したお金と、会社が稼いで貯めた利益を示す**株主資本**と、資産の評価の差額などを示す**評価・換算差額等**だ。

::table 純資産の部の構成（汐見酒造、2027年6月30日、単位：万円）
| 区分 | 勘定 | 金額 | 何を表すか |
| 株主資本 | 資本金 | 1,000 | 株主が出したお金（法律で定めた額） |
| 株主資本 | 資本剰余金（資本準備金・その他資本剰余金） | 0 | 株主が出したお金のうち、資本金にしなかった部分 |
| 株主資本 | 利益剰余金：利益準備金 | 250 | 稼いだ利益のうち、法律で積み立てが義務づけられた部分 |
| 株主資本 | 利益剰余金：その他利益剰余金（繰越利益剰余金） | 3,635 | 稼いだ利益の残り（配当などに使える） |
| 評価・換算差額等 | その他有価証券評価差額金 | 210 | その他有価証券の時価の上昇（第18章・第21章） |
|= 純資産合計 | | 5,095 | |
::

::theory 資本取引と損益取引
株主が出資したり、株主に配当したりする取引（**資本取引**）は、株主資本を直接増減させる。損益計算書を通らない。
会社が商売をして稼いだり損したりする取引（**損益取引**）は、損益計算書を通って、最後に当期純損益として繰越利益剰余金に入る。
2つを混ぜてはいけない。株主が出したお金を「利益」に見せたり、利益の不足を株主の出資で「埋めた」ように見せたりすれば、会社がどれだけ稼いだかが分からなくなる。
::

## 当期純損益の振替え ― 赤字は、繰越利益剰余金を減らす

決算で損益勘定に集めた当期純損益は、最後に繰越利益剰余金に振り替える。

::example 6月30日、当期純損失14,900,000円を、損益勘定から繰越利益剰余金に振り替えなさい
::answer
::journal 当期純損失は、繰越利益剰余金の借方へ
繰越利益剰余金 14,900,000 | 損益 14,900,000
::
当期純利益なら、貸借が逆になる（「損益／繰越利益剰余金」）。繰越利益剰余金は、これまでの利益の積み重ねから、配当や今期の損失を差し引いた残りだ。今期が赤字でも、過去の利益の貯えが残っていれば、繰越利益剰余金はプラスのまま。だから、赤字の年でも、配当を出すこと自体はできる。
::
::

## 剰余金の配当と、利益準備金

配当は、株主総会の決議で決まる。配当を出すときは、会社法の定めで、配当額の10分の1を**準備金**（繰越利益剰余金から配当するなら**利益準備金**）として積み立てなければならない。ただし、資本準備金と利益準備金の合計が、資本金の4分の1に達するまでだ。

::formula 利益準備金の積立額
次の①と②のうち、小さいほう
① 配当額 × 1/10
② 資本金 × 1/4 －（資本準備金 ＋ 利益準備金）
::

::example 剰余金の配当と処分を仕訳しなさい
(1) 前期の8月、株主総会で、繰越利益剰余金から1株500円、総額1,000,000円の配当を決議した（発行済株式2,000株）。当時の資本金は10,000,000円、資本準備金は0円、利益準備金は2,400,000円だった。
(2) (1)の配当金を普通預金から支払った。
(3) 別の会社の例：株主総会で、繰越利益剰余金から配当3,000,000円、別途積立金の積立て500,000円を決議した。資本金20,000,000円、資本準備金3,000,000円、利益準備金1,500,000円。
::answer
::journal (1) 利益準備金：①1,000,000円×1/10＝100,000円、②10,000,000円×1/4－2,400,000円＝100,000円。小さいほう100,000円
繰越利益剰余金 1,100,000 | 未払配当金 1,000,000
 | 利益準備金 100,000
::
::journal (2)
未払配当金 1,000,000 | 普通預金 1,000,000
::
::journal (3) 利益準備金：①300,000円、②20,000,000円×1/4－(3,000,000円＋1,500,000円)＝500,000円。小さいほう300,000円
繰越利益剰余金 3,800,000 | 未払配当金 3,000,000
 | 利益準備金 300,000
 | 別途積立金 500,000
::
(1)で、利益準備金は2,500,000円になり、資本金の4分の1（2,500,000円）に達した。これ以降、資本金が変わらないかぎり、配当をしても利益準備金を積み立てる必要はない。
配当や積立てのように、繰越利益剰余金の使い道を決めることを**剰余金の処分**という（配当も処分の1つ）。別途積立金のような**任意積立金**は、会社が自分で決めて積み立てる。
::
::

### 会社を始めるときの費用 ― 創立費と開業費

株主総会の後、千尋が、芹沢酒造の古い帳簿を持ってきた。130年前の創業の記録は残っていないが、40年前に株式会社にしたときの費用の記録があった。定款を作る費用、登記の費用。そして、新しい瓶詰め場を開くまでの準備の費用。
「会社を作る前後の費用って、どう扱うの？」

::theory 創立費と開業費
- **創立費**：会社を設立するためにかかった費用（定款の作成、設立の登記、株式の募集の広告など）
- **開業費**：会社を設立した後、営業を始めるまでにかかった費用（開業の準備のための給料・広告・事務所の賃料など）
2級では、どちらも支出したときの**費用**として処理する。損益計算書では、創立費は営業外費用、開業費は営業外費用（または販売費及び一般管理費）に表示する。これらを資産（繰延資産）として計上し、何年かで償却する方法は1級の範囲だ。
::

::example 新しく設立した会社の費用を仕訳しなさい（別の会社の例）
(1) 会社の設立にあたり、定款の作成と登記の費用300,000円を普通預金から支払った。
(2) 設立後、営業開始までの間に、開業準備のための広告と事務所の賃料200,000円を普通預金から支払った。
::answer
::journal (1)
創立費 300,000 | 普通預金 300,000
::
::journal (2)
開業費 200,000 | 普通預金 200,000
::
::
::

::exam 純資産の急所
- 配当のときの準備金：**配当額の1/10**と、**資本金の1/4－(資本準備金＋利益準備金)**の小さいほう。その他資本剰余金から配当するなら資本準備金、繰越利益剰余金からなら利益準備金
- 株式の発行：払込金額の全額が資本金が原則。**2分の1を超えない額**を資本準備金にできる。問題文の「会社法が認める最低額を資本金とする」は「2分の1を資本金、残りを資本準備金」
- 当期純利益は「損益／繰越利益剰余金」、当期純損失は「繰越利益剰余金／損益」
- 繰越利益剰余金がマイナス（借方残高）のときの配当はできない。欠損は、その他資本剰余金や任意積立金で填補できる（株主資本の計数の変動）
- **株主資本等変動計算書**：行は「当期首残高→当期変動額（項目ごと）→当期末残高」、列は純資産の各勘定。2級では株主資本とその他有価証券評価差額金を扱う
::

## 株式の発行 ― 澪が、蔵に出資する

株主総会の最後に、澪は1つの提案をした。「私が、汐見酒造に1,000万円を出資します」
商社で6年働いて貯めたお金だった。純資産を厚くして、芹沢酒造の問題に向き合う力を蔵につける。そして、それは、自分が蔵を継ぐという意思表示でもあった。
父は何も言わなかった。ただ、車椅子の手すりを握る右手に、力が入ったのを澪は見た。

::theory 株式の発行（増資）と、資本金・資本準備金
会社が株式を発行して、株主から払込みを受けたときは、**払込金額の全額を資本金**とするのが原則だ。ただし、払込金額の**2分の1を超えない額**は、資本金にせず**資本準備金**とすることができる。
資本金も資本準備金も、株主が出したお金で、配当には使えない。違いは、法律上の扱い（減らすときの手続きなど）と、資本金の額で決まる税金（登記の登録免許税など）にある。
{{new:2027年度〜}} 資本準備金・その他資本剰余金、剰余金の配当・処分、株主資本の計数の変動は、2027年度からの出題区分表で、2級の論点としてあらためて明記された。
::

::example 増資を仕訳しなさい
9月1日、汐見酒造は株式200株を1株50,000円で発行し、澪から払込金額10,000,000円が普通預金に入金された。会社法が認める最低額を資本金とする。
::answer
::journal 払込金額の2分の1を資本金、残りを資本準備金
普通預金 10,000,000 | 資本金 5,000,000
 | 資本準備金 5,000,000
::
この増資は資本取引なので、損益計算書には何も載らない。純資産は1,000万円増えるが、それは「稼いだ利益」ではなく「株主が出したお金」だ。
::
::

### 株主資本の計数の変動

株主資本の中で、勘定から勘定へ金額を移すことを**株主資本の計数の変動**という。株主総会の決議などで行い、純資産の合計は変わらない。

::example 株主資本の計数の変動を仕訳しなさい（いずれも別の会社の例）
(1) 資本準備金2,000,000円を資本金に組み入れた。
(2) 繰越利益剰余金の借方残高（欠損）3,000,000円を、その他資本剰余金で填補した。
(3) 別途積立金1,000,000円を取り崩して、繰越利益剰余金に振り替えた。
::answer
::journal (1)
資本準備金 2,000,000 | 資本金 2,000,000
::
::journal (2)
その他資本剰余金 3,000,000 | 繰越利益剰余金 3,000,000
::
::journal (3)
別途積立金 1,000,000 | 繰越利益剰余金 1,000,000
::
どれも、純資産の合計は1円も変わらない。中の「名札」が付け替わるだけだ。
::
::

## 答え合わせ ― 出せることと、出すべきこと

::solve 配当の原資は「今期の利益」ではなく、「これまでに貯めた剰余金」
配当は、今期の利益から出すのではない。これまでの利益の積み重ねである**繰越利益剰余金**（その他利益剰余金）から出す。今期が1,490万円の赤字でも、過去の貯えが3,635万円残っていれば、その範囲で配当はできる。
だが、「出せる」ことと「出すべき」ことは違う。配当は、現金で払う。繰越利益剰余金は帳簿の上の金額で、それと同じだけの現金が蔵にあるわけではない。そして、今期の赤字は、繰越利益剰余金を1,490万円減らした。来期も赤字が続けば、貯えはさらに減っていく。
::

澪は、株主総会でこう説明した。「今期は、無配にさせてください。剰余金は残っています。でも、そのお金は、新しいラインと研究と、小松さんの退職金と、芹沢酒造のために要ります。来期に黒字に戻したら、配当を再開します」
叔父は、腕を組んで考えていた。やがて言った。「お前が自分の金を1,000万円入れると言うんなら、俺が100万円にこだわるのも、みっともない話だな」

## 叔父の質問 ― 手元資金1,318億ドルで、株主資本はマイナス1,499億ドル

::scene 8月28日、夕方 ― 株主総会の後の座敷
総会の後、叔父は、澪の出資のことを、もう一度聞いてきた。
「お前の1,000万円は、損益計算書には載らんのだろう。株主の出した金と、会社の稼いだ金は、そんなにきっちり分けるものか」
澪は、スマートフォンで、あのAI企業の貸借対照表を開いて見せた。「叔父さん、この会社、手元に1,300億ドル以上のお金があるのに、株主資本はマイナス1,500億ドル近いんです」
「なんだそれは。債務超過か」
「そう見えます。でも、中身を分けると、まるで違う話になるんです」
::

上場を控えた Anthropic の貸借対照表（2026年9月30日）では、現金・現金同等物と短期投資は**1,318億ドル**。総資産は1,543億ドル。ところが、純資産の部の**株主資本は、マイナス1,499億ドル**だった。
内訳はこうだ。負債の合計は1,467億ドルで、その大部分の**1,305億ドルが転換約束手形**（将来、株式に転換される借入れ）。そして、負債と株主資本の間に、償還の可能性がある**転換優先株式1,575億ドル**が置かれている。株主資本の中の**累積の損失は1,562億ドル**。そのうち、2023年から2026年9月までに計上した、転換社債などの公正価値の変動の損失だけで、約1,351億ドルにのぼる（第18章・第22章）。
米国の会計基準では、一定の条件のある優先株式は株主資本の外に、転換約束手形は負債に表示される。だが、同社の届出書によれば、上場の際に、優先株式と転換約束手形は普通株式に転換される予定だ。
「お金を出した人の権利の形が、借金から株に変わるだけです」と澪は言った。「この章で習った、資本取引です。損益計算書は通りません」
澪は、叔父の前で、ノートに仕訳を書いた。仮に、転換約束手形のうち100億ドル分が普通株式に転換されたとすると（仕組みを示すための例。日本の会社法の考え方で、2分の1を資本金とする。単位：億ドル）、

::journal 負債（転換社債）が、純資産（資本金・資本準備金）に変わる
転換社債 100 | 資本金 50
 | 資本準備金 50
::

負債が100億ドル減り、純資産が100億ドル増える。現金は1ドルも動かず、損益もゼロだ。転換がすべて終われば、株主資本のマイナスの大部分は、負債と中間の区分から移ってくる金額で埋まる見込みになる。
叔父は、しばらく仕訳を眺めていた。「株主資本がマイナスなら、ふつうは潰れかけだ。だが、この会社は、手元に1,300億ドルある。マイナスの理由の多くは、株に変わる予定の借金と、その評価の上の損失というわけか」
「純資産の数字も、損益の数字と同じで、中身を分けないと正反対の結論になります。だから、私の1,000万円も、稼いだ利益と混ぜないで、資本金と資本準備金に入れるんです」
叔父は笑った。「お前に説教されるとはな」

::note

::cfo 澪の出資1,000万円 ― どう記録するか
株主総会の後、増資の手続きのために、椎名が3つの記録のしかたを並べた。岩倉は、別の案を持ち出した。「その1,000万円で、今期の赤字を消してしまえばいい。繰越利益剰余金に入れれば、決算書の赤字の跡が薄くなる」
::table 増資の記録のしかたの比較（払込金額1,000万円）
| 案 | 資本金 | 資本準備金 | 登記の登録免許税（資本金の増加額×0.7%、最低3万円） |
| A 全額を資本金 | 1,000万円 | 0円 | 7万円 |
| B 半分を資本金、半分を資本準備金 | 500万円 | 500万円 | 3万5,000円 |
| C 全額を資本準備金 | 0円 | 1,000万円 | ― |
| D 繰越利益剰余金に入れて、今期の赤字を埋める | ― | ― | ― |
::
まず、それぞれの案が会社法と、資本取引と損益取引の区別に合っているかを確かめてから選んでほしい。
::choice A. 全額を資本金にする。資本金が大きいほど、会社の信用が上がる
**△ 認められるが、得はない。**全額を資本金にするのは原則どおりで、問題はない。ただ、登録免許税は7万円と、B案の2倍になる。資本金が大きいことで信用が上がるという考えもあるが、融資の担当者が見るのは、資本金の額より、純資産の合計とその中身だ。
::
::choice B. 半分の500万円を資本金、残りの500万円を資本準備金にする
**◎ 会社法の範囲で、手続きと費用が最も合理的だ。**払込金額の2分の1までは資本準備金にできる。登録免許税は500万円×0.7%＝3万5,000円で済む。純資産の合計は、A案と同じく1,000万円増える。
仕訳は「普通預金 10,000,000／資本金 5,000,000・資本準備金 5,000,000」。
::
::choice C. 全額を資本準備金にして、資本金は増やさない
**× 会社法で認められていない。**資本準備金にできるのは、払込金額の2分の1までだ。少なくとも500万円は資本金にしなければならない。
::
::choice D. 繰越利益剰余金に入れて、今期の赤字を埋める
**× 資本取引と損益取引を混ぜている。**澪の1,000万円は、株主が出したお金（資本）であって、蔵が稼いだ利益ではない。これを繰越利益剰余金に入れれば、稼いでいない利益が貯えに混ざり、配当として払い出せる形になってしまう。決算書を読む人は、蔵が本当にいくら稼いで貯めたのかが分からなくなる。株主の出資で赤字の跡を消すことはできない。
::
::answer 考え方の例を見る
株主が出したお金（資本金・資本準備金）と、会社が稼いで貯めたお金（利益剰余金）は、純資産の中でも、はっきり分けて記録する。株式の発行では、払込金額の2分の1以上を資本金にし、残りを資本準備金にできる。
澪はB案で増資の登記をした。9月1日、汐見酒造の株主名簿に、澪の名前が加わった。持株は200株。父の1,300株にはまだ遠い。だが、父は病院で、株主名簿の写しを長いこと眺めていたと、母があとで教えてくれた。
::

::quiz
::problem 次の資料から、利益準備金の積立額を求めなさい。
繰越利益剰余金からの配当 4,000,000円、資本金 30,000,000円、資本準備金 5,000,000円、利益準備金 2,200,000円
利益準備金の積立額 [[300,000]] 円
::answer
①4,000,000円×1/10＝400,000円、②30,000,000円×1/4－(5,000,000円＋2,200,000円)＝7,500,000円－7,200,000円＝300,000円。小さいほうの**300,000円**を積み立てる。
::

::summary
- 純資産は、株主資本（資本金・資本剰余金・利益剰余金）と評価・換算差額等（その他有価証券評価差額金など）からなる
- 株式の発行は払込金額の全額が資本金の原則。2分の1を超えない額は資本準備金にできる
- 配当は繰越利益剰余金（過去の利益の貯え）から出す。配当額の1/10を、準備金の合計が資本金の1/4に達するまで利益準備金に積み立てる
- 株主資本の計数の変動は、純資産の中の名札の付け替えで、合計は変わらない
- 資本取引（出資・配当）と損益取引を混ぜない。出資で赤字を消すことはできない
- 赤字の年でも配当は出せるが、出すべきかは、現金と将来の計画で判断する
::
