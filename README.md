# ケースで学ぶ簿記2級

潰れかけた新潟の酒蔵を、跡取りの汐見澪が数字で立て直す1年の物語を追いながら、日商簿記2級の商業簿記と工業簿記の全範囲を学ぶ HTML 教科書です。就活生・転職を考えている人・仕事で資格が必要な人、そして簿記を理解して数字に強くなりたい人に向けて、「読み物として面白く、手を動かして身につき、仕事にまでつながる」ことを目指しています。

本書には、もう1つの通しの問いがあります。**「赤字」の中身を読む**ことです。売上が1年で12倍になったアメリカのAI企業 Anthropic が、なぜ420億ドルの赤字を出したのか。上場の届出書の数字を、2級の勘定科目と損益の「段」で読み解き、主人公の蔵の赤字の決算書と並べていきます。

## 読み方

- `public/index.html` をブラウザで開くと、表紙と目次が表示されます（スマートフォン最適化済み）。
- `public/all.html` は全章を1ファイルにまとめた一気読み版です。
- 表示には Tailwind CSS（CDN）と Google Fonts を読み込むため、インターネット接続が必要です。

## 物語の仕掛け（第2版）

学習漫画のように、ページをめくる手が止まらない仕掛けを入れています。

- **タイムリミット**：章の扉に「融資審査まで あと○日」（第3部は「再建計画の提出まで」）。審査の日は第22章
- **事件（::mystery）**：各章は、蔵で起きる数字の事件と、太字の問いから始まる。主人公はときに間違え、番頭や会計士の問いに導かれて仕訳で謎を解く
- **父の黒い手帳（::memo）**：倒れた父が残した暗号の行が、2級の知識がそろうたびに1行ずつ読める。最後の紙は終章で開く
- **次回予告（::teaser）**：各章の最後に、次の事件の予告

## 各章の型

事件 → 本編（場面から入り、会話で解説）→ 謎解き（::solve）→ 試験で狙われるパターンと「解法の型」→ 実際の事例の場面（登場人物が持ち込み、その章の仕訳で再現。出典つき）→ 落とし穴（::danger）→ **考えてみよう**（3級と同じ形の選択式。前提・4つの選択肢・講評・考え方の例）→ 試験の急所 → 次の級へ → まとめ → 確認問題（自動採点）→ 次回予告

## 構成

| パス | 内容 |
| --- | --- |
| `public/` | **公開するファイル（HTMLのみ）**。`build.pl` が自動生成する |
| `_src/` | 本文の原稿（独自の軽量マークアップ）。`book.txt` が章の並びと本の設定 |
| `_notes/` | 調査ノート（`research.md`）、物語の設計書（`story-bible.md`）、出題範囲の対応表（`coverage.md`）、設定の台帳（`continuity.md`）。公開しない |
| `build.pl` | HTMLを生成し、仕訳の貸借一致などを自動で検証するスクリプト（Perl 5、追加モジュール不要） |
| `assets/kb.js` | 演習・用語・考えてみよう・シミュレーター・模擬試験のスクリプト（ビルド時に各ページへ埋め込む） |
| `.claude/skills/boki-textbook/` | 教科書の作り方をまとめた Claude Code のスキル（手順・記法・品質基準・検証スクリプト） |
| `CLAUDE.md` | この作業フォルダでの決まりごと（Claude Code が自動で読む） |

## 演習

- 仕訳入力（ドラッグ＋金額入力＋答え合わせ）119問、穴埋め41、分類12
- 考えてみよう（選択式・講評つき）：各章に1つ、計28
- シミュレーター：第10章の損益分岐図表（`::sim cvp`。販売価格・変動費・固定費・販売本数を動かせる）
- 模擬試験：付録D（90分タイマー、大問ごとの自動採点、復習する章の提示）

## 編集・再生成

```sh
perl build.pl
```

- 記法の一覧は `build.pl` 冒頭のコメントと、`.claude/skills/boki-textbook/references/markup.md` を参照してください。
- ビルド時に、すべての仕訳の貸借一致、T字勘定の合計、`sum` 指定した表の縦計、表の列数を検証します。不一致があると警告を表示して終了コード1で終わります。
- ページの URL に `?selftest` を付けて開くと、そのページの演習を自動で検査し、結果を画面上部に表示します（`bash .claude/skills/boki-textbook/scripts/st.sh public ch01.html` でヘッドレスの Chrome から実行できます）。

## 公開（Cloudflare Pages）

GitHub のリポジトリに push し、Cloudflare Pages で `public/` を配信します（Framework preset：None、Build command：空欄、Build output directory：`public`）。

## 架空と実在について

物語に登場する企業（汐見酒造・芹沢酒造・越後物産・越後みなと信用金庫など）・人物・銘柄・数値は、学習用に設計した架空のものです。実在の企業・団体とは関係ありません。登場人物が持ち込む実際の事例は、各章の出典（公的資料・企業の開示・報道）にもとづいています。
