# ケースで学ぶ簿記2級

潰れかけた新潟の酒蔵を、跡取りの汐見澪が数字で立て直す1年の物語を追いながら、日商簿記2級の商業簿記と工業簿記の全範囲を学ぶ HTML 教科書です。

本書には、もう1つの通しの問いがあります。**「赤字」の中身を読む**ことです。売上が1年で12倍になったアメリカのAI企業 Anthropic が、なぜ420億ドルの赤字を出したのか。研究開発費を発生した年に全額費用にするルール、計算資源（設備・リース）の計上のタイミング、評価の上だけで生まれる損失など、2級で学ぶ計上のしかたで分解すると、「赤字」という1語の中に性質の違うものが混ざっていることが見えてきます。蔵の決算も、同じ読み方で信用金庫に説明することになります。

## 読み方

- `public/index.html` をブラウザで開くと、表紙と目次が表示されます（スマートフォン最適化済み）。
- `public/all.html` は全章を1ファイルにまとめた一気読み版です。
- 表示には Tailwind CSS（CDN）と Google Fonts を読み込むため、インターネット接続が必要です。

## 構成

| パス | 内容 |
| --- | --- |
| `public/` | **公開するファイル（HTMLのみ）**。`build.pl` が自動生成する |
| `_src/` | 本文の原稿（独自の軽量マークアップ）。`book.txt` が章の並びと本の設定 |
| `_notes/` | 調査ノート（`research.md`）と物語の設計書（`story-bible.md`）。公開しない |
| `build.pl` | HTMLを生成し、仕訳の貸借一致などを自動で検証するスクリプト（Perl 5、追加モジュール不要） |
| `assets/kb.js` | 演習・用語・シミュレーター・模擬試験のスクリプト（ビルド時に各ページへ埋め込む） |
| `.claude/skills/boki-textbook/` | 教科書の作り方をまとめた Claude Code のスキル（手順・記法・品質基準・検証スクリプト） |
| `CLAUDE.md` | この作業フォルダでの決まりごと（Claude Code が自動で読む） |

出題範囲は、日本商工会議所が2026年7月31日に公表した「2027年度適用」の出題区分表（2027年4月1日以降の試験に適用）に準拠し、2027年3月までの試験との違いを各章で注記しています。

## 演習

- 仕訳入力（ドラッグ＋金額入力＋答え合わせ）186問、穴埋め47、分類11、判断してみよう（選択式）29
- シミュレーター：第10章の損益分岐図表（`::sim cvp`。販売価格・変動費・固定費・販売本数を動かせる）
- 模擬試験：付録D（90分タイマー、大問ごとの自動採点、復習する章の提示）

## 編集・再生成

```sh
perl build.pl
```

- 記法の一覧は `build.pl` 冒頭のコメントと、`.claude/skills/boki-textbook/references/markup.md` を参照してください。
- ビルド時に、すべての仕訳の貸借一致、T字勘定の合計、`sum` 指定した表の縦計、表の列数を検証します。不一致があると警告を表示して終了コード1で終わります。
- ページの URL に `?selftest` を付けて開くと、そのページの演習を自動で検査し、結果を画面上部に表示します（`bash .claude/skills/boki-textbook/scripts/st.sh public ch01.html` で一括実行）。

## 公開（Cloudflare Pages）

GitHub のリポジトリに push し、Cloudflare Pages で `public/` を配信します（Framework preset：None、Build command：空欄、Build output directory：`public`）。

## 架空と実在について

物語に登場する企業（汐見酒造・芹沢酒造・越後物産・越後みなと信用金庫など）・人物・銘柄・数値は、学習用に設計した架空のものです。実在の企業・団体・商品とは関係ありません。物語の中で取り上げる実際の事例と統計は、公開されている報道・統計資料・企業の開示資料にもとづき、出典を併記しています。仕組みを示すために単純化した数字は、本文でそう明記しています。本書は特定の企業への投資を勧めるものではありません。
