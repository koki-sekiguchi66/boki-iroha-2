# ケースで学ぶ簿記2級

潰れかけた新潟の酒蔵を、跡取りの汐見澪が数字で立て直す1年の物語を追いながら、日商簿記2級の商業簿記と工業簿記を学ぶ HTML 教科書です（制作中：序章・第1章の試作まで）。

## 読み方

- `public/index.html` をブラウザで開くと、表紙と目次が表示されます（スマートフォン最適化済み）。
- `public/all.html` は全章を1ファイルにまとめた一気読み版です。
- 表示には Tailwind CSS（CDN）と Google Fonts を読み込むため、インターネット接続が必要です。

## 構成

| パス | 内容 |
| --- | --- |
| `public/` | **公開するファイル（HTMLのみ）**。`build.pl` が自動生成する |
| `_src/` | 本文の原稿（独自の軽量マークアップ）。`book.txt` が章の並びと本の設定 |
| `_notes/` | 調査ノート（`research.md`）と物語の設計書（`story-bible.md`）。公開しない |
| `build.pl` | HTMLを生成し、仕訳の貸借一致などを自動で検証するスクリプト（Perl 5、追加モジュール不要） |
| `assets/kb.js` | 演習・用語・模擬試験のスクリプト（ビルド時に各ページへ埋め込む） |
| `.claude/skills/boki-textbook/` | 教科書の作り方をまとめた Claude Code のスキル（手順・記法・品質基準・検証スクリプト） |
| `CLAUDE.md` | この作業フォルダでの決まりごと（Claude Code が自動で読む） |

出題範囲は、日本商工会議所が2026年7月31日に公表した「2027年度適用」の出題区分表（2027年4月1日以降の試験に適用）に準拠し、2027年3月までの試験との違いを各章で注記します。

## 編集・再生成

```sh
perl build.pl
```

- 記法の一覧は `build.pl` 冒頭のコメントと、`.claude/skills/boki-textbook/references/markup.md` を参照してください。
- ビルド時に、すべての仕訳の貸借一致、T字勘定の合計、`sum` 指定した表の縦計、表の列数を検証します。不一致があると警告を表示して終了コード1で終わります。
- ページの URL に `?selftest` を付けて開くと、そのページの演習を自動で検査し、結果を画面上部に表示します。

## 公開（Cloudflare Pages）

本の完成後に GitHub の公開リポジトリへ push し、Cloudflare Pages で `public/` を配信します（Framework preset：None、Build command：空欄、Build output directory：`public`）。

物語に登場する企業・人物・銘柄・数値は、学習用に設計した架空のものです。「実際にあった話」で紹介する事例と統計は、公開されている報道・統計資料にもとづき、出典を併記しています。
